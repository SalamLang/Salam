Salam Agent

Salam AI, with hands. Salam Agent opens the assistant in its own window and lets it work in a folder on your computer: run commands, use Docker and WSL, read and edit files and run your tests. You decide how much it may do without asking.

How it works

The assistant runs on Salam's servers. Salam Agent is the part on your computer that carries out its requests, so your files stay where they are.

Install and sign in

Open Salam Agent and sign in with your Salam AI account. The app registers this computer and keeps its key in your system's keychain.

Choose a folder

Start a chat with a work folder. That folder is the assistant's workspace: commands start in it, and file tools check every path against it and ask before using one outside it.

Approve and watch

Each command and change appears as a card in the chat. Allow it, deny it, or always allow that tool. A running command can be stopped from its card.

What it can do

Everything you would do in a terminal and an editor to get a Salam project working, done by the assistant while you watch.

  • Run commands in Bash, sh, PowerShell or cmd
  • Build and run containers with Docker, and use WSL on Windows
  • Read, search, create and edit files in the work folder
  • Build your program, run its tests and fix what fails
  • Port an existing PHP, C#, C, C++ or Go project to Salam; new projects are written in Salam

You set the limits

Pick an access level for each chat in the message box.

Level Reading in the folder Writing and commands in the folder Anything outside the folder
Ask before every changeRunsAsks you, or always for that toolAsks you
Automatic in the work folderRunsRunsAsks you
Read onlyRunsRefusedAsks for reads, refuses the rest

Writes inside .git are always refused. Commands stop after two minutes unless the assistant asks for longer, up to 30 minutes. Only ai.salamlang.ir can talk to the app, and links to other sites open in your normal browser. Shell commands start in the work folder but are not confined to it, so in automatic mode a command can still reach paths outside it; read what you ask for.

First launch

The macOS builds are not notarized yet. After copying the app to Applications, run this once, or right-click the app and choose Open.

xattr -dr com.apple.quarantine "/Applications/Salam Agent.app"

Windows SmartScreen may ask you to confirm for the same reason: choose More info, then Run anyway.

Check your download

Every file on the release page has a .sha256 file beside it. Download both into the same folder and run:

sha256sum -c salam-agent-*.sha256

On macOS use shasum -a 256 -c. On Windows, certutil -hashfile file SHA256 prints the hash to compare.
