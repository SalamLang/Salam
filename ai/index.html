Salam AI

An assistant built for the Salam programming language. Ask it how something works, have it write or fix a program, or paste a compiler error and get it explained. It answers from the current language and standard library, not from guesses based on other languages.

Open Salam AI Get Salam Agent

Sign up with an email address; your chats are saved to your account. The interface is in Persian and right to left.

What it is good at

Salam's syntax differs from every mainstream language, so a general chatbot tends to make it up. Salam AI checks against the real thing.

Questions about Salam

Syntax, types, loops, structs, generics, error handling and the layout language. Ask in your own words and get an answer with code you can run.

Writing and fixing code

Describe a program and get Salam code that the assistant checks with the Salam compiler, or paste one that does not compile and find out why. Code in answers is highlighted with the same grammar as the VS Code plugin.

The standard library

More than 80 packages, from JSON and HTTP to databases and machine learning. It looks up the real function names and signatures instead of inventing them.

Salam Agent

Let it work on your computer

Salam Agent is a desktop app for Windows, macOS and Linux. It opens Salam AI in its own window and lets the assistant work in a folder you choose, within the limits you set: run commands, edit files and run your tests.

Get Salam Agent
  • Runs Bash, sh, PowerShell and cmd commands, plus Docker and WSL
  • Reads, searches, creates and edits files in your work folder
  • Asks before every change, or works on its own inside the folder, your choice
  • Its file tools ask before reading or writing anything outside the folder

For developers

The same assistant is available to your own programs and to the AI tools you already use.

OpenAI-compatible API

Point any OpenAI client at the Salam AI API and use the model salam. Create a key on the keys page of Salam AI.

from openai import OpenAI client = OpenAI(base_url="https://ai-api.salamlang.ir", api_key="sk-salam-...") reply = client.chat.completions.create( model="salam", messages=[{"role": "user", "content": "Write hello world in Salam"}], )

MCP server

Give Claude Code, Cursor or any other MCP client the Salam tools: check, run and format code, search the standard library and read the docs. You sign in with your Salam AI account, on any plan, including the free one.

claude mcp add --transport http salam https://mcp.salamlang.ir/mcp
