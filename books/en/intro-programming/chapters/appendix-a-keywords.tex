This appendix lists every Salam keyword in both languages, taken directly from the
compiler's language pack (\code{compiler/langpack.salam}). A program is written
in one language; the compiler recognises which one from its keywords, and
\code{--lang=en} or \code{--lang=fa} states it explicitly. Only the spellings
below differ between the two: the meaning and grammar are identical.

\noindent Two Persian words do double duty. \code{\fa{تا}} is \code{until}, and
inside a \code{\fa{تکرار}} header it is \code{to}; \code{\fa{هر}} is \code{each},
and inside a \code{\fa{تکرار}} header it is \code{by}. The compiler picks the
meaning from the position. In Persian, \code{\fa{صفحه}} is the layout keyword


\begin{note}
Words that other languages use, such as \code{while}, \code{for}, \code{return},
\code{elif}, \code{let}, \code{var}, \code{def}, \code{class} and \code{auto},
are not Salam keywords. The compiler recognises the common ones and tells you the
Salam word to write instead.
\end{note}

\begin{note}
The entry function \code{main} is \code{\fa{ریشه}} in a Persian program. It is
an ordinary function name rather than a keyword, but the compiler looks for it
as the place to start.
\end{note}

\noindent The short spellings \code{int} ($=$ \code{i32}), \code{uint}
($=$ \code{u32}) and \code{float} ($=$ \code{f32}) name the very same types;
\code{int} is what this book uses in ordinary code. Note that \code{\fa{اعشار}}
is \code{f32}, while a float literal such as \code{3.14} is \code{f64}
(\code{\fa{اعشار۶۴}}). There is no type called \code{auto}: a declaration
\code{x := value} takes its type from the value. The digits inside the Persian
type names (for example \fa{۳۲} in \code{\fa{صحیح۳۲}}) are Persian digits, part
of the name's spelling. Number literals in a program may be written with the
ordinary digits \code{0} to \code{9} or with Persian digits; either way, a program
prints its numbers with the ordinary digits.
