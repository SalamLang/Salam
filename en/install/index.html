Install Salam

The Salam compiler is a single executable. The installer puts it in your home directory and adds it to your path; it does not need administrator access.

Linux and macOS

Run this in a terminal. The installer detects your operating system and architecture and adds the Salam directory to your PATH; open a new terminal once it finishes.

{ curl -fsSL https://raw.githubusercontent.com/SalamLang/Salam/refs/heads/main/install.sh || wget -qO- https://raw.githubusercontent.com/SalamLang/Salam/refs/heads/main/install.sh; } | sh

To pass options to the installer, put them after sh -s --, for example … | sh -s -- --version 0.5.0.

Windows

Open PowerShell and run this command.

irm https://raw.githubusercontent.com/SalamLang/Salam/refs/heads/main/install.ps1 | iex

If PowerShell reports a secure connection error, run the installer from the command prompt instead:

curl -fsSLo "%TEMP%\salam-install.bat" https://raw.githubusercontent.com/SalamLang/Salam/refs/heads/main/install.bat && "%TEMP%\salam-install.bat"

Check the install

Open a new terminal and ask Salam for its version. If it prints one, you are ready.

salam version

Installer options

The Linux and macOS installer accepts these options. Run it with --help for the full list.

Option What it does
--dir DIRInstall into a directory of your choice instead of ~/.salam/bin
--version X.Y.ZInstall a specific release instead of the latest one
--platform NAMEChoose the operating system and architecture by hand
--no-modify-pathLeave your shell files and PATH untouched

Docker

If you would rather not install anything, run Salam in Docker. Run this in a directory containing app.salam; the current directory is mounted inside the container. Images are built for x86-64, ARM64 (including Apple silicon), ARMv7 and i386; run docker pull basemax/salam first to get the latest one.

docker run --rm -v "$PWD":/work basemax/salam run app.salam

Build from source

The Salam compiler is written in Salam. To build it you need an installed Salam and a C compiler.

git clone https://github.com/SalamLang/Salam && cd Salam && sh tools/bash/build-selfhost.sh

Installed? Head to the course to write your first program, or pick up your editor plugin from the tools page.
