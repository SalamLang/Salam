Working with C

Salam talks to C libraries directly, which means every C library in the world is available from Salam.

In this lesson
  1. extern
  2. Linking a library
  3. export

extern

Inside an extern: block, declare C functions with their parameter and result types, then call them like any Salam function:

ffi-extern.salam
extern:
    func sqrt(x: f64): f64
    func abs(x: int): int
end

func main:
    println sqrt(2.0)
    println abs(-42)
end
Output1.4142135623730951 42

Linking a library

For an outside library, write link dynamic "sqlite3" (or link static) before the declarations. A function that takes a variable number of arguments, such as printf, needs ... in its declaration.

export

Functions that C code has to call go in an export: block, so they are reachable from C under their plain name.
