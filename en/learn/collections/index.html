Vector and HashMap

An array has a fixed size. A Vector is a list that grows and shrinks, and a HashMap connects every key to a value.

In this lesson
  1. Vector
  2. HashMap

Vector

Build one with Vector {} as Vector<type>. push adds an element, get and set read and replace one, pop takes the last one off and len gives the count.

vector.salam
func main:
    mut numbers := Vector {} as Vector<int>
    defer numbers.free()
    numbers.push(10)
    numbers.push(20)
    numbers.push(30)
    numbers.set(1, 25)
    println numbers.len(), numbers.get(1)
    last := numbers.pop()
    println last, numbers.len()
    each n in numbers:
        println n
    end
end
Output3 25 30 2 10 25

A Vector and a HashMap both allocate. Write defer ....free() straight after creating one, so the memory is released when the function ends.

HashMap

A HashMap connects keys to values: put stores a pair, get returns the value for a key, has tests whether a key is there, remove takes it out and size gives the number of pairs. each key, value in map walks all of them.

hashmap.salam
func main:
    mut capitals := HashMap {} as HashMap<str, str>
    defer capitals.free()
    capitals.put("Iran", "Tehran")
    capitals.put("Japan", "Tokyo")
    println capitals.get("Iran")
    println capitals.has("France"), capitals.size()
    capitals.remove("Japan")
    each country, city in capitals:
        println country, "->", city
    end
end
OutputTehran false 2 Iran -> Tehran
