Your first program

In this lesson you write and run your first Salam program and get a feel for what Salam code looks like.

In this lesson
  1. Hello, world
  2. Running a program
  3. Printing output
  4. Reading input
  5. Comments
  6. One line blocks

Hello, world

Every Salam program starts at func main, the first thing that runs. A block opens with a colon (:) and closes with end, and indenting the lines inside it keeps the code readable.

hello.salam
func main:
    println "Hello, world!"
end
OutputHello, world!

Running a program

Save your code in a file with a .salam extension, say hello.salam. salam run hello.salam compiles it and runs it straight away. If you want a standalone executable instead, use salam build hello.salam and a native binary appears next to your source. salam format tidies the code into one consistent shape, and salam translate fa hello.salam turns an English program into a Persian one (translate en goes the other way). You can also run every example here in the online editor without installing anything.

Printing output

println prints its values and moves to the next line; print stays on the same line. Separate several values with commas and Salam writes them out with one space between them.

start-print.salam
func main:
    println "Hello", "world"
    print "no "
    print "line break"
    println ""
    println "today it is", 20, "degrees"
end
OutputHello world no line break today it is 20 degrees

For error messages use printerrln and printerr. They write to standard error, so they stay out of the program's real output and survive being piped elsewhere.

start-stderr.salam
func main:
    println "this line goes to standard output"
    printerrln "this line goes to standard error"
end
Outputthis line goes to standard output this line goes to standard error

Reading input

input reads one line from the user and gives it back as a string. Like print it takes no parentheses, and it always wants a prompt, which it prints before reading. If you do not want one, write input "":

start-input.salam
func main:
    name := input "Your name: "
    println "Hello,", name
end

Comments

Anything after // to the end of the line, and anything between /* and */, is a comment and is not run.

start-comments.salam
// this is a single line comment and is not run

/*
A block comment:
anything between these two markers is ignored.
*/

func main:
    println "comments never show up in the output" // this is a comment too
end
Outputcomments never show up in the output

One line blocks

When the body of a block is short, you can put the whole thing on one line:

start-oneline.salam
func main: println "a one line program" end
Outputa one line program

Salam is bilingual: every program on this site can also be written with Persian words. The keyword lesson has the full table.
