Concurrency

A Salam program can do several things at once, across the cores of the processor.

In this lesson
  1. spawn and join

spawn and join

spawn(function) starts the function on a new thread and gives back its handle; join(handle) waits for that thread to finish. The function may take no parameters, or exactly one pointer: spawn(function, data).

threads.salam
mut message := ""

func worker():
    message = "the work was done on another thread"
end

func main:
    t := spawn(worker)
    join(t)
    println message
end
Outputthe work was done on another thread

For coordinating threads with locks, channels and atomic counters, reach for the sync, chan and atomic packages.
