Salam for Sublime Text
======================

Thanks for installing Salam language support.

Getting started
---------------

  1. Make sure the compiler is on your PATH:  salam version
     If it is not, set "compiler_path" in
     Preferences > Package Settings > Salam > Settings.

  2. Open a .salam file. Highlighting and indentation apply automatically.

  3. Tools > Build System > Salam, then Ctrl+B to run the file.
     Ctrl+Shift+B picks a variant: build, check, format, inspect, web, js.

  4. Command palette: "Salam: Format File" and "Salam: Check File".

Persian and Arabic
------------------

Keywords may be written in English, Persian or Arabic. All three are
highlighted, and the keyword pack is detected per file from a "//! lang:"
directive or from the script the file is written in. Set "language_pack"
to "en", "fa" or "ar" to pin it.

Documentation: https://github.com/SalamLang/Salam
