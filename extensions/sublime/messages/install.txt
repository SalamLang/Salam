Salam for Sublime Text
======================

Thanks for installing Salam language support.

Getting started
---------------

  1. Make sure the compiler is on your PATH:  salam version
     If it is not, set "compiler_path" in
     Preferences > Package Settings > Salam > Settings.

  2. Open a .salam file. Highlighting and indentation apply automatically.

  3. Tools > Build System > Salam, then Ctrl+B to run the file or project.
     Ctrl+Shift+B picks a variant: build, check, format, inspect, web, js.

  4. Command palette: "Salam: New Project", "Salam: Select Platform",
     "Salam: Run", "Salam: Build", "Salam: Format File", "Salam: Check File".

  5. The status bar shows the blocks around the cursor, such as
     page > box > button, and the chosen platform.

Persian
-------

Keywords may be written in English or Persian. Both are
highlighted, and the keyword pack is detected per file from a
"// زبان: فارسی" or "// lang: en" directive or from the script the file is written in. Set "language_pack"
to "en" or "fa" to pin it.

Documentation: https://github.com/SalamLang/Salam
