*salam.txt*   Salam language support for Vim and Neovim

                            SALAM                            *salam* *salam.vim*

Syntax highlighting, indentation, snippets, formatting and diagnostics for the
Salam programming language.  https://github.com/SalamLang/Salam

Salam keywords are spelled in English, Persian or Arabic.  All three are
highlighted, and the keyword pack is detected per file.

1. INSTALL                                                    *salam-install*

With any plugin manager, point it at the `extensions/vim` directory of the
Salam repository.

vim-plug: >
    Plug 'SalamLang/Salam', { 'rtp': 'extensions/vim' }
<
lazy.nvim: >
    { 'SalamLang/Salam', config = function()
        vim.opt.rtp:append(vim.fn.stdpath('data')
              .. '/lazy/Salam/extensions/vim')
      end }
<
Without a manager, copy the contents of `extensions/vim` into `~/.vim` (Vim)
or `~/.config/nvim` (Neovim), then run `:helptags ALL`.

The `salam` compiler must be on your `$PATH`, or |g:salam_compiler| must give
its full path.

==============================================================================
2. COMMANDS                                                  *salam-commands*

                                                                   *:SalamRun*
:SalamRun [args]        Write the buffer and run it.  Uses `salam exec` by
                        default; see |g:salam_run_command|.  Extra arguments
                        are passed to the compiler.

                                                                 *:SalamBuild*
:SalamBuild [args]      Write the buffer and compile it to an executable.
                        Errors go to the quickfix list.

                                                                 *:SalamCheck*
:SalamCheck             Lex, parse and analyze the file without running it,
                        and load the diagnostics into the quickfix list.

                                                                   *:SalamFmt*
:SalamFmt               Reformat the buffer with `salam format`.  Undo and
                        the cursor position survive.

                                                              *:SalamFmtCheck*
:SalamFmtCheck          Report whether the file is already formatted.

                          *:SalamTokens* *:SalamAst* *:SalamSymbols*
:SalamTokens            Open the token stream as XML in a scratch window.
:SalamAst               Open the analyzed AST as XML.
:SalamSymbols           Open the symbol table as XML.

                                                               *:SalamVersion*
:SalamVersion           Echo the compiler version.

==============================================================================
3. OPTIONS                                                    *salam-options*

                                                           *g:salam_compiler*
Path to the compiler.  A bare name is looked up on `$PATH`. >
    let g:salam_compiler = 'salam'
<
                                                               *g:salam_lang*
Keyword pack passed as `--lang`: "auto", "en", "fa" or "ar".  "auto" reads a
`//! lang:` directive, then falls back to the script the file is written in. >
    let g:salam_lang = 'auto'
<
                                                        *g:salam_run_command*
Subcommand |:SalamRun| uses.  "exec" is the tree-walking interpreter and needs
no C toolchain; "run" compiles first. >
    let g:salam_run_command = 'exec'
<
                                                      *g:salam_format_indent*
Indentation handed to `salam format --indent`: "tab", or 1 to 16 spaces. >
    let g:salam_format_indent = '4'
<
                                                     *g:salam_format_on_save*
Reformat the buffer on every write. >
    let g:salam_format_on_save = 0
<
                                                      *g:salam_check_on_save*
Run |:SalamCheck| after every write. >
    let g:salam_check_on_save = 0
<
                                                       *g:salam_stdlib_path*
Root directory for `std/...` imports, passed as `--stdlib-path`.  Empty lets
the compiler find it. >
    let g:salam_stdlib_path = ''
<

4. NEOVIM                                                        *salam-nvim*

Everything above works in Neovim unchanged.  A Lua layer adds asynchronous
diagnostics through |vim.diagnostic|: >
    require('salam').setup({
      compiler = 'salam',
      lang = 'auto',
      indent = '4',
      format_on_save = false,
      diagnostics = true,
    })
<
With `diagnostics = true` the file is type-checked after every write and on
read, and the results appear as normal Neovim diagnostics.

                                                    *:SalamCheckDiagnostics*
:SalamCheckDiagnostics  Type-check now and refresh |vim.diagnostic|.

`:checkhealth salam` reports whether the compiler was found and which version
it is.

==============================================================================
5. SNIPPETS                                                  *salam-snippets*

`UltiSnips/salam.snippets` is read automatically by SirVer/ultisnips.  The
triggers are: >
    main func funcv if ifelse until each eachi eachkv repeat repeati
    repeatrange var mut const struct enum interface impl import extern
    layout component println
<
==============================================================================
6. LINTING                                                       *salam-lint*

|:SalamCheck| needs nothing extra.

With dense-analysis/ale installed, `ale_linters/salam/salam.vim` registers a
`salam` linter that runs the same check as you type: >
    let g:ale_salam_executable = 'salam'
    let g:ale_salam_options = ''
<

7. HIGHLIGHT GROUPS                                         *salam-highlight*

The syntax file defines these and links them to the standard groups, so any
colorscheme works.  Override a link to change one: >
    hi link salamLayoutElement Special
<
    salamConditional      if, else, match
    salamRepeat           until, while, repeat, each
    salamStatement        ret, end, break, continue, defer, to, by, in, with
    salamStorageClass     mut, const, pub, inline, extern, ...
    salamStructure        type, struct, enum, interface, component
    salamInclude          import, package
    salamKeyword          on, as, layout, operator, impl
    salamFuncDecl         func
    salamContextual       link, static, dynamic, framework, kind, dyn
    salamType             primitive type names, auto
    salamBuiltinType      Vector, HashMap, MapIter, File, Variant
    salamBuiltin          print, println, printerr, printerrln, input
    salamBuiltinMethod    push, pop, get, set, len, ... after a dot
    salamFunctionName     the name in a declaration
    salamFunctionCall     a name followed by (
    salamTypeName         the name after struct, enum, type, ...
    salamModuleName       the name after import or package
    salamLayoutElement    a layout DSL element opening a block
    salamThis             this
    salamBoolean          true, false
    salamNull             null
    salamOperatorWord     the Persian and Arabic and/or operators
    salamDirective        a //! header line
    salamDirectiveKey     mode, title, lang, dir, name, version
    salamAnnotation       @name
    salamString           "..." and """..."""
    salamRawString        `...`
    salamCharacter        'c'
    salamEscape           an escape inside a string
    salamEscapeError      an escape that is not valid
    salamNumber           integers, including Persian and Arabic digits
    salamFloat            floats, including Persian and Arabic digits
