Conditions

Conditions are how a program decides, from its data, which way to go.

In this lesson
  1. if, else if, else
  2. Short conditions, and joining them
  3. The rules a condition follows

if, else if, else

The body of an if runs only when its condition holds. Test further conditions with else if, and cover everything that is left with else.

conditions.salam
func grade(score: int): str:
    if score >= 90:
        ret "excellent"
    else if score >= 70:
        ret "good"
    else:
        ret "needs more work"
    end
end

func main:
    println grade(95)
    println grade(72)
    println grade(40)
end
Outputexcellent good needs more work

Short conditions, and joining them

A short condition fits on one line. Join several conditions with and and or.

cond-inline.salam
func main:
    number := 7
    if number % 2 == 0: println "even" else: println "odd" end
    if number > 0 and number < 10:
        println "a positive single digit number"
    end
end
Outputodd a positive single digit number

The rules a condition follows

  • A condition has to be a bool. if number: is an error; write if number != 0:.
  • A condition that is always true, or always false, is rejected, because one of the branches would never run.
  • No branch may be empty. Instead of an empty branch, invert the condition with not.
