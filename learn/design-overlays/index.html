Overlays and menus

Some parts of a page appear only when asked: a dialog, a menu, a hint. This lesson shows every such component of the design system, with its elements, attributes, values and a live example you can click.

In this lesson
  1. Panels that stay on the page
  2. Dialogs, sheets and drawers
  3. Popovers and tooltips
  4. Menus

Panels that stay on the page

Overlays are drawn above the page or hide part of it until asked. Behaviour (keyboard, focus, ARIA, events) does not depend on the design: with design = "none" or no design at all they still work (only the look is missing). Every example below is live. Where something opens, press the button, hover or click as the text says.

tabs (Persian: زبانه ها)

Tabs show one panel at a time. The tabs root holds a tab list of tab trigger buttons and one tab content per trigger; the value of a trigger and its content must match, and default value picks the open one. The arrow keys (aware of right to left text), Home and End move and select. The example shows the default list, the line list variant and vertical tabs.

ds-overlay-tabs.salam
page:
    design = "shadcn"
    box:
        layout = "column"
        gap = 16
        width = 360
        tabs:
            default value = "account"
            tab list:
                tab trigger:
                    value = "account"
                    content = "Account"
                end
                tab trigger:
                    value = "password"
                    content = "Password"
                end
                tab trigger:
                    value = "off"
                    content = "Off"
                    disabled = true
                end
            end
            tab content:
                value = "account"
                paragraph:
                    content = "Change your name and email here."
                end
            end
            tab content:
                value = "password"
                paragraph:
                    content = "Pick a new password."
                end
            end
        end
        tabs:
            default value = "one"
            tab list:
                variant = "line"
                tab trigger:
                    value = "one"
                    content = "Overview"
                end
                tab trigger:
                    value = "two"
                    content = "Activity"
                end
            end
            tab content:
                value = "one"

                end

accordion (Persian: آکاردئون)

An accordion is a stack of sections that open and close. Each accordion item holds an accordion trigger and an accordion content. With type = "single" opening one closes the others; collapsible = true lets the open one be closed again; type = "multiple" keeps several open. Put open = true on an item to start open. Opening and closing animate for 200 ms unless the visitor asked for reduced motion.

ds-overlay-accordion.salam
page:
    design = "shadcn"
    box:
        layout = "column"
        gap = 24
        width = 400
        accordion:
            type = "single"
            collapsible = true
            accordion item:
                value = "a"
                open = true
                accordion trigger:
                    content = "Is it accessible?"
                end
                accordion content:
                    content = "Yes. It follows the WAI-ARIA pattern and works with the keyboard."
                end
            end
            accordion item:
                value = "b"
                accordion trigger:
                    content = "Is it styled?"
                end
                accordion content:
                    content = "Yes. It comes with the design of the page."
                end
            end
            accordion item:
                value = "c"
                accordion trigger:
                    content = "Is it locked?"
                    disabled = true
                end
                accordion content:
                    content = "Not shown."
                end
            end
        end
        accordion:
            type = "multiple"
            accordion item:
                value = "x"
                accordion trigger:
                    content = "First"
                end
                accordion content:
                    content = "With multiple, several items can be open."
                end
            end
            accordion item:
                value = "y"
                accordion trigger:
                    content = "Second"
                end
                accordion content:
                    content = "Open this one too."
                end
            end
        end
    end
end

Dialogs, sheets and drawers

dialog (Persian: پنجره گفتگو)

A dialog is a modal window over the page. It is a native dialog opened with showModal, so focus stays inside, the page behind is inert, Escape closes it and focus returns to the button. Give it an id and set opens to that id on a button or a dialog trigger. Close it with closes = true on a button, with a dialog close element, or with the corner X (turn that off with show close = false). A click outside the window also closes it; write close outside = false to turn that off so that only the buttons and Escape close it. width sets the size. Press the buttons in the example to open them. Inside, dialog header holds the dialog title and dialog description, and dialog footer holds the buttons; the example uses all four.

ds-overlay-dialog.salam
page:
    design = "shadcn"
    dialog trigger:
        opens = "edit"
        content = "Edit profile"
    end
    dialog:
        id = "edit"
        dialog header:
            dialog title:
                content = "Edit profile"
            end
            dialog description:
                content = "Change your public name. Press Escape to close."
            end
        end
        dialog footer:
            dialog close:
                content = "Cancel"
            end
            button:
                closes = true
                content = "Save"
            end
        end
    end
    dialog:
        id = "plain"
        show close = false
        width = 280
        dialog title:
            content = "No corner X"
        end
        dialog footer:
            dialog close:
                content = "Got it"
            end
        end
    end
    button:
        variant = "secondary"
        opens = "plain"
        content = "Small, no X"
    end
end
ElementAttributesValues or notes
dialogid, show close, close outside, width, opentrue, false for the X; close outside is true unless you write false
dialog header, title, description, footercontentthe usual parts
dialog triggeropensthe id to open
dialog closevariant, sizebutton values, default outline

By default a click on the dark area outside a window closes it, for the dialog, the alert dialog, the sheet and the drawer. Write close outside = false on the window when only its buttons and Escape should close it, for example a form that must not be lost by a stray click. The first button below uses the default and the second turns it off.

ds-overlay-close-outside.salam
page:
    design = "shadcn"
    box:
        layout = "row"
        gap = 8
        button:
            opens = "auto"
            content = "Closes on outside click"
        end
        button:
            variant = "outline"
            opens = "locked"
            content = "Stays open"
        end
    end
    dialog:
        id = "auto"
        dialog title:
            content = "Click outside me"
        end
        dialog description:
            content = "A click on the dark area closes this window. This is the default."
        end
    end
    dialog:
        id = "locked"
        close outside = false
        dialog title:
            content = "Outside clicks are ignored"
        end
        dialog description:
            content = "Only the corner X, the button and Escape close this window."
        end
        dialog footer:
            dialog close:
                content = "Close"
            end
        end
    end
end

alert dialog (Persian: پنجره هشدار)

An alert dialog asks for a decision before something that cannot be undone. It has no corner X, and the visitor normally picks alert dialog cancel or alert dialog action. size = "sm" makes the small form. Open it with the buttons below. The question goes in alert dialog header as an alert dialog title and an alert dialog description, and the two choices go in alert dialog footer. It also closes on an outside click, like the other windows; write close outside = false when the visitor has to choose a button.

ds-overlay-alert-dialog.salam
page:
    design = "shadcn"
    box:
        layout = "row"
        gap = 8
        button:
            variant = "destructive"
            opens = "del"
            content = "Delete account"
        end
        button:
            variant = "outline"
            opens = "small"
            content = "Small size"
        end
    end
    alert dialog:
        id = "del"
        alert dialog header:
            alert dialog title:
                content = "Are you sure?"
            end
            alert dialog description:
                content = "This cannot be undone. Clicking outside does not close it."
            end
        end
        alert dialog footer:
            alert dialog cancel:
                content = "Cancel"
            end
            alert dialog action:
                variant = "destructive"
                content = "Delete"
            end
        end
    end
    alert dialog:
        id = "small"
        size = "sm"
        alert dialog header:
            alert dialog media:
                span:
                    content = "!"
                end
            end
            alert dialog title:
                content = "Leave page?"
            end
            alert dialog description:
                content = "Unsaved changes are lost."
            end
        end
        alert dialog footer:
            alert dialog cancel:
                content = "Stay"
            end
            alert dialog action:
                content = "Leave"
            end
        end
    end
end

sheet (Persian: برگه کناری)

A sheet is a dialog that slides in from an edge of the screen, for settings or a menu. side picks the edge: top, right (the default), bottom or left. It opens and closes like a dialog. The example has one button for each side; the left one has no corner X. Each sheet in the example is built from a sheet header with a sheet title and sheet description, and a sheet footer for the actions. A click outside closes it unless you write close outside = false.

        side = "right"

drawer (Persian: کشو)

A drawer is a sheet made for touch: by default it rises from the bottom with a handle, and dragging it down dismisses it. side moves it to another edge. Its content uses the same drawer header, drawer title, drawer description and drawer footer as a sheet. A click outside closes it unless you write close outside = false.

Popovers and tooltips

popover (Persian: پنجره شناور)

A popover is a small panel next to its trigger, for a bit of extra content or a mini form. The root holds a popover trigger and a popover content. A trigger with no children draws an outline button from its content; put your own button inside to use another. On the content, side, align and side offset place it; it flips when there is no room. Escape or a click outside closes it. Press the buttons to open them. Inside the content, popover header groups a popover title and a popover description.

ds-overlay-popover.salam
page:
    design = "shadcn"
    box:
        layout = "row"
        gap = 12
        popover:
            popover trigger:
                content = "Open popover"
            end
            popover content:
                popover header:
                    popover title:
                        content = "Dimensions"
                    end
                    popover description:
                        content = "Set the size of the layer."
                    end
                end
            end
        end
        popover:
            popover trigger:
                variant = "secondary"
                content = "Bottom, aligned end"
            end
            popover content:
                side = "bottom"
                align = "end"
                side offset = 12
                popover title:
                    content = "Placement"
                end
            end
        end
    end
    box:
        height = 150
    end
end

Menus

dropdown menu (Persian: منوی کشویی)

A dropdown menu opens a list of actions from a button. Inside menu content you can put menu item (with variant = "destructive", disabled and a menu shortcut), menu checkbox item, a menu radio group of menu radio item, menu label, menu group, menu separator and a submenu made of menu sub, menu sub trigger and menu sub content. The keyboard works as in a desktop menu: arrows, Home, End, typing the first letters, Enter or Space to choose, Escape to close. Each choice fires ds-select with detail.value and detail.checked. Press the button to open it.

page:
    design = "shadcn"

menubar (Persian: نوار منو)

A menubar is a row of menus like File, Edit and View in a desktop app. Each menubar menu holds a menubar trigger and a menu content. Once one is open, hovering another trigger switches to it, and Left and Right move between them. Click File in the example.

navigation menu (Persian: منوی ناوبری)

A navigation menu is the main menu of a site. navigation menu list holds navigation menu items; an item has either a navigation menu trigger with a navigation menu content full of links, or a plain navigation menu link with url and active for the current page. It opens on hover or click and closes on Escape or a click outside. Hover Learn in the example.

ds-overlay-navigation-menu.salam
page:
    design = "shadcn"
    navigation menu:
        navigation menu list:
            navigation menu item:
                navigation menu trigger:
                    content = "Learn"
                end
                navigation menu content:
                    link:
                        url = "/learn/"
                        content = "Lessons"
                    end
                    link:
                        url = "/std/"
                        content = "Standard library"
                    end
                end
            end
            navigation menu item:
                navigation menu trigger:
                    content = "Tools"
                end
                navigation menu content:
                    link:
                        url = "/editor/"
                        content = "Editor"
                    end
                end
            end
            navigation menu item:
                navigation menu link:
                    url = "/docs"
                    active = true
                    content = "Docs"
                end
            end
        end
    end
    box:
        height = 150
    end
end
