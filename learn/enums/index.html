Enums

An enum is a type with a closed set of cases, and a case can carry data of its own.

In this lesson
  1. A plain enum
  2. Enums that carry data
  3. Generic enums
  4. Result and the ? operator

A plain enum

Cases are separated by commas and numbered from zero. You can give a case a value of your own, and the cases after it carry on from there. as int gives you the number behind a case.

enum-values.salam
enum Status:
    Draft, Published = 10, Archived
end

func main:
    state := Status.Published
    println state as int, Status.Archived as int
    println state == Status.Published
end
Output10 11 true

.name() gives the name of a case as a string, and .Count() on the enum itself gives the number of cases:

enum-name.salam
enum Season: Spring, Summer, Autumn, Winter end

func main:
    s := Season.Autumn
    println s.name()
    println "number of seasons:", Season.Count()
    println s == Season.Autumn, s as int
end
OutputAutumn number of seasons: 4 true 2

Enums that carry data

A case can carry named data, such as a radius for a circle. Use match to tell the cases apart and pull the data out. A branch may add a condition with if, and match makes sure every case is covered.

enum-data.salam
enum Shape:
    Circle(radius: f64)
    Rectangle(width: f64, height: f64)
    None
end

func area(s: Shape): f64:
    ret match s:
        Circle(r): 3.14 * r * r end
        Rectangle(w, h) if w == h: w * w end
        Rectangle(w, h): w * h end
        None: 0.0 end
    end
end

func main:
    println area(Shape.Circle(2.0))
    println area(Shape.Rectangle(3.0, 4.0))
    println area(Shape.None)
    println Shape.Circle(1.5)
end
Output12.56 12 0 Circle(radius = 1.5)

Generic enums

An enum that carries data can be generic too. Maybe<T> either holds a value or holds nothing: a safe way to say "there is no result" without a null.

enum-generic.salam
enum Maybe<T>:
    Some(value: T)
    None
end

func divide(a: int, b: int): Maybe<int>:
    if b == 0:
        ret Maybe.None
    end
    ret Maybe.Some(a / b)
end

func describe(m: Maybe<int>): str:
    ret match m:
        Some(v): "the result is " + v end
        None: "division by zero" end
    end
end

func main:
    println describe(divide(10, 2))
    println describe(divide(1, 0))
end
Outputthe result is 5 division by zero

Result and the ? operator

Salam has no exceptions. The result package provides Result<T, E>, which is either Ok with a value or Err with an error. Inside a function that returns a Result, writing ? after a call unwraps the successful value, and on an error returns that error straight away.

result-try.salam
import result

func number(text: str): result.Result<int, str>:
    if text == "7":
        ret result.Result.Ok(7)
    end
    ret result.Result.Err("not a valid number: " + text)
end

func add(a: str, b: str): result.Result<int, str>:
    x := number(a)?
    y := number(b)?
    ret result.Result.Ok(x + y)
end

func main:
    println add("7", "7")
    println add("7", "seven")
end
OutputOk(value = 14) Err(error = "not a valid number: seven")
