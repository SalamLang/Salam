The complete, free course

Learn Salam

This course covers the whole language, from your first program to the advanced parts, in short lessons that build on each other. Every lesson has complete programs with the output they actually produce; copy them and run them in the online editor.

Start with lesson one Try it in the browser

Getting started

  1. 1Your first programThe entry point, running a program, printing output and comments
  2. 2Variables and constantsDeclaring with :=, mutable variables, globals and naming rules
  3. 3TypesWhole and decimal numbers, strings, booleans, characters and conversion
  4. 4OperatorsArithmetic, comparison, logic, the ternary, bitwise and compound operators
  5. 5Strings and textWriting text, escapes, raw and multi-line strings, and string methods

Control flow

  1. 6Conditionsif, else if and else, and one line conditions
  2. 7Loopsrepeat with a counter and a range, until, each in, and break and continue
  3. 8match and switchChoosing between several cases with match and switch

Functions

  1. 9FunctionsDeclaring a function, parameters and results, default values, overloads and reference parameters
  2. 10Anonymous functionsFunctions as values, short function bodies and the function type
  3. 11defer and function modifiersRunning cleanup at the end of a function with defer, plus pure and inline

Data and types

  1. 12Arrays and slicesArrays, indexing, two dimensional arrays and slices
  2. 13Vector and HashMapA growable list with Vector, and key and value pairs with HashMap
  3. 14StructsRelated data together, methods, this, static members and embedding
  4. 15EnumsA closed set of cases, chosen values, and enums that carry data
  5. 16New types and operatorsType aliases, distinct types, operator overloading and Variant
  6. 17Generics and interfacesGeneric functions and structs, interfaces, impl and dyn

Larger programs

  1. 18Packages and filesPackages, including a file, importing a library, and pub
  2. 19What the compiler insists onThe errors Salam reports, and why they are on your side
  3. 20Values, references and memoryValues are copied, reference parameters, and freeing memory
  4. 21Conditional compilationSeparate code per operating system, decided while compiling
  5. 22Working with CCalling C functions with extern, and linking libraries
  6. 23ConcurrencyThreads with spawn and join, sharing data safely, channels and parallel loops
  7. 24The layout languageBuilding a web page with layout: HTML and CSS from Salam code
  8. 25The English and Persian glossaryEvery Salam keyword in both languages

This course is about the language itself. For the standard library (files, text, numbers, networking and the rest) see the library reference.
