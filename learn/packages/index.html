Packages and files

Larger programs are written across several files. Each file is a package, and shares with the rest of the program whatever it marks public.

In this lesson
  1. Packages
  2. Including a file
  3. Importing a library
  4. The order of definitions

Packages

A file that begins with package name is a package. Only the functions, constants and types marked pub are visible outside it; everything else is an internal detail.

pkg-lib.salam
package tools

pub const VERSION := "1.0"

func double(n: int): int:
    ret n * 2
end

pub func quadruple(n: int): int:
    ret double(double(n))
end

Including a file

include name "file.salam" brings a file from your own project in under a short name, and you reach its public members as name.thing. The path is relative to the file doing the including.

pkg-include.salam
include tools "pkg-lib.salam"

func main:
    println tools.quadruple(5)
    println "tools version:", tools.VERSION
end
Output20 tools version: 1.0

Importing a library

Standard library packages are imported by name, without quotes, as in import str or import os. import is for libraries and include is for your own files.

pkg-import.salam
import str
import math

func main:
    text := "  hello world  "
    println str.Trim(text)
    println str.Contains(text, "world")
    println math.Sqrt(81.0), math.Pow(2.0, 10.0)
end
Outputhello world true 9 1024

In an English file you have to use the English names, and a Persian one such as str.طول is an error. Every standard library function carries its Persian name next to its English one in the library source, under the std directory, written with @fa. You can make your own public functions bilingual the same way, so that Persian files can call them too:

pkg-bilingual.salam
@en "Twice"
@fa "دوبار"
pub func Twice(n: int): int:
    ret n * 2
end

func main:
    println Twice(21)
end
Output42

The order of definitions

Salam asks for a fixed order among the top-level definitions in a file, so that every file reads the same way:

  1. package
  2. Imports, then includes
  3. Constants and global variables
  4. Types, structs, enums and interfaces
  5. Functions, with the public ones last

salam format tidies a file up and does much of this moving for you.
