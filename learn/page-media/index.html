Links, images and media

A page is more than text: it links to other pages, shows pictures, plays sound and video and draws shapes. This lesson covers the elements for all of that, and the attributes that make them fast, accessible and safe.

Links

A link takes the reader somewhere. Its url is required and its content is the text the reader clicks. The address can point to another site, to a file next to your page, or to a place on the same page: a url that starts with # scrolls to the element whose id is the rest of it. Two more kinds are worth knowing. mailto: opens the mail program with a new message, and tel: offers to call the number on a phone.

web-media-links.salam
page:
    title = "Links"
    global: selector = "body" font family = "system-ui, sans-serif" margin = "1.5rem" line height = 1.8 end
    paragraph:
        content = "Read the "
        link: url = "#rules" content = "house rules" end
        span: content = " first, then write to " end
        link: url = "mailto:club@example.com" content = "the club" end
        span: content = " or call " end
        link: url = "tel:+15550100" content = "555 0100" end
        span: content = "." end
    end
    paragraph:
        link: url = "https://example.com/guide" target = "new" rel = "noopener" content = "The full guide (new tab)" end
    end
    paragraph:
        link:
            url = "maps/garden.pdf"
            download = "garden-map.pdf"
            type = "application/pdf"
            hreflang = "en"
            content = "Download the garden map"
        end
    end
    heading: id = "rules" size = 2 content = "House rules" end
    paragraph: content = "Keep the gate closed. Water the beds in the morning." end
end

The attributes in the example each do one job. target says where the page opens: new is a new tab (the HTML word is _blank, and both work), same is the current tab, and parent and top matter only inside frames. rel describes the relationship to the target. With noopener the new tab cannot reach back to your page, which matters for a link to a site you do not control, and nofollow asks search engines not to count the link. download makes the browser save the file instead of showing it, and its value is the suggested file name. type is the kind of file you expect and hreflang the language of the target page. Both are hints. ping lists addresses that are told when someone follows the link, and referrer policy controls how much of your address the target site is given.

Write link text that makes sense on its own, such as "the house rules", and not "click here": screen readers can read out a list of all the links on a page. A link cannot contain another link or a button, and the compiler reports an error (E116) if you try. It also refuses addresses like javascript: that would run code (E018).

Images

image shows a picture. The url is required. The text description is the alt attribute, and content sets the same attribute, so you can write whichever reads better. The description is what a screen reader says and what the browser shows when the file cannot be loaded. Describe what the picture tells, not what it is: "A red kite over green hills", not "image". If the picture is only decoration, give it an empty description, alt = "", and screen readers will skip it. When you give neither, the compiler writes the empty one for you.

web-media-image.salam
page:
    title = "Images"
    global: selector = "body" font family = "system-ui, sans-serif" margin = "1.5rem" end
    paragraph: content = "A photo with a description:" end
    image:
        content = "A red kite flying over green hills"
        width = 160
        height = 100
        loading = lazy
        decoding = async
        url = "data:image/svg+xml,%3Csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20viewBox=%270%200%20160%20100%27%20width=%27160%27%20height=%27100%27%3E%3Crect%20width=%27160%27%20height=%27100%27%20fill=%27%23bae6fd%27/%3E%3Cpath%20d=%27M0%20100%20Q50%2055%20100%2085%20T160%2075%20V100Z%27%20fill=%27%2316a34a%27/%3E%3Cpath%20d=%27M110%2012%20L130%2032%20L110%2052%20L90%2032Z%27%20fill=%27%23dc2626%27/%3E%3Cpath%20d=%27M110%2052%20Q100%2070%20112%2082%27%20stroke=%27%23475569%27%20fill=%27none%27/%3E%3Ctext%20x=%276%27%20y=%2714%27%20font-size=%2711%27%20font-family=%27sans-serif%27%20fill=%27%230c4a6e%27%3E%3C/text%3E%3C/svg%3E"
    end
    paragraph: content = "A decorative picture has an empty description:" end
    image: alt = "" width = 80 height = 50 url = "data:image/svg+xml,%3Csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20viewBox=%270%200%20160%20100%27%20width=%27160%27%20height=%27100%27%3E%3Crect%20width=%27160%27%20height=%27100%27%20fill=%27%23bae6fd%27/%3E%3Cpath%20d=%27M0%20100%20Q50%2055%20100%2085%20T160%2075%20V100Z%27%20fill=%27%2316a34a%27/%3E%3Cpath%20d=%27M110%2012%20L130%2032%20L110%2052%20L90%2032Z%27%20fill=%27%23dc2626%27/%3E%3Cpath%20d=%27M110%2052%20Q100%2070%20112%2082%27%20stroke=%27%23475569%27%20fill=%27none%27/%3E%3Ctext%20x=%276%27%20y=%2714%27%20font-size=%2711%27%20font-family=%27sans-serif%27%20fill=%27%230c4a6e%27%3E%3C/text%3E%3C/svg%3E" end
    paragraph: content = "A picture that fails to load shows its description instead:" end
    image: content = "Photo of the garden gate" width = 200 height = 40 url = "missing/gate.jpg" end
end

Always set width and height to the real size of the file. The browser then reserves the space before the picture arrives, and the text below does not jump when it does. loading = lazy tells the browser to fetch the picture only when the reader scrolls near it, which saves data for pictures far down the page. Leave the first picture on the page at the default, eager. decoding chooses whether decoding may happen off to the side (async) and fetch priority lets you mark the most important picture as high.

The long text in url is a data address: the whole picture written as text, so the example needs no extra file. The compiler accepts data addresses for images, audio, video and fonts and refuses the rest. In your own pages you will usually write a file name or an address instead.

One picture, many sizes

A phone and a large monitor do not need the same file. srcset lists several versions of the picture, and the browser picks one. There are two ways to describe them. With density descriptors, as in the example, each file is marked 1x, 2x and so on, and the browser chooses by the pixel density of the screen. With width descriptors, photo-480.jpg 480w, photo-960.jpg 960w, each file is marked with its real width, and sizes tells the browser how wide the picture will be drawn, for example sizes = "(max-width: 600px) 100vw, 600px". The url stays as the fallback for browsers that do not know srcset.

web-media-srcset.salam
import dom

page:
    title = "Image sets"
    global: selector = "body" font family = "system-ui, sans-serif" margin = "1.5rem" line height = 1.6 end
    image:
        id = "swatch"
        content = "A color swatch (the files do not exist here)"
        width = 160
        height = 100
        srcset = "swatch.png 1x, swatch-2x.png 2x"
        url = "swatch.png"
        error = (): dom.SetText(dom.ById("chosen"), "The browser chose: " + dom.GetStr(dom.ById("swatch"), "currentSrc")) end
    end
    paragraph: id = "chosen" content = "Waiting for the browser." end
end

The files in this example do not exist, so the browser draws nothing. It still decides which one it would load, and the function named after error = runs when the image cannot be loaded and reads that choice from the currentSrc property of the image. On a screen with twice the pixels you would read the second name.

When the versions are not the same picture, for example a wide crop for a desktop and a tall one for a phone, use picture. Inside it, each source has a media condition and a srcset, and the browser takes the first source whose condition is true. The last child is always a normal image: it is the fallback and it carries the description. A source can also have a type, such as image/webp, so that browsers that do not know the format skip it.

web-media-picture.salam
page:
    title = "Picture"
    global: selector = "body" font family = "system-ui, sans-serif" margin = "1.5rem" end
    picture:
        source: media = "(min-width: 500px)" srcset = "data:image/svg+xml,%3Csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20viewBox=%270%200%20320%20120%27%20width=%27320%27%20height=%27120%27%3E%3Crect%20width=%27320%27%20height=%27120%27%20fill=%27%23bae6fd%27/%3E%3Ccircle%20cx=%27260%27%20cy=%2736%27%20r=%2720%27%20fill=%27%23facc15%27/%3E%3Cpath%20d=%27M0%20120%20Q90%2060%20170%20100%20T320%2085%20V120Z%27%20fill=%27%2316a34a%27/%3E%3Ctext%20x=%278%27%20y=%2716%27%20font-size=%2712%27%20font-family=%27sans-serif%27%20fill=%27%230c4a6e%27%3Ewide%3C/text%3E%3C/svg%3E" end
        image:
            content = "Green hills under a yellow sun"
            url = "data:image/svg+xml,%3Csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20viewBox=%270%200%20120%20160%27%20width=%27120%27%20height=%27160%27%3E%3Crect%20width=%27120%27%20height=%27160%27%20fill=%27%23bae6fd%27/%3E%3Ccircle%20cx=%2790%27%20cy=%2730%27%20r=%2716%27%20fill=%27%23facc15%27/%3E%3Cpath%20d=%27M0%20160%20Q40%2090%2080%20140%20T120%20120%20V160Z%27%20fill=%27%2316a34a%27/%3E%3Ctext%20x=%278%27%20y=%2716%27%20font-size=%2712%27%20font-family=%27sans-serif%27%20fill=%27%230c4a6e%27%3Enarrow%3C/text%3E%3C/svg%3E"
        end
    end
    paragraph: content = "In a window narrower than 500 pixels you see the tall picture. In a wider window the browser swaps in the wide one." end
end

Clickable image maps

An image map makes parts of one picture into separate links. The image names the map with use map = "#shapes", and an image map with name = "shapes" holds one area per hotspot. An area has a shape: rect with the coordinates left,top,right,bottom, circle with center-x,center-y,radius, poly with the corners as x1,y1,x2,y2 and so on, or default for everything not covered. The coordinates are in pixels of the picture as it is drawn. An area is a link, so it also takes url, target, rel, download, ping and referrer policy, and it needs alt, the text for people who cannot click the picture.

web-media-map.salam
import dom

page:
    title = "Image map"
    global: selector = "body" font family = "system-ui, sans-serif" margin = "1.5rem" end
    image:
        content = "A red square next to a blue circle"
        use map = "#shapes"
        width = 200
        height = 100
        url = "data:image/svg+xml,%3Csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20viewBox=%270%200%20200%20100%27%3E%3Crect%20x=%2710%27%20y=%2710%27%20width=%2780%27%20height=%2780%27%20fill=%27%23dc2626%27/%3E%3Ccircle%20cx=%27150%27%20cy=%2750%27%20r=%2740%27%20fill=%27%232563eb%27/%3E%3C/svg%3E"
    end
    image map: name = "shapes"
        area: shape = "rect" coords = "10,10,90,90" alt = "red square" url = "#" click = (): dom.SetText(dom.ById("said"), "You chose the square.") end end
        area: shape = "circle" coords = "150,50,40" alt = "blue circle" url = "#" click = (): dom.SetText(dom.ById("said"), "You chose the circle.") end end
    end
    paragraph: id = "said" content = "Click a shape." end
end

In the example each area also has a click handler that writes into the paragraph. The older ismap attribute is different: on an image inside a link it makes the browser send the clicked coordinates to the server, which then decides what to do.

Audio and video

audio and video play sound and moving pictures without any plug-in. Add controls or the reader gets no way to start them. Give the file with url or, better, with one or more source children, each with its type. The browser takes the first one it can play, so list the best format first. The content text is shown only by a browser that cannot play the element at all.

web-media-audio.salam
page:
    title = "Audio"
    global: selector = "body" font family = "system-ui, sans-serif" margin = "1.5rem" end
    paragraph: content = "A short beep. Press play:" end
    audio:
        controls = true
        preload = "auto"
        content = "Your browser cannot play audio."

A video also has width and height, a poster picture shown until it plays, and plays inline, which stops phones from forcing it to full screen.

Frames and embedded objects

iframe shows another page inside yours. The page can be an address in url or a short document written in srcdoc. Give it a title so screen readers can announce it, and a width and height. Use loading = lazy for frames far down the page.

web-media-iframe.salam
page:
    title = "Frames"
    global: selector = "body" font family = "system-ui, sans-serif" margin = "1.5rem" end
    paragraph: content = "A separate little page, locked in a sandbox with no scripts:" end
    iframe:
        title = "Greeting"
        width = 320
        height = 90
        sandbox = ""
        loading = lazy
        srcdoc = "<body style='font-family:sans-serif'><h3>Inside the frame</h3><p>This page cannot run scripts.</p></body>"
        border = "2px solid #0f766e"
    end
end

A frame can bring a stranger's code into your page, so lock it down with sandbox. An empty sandbox = "" removes every permission: no scripts, no forms, no popups. You then give back only what the frame needs, by listing words such as allow-scripts or allow-forms, separated by spaces. Never combine allow-scripts with allow-same-origin for a page you do not trust. allow is a separate list for browser features, such as "fullscreen; camera", and allow fullscreen permits the full screen button. name gives the frame a name for scripts, and referrer policy works as for links.

embed and object place an external resource, such as a PDF, into the page. Both take a url, a type and a size. embed has no content. object shows its content when the browser cannot display the file, which is the place for a download link, and its form and name attributes connect it to a form. For a PDF, a plain link is often the better choice.

Canvas, SVG and math

canvas is a blank rectangle you draw on with code. Set its size with the width and height attributes, which are the number of pixels of the drawing surface. A size set with CSS only stretches those pixels, and the drawing turns blurry. Drawing itself is done through the dom package. dom.GetContext(canvas, "2d") returns the drawing tool, dom.SetStr sets a property of it such as fillStyle, and dom.Call4 calls one of its methods with four numbers. The example stamps a square where you click: dom.GetNum(e, "offsetX") reads the click position inside the canvas from the event. The two functions above the page, stamp and wipe, are connected to the canvas and the button with click = stamp and click = wipe.

web-media-canvas.salam
import dom

func stamp(e: i64):
    ctx := dom.GetContext(dom.ById("pad"), "2d")
    dom.SetStr(ctx, "fillStyle", "#0f766e")
    _ := dom.Call4(ctx, "fillRect", dom.GetNum(e, "offsetX") - 10, dom.GetNum(e, "offsetY") - 10, 20, 20)
end

func wipe():
    ctx := dom.GetContext(dom.ById("pad"), "2d")
    _ := dom.Call4(ctx, "clearRect", 0, 0, 320, 160)
end

page:
    title = "Canvas"
    global: selector = "body" font family = "system-ui, sans-serif" margin = "1.5rem" end
    paragraph: content = "Click the canvas to stamp a square." end
    canvas: id = "pad" width = 320 height = 160 background = "#f1f5f9" border = "1px solid #94a3b8" click = stamp end
    box: margin top = 8
        button: content = "Clear" click = wipe end
    end
end

Text inside the canvas element, if you add some, is shown only when the browser cannot draw, and screen readers cannot see into the drawing. Put any information the drawing carries into the page as text as well.

svg draws with shapes that stay sharp at every size. The content of an svg is the markup of its shapes, written as it is, and it is not escaped, so use it only for markup you wrote yourself. view box is the coordinate system inside, four numbers min-x min-y width height, and width and height are the size on the page. The drawing scales to fit. xmlns is only needed when the SVG is a file of its own. math works the same way for mathematics, with MathML in its content: mi for a name, mo for an operator, mn for a number, mfrac for a fraction and msup for a power.

web-media-svg.salam
page:
    title = "SVG and math"
    global: selector = "body" font family = "system-ui, sans-serif" margin = "1.5rem" end
    svg:
        view box = "0 0 120 60"
        width = 240
        height = 120
        content = "<rect width='120' height='60' rx='8' fill='#ccfbf1'/><circle cx='30' cy='30' r='18' fill='#0f766e'/><text x='58' y='36' font-size='16' fill='#134e4a'>Salam</text>"
    end
    paragraph:
        content = "The area of a circle is "
        math: content = "<mi>A</mi><mo>=</mo><mi>&#960;</mi><msup><mi>r</mi><mn>2</mn></msup>" end
        span: content = "." end
    end
end

Reference: links, images and media

Every element of this lesson is below, with its attributes and a short example. The examples are checked by the compiler, so you can paste any of them inside a page: block. Files such as photo.jpg in the examples are only names, you need your own files to see them. The attributes that every element has, such as id and title, are in the lesson on the head and global attributes.

Links

link (Persian: پیوند; HTML: <a>)

A link (HTML a). The required url is where it goes and the content is the text to click. It can hold text, an image or other inline content, but not another link or a button.

link: url = "/guide" content = "Read the guide" end

Required: url

AttributeWhat it doesExample
type
نوع		A hint about the kind of file at the address, as a MIME type such as application/pdf. The browser may use it before it has fetched the file. It does not change what the file is. [mime]link: url = "notes.pdf" type = "application/pdf" content = "Notes (PDF)" end
download
دانلود		Makes the browser save the target instead of opening it. The value is the file name to suggest; an empty value keeps the original name. It works for files from your own site. [string]link: url = "report.pdf" download = "report-2026.pdf" content = "Save the report" end
rel
رابطه		A space separated list of words that describe how the target relates to this page, such as noopener (the new page cannot control this one), noreferrer, nofollow (search engines should not count the link) or external. [token (list)]link: url = "https://example.org" target = "new" rel = "noopener nofollow" content = "A site we do not vouch for" end
referrer policy
سیاست ارجاع		How much of this page's address is sent to the target: no-referrer (nothing), same-origin, origin (only the site), strict-origin-when-cross-origin and others. ping
پینگ		A space separated list of addresses that the browser notifies when the link is followed. It is used for click counting. Some browsers ignore it. [url (list)]link: url = "/offer" ping = "https://example.com/count" content = "See the offer" end
hreflang
زبان مقصد		The language of the target page, as a language code such as fa or en. It is a hint for browsers and search engines. [lang]link: url = "/fa/" hreflang = "fa" content = "Persian version" end
url
نشانی		The address the link goes to, required. It can be a full address (https://...), a file name next to the page, a place on this page (#id), mailto: or tel:. Addresses that run code, such as javascript:, are refused. [url]link: url = "#prices" content = "Jump to the prices" end
target
هدف		Where the page opens: new (or _blank) for a new tab, same (_self) for the current one, parent and top for the enclosing frame or the whole window. [enum: target]link: url = "https://example.com" target = "new" content = "Open in a new tab" end

Images and maps

image (Persian: تصویر; HTML: <img>)

A picture (HTML img). The url is required. It has no children. Give it a description in alt or content, and its width and height.

image: url = "photo.jpg" content = "The garden gate in spring" width = 320 height = 200 end

Required: url · Void element, it cannot have children

AttributeWhat it doesExample
width
عرض		The width of the picture. A bare number means pixels. Set it, with height, to the real size of the file so the browser can reserve the space before the picture loads. [ulength]image: url = "photo.jpg" alt = "Gate" width = 240 height = 150 end
height
ارتفاع		The height of the picture, in pixels when it is a bare number. Together with width it lets the browser keep the picture's shape while it loads. [ulength]image: url = "photo.jpg" alt = "Gate" width = 240 height = 150 end
srcset
مجموعه منبع		A list of picture files for the browser to choose from, separated by commas. Each item is an address followed by 1x, 2x (screen density) or 480w, 960w (file width in pixels). sizes
اندازه‌ها		How wide the picture will be drawn, so the browser can pick from a srcset that uses w descriptors. A list of conditions with widths, ending with a default, for example (max-width: 600px) 100vw, 600px. [string]image: url = "photo-480.jpg" alt = "Gate" srcset = "photo-480.jpg 480w, photo-960.jpg 960w" sizes = "(max-width: 600px) 100vw, 600px" end
crossorigin
میان‌مبدا		Whether the request for a picture from another site carries credentials: anonymous (none) or use-credentials. It is needed when a script reads the pixels of a picture from another site. [enum: crossorigin]image: url = "https://cdn.example.com/map.png" alt = "Map" crossorigin = "anonymous" end
referrer policy
سیاست ارجاع		How much of this page's address is sent when the picture is requested. The words are the same as for a link: no-referrer, origin, same-origin and so on. [enum: referrer_policy]image: url = "https://img.example.com/a.png" alt = "Ad" referrer policy = "no-referrer" end
loading
بارگذاری		When to fetch the picture: eager at once (the default) or lazy only when the reader scrolls close to it. Use lazy for pictures below the first screen. [enum: loading]image: url = "footer-photo.jpg" alt = "The team" width = 320 height = 180 loading = "lazy" end
decoding
رمزگشایی		Whether the browser may decode the picture off to the side: async (yes, so the page is not held up), sync (decode together with the rest) or auto (the browser decides, the default). [enum: decoding]image: url = "big.jpg" alt = "A large panorama" width = 640 height = 200 decoding = "async" end
fetch priority
اولویت دریافت		A hint about how urgent the picture is: high, low or auto. Mark the main picture of the page high. [enum: fetch_priority]image: url = "hero.jpg" alt = "The harbour at dawn" width = 640 height = 260 fetch priority = "high" end
use map
نقشه		Connects the picture to an image map. The value is a # followed by the name of the map. [string]image: url = "plan.png" alt = "Floor plan" use map = "#rooms" end image map: name = "rooms" area: shape = "rect" coords = "0,0,50,50" alt = "Kitchen" url = "#kitchen" end end
ismap
نقشه سمت سرور		A boolean. On an image inside a link, it makes the browser add the click position to the address, so a server can decide what the click meant. Rarely needed today. [bool]link: url = "/where" image: url = "map.png" alt = "Map" ismap = true end end
url
نشانی		The address of the picture file, required. It can be a file name, a full address or a data address for small pictures. [url]image: url = "images/kite.png" alt = "A red kite" end
alt
جایگزین		The text description of the picture. Screen readers read it, and the browser shows it if the file cannot be loaded. Use an empty value (alt = "") for a picture that is only decoration. [string]image: url = "chart.png" alt = "Rainfall by month, highest in March" end
content
محتوا		Another way to write alt: the text you give as content becomes the description. Use whichever reads better; do not give both. [string]image: url = "logo.png" content = "Salam logo" end

picture (Persian: عکس; HTML: <picture>)

A container that lets the browser choose between several versions of a picture. It holds source elements and ends with the normal image, which is the fallback and carries the description.

AttributeWhat it doesExample
width
عرض		The width of the picture file of this candidate, in pixels. It helps the browser keep the right shape before the file arrives. [ulength]picture: source: srcset = "wide.jpg" media = "(min-width: 700px)" width = 1200 height = 600 end image: url = "narrow.jpg" alt = "The harbour" end end
height
ارتفاع		The height of the picture file of this candidate, in pixels. Give it together with width. [ulength]picture: source: srcset = "square.jpg" media = "(max-width: 400px)" width = 400 height = 400 end image: url = "wide.jpg" alt = "The harbour" end end
url
نشانی		The address of the audio or video file. Inside a picture use srcset instead. [url]audio: controls = true source: url = "song.mp3" type = "audio/mpeg" end end

رسانه		A media condition, written as in CSS. The candidate is used only while the condition is true, such as (min-width: 700px) or (orientation: portrait). [media_query]picture: source: media = "(orientation: portrait)" srcset = "tall.jpg" end image: url = "wide.jpg" alt = "The harbour" end end

فضای نام		The XML namespace address, http://www.w3.org/2000/svg. It is only needed when the SVG is saved as a file of its own. Inside a page you can leave it out. math (Persian: ریاضی; HTML: <math>)

A mathematical formula written in MathML (HTML math). Its content is the markup, inserted as written: mi for a name, mn for a number, mo for an operator, mfrac for a fraction, msup for a power, msqrt for a square root.

math: content = "<msqrt><mi>x</mi></msqrt><mo>=</mo><mfrac><mn>1</mn><mn>2</mn></mfrac>" end
