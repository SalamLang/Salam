Structs

A struct gathers several related pieces of data under one name, along with the functions, called methods, that work on them.

In this lesson
  1. Declaring a struct
  2. Creating and printing
  3. Mutating methods
  4. Static members
  5. Composition with use

Declaring a struct

Every field has a name, a type and optionally a default value. Fields and methods are private by default; pub makes them reachable from outside the struct. Inside a method, this refers to the struct itself.

structs.salam
struct Rectangle:
    pub width: int = 1
    pub height: int = 1
    pub func area(): int:
        ret this.width * this.height
    end
end

func main:
    plot := Rectangle { width = 12, height = 8 }
    println "area of the plot:", plot.area()
end
Outputarea of the plot: 96

Creating and printing

When you create an instance, any field you leave out takes its default value. A struct can be printed directly:

struct-print.salam
struct Point:
    pub x: int = 0
    pub y: int = 0
end

func main:
    p := Point { x = 3, y = 4 }
    println p
    println Point {}
end
OutputPoint {x = 3, y = 4} Point {x = 0, y = 0}

Mutating methods

A method that changes the struct's fields is declared mut func, and can only be called on a variable that is itself mut. No other method may change the struct.

struct-mut.salam
struct Counter:
    value: int = 0
    pub func read(): int:
        ret this.value
    end
    pub mut func increment():
        this.value += 1
    end
end

func main:
    mut c := Counter {}
    c.increment()
    c.increment()
    println c.read()
end
Output2

Static members

static func and const inside a struct belong to the type rather than to an instance; call them through the struct's name. They are a good home for ready-made instances.

struct-static.salam
struct Color:
    pub red: int = 0
    pub green: int = 0
    pub blue: int = 0
    pub const MAX := 255
    pub static func gray(value: int): Color:
        ret Color { red = value, green = value, blue = value }
    end
end

func main:
    white := Color.gray(Color.MAX)
    println white
end
OutputColor {red = 255, green = 255, blue = 255}

Composition with use

use places one struct inside another and makes its public fields and methods reachable directly: composition instead of inheritance.

struct-embed.salam
struct Animal:
    pub name: str = ""
    pub func introduce(): str:
        ret "I am " + this.name
    end
end

struct Dog:
    pub use Animal
    pub breed: str = ""
end

func main:
    d := Dog { name = "Rex", breed = "hound" }
    println d.introduce()
    println d.name, d.breed
end
OutputI am Rex Rex hound
