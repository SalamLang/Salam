Style vocabulary reference

States

Any style property can carry one state prefix and then applies only in that state, for example hover background = #ffeecc. The states are hover, focus, focus within, active, disabled, checked, invalid, placeholder and selection.

Value forms

  • A bare number uses the natural unit of the property: pixels for lengths, milliseconds for times, degrees for angles.
  • Percent: 50%. Units: px em rem fr vw vh ms s deg turn.
  • A comma list continues one property: padding = 8, 16. Brackets group one item of a repeated property: shadow = [0, 4, 8, black], [0, 1, 2, red].
  • Colours: red, #3366aa, rgb(51, 102, 170), hsl(210, 50%, 40%), mix(red, blue, 30%), light dark(white, black).
