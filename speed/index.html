Measured on 42 equivalent programs, 27 October 2026

How fast is Salam?

Salam compiles straight to machine code, with no virtual machine and no garbage collector. On the 39 programs that use the same algorithm in every language, Salam averaged 10.6 ms, C 11.7 ms and Rust 11.3 ms: the same range, with small gaps either way. Against the fastest of C, C++, Rust and Go on each program, Salam was ahead on 6, level on 27 and behind on 6. Interpreted languages are another story: Python took 56 times as long and PHP 9.6 times.

Ahead, level and behind

A program counts as level when Salam is within 5% (or half a millisecond) of the fastest of C, C++, Rust and Go, because gaps that small change from run to run. On the 39 same-algorithm programs (times in ms):

Behind

LCG random 19.4 vs 17.9 (C), loop count 5.9 vs 5.3 (C), binary search 667.7 vs 583.9 (Rust), n-queens 41.1 vs 35.7 (C), recursive Fibonacci 3.1 vs 2.4 (C), printing a line a million times 8.2 vs 2.6 (Rust).

What these numbers do not show

  • Most programs finish in 2 to 30 ms (the median C time is 10.5 ms), so process start-up is part of every time and a millisecond is a large share. One sign of it: Salam built with tcc and no optimiser still averages 11.0 ms, close to the optimised build. The suite separates compiled languages from interpreted ones clearly; between compiled languages, read it as the same range, not as a ranking.
  • Each time is the fastest of 10 runs on a shared GitHub Actions virtual machine. Gaps under about 5% can flip on the next run.
  • Three programs (40 to 42) use Salam's own matrix and tensor library while C, C++, Rust and Go use hand-written loops, so they compare libraries, not compilers, and are left out of the averages above. Salam is ahead on two (14.3 ms vs 42.5 ms for C, and 7.3 ms vs 38.1 ms for C++) and far behind on the third (36.4 ms vs 4.1 ms for C, where gcc removes most of the loop work).
  • Every language implements the same algorithm with the same output, written the way that language is normally written. These are small programs; they do not measure large applications, memory-heavy workloads or how long a big project takes to build.

A second benchmark: the HTTP router

How fast is Salam's web server?

Not every server people reach for is written in a compiled language. Nine servers answered the same eleven routes on the same machine, in one interleaved run, each route measured on every server back to back: Salam's own net.http, Go's standard library router, three of the most popular Go frameworks (Fiber, Gin, Echo), nginx, Apache, Node (Express 5), and PHP's built-in server.

Method

Each of the 42 programs was written in C, C++, Rust, Go, Python, PHP and Salam with the same algorithm, and every version's output was checked against C's before timing. Each program ran 10 times after one untimed warm-up and the fastest run was kept; the averages are geometric means of those times. C and C++ were built with gcc -O3, Rust with -C opt-level=3, and Salam with its LLVM backend at -O3. Plain salam build with no options uses tcc without an optimiser and averaged 11.0 ms on the same 39 programs.
