How fast is Salam?

Salam programs compile straight to machine code, with no virtual machine and no garbage collector. The result is that Salam runs level with the fastest languages around and tens of times faster than interpreted ones like Python and PHP.

Where Salam comes out ahead

Salam was the fastest language, or tied with it, in 24 of the 42 programs, more than any other language: C managed 19 and Rust 15. A few of them:

Method

Forty-two programs (numeric work, primes, sorting, strings, matrices, tensors and more) were implemented the same way in C, C++, Rust, Go, Python, PHP and Salam, and every language's output was compared before timing to make sure they agreed. For each program the fastest run was recorded, and for each language the geometric mean of those times was taken; C and C++ were built at the highest optimisation level (O3). The Salam numbers on this page come from the LLVM backend at O3, so that the comparison with C and Rust is fair; plain salam build with no options uses tcc with no optimiser and averages 16.32 ms.
