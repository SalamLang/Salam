archive

Making and opening zip and tar archives, reading and writing RAR, and gzipping a file.

An archive gathers several files into one. Zip compresses each file on its own; tar only puts the files one after another and is usually gzipped afterwards (.tar.gz).

The functions work both in memory and on files. They take the archive data as an address and a length, such as b.data and b.len of a byte buffer.

The compression itself comes from compress; use that package directly to gzip a single file or stream. For reading and writing the files on disk around an archive, see fs.file.

Limits to know about

  • Zip: no zip64, so archives and entries must stay under 2 GB; only methods 0 (stored) and 8 (DEFLATE) are read, so entries packed with bzip2, LZMA or zstd fail to extract; encrypted entries are refused; the CRC-32 is not checked on extract.
  • Zip names and dates: new zips do not set the UTF-8 flag, so tools that assume the old DOS code page, such as Windows Explorer, may show Persian file names garbled, and every entry is dated 1 January 1980. Entry.mtime is always 0 for zip entries.
  • Tar: names longer than 100 bytes are cut, both when writing and reading, and the ustar prefix field and GNU or PAX long names are not used. Links and other special entries are listed as ordinary files of size 0. New entries get a time of 0, and the mode you set, or 644 for files and 755 for folders when you leave it at 0.
  • RAR: RAR 5 archives are read completely: every compression level, solid archives and the built-in filters, with each entry's CRC-32 checked. Older archives (RAR 1.5 to 4.x) are read the same way, including PPMd text compression and the standard filters. Password-protected archives open with RarOpen and a password, including ones whose file names are encrypted; without it they report RAR_ENCRYPTED, and a wrong password reports RAR_BAD_PASSWORD. Multi-volume archives open from the list of volumes (RarOpenVolumes, or RarReadVolumes to load a set from disk); a set with a missing volume reports RAR_MULTIVOLUME for the files that cross it. A file that is both encrypted and split across volumes is not supported. New archives are RAR 5 with the files stored, because only WinRAR itself can compress to RAR; any RAR tool opens them.

The guide below shows the usual jobs: zipping a set of files, making and reading a .tar.gz, telling formats apart by their first bytes, and extracting without letting an archive write outside the target folder.

Zip a set of files

Each file you put into a zip is a ZipFileInput: its path inside the archive, the address and length of its bytes, and the method, 8 for DEFLATE or 0 to store it as it is. A name that ends with / is a folder. ZipCreateFile writes the archive to disk and returns false when it cannot; ZipCreate keeps it in memory, for example to send it as an HTTP response.

archive-guide-bundle.salam
import archive
import compress

func main:
    html := compress.BufFromStr("<html><body><h1>Hello</h1><p>Hello again, hello once more.</p></body></html>\n")
    css := compress.BufFromStr("body { margin: 0; }\nh1 { margin: 0; }\np { margin: 0; }\n")
    logo := compress.GzipCompressStr("pretend this is an image that is already compressed")
    mut files := Vector {} as Vector<archive.ZipFileInput>
    files.push(archive.MakeZipFileInput("site/", null, 0, 0))
    files.push(archive.MakeZipFileInput("site/index.html", html.data, html.len, 8))
    files.push(archive.MakeZipFileInput("site/style.css", css.data, css.len, 8))
    files.push(archive.MakeZipFileInput("site/logo.bin", logo.data, logo.len, 0))
    if not archive.ZipCreateFile(files, "site.zip"):
        println "could not write site.zip"
        ret 1
    end
    mut ok := false
    z := archive.ReadBinaryFile("site.zip", ok)
    mut entries := archive.ZipList(z.data, z.len)
    each e in entries:
        if e.is_dir:
            println e.name, "(folder)"
        else:
            println e.name, e.size, "->", e.compressed_size, "method", e.method
        end
    end
    archive.FreeEntries(entries)
    ret 0
end
Outputsite/ (folder) site/index.html 77 -> 63 method 8 site/style.css 55 -> 29 method 8 site/logo.bin 64 -> 64 method 0

Text shrinks well. The logo is already compressed, so it uses method 0: running DEFLATE on it again would only cost time and could even make it bigger. The same rule holds for JPEG, PNG, MP4 and other zips.

Make and read a .tar.gz

Tar does not compress. It puts each file after a 512 byte header and pads its contents to a multiple of 512 bytes, so three small files already take 3.5 KB. The usual answer is to gzip the whole tar, and all that padding then nearly disappears. In memory that is TarCreate followed by compress.GzipCompressBuf; for a tar that is already on disk, GzipCompressFile and GzipDecompressFile do it file to file.

archive-guide-targz.salam
import archive
import compress

func main:
    readme := compress.BufFromStr("Backup of the config folder.\n")
    conf := compress.BufFromStr("port = 8080\nworkers = 4\nport_admin = 8081\n")
    mut files := Vector {} as Vector<archive.TarFileInput>
    files.push(archive.MakeTarFileInput("config", null, 0, true))
    files.push(archive.MakeTarFileInput("config/README", readme.data, readme.len, false))
    files.push(archive.MakeTarFileInput("config/app.conf", conf.data, conf.len, false))
    tar := archive.TarCreate(files)
    tgz := compress.GzipCompressBuf(tar)
    println "tar:", tar.len, "bytes, tar.gz:", tgz.len, "bytes"
    archive.WriteBinaryFileBuf("config.tar.gz", tgz)

    mut ok := false
    packed := archive.ReadBinaryFile("config.tar.gz", ok)
    plain := compress.GzipDecompressBuf(packed, ok)
    if not ok:
        println "config.tar.gz is not valid gzip"
        ret 1
    end
    mut entries := archive.TarList(plain.data, plain.len)
    each e in entries:
        println e.name, e.size, e.is_dir
    end
    archive.FreeEntries(entries)
    app := archive.TarExtractByName(plain.data, plain.len, "config/app.conf", ok)
    print compress.BufToStrUnsafe(app)
    ret 0
end
Outputtar: 3584 bytes, tar.gz: 208 bytes config 0 true config/README 29 false config/app.conf 42 false port = 8080 workers = 4 port_admin = 8081

Reading goes the other way: gunzip with compress.GzipDecompressBuf, check ok, then TarList and TarExtractByName on the plain tar. Directory entries in a tar have size 0 and is_dir set.

Tell the format from the first bytes

A file name can lie, the bytes cannot. Every format starts with a fixed signature, so a program that accepts uploads should look at the bytes before it picks a reader:

FormatSignatureCheck
zip50 4b 03 04 (PK) at the startcompare the first four bytes
gzip1f 8b at the startcompare the first two bytes
RARRar! at the startIsRar
tarustar at byte 257compare five bytes from offset 257
archive-guide-detect.salam
import archive
import compress

func kind(b: compress.ByteBuf): str:
    if b.len >= 4 and compress.BufGet(b, 0) == 80 and compress.BufGet(b, 1) == 75 and compress.BufGet(b, 2) == 3 and compress.BufGet(b, 3) == 4:
        ret "zip"
    end
    if b.len >= 2 and compress.BufGet(b, 0) == 31 and compress.BufGet(b, 1) == 139:
        ret "gzip"
    end
    if archive.IsRar(b.data, b.len):
        ret "rar"
    end
    if b.len >= 262 and compress.BufGet(b, 257) == 117 and compress.BufGet(b, 258) == 115 and compress.BufGet(b, 259) == 116 and compress.BufGet(b, 260) == 97 and compress.BufGet(b, 261) == 114:
        ret "tar"
    end
    ret "unknown"
end

func count(b: compress.ByteBuf): int:
    k := kind(b)
    if k == "zip": ret archive.ZipList(b.data, b.len).len() end
    if k == "tar": ret archive.TarList(b.data, b.len).len() end
    if k == "rar": ret archive.RarList(b.data, b.len).len() end
    if k == "gzip":
        mut ok := false
        inner := compress.GzipDecompressBuf(b, ok)
        if ok: ret count(inner) end
    end
    ret 0
end

func main:
    note := compress.BufFromStr("a short note\n")
    mut zf := Vector {} as Vector<archive.ZipFileInput>
    zf.push(archive.MakeZipFileInput("note.txt", note.data, note.len, 8))
    mut tf := Vector {} as Vector<archive.TarFileInput>
    tf.push(archive.MakeTarFileInput("note.txt", note.data, note.len, false))
    tar := archive.TarCreate(tf)
    samples := [archive.ZipCreate(zf), tar, compress.GzipCompressBuf(tar), note]
    each s in samples:
        println kind(s), s.len, "bytes,", count(s), "entries"
    end
end
Outputzip 129 bytes, 1 entries tar 2048 bytes, 1 entries gzip 100 bytes, 1 entries unknown 13 bytes, 0 entries

The gzip sample is the tar from the line above it, gzipped, so the program opens it and counts the entries of the tar inside. A plain text file matches nothing.

Extract safely

ZipExtractAll and TarExtractAll create the folders they need under the target directory. An archive from someone else can hold names like ../escape.txt or /etc/passwd that would land outside it; both functions skip such entries, write the rest, and return false so you know something was left out. ZipExtractByName and TarExtractByName set ok to false when the name is not in the archive.

archive-guide-extract.salam
import archive
import compress

func main:
    a := compress.BufFromStr("first file\n")
    b := compress.BufFromStr("second file\n")
    mut files := Vector {} as Vector<archive.ZipFileInput>
    files.push(archive.MakeZipFileInput("docs/a.txt", a.data, a.len, 8))
    files.push(archive.MakeZipFileInput("docs/deep/b.txt", b.data, b.len, 8))
    z := archive.ZipCreate(files)
    println "all extracted:", archive.ZipExtractAll(z.data, z.len, "out")
    mut ok := false
    back := archive.ReadBinaryFile("out/docs/deep/b.txt", ok)
    print "out/docs/deep/b.txt:", compress.BufToStrUnsafe(back)

    _ := archive.ZipExtractByName(z.data, z.len, "docs/c.txt", ok)
    println "docs/c.txt found:", ok

    mut evil := Vector {} as Vector<archive.ZipFileInput>
    evil.push(archive.MakeZipFileInput("../escape.txt", a.data, a.len, 0))
    evil.push(archive.MakeZipFileInput("safe.txt", a.data, a.len, 0))
    ez := archive.ZipCreate(evil)
    println "all extracted:", archive.ZipExtractAll(ez.data, ez.len, "out2")
    _ := archive.ReadBinaryFile("escape.txt", ok)
    println "escape.txt written:", ok
    _ := archive.ReadBinaryFile("out2/safe.txt", ok)
    println "out2/safe.txt written:", ok
end
Outputall extracted: true out/docs/deep/b.txt: second file docs/c.txt found: false all extracted: false escape.txt written: false out2/safe.txt written: true

A false result from an extract call is therefore not always a disk error: check the entry names with ZipList or TarList when you need to tell the two apart.

Read and write a RAR

Reading goes through RarList and RarExtract, the same way as zip. The sample below is a small solid RAR 5 made by WinRAR: the second file is packed against the first, so RarExtract unpacks both to reach it. Every entry is checked against its CRC-32, and the status says what went wrong instead of returning silent garbage.

Open a password-protected RAR

A RarArchive remembers the data and the password, so the list, a single read and a full extraction share them. With the wrong password the archive does not open (when the names are encrypted) or each read fails with RAR_BAD_PASSWORD; with none at all you get RAR_ENCRYPTED. RAR 5 checks the password up front. RAR 3 and 4 have no check value, so for them a wrong password shows up as a failed checksum, and it is reported the same way.

Read a multi-volume RAR

A big archive is often cut into volumes: name.part01.rar, name.part02.rar, and so on, or the older name.rar, name.r00, name.r01. RarReadVolumes takes the first file name, finds the rest by that naming and loads them; RarOpenVolumes turns the list into a RarArchive, and the usual RarEntries and RarRead work across the cuts. Close the archive with RarClose and free the volumes with RarFreeVolumes.

func from_hex(text: str): compress.ByteBuf:
    mut out := compress.NewByteBuf()
    bytes := text as u8*
    mut high := -1
    repeat text.len() in i:
        v := digit(bytes[i] as int)
        if v < 0:
            continue
        end
        if high < 0:
            high = v
        else:
            compress.BufPush(out, high * 16 + v)
            high = -1
        end
    end

func digit(c: int): int:
    if c >= 48 and c <= 57:
        ret c - 48
    end
    if c >= 97 and c <= 102:
        ret c - 87
    end
    ret -1
end

func from_hex(text: str): compress.ByteBuf:
    mut out := compress.NewByteBuf()
    bytes := text as u8*
    mut high := -1
    repeat text.len() in i:
        v := digit(bytes[i] as int)
        if v < 0:
            continue
        end
        if high < 0:
            high = v
        else:
            compress.BufPush(out, high * 16 + v)
            high = -1
        end
    end
    ret out
end
