audio

Sound as a clip of samples: cutting, mixing, measuring and converting it.

import audio

This is an official package that does not ship with Salam. Add it to a project first: salam add audio

This package is the middle of everything to do with sound in Salam. A Clip holds the sound itself: plain 32 bit floating point samples between -1 and 1, one frame after another, with the channels side by side. Reading and writing files is the job of the format packages, audio/wav today, and audio/codec opens any of them without being told which. Filters, a Fourier transform and careful resampling live in audio/dsp.

What is here is the clip and everything that does not need to know a file format: cutting, joining, mixing, fading, measuring how loud something is, moving between mono and stereo and between sample rates, and the most significant bit first bitstream reader that every audio codec is written on top of.

Things to know

  • Samples are 32 bit floats. Every clip owns that memory; release it with Free.
  • Because a float carries 24 bits of mantissa, 8, 16 and 24 bit sound makes the round trip through a clip exactly. Only a true 32 bit integer source loses its lowest 8 bits.
  • A three minute stereo song at 44100 is about 63 MB as a clip, so decode a long file in pieces rather than all at once.
  • bits remembers the depth a clip was read at, so writing it again keeps that depth. A clip made with New has no depth, and an encoder then picks 16 bit.
  • Anything that fails returns an empty clip rather than stopping the program, so check with IsEmpty.
  • MsbReader reads the most significant bit first. The BitReader in compress reads the other way round, for DEFLATE, and is not interchangeable with it.

A clip of sound

A clip is a rate, a channel count, a frame count and the samples. New gives you silence to fill in; SetSample and Sample reach one sample at a time by frame and channel. A frame is one sample for every channel, so a stereo clip of 100 frames holds 200 samples.

Every clip holds memory of its own, so release each one with Free. Reading or writing outside the clip is not an error: Sample gives 0 and SetSample does nothing, which keeps loops at the edges simple.

How loud is it

Peak is the furthest any single sample gets from zero and RMS follows loudness as an ear hears it. Both have a decibel form, where 0 dB is as loud as a sample can be and everything quieter is negative. GainToDb and DbToGain move between a plain multiplier and decibels.

Silence has no decibel value, so GainToDb(0.0) returns SilenceFloorDb instead of running off to minus infinity. FirstSound and LastSound find where the sound really starts and stops, which is what TrimSilence is built from.

Cutting and joining

Slice and Trim take a piece out, by frame or by time; Concat puts one clip after another and Mix lays them on top of each other. Normalize scales a clip so its peak lands exactly where you ask, and the two fades shape the ends so a cut does not click.

Joining and mixing need both clips to agree on the sample rate and the channel count, and return an empty clip when they do not. Use ToRate and ToChannels first to bring them into line.

Rates, channels and depths

ToMono averages the channels together and ToStereo spreads one channel across two. ToRate changes the sample rate by interpolating between samples, which is quick and good enough for speech; for music use ResampleSinc from audio/dsp. ToBits does not write a file, it rounds the samples to the steps of a depth so you can hear what that depth will cost.

Deinterleave hands back one clip per channel, each of which you must free, and Interleave weaves them back together.

Which format is this

DetectFormat looks at the first few bytes and FormatFromExt at the file name. Both answer with a Format number, which FormatName turns into a short name. Knowing the format does not mean this build can decode it: ask CanDecode in audio/codec for that.

An Info is what a file says about itself, which the format packages fill in by reading a header rather than the whole file. It is the cheap way to show a length or a bit rate in a listing.

Reading a bitstream

Compressed audio is not laid out in bytes, it is laid out in bits, and every format from MP3 to FLAC counts those bits from the most significant end. MsbReader does that, with MsbReadSigned for two's complement fields and MsbUnary for the run of zeros that Rice and Golomb codes are built from. MsbWriter is the same thing in reverse.

A read past the end does not stop the program: it hands back zeros and sets bad, which stays set, so one check after a group of reads is enough. Note again that compress has a bit reader of its own that runs the other way round, for DEFLATE; do not use it for audio.

Types

Clip

struct Clip
A piece of sound: interleaved f32 samples with a sample rate, a channel count and a frame count.
NameTypeDescription
rateint = 0Frames per second, such as 44100.
channelsint = 0How many channels each frame holds; 1 is mono, 2 is stereo.
framesint = 0How many frames the clip holds. One frame is one sample per channel.
bitsint = 0The bit depth the samples came from, or 0 when they were made in memory. An encoder with no depth of its own writes 16 bit.
samplesvoid*The samples themselves, 32 bit floats, one frame after another with the channels side by side.
audio-Clip.salam
import audio

func main:
    mut c := audio.New(8000, 2, 400)
    println c.rate, c.channels, c.frames, c.bits
    println audio.SampleCount(c), audio.Duration(c), audio.IsEmpty(c)
    audio.SetSample(c, 0, 0, 0.5)
    audio.SetSample(c, 0, 1, -0.25)
    audio.AddSample(c, 0, 0, 0.25)
    println audio.Sample(c, 0, 0), audio.Sample(c, 0, 1), audio.Sample(c, 399, 0)
    println audio.Sample(c, 4000, 0), audio.InBounds(c, 399, 1), audio.InBounds(c, 400, 0)
    println audio.FrameAt(c, 0.025), audio.SecondsAt(c, 200), audio.FrameAt(c, 99.0)
    mut q := audio.Clone(c)
    println audio.Sample(q, 0, 0), audio.Peak(q)
    audio.Silence(q)
    println audio.Peak(q)
    mut s := audio.NewSilence(8000, 1, 0.25)
    println s.frames, audio.MaxSamples
    audio.Free(c)
    println audio.IsEmpty(c), c.frames
    audio.Free(q)
    audio.Free(s)
end

MsbReader

struct MsbReader
Reads a bit at a time, most significant bit first, the order every audio codec uses.
NameTypeDescription
datavoid*The bytes being read.
lenint = 0How many bytes there are.
posint = 0Which byte comes next.
acci64 = 0Bits already pulled out of the bytes but not yet handed back.
nbitsint = 0How many bits are waiting in the accumulator.
badbool = falseTrue once a read ran past the end. It stays true.
audio-Msb.salam
import audio
import compress

func main:
    mut w := audio.NewMsbWriter()
    audio.MsbWrite(w, 10, 4)
    audio.MsbWrite(w, 5, 4)
    println audio.MsbLen(w)
    audio.MsbWrite(w, 60, 8)
    bytes := audio.MsbFinish(w)
    println compress.BufLen(bytes), compress.BufGet(bytes, 0), compress.BufGet(bytes, 1)
    mut r := audio.MsbReaderFromBuf(bytes)
    println audio.MsbRead(r, 4), audio.MsbRead(r, 4), audio.MsbRead(r, 8), audio.MsbBad(r)
    mut s := audio.MsbReaderFromBuf(bytes)
    println audio.MsbReadSigned(s, 4), audio.MsbReadBit(s), audio.MsbTell(s)
    mut t := audio.MsbReaderFromBuf(bytes)
    println audio.MsbReadI64(t, 16)
    mut u := audio.NewMsbWriter()
    audio.MsbWriteUnary(u, 0)
    audio.MsbWriteUnary(u, 3)
    audio.MsbWriteUnary(u, 7)
    runs := audio.MsbFinish(u)
    mut ur := audio.MsbReaderFromBuf(runs)
    println audio.MsbUnary(ur), audio.MsbUnary(ur), audio.MsbUnary(ur)
    mut j := audio.MsbReaderFromBuf(bytes)
    audio.MsbSkip(j, 8)
    println audio.MsbRead(j, 8)
    audio.MsbSeek(j, 4)
    println audio.MsbRead(j, 4), audio.MsbTell(j), audio.MsbLeft(j)
    mut k := audio.MsbReaderFromBuf(bytes)
    audio.MsbRead(k, 3)
    audio.MsbAlign(k)
    println audio.MsbRead(k, 8)
    mut p := audio.NewMsbWriter()
    audio.MsbWriteBit(p, 1)
    audio.MsbPad(p)
    padded := audio.MsbFinish(p)
    println compress.BufLen(padded), compress.BufGet(padded, 0)
    mut over := audio.NewMsbReader(bytes.data, 1)
    audio.MsbRead(over, 16)
    println audio.MsbBad(over)
    audio.MsbFree(w)
    audio.MsbFree(u)
    audio.MsbFree(p)
end

import audio
import audio.wav
import compress

func main:
    mut c := audio.New(44100, 2, 44100)
    buf := wav.EncodeWAV(c)
    println audio.FormatName(audio.DetectFormat(buf.data, buf.len))
    println audio.DetectFormat(buf.data, 4) == audio.FormatUnknown
    println audio.FormatName(audio.FormatFromExt("song.flac")), audio.FormatName(audio.FormatFromExt("SONG.WAV"))
    println audio.FormatName(audio.FormatFromExt("a.mp3")), audio.FormatName(audio.FormatFromExt("a.ogg")), audio.FormatName(audio.FormatFromExt("a.mid"))

    println audio.FormatIsLossless(audio.FormatWAV), audio.FormatIsLossless(audio.FormatFLAC), audio.FormatIsLossless(audio.FormatMP3)
    mut ok := false
    info := wav.ProbeWAV(buf.data, buf.len, ok)
    println ok, audio.FormatName(info.format)
    println info.rate, info.channels, info.bits, info.frames
    println info.duration, info.bitrate, info.lossless, info.vbr

SilenceFloorDb

The decibel value used for silence, because true silence has no decibel value.
audio-Measure.salam
import audio

func main:
    mut c := audio.New(8000, 1, 4)
    audio.SetSample(c, 0, 0, 1.0)
    audio.SetSample(c, 1, 0, -0.5)
    audio.SetSample(c, 2, 0, 0.0)
    audio.SetSample(c, 3, 0, 0.25)
    println audio.Peak(c), audio.PeakChannel(c, 0), audio.DcOffset(c)
    println audio.IsClipped(c), audio.CountClipped(c)
    println audio.GainToDb(1.0), audio.DbToGain(0.0)
    println audio.DbToGain(audio.GainToDb(0.25))
    println audio.GainToDb(0.0), audio.SilenceFloorDb, audio.DbToGain(audio.SilenceFloorDb)
    println audio.IsSilent(c, -60.0), audio.FirstSound(c, -60.0), audio.LastSound(c, -60.0)
    mut gap := audio.New(8000, 1, 8)
    audio.SetSample(gap, 3, 0, 0.5)
    audio.SetSample(gap, 4, 0, 0.5)
    println audio.FirstSound(gap, -60.0), audio.LastSound(gap, -60.0)
    mut quiet := audio.New(8000, 1, 8)
    println audio.IsSilent(quiet, -60.0), audio.FirstSound(quiet, -60.0)
    println audio.RMS(gap), audio.RMSRange(gap, 3, 2)
    audio.Free(c)
    audio.Free(gap)
    audio.Free(quiet)
end

audio-Edit.salam
import audio

func ramp(frames: int): audio.Clip:
    mut c := audio.New(8000, 1, frames)
    mut i := 0
    until i < frames:
        audio.SetSample(c, i, 0, (i as f64) / 32.0)
        i += 1
    end
    ret c
end

func main:
    a := ramp(8)
    sl := audio.Slice(a, 2, 3)
    println sl.frames, audio.Sample(sl, 0, 0), audio.Sample(sl, 2, 0)
    println audio.Trim(a, 0.0, 0.0005).frames, audio.Slice(a, 6, 10).frames
    cat := audio.Concat(sl, sl)
    println cat.frames, audio.Sample(cat, 3, 0)
    println audio.Repeat(sl, 4).frames
    mix := audio.Mix(a, a, 1.0, 0.5)
    println audio.Sample(mix, 4, 0)
    mut g := audio.Clone(a)
    audio.Scale(g, 2.0)
    println audio.Sample(g, 1, 0)
    audio.Gain(g, 0.0)
    println audio.Sample(g, 1, 0)
    audio.Scale(g, 100.0)
    audio.Clamp(g)
    println audio.Peak(g)
    mut n := audio.Clone(a)
    audio.Normalize(n, 0.0)
    println audio.Peak(n)
    mut r := audio.Clone(a)
    audio.Reverse(r)
    println audio.Sample(r, 0, 0), audio.Sample(r, 7, 0)
    mut f := audio.Clone(a)
    audio.FadeIn(f, audio.Duration(f))
    println audio.Sample(f, 0, 0), audio.Sample(f, 4, 0)
    mut o := audio.Clone(a)
    audio.FadeOut(o, audio.Duration(o))
    println audio.Sample(o, 0, 0)
    println audio.Pad(a, 0.001, 0.001).frames
    mut head := audio.Clip {}
    mut tail := audio.Clip {}
    audio.Split(a, 0.0005, head, tail)
    println head.frames, tail.frames, audio.Sample(tail, 0, 0)
    mut gap := audio.New(8000, 1, 8)
    audio.SetSample(gap, 3, 0, 0.5)
    audio.SetSample(gap, 4, 0, 0.5)
    println audio.TrimSilence(gap, -60.0).frames
    mut dst := audio.New(8000, 1, 8)
    audio.MixAt(dst, sl, 2, 1.0)
    println audio.Sample(dst, 2, 0), audio.Sample(dst, 0, 0)
    audio.Free(a)
end

audio-Convert.salam
import audio

func main:
    mut st := audio.New(8000, 2, 4)
    mut i := 0
    until i < 4:
        audio.SetSample(st, i, 0, (i as f64) / 8.0)
        audio.SetSample(st, i, 1, 0.0 - (i as f64) / 16.0)
        i += 1
    end
    st.bits = 16
    mono := audio.ToMono(st)
    println mono.channels, audio.Sample(mono, 2, 0), mono.bits
    wide := audio.ToStereo(mono)
    println wide.channels, audio.Sample(wide, 2, 0) == audio.Sample(wide, 2, 1)
    quad := audio.ToChannels(mono, 4)
    println quad.channels, audio.Sample(quad, 1, 3)
    left := audio.Channel(st, 0)
    right := audio.Channel(st, 1)
    println left.channels, audio.Sample(left, 3, 0), audio.Sample(right, 3, 0)
    parts := audio.Deinterleave(st)
    println parts.len()
    woven := audio.Interleave(parts)
    println woven.channels, audio.Sample(woven, 3, 1) == audio.Sample(st, 3, 1)
    down := audio.ToRate(st, 4000)
    println down.rate, down.frames, down.bits
    up := audio.ToRate(mono, 16000)
    println up.rate, up.frames, audio.Sample(up, 2, 0)
    rough := audio.ToBits(mono, 4)
    println rough.bits, audio.Sample(rough, 1, 0), audio.Sample(rough, 3, 0)
    audio.Free(st)
    audio.Free(mono)
end

MuLawToPcm

func MuLawToPcm(b: int): int

audio-Pcm.salam
import audio
import compress
import math

func main:
    println audio.PcmDepthValid(16), audio.PcmDepthValid(12), audio.PcmDepthValid(32)

    mut c := audio.New(8000, 1, 4)
    audio.SetSample(c, 0, 0, 0.5)
    audio.SetSample(c, 1, 0, -0.5)
    audio.SetSample(c, 2, 0, 0.25)

    mut le := compress.NewByteBuf()
    audio.EncodePcm(le, c, 16, false, false)
    println compress.BufLen(le), compress.BufGet(le, 0), compress.BufGet(le, 1)
    mut be := compress.NewByteBuf()
    audio.EncodePcm(be, c, 16, true, false)
    println compress.BufGet(be, 0), compress.BufGet(be, 1)

    mut back := audio.New(8000, 1, 4)
    println audio.DecodePcm(le.data, 0, back, 16, false, false)
    println audio.Sample(back, 0, 0), audio.Sample(back, 1, 0), audio.Sample(back, 2, 0)
    mut bback := audio.New(8000, 1, 4)
    audio.DecodePcm(be.data, 0, bback, 16, true, false)
    println audio.Sample(bback, 0, 0) == audio.Sample(back, 0, 0)

    mut f := compress.NewByteBuf()
    audio.EncodeFloatPcm(f, c, 32, false)
    mut fback := audio.New(8000, 1, 4)
    println audio.DecodeFloatPcm(f.data, f.len, 0, fback, 32, false)
    println audio.Sample(fback, 0, 0) == audio.Sample(c, 0, 0)

    println audio.PcmToMuLaw(0), audio.MuLawToPcm(audio.PcmToMuLaw(0))
    println audio.PcmToMuLaw(16000), audio.MuLawToPcm(144)
    println audio.PcmToALaw(16000), audio.ALawToPcm(186)
    mut worst := 0
    mut v := -32768
    until v < 32768:
        d := math.AbsI(audio.MuLawToPcm(audio.PcmToMuLaw(v)) - v)
        if d > worst:
            worst = d
        end
        v += 7
    end
    println worst < 820

    mut law := compress.NewByteBuf()
    audio.EncodeLawPcm(law, c, false)
    println compress.BufLen(law)
    mut lback := audio.New(8000, 1, 4)
    println audio.DecodeLawPcm(law.data, 0, lback, false)
    println math.Abs(audio.Sample(lback, 0, 0) - 0.5) < 0.02

    compress.BufFree(le)
    compress.BufFree(be)
    compress.BufFree(f)
    compress.BufFree(law)
    audio.Free(c)
    audio.Free(back)
    audio.Free(bback)
    audio.Free(fback)
    audio.Free(lback)
end
