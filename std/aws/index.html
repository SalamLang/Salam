aws

Amazon S3, SQS and STS, and any S3 compatible service, with Signature Version 4.

import aws
On this page
  1. Types
  2. Constants and variables
  3. Functions

This package works with Amazon S3 and any storage compatible with it without the official SDK, including MinIO, Cloudflare R2, DigitalOcean Spaces, Wasabi, Backblaze and any other S3 compatible cloud storage. Build the configuration with ForAws or ForEndpoint and hand it the keys with WithCredentials, or let the package find them itself with FromEnvironment and ResolveConfig.

The S3... functions work with objects and buckets: writing and reading, listing, copying, files and folders, multipart uploads for large files, and presigned URLs so a browser can talk to S3 directly. The Sqs... functions cover SQS message queues and the AssumeRole... functions cover temporary STS credentials. For other services, such as DynamoDB, call any API with NewJsonCall and Invoke.

Never write keys into your code; use environment variables or an IAM role. The examples that need an AWS account are only checked on the site, not run.

    println up.ok, up.bytes, up.parts, up.etag
    println aws.S3FileEtag("/tmp/dump_en.sql", aws.S3_PART_DEFAULT) == up.etag

    dir := aws.S3UploadDir(cfg, "/var/www/site", "site/", aws.PutOptions {})
    println dir.ok, dir.files, dir.bytes, dir.skipped, dir.failed_path

    _ := aws.S3PutLarge(cfg, "big.bin", chunk as void*, chunk.len(), 0, aws.PutOptions {})
