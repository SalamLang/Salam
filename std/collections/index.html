Standard library · Numbers and collections

collections

Data structures: vector and map, stack, queue, deque, set, linked list, priority queue and counter.

import collections
On this page
  1. Types
  2. Functions

Vector and HashMap, which turn up in every program, are defined in this package, but you do not have to import it to use them. The rest, such as the stack and the queue, become available with import collections.

All of these are generic: you set the element type with <...>, as in collections.Stack<str>. All of them allocate, so write defer ....free() right after creating one.

Which should you pick? For an ordinary list, Vector; for "last in, first out", Stack; for "first in, first out", Queue; for adding and removing at both ends, Deque; for fast lookup by a key, HashMap; for removing duplicates, Set; and for "always give me the smallest", PriorityQueue.

func main:

import collections

func main:

Vector

struct Vector<T>
A list whose size changes: the data structure you will use most. The elements sit next to each other in memory and access by index is immediate. You can also read and write elements with [i].
NameTypeDescription
dataT*The address of the elements in memory.
collections-Vector.salam
func main:
    mut v := Vector {} as Vector<int>
    defer v.free()
    v.reserve(8)
    println v.len(), v.cap() >= 8, v.is_empty()
    v.push(10)
    v.push(20)
    v.push(30)
    println v, v.first(), v.last(), v.get(1), v[2]
    v.set(0, 11)
    v[1] = 22
    v.insert(1, 15)
    println v
    println v.remove_at(1), v.pop(), v
    r := v.ref(0)
    r[0] = 99
    println v
    v.resize_set(v.len(), 7)
    println v
    v.clear()
    println v.len()
    mut z := Vector {} as Vector<int>
    defer z.free()
    z.zeros(3)
    println z
    mut a := Vector {} as Vector<int>
    defer a.free()
    a.alloc(4)
    println a.len()
end
Output0 true true [10, 20, 30] 10 30 20 30 [11, 15, 22, 30] 15 30 [11, 22] [99, 22] [99, 22, 7] 0 [0, 0, 0] 4
