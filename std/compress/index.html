This package is the base of all binary data work in Salam. ByteBuf, a growable byte buffer, and ByteReader, a cursor over bytes, are what packages such as encoding.binary, archive and encoding.msgpack pass around. On top of them it has gzip, bzip2, raw DEFLATE, a few teaching compressors (RLE, LZ77, LZW, Huffman, BWT), bit-level reading and writing, and the CRC-32 and Adler-32 checksums.

To pack several files into one .zip or .tar, use archive, which calls this package for the compression. To write numbers in a fixed byte order, use encoding.binary on the same buffers.

For compression, reach for gzip when the data has to be read by other programs. Use bzip2 when the result should be smaller than gzip and a slower pack is fine; it reads and writes standard .bz2 data. The other methods are mostly there to learn from and experiment with, and their output format belongs to this package alone. The examples show that for small data the overhead of Huffman and DEFLATE comes to more than the data itself.

What trips people up

  • Gzip verifies its checksum. GzipDecompress checks the header, inflates the data, then compares both the CRC-32 and the uncompressed length in the trailer; a mismatch sets ok false and returns an empty buffer.
  • Xz and LZMA writing is a fast match finder, not a tuned one. The packed size is within a few percent of xz at the same level, never smaller. The whole input and the whole result are held in memory, and level 9 asks for a 64 MiB window. The result of a decoder is kept whole in memory too, so use the ...Max functions on data you did not make yourself.
  • Zstandard output is valid, not the smallest. The writer is simple, so ZstdCompressLevel makes frames usually a quarter to a half larger than the zstd tool at the same level; every reader still accepts them. Reading is complete, but only ZstdDecompressDict and ZstdDecompressEx take a dictionary, and the decoder holds the whole result in memory, so use ZstdDecompressMax on data from outside.
  • Bzip2 checks every checksum and can be capped. Bzip2Decompress verifies each block CRC and the whole stream CRC and rejects broken tables and indexes, and it accepts several streams one after another and nothing else after them. A tiny file can expand to a huge one, so use Bzip2DecompressMax on data from outside.
  • The method is not stored. Compress output does not say which method made it; keep the method number next to the data.
  • A str stops at the first zero byte. Keep binary data in a ByteBuf; BufToStrUnsafe is for bytes that are really text.
  • Buffers are not freed for you. Call BufFree on buffers you are done with, especially in loops and servers.

The guide below covers the jobs this package is used for day to day: gzipping and bzip2-ing text, laying out your own binary records in a ByteBuf, checking data with CRC-32, and choosing a compression method. Each section has a complete program with its output.

Gzip text for storage or transport

GzipCompressStr turns a string into a gzip stream that gzip -d, browsers and every other gzip reader understand, and GzipDecompressBuf turns it back. Gzip output is binary, so when it has to travel inside JSON, a URL or an environment variable, wrap it in Base64 with BufToBase64. On the receiving side encoding.Base64DecodeBytes writes the bytes into a buffer you have made big enough; set the buffer's len to the count it returns. It throws when the text is not Base64 or does not fit, so call it inside try:.

compress-guide-gzip.salam
import compress
import encoding

func main:
    mut log := ""
    repeat 20:
        log += "GET /api/users 200 12ms\n"
    end
    packed := compress.GzipCompressStr(log)
    println "original:", log.len(), "bytes"
    println "gzipped: ", packed.len, "bytes"
    println "ratio:   ", compress.Ratio(packed.len, log.len())
    text := compress.BufToBase64(packed)
    println "base64:  ", text.len(), "characters"
    mut ok := false
    mut wire := compress.NewByteBufCap(text.len())
    try:
        wire.len = encoding.Base64DecodeBytes(text, wire.data, text.len())
        ok = true
    catch e:
        println "base64:", e.to_str()
    end
    println "decoded: ", ok, compress.BufEquals(wire, packed)
    back := compress.GzipDecompressBuf(wire, ok)
    println "restored:", ok, compress.BufToStrUnsafe(back) == log
end
Outputoriginal: 480 bytes gzipped: 48 bytes ratio: 0.1 base64: 64 characters decoded: true true restored: true true

A log with the same line twenty times shrinks to a tenth of its size. Base64 costs a third back (64 characters for 48 bytes), which is still far smaller than the original. BufToStrUnsafe copies the bytes into a string, so use it only for data that is really text: a str ends at the first zero byte.

Bzip2 for smaller files

Bzip2CompressStr, Bzip2Compress and Bzip2CompressBuf write a standard bzip2 stream (what bzip2 and Python's bz2 read), and Bzip2CompressLevel takes a level from 1 to 9: the block size in units of 100000 bytes, 9 by default. Bzip2DecompressBuf reads one or more streams, including old ones with randomised blocks, and checks all CRCs. The program packs the same text both ways and then shows the two safety nets: a cap on the unpacked size, and a flipped bit.

compress-guide-bzip2.salam
import compress

func main:
    words := ["salam", "compress", "block", "sort", "stream", "byte", "table", "code", "bit", "run"]
    mut text := ""
    mut x := 7
    repeat 4000:
        x = (x * 75 + 74) % 65537
        text += words[x % 10]
        text += " "
    end
    gz := compress.GzipCompressStr(text)
    bz := compress.Bzip2CompressStr(text)
    println "original:", text.len(), "bytes"
    println "gzip:    ", gz.len, "bytes"
    println "bzip2:   ", bz.len, "bytes"
    mut ok := false
    back := compress.Bzip2DecompressBuf(bz, ok)
    println "restored:", ok, compress.BufToStrUnsafe(back) == text
    _ := compress.Bzip2DecompressMax(bz.data, bz.len, 1000, ok)
    println "capped at 1000 bytes:", ok
    mut damaged := compress.BufClone(bz)
    compress.BufSet(damaged, damaged.len / 2, compress.BufGet(damaged, damaged.len / 2) ^ 1)
    _ := compress.Bzip2DecompressBuf(damaged, ok)
    println "damaged:", ok
end
Outputoriginal: 22837 bytes gzip: 3281 bytes bzip2: 2050 bytes restored: true true capped at 1000 bytes: false damaged: false

On text with many repeated words bzip2 beats gzip by a good margin, while on short or already compressed data the two are close. Bzip2 needs more time and memory per megabyte than gzip, so it suits files that are written once and read rarely. To work with .bz2 files on disk, use Bzip2CompressFile and Bzip2DecompressFile from archive.

Your own binary format with ByteBuf

A ByteBuf grows as you push into it, and a ByteReader walks over the bytes from the start. That is all you need for a small file format: a few magic bytes so that a wrong file is rejected, a count, and then each record as a length and its bytes. BufPushU32 and RdU32 write and read a 32 bit number in big-endian order; for little-endian or 64 bit numbers use encoding.binary, which works on the same buffers.

compress-guide-record.salam
import compress

func write_names(names: Vector<str>): compress.ByteBuf:
    mut b := compress.NewByteBuf()
    compress.BufPushBuf(b, compress.BufFromStr("NAMS"))
    compress.BufPushU32(b, names.len())
    each name in names:
        compress.BufPushU32(b, name.len())
        compress.BufPushBuf(b, compress.BufFromStr(name))
    end
    ret b
end

func read_names(b: compress.ByteBuf):
    mut r := compress.ReaderFromBuf(b)
    magic := compress.RdBytes(r, 4)
    if compress.BufToStrUnsafe(magic) != "NAMS":
        println "not a names file"
        ret
    end
    count := compress.RdU32(r)
    repeat count in i:
        n := compress.RdU32(r)
        name := compress.RdBytes(r, n)
        if r.bad:
            println "record", i, "is cut short"
            ret
        end
        println i, compress.BufToStrUnsafe(name)
    end
end

func main:
    mut names := Vector {} as Vector<str>
    names.push("Ada")
    names.push("Grace")
    names.push("Linus")
    b := write_names(names)
    println "bytes:", compress.BufLen(b)
    read_names(b)
    mut cut := compress.NewByteReader(b.data, 20)
    read_names(compress.RdBytes(cut, 20))
end
Outputbytes: 33 0 Ada 1 Grace 2 Linus 0 Ada record 1 is cut short

The reader never reads past the end. When a read asks for more bytes than are left, the reader sets bad, returns zeros or an empty buffer, and stays bad, so it is enough to check r.bad once after a group of reads. The last call reads a copy cut to 20 bytes: the first name still fits, the second does not.

Checking data with CRC-32

A checksum tells you whether bytes arrived unchanged. CRC32Str and CRC32Buf compute the same CRC-32 that zip, gzip and PNG use; Adler32Str and Adler32Buf are faster and weaker, the one zlib uses. The program seals a message by appending its CRC, then shows that changing a single byte is caught.

compress-guide-checksum.salam
import compress

func seal(payload: str): compress.ByteBuf:
    mut b := compress.BufFromStr(payload)
    compress.BufPushU32(b, compress.CRC32Str(payload) as int)
    ret b
end

func check(b: compress.ByteBuf): bool:
    if b.len < 4: ret false end
    mut r := compress.NewByteReader(b.data, b.len)
    body := compress.RdBytes(r, b.len - 4)
    stored := compress.RdU32(r) as u32
    ret compress.CRC32Buf(body) == stored
end

func gunzip_checked(g: compress.ByteBuf, ok &: bool): compress.ByteBuf:
    out := compress.GzipDecompressBuf(g, ok)
    if not ok: ret out end
    at := g.len - 8
    stored := compress.BufGet(g, at) | (compress.BufGet(g, at + 1) << 8) | (compress.BufGet(g, at + 2) << 16) | (compress.BufGet(g, at + 3) << 24)
    ok = compress.CRC32Buf(out) == stored as u32
    ret out
end

func main:
    mut packet := seal("move 3 to slot 7")
    println "length:", packet.len, "intact:", check(packet)
    compress.BufSet(packet, 5, 52)
    println "after one changed byte, intact:", check(packet)
    g := compress.GzipCompressStr("move 3 to slot 7")
    mut broken := compress.BufClone(g)
    compress.BufSet(broken, broken.len - 6, compress.BufGet(broken, broken.len - 6) ^ 1)
    mut ok := false
    _ := compress.GzipDecompressBuf(broken, ok)
    println "damaged gzip, plain decompress:", ok
    _ := gunzip_checked(broken, ok)
    println "damaged gzip, checked:", ok
    _ := gunzip_checked(g, ok)
    println "good gzip, checked:", ok
end
Outputlength: 20 intact: true after one changed byte, intact: false damaged gzip, plain decompress: false damaged gzip, checked: false good gzip, checked: true

GzipDecompress and GzipDecompressBuf check the header and the optional header CRC, inflate the data, and then compare the CRC-32 and the length in the last eight bytes of the stream. A flipped bit there, or a corruption that still decodes, is reported by ok being false, so you never see damaged data as a successful read.

Choosing a method

Compress, CompressBuf and CompressStr take a method number, and CompressBest tries each one and keeps the smallest result. The best method depends on the shape of the data, as these output sizes show:

compress-guide-choose.salam
import compress
import str

func methodName(m: int): str:
    switch m:
        compress.MethodRLE: ret "rle" end
        compress.MethodHuffman: ret "huffman" end
        compress.MethodLZ77: ret "lz77" end
        compress.MethodLZW: ret "lzw" end
        compress.MethodDeflate: ret "deflate" end
        compress.MethodBWT: ret "bwt" end
    end
    ret "none (stored)"
end

func row(label: str, data: str):
    b := compress.BufFromStr(data)
    mut line := label + ": " + str.FromInt(b.len) + " bytes, rle " + str.FromInt(compress.CompressBuf(compress.MethodRLE, b).len)
    line = line + ", lz77 " + str.FromInt(compress.CompressBuf(compress.MethodLZ77, b).len)
    line = line + ", gzip " + str.FromInt(compress.GzipCompressBuf(b).len)
    mut best := 0
    smallest := compress.CompressBest(b.data, b.len, best)
    println line
    println "  best:", methodName(best), "at", smallest.len, "bytes"
end

func main:
    mut runs := ""
    repeat 200: runs += "0" end
    mut words := ""
    repeat 10: words += "error at line 42; " end
    row("runs", runs)
    row("words", words)
    row("short", "hi there")
end
Outputruns: 200 bytes, rle 8, lz77 30, gzip 23 best: rle at 8 bytes words: 180 bytes, rle 186, lz77 44, gzip 40 best: lz77 at 44 bytes short: 8 bytes, rle 13, lz77 13, gzip 28 best: none (stored) at 12 bytes

RLE wins on long runs of one byte and makes ordinary text bigger. LZ77 does well on repeated phrases. MethodDeflate is left out of the list because it is this package's own container, which stores its Huffman tables in full and so starts at almost 300 bytes; gzip uses real DEFLATE with compact tables and is the better choice whenever the data leaves your program. Two rules follow: the output of Compress does not say which method made it, so store the method number next to the data (the value CompressBest wrote into its last argument), and very short inputs are best stored as they are (method 0, which CompressBest reports as none for the short line above).

Read .xz and .lzma files

XzDecompress opens the .xz files that xz, tar -J and 7z a -txz write, and LzmaDecompress the older .lzma format. An xz file is checked as it is read: the headers, the index and the CRC-32, CRC-64 or SHA-256 of every block, and any mismatch gives ok false with an empty result. The decoders hold the whole result in memory, so on data you did not make yourself call XzDecompressMax or LzmaDecompressMax with the biggest size you accept; a few hundred bytes of LZMA can describe gigabytes.

compress-guide-xz.salam
import compress

const PACKED := """

"""

func nib(c: int): int:
    if c >= 48 and c <= 57:
        ret c - 48
    end
    if c >= 97 and c <= 102:
        ret c - 87
    end
    ret -1
end

func unhex(s: str): compress.ByteBuf:
    mut b := compress.NewByteBuf()
    bp := s as u8*
    mut hi := -1
    repeat s.len() in i:
        v := nib(bp[i] as int)
        if v < 0:
            continue
        end
        if hi < 0:
            hi = v
        else:
            compress.BufPush(b, hi * 16 + v)
            hi = -1
        end
    end
    ret b
end

func main:
    packed := unhex(PACKED)
    mut ok := false
    text := compress.XzDecompressBuf(packed, ok)
    println "decoded:", ok, text.len, "bytes from", packed.len
    println compress.BufToStrUnsafe(text)

    mut damaged := compress.BufClone(packed)
    compress.BufSet(damaged, damaged.len - 20, compress.BufGet(damaged, damaged.len - 20) ^ 1)
    broken := compress.XzDecompressBuf(damaged, ok)
    println "damaged file:", ok, broken.len

    small := compress.XzDecompressMax(packed.data, packed.len, 100, ok)
    println "capped at 100 bytes:", ok, small.len
end

Write .xz and .lzma files

XzCompressStr, XzCompress and XzCompressBuf write a standard .xz file that xz, unxz, tar -J and 7-Zip open: one LZMA2 block, a CRC-64 check, and an index. XzCompressLevel takes a level from 0 (fastest, 256 KiB window) to 9 (64 MiB window, longest search), and XzCompressCheck also picks the check: XzCheckNone, XzCheckCrc32, XzCheckCrc64 or XzCheckSha256. Data that does not shrink is stored in uncompressed chunks, so the result is only the container overhead over the input. LzmaCompressStr, LzmaCompress, LzmaCompressBuf and LzmaCompressLevel write the older .lzma format, which has no check; archive.XzCompressFile and archive.LzmaCompressFile do it for a file.

compress-guide-xz-write.salam
/*

 *
 * Designed by Seyyed Ali Mohammadiyeh and the Salam Team
 * Born from a decade of language design experience (since 2018)
 *
 * Repository: https://github.com/SalamLang/Salam

 */

package main

import compress

func main:
    text := "the quick brown fox jumps over the lazy dog. " * 50
    mut ok := false

    xz := compress.XzCompressStr(text)
    back := compress.XzDecompressBuf(xz, ok)
    println ".xz:", text.len(), "to", xz.len, "bytes", ok, back.len
    println "magic:", compress.BufGet(xz, 0), compress.BufGet(xz, 1), compress.BufGet(xz, 2)

    fast := compress.XzCompressLevel(text as void*, text.len(), 0)
    best := compress.XzCompressLevel(text as void*, text.len(), 9)
    println "levels:", fast.len, best.len

    none := compress.XzCompressCheck(text as void*, text.len(), 6, compress.XzCheckNone)
    sha := compress.XzCompressCheck(text as void*, text.len(), 6, compress.XzCheckSha256)
    println "checks:", none.len, xz.len, sha.len
    small := compress.XzDecompressBuf(sha, ok)
    println "sha256 stream:", ok, small.len

    lz := compress.LzmaCompressStr(text)
    again := compress.LzmaDecompressBuf(lz, ok)
    println ".lzma:", lz.len, "bytes", ok, again.len
    lz9 := compress.LzmaCompressLevel(text as void*, text.len(), 9)
    println "level 9:", lz9.len
    buf := compress.LzmaCompressBuf(back)
    println "buffer:", compress.BufEquals(buf, lz)
    println "empty:", compress.XzCompressBuf(compress.NewByteBuf()).len
end

Inside 7z archives and xz blocks the compressed data comes without a container. LzmaRawDecompress and Lzma2RawDecompress read that form when you know the properties and the unpacked size, and BcjDecode and DeltaDecode undo the filters that sit in front of it. Dictionaries above 1 GiB (LzmaMaxDictSize) are refused.

Read and write .zst files

ZstdDecompress opens the .zst files that zstd, tar --zstd and 7z a -tzstd write: one frame or several in a row, any compression level, with or without a checksum, and frames written with long-distance matching or many threads. The decoder checks as it reads. A bad table, an offset that points before the data, a size that does not add up or a wrong XXH64 checksum gives ok false and an empty result; ZstdDecompressEx also says which of these it was, through the ZstdErr... codes. The whole result is kept in memory, so on data you did not make yourself call ZstdDecompressMax with the biggest size you accept.

ZstdCompressLevel writes a standard frame at a level from 1 to 22 (0 stores the data as it is), with the content size and a checksum in the header. The writer is deliberately simple: it finds repeats with a greedy or lazy search over a hash chain and codes them with the predefined tables, so the result is usually a quarter to a half larger than the zstd tool's at the same level. Every reader accepts it. Dictionaries are supported for reading only (ZstdDecompressDict); the writer does not use one.

Unpack a big file without holding it in memory

Everything above works on a whole buffer. For a file that may not fit in memory, NewFileBitReader reads a part of a file in pieces of 64 KiB and RawInflateToSink writes the unpacked data into a FileSink, which counts the bytes, keeps a CRC-32 and stops at a cap you choose. The archive package uses exactly these calls to unpack zip, gzip and RAR entries to disk. FileSeek, FileSize and FileReadAt use 64 bit offsets, and CRC32Update lets you checksum data that arrives in parts.

XzFileToSink

func XzFileToSink(fp: void*, off: i64, len: i64, sink &: FileSink, memcap: i64): int
Decodes an xz file of len bytes read from fp at off into a sink without holding it in memory. The index at the end of each stream is read first, so the unpacked size is known (and checked against the sink's cap) before anything is written; then every block is unpacked through a window the size of its dictionary, and its CRC-32, CRC-64 or SHA-256 is checked. Several streams in a row and stream padding are accepted. A file that uses a Delta or BCJ filter is read whole and decoded in memory instead (up to 2 GB). memcap limits the window (0 for none). The result is DecodeOk, DecodeCorrupt, DecodeTooBig or DecodeIo.
compress-XzFile.salam
import archive
import compress
import mem
import os
import str

func collect(p: void*, n: int, c: void*): bool:
    compress.BufPushBytes((c as compress.ByteBuf*)[0], p, n)
    ret true
end

func main:
    mut text := compress.NewByteBuf()
    repeat 5000 in i:
        line := "line " + str.FromInt((i * 7) as i64) + "\n"
        compress.BufPushBytes(text, line as void*, line.len())
    end
    mut packed := compress.XzCompress(text.data, text.len)
    archive.WriteBinaryFileBuf("xz.tmp", packed)

    fp := compress.FileOpenRead("xz.tmp")
    got := mem.AllocateZeroed(sizeof(compress.ByteBuf)) as compress.ByteBuf*
    got[0] = compress.NewByteBuf()
    mut sink := compress.SinkCallback(0 as i64, (p: void*, n: int, c: void*): ret collect(p, n, c) end, got as void*)
    st := compress.XzFileToSink(fp, 0 as i64, compress.FileSize(fp), sink, 0 as i64)
    println st == compress.DecodeOk, sink.written == (text.len as i64), compress.BufEquals(got[0], text)
    compress.FileClose(fp)

    fp2 := compress.FileOpenRead("xz.tmp")
    mut small := compress.SinkCallback(100 as i64, (p: void*, n: int, c: void*): ret collect(p, n, c) end, got as void*)
    println compress.XzFileToSink(fp2, 0 as i64, compress.FileSize(fp2), small, 0 as i64) == compress.DecodeTooBig
    compress.FileClose(fp2)
    compress.BufFree(got[0])
    mem.Free(got as void*)
    compress.BufFree(text)
    compress.BufFree(packed)
    os.Remove("xz.tmp")
end

ZstdFileToSink

func ZstdFileToSink(fp: void*, off: i64, len: i64, sink &: FileSink, memcap: i64): int
Decodes a zstd file of len bytes read from fp at off into a sink block by block, with a sliding window: memory is the frame's window size (from its header) plus a few hundred kilobytes, however big the output is. A frame whose window is over memcap (0 means 1 GiB) is refused with ZstdErrTooBig, and so is one whose declared size or output passes the sink's own cap. The content checksum is verified, several frames and skippable frames are accepted, and a frame that needs a dictionary gives ZstdErrDict. When the sink itself fails, sink.failed is set.
