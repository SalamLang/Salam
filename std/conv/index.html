conv

Converting numbers and booleans to text and back, including Persian digits.

import conv
On this page

  2. Adding up numbers in mixed digits
  3. Booleans and hex values from a settings file
  4. Choosing a float format
  5. Functions

Text arriving from a user, a file or the network is always a string; to do arithmetic with it you have to turn it into a number, and to show the result you turn it back into text. The conv package does both halves of that.

The parsing functions also understand Persian digits (۰۱۲۳۴۵۶۷۸۹) and Arabic ones (٠١٢٣٤٥٦٧٨٩), so a number typed on a Persian keyboard is read without any fuss. These functions never fail: they read from the start of the string for as long as it makes sense as a number and ignore the rest, and return zero when they find no digits at all.

fmt wraps the formatting half of this package with padding and templates; reach for conv when you need the parsing half, or one of the three float formats below. The string methods to_int and to_float do the same parsing as ParseInt and ParseFloat.

Things that catch people out:

  • A number that does not fit is not reported. ParseInt wraps around past the 64-bit range, and Atoi cuts the result to 32 bits, so Atoi("3000000000") is -1294967296. Use ParseInt for ids, sizes and timestamps.
  • ParseBool is case sensitive: True and YES are false.
  • A comma is not a decimal separator: ParseFloat("1,5") is 1.

Strict parsing of user input

Because ParseInt never fails, "12abc" quietly becomes 12 and an empty field becomes 0. That is handy for loose input, but a form usually has to reject such values. A simple strict check: normalise the digits, parse, format the number back with FormatInt and compare. If anything was dropped on the way, the two strings differ.

conv-guide-strict.salam
import conv
import str

func whole_number(text: str, ok &: bool): i64:
    clean := str.ToEnglishDigits(str.Trim(text))
    n := conv.ParseInt(clean)
    ok = clean != "" and conv.FormatInt(n) == str.TrimPrefix(clean, "+")
    ret n
end

func main:
    each typed in ["42", " ۱۴۰۳ ", "+7", "12abc", "", "-0015"]:
        mut ok := false
        n := whole_number(typed, ok)
        if ok:
            println "[" + typed + "]", "->", n
        else:
            println "[" + typed + "]", "is not a whole number"
        end
    end
end
Output[42] -> 42 [ ۱۴۰۳ ] -> 1403 [+7] -> 7 [12abc] is not a whole number [] is not a whole number [-0015] is not a whole number

str.ToEnglishDigits turns Persian and Arabic digits into ASCII ones first, so ۱۴۰۳ passes the comparison. This check also rejects leading zeros, as in -0015; if you want to allow them, strip the zeros before comparing. Report the problem to the user with the original text, not the parsed number.

Adding up numbers in mixed digits

Text pasted from different sources often mixes ASCII, Persian and Arabic digits, and writes the decimal point as . or as the Persian separator ٫. The parsing functions accept all of them, so no clean up is needed before the arithmetic.

conv-guide-sum.salam
import conv
import str

func main:
    line := "۱۲ 7 ٣٠ 4.5 ۰٫۵"
    parts := str.Fields(line)
    defer parts.free()
    mut whole := 0 as i64
    mut exact := 0.0
    each p in parts:
        whole += conv.ParseInt(p)
        exact += conv.ParseFloat(p)
    end
    println "numbers:", parts.len()
    println "sum of whole parts:", whole
    println "exact sum:", conv.FormatFloatShort(exact)
end
Outputnumbers: 5 sum of whole parts: 53 exact sum: 54

ParseInt stops at the decimal point and keeps only the whole part, which is why the two sums differ. Use ParseFloat whenever a value may have a fraction. FormatFloatShort prints the result without a trailing .0 or long tails of digits.

Booleans and hex values from a settings file

Settings files spell their switches in many ways. ParseBool accepts true, 1, yes and on, in lower case, with any spaces around them and treats everything else as false, so a missing or misspelled value turns a feature off rather than on. ParseHex reads colors, masks and ids written in base sixteen, in either case.

conv-guide-settings.salam
import conv
import str

func main:
    raw := HashMap {} as HashMap<str, str>
    defer raw.free()
    raw.put("debug", " yes ")
    raw.put("cache", "0")
    raw.put("accent", "#1E90FF")
    raw.put("limit", "۲۵۰")
    debug := conv.ParseBool(raw.get("debug"))
    cache := conv.ParseBool(raw.get("cache"))
    color := conv.ParseHex(str.TrimPrefix(raw.get("accent"), "#"))
    limit := conv.Atoi(raw.get("limit"))
    println "debug:", conv.FormatBool(debug), "cache:", conv.FormatBool(cache)
    println "red:", color >> 16, "green:", (color >> 8) & 255, "blue:", color & 255
    println "limit doubled:", limit * 2
    println "accent back to hex:", conv.FormatHex(color as u64)
end
Outputdebug: true cache: false red: 30 green: 144 blue: 255 limit doubled: 500 accent back to hex: 1e90ff

The prefix 0x is optional for ParseHex (the upper case 0X is not understood), and neither is #, so it is cut first with str.TrimPrefix. The shifts and masks then take the three color channels out of the single number.

Choosing a float format

A decimal number can be turned into text in three ways, and each one suits a different job. FormatFloat writes every digit needed to read back exactly the same number, which is what you want in a file another program will read. FormatFloatShort rounds to six significant digits, like %g in C, which is what a person expects to see. FormatFloatPrec rounds to a fixed number of places, for money and reports.

conv-guide-floats.salam
import conv

func main:
    price := 0.1 * 3.0
    println "FormatFloat:     ", conv.FormatFloat(price)
    println "FormatFloatShort:", conv.FormatFloatShort(price)
    println "FormatFloatPrec: ", conv.FormatFloatPrec(price, 2)
    back := conv.ParseFloat(conv.FormatFloat(price))
    println "round trip exact:", back == price
    short := conv.ParseFloat(conv.FormatFloatShort(price))
    println "short is exact:  ", short == price
    println conv.FormatFloatPrec(1.0 / 3.0, 4), conv.FormatFloatShort(1e21)
end
OutputFormatFloat: 0.30000000000000004 FormatFloatShort: 0.3 FormatFloatPrec: 0.30 round trip exact: true short is exact: false 0.3333 1e+21

The output shows the trade off: the short form of 0.1 * 3.0 reads as 0.3, but parsing that text gives a slightly different number. Save data with FormatFloat and show it with one of the other two.

ParseBool

func ParseBool(s: str): bool
Turns a string into a boolean. "true", "1", "yes" and "on", with any surrounding spaces, count as true, and anything else as false. The check is case sensitive, so "True" is false.
conv-ParseInt.salam
import conv

func main:
    println conv.ParseInt("  -۲۷ "), conv.ParseInt("-27"), conv.ParseInt("12abc"), conv.ParseInt("no digits")
    println conv.Atoi("+15")
    println conv.ParseHex("0xff"), conv.ParseHex("1A")
    println conv.ParseBool("yes"), conv.ParseBool(" true "), conv.ParseBool("maybe")
end
Output-27 -27 12 0 15 255 26 true true false

ParseInt

func ParseInt(s: str): i64
Reads a whole number from the start of a string. Leading spaces are ignored and a + or - sign is accepted. Persian, Arabic and English digits are all understood, and reading stops at the first character that is not a digit. There is no overflow check: a number past the 64-bit range wraps around.

The example for this item is shown with the ones above: conv-ParseInt.salam

Atoi

func Atoi(s: str): int
The same as ParseInt, but returns an int, which is 32 bits. Larger values are cut to their low 32 bits without warning.

The example for this item is shown with the ones above: conv-ParseInt.salam

ParseFloat

func ParseFloat(s: str): f64
Reads a decimal number from a string. Scientific notation such as 2.5e3, and Persian digits with the Persian decimal separator (۳٫۷۵), are both accepted. A comma is not read as a decimal point, and text with no number in it gives 0.
conv-ParseFloat.salam
import conv

func main:
    x := conv.ParseFloat("۳٫۷۵")
    println x * 2
    println conv.FormatFloat(0.1 + 0.2)
    println conv.FormatFloatShort(0.1 + 0.2)
    println conv.FormatFloatPrec(2.0 / 3.0, 3)
    nan := conv.ParseFloat("nan")
    println conv.IsNaNF(nan), conv.IsNaNF(x)
end
Output7.5 0.30000000000000004 0.3 0.667 true false

IsNaNF

func IsNaNF(x: f64): bool
Returns true when the number is "not a number" (NaN), for instance the result of parsing "nan". No comparison with == can detect this case, because NaN is not even equal to itself.

The example for this item is shown with the ones above: conv-ParseFloat.salam

FormatFloat

func FormatFloat(x: f64): str
Turns a decimal number into text with every digit needed to read exactly the same number back.

The example for this item is shown with the ones above: conv-ParseFloat.salam

FormatFloatShort

func FormatFloatShort(x: f64): str
Rounds to six significant digits and drops trailing zeros, like %g in C: 0.1 + 0.2 comes out as 0.3 and 3.14159265 as 3.14159. From a million up, and below 0.0001, it switches to an exponent, so 1234567.0 is 1.23457e+06.

The example for this item is shown with the ones above: conv-ParseFloat.salam

FormatFloatPrec

func FormatFloatPrec(x: f64, prec: int): str
Turns a decimal number into text with the number of decimal places you ask for, rounding halves away from zero. At most 15 places are written, and a value above about 9e14 falls back to FormatFloat.

The example for this item is shown with the ones above: conv-ParseFloat.salam

FormatHex

func FormatHex(x: u64): str
Writes the number in base sixteen in lower case, with no 0x prefix.

The example for this item is shown with the ones above: conv-FormatInt.salam

ParseHex

func ParseHex(s: str): i64
Reads a base sixteen number. The 0x prefix is optional and both upper and lower case digits are accepted, but the prefix itself must be a lower case 0x. Reading stops at the first character that is not a hex digit.

The example for this item is shown with the ones above: conv-ParseInt.salam
