data

Reading data for machine learning: CSV tables, batching samples, MNIST and images, and synthetic data.

This is an official package that does not ship with Salam. Add it to a project first: salam add data

This package readies data for training a model. LoadCsv reads a CSV file into a Table, decides for each column whether it holds integers, floats, categories or free text, and turns categories into numbers by itself; split_xy then divides the table into a feature matrix and a label. MatrixDataset hands the rows out in shuffled mini-batches, LoadMnist, LoadIdx and LoadImageFolder read image sets, and the Make... functions build synthetic data from a fixed seed, for trying algorithms out without a file.

Everything comes out as a matrix or a tensor, ready for ml and nn. To read a CSV file cell by cell as text, use encoding/csv; for spreadsheets, excel; for arrays saved by NumPy, npy.

What trips people up

  • Category codes depend on the file. Codes are given in order of first appearance, so red may be 0 in the training file and 2 in the test file, and a column with 25 distinct values may be a category in one file and text in another. Load all rows from one file and split them, as the test-set guide does, or map new files through the training table's cat_levels.
  • One bad cell changes a column's kind. A single 12,5 or n/a in a number column turns the whole column into categories or text. Check kinds after loading.
  • Empty cells are NaN in number columns but their own category, the empty string, in category columns.
  • Only commas. The separator is always ,; convert semicolon or tab files first, for example with encoding/csv.

The guide below follows the order of a small machine learning project: load a CSV file and see how its columns were read, split it into features and a label and fit a first model, train in mini-batches, hold back a test set, and read the MNIST file format.

How LoadCsv reads each column

LoadCsv looks at every value of a column and picks its kind on its own. All whole numbers give COL_INT, all numbers COL_FLOAT. Text with a limited number of different values (at most 20, or a tenth of the rows when that is more, and fewer than the rows) becomes COL_CAT: each value gets a code from 0 in order of first appearance and cat_levels gives the names back. Text where every row is different, such as a free comment, stays COL_STR. An empty cell in a number column is stored as NaN, which math.IsNaN detects; in a category column it becomes a level of its own.

data-columns.salam
import data
import matrix
import math

func kind_name(k: int): str:
    if k == data.COL_INT: ret "int" end
    if k == data.COL_FLOAT: ret "float" end
    if k == data.COL_CAT: ret "category" end
    ret "text"
end

func main:
    text := "id,city,age,income,comment\n1,Tehran,34,2.5,fast delivery\n2,Shiraz,,3.1,ok\n3,Tehran,51,4.0,late\n4,Tabriz,28,1.9,good price\n"
    mut t := data.LoadCsv(text, true)
    each j, name in t.names:
        println name, "->", kind_name(t.kinds.get(j))
    end
    levels := t.cat_levels("city")
    println "city levels:", levels
    city := t.col_index("city")
    age := t.col_index("age")
    repeat t.rows() in i:
        code := t.cells.at(i, city) as int
        mut shown := "missing"
        if math.IsNaN(t.cells.at(i, age)) == false: shown = "known" end
        println "row", i, "city code", code, "=", levels.get(code), "age", shown
    end
    mut m := t.to_matrix()
    println "to_matrix keeps", m.cols, "of", t.cols(), "columns"
    mut onehot := matrix.Zeros(t.rows(), levels.len())
    repeat t.rows() in i: onehot.set(i, t.cells.at(i, city) as int, 1.0) end
    println "one-hot row 3:", onehot.at(3, 0), onehot.at(3, 1), onehot.at(3, 2)
    matrix.Free(onehot)
    matrix.Free(m)
    t.free()
    ret 0
end
Outputid -> int city -> category age -> int income -> float comment -> text city levels: ["Tehran", "Shiraz", "Tabriz"] row 0 city code 0 = Tehran age known row 1 city code 1 = Shiraz age missing row 2 city code 0 = Tehran age known row 3 city code 2 = Tabriz age known to_matrix keeps 4 of 5 columns one-hot row 3: 0 0 1

to_matrix and split_xy leave COL_STR columns out, which is why five columns become four. A category is stored as its code, which suits decision trees; for a linear model or a neural network build one-hot columns from the code, as the last lines do.

From a CSV file to a first model

split_xy takes the name of the label column and fills two matrices: every other usable column as features, and the label as a one column matrix. It returns false when the label is missing or is plain text. That is exactly the shape matrix functions expect, so a least squares fit with matrix.LinearRegression is one more line. Its result has the intercept first, then one coefficient per feature.

data-regression.salam
import data
import matrix
import conv

func main:
    text := "area,rooms,price\n50,1,105\n70,2,147\n80,2,164\n100,3,208\n120,3,244\n150,4,305\n"
    mut t := data.LoadCsv(text, true)
    mut x := matrix.Matrix {}
    mut y := matrix.Matrix {}
    if t.split_xy("price", x, y) == false:
        println "no price column"
        ret 1
    end
    println "features:", x.rows, "x", x.cols, "label:", y.rows, "x", y.cols
    mut beta := matrix.LinearRegression(x, y)
    println "intercept:", conv.FormatFloatPrec(beta.at(0, 0), 2)
    println "per m2:", conv.FormatFloatPrec(beta.at(1, 0), 2)
    println "per room:", conv.FormatFloatPrec(beta.at(2, 0), 2)
    guess := beta.at(0, 0) + 90.0 * beta.at(1, 0) + 2.0 * beta.at(2, 0)
    println "90 m2 with 2 rooms:", conv.FormatFloatPrec(guess, 1)
    matrix.Free(beta)
    matrix.Free(x)
    matrix.Free(y)
    t.free()
    ret 0
end
Outputfeatures: 6 x 2 label: 6 x 1 intercept: 7.33 per m2: 1.81 per room: 6.44 90 m2 with 2 rooms: 183.2

Training in mini-batches

Gradient descent on a large data set looks at a few rows at a time. Wrap the features and labels in a MatrixDataset, ask it for batches(size, shuffle, seed), and call next until it returns false; each call replaces the two matrices you pass with the next batch. reset(epoch) starts a new pass and shuffles again with the seed plus the epoch, so every epoch sees a different order but a run can be repeated exactly. MakeRegression builds a test problem with known true coefficients, so you can see that training found them.

data-minibatch.salam
import data
import matrix
import conv

func main:
    mut y := matrix.Matrix {}
    mut coef := matrix.Matrix {}
    x := data.MakeRegression(200, 3, 0.05, 11, y, coef)
    mut set := data.MatrixDataset { x = x, y = y }
    mut w := matrix.Zeros(3, 1)
    mut it := set.batches(20, true, 7)
    mut batch_x := matrix.Matrix {}
    mut batch_y := matrix.Matrix {}
    repeat 5 in epoch:
        it.reset(epoch as i64)
        mut loss := 0.0
        until it.next(batch_x, batch_y):
            mut pred := matrix.MatMul(batch_x, w)
            mut diff := matrix.Sub(pred, batch_y)
            mut grad := matrix.TransposeMul(batch_x, diff)
            matrix.AddScaled(w, grad, -0.1 / (batch_x.rows as f64))
            loss += matrix.Dot(diff, diff)
            matrix.Free(pred)
            matrix.Free(diff)
            matrix.Free(grad)
        end
        println "epoch", epoch + 1, "batches", it.batches_per_epoch(), "loss", conv.FormatFloatPrec(loss / (set.len() as f64), 4)
    end
    repeat 3 in j:
        println "w" + j, "learned", conv.FormatFloatPrec(w.at(j, 0), 2), "true", conv.FormatFloatPrec(coef.at(j, 0), 2)
    end
    matrix.Free(batch_x)
    matrix.Free(batch_y)
    matrix.Free(w)
    matrix.Free(coef)
    it.free()
    set.free()
    ret 0
end
Outputepoch 1 batches 10 loss 0.5009 epoch 2 batches 10 loss 0.0808 epoch 3 batches 10 loss 0.0147 epoch 4 batches 10 loss 0.0041 epoch 5 batches 10 loss 0.0024 w0 learned -0.86 true -0.88 w1 learned -0.54 true -0.54 w2 learned -0.26 true -0.25

next frees the matrices it is given before it fills them, so pass the same two variables every time and free them once after the loop.

Keeping a test set aside

A model has to be judged on rows it never saw. The simplest split reuses the batch iterator: shuffle once with a fixed seed, take a first batch the size of the training set and a second batch with the rest. Here a nearest-centre classifier learns the centre of each of three clusters from MakeBlobs and is scored on the 30 held back points.

data-split.salam
import data
import matrix

func nearest(centers: matrix.Matrix, x: matrix.Matrix, i: int): int:
    mut best := 0
    mut best_d := -1.0
    repeat centers.rows in c:
        mut d := 0.0
        repeat x.cols in j:
            diff := x.at(i, j) - centers.at(c, j)
            d += diff * diff
        end
        if best_d < 0.0 or d < best_d:
            best = c
            best_d = d
        end
    end
    ret best
end

func main:
    mut y := matrix.Matrix {}
    x := data.MakeBlobs(120, 3, 2, 1.0, 5, y)
    mut set := data.MatrixDataset { x = x, y = y }
    mut it := set.batches(90, true, 1)
    mut train_x := matrix.Matrix {}
    mut train_y := matrix.Matrix {}
    mut test_x := matrix.Matrix {}
    mut test_y := matrix.Matrix {}
    it.next(train_x, train_y)
    it.next(test_x, test_y)
    println "train:", train_x.rows, "test:", test_x.rows
    mut centers := matrix.Zeros(3, 2)
    mut sizes := matrix.Zeros(3, 1)
    repeat train_x.rows in i:
        c := train_y.at(i, 0) as int
        repeat 2 in j: centers.set(c, j, centers.at(c, j) + train_x.at(i, j)) end
        sizes.set(c, 0, sizes.at(c, 0) + 1.0)
    end
    repeat 3 in c:
        repeat 2 in j: centers.set(c, j, centers.at(c, j) / sizes.at(c, 0)) end
    end
    mut right := 0
    repeat test_x.rows in i:
        if nearest(centers, test_x, i) == test_y.at(i, 0) as int: right += 1 end
    end
    println "correct on unseen points:", right, "of", test_x.rows
    each m in [train_x, train_y, test_x, test_y, centers, sizes]:
        mut t := m
        matrix.Free(t)
    end
    it.free()
    set.free()
    ret 0
end
Outputtrain: 90 test: 30 correct on unseen points: 25 of 30

Changing the seed gives another split and slightly different numbers. For a fair comparison of two models, use the same seed for both.

The MNIST file format

MNIST and many image sets that copy it use the IDX format: a magic number whose third byte is the element type and fourth the number of dimensions, the size of each dimension as a big-endian 32 bit number, then the raw bytes. LoadMnist reads an image file and a label file into a matrix with one image per row, pixels scaled from 0..255 to 0..1, and a one column label matrix. LoadIdx reads any IDX file as it is. The program writes three tiny 2x2 images itself so it runs without a download; for the real set, point the same call at train-images-idx3-ubyte and train-labels-idx1-ubyte.

data-mnist-format.salam
import data
import matrix
import compress
import archive
import encoding.binary
import conv

func write_idx(path: str, dims: Vector<int>, values: Vector<int>): bool:
    mut buf := compress.NewByteBuf()
    binary.WriteU8(buf, 0)
    binary.WriteU8(buf, 0)
    binary.WriteU8(buf, 8)
    binary.WriteU8(buf, dims.len())
    each d in dims: binary.WriteU32BE(buf, d) end
    each v in values: binary.WriteU8(buf, v) end
    ok := archive.WriteBinaryFileBuf(path, buf)
    compress.BufFree(buf)
    ret ok
end

func main:
    mut dims := Vector {} as Vector<int>
    dims.push(3)
    dims.push(2)
    dims.push(2)
    mut pixels := Vector {} as Vector<int>
    repeat 12 in i: pixels.push(i * 20) end
    write_idx("images.idx", dims, pixels)
    mut count := Vector {} as Vector<int>
    count.push(3)
    mut labels := Vector {} as Vector<int>
    labels.push(7)
    labels.push(2)
    labels.push(7)
    write_idx("labels.idx", count, labels)
    mut x := matrix.Matrix {}
    mut y := matrix.Matrix {}
    if data.LoadMnist("images.idx", "labels.idx", x, y) == false:
        println "could not load"
        ret 1
    end
    println "images:", x.rows, "pixels each:", x.cols, "labels:", y.rows
    repeat x.rows in i:
        println "label", y.at(i, 0), "pixels", conv.FormatFloatPrec(x.at(i, 0), 3), conv.FormatFloatPrec(x.at(i, 3), 3)
    end
    mut ok := false
    raw := data.LoadIdx("images.idx", ok)
    println "raw value of the last pixel:", raw.at(2, 3)
    println "without labels:", data.LoadMnist("images.idx", "missing.idx", x, y)
    matrix.Free(x)
    matrix.Free(y)
    ret 0
end
Outputimages: 3 pixels each: 4 labels: 3 label 7 pixels 0.000 0.235 label 2 pixels 0.314 0.549 label 7 pixels 0.627 0.863 raw value of the last pixel: 220 without labels: false

Both readers return false, or clear ok, when a file is missing or does not match, so check the result before you use the matrices.
