This is an official package that does not ship with Salam. Add it to a project first: salam add db.meilisearch

Meilisearch is a fast search engine with typo tolerance, filters, facets and AI powered hybrid search. This package talks to its HTTP API directly with net.http and covers all of it: indexes, documents in JSON, NDJSON or CSV, every search parameter, multi-search and federated search, facet search, similar documents, every index setting, tasks and batches, API keys and tenant tokens, webhooks, dynamic search rules and chat workspaces. This page starts with a tutorial; the full reference of every function and type comes after it.

Tutorial: a movie search in eleven steps

The steps below build one small movie catalogue and search it. Each step is a complete program, and the output under it is what it printed against a real Meilisearch 1.55. Run them in order, because each step uses the data the earlier ones left behind.

First start a server. With Docker that is one command; without it, download the meilisearch binary from the Meilisearch releases page and run it with the same key:

docker run -p 7700:7700 -e MEILI_MASTER_KEY=masterKey getmeili/meilisearch:v1.55.0

The programs assume http://127.0.0.1:7700 and the master key masterKey. A real deployment uses a long random master key and gives applications smaller keys, as step 9 shows.

1. Connect

New makes a client: a plain value with the address and the key, which threads can share. WithTimeout returns a copy that stops waiting after the given milliseconds; without it a request waits as long as the server takes. Every call that can fail takes an Error as its last argument. Ok tells you whether the call worked and ErrorString turns the error into one line.

meili-connect.salam
import db.meilisearch

func main:
    c := meilisearch.WithTimeout(meilisearch.New("http://127.0.0.1:7700", "masterKey"), 5000)
    if not meilisearch.IsHealthy(c):
        println "Meilisearch is not running at " + c.host
        ret 1
    end
    mut err := meilisearch.Error {}
    version := meilisearch.GetVersion(c, err)
    println "connected to Meilisearch " + version.pkg_version

    meilisearch.GetIndex(c, "no_such_index", err)
    if not meilisearch.Ok(err):
        println meilisearch.ErrorString(err)
    end
    ret 0
end
Outputconnected to Meilisearch 1.55.0 meilisearch 404 [index_not_found]: Index `no_such_index` not found.

The error carries everything Meilisearch sent: the HTTP status, the code to branch on (here index_not_found), the message and a link to its documentation. When the server cannot be reached at all, code is communication_error, or timeout when the time limit ran out.

2. Create an index and add documents

An index is a named collection of documents, each with a unique primary key. Documents can be Salam structs: AddDocumentsOf turns each one into JSON. AddDocuments takes JSON text instead, and AddDocumentsNdjson and AddDocumentsCsv take those formats.

meili-index.salam
import db.meilisearch

struct Movie:
    pub id: int = 0
    pub title: str = ""
    pub genre: str = ""
    pub year: int = 0
    pub overview: str = ""
end

func movie(id: int, title: str, genre: str, year: int, overview: str): Movie:
    ret Movie { id = id, title = title, genre = genre, year = year, overview = overview }
end

func main:
    c := meilisearch.New("http://127.0.0.1:7700", "masterKey")
    mut err := meilisearch.Error {}

    meilisearch.Wait(c, meilisearch.CreateIndex(c, "movies", "id", err), err)

    mut movies := Vector {} as Vector<Movie>
    movies.push(movie(1, "Heat", "Crime", 1995, "A detective hunts a crew of professional thieves in Los Angeles."))
    movies.push(movie(2, "Moana", "Family", 2016, "A girl sails across the ocean to save her island."))
    movies.push(movie(3, "Alien", "Horror", 1979, "The crew of a space freighter meets a deadly creature."))
    movies.push(movie(4, "Up", "Family", 2009, "An old man flies his house away with thousands of balloons."))
    movies.push(movie(5, "Arrival", "Drama", 2016, "A linguist learns to talk with visitors from another world."))
    movies.push(movie(6, "Dune", "Adventure", 2021, "A young noble fights for a desert planet."))
    movies.push(movie(7, "Interstellar", "Drama", 2014, "Explorers travel through a wormhole to find a new home."))
    movies.push(movie(8, "Coco", "Family", 2017, "A boy enters the land of the dead to find his family."))

    task := meilisearch.Wait(c, meilisearch.AddDocumentsOf(c, "movies", movies, "id", err), err)
    if not meilisearch.Ok(err):
        println meilisearch.ErrorString(err)
        ret 1
    end
    println "indexing: " + task.status
    stats := meilisearch.GetIndexStats(c, "movies", err)
    println "documents in movies: " + stats.number_of_documents
    ret 0
end
Outputindexing: succeeded documents in movies: 8

Meilisearch does not apply a change at once. A write returns a TaskInfo, a receipt with a task number, and the server applies the tasks in order in the background. Wait blocks until that task has finished, which is what you want when the next line depends on the change. A batch import does not need to wait after every call; wait once at the end, or not at all.

3. Search

Query searches for some words with every option at its default. The hits come back as JSON text, and HitsAs reads them into your own struct. A struct with fewer fields than the document is fine: the extra fields are ignored.

meili-search.salam
import db.meilisearch

struct Movie:
    pub id: int = 0
    pub title: str = ""
    pub year: int = 0
end

func main:
    c := meilisearch.New("http://127.0.0.1:7700", "masterKey")
    mut err := meilisearch.Error {}

    res := meilisearch.Query(c, "movies", "spcae", err)
    println "hits for \"" + res.query + "\": " + res.estimated_total_hits
    mut movies := Vector {} as Vector<Movie>
    if meilisearch.HitsAs(res, movies, err):
        each m in movies:
            println "  " + m.title + " (" + m.year + ")"
        end
    end
    ret 0
end
Outputhits for "spcae": 1 Alien (1979)

The query was misspelled on purpose: spcae still finds the movie whose overview says space, because Meilisearch tolerates typos out of the box.

4. Filter, sort and count facets

Filtering and sorting need to be switched on for the fields involved; that is a setting of the index, and UpdateSettings changes several settings in one task. A SearchRequest holds every search option and sends only the ones you set.

meili-filter.salam
import db.meilisearch

func main:
    c := meilisearch.New("http://127.0.0.1:7700", "masterKey")
    mut err := meilisearch.Error {}

    settings := `{"filterableAttributes": ["genre", "year"], "sortableAttributes": ["year"]}`
    meilisearch.Wait(c, meilisearch.UpdateSettings(c, "movies", settings, err), err)

    mut req := meilisearch.SearchRequest { filter = "genre = Family AND year > 2010" }
    req.sort.push("year:desc")
    req.facets.push("genre")
    req.attributes_to_retrieve.push("title")
    req.attributes_to_retrieve.push("year")
    res := meilisearch.Search(c, "movies", req, err)
    if not meilisearch.Ok(err):
        println meilisearch.ErrorString(err)
        ret 1
    end
    each hit in res.hits:
        println hit
    end

    all := meilisearch.Search(c, "movies", meilisearch.SearchRequest { facets = req.facets, limit = 0 }, err)
    println "genres: " + all.facet_distribution
    ret 0
end
Output{"title":"Coco","year":2017} {"title":"Moana","year":2016} genres: {"genre":{"Adventure":1,"Crime":1,"Drama":2,"Family":3,"Horror":1}}

facets asks how many hits have each value of a field, which is how a search page shows filter options with counts. attributes_to_retrieve keeps the hits small by returning only the fields you need.

5. Highlight, crop and page through results

For a results page you usually want the matched words marked and long text cut down around them. Meilisearch adds a _formatted copy of each hit with both done. page and hits_per_page give numbered pages with an exact total; offset and limit are the cheaper choice for endless scrolling.

meili-highlight.salam
import db.meilisearch
import encoding.json

func main:
    c := meilisearch.New("http://127.0.0.1:7700", "masterKey")
    mut err := meilisearch.Error {}

    mut req := meilisearch.SearchRequest { query = "crew", hits_per_page = 1, page = 1 }
    req.attributes_to_highlight.push("overview")
    req.highlight_pre_tag = "["
    req.highlight_post_tag = "]"
    req.attributes_to_crop.push("overview")
    req.crop_length = 6
    res := meilisearch.Search(c, "movies", req, err)
    println "page " + res.page + " of " + res.total_pages + ", " + res.total_hits + " hits"
    each hit in res.hits:
        formatted := json.Get(hit, "_formatted")
        println json.Get(hit, "title") + ": " + json.Get(formatted, "overview")
    end
    ret 0
end
Outputpage 1 of 2, 2 hits Alien: The [crew] of a space freighter…

6. Tune relevancy

Every index setting has its own Get, Update and Reset function. Synonyms make different words find each other, stop words are ignored in queries, and the searchable attributes choose which fields are searched and how much each one counts.

meili-settings.salam
import db.meilisearch

func main:
    c := meilisearch.New("http://127.0.0.1:7700", "masterKey")
    mut err := meilisearch.Error {}

    meilisearch.Wait(c, meilisearch.UpdateSynonyms(c, "movies", `{"cartoon": ["family"], "space": ["planet", "wormhole"]}`, err), err)
    mut stop := Vector {} as Vector<str>
    stop.push("the")
    stop.push("a")
    meilisearch.Wait(c, meilisearch.UpdateStopWords(c, "movies", stop, err), err)
    mut searchable := Vector {} as Vector<str>
    searchable.push("title")
    searchable.push("overview")
    meilisearch.Wait(c, meilisearch.UpdateSearchableAttributes(c, "movies", searchable, err), err)

    res := meilisearch.Query(c, "movies", "cartoon", err)
    println "hits for \"cartoon\", a synonym of family: " + res.estimated_total_hits
    space := meilisearch.Query(c, "movies", "space", err)
    println "hits for \"space\": " + space.estimated_total_hits
    println "searchable: " + meilisearch.GetSetting(c, "movies", "searchable-attributes", err)
    ret 0
end
Outputhits for "cartoon", a synonym of family: 1 hits for "space": 3 searchable: ["title","overview"]

Other settings follow the same pattern: UpdateRankingRules, UpdateTypoTolerance, UpdateDistinctAttribute, UpdatePagination, UpdateFaceting, UpdateDictionary and the rest in the reference below. GetSetting and UpdateSetting reach any setting by its route name, including ones newer than this package.

7. Search several indexes at once

MultiSearch sends several searches in one request and returns one result each. FederatedSearch merges them into a single ranked list, which suits one search box over different kinds of content. FacetSearch searches the values of one facet, for a filter box that completes as you type.

meili-multi.salam
import db.meilisearch

func main:
    c := meilisearch.New("http://127.0.0.1:7700", "masterKey")
    mut err := meilisearch.Error {}

    meilisearch.Wait(c, meilisearch.AddDocuments(c, "books", `[{"id": 1, "title": "Dune", "author": "Frank Herbert"}, {"id": 2, "title": "Coco and the Moon", "author": "A. Writer"}]`, "id", err), err)

    mut queries := Vector {} as Vector<meilisearch.MultiQuery>
    queries.push(meilisearch.MultiQuery { index_uid = "movies", request = meilisearch.SearchRequest { query = "dune" } })
    queries.push(meilisearch.MultiQuery { index_uid = "books", request = meilisearch.SearchRequest { query = "dune" } })
    each r in meilisearch.MultiSearch(c, queries, err):
        println r.index_uid + ": " + r.hits.len() + " hit"
    end

    merged := meilisearch.FederatedSearch(c, queries, meilisearch.Federation { limit = 5 }, err)
    println "federated: " + merged.hits.len() + " hits in one list"

    genres := meilisearch.FacetSearch(c, "movies", meilisearch.FacetSearchRequest { facet_name = "genre", facet_query = "fam" }, err)
    each g in genres.hits:
        println "genre " + g.value + ": " + g.count
    end
    ret 0
end
Outputmovies: 1 hit books: 1 hit federated: 2 hits in one list genre Family: 3

8. Vector and hybrid search

Meilisearch can also search by meaning. An embedder turns documents into vectors; it can call a model such as OpenAI or Hugging Face, or take vectors you computed yourself, which is what the userProvided source in this step does. A search with hybrid_embedder mixes keyword and vector results; a hybrid_semantic_ratio of 1 uses vectors only. SimilarDocuments finds the documents nearest to one you already have.

meili-vectors.salam
import db.meilisearch

func main:
    c := meilisearch.New("http://127.0.0.1:7700", "masterKey")
    mut err := meilisearch.Error {}

    meilisearch.Wait(c, meilisearch.CreateIndex(c, "movies_ai", "id", err), err)
    meilisearch.Wait(c, meilisearch.UpdateEmbedders(c, "movies_ai", `{"manual": {"source": "userProvided", "dimensions": 3}}`, err), err)
    if not meilisearch.Ok(err):
        println meilisearch.ErrorString(err)
        ret 1
    end
    docs := `[
        {"id": 2, "title": "Moana", "_vectors": {"manual": [0.9, 0.1, 0.0]}},
        {"id": 4, "title": "Up", "_vectors": {"manual": [0.8, 0.2, 0.1]}},
        {"id": 5, "title": "Arrival", "_vectors": {"manual": [0.1, 0.9, 0.3]}},
        {"id": 6, "title": "Dune", "_vectors": {"manual": [0.2, 0.8, 0.4]}},
        {"id": 7, "title": "Interstellar", "_vectors": {"manual": [0.1, 0.8, 0.5]}},
        {"id": 8, "title": "Coco", "_vectors": {"manual": [0.9, 0.0, 0.1]}}
    ]`
    task := meilisearch.Wait(c, meilisearch.AddDocuments(c, "movies_ai", docs, "", err), err)
    println "vectors stored: " + task.status

    mut req := meilisearch.SearchRequest { hybrid_embedder = "manual", hybrid_semantic_ratio = 1.0, limit = 2 }
    req.vector.push(0.15)
    req.vector.push(0.85)
    req.vector.push(0.4)
    req.attributes_to_retrieve.push("title")
    res := meilisearch.Search(c, "movies_ai", req, err)
    if not meilisearch.Ok(err):
        println meilisearch.ErrorString(err)
        ret 1
    end
    each hit in res.hits:
        println "close to the query: " + hit
    end

    mut like := meilisearch.SimilarRequest { id = "2", embedder = "manual", limit = 2 }
    like.attributes_to_retrieve.push("title")
    each hit in meilisearch.SimilarDocuments(c, "movies_ai", like, err).hits:
        println "like Moana: " + hit
    end
    ret 0
end
Outputvectors stored: succeeded close to the query: {"title":"Dune"} close to the query: {"title":"Arrival"} like Moana: {"title":"Coco"} like Moana: {"title":"Up"}

A userProvided embedder needs a vector in every document, so this step uses its own index. Add the embedder while the index is still empty and send the vectors in each document under _vectors.

9. API keys and tenant tokens

The master key can do everything, so applications should get smaller keys. CreateKey makes a key limited to some actions and indexes. A tenant token goes one step further: TenantToken signs, in your own program and without asking the server, a key that adds a filter to every search. Give each user their own token and they can search directly from the browser while seeing only their rows.

meili-keys.salam
import db.meilisearch
import time

func main:
    admin := meilisearch.New("http://127.0.0.1:7700", "masterKey")
    mut err := meilisearch.Error {}

    mut r := meilisearch.KeyRequest { name = "Shop front end", description = "Search the movies index only" }
    r.actions.push("search")
    r.indexes.push("movies")
    key := meilisearch.CreateKey(admin, r, err)
    println "new key " + key.name + " can: " + key.actions.get(0)

    rules := `{"movies": {"filter": "genre = Family"}}`
    token := meilisearch.TenantToken(key.uid, key.key, rules, time.Now() + 3600, err)
    kids := meilisearch.New("http://127.0.0.1:7700", token)
    res := meilisearch.Query(kids, "movies", "", err)
    println "the token sees " + res.estimated_total_hits + " family movies"

    meilisearch.Query(kids, "books", "", err)
    println "books with the token: " + err.code

    println "key deleted: " + meilisearch.DeleteKey(admin, key.uid, err)
    ret 0
end
Outputnew key Shop front end can: search the token sees 3 family movies books with the token: invalid_api_key key deleted: true

10. Update and delete documents

AddDocuments replaces a whole document with the same id; UpdateDocuments changes only the fields you send. Documents can be deleted one by one, by a list of ids, by a filter, or all at once.

meili-update.salam
import db.meilisearch

struct Movie:
    pub id: int = 0
    pub title: str = ""
    pub year: int = 0
end

func main:
    c := meilisearch.New("http://127.0.0.1:7700", "masterKey")
    mut err := meilisearch.Error {}

    meilisearch.Wait(c, meilisearch.UpdateDocuments(c, "movies", `[{"id": 6, "title": "Dune: Part One"}]`, "", err), err)
    mut dune := Movie {}
    if meilisearch.GetDocumentAs(c, "movies", "6", dune, err):
        println "renamed: " + dune.title + " (" + dune.year + ")"
    end

    meilisearch.Wait(c, meilisearch.DeleteDocument(c, "movies", "3", err), err)
    meilisearch.GetDocument(c, "movies", "3", Vector {} as Vector<str>, err)
    println "after delete: " + err.code

    removed := meilisearch.Wait(c, meilisearch.DeleteDocumentsByFilter(c, "movies", "year < 2000", err), err)
    println "delete by filter: " + removed.status + " " + removed.details
    println "left: " + meilisearch.GetIndexStats(c, "movies", err).number_of_documents
    ret 0
end
Outputrenamed: Dune: Part One (2021) after delete: document_not_found delete by filter: succeeded {"providedIds":0,"deletedDocuments":1,"originalFilter":"\"year < 2000\""} left: 6

11. Tasks and failures

A write that is accepted can still fail later, while the server applies it. The error then lives on the task, not on the call that queued it. WaitForTask copies it into your Error, so the usual check works. GetTasks lists past tasks with filters on index, type, status and dates.

meili-tasks.salam
import db.meilisearch

func main:
    c := meilisearch.New("http://127.0.0.1:7700", "masterKey")
    mut err := meilisearch.Error {}

    info := meilisearch.AddDocuments(c, "movies", `[{"title": "No id here"}]`, "", err)
    println "queued task " + info.task_uid + ": " + info.status
    task := meilisearch.WaitForTask(c, info.task_uid, 10000, 50, err)
    println "finished as " + task.status
    if not meilisearch.Ok(err):
        println "why: " + err.code
    end

    mut q := meilisearch.TaskQuery { limit = 3 }
    q.index_uids.push("movies")
    q.statuses.push(meilisearch.STATUS_SUCCEEDED)
    page := meilisearch.GetTasks(c, q, err)
    println "recent successful tasks on movies:"
    each t in page.results:
        println "  " + t.kind
    end
    ret 0
end
Outputqueued task 13: enqueued finished as failed why: missing_document_id recent successful tasks on movies: documentDeletion documentDeletion documentAdditionOrUpdate

More

The rest of the API works the same way; the reference below covers each function. A few pointers:

  • CreateWebhook registers a URL that Meilisearch calls when tasks finish, so you do not need to poll.
  • UpdateSearchRule pins or boosts chosen documents for chosen queries, such as a sale banner for sale; it needs the dynamicSearchRules experimental feature.
  • UpdateChatSettings and ChatCompletion answer questions in plain language from your indexes through an LLM; they need the chatCompletions feature.
  • WithMetadata tags every document write with a label that comes back on the task, to follow one import through the task list.
  • CreateDump, CreateSnapshot, GetStats, GetMetrics and SetStderrLogs are for running the server.
  • For a route with no function of its own, Request sends any method, path and JSON body.

The Salam repository has one runnable example for each part of the API, in English under tests/en/stdlib/meilisearch/examples and in Persian under tests/fa/stdlib/meilisearch/examples.
