debug

Tools for finding a bug: assertions, a hand-kept call stack, tracing and timing.

import debug
On this page
  1. Functions

The debug package holds a few simple tools for when the program is not doing the right thing. Assert checks a condition that should always hold. Enter and Exit build a call stack by hand, so you know where in the program you are. The timers show which part is slow.

Functions

Assert

func Assert(cond: bool, msg: str)
If the condition is false, prints the message and stops the program.
debug-Enter.salam
import debug

func child():
    debug.Enter("child")
    println debug.Depth()
    println debug.Stack()
    debug.Exit()
end

func main:
    debug.Enter("root")
    child()
    debug.Exit()
    println debug.Depth()
    debug.Assert(1 + 1 == 2, "the arithmetic holds")
    debug.AssertNotNil(debug.MemStats() as void*, "the memory statistics")
    debug.EnableTrace(true)
    println debug.TraceEnabled()
    debug.Trace("a trace message")
    debug.StartTimer("loop")
    mut total := 0
    repeat 1000 in i:
        total += i
    end
    println total, debug.StopTimer("loop") >= 0.0
    if total < 0:
        debug.Break()
    end
end
Output2 root > child 0 true [TRACE] a trace message 499500 true
