decimal

Exact decimal numbers for money and accounting, with none of the rounding error of floating point.

import decimal

In f64, 0.1 + 0.2 is not exactly 0.3. For science and graphics that tiny error does not matter; for money it does, because a lost cent in the accounts is not acceptable. The decimal package keeps a number as a bigint and a scale, the count of digits after the point, so 10.05 is 1005 with scale 2 and no error can creep in. Use it for prices, invoices, balances, tax and interest. Use f64 and math for measurements and statistics, and plain i64 cents when every amount has the same two places and never exceeds about 92 quadrillion.

Addition, subtraction and multiplication are always exact. The scale of a sum is the larger of the two, and the scale of a product is the two added together. Division may not terminate, as one third does not, so Div takes the number of places you want and a Rounding method. Seven methods are offered; accounting usually wants HalfEven, and customer-facing totals often HalfUp.

What people get wrong:

  • Letting the scale grow. Each Mul adds the scales together, so a balance multiplied by a rate every month carries more digits each time. Round to cents after every step that a statement shows.
  • Expecting school rounding from the formatters. ToStrFixed, FormatGrouped, Round and Percent round half to even, so 2.345 shows as 2.34. Call RoundHalfUp first when you want 2.35.
  • Dividing by zero. Div, DivRound and DivInt return 0 instead of stopping the program, so check the divisor yourself.
  • Copying with =. A Dec holds a bigint.Int, so b := a shares its digits; use Clone for an independent copy, and free each number once.

Why not f64?

Adding 0.1 ten times in f64 gives 0.9999999999999999, because 0.1 has no exact binary form. The same loop with Dec gives exactly 1.0. Build amounts from text with Parse or from whole cents with FromScaled; FromFloat works when you already have an f64, as long as you say how many places it should keep.

decimal-guide-float.salam
import decimal

func main:
    mut f := 0.0
    repeat 10:
        f = f + 0.1
    end
    println "f64 sum of ten 0.1:", f, f == 1.0

    mut d := decimal.Zero()
    tenth := decimal.FromScaled(1, 1)
    repeat 10:
        d = decimal.Add(d, tenth)
    end
    println "decimal sum of ten 0.1:", decimal.ToStr(d), decimal.Equals(d, decimal.FromInt(1))

    price := decimal.FromFloat(19.99, 2)
    println "19.99 from f64:", decimal.ToStr(price)
    println "times 3:", decimal.ToStr(decimal.MulInt(price, 3))
end
Outputf64 sum of ten 0.1: 0.9999999999999999 false decimal sum of ten 0.1: 1.0 true 19.99 from f64: 19.99 times 3: 59.97

An invoice with discount and tax

Prices usually come from a database or a form as text, so Parse is the natural start. MulInt multiplies by a quantity without any rounding, and Percent takes a percentage and rounds the result to the places you ask for, half to even. Print with ToStrFixed so that 12 shows as 12.00, or with FormatGrouped for thousands separators.

decimal-guide-invoice.salam
import decimal

struct Line:
    pub name: str = ""
    pub price: str = ""
    pub qty: int = 0
end

func main:
    mut lines := Vector {} as Vector<Line>
    defer lines.free()
    lines.push(Line { name = "Notebook", price = "4.75", qty = 3 })
    lines.push(Line { name = "Pen", price = "1.20", qty = 10 })
    lines.push(Line { name = "Backpack", price = "39.90", qty = 1 })

    mut subtotal := decimal.Zero()
    each l in lines:
        mut ok := false
        unit := decimal.Parse(l.price, ok)
        amount := decimal.MulInt(unit, l.qty as i64)
        println l.name, l.qty, "x", decimal.ToStrFixed(unit, 2), "=", decimal.ToStrFixed(amount, 2)
        subtotal = decimal.Add(subtotal, amount)
    end

    discount := decimal.Percent(subtotal, decimal.FromInt(5), 2)
    taxable := decimal.Sub(subtotal, discount)
    tax := decimal.Percent(taxable, decimal.FromScaled(95, 1), 2)
    total := decimal.Add(taxable, tax)
    println "subtotal", decimal.ToStrFixed(subtotal, 2)
    println "discount 5%", decimal.ToStrFixed(discount, 2)
    println "tax 9.5%", decimal.ToStrFixed(tax, 2)
    println "total", decimal.FormatGrouped(total, 2, ",", ".")
end
OutputNotebook 3 x 4.75 = 14.25 Pen 10 x 1.20 = 12.00 Backpack 1 x 39.90 = 39.90 subtotal 66.15 discount 5% 3.31 tax 9.5% 5.97 total 68.81

Round once per step that a real invoice shows (the discount, the tax), not at the very end only. Customers and tax offices check each printed line, so each line must already be in cents. The example does not free its numbers to stay short; a long-running server should Free each one, as the split example does.

Interest and the cost of rounding

A bank pays interest in whole cents every year, and those rounded cents then earn interest themselves. The example runs five years with yearly rounding and compares the result with the exact formula: the difference is one cent. Div and DivInt always ask for the number of places and a Rounding method, because a division such as one twelfth has no end.

decimal-guide-interest.salam
import decimal

func main:
    mut balance := decimal.FromInt(10000)
    rate := decimal.FromScaled(15, 3)
    one := decimal.FromInt(1)
    repeat 1 to 5 in year:
        interest := decimal.Round(decimal.Mul(balance, rate), 2)
        balance = decimal.Add(balance, interest)
        println "year", year, "interest", decimal.ToStrFixed(interest, 2), "balance", decimal.FormatGrouped(balance, 2, ",", ".")
    end

    factor := decimal.Pow(decimal.Add(one, rate), 5)
    exact := decimal.Mul(decimal.FromInt(10000), factor)
    println "without yearly rounding", decimal.ToStr(exact)
    println "rounded", decimal.ToStrFixed(decimal.Round(exact, 2), 2)

    monthly := decimal.DivInt(balance, 12, 2, decimal.Rounding.Down)
    println "a twelfth, rounded down", decimal.ToStrFixed(monthly, 2)
end
Outputyear 1 interest 150.00 balance 10,150.00 year 2 interest 152.25 balance 10,302.25 year 3 interest 154.53 balance 10,456.78 year 4 interest 156.85 balance 10,613.63 year 5 interest 159.20 balance 10,772.83 without yearly rounding 10772.840038843750000 rounded 10772.84 a twelfth, rounded down 897.73

Splitting a bill without losing a cent

Dividing 100.00 by 3 and rounding gives 33.33 three times, which adds up to 99.99. Split gives the missing cent to the first share, so the shares always add up to the original amount. Allocate does the same for shares in a ratio, such as profit split between partners.

decimal-guide-split.salam
import decimal

func show(label: str, parts: Vector<decimal.Dec>):
    mut line := label
    each p in parts:
        line = line + " " + decimal.ToStrFixed(p, 2)
    end
    total := decimal.Sum(parts)
    println line, "| total", decimal.ToStrFixed(total, 2)
end

func main:
    bill := decimal.FromScaled(10000, 2)
    mut naive := decimal.DivInt(bill, 3, 2, decimal.Rounding.HalfEven)
    println "100.00 / 3 rounded:", decimal.ToStrFixed(naive, 2), "x 3 =", decimal.ToStrFixed(decimal.MulInt(naive, 3), 2)
    naive.free()

    mut shares := decimal.Split(bill, 3)
    show("split in 3:", shares)
    decimal.FreeAll(shares)

    mut ratios := Vector {} as Vector<i64>
    defer ratios.free()
    ratios.push(50)
    ratios.push(30)
    ratios.push(20)
    profit := decimal.FromScaled(123457, 2)
    mut parts := decimal.Allocate(profit, ratios)
    show("50/30/20 of 1234.57:", parts)
    decimal.FreeAll(parts)
end
Output100.00 / 3 rounded: 33.33 x 3 = 99.99 split in 3: 33.34 33.33 33.33 | total 100.00 50/30/20 of 1234.57: 617.29 370.37 246.91 | total 1234.57

The leftover smallest units go to the first shares, one each, in both functions; Allocate does not look at which share lost the most to rounding. Split with fewer than one share, and Allocate with no ratios, a negative ratio or ratios that add up to zero, return an empty vector. Both return a new vector of numbers; free it with FreeAll, which releases every number and the vector.

What Parse accepts

Parse skips spaces around the number, accepts a sign, Persian digits, underscores between digits and scientific notation. It refuses a comma as the decimal separator and the Persian separator ٫: replace either with a dot before parsing if your users type them. ParseOr returns zero on failure, which suits optional fields but hides typing mistakes.

decimal-guide-parse.salam
import decimal

func main:
    inputs := ["1250.50", "  -3.75 ", "1_000_000", "۱۲۳.۴۵", "۱۲۳٫۴۵", "2.5e3", "12,50", "abc", ""]
    each s in inputs:
        mut ok := false
        d := decimal.Parse(s, ok)
        if ok:
            println "[" + s + "]", "->", decimal.ToStr(d), "scale", decimal.Scale(d)
        else:
            println "[" + s + "]", "-> not a number"
        end
    end
    println decimal.ToStr(decimal.ParseOr("oops"))
end
Output[1250.50] -> 1250.50 scale 2 [ -3.75 ] -> -3.75 scale 2 [1_000_000] -> 1000000 scale 0 [۱۲۳.۴۵] -> 123.45 scale 2 [۱۲۳٫۴۵] -> not a number [2.5e3] -> 2500 scale 0 [12,50] -> not a number [abc] -> not a number [] -> not a number 0

Scientific notation can lower the scale: 2.5e3 becomes 2500 with scale 0, and 1.50e1 becomes 15.0.

Rounding, growing scales and zero

The three surprises from the list above, in one program. The price is a typical half-cent case, the repeated Mul is a monthly rate applied four times, and the zero divisor is a team with no members.

decimal-guide-pitfalls.salam
import decimal

func main:
    mut ok := false
    price := decimal.Parse("2.345", ok)
    println "ToStrFixed rounds half to even:", decimal.ToStrFixed(price, 2)
    println "RoundHalfUp first:", decimal.ToStrFixed(decimal.RoundHalfUp(price, 2), 2)
    rate := decimal.Parse("1.075", ok)
    mut grown := decimal.Mul(price, rate)
    println "Mul adds the scales:", decimal.ToStr(grown), "scale", decimal.Scale(grown)
    repeat 3:
        grown = decimal.Mul(grown, rate)
    end
    println "three more times:", decimal.ToStr(grown), "scale", decimal.Scale(grown)
    println "rounded to cents:", decimal.ToStr(decimal.Round(grown, 2))
    staff := decimal.Zero()
    println "shared among zero staff:", decimal.ToStr(decimal.DivRound(price, staff, 2))
    if decimal.IsZero(staff):
        println "check the divisor before you divide"
    end
end
OutputToStrFixed rounds half to even: 2.34 RoundHalfUp first: 2.35 Mul adds the scales: 2.520875 scale 6 three more times: 3.131675134765625 scale 15 rounded to cents: 3.13 shared among zero staff: 0.00 check the divisor before you divide

FromFloat has a limit of its own: it multiplies the f64 by ten for each place and converts to i64, so a value times 10scale must stay below about 9.2 × 1018. For large amounts, parse text instead.

Rounding

enum Rounding
How to round when digits have to be dropped. The example below shows every method applied to −2.5.
NameTypeDescription
DownTowards zero: the extra digits are thrown away.
UpAway from zero.
FloorDownwards, towards negative infinity.
CeilUpwards, towards positive infinity.
HalfUpTo the nearest, with a half going away from zero. This is the rounding taught at school.
HalfDownTo the nearest, with a half going towards zero.
HalfEvenTo the nearest, with a half going to the even number, known as banker's rounding. Over many additions it keeps the rounding error at zero on average.
decimal-Round.salam
import decimal

func main:
    x := decimal.FromScaled(-25, 1)
    println decimal.ToStr(decimal.Round(x, 0)), decimal.ToStr(decimal.RoundHalfUp(x, 0)), decimal.ToStr(decimal.Truncate(x, 0))
    each mode in [decimal.Rounding.Down, decimal.Rounding.Up, decimal.Rounding.Floor, decimal.Rounding.Ceil, decimal.Rounding.HalfUp, decimal.Rounding.HalfDown, decimal.Rounding.HalfEven]:
        print decimal.ToStr(decimal.Rescale(x, 0, mode)), ""
    end
    println ""
    println decimal.ToStr(decimal.Trim(decimal.FromScaled(12500, 4)))
end
Output-2 -3 -2 -2 -3 -3 -2 -3 -2 -2 1.25

import decimal
import bigint

func main:

Split

func Split(total: Dec, n: int): Vector<Dec>
Divides an amount into n equal shares whose total is exactly the amount; the leftover smallest units go to the first shares, one each. Fewer than one share gives an empty vector.
decimal-Split.salam
import decimal

func main:
    total := decimal.FromScaled(10000, 2)
    mut shares := decimal.Split(total, 3)
    defer decimal.FreeAll(shares)
    each s in shares:
        print decimal.ToStr(s), ""
    end
    println ""
    println decimal.ToStr(decimal.Sum(shares))
    mut ratios := Vector {} as Vector<i64>
    defer ratios.free()
    ratios.push(1 as i64)
    ratios.push(2 as i64)
    mut parts := decimal.Allocate(total, ratios)
    defer decimal.FreeAll(parts)
    each p in parts:
        print decimal.ToStr(p), ""
    end
    println ""
end
Output33.34 33.33 33.33 100.00 33.34 66.66

Cmp

func Cmp(a: Dec, b: Dec): int
Compares two numbers whatever their scales; 1.50 and 1.5 are equal.
decimal-Cmp.salam
import decimal

func main:
    a := decimal.FromScaled(150, 2)
    b := decimal.FromScaled(15, 1)
    println decimal.Cmp(a, b), decimal.Equals(a, b)
    println decimal.Less(a, decimal.FromInt(2)), decimal.Greater(a, decimal.FromInt(2))
    println decimal.ToStr(decimal.Min(a, decimal.FromInt(1))), decimal.ToStr(decimal.Max(a, decimal.FromInt(1)))
end
Output0 true true false 1 1.50
