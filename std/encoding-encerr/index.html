encoding/encerr

The shared error of the format readers: a kind, a message and a position in the text.

import encoding.encerr
On this page
  1. Types
  2. Constants and variables
  3. Functions

The functions that read JSON, YAML, env files and MessagePack report their errors in an EncodingError. Build one with NoError, pass it to the function, and then check IsError.

Types

EncodingError

struct EncodingError
An error from reading or writing a format.
NameTypeDescription
kindintThe kind of error; one of the Kind constants.
messagestr = ""The error message, in English.
positionint = -1Where the error is in the text, in bytes, or -1 when it is not known.
encoding-encerr-Error.salam
import encoding.encerr
import encoding.json

func main:
    mut e := encerr.NoError()
    println encerr.IsError(e), e.kind == encerr.KindNone
    _ := json.Decode(`{"a": }`, e)
    println encerr.IsError(e), e.kind, e.position, e.message
    custom := encerr.NewError(encerr.KindCustom, "a negative value is not allowed", 12)
    println custom.kind, custom.message, custom.position
    println encerr.ErrUnexpectedEOF(40).kind == encerr.KindUnexpectedEOF
    println encerr.ErrUnexpectedToken("expected ':'", 3).kind == encerr.KindUnexpectedToken
    println encerr.ErrTypeMismatch("a number", 5).message
    println encerr.KindInvalidUTF8, encerr.KindInvalidNumber, encerr.KindDepthExceeded, encerr.KindTypeMismatch, encerr.KindKeyNotFound, encerr.KindTrailingData
end
Outputfalse true true 2 6 invalid value 99 a negative value is not allowed 12 true true expected a number 3 4 5 6 7 8
