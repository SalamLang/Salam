encoding/query

Reading and building the query string of a web address, such as q=hello&page=2.

import encoding.query
On this page
  1. Types
  2. Functions

The query string is the part after the ? in a web address. One key may appear several times, as in tag=a&tag=b, so a QueryMap keeps a list of values for each key, and keeps the keys in order.

Functions such as Get and Has work on the string directly, which suits reading something once.

Types

QueryOptions

struct QueryOptions
The encoding options.
NameTypeDescription
space_as_plusbool = trueWrite a space as +; true by default. When false, %20 is written.
encoding-query-Query.salam
import encoding.query

func main:
    text := "q=hello&page=2&tag=a&tag=b&empty="
    println query.Get(text, "q"), query.Get(text, "page"), query.Has(text, "empty"), query.Has(text, "x")
    println query.GetAll(text, "tag")
    mut m := query.Decode(text)
    println query.Size(m), query.Keys(m)
    query.Add(m, "tag", "c")
    query.Set(m, "page", "3")
    println query.Remove(m, "empty")
    println query.Encode(m)
    mut keep := Vector {} as Vector<str>
    keep.push("q")
    query.Retain(m, keep)
    println query.Encode(m)
    opts := query.QueryOptions {}
    println query.EncodeWith(query.DecodeWith("b=2&a=1", opts), opts)
    empty := query.NewQueryMap()
    println query.Size(empty)
end
Outputhello 2 true false ["a", "b"] 4 ["q", "page", "tag", "empty"] true q=hello&page=3&tag=a&tag=b&tag=c q=hello b=2&a=1 0
