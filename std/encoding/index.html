Standard library · Encoding and data

encoding

Turning text and data into Base64, hexadecimal and URL encoding.

import encoding
On this page

  2. Guide: strict or lenient Base64
  3. Guide: seeing the bytes with hex
  4. Guide: putting text into a URL
  5. Which encoding for which job
  6. Functions

This package holds the common ways of writing bytes as plain text: Base64 for fitting binary data into JSON or email, hexadecimal for showing bytes, and URL encoding for putting text or special characters into a web address.

The larger formats, such as JSON, YAML and XML, have sub-packages of their own, listed in this same group.

Every function takes and returns str, except the two ...Bytes forms, which work on a pointer and a length for binary data. Neighbouring packages: encoding/binary for numbers packed into bytes, crypto for hashes that you then show in hex, and jwt for tokens, which use the URL-safe Base64 alphabet that this package does not have.

The things people get wrong:

  • Decoding binary into a str. A str ends at the first zero byte, so Base64Decode and HexDecode cut binary data short; use Base64DecodeBytes into a buffer.
  • Expecting HexDecode to report bad input. It stops at the first pair that is not hex and returns what it decoded so far, and an odd last digit is dropped. Check the length and the characters first when the text comes from outside.
  • Feeding it URL-safe Base64 (- and _ instead of + and /, often without padding). The lenient decoder skips those characters and returns damaged bytes; the strict one refuses.
  • URLEncode writes a space as %20, while URLDecode reads both %20 and + as a space.

Guide: an HTTP Basic login header

HTTP Basic authentication sends user:password in Base64 after the word Basic. Base64 is not encryption, anyone can decode it, so this only belongs on HTTPS. Building the header is one call; reading it on the server side means decoding with Base64DecodeStrict and splitting at the first colon, since the password itself may contain more colons.

encoding-guide-basic-auth.salam
import encoding

func basic_header(user: str, password: str): str:
    ret "Basic " + encoding.Base64Encode(user + ":" + password)
end

func read_header(header: str, user &: str, password &: str): bool:
    if header.find("Basic ") != 0:
        ret false
    end
    mut ok := false
    pair := encoding.Base64DecodeStrict(header.substr(6, header.len() - 6), ok)
    colon := pair.find(":")
    if not ok or colon < 0:
        ret false
    end
    user = pair.substr(0, colon)
    password = pair.substr(colon + 1, pair.len() - colon - 1)
    ret true
end

func main:
    h := basic_header("sara", "p@ss:2026")
    println "Authorization:", h

    mut user := ""
    mut password := ""
    if read_header(h, user, password):
        println "user:", user
        println "password:", password
    end
    println "bad header accepted:", read_header("Basic !!not-base64!!", user, password)
end
OutputAuthorization: Basic c2FyYTpwQHNzOjIwMjY= user: sara password: p@ss:2026 bad header accepted: false

The strict decoder reports through its ok argument whether the text was valid Base64, so a garbled header is refused instead of being turned into a random user name.

Guide: strict or lenient Base64

Base64Decode never fails: it skips characters it does not know and accepts missing padding. That is handy for text you produced yourself. For anything that comes from outside, use Base64DecodeStrict, which accepts only padded standard Base64 and tells you when the input is broken.

encoding-guide-strict.salam
import encoding

func check(label: str, s: str):
    mut ok := false
    text := encoding.Base64DecodeStrict(s, ok)
    if ok:
        println label, "ok:", text
    else:
        println label, "rejected"
    end
end

func main:
    check("padded   ", "U2FsYW0=")
    check("unpadded ", "U2FsYW0")
    check("typo     ", "U2Fs*W0=")
    check("wrapped  ", "U2Fs\nYW0=")
    check("persian  ", encoding.Base64Encode("سلام"))
    println "lenient on the typo: [" + encoding.Base64Decode("U2Fs*W0=") + "]"
    println "lenient unpadded: [" + encoding.Base64Decode("U2FsYW0") + "]"
end
Outputpadded ok: Salam unpadded rejected typo rejected wrapped ok: Salam persian ok: سلام lenient on the typo: [Sal[] lenient unpadded: [Salam]

Line breaks are allowed in both, because MIME and PEM files wrap Base64 at 76 or 64 characters. A typo is where the two differ: the strict form says no, the lenient form quietly returns damaged bytes. For binary data use Base64EncodeBytes and Base64DecodeBytes, which work on a pointer and a length, because a str stops at the first zero byte.

Guide: seeing the bytes with hex

Hexadecimal writes each byte as two digits, which makes it the easiest way to see what a string really holds. Persian letters take two bytes each in UTF-8, so len of a Persian word counts bytes, not letters. Hex is also the usual form for hashes, keys and colours.

encoding-guide-hex.salam
import encoding

func main:
    words := ["A", "é", "س", "سلام"]
    each w in words:
        println w, "is", w.len(), "bytes:", encoding.HexEncode(w)
    end

    stored := "d8b3d984d8a7d985"
    println "decoded:", encoding.HexDecode(stored)
    println "upper case works too:", encoding.HexDecode("D8B3D984D8A7D985")
end
OutputA is 1 bytes: 41 é is 2 bytes: c3a9 س is 2 bytes: d8b3 سلام is 8 bytes: d8b3d984d8a7d985 decoded: سلام upper case works too: سلام

HexEncode writes lower case; HexDecode reads both cases.

Guide: putting text into a URL

A query value cannot contain spaces, &, = or non-ASCII letters as they are. URLEncode escapes everything except letters, digits and - _ . ~, so the result is safe anywhere in a URL. URLDecode undoes it and also reads + as a space, the way HTML forms send it.

encoding-guide-url.salam
import encoding

func link(base: str, q: str, city: str): str:
    ret base + "?q=" + encoding.URLEncode(q) + "&city=" + encoding.URLEncode(city)
end

func main:
    url := link("https://example.com/search", "coffee & cake", "تهران")
    println url

    part := "coffee%20%26%20cake"
    println "q is", encoding.URLDecode(part)
    println "plus means space:", encoding.URLDecode("tea+time")
    println "round trip:", encoding.URLDecode(encoding.URLEncode("a/b?c=d")) == "a/b?c=d"
end
Outputhttps://example.com/search?q=coffee%20%26%20cake&city=%D8%AA%D9%87%D8%B1%D8%A7%D9%86 q is coffee & cake plus means space: tea time round trip: true

Encode each value on its own and join them with &, as link does: encoding the whole URL at once would also escape the ? and & that hold it together. For whole query strings with repeated keys, encoding/query does the bookkeeping, and encoding/url parses and rebuilds complete URLs.

Which encoding for which job

JobUse
Binary data inside JSON, email or a headerBase64Encode, Base64EncodeBytes
Reading Base64 from a client or a fileBase64DecodeStrict, Base64DecodeBytes
Hashes, keys, debugging outputHexEncode, HexDecode
One value in a URL path or queryURLEncode, URLDecode

Base64Encode

func Base64Encode(data: str): str
Turns text into standard Base64, padded with =.
encoding-Base64.salam
import encoding
import mem

func main:
    e := encoding.Base64Encode("hello world")
    println e
    println encoding.Base64Decode(e)
    mut ok := false
    println "[" + encoding.Base64DecodeStrict("***", ok) + "]", ok
    println encoding.Base64DecodeStrict("YWJj", ok), ok
    b := mem.Allocate(3 as u64)
    mem.Set(b, 255, 3 as u64)
    println encoding.Base64EncodeBytes(b, 3)
    out := mem.Allocate(8 as u64)
    println encoding.Base64DecodeBytes("AAEC", out, 8, ok), ok
    mem.Free(b)
    mem.Free(out)
end
OutputaGVsbG8gd29ybGQ= hello world [] false abc true //// 3 true

HexEncode

func HexEncode(data: str): str
Writes each byte of the text as two lower case hexadecimal digits.

import encoding

func main:
    h := encoding.HexEncode("Hi!")
    println h, encoding.HexDecode(h)
    println encoding.HexVal("f"), encoding.HexVal("A"), encoding.HexVal("z")
    u := encoding.URLEncode("name=Ali & age=30")
    println u
    println encoding.URLDecode(u)
end
Output486921 Hi! 15 10 -1 name%3DAli%20%26%20age%3D30 name=Ali & age=30

HexVal

func HexVal(c: str): int
The value of the first character as a hexadecimal digit, or -1 when it is not one.

HexDecode

func HexDecode(s: str): str
Turns a hexadecimal string back into bytes, reading upper and lower case. It stops at the first invalid pair and drops an odd last digit, without an error.

The example for this item is shown with the ones above: encoding-Hex.salam

URLEncode

func URLEncode(s: str): str
Percent-encodes text for a web address, byte by byte with upper case hex; letters, digits and -_.~ are left as they are, and a space becomes %20.

The example for this item is shown with the ones above: encoding-Hex.salam

URLDecode

func URLDecode(s: str): str
Undoes percent encoding and turns + into a space. A % not followed by two hex digits is kept as it is.

The example for this item is shown with the ones above: encoding-Hex.salam

Base64DecodeStrict

func Base64DecodeStrict(s: str, ok &: bool): str
Like Base64Decode, but only padded standard Base64 is accepted; any other character, misplaced = or wrong length makes ok false and returns an empty string. Whitespace is still allowed.

The example for this item is shown with the ones above: encoding-Base64.salam

Base64DecodeBytes

func Base64DecodeBytes(s: str, out: void*, cap: int, ok &: bool): int
Decodes strict Base64 into the buffer out, of capacity cap, and returns how many bytes it wrote. Bad input, or more bytes than cap, makes ok false and returns 0.

The example for this item is shown with the ones above: encoding-Base64.salam
