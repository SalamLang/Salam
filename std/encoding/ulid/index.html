encoding.ulid

Sortable unique identifiers: ULID text and binary forms, a thread safe monotonic generator, and range bounds for queries.

import encoding.ulid

A ULID is a 128 bit identifier made of a 48 bit timestamp in milliseconds and 80 random bits, written as 26 characters of Crockford base32. It is the sortable alternative to a random UUID: the text sorts in the order the ids were made, so a database index stays compact and a range of time is a range of ids. This package follows the ULID specification and is written in Salam.

The text uses the digits and the letters without I, L, O and U. The largest id is 7ZZZZZZZZZZZZZZZZZZZZZZZZZ, because 130 bits are used to hold 128. Parsing accepts lowercase, reads I and L as 1 and O as 0, and refuses U and anything above that largest id.

PieceWhat it is
ULIDThe value: time plus two 40 bit halves of the randomness. Compare with Compare, Equal and Less.
New, NewString, NewBatchIds from the default generator. Strictly increasing in one process, safe from any number of threads.
GeneratorThe monotonic generator of the specification, one lock around the last id. NewGeneratorWith takes your clock and entropy.
Parse, StringText in and out. Bytes and FromBytes give the 16 bytes, also the bytes of a UUID.
FromPartsA time and 10 given bytes: no randomness, for exact tests.
MinAt, MaxAtThe first and the last id of a millisecond, the bounds of a range query.

Make, print and read back

New gives the next id of the default generator and String writes the 26 characters. NewAt makes an id for a time you choose. Every id is a value: copy it, compare it, keep it in a struct.

encoding-ulid-guide-basics.salam
import encoding.ulid

func main:
    id := ulid.New()
    text := ulid.String(id)
    println "length:", text.Len()
    back := ulid.Parse(text)
    println "round trip:", back.ok and ulid.Equal(back.id, id)
    println "close to now:", ulid.Time(id) - ulid.Now() < 5000
    stamp := ulid.NewAt(1469918176385)
    println ulid.String(stamp.id).Len(), ulid.Time(stamp.id)
end
Outputlength: 26 round trip: true close to now: true 26 1469918176385

Parsing and the rules of the text

Parse follows the specification: lowercase and the aliases I, L and O are accepted, U is not, and the first character may not be above 7 because the value would not fit in 128 bits. ParseStrict wants exactly what String writes. Errors are codes, with ErrorText for a message.

encoding-ulid-guide-parse.salam
import encoding.ulid

func show(text: str):
    r := ulid.Parse(text)
    if r.ok:
        println text, "->", ulid.Time(r.id), ulid.String(r.id)
    else:
        println text, "->", ulid.ErrorText(r.err)
    end
end

func main:
    show("01ARYZ6S41TSV4RRFFQ69G5FAV")
    show("01aryz6s41tsv4rrffq69g5fav")
    show("O1ARYZ6S41TSV4RRFFQ69G5FAV")
    show("7ZZZZZZZZZZZZZZZZZZZZZZZZZ")
    show("80000000000000000000000000")
    show("01ARYZ6S41TSV4RRFFQ69G5FAU")
    show("01ARYZ6S41")
    println ulid.ParseStrict("01aryz6s41tsv4rrffq69g5fav").ok
    println ulid.ParseStrict("01ARYZ6S41TSV4RRFFQ69G5FAV").ok
end

Order and range queries

Text order is time order, so ids sort by a plain string sort. To select the ids of a time window ask for everything between MinAt(start) and MaxAt(end); in SQL that is a BETWEEN on the id column.

encoding-ulid-guide-order.salam
import encoding.ulid

func main:
    mut ids := Vector {} as Vector<ulid.ULID>
    defer ids.Free()
    mut mark := 1700000000000 as i64
    repeat 4:
        ids.Push(ulid.MinAt(mark))
        mark += 1500
    end
    repeat ids.Len() in i:
        println ulid.String(ids.Get(i))
    end

    low := ulid.MinAt(1700000001000)
    high := ulid.MaxAt(1700000003000)
    println "range:", ulid.String(low), ulid.String(high)
    repeat ids.Len() in i:
        inside := ulid.Compare(ids.Get(i), low) >= 0 and ulid.Compare(ids.Get(i), high) <= 0
        println i, inside
    end
end
Output01HF7YAT000000000000000000 01HF7YAVEW0000000000000000 01HF7YAWXR0000000000000000 01HF7YAYCM0000000000000000 range: 01HF7YATZ80000000000000000 01HF7YAWXRZZZZZZZZZZZZZZZZ 0 false 1 true 2 true 3 false

The monotonic generator

Two ids made in the same millisecond must still sort in the order they were made. A Generator does what the specification says: in a new millisecond it draws fresh randomness, in the same one it adds 1 to the last random part, and when the clock moves back it keeps the last timestamp. If the 80 bits ever overflow, the timestamp moves one millisecond ahead instead of failing. The example uses a fake clock and a fixed entropy function so every character is known.

encoding-ulid-guide-monotonic.salam
import encoding.ulid

mut now_ms := 1000 as i64
mut chunk := 7 as i64

func clock(): i64:
    ret now_ms
end

func source(): i64:
    ret chunk
end

func main:
    g := ulid.NewGeneratorWith((): ret clock() end, (): ret source() end)
    defer ulid.Free(g)
    repeat 3:
        println ulid.String(ulid.Next(g).id)
    end
    now_ms = 1001
    chunk = 9
    println ulid.String(ulid.Next(g).id)
    now_ms = 900
    last := ulid.Next(g)
    println "clock went back:", ulid.Time(last.id), ulid.String(last.id)
    println ulid.String(ulid.Increment(last.id).id)
end
Output00000000Z80000000700000007 00000000Z80000000700000008 00000000Z80000000700000009 00000000Z90000000900000009 clock went back: 1001 00000000Z9000000090000000A 00000000Z9000000090000000B

Many threads

The default generator and every Generator guard their state with a mutex, so threads share one without duplicates and without going out of order: every thread sees its own ids increase, and all ids together are distinct. NewBatch takes the lock once for n ids. The cost is one lock and one clock read per id.

encoding-ulid-guide-threads.salam
import encoding.ulid
import pool
import mem

const WORKERS := 8
const EACH := 500

func main:
    out := mem.AllocateZeroed((WORKERS * EACH * 3 * 8) as u64) as i64*
    shared := ulid.Default()
    pool.ParallelFor(WORKERS as i64, 4 as i64, (task: i64): repeat EACH in k: id := ulid.New() slot := ((task * EACH + k) * 3) as int out[slot] = id.time out[slot + 1] = id.hi out[slot + 2] = id.lo end end)
    mut seen := HashMap {} as HashMap<str, bool>
    defer seen.Free()
    repeat WORKERS * EACH in n:
        id := ulid.ULID { time = out[n * 3], hi = out[n * 3 + 1], lo = out[n * 3 + 2] }
        seen.Put(ulid.String(id), true)
    end
    println "ids:", WORKERS * EACH, "distinct:", seen.Size()
    println ulid.Last(shared).ok
    mem.Free(out as void*)
end
Outputids: 4000 distinct: 4000 true

When the random source fails

The built in source reads the operating system random generator through crypto.RandomBytes, which stops the program if the system cannot give random bytes: a weak id is never made. A source of your own, passed to NewGeneratorWith, can fail politely by returning a negative number. Next then returns ERR_ENTROPY and leaves the generator untouched, so the next call can succeed.

encoding-ulid-guide-entropy.salam
import encoding.ulid

mut failing := true

func clock(): i64:
    ret 5000
end

func source(): i64:
    if failing:
        ret -1
    end
    ret 123456
end

func main:
    g := ulid.NewGeneratorWith((): ret clock() end, (): ret source() end)
    defer ulid.Free(g)
    r := ulid.Next(g)
    println r.ok, r.err == ulid.ERR_ENTROPY, ulid.ErrorText(r.err)
    println "state untouched:", ulid.Last(g).ok
    failing = false
    ok := ulid.Next(g)
    println ok.ok, ulid.String(ok.id)
end
Outputfalse true the entropy source failed state untouched: false true 00000004W800003RJ000003RJ0

Bytes, UUIDs and fixed ids

Bytes gives 16 bytes, big endian, the same size as a UUID, and FromBytes reads them back; the package does not depend on a UUID type, only on the bytes. FromParts builds an id from a time and 10 bytes you pick, which is how tests get exact answers. Free the byte vectors.

encoding-ulid-guide-bytes.salam
import encoding.ulid
import str

func hex(data: Vector<u8>): str:
    digits := "0123456789abcdef"
    mut out := ""
    repeat data.Len() in i:
        code := data.Get(i) as int
        out = out + str.Substr(digits, code / 16, 1) + str.Substr(digits, code % 16, 1)
    end
    ret out
end

func main:
    r := ulid.Parse("01ARYZ6S41TSV4RRFFQ69G5FAV")
    raw := ulid.ToUUIDBytes(r.id)
    defer raw.Free()
    println raw.Len(), hex(raw)
    back := ulid.FromUUIDBytes(raw)
    println back.ok, ulid.String(back.id)

    mut seed := Vector {} as Vector<u8>
    defer seed.Free()
    repeat 10 in i:
        seed.Push((i * 3) as u8)
    end
    made := ulid.FromParts(1469918176385, seed)
    println ulid.String(made.id)
    part := ulid.Entropy(made.id)
    defer part.Free()
    println hex(part)
end
Output16 01563df36481d6764c61efb99302bd5b true 01ARYZ6S41TSV4RRFFQ69G5FAV 01ARYZ6S41001GC28C1W91A60V 000306090c0f1215181b

What people get wrong:

  • Expecting NewAt to be ordered inside one millisecond. It keeps no state; use a Generator.
  • Treating the time as secret. The first 10 characters are the creation time, readable by anyone who sees the id.
  • Comparing text with lowercase or aliases without Parse: 01arz and 01ARZ are the same id but different strings.
  • Forgetting to Free a generator or to free the vectors of Bytes, Entropy and Batch.
  • Comparing ids made by different generators or machines for strict order: clocks differ, so only ids of one generator are strictly ordered.

Generator

struct Generator
A monotonic generator. It owns a lock and its last id, so the copies of one Generator share state and any number of threads may call it. Release it with Free.
NameTypeDescription
statei64*The shared last timestamp and random parts, behind the lock.
musync.MutexThe lock that guards the state.
clockfunc(): i64The function that returns the current time in milliseconds.
entropyfunc(): i64The function that returns 40 random bits, or a negative number when it fails.

import encoding.ulid

mut tick := 100 as i64

func clock(): i64:
    ret tick
end

func source(): i64:

Next

func Next(g: Generator): Result
The next id of a generator. In a new millisecond the random part is fresh; in the same millisecond, or when the clock went back, the previous random part grows by one. If the 80 bits run out the timestamp moves one millisecond ahead. Safe from many threads.

Batch

func Batch(g: Generator, n: int): Vector<ULID>
Makes n ids under one lock with one clock read. A failing entropy source ends the batch early, so check the length. Free the vector.
encoding-ulid-Batch.salam
import encoding.ulid

func main:
    ids := ulid.NewBatch(5)
    defer ids.Free()
    mut increasing := ids.Len() == 5
    repeat ids.Len() - 1 in i:
        if not ulid.Less(ids.Get(i), ids.Get(i + 1)):
            increasing = false
        end
    end
    println ids.Len(), increasing
end
