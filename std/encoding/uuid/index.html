encoding.uuid

UUIDs as RFC 9562 defines them: versions 1 to 8, nil and max, strict parsing, and generation that is safe from many threads.

import encoding.uuid

A UUID is a 128 bit identifier that can be made on any machine without asking a server. This package follows RFC 9562, which replaced RFC 4122, and checks its output against the test vectors of that RFC. A UUID is a small value of two 64 bit halves, so it is cheap to copy, compare and use as a key.

Which version to use:

VersionMade byUse it for
4NewV4, NewPlain random ids. The default choice.
7NewV7Database keys and anything you sort or index: the time comes first, so new ids land at the end of an index.
5NewV5The same name must always give the same id, for example an id for a URL.
3NewV3Like 5 with MD5, only to match ids that already exist.
1 and 6NewV1, NewV6Time based ids that other systems expect. Version 6 is version 1 reordered so it sorts by time; prefer it for new code.
8NewV8Your own layout in the 122 free bits.

The random versions read only the operating system secure random source. The package never uses std/rand, which is not meant for identifiers. If the secure source cannot be read the process stops, because an id built from anything weaker would be a security hole; there is no half working mode to handle.

Making an id

New makes a random version 4 id and String writes it as the usual 36 characters. Nil and Max are the all zero and all one ids. Printing a UUID with println writes the same text.

encoding-uuid-guide-basics.salam
import encoding.uuid

func main:
    id := uuid.New()
    println uuid.String(id).Len(), uuid.Version(id), uuid.Variant(id) == uuid.VARIANT_RFC
    text := uuid.NewString()
    println uuid.IsValid(text), text.Len()
    println uuid.Nil()
    println uuid.Max()
    println uuid.IsNil(uuid.Nil()), uuid.IsNil(id)
end
Output36 4 true true 36 00000000-0000-0000-0000-000000000000 ffffffff-ffff-ffff-ffff-ffffffffffff true false

Reading and writing text

Parse accepts the canonical form, the form in braces, the urn:uuid: form and the form with no hyphens, in capitals or not. It is strict: no spaces around the text, every hyphen where it belongs, nothing but hex digits. It returns a ParseResult with ok, id and error. Use MustParse for literals in your own code and ParseOr when you have a fallback. String, Upper, Compact, Braced and URN write the other direction.

encoding-uuid-guide-parse.salam
import encoding.uuid

func main:
    forms := [
        "f81d4fae-7dec-11d0-a765-00a0c91e6bf6", "F81D4FAE-7DEC-11D0-A765-00A0C91E6BF6",
        "f81d4fae7dec11d0a76500a0c91e6bf6", "{f81d4fae-7dec-11d0-a765-00a0c91e6bf6}",
        "urn:uuid:f81d4fae-7dec-11d0-a765-00a0c91e6bf6", "f81d4fae-7dec-11d0-a765",
        "f81d4fae-7dec-11d0-a765-00a0c91e6bfz"
    ]
    each text in forms:
        r := uuid.Parse(text)
        if r.ok:
            println "ok   ", uuid.String(r.id)
        else:
            println "error", r.error
        end
    end
    id := uuid.MustParse("f81d4fae-7dec-11d0-a765-00a0c91e6bf6")
    println uuid.Upper(id)
    println uuid.Compact(id)
    println uuid.Braced(id)
    println uuid.URN(id)
end

Ids made from names

Version 5 (and 3) hashes a namespace id and a name, so the same pair always gives the same id. The four namespaces of the RFC are NamespaceDNS, NamespaceURL, NamespaceOID and NamespaceX500; you can also use any UUID of your own as a namespace. The values below are the ones printed in RFC 9562.

encoding-uuid-guide-names.salam
import encoding.uuid

func main:
    dns := uuid.NamespaceDNS()
    println uuid.NewV5(dns, "www.example.com")
    println uuid.NewV3(dns, "www.example.com")
    println uuid.NewV5(dns, "www.example.com") == uuid.NewV5(dns, "www.example.com")
    println uuid.Equal(uuid.NewV5(dns, "python.org"), uuid.NewV5(uuid.NamespaceURL(), "python.org"))
end
Output2ed6657d-e927-568b-95e1-2665a8aea6a2 5df41881-3aed-3515-88a7-2f4a814cf09e true false

Time based ids

Versions 1, 6 and 7 carry a time. UnixMillis and UnixNanos read it back, Timestamp gives the raw 60 bit count of version 1 and 6. The From...Parts functions build an id from exact parts, which is how the tests pin the RFC test vectors. NewV7 returns a larger id on every call, even in the same millisecond, even from other threads, and even when the clock is set back. NewV1 and NewV6 never repeat either: ids in the same 100 nanosecond tick move the time forward by one tick, and a clock that jumps far back changes the clock sequence as RFC 9562 asks. Their node is random per process with the multicast bit set, never a real network address.

encoding-uuid-guide-time.salam
import encoding.uuid

func main:
    v1 := uuid.FromV1Parts(0x1EC9414C232AB00, 0x33C8, 0x9F6BDECED846)
    v6 := uuid.FromV6Parts(0x1EC9414C232AB00, 0x33C8, 0x9F6BDECED846)
    v7 := uuid.FromV7Parts(1645557742000, 0xCC3, 0x18C4DC0C0C07398F)
    println v1
    println v6
    println v7
    println uuid.UnixMillis(v1), uuid.UnixMillis(v6), uuid.UnixMillis(v7)
    println uuid.ClockSequence(v1), uuid.Node(v1) == 0x9F6BDECED846

    first := uuid.NewV7()
    second := uuid.NewV7()
    println uuid.Less(first, second), uuid.String(first) < uuid.String(second)
    println uuid.UnixMillis(second) - uuid.UnixMillis(first) < 1000
end

Many threads at once

All the generators can be called from any number of threads, with go, spawn or a pool. The clock state, the version 7 counter and the buffer of random bytes sit behind locks of their own, so there are no duplicates and no id goes backwards in a thread. The example makes 8000 ids from 8 tasks and counts the different ones.

encoding-uuid-guide-threads.salam
import encoding.uuid
import mem
import pool

const WORKERS := 8
const PER := 1000

mut slots := null as u64*

func produce(worker: int):
    repeat PER in i:
        id := uuid.NewV7()
        slot := (worker * PER + i) * 2
        slots[slot] = id.hi
        slots[slot + 1] = id.lo
    end
end

func main:
    slots = mem.Allocate((WORKERS * PER * 16) as u64) as u64*
    repeat WORKERS in worker:
        go produce(worker)
    end
    pool.GoWait()
    mut seen := HashMap {} as HashMap<str, int>
    defer seen.Free()
    repeat WORKERS * PER in i:
        seen.Put(uuid.Compact(uuid.UUID { hi = slots[i * 2], lo = slots[i * 2 + 1] }), 1)
    end
    println "generated", WORKERS * PER, "unique", seen.Size()
    mem.Free(slots as void*)
end
Outputgenerated 8000 unique 8000

Short forms

Base64URL writes an id in 22 characters that are safe in a URL and Base32 in 26 lowercase characters that are safe in a file name or a host name. Reading them back is as strict as Parse: the unused bits must be zero, so one id has one text.

encoding-uuid-guide-short.salam
import encoding.uuid

func main:
    id := uuid.MustParse("f81d4fae-7dec-11d0-a765-00a0c91e6bf6")
    short := uuid.Base64URL(id)
    println short, short.Len()
    println uuid.Base32(id)
    back := uuid.FromBase64URL(short)
    println back.ok, uuid.Equal(back.id, id)
    println uuid.FromBase64URL("too short").error
end
Output-B1Prn3sEdCnZQCgyR5r9g 22 7aou7lt55qi5bj3facqmshtl6y true true uuid: base64url text must have 22 characters

Custom ids and bytes

Version 8 keeps the version and variant bits and leaves the rest to you: FromV8Parts takes the three fields of the RFC and NewV8 takes two 64 bit halves. Bytes and FromBytes convert to the 16 bytes in network order, and ToBuffer and FromBuffer do the same for raw memory.

encoding-uuid-guide-custom.salam
import encoding.uuid

func main:
    custom := uuid.FromV8Parts(0x2489E9AD2EE2, 0xE00, 0xEC932D5F69181C0)
    println custom, uuid.Version(custom), uuid.Variant(custom) == uuid.VARIANT_RFC
    other := uuid.NewV8(0x0123456789ABCDEF as u64, 0xFEDCBA9876543210 as u64)
    println other
    mut bytes := uuid.Bytes(other)
    println bytes.Len(), bytes.Get(0), bytes.Get(15)
    println uuid.Equal(uuid.FromBytes(bytes), other)
    bytes.Free()
    batch := uuid.Batch(3)
    println batch.Len()
    batch.Free()
end
Output2489e9ad-2ee2-8e00-8ec9-32d5f69181c0 8 true 01234567-89ab-8def-bedc-ba9876543210 16 1 16 true 3

What people get wrong:

  • Using version 4 as a primary key in a big table. Random keys scatter writes over the whole index; version 7 keeps them together.
  • Hiding secrets in the time of a version 1, 6 or 7 id. The time can be read back by anyone who has the id.
  • Expecting version 5 to be secret. It is a hash of public values, anyone who knows the name can compute it.
  • Comparing the text of ids made in different cases. Compare with Equal, or write both with String.
  • Forgetting to free the vectors from Bytes, Batch and BatchV7.

For random bytes and tokens see crypto; for hex and base64 of arbitrary data see encoding.

NewV4

func NewV4(): UUID
A random UUID, version 4. It has 122 random bits from the operating system secure random source and nothing else. The source is read in large blocks under a lock, so it is safe from many threads.

The example for this item is shown with the ones above: encoding-uuid-NewV4.salam

NewV7

func NewV7(): UUID
A UUID made of the Unix time in milliseconds followed by a counter and random bits, version 7. Every call returns a larger UUID than the one before, in the whole process and across threads, even when the clock stands still or goes back.
encoding-uuid-NewV7.salam
import encoding.uuid

func main:
    ids := uuid.BatchV7(5)
    defer ids.Free()
    mut ordered := true
    repeat ids.Len() - 1 in i:
        if not uuid.Less(ids.Get(i), ids.Get(i + 1)): ordered = false end
    end
    println "version", uuid.Version(ids.Get(0)), "ordered", ordered
    println uuid.HasTime(ids.Get(0))
end
Outputversion 7 ordered true true

    v1 := uuid.FromV1Parts(0x1EC9414C232AB00, 0x33C8, 0x9F6BDECED846)

    println v1
    println v6
    println uuid.UnixMillis(v1), uuid.ClockSequence(v6), uuid.Node(v1) == 0x9F6BDECED846
    println uuid.Timestamp(v1) == uuid.Timestamp(v6)
    a := uuid.NewV1()
    b := uuid.NewV1()
    println uuid.Timestamp(a) < uuid.Timestamp(b), uuid.Node(a) == uuid.NodeID()
    own := uuid.NewV1WithNode(0x0123456789AB)
    println uuid.Node(own) == 0x0123456789AB, uuid.Version(uuid.NewV6())
end
