error

Structured errors with a kind, a message, a chain of causes, metadata and a retry policy.

import error

Salam has no exceptions, so a function that may fail says so in its result. The error package gives your own code one error type for that: an error.Error is either nil, meaning everything went well, or an error with a kind, such as not_found, and a message. The kind is for the code to decide on; the message is for a person to read. The usual shape is an err &: error.Error out parameter, as in the standard library.

When an error comes up from a lower layer, Wrap it so the current layer's explanation is added. The final message shows the whole chain, as in could not save the report: the disk is full, and RootMessage gives the original cause. For transient errors, such as a dropped network connection, RetryPolicy says how often to try again and how long to wait between attempts.

Neighbouring packages: result and option return a value or its absence in one result, which suits short chains with ?; os/error holds the last error of a file or process call. Many std packages, such as the database clients, have an Error type of their own; turn it into an error.Error at the edge of your code when you want one type throughout.

The things people get wrong:

  • Wrap and WithMeta on a nil error make a real error. Check Ok before you wrap.
  • Every Wrap, WithMeta and WrapKind returns a new error with its own copies, and leaves the old one as it was. Free the ones you no longer need with Free.
  • Is and the Is... helpers look at every layer, not only the outer kind. After WrapKind to internal, an error that started as a timeout still answers true to IsTimeout and IsRetryable (see below). Compare Kind when only the outer kind should count.
  • DelayForAttempt only computes the wait; your loop has to sleep. It adds no random jitter, so many clients that fail together retry together.

Errors through the layers of a program

A typical program has layers: one reads data, the next builds something from it, and the top one answers a user. Each layer that can fail takes an err &: error.Error out parameter, sets it to error.Nil() on success, and on failure either makes a new error or wraps the one it got from below. Only the top layer decides what to do, and it decides by kind, not by reading the message.

error-guide-layers.salam
import error
import str

func load user(id: int, err &: error.Error): str:
    if id <= 0:
        err = error.New(error.KindInvalidArgument, "the id must be positive")
        ret ""
    end
    if id != 7:
        err = error.WithMeta(error.New(error.KindNotFound, "no such user"), "id", str.FromInt(id))
        ret ""
    end
    err = error.Nil()
    ret "Leila"
end

func greeting(id: int, err &: error.Error): str:
    mut inner := error.Nil()
    name := load user(id, inner)
    if not error.Ok(inner):
        err = error.Wrap(inner, "could not build the greeting")
        ret ""
    end
    err = error.Nil()
    ret "Welcome back, " + name
end

func status for(e: error.Error): int:
    if error.Ok(e): ret 200 end
    if error.IsNotFound(e): ret 404 end
    if error.IsInvalidArgument(e): ret 400 end
    ret 500
end

func main:
    each id in [7, 3, -1]:
        mut err := error.Nil()
        text := greeting(id, err)
        status := status for(err)
        if error.Ok(err):
            println status, text
        else:
            println status, error.Message(err)
            if error.Meta(err, "id") != "":
                println "    missing id:", error.Meta(err, "id")
            end
        end
    end
end
Output200 Welcome back, Leila 404 could not build the greeting: no such user missing id: 3 400 could not build the greeting: the id must be positive

Wrapping keeps the kind of the original error, so the top layer can still see that the root cause was "not found" and answer 404. WithMeta attaches a detail, here the missing id, that the code can read back with Meta without parsing text.

A retry loop

ShouldRetry answers the whole question in one call: is there an error at all, is it the kind that may go away by itself (unavailable, timeout or io), and are there attempts left? DelayForAttempt gives the wait before the next try, doubling each time up to the maximum.

error-guide-retry.salam
import error
import sync

mut calls := 0

func fetch price(err &: error.Error): int:
    calls += 1
    if calls < 3:
        err = error.New(error.KindUnavailable, "the price service is busy")
        ret 0
    end
    err = error.Nil()
    ret 4200
end

func main:
    mut policy := error.NewRetryPolicy(5, 10, 80)
    mut attempt := 1
    mut err := error.Nil()
    mut price := fetch price(err)
    until error.ShouldRetry(policy, err, attempt):
        wait := error.DelayForAttempt(policy, attempt)
        println "attempt", attempt, "failed:", error.Message(err), "| waiting", wait, "ms"
        sync.SleepMs(wait)
        attempt += 1
        price = fetch price(err)
    end
    if error.Ok(err):
        println "price:", price, "after", attempt, "attempts"
    else:
        println "gave up:", error.Format(err)
    end
    bad := error.New(error.KindInvalidArgument, "unknown product")
    println "retry a bad request?", error.ShouldRetry(policy, bad, 1)
end
Outputattempt 1 failed: the price service is busy | waiting 10 ms attempt 2 failed: the price service is busy | waiting 20 ms price: 4200 after 3 attempts retry a bad request? false

An invalid argument is never retried: sending the same bad request again gives the same answer. In a server, keep the total wait well below the time the caller is willing to wait for you.

Collect every problem at once

For a form or a config file, stopping at the first mistake makes the user fix them one by one. Collect the errors in a vector instead and show them all. Newf fills the {} placeholders of a message from a vector of strings, and a field meta entry says which input each error is about.

error-guide-validate.salam
import error

struct Signup:
    pub email: str = ""
    pub age: int = 0
    pub password: str = ""
end

func check(s: Signup): Vector<error.Error>:
    mut problems := Vector {} as Vector<error.Error>
    if not s.email.includes("@"):
        problems.push(error.WithMeta(error.New(error.KindInvalidArgument, "the email has no @"), "field", "email"))
    end
    if s.age < 13:
        mut args := Vector {} as Vector<str>
        defer args.free()
        args.push("13")
        problems.push(error.WithMeta(error.Newf(error.KindInvalidArgument, "you must be at least {}", args), "field", "age"))
    end
    if s.password.len() < 8:
        problems.push(error.WithMeta(error.New(error.KindInvalidArgument, "the password is too short"), "field", "password"))
    end
    ret problems
end

func main:
    form := Signup { email = "sara.example.com", age = 11, password = "abc" }
    problems := check(form)
    println problems.len(), "problems:"
    each p in problems:
        println "  " + error.Meta(p, "field") + ":", error.Message(p)
    end
    ok := check(Signup { email = "sara@example.com", age = 30, password = "long enough" })
    println "a good form has", ok.len(), "problems"
end
Output3 problems: email: the email has no @ age: you must be at least 13 password: the password is too short a good form has 0 problems

Logging an error with its trace

NewAt and WrapAt also record where the error passed, which Trace joins with ->. WrapKind gives the error a new outer kind, here internal once the program has decided it cannot start. Format puts everything on a few lines for a log: the outer kind in brackets, the full message, the trace and each meta entry.

error-guide-format.salam
import error

func read_file(path: str, err &: error.Error):
    mut e := error.NewAt(error.KindIO, "permission denied reading " + path, "fs.read_file")
    defer error.Free(e)
    err = error.WithMeta(e, "path", path)
end

func load_config(err &: error.Error):
    mut inner := error.Nil()
    read_file("/etc/shop/config.yaml", inner)
    defer error.Free(inner)
    if not error.Ok(inner):
        err = error.WrapAt(inner, "could not load the settings", "config.load")
        ret
    end
    err = error.Nil()
end

func start(err &: error.Error):
    mut inner := error.Nil()
    load_config(inner)
    defer error.Free(inner)
    if not error.Ok(inner):
        err = error.WrapKind(inner, error.KindInternal, "the shop did not start")
        ret
    end
    err = error.Nil()
end

func main:
    mut err := error.Nil()
    start(err)
    defer error.Free(err)
    println error.Format(err)
    println "kind:", error.Kind(err)
    println "root cause:", error.RootMessage(err)
    println "was an io error:", error.Is(err, error.KindIO)
    println "retryable:", error.IsRetryable(err)
end
Output[internal] the shop did not start: could not load the settings: permission denied reading /etc/shop/config.yaml trace: fs.read_file -> config.load path=/etc/shop/config.yaml kind: internal root cause: permission denied reading /etc/shop/config.yaml was an io error: true retryable: true

The last two lines are the trap from the list above: the error now reads as internal, but Is still finds the io kind of its root cause, so IsRetryable says yes. Each layer frees the error it got from below with defer error.Free(inner); that is safe because the wrapped error has its own copies.

Choosing a kind

KindUse it whenRetry?
KindInvalidArgumentThe caller passed bad inputNo
KindNotFoundThe thing asked for does not existNo
KindAlreadyExistsCreating something that is already thereNo
KindPermissionDeniedThe caller may not do thisNo
KindUnavailableA service is down or busyYes
KindTimeoutSomething took too longYes
KindIOA file or device operation failedYes
KindCanceledThe work was stopped on purposeNo
KindInternalA bug or a broken invariantNo

Keep messages short and in lower case without a final full stop, because Message joins them with ": " into one sentence. Put values the code needs, such as ids and file names, in WithMeta, and show Format in logs, where the trace and meta entries help most.

error-New.salam
import error

func find_user(id: int): error.Error:
    if id <= 0:
        ret error.New(error.KindInvalidArgument, "the id has to be positive")
    end
    if id > 100:
        ret error.NewAt(error.KindNotFound, "no such user", "find_user")
    end
    ret error.Nil()
end

func main:
    each id in [7, -1, 500]:
        mut e := find_user(id)
        if error.Ok(e):
            println id, "found", error.IsNil(e)
        else:
            println id, error.Kind(e), error.Message(e)
            println error.Is(e, error.KindNotFound), error.IsNotFound(e), error.IsInvalidArgument(e)
        end
        error.Free(e)
    end
    mut args := Vector {} as Vector<str>
    defer args.free()
    args.push("config.ini")
    e2 := error.Newf(error.KindIO, "cannot read {}", args)
    println error.Message(e2)
end
Output7 found true -1 invalid_argument the id has to be positive false false true 500 not_found no such user true true false cannot read config.ini

RetryPolicy

struct RetryPolicy
A retry policy.
NameTypeDescription
max_attemptsint = 3The greatest number of attempts; three by default.
base_delay_msint = 100The delay after the first failed attempt, in milliseconds; 100 by default.
max_delay_msint = 5000The ceiling on the delay, in milliseconds; 5000 by default.
error-RetryPolicy.salam
import error

func main:
    mut policy := error.NewRetryPolicy(4, 100, 1000)
    println policy.max_attempts, policy.base_delay_ms, policy.max_delay_ms
    e := error.New(error.KindTimeout, "the server did not answer")
    mut attempt := 1
    until error.ShouldRetry(policy, e, attempt):
        println "attempt", attempt, "after", error.DelayForAttempt(policy, attempt), "milliseconds"
        attempt += 1
    end
    println error.ShouldRetry(policy, error.New(error.KindInvalidArgument, "bad input"), 1)
end
Output4 100 1000 attempt 1 after 100 milliseconds attempt 2 after 200 milliseconds attempt 3 after 400 milliseconds false

error-Wrap.salam
import error

func main:
    root := error.New(error.KindIO, "the disk is full")
    a := error.Wrap(root, "could not save the report")
    b := error.WrapAt(a, "the nightly run stopped", "nightly job")
    c := error.WrapKind(b, error.KindInternal, "internal error")
    d := error.WithMeta(c, "disk", "/dev/sda1")
    println error.Message(d)
    println error.RootMessage(d)
    println error.Kind(d), error.IsInternal(d), error.Meta(d, "disk")
    println error.Trace(d)
    println error.Format(d)
end
