fs

File times and permissions; the base of the file, dir and path packages.

import fs
On this page
  1. Keep a secret file private
  2. Reading the permission digits
  3. Rebuild only what changed
  4. Platform notes
  5. Functions

The fs package holds a few functions about a file's metadata (its times and its permissions) and three sub-packages you will use far more often: fs.file for reading and writing files, fs.dir for folders and fs.path for building paths. The simpler os package covers whole-file reads, folder listings and existence checks; come here for when a file changed and who may read it.

Times are whole seconds since the start of 1970 (Unix time), as an i64. Every function returns -1 when the path does not exist or the system cannot answer.

Write permissions in octal, such as 0o644, meaning the owner reads and writes and everyone else reads. Permissions returns the same digits as an ordinary number, such as 644, so that it reads easily. The two are not the same number (0o644 is 420), so never pass the result of Permissions back to Chmod unchanged.

Keep a secret file private

A new file gets the system default permissions, usually 644, which lets every account on the machine read it. For tokens, keys and passwords, write the file and then narrow it to 0o600. Keep the two notations apart: Chmod takes octal (0o600), while Permissions gives the same digits back as an ordinary number (600). That is why p % 100 == 0 below means that the group and everyone else have no rights at all.

fs-guide-private.salam
import fs
import fs.file

func main:
    file.WriteText("token.txt", "s3cr3t")
    fs.Chmod("token.txt", 0o644)
    println "before:", fs.Permissions("token.txt")
    fs.Chmod("token.txt", 0o600)
    p := fs.Permissions("token.txt")
    println "after: ", p
    if p % 100 == 0:
        println "only the owner can read it"
    end
    file.Delete("token.txt")
end
Outputbefore: 644 after: 600 only the owner can read it

Reading the permission digits

The three digits are for the owner, the group and everyone else, in that order. Inside one digit, 4 means read, 2 means write and 1 means execute, and the digit is their sum:

DigitLettersMeaning
7rwxread, write and run
6rw-read and write
5r-xread and run
4r--read only
0---nothing

This example turns the number into the letters that ls -l prints. A script needs the execute bit for its owner (0o755 or 0o700) before the shell runs it, and a directory needs it before anyone can open it.

fs-guide-rwx.salam
import fs
import fs.file

func letters(digit: int): str:
    mut out := ""
    if digit >= 4: out = out + "r" else: out = out + "-" end
    if digit % 4 >= 2: out = out + "w" else: out = out + "-" end
    if digit % 2 == 1: out = out + "x" else: out = out + "-" end
    ret out
end

func show(p: int): str:
    ret letters(p / 100) + letters(p / 10 % 10) + letters(p % 10)
end

func main:
    file.WriteText("deploy.sh", "echo deploying\n")
    each mode in [0o755, 0o750, 0o644, 0o600]:
        fs.Chmod("deploy.sh", mode)
        p := fs.Permissions("deploy.sh")
        println p, show(p)
    end
    file.Delete("deploy.sh")
end
Output755 rwxr-xr-x 750 rwxr-x--- 644 rw-r--r-- 600 rw-------

Rebuild only what changed

ModTime is how build tools such as make decide what to do: an output is out of date when its source changed after the output was written. For a path that does not exist ModTime returns -1, which the example reads as "build it". Times are in whole seconds, so a source and an output written in the same second count as up to date. That is the right answer here, because the output was written after the source.

fs-guide-rebuild.salam
import fs
import fs.file

func needs_build(src: str, out: str): bool:
    built := fs.ModTime(out)
    if built < 0: ret true end
    ret fs.ModTime(src) > built
end

func main:
    file.WriteText("page.md", "# Hello\n")
    println "first run, build:", needs_build("page.md", "page.html")
    file.WriteText("page.html", "<h1>Hello</h1>\n")
    println "after building, build:", needs_build("page.md", "page.html")
    file.Delete("page.html")
    println "output deleted, build:", needs_build("page.md", "page.html")
    file.Delete("page.md")
end
Outputfirst run, build: true after building, build: false output deleted, build: true

Platform notes

  • CreatedTime is 0 where the file system does not record a creation time, which is common on Linux. Use ModTime when you need a value that is always there.
  • On Linux, macOS and BSD the time functions and Permissions run the system stat command through the shell, with the path quoted. That is quick for a handful of files, but over thousands of files in a loop the process starts add up. Chmod calls the system directly.
  • Windows has no Unix permission bits, only a read only flag, so Chmod can only switch that flag, and Permissions returns 292 (0o444) for a read only file and 438 (0o666) otherwise: the octal value, not the digits it gives on Unix. Write permission logic for Unix and test it there.

Functions

ModTime

func ModTime(path: str): i64
When the file's content was last changed, in Unix seconds; -1 when the path does not exist.
fs-ModTime.salam
import fs
import fs.file

func main:
    file.WriteText("report.txt", "hello")
    t := fs.ModTime("report.txt")
    println t > 0, fs.AccessedTime("report.txt") > 0, fs.CreatedTime("report.txt") >= 0
    fs.Chmod("report.txt", 0o644)
    println fs.Permissions("report.txt")
end
Outputtrue true true 644

AccessedTime

func AccessedTime(path: str): i64
When the file was last read, in Unix seconds. Many systems update it lazily or not at all (noatime), so do not rely on it.

CreatedTime

func CreatedTime(path: str): i64
When the file was created, in Unix seconds, or zero where the file system does not keep it.

The example for this item is shown with the ones above: fs-ModTime.salam

Chmod

func Chmod(path: str, mode: int): int
Changes a file's permissions; give them in octal, such as 0o644. Returns 0 on success and -1 on failure. On Windows only the read only flag can change.

The example for this item is shown with the ones above: fs-ModTime.salam

Permissions

func Permissions(path: str): int
A file's permissions as their octal digits read as a decimal number, such as 644; -1 when the path does not exist. On Windows it returns 292 or 438 instead.

The example for this item is shown with the ones above: fs-ModTime.salam
