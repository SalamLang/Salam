gui.color

Colours for the Salam UI standard: every colour syntax in English and Persian, checked with clear errors, conversion between colour spaces, mixing in oklab, light and dark pairs, contrast and the CSS the web target emits.

import gui.color
On this page
  1. A light and dark palette
  2. Checking colours that people type
  3. Types
  4. Functions

gui.color is the colour part of the Salam UI standard. It reads every colour a page may use, in the same syntax in page source, in a string and in a value computed at run time, and it turns a colour into what each target needs: a packed u32 for the native renderer and CSS text for the web.

A Color holds sRGB channels from 0 to 1 and an alpha. A colour from a wider gamut, such as color(display p3, 1, 0, 0), keeps channels below 0 or above 1, so nothing is lost until it is drawn.

What Parse accepts:

  • Names: all 148 CSS colour names plus transparent and current (the text colour), in any case and with or without spaces (alice blue), and Persian names such as قرمز, آبی and قهوه ای.
  • Hex: #rgb, #rgba, #rrggbb and #rrggbbaa.
  • Functions: rgb, rgba, hsl, hsla, hwb, lab, lch, oklab, oklch, cmyk (also device cmyk) and color(space, c1, c2, c3) with the spaces srgb, srgb linear, display p3, a98 rgb, prophoto rgb, rec2020, xyz, xyz d50 and xyz d65. Values are separated by commas, as in rgb(51, 102, 170), or by spaces with / before the alpha, as in CSS. The hyphenated CSS spellings (display-p3) work too.
  • mix(a, b, amount, space): amount is how much of b, as a number from 0 to 1 or a percent, 50% when left out; the space is oklab unless given.
  • light dark(a, b): a colour with a light and a dark variant.
  • Numbers: a percent with % or ٪, Persian digits, the Persian comma ،, and hue angles as a bare number of degrees or with deg, rad, grad or turn.

Things to know:

  • Values are checked, not clamped. rgb(300, 0, 0) is an error, not red. Error says what was expected and the column where the problem starts, and suggests a name when one is close.
  • Css writes what every current browser draws the same: #rrggbb or #rrggbbaa inside sRGB, color(display-p3 ...) for a wide gamut colour that fits Display P3, oklch(...) beyond that, currentColor and light-dark(a, b).
  • Argb clamps each channel to sRGB, so a wide gamut colour is drawn as its nearest sRGB colour on the native target.
  • cmyk is the plain formula (red is (1 - c) * (1 - k)), with no printer profile.
  • current cannot be mixed while parsing, because the text colour is only known when the page is shown.

A light and dark palette

A theme starts from one brand colour. Each role gets a LightDark pair, Lighten and Darken move the lightness in oklch and stay inside sRGB, and Mix works on both variants at once. Contrast then checks every pair against the 4.5 ratio that WCAG asks of body text, in light and in dark mode.

gui-color-guide-theme.salam
import gui.color
import math

func r2(v: f64): f64:
    ret math.Round(v * 100.0) / 100.0
end

func check(name: str, text: color.Color, back: color.Color):
    light := color.Contrast(color.Light(text), color.Light(back))
    dark := color.Contrast(color.Dark(text), color.Dark(back))
    mut verdict := "ok"
    if light < 4.5 or dark < 4.5:
        verdict = "too low for body text"
    end
    println name, "light", r2(light), "dark", r2(dark), verdict
end

func main:
    mut brand := color.Color {}
    if not color.Parse("#3366aa", brand):
        ret 1
    end
    page := color.LightDark(color.Hex(0xffffff), color.Hex(0x121212))
    text := color.LightDark(color.Hex(0x1a1a1a), color.Hex(0xeeeeee))
    accent := color.LightDark(brand, color.Lighten(brand, 0.2))
    muted := color.Mix(text, page, 0.45)
    hover := color.LightDark(color.Darken(brand, 0.08), color.Lighten(brand, 0.28))
    println "page   ", color.Css(page)
    println "text   ", color.Css(text)
    println "accent ", color.Css(accent)
    println "muted  ", color.Css(muted)
    println "hover  ", color.Css(hover)
    check("text on page  ", text, page)
    check("accent on page", accent, page)
    check("muted on page ", muted, page)
end
Outputpage light-dark(#ffffff, #121212) text light-dark(#1a1a1a, #eeeeee) accent light-dark(#3366aa, #6ea3ec) muted light-dark(#777777, #818181) hover light-dark(#1b4f91, #8cbdff) text on page light 17.4 dark 16.15 ok accent on page light 5.8 dark 7.25 ok muted on page light 4.47 dark 4.82 too low for body text

Checking colours that people type

A settings screen that takes a colour as text needs to say what is wrong with it. Error returns an empty string for a colour Parse accepts, and otherwise one line with the column and the expected form, so it can be shown under the field as it is.

gui-color-guide-input.salam
import gui.color

func main:
    inputs := ["#3366aa", "rgb(51 102 170 / 50%)", "hsl(210, 50%, 40%)", "mix(red, blue, 30%)", "rgb(300, 0, 0)", "hsl(210 50%)", "darkgrey", "dark grey", "darkgray", "lightgreem", "rgb(51, 102 170)", "#12345"]
    mut accepted := 0
    each text in inputs:
        message := color.Error(text)
        if message == "":
            mut c := color.Color {}
            color.Parse(text, c)
            println "ok     ", text, "=>", color.Css(c)
            accepted++
        else:
            println "refused", text
            println "       ", message
        end
    end
    println accepted, "of", inputs.Len(), "accepted"
end
Outputok #3366aa => #3366aa ok rgb(51 102 170 / 50%) => #3366aa80 ok hsl(210, 50%, 40%) => #336699 ok mix(red, blue, 30%) => #ba4d79 refused rgb(300, 0, 0) column 5: the red channel of rgb() must be 0 to 255, found 300 refused hsl(210 50%) column 12: hsl() takes 3 values (hue, saturation, lightness) and an optional alpha, found 2 values ok darkgrey => #a9a9a9 ok dark grey => #a9a9a9 ok darkgray => #a9a9a9 refused lightgreem column 1: unknown colour name 'lightgreem'; did you mean 'lightgreen'? refused rgb(51, 102 170) column 13: expected ',' between the values of rgb(...), found '170' refused #12345 column 1: '#12345' has 5 hex digits; a hex colour has 3, 4, 6 or 8 7 of 12 accepted

Color

struct Color
A colour: sRGB channels from 0 to 1, an alpha, and an optional dark variant made by light dark. Channels may be below 0 or above 1 for colours outside sRGB.
NameTypeDescription
rf64 = 0The red channel, 0 to 1 inside sRGB.
gf64 = 0The green channel, 0 to 1 inside sRGB.
bf64 = 0The blue channel, 0 to 1 inside sRGB.
af64 = 1The alpha, from 0 (transparent) to 1 (opaque), not premultiplied.
currentbool = falseTrue for current, the text colour of the element; the channels are then unused.
has_darkbool = falseTrue when the colour has a dark variant, as made by light dark(a, b) or LightDark.
dark_rf64 = 0The red channel of the dark variant. Read the dark variant with Dark instead of these fields.
dark_gf64 = 0The green channel of the dark variant.
dark_bf64 = 0The blue channel of the dark variant.
dark_af64 = 1The alpha of the dark variant.
dark_currentbool = falseTrue when the dark variant is current.

Reads a colour in any syntax the package accepts into out and returns true. On an error it returns false and leaves out as it was; Error gives the message.
