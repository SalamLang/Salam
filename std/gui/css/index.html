gui.css

The CSS style engine of the native UI runtime: selectors, the cascade, inheritance, media queries, shorthands, var() and computed values that match Chromium.

This package is the style engine of the native UI runtime. For each element of a page it takes what the web generator writes for it today (its own declarations, the extra ones for hover, focus and active, its element key, classes and id) together with the page's global and media rules, and computes the final value of every property exactly as a browser would. The native window then looks like the web page.

A Sheet starts with the user agent style sheet, the browser defaults that give a heading its size and a paragraph its margins, written after Chromium's own and compared with Chromium property by property. You add rules with AddRule, AddMediaRule or a whole style sheet with AddCss, describe the elements as a vector of Element in document order, and call Compute. Style then gives each element a ComputedStyle: lengths in pixels (percentages stay relative until layout), colours as straight RGBA, keywords as enums, and lists for backgrounds, shadows, transforms and transitions. ToBox turns it into a gui.cssbox style for layout.

Supported: type, class, id and attribute selectors, descendant, child and sibling combinators, :hover, :focus, :focus-visible, :active, the child and type position pseudo-classes, :not(), :is() and :where(); specificity and !important; inheritance with inherit, initial and unset; media queries on size, orientation, colour scheme, reduced motion, hover and pointer; every length unit, calc(), min(), max() and clamp(); colours in every common syntax; gradients, shadows, transforms, transitions, fonts, logical properties for right to left pages, and var() with fallbacks. Grid and table properties are parsed, cascaded and checked: track lists, areas, placements and their shorthands (grid, grid-template, grid-area, grid-row, grid-column), border-collapse, border-spacing, table-layout and caption-side; ToBox hands them to the layout engine. Pseudo-elements, subgrid, animations and container queries are not done.

Things to know

  • An element's own declarations act like a class rule written after the global rules, which is what the web generator emits. Its hover, focus and active declarations act like the same class with that pseudo-class.
  • Elements must come in document order, each after its parent. The page itself has parent -1; an implicit html root above it matches :root.
  • Elements with the same inputs share one computed style. Each distinct declaration string is parsed once.
  • After a pointer move, call HoverChain and pass its result to Restyle: only the elements whose state changed, and their descendants when an inherited value changed, are computed again.
  • Strings returned by the text helpers belong to the caller. The vectors inside a ComputedStyle belong to the sheet.
  • border-image and its longhands, gradient colour hints and calc() stop positions are supported. Gradient stops are resolved when painting with GradientStops, which expands hints and non-sRGB segments in the interpolation colour space the way Chromium does. Colour transitions between non-legacy colours mix in Oklab.
  • Values are applied by keyword id, not by comparing strings, and the cascade passes its large structures by reference: computing all styles of a 202-element page shaped like tools/bench/gui_ui.salam went from about 282 us to about 113 us (minimum of 500 runs, one core, C backend).

Styling a page

A card with a heading and a paragraph. The global rule sets the heading's margins, the user agent sheet gives it its size and weight, and the card's own declarations are converted to a layout style and placed with gui.cssbox.

gui-css-guide-page.salam
import gui.css
import gui.cssbox

func add(els &: Vector<css.Element>, kind: str, parent: int, classes: str, base: str): int:
    mut e := css.NewElement(kind, parent)
    e.classes = classes
    e.base = base
    els.push(e)
    ret els.len() - 1
end

func main:
    mut sheet := css.NewSheet()
    defer sheet.Free()
    _g := sheet.AddRule("*", "box-sizing: border-box")
    _c := sheet.AddRule(".card h2", "margin: 0 0 8px")
    mut els := Vector {} as Vector<css.Element>
    body := add(els, "page", -1, "", "font-family: Vazirmatn, sans-serif; background: #f8fafc")
    card := add(els, "box", body, "card", "padding: 1em; border: 1px solid #e2e8f0; border-radius: 12px; max-width: 30rem")
    title := add(els, "h2", card, "", "color: #0f172a")
    text := add(els, "paragraph", card, "", "line-height: 1.5")
    _n := sheet.Compute(els, css.Env { width = 800.0, height = 600.0 })
    each i in [body, card, title, text]:
        cs := sheet.Style(i)
        println els[i].tag, css.ValueText(cs, "display"), css.ValueText(cs, "font-size"), css.ValueText(cs, "margin-top"), css.ValueText(cs, "padding-top"), css.ValueText(cs, "color")
    end
    mut tree := cssbox.Tree {}
    defer tree.Free()
    mut ids := Vector {} as Vector<int>
    defer ids.free()
    repeat els.len() in i:
        ids.push(tree.AddNode(css.ToBox(sheet.Style(i))))
        if els[i].parent >= 0:
            tree.AddChild(ids[els[i].parent], ids[i])
        end
    end
    tree.Compute(ids[0], cssbox.Definite(800.0), cssbox.Definite(600.0))
    l := tree.Layout(ids[card])
    println "card box", l.x, l.y, l.width, l.height
    repeat els.len() in i:
        mut x := els.ref(i)
        x.Free()
    end
    els.free()
end

Hover, pressed and media

The button's hover background applies once the pointer is over it, and only the elements on the hover path are computed again. A media condition changes the navigation into a column when the window is narrow. Computing styles for 5,000 elements with 11 distinct styles takes about 10 ms on one desktop core; a hover change restyles four elements in about 0.1 ms. With 5,000 different styles it takes about 100 ms the first time and about 50 ms once the declarations are parsed.

import gui.css

    els.push(nav)

Compiled style programs

A page built with --ui=native does not parse CSS when it runs. At compile time the compiler fills a Program with CompileDecls (one id per distinct declaration list), CompileRule and CompileCss: shorthands are expanded, values are tokenized and validated, selectors and media conditions are compiled, and anything invalid is reported through ProgramErrors. ProgramSource then writes a Salam function that rebuilds the same program from literals, one call per declaration, and the program turns it into a sheet with SheetFromProgram. Elements point at declaration lists through decl_base, decl_hover, decl_focus and decl_active, so computing styles never touches CSS text. Only a style value that is a runtime expression goes through DynDecl, which parses that one value once and caches it. The user agent sheet is itself a generated program, so NewSheet no longer parses CSS either.

gui-css-guide-program.salam
import gui.css
import mem

func styles(): css.Program:
    mut p := css.NewProgram()
    p.AddSimple(3, "card", "", 0, 0, 0, false)
    p.AddCompound(0, 1, 0)
    p.AddSelector(0, 1, 1000, false, false)
    p.AddMedia(-1, [css.Fn(""), css.Kw("max-width"), css.Delim(58, false), css.Dim(600.0, "px"), css.Close()])
    p.AddDecl("padding-top", false, [css.Dim(12.0, "px")])
    p.AddDecl("color", true, [css.Hash("334155")])
    p.AddDecl("font-family", false, [css.KwAs("vazirmatn", "Vazirmatn"), css.Comma(), css.Kw("sans-serif")])
    p.AddDecl("line-height", false, [css.Num(1.5)])
    p.AddDecl("order", false, [css.Int(2.0)])
    p.AddDecl("width", false, [css.Pct(50.0)])
    p.AddDecl("background-image", false, [css.Url("bg.png")])
    p.AddVarDecl("--label", "\"hi\"", false)
    p.EndList(8)
    p.AddDecl("margin-top", false, [css.Str("x")])
    p.EndList(1)
    p.AddRule(0, 0, 0)
    ret p
end

func main:
    mut p := css.NewProgram()
    card := css.CompileDecls(p, "padding: 16px; border-radius: 8px")
    println "list", card, "same text", css.CompileDecls(p, "padding: 16px; border-radius: 8px"), "empty", css.CompileDecls(p, "")
    println "rule", css.CompileRule(p, ".card:hover", "background: #eef", ""), css.CompileRule(p, ".card", "padding: 8px", "(max-width: 600px)")
    println "css rules", css.CompileCss(p, "h1 { margin: 0 } @media (prefers-color-scheme: dark) { body { color: #eee } }")
    _bad := css.CompileDecls(p, "colr: red")
    println "errors", css.ProgramErrors(p)
    e := css.ProgramError(p, 0)
    println e
    mem.Free(e as void*)
    src := css.ProgramSource(p, "page_styles", "css")
    println src.starts_with("func page_styles(): css.Program:")
    mem.Free(src as void*)
    wide := css.DynDecl(p, "width", "240px")
    mut sheet := css.SheetFromProgram(p)
    mut els := Vector {} as Vector<css.Element>
    els.push(css.NewElement("page", -1))
    mut box := css.NewElement("box", 0)
    box.classes = "card"
    box.decl_base = card
    box.decl_hover = -1
    box.decl_focus = -1
    box.decl_active = -1
    box.decl_dyn.push(wide)
    els.push(box)
    _n := sheet.Compute(els, css.Env { width = 500.0 })
    cs := sheet.Style(1)
    println "padding", css.LenText(cs.padding_top), "width", css.LenText(cs.width)
    println "added again", sheet.AddProgram(p)
    mut q := styles()
    piece := css.Kw("auto")
    println "piece", piece.kind, piece.text, piece.raw, piece.num, piece.code, piece.space, "program", q.id >= 0

        mut x := els.ref(i)
        x.Free()
    end
    els.free()
    sheet.Free()
    q.Free()
    p.Free()
end

Typed values and colours

The program that ProgramSource writes carries values decided at compile time. A declaration is AddTyped with the integer property id from PropertyId; keywords, units and function names are indexes into one name table (KeywordId); lengths keep their number and unit, with absolute units already in pixels and angles in degrees; a calc() that needs nothing from the page is folded to one value; and every colour that does not depend on currentColor is resolved to straight RGBA for the light and the dark scheme. Loading such a program compares no strings and parses nothing.

Colours follow CSS Color 4 and 5: hex, the 148 named colours, transparent, currentColor, rgb(), hsl() and hwb() in the modern and the comma syntax, lab(), lch(), oklab(), oklch(), color() in srgb, srgb-linear, display-p3, a98-rgb, prophoto-rgb, rec2020, xyz, xyz-d50 and xyz-d65, color-mix() in any of those spaces with the four hue interpolation methods, relative colours such as rgb(from red r g calc(b * 2)), light-dark() and the system colours with Chromium's values for each scheme. Every colour inside sRGB matches Chromium; colours outside it are gamut mapped with the CSS Color 4 algorithm, where Chromium clips. Gradients interpolate in the space given with in, and in Oklab when a stop uses one of the newer syntaxes. When the operating system switches between light and dark, SetColorScheme restyles only the elements that depend on the scheme.

gui-css-guide-typed.salam
import gui.css
import mem

func styles(): css.Program:
    mut p := css.NewProgram()
    p.AddTyped(css.PropertyId("display"), 0, [css.KwId(css.KeywordId("flex"))])
    p.AddTyped(css.PropertyId("margin-top"), 0, [css.DimId(1.5, css.KeywordId("em"))])
    p.AddTyped(css.PropertyId("width"), 0, [css.FnId(css.KeywordId("calc")), css.Pct(100.0), css.Delim(45, true), css.DimId(20.0, css.KeywordId("px")), css.Close()])
    p.AddTyped(css.PropertyId("color-scheme"), 2, [css.KwId(css.KeywordId("light")), css.KwId(css.KeywordId("dark"))])
    p.AddTyped(css.PropertyId("color"), 2, [css.ColorValue(0x111111ff, 0xeeeeeeff, 1)])
    p.EndList(5)
    ret p
end

func main:
    name := css.PropertyName(css.PropertyId("color"))
    kw := css.KeywordName(css.KeywordId("flex"))
    println "ids", css.PropertyId("color"), name, css.KeywordId("flex"), kw
    mem.Free(name as void*)
    mem.Free(kw as void*)
    piece := css.ColorValue(0x3366aaff, 0x99bbffff, 1)
    println "piece", piece.id, piece.color, piece.dark, css.KwId(5).id
    mut c := css.Color {}
    _ok := css.ParseColor("oklch(0.7 0.1 30)", c)
    println "oklch", c.r, c.g, c.b
    mixed := css.ColorText(css.MixColors(css.Color { r = 255 }, css.Color { b = 255, a = 0 }, 0.5))
    println "mix", mixed
    mem.Free(mixed as void*)
    mut p := styles()
    mut sheet := css.SheetFromProgram(p)
    mut els := Vector {} as Vector<css.Element>
    els.push(css.NewElement("page", -1))
    mut box := css.NewElement("box", 0)
    box.decl_base = 0
    els.push(box)
    _n := sheet.Compute(els, css.Env { width = 400.0 })
    println "light", css.ValueText(sheet.Style(1), "color"), css.ValueText(sheet.Style(1), "width")
    println "restyled", sheet.SetColorScheme(els, true)
    println "dark", css.ValueText(sheet.Style(1), "color")
    repeat els.len() in i:
        mut x := els.ref(i)
        x.Free()
    end
    els.free()
    sheet.Free()
    p.Free()
end
