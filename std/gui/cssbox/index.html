gui.cssbox

A CSS box layout engine in pure Salam: block flow with margin collapsing, flexbox, grid, tables, absolute positioning and incremental relayout.

import gui.cssbox

This package computes where every box of a user interface goes, using the rules of CSS, so that a page drawn natively has the same geometry as the same page in a browser. You build a Tree of boxes, give each one a Style (display, size, margins, padding, border, flex properties and so on), and call Compute with the size of the window. Layout then gives each box its position, size, content box and scrollable area. The package draws nothing and knows nothing about fonts: text and images are leaves whose size comes from a measure callback you supply.

Block flow follows CSS 2 with margin collapsing between siblings, between a parent and its first or last child, and through empty boxes. Flexbox follows the CSS flexbox specification: flex base sizes, the grow and shrink loop with freezing, wrapping, every justify and align value, auto margins, baselines, reverse directions, order and right to left rows. Absolute and fixed boxes are placed against their containing block, including their static position when insets are auto. Floats, inline text flow and writing modes other than horizontal are not done.

Grid follows CSS Grid Level 1: track lists with pixels, percentages, fr, auto, min-content, max-content, fit-content(), minmax() and repeat() including auto-fill and auto-fit, named lines, grid-template-areas, implicit tracks from grid-auto-rows and grid-auto-columns, sparse and dense auto placement in either direction, spans and negative lines, the full track sizing algorithm, every justify and align value for items and content, baselines, and absolutely positioned items placed in their grid area. Subgrid is not done. Grid properties are strings in CSS syntax, such as grid_template_columns = "repeat(3, 1fr)"; the tree keeps its own copy, and IsTrackList and the other checks tell whether a value is valid.

Tables follow the CSS 2.1 table model the way Chrome lays it out: rows, row groups, header and footer groups (moved to the top and bottom), columns and column groups, captions on either side, anonymous rows and cells around misplaced children, col_span and row_span, automatic column widths from each cell's minimum and maximum content width (with percentage and fixed cells), fixed table layout, border-spacing, collapsed borders, extra height given to rows, and vertical-align in cells.

The block, flex and grid algorithms are ports of Taffy, and the package is tested against 1,527 of Taffy's fixtures measured in Chrome (616 of them with grid), in both box sizing models and both directions. Tables were written from the specification and checked against 53 cases measured in headless Chrome.

Things to know

  • Lengths are already resolved: give pixels or percentages. Convert em, rem, vw and vh before building the style.
  • Defaults are the CSS initial values: display is block, position is static and box_sizing is content-box.
  • Ids are plain integers in the order of AddNode; the node you pass to Compute is the root.
  • Results are rounded to whole pixels the way Chrome rounds them. Turn this off with SetRounding(false) to read fractions.
  • Each node caches its last results. After a style change only the changed node and its ancestors are laid out again; call MarkDirty when the content behind a measure callback changes.

A toolbar with flexbox and text

A row with a growing title, a button and a badge moved first with order. The measure callback stands in for text: it answers how wide the text is with unlimited room, how narrow it can get, and how tall it is at a given width. Switching the direction to right to left mirrors the row.

gui-cssbox-guide-flex.salam
import gui.cssbox

func label(chars: int, mi: cssbox.MeasureInput): cssbox.MeasureOutput:
    full := (chars as f64) * 8.0
    if mi.available_width.kind == cssbox.SpaceKind.MinContent:
        ret cssbox.MeasuredWithBaseline(40.0, 32.0, 12.0)
    end
    if mi.available_width.kind == cssbox.SpaceKind.Definite and mi.available_width.value < full:
        ret cssbox.MeasuredWithBaseline(mi.available_width.value, 32.0, 12.0)
    end
    ret cssbox.MeasuredWithBaseline(full, 16.0, 12.0)
end

func main:
    mut t := cssbox.Tree {}
    defer t.Free()
    bar := t.AddNode(cssbox.Style { display = cssbox.Display.Flex, width = cssbox.Px(400.0), padding = cssbox.AllSides(cssbox.Px(8.0)), column_gap = cssbox.Px(8.0), align_items = cssbox.Align.Baseline, justify_content = cssbox.Align.SpaceBetween })
    title := t.AddNode(cssbox.Style { flex_grow = 1.0, flex_shrink = 1.0, flex_basis = cssbox.Auto() })
    t.SetMeasure(title, (mi: cssbox.MeasureInput): ret label(30, mi) end)
    button := t.AddNode(cssbox.Style { padding = cssbox.SidesOf(cssbox.Px(4.0), cssbox.Px(12.0), cssbox.Px(4.0), cssbox.Px(12.0)), border = cssbox.AllSides(cssbox.Px(1.0)) })
    t.SetMeasure(button, (mi: cssbox.MeasureInput): ret label(4, mi) end)
    badge := t.AddNode(cssbox.Style { width = cssbox.Px(24.0), height = cssbox.Px(24.0), align_self = cssbox.Align.Center, order = -1 })
    t.AddChild(bar, title)
    t.AddChild(bar, button)
    t.AddChild(bar, badge)
    t.Compute(bar, cssbox.MaxContentSpace(), cssbox.MaxContentSpace())
    each id in [bar, badge, title, button]:
        l := t.Layout(id)
        println id, l.x, l.y, l.width, l.height
    end
    rtl := t.GetStyle(bar)
    mut s := rtl
    s.direction = cssbox.Direction.Rtl
    t.SetStyle(bar, s)
    t.Compute(bar, cssbox.MaxContentSpace(), cssbox.MaxContentSpace())
    println "rtl badge x", t.Layout(badge).x, "title x", t.Layout(title).x
end

Block flow and absolute positioning

The header's bottom margin and the card's top margin collapse into one 30 pixel gap, the card is centred with auto margins, and the close button is placed in the corner of the page, which is its containing block because it is positioned. A box with display none takes no space.

gui-cssbox-guide-block.salam
import gui.cssbox

func main:
    mut t := cssbox.Tree {}
    defer t.Free()
    page := t.AddNode(cssbox.Style { width = cssbox.Px(320.0), position = cssbox.Position.Relative, border = cssbox.AllSides(cssbox.Px(2.0)) })
    head := t.AddNode(cssbox.Style { height = cssbox.Px(40.0), margin = cssbox.SidesOf(cssbox.Px(10.0), cssbox.Px(0.0), cssbox.Px(20.0), cssbox.Px(0.0)) })
    card := t.AddNode(cssbox.Style { width = cssbox.Percent(50.0), margin = cssbox.SidesOf(cssbox.Px(30.0), cssbox.Auto(), cssbox.Px(0.0), cssbox.Auto()), padding = cssbox.AllSides(cssbox.Px(10.0)), box_sizing = cssbox.BoxSizing.BorderBox, min_height = cssbox.Px(60.0) })
    close := t.AddNode(cssbox.Style { position = cssbox.Position.Absolute, inset = cssbox.SidesOf(cssbox.Px(4.0), cssbox.Px(4.0), cssbox.Auto(), cssbox.Auto()), width = cssbox.Px(16.0), height = cssbox.Px(16.0) })
    hidden := t.AddNode(cssbox.Style { display = cssbox.Display.None, height = cssbox.Px(500.0) })
    t.AddChild(page, head)
    t.AddChild(page, card)
    t.AddChild(page, close)
    t.AddChild(page, hidden)
    t.Compute(page, cssbox.Definite(800.0), cssbox.Definite(600.0))
    each id in [page, head, card, close, hidden]:
        l := t.Layout(id)
        println id, l.x, l.y, l.width, l.height, "margin", l.margin.top, l.margin.left
    end
end

Changing one box

The counters show the cache at work: a second Compute with nothing changed computes nothing, and changing one leaf recomputes that leaf and its ancestors. Laying out a 5,000 box page (50 wrapping flex rows of 100 text leaves) takes about 15 ms the first time on one desktop core, and about 0.7 ms after one leaf changes; most of that is rounding the whole tree.

gui-cssbox-guide-incremental.salam
import gui.cssbox

func main:
    mut t := cssbox.Tree {}
    defer t.Free()
    list := t.AddNode(cssbox.Style { display = cssbox.Display.Flex, flex_direction = cssbox.FlexDirection.Column, row_gap = cssbox.Px(4.0) })
    mut items := Vector {} as Vector<int>
    defer items.free()
    repeat 3 in i:
        item := t.AddNode(cssbox.Style { height = cssbox.Px(20.0) })
        t.SetMeasure(item, (_mi: cssbox.MeasureInput): ret cssbox.Measured(100.0 + (i as f64) * 10.0, 20.0) end)
        items.push(item)
    end
    t.SetChildren(list, items)
    println "nodes", t.NodeCount(), "children", t.ChildCount(list), "second", t.Child(list, 1), "parent", t.Parent(items.get(0))
    t.Compute(list, cssbox.MaxContentSpace(), cssbox.MaxContentSpace())
    println "size", t.Layout(list).width, t.Layout(list).height, "calls", t.LayoutCalls(), "measures", t.MeasureCalls()
    t.ResetCounters()
    t.Compute(list, cssbox.MaxContentSpace(), cssbox.MaxContentSpace())
    println "again", t.LayoutCalls(), "dirty", t.IsDirty(list)
    t.SetMeasure(items.get(2), (_mi: cssbox.MeasureInput): ret cssbox.Measured(200.0, 20.0) end)
    println "dirty", t.IsDirty(list), t.IsDirty(items.get(0))
    t.Compute(list, cssbox.MaxContentSpace(), cssbox.MaxContentSpace())
    println "width", t.Layout(list).width, "calls", t.LayoutCalls()
    t.ClearMeasure(items.get(2))
    t.MarkDirty(items.get(1))
    t.SetRounding(false)
    t.Compute(list, cssbox.MinContentSpace(), cssbox.MaxContentSpace())
    println "width", t.Layout(list).width
end

A page grid with named areas

A header, sidebar, main area and footer are placed by area name; the main box is centred in its cell with justify_self. The second grid fills a 250 pixel row with as many 70 pixel columns as fit, then stretches them, and the fourth tile wraps to the next row. A 20 by 50 grid of measured text cells lays out in about 1 to 3.5 ms the first time and about 0.8 to 3.3 ms after one cell changes, on one desktop core.

gui-cssbox-guide-grid.salam
import gui.cssbox

func main:
    mut t := cssbox.Tree {}
    defer t.Free()
    page := t.AddNode(cssbox.Style { display = cssbox.Display.Grid, width = cssbox.Px(400.0), grid_template_columns = "120px 1fr", grid_template_rows = "40px auto 30px", grid_template_areas = `"head head" "side main" "foot foot"`, column_gap = cssbox.Px(10.0), row_gap = cssbox.Px(6.0) })
    head := t.AddNode(cssbox.Style { grid_row_start = "head", grid_row_end = "head", grid_column_start = "head", grid_column_end = "head" })
    side := t.AddNode(cssbox.Style { grid_row_start = "side", grid_row_end = "side", grid_column_start = "side", grid_column_end = "side", height = cssbox.Px(80.0) })
    body := t.AddNode(cssbox.Style { grid_row_start = "main", grid_row_end = "main", grid_column_start = "main", grid_column_end = "main", justify_self = cssbox.Align.Center, width = cssbox.Px(100.0), height = cssbox.Px(50.0) })
    foot := t.AddNode(cssbox.Style { grid_row_start = "foot", grid_row_end = "foot", grid_column_start = "foot", grid_column_end = "foot" })
    tiles := t.AddNode(cssbox.Style { display = cssbox.Display.Grid, width = cssbox.Px(250.0), grid_template_columns = "repeat(auto-fill, minmax(70px, 1fr))", grid_auto_flow = cssbox.GridAutoFlow.Row, column_gap = cssbox.Px(4.0) })
    each c in [head, side, body, foot]:
        t.AddChild(page, c)
    end
    repeat 4:
        tile := t.AddNode(cssbox.Style { height = cssbox.Px(20.0) })
        t.AddChild(tiles, tile)
    end
    t.Compute(page, cssbox.MaxContentSpace(), cssbox.MaxContentSpace())
    each id in [page, head, side, body, foot]:
        l := t.Layout(id)
        println id, l.x, l.y, l.width, l.height
    end
    t.Compute(tiles, cssbox.MaxContentSpace(), cssbox.MaxContentSpace())
    repeat t.ChildCount(tiles) in i:
        l := t.Layout(t.Child(tiles, i))
        println "tile", i, l.x, l.y, l.width
    end
    println cssbox.IsTrackList("1fr [mid] minmax(40px, 2fr)"), cssbox.IsTrackSizes("50px auto"), cssbox.IsGridLine("span 2"), cssbox.IsGridAreas("'a b' 'a c'")
end

A table with spans and a caption

Column widths come from the cells' content. The first cell spans two rows and is centred vertically, the last spans two columns, and the caption sits below. The table then switches to a fixed 300 pixel layout with collapsed borders: the four columns share the width equally and each cell keeps half of every shared border. A table of 200 rows and 5 measured columns takes about 0.7 to 1 ms the first time and about 0.4 to 0.5 ms after one cell changes.

gui-cssbox-guide-table.salam
import gui.cssbox

func main:
    mut t := cssbox.Tree {}
    defer t.Free()
    table := t.AddNode(cssbox.Style { display = cssbox.Display.Table, border_spacing_x = 4.0, border_spacing_y = 2.0, border = cssbox.AllSides(cssbox.Px(1.0)) })
    caption := t.AddNode(cssbox.Style { display = cssbox.Display.TableCaption, caption_side = cssbox.CaptionSide.Bottom, height = cssbox.Px(16.0) })
    body := t.AddNode(cssbox.Style { display = cssbox.Display.TableRowGroup })
    t.AddChild(table, caption)
    t.AddChild(table, body)
    widths := [30.0, 80.0, 50.0, 40.0, 120.0]
    mut cells := Vector {} as Vector<int>
    defer cells.free()
    repeat 2 in r:
        row := t.AddNode(cssbox.Style { display = cssbox.Display.TableRow })
        t.AddChild(body, row)
        repeat 3 - r in c:
            mut st := cssbox.Style { display = cssbox.Display.TableCell, border = cssbox.AllSides(cssbox.Px(2.0)), padding = cssbox.AllSides(cssbox.Px(2.0)), vertical_align = cssbox.VerticalAlign.Middle }
            if r == 1 and c == 1:
                st.col_span = 2
            end
            if r == 0 and c == 0:
                st.row_span = 2
            end
            cell := t.AddNode(st)
            inner := t.AddNode(cssbox.Style { width = cssbox.Px(widths[r * 3 + c]), height = cssbox.Px(12.0 + (r as f64) * 10.0) })
            t.AddChild(cell, inner)
            t.AddChild(row, cell)
            cells.push(cell)
        end
    end
    t.Compute(table, cssbox.MaxContentSpace(), cssbox.MaxContentSpace())
    tl := t.Layout(table)
    println "table", tl.width, tl.height
    each c in cells:
        l := t.Layout(c)
        println "cell", c, l.x, l.y, l.width, l.height
    end
    cl := t.Layout(caption)
    println "caption", cl.y, cl.width
    mut fixed := t.GetStyle(table)
    fixed.table_layout = cssbox.TableLayout.Fixed
    fixed.width = cssbox.Px(300.0)
    fixed.border_collapse = cssbox.BorderCollapse.Collapse
    t.SetStyle(table, fixed)
    t.Compute(table, cssbox.MaxContentSpace(), cssbox.MaxContentSpace())
    each c in cells:
        l := t.Layout(c)
        println "fixed", c, l.x, l.width, l.border.left
    end
    mut first := t.GetStyle(cells[0])
    first.border_kinds = cssbox.BorderKinds { top = cssbox.BorderKind.Hidden, right = cssbox.BorderKind.Double, bottom = cssbox.BorderKind.Solid, left = cssbox.BorderKind.Dashed }
    t.SetStyle(cells[0], first)
    t.Compute(table, cssbox.MaxContentSpace(), cssbox.MaxContentSpace())
    mut segs := t.CollapsedBorders(table)
    defer segs.free()
    println "segments", segs.len()
    s0 := segs[0]
    println "segment", s0.x, s0.y, s0.width, s0.height, s0.node, s0.side, s0.vertical
end

LengthKind

enum LengthKind
What a Length holds: auto, pixels, a percentage or a sizing keyword.
NameTypeDescription
AutoThe CSS auto value.
PxA length in logical pixels.
PercentA percentage of the containing block; value is the CSS number, so 50 means 50%.
MinContentThe min-content keyword: as narrow as the content allows.
MaxContentThe max-content keyword: as wide as the content wants without wrapping.
FitContentThe fit-content keyword: max-content, but never wider than the space available.
StretchThe stretch keyword: fill the containing block minus margins.

import gui.cssbox

func main:

    s := cssbox.Stretch()

    println sp.kind == cssbox.SpaceKind.Definite, sp.value, cssbox.MinContentSpace().kind == cssbox.SpaceKind.MinContent
    mut t := cssbox.Tree {}
    defer t.Free()
    root := t.AddNode(cssbox.Style { width = cssbox.Px(200.0), overflow_y = cssbox.Overflow.Scroll, scrollbar_width = 12.0, height = cssbox.Px(50.0), border = cssbox.AllSides(cssbox.Px(3.0)), padding = cssbox.AllSides(cssbox.Px(5.0)) })
    child := t.AddNode(cssbox.Style { height = cssbox.Px(90.0) })

    t.Compute(root, cssbox.MaxContentSpace(), cssbox.MaxContentSpace())
    l := t.Layout(root)
    println l.x, l.y, l.abs_x, l.abs_y, l.width, l.height
    println l.content_x, l.content_y, l.content_width, l.content_height
    println l.padding.top, l.padding.right, l.padding.bottom, l.padding.left
    println l.border.top, l.border.right, l.border.bottom, l.border.left, l.margin.top
    println l.scrollbar_width, l.scrollbar_height, l.scroll_width, l.scroll_height, l.has_baseline, l.baseline
end

enum Display
The CSS display property.
NameTypeDescription
BlockA block box laid out with block flow and margin collapsing.
InlineBlockTreated as a block that shrinks to fit its content and starts a new formatting context; inline flow is not done yet.
FlowRootA block that starts a new block formatting context, so its children's margins do not collapse through it.
FlexA flex container laid out with the CSS flexbox algorithm.
InlineFlexA flex container that shrinks to fit inside a block parent.
ContentsThe box itself disappears and its children take its place in the parent.
NoneThe box and its subtree take no space and get a zero layout.
GridA grid container laid out with the CSS grid algorithm.
InlineGridA grid container that shrinks to fit inside a block parent.
TableA table: its children are laid out with the CSS table model, and the box shrinks to fit its columns unless it has a width.
InlineTableA table that shrinks to fit inside a block parent.
TableRowGroupA group of rows, like tbody.
TableHeaderGroupA group of rows drawn first, like thead.
TableFooterGroupA group of rows drawn last, like tfoot.
TableRowA table row; its children are its cells.
TableCellA table cell, laid out inside like a block that starts a new formatting context.
