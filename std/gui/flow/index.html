gui.flow

The layout engine of the Salam style standard: column, row, grid, stack and flow layouts, positioning, scrolling and right to left, with incremental relayout.

import gui.flow
On this page

  2. Text through a measure function
  3. Types
  4. Constants and variables
  5. Functions

gui.flow computes the rectangle of every box of a native user interface. It implements exactly the layouts of the Salam style standard and nothing else: column and row (the flex model with grow, shrink, basis, wrapping, gaps, alignment and order), grid (track lists with pixels, percent, fr, auto, minmax, repeat, fit and content sizes, explicit lines, spans and auto placement), stack (every child in one cell) and flow (children placed like words, wrapped onto lines and baseline aligned). It is not a CSS engine: there is no display, float, block formatting context, margin collapsing or table.

You build a Tree, give every box a FlowStyle, give leaves such as text and images a measure function, and call Layout with the size of the window. Then X, Y, W and H give each box relative to its parent. The package depends on nothing else in gui; gui.ui maps the style of an element to a FlowStyle.

Things to know:

  • Every box is border box. Width and height include padding and border, and margins apply in every layout, auto margins included.
  • Lengths come resolved. em, rem, vw and vh are converted to pixels by the caller; only percent stays, because only the layout knows the reference.
  • Content is not crushed. min_width and min_height default to Auto(): a child of a row or column does not shrink below its min content width or content height, as in a browser. Set them to 0 to allow it, or give a child an overflow other than visible.
  • The flow layout has no gaps. It is formatted like inline text, so space its children with margins.
  • Absolute and fixed boxes keep their static position on an axis with no inset: where the parent's justify and align would place them as the only child.
  • A root fills the viewport when its width or height is auto; use Fit() to size it to its content.
  • Right to left mirrors rows, flow lines, grid columns, start and end. left and right stay physical.
  • Layout is incremental. Changing a style or a measure marks the box and its ancestors; Layout lays out only those again and reuses cached sizes elsewhere. LayoutCalls and MeasureCalls show the work done.

An application shell

A header, a body with a side bar and a scrolling content area, and a footer. The body has basis = 0, grows, and has min_height = 0, so its long content does not push the header and footer away (by default a child of a column is never shorter than its content); the content area scrolls instead, and ContentH tells how far. The same tree in right to left puts the side bar on the right.

gui-flow-guide-app.salam
import gui.flow

func show(t &: flow.Tree, name: str, id: int):
    println name, t.X(id), t.Y(id), t.W(id), t.H(id)
end

func build(t &: flow.Tree, dir: int): (int, int, int, int):
    app := t.Add(-1, flow.FlowStyle { direction = dir })
    header := t.Add(app, flow.FlowStyle { layout = flow.LAYOUT_ROW, height = flow.Px(48.0), padding = flow.Sides(flow.Px(0.0), flow.Px(16.0), flow.Px(0.0), flow.Px(16.0)), align = flow.ALIGN_CENTER, column_gap = flow.Px(12.0) })
    t.Add(header, flow.FlowStyle { width = flow.Px(32.0), height = flow.Px(32.0) })
    t.Add(header, flow.FlowStyle { grow = 1.0, height = flow.Px(20.0) })
    body := t.Add(app, flow.FlowStyle { layout = flow.LAYOUT_ROW, grow = 1.0, basis = flow.Px(0.0), min_height = flow.Px(0.0) })
    side := t.Add(body, flow.FlowStyle { width = flow.Px(180.0), border = flow.Sides(flow.Px(0.0), flow.Px(1.0), flow.Px(0.0), flow.Px(0.0)) })
    content := t.Add(body, flow.FlowStyle { grow = 1.0, padding = flow.All(flow.Px(16.0)), row_gap = flow.Px(8.0), overflow_y = flow.OVERFLOW_AUTO })
    repeat 30:
        t.Add(content, flow.FlowStyle { height = flow.Px(40.0), shrink = 0.0 })
    end
    footer := t.Add(app, flow.FlowStyle { height = flow.Px(24.0) })
    ret header, side, content, footer
end

func main:
    mut t := flow.NewTree()
    header, side, content, footer := build(t, flow.DIR_LTR)
    t.Layout(800.0, 600.0)
    show(t, "header", header)
    show(t, "side", side)
    show(t, "content", content)
    show(t, "footer", footer)
    println "content scrolls by", t.ContentH(content) - t.H(content)

    mut r := flow.NewTree()
    _, rside, rcontent, _ := build(r, flow.DIR_RTL)
    r.Layout(800.0, 600.0)
    show(r, "rtl side", rside)
    show(r, "rtl content", rcontent)
end

Text through a measure function

A leaf's measure function gets the available width and returns the size of the wrapped text. Here a one word label and a long paragraph sit in a row aligned on their baselines; the paragraph has basis = 0 and grows, so it takes the rest of the row and wraps when the window narrows. A layout with nothing changed does no work, and marking the paragraph dirty measures it once.

gui-flow-guide-text.salam
import gui.flow

func paragraph(t &: flow.Tree, parent: int, words: int): int:
    id := t.Add(parent, flow.FlowStyle {})
    t.SetMeasure(id, (_id: int, w: f64, _h: f64):
        mut per := words
        if w >= 0.0:
            per = ((w + 4.0) / 44.0) as int
            if per < 1:
                per = 1
            end
            if per > words:
                per = words
            end
        end
        lines := (words + per - 1) / per
        ret flow.Size { w = (per as f64) * 44.0 - 4.0, h = (lines as f64) * 18.0, baseline = 14.0 }
    end)
    ret id
end

func main:
    mut t := flow.NewTree()
    card := t.Add(-1, flow.FlowStyle { layout = flow.LAYOUT_ROW, align = flow.ALIGN_BASELINE, column_gap = flow.Px(12.0), padding = flow.All(flow.Px(8.0)), height = flow.Fit() })
    label := paragraph(t, card, 1)
    text := paragraph(t, card, 20)
    mut st := t.Style(text)
    st.grow = 1.0
    st.basis = flow.Px(0.0)
    t.SetStyle(text, st)
    each width in [600.0, 300.0, 600.0]:
        t.ResetCounters()
        t.Layout(width, 400.0)
        println "width", width, "card height", t.H(card), "text size", t.W(text), t.H(text), "label y", t.Y(label), "measures", t.MeasureCalls()
    end
    t.ResetCounters()
    t.Layout(600.0, 400.0)
    println "unchanged layout calls", t.LayoutCalls(), "measures", t.MeasureCalls()
    t.MarkDirty(text)
    t.Layout(600.0, 400.0)
    println "text changed, layout calls", t.LayoutCalls(), "measures", t.MeasureCalls()
end

Tree

struct Tree
A tree of boxes with integer ids. It keeps the results of the last layout and lays out again only what changed.
gui-flow-Tree.salam
import gui.flow

func main:
    mut t := flow.NewTree()
    root := t.Add(-1, flow.FlowStyle { row_gap = flow.Px(4.0) })
    a := t.Add(root, flow.FlowStyle { height = flow.Px(20.0) })
    b := t.Add(root, flow.FlowStyle {})
    t.SetMeasure(b, (_id: int, w: f64, _h: f64):
        mut lines := 1.0
        if w >= 0.0 and w < 200.0:
            lines = 2.0
        end
        ret flow.Size { w = 200.0, h = lines * 16.0, baseline = 12.0 }
    end)
    t.Layout(300.0, 200.0)
    println "valid", t.Valid(b), t.Valid(42), "count", t.Count()
    println "parent", t.Parent(b), "children", t.ChildCount(root), "second", t.Child(root, 1)
    println "b", t.X(b), t.Y(b), t.W(b), t.H(b), "baseline", t.Baseline(b)
    println "calls", t.LayoutCalls(), t.MeasureCalls()
    t.ResetCounters()
    t.Layout(300.0, 200.0)
    println "again", t.LayoutCalls(), t.MeasureCalls(), "dirty", t.IsDirty(root)

    mut st := t.Style(a)
    st.height = flow.Px(30.0)
    t.SetStyle(a, st)
    println "after SetStyle dirty", t.IsDirty(a), t.IsDirty(root), t.IsDirty(b)
    t.Layout(300.0, 200.0)
    println "b moved to", t.Y(b), "calls", t.LayoutCalls()

    t.MarkDirty(b)
    t.Layout(150.0, 200.0)
    println "narrow b", t.W(b), t.H(b)
    t.ClearMeasure(b)
    t.Move(b, root, 0)
    t.Layout(150.0, 200.0)
    println "b first", t.Child(root, 0), t.Y(a), t.H(b)
    t.Remove(a)
    println "removed", t.Valid(a), t.ChildCount(root)
    t.Free()
    println "freed", t.Count()
end

import gui.flow

func show(t &: flow.Tree, name: str, id: int):
    println name, t.X(id), t.Y(id), t.W(id), t.H(id)
end

func main:
    mut cols := Vector {} as Vector<flow.Track>
    cols.Push(flow.TrackLen(flow.Px(80.0)))
    cols.Push(flow.TrackMinMax(flow.TrackLen(flow.Px(60.0)), flow.TrackFr(1.0)))
    cols.Push(flow.TrackFit(flow.Px(100.0)))
    mut rows := Vector {} as Vector<flow.Track>
    rows.Push(flow.TrackLen(flow.Px(30.0)))
    rows.Push(flow.TrackAuto())

FlowStyle

struct FlowStyle
Every layout property of a box from the Salam style standard, typed and resolved except percent.
NameTypeDescription
layoutintHow the children are laid out: one of the LAYOUT_ constants. Default column.
row_gapLenSpace between rows, wrapped lines and grid rows. The flow layout ignores it.
column_gapLenSpace between items of a row, wrapped columns and grid columns. The flow layout ignores it.
alignintCross axis alignment of the children: start, center, end, stretch or baseline. Default stretch. In a grid it aligns items in their rows, in a stack vertically.
justifyintMain axis distribution: start, center, end, between, around or evenly. In a grid it distributes the columns, in a stack it places children horizontally.
align_contentintDistribution of wrapped lines, or of grid rows. Default start.
wrapbool = falseRow and column only: wrap children onto new lines when they do not fit.
reversebool = falseRow and column only: lay the children out from the end.
columnsVectorColumn track list of a grid.
rowsVectorRow track list of a grid.
auto_columnsTrackTrack for columns added past the list. Default auto.
auto_rowsTrackTrack for rows added past the list. Default auto.
auto_flowintHow grid items without a place are placed: one of the AUTO_FLOW_ constants.
growf64 = 0Share of positive free space this child takes in a row or column. Default 0.
shrinkf64 = 1Share of negative free space, weighted by the basis. Default 1.
basisLenStarting main size before growing and shrinking; auto uses the width or height, then the content.
align_selfintThis child's own cross axis alignment; auto uses the parent's align.
justify_selfintGrid and stack only: this child's horizontal alignment in its cell; auto stretches in a grid and uses the parent's justify in a stack.
columnint = 0Grid column line where the item starts, 1 based. A negative number counts from the end and puts the item's end edge on that line, so -1 is the last column. 0 places it automatically.
rowint = 0Grid row line, with the same rules as column.
column_spanint = 1Number of columns the item covers. Default 1.
row_spanint = 1Number of rows the item covers. Default 1.
orderint = 0Children with a smaller order come first in rows, columns, grids and flow; equal orders keep their order.
positionintOne of the POS_ constants.
insetEdgesTop, end, bottom, start, left and right offsets for absolute, fixed and sticky boxes. A side that is not set is auto.
layerint = 0Paint and hit test order among siblings, read back with Layer and PaintOrder; it does not change the layout.
widthLenBorder box width: a length, auto, fill, fit, min content or max content.
heightLenBorder box height, with the same kinds as width.
min_widthLenSmallest width. The default Auto() keeps a child of a row at least as wide as its min content (or its width, when that is smaller), unless its horizontal overflow is not visible; elsewhere it is 0. Set 0 to let a child shrink below its content.
min_heightLenSmallest height. The default Auto() keeps a child of a column at least as tall as its content (or its height, when that is smaller), unless its vertical overflow is not visible; elsewhere it is 0. Set 0 to let a child shrink below its content.
max_widthLenLargest width, or no limit. A min larger than the max wins.
max_heightLenLargest height, or no limit.
aspect_ratiof64 = 0Width divided by height; used when one of them is auto. 0 means none.
paddingEdgesSpace inside the border. Every box is border box: padding and border are part of the width and height.
marginEdgesSpace outside the border; an auto side takes the free space, which centres or pushes the box.
borderEdgesBorder widths; they take space like padding.

overflow_yintVertical overflow: one of the OVERFLOW_ constants. When one axis is not visible, visible on the other axis acts as auto.
visiblebool = trueFalse removes the box and its children from the layout.
directionintOne of the DIR_ constants. Changing it relays out the whole subtree.
text_alignintAlignment of the lines of a flow layout: one of the TEXT_ constants.

func main:
    mut t := flow.NewTree()
    page := t.Add(-1, flow.FlowStyle { layout = flow.LAYOUT_STACK, overflow_x = flow.OVERFLOW_HIDDEN, overflow_y = flow.OVERFLOW_SCROLL })
    content := t.Add(page, flow.FlowStyle { height = flow.Px(900.0), width = flow.Fill() })
    mut top := flow.FlowStyle { position = flow.POS_STICKY, height = flow.Px(40.0) }
    top.inset.top = flow.Px(0.0)
    bar := t.Add(content, top)
    mut corner := flow.FlowStyle { position = flow.POS_ABSOLUTE, width = flow.Px(50.0), height = flow.Px(20.0), layer = 1 }
    corner.inset.end = flow.Px(10.0)
    corner.inset.top = flow.Px(10.0)
    badge := t.Add(content, corner)
    mut fab := flow.FlowStyle { position = flow.POS_FIXED, width = flow.Px(48.0), height = flow.Px(48.0), layer = 2 }
    fab.inset.right = flow.Px(16.0)
    fab.inset.bottom = flow.Px(16.0)
    button := t.Add(content, fab)
    t.Layout(300.0, 400.0)
    println "content size", t.ContentW(page), t.ContentH(page)
    t.SetScroll(page, 0.0, 120.0)
    println "scroll", t.ScrollX(page), t.ScrollY(page)
    show(t, "bar", bar)
    show(t, "badge", badge)
    show(t, "button", button)
    println "button on screen", t.AbsX(button), t.AbsY(button)
    print "paint order"
    order := t.PaintOrder(content)
    each id in order:
        print " ", id, "layer", t.Layer(id)
    end
    println ""
    order.Free()
    println "positions", flow.POS_NORMAL, flow.POS_ABSOLUTE, flow.POS_FIXED, flow.POS_STICKY
    println "overflow", flow.OVERFLOW_VISIBLE, flow.OVERFLOW_HIDDEN, flow.OVERFLOW_SCROLL, flow.OVERFLOW_AUTO

    mut p := flow.NewTree()
    para := p.Add(-1, flow.FlowStyle { layout = flow.LAYOUT_FLOW, text_align = flow.TEXT_CENTER, width = flow.Px(100.0), height = flow.Fit() })
    mut words := Vector {} as Vector<int>
    repeat 4:
        id := p.Add(para, flow.FlowStyle { margin = flow.Sides(flow.Px(0.0), flow.Px(2.0), flow.Px(0.0), flow.Px(2.0)) })

        words.Push(id)

    p.Layout(300.0, 300.0)
    each i, id in words:
        show(p, "word" + i, id)
    end
    println "paragraph baseline", p.Baseline(para)
    println "text aligns", flow.TEXT_START, flow.TEXT_CENTER, flow.TEXT_END, flow.TEXT_JUSTIFY, flow.TEXT_LEFT, flow.TEXT_RIGHT
end
