gui.paint

A pure Salam 2D painter for CSS boxes: rounded rectangles, borders, gradients, shadows, images, paths, clipping and layers, with the same pixels on every system.

import gui.paint
On this page

  2. Repainting only what changed
  3. Types
  4. Functions

This package is the drawing layer of the native user interface: it paints everything a CSS box can look like into a pixel buffer, in pure Salam, with the same pixels on every operating system. A Canvas holds premultiplied 32-bit pixels (0xAARRGGBB, so B, G, R, A bytes in memory), which X11, Win32, Cocoa and Wayland windows can show without a copy. Colours in the API are ordinary straight RGBA, as in CSS.

A box is painted in the CSS order: DrawShadow, then the background with FillRoundedRect, FillGradient or DrawImage, then DrawBorder, the content, and DrawOutline. Rounded corners take a horizontal and a vertical radius per corner and are scaled down the way CSS does when they do not fit. Edges are anti-aliased with exact coverage computed line by line in fixed point, borders have a width, colour and style (solid, dashed, dotted) per side, and shadows are Gaussian blurs computed analytically, outside or inside the box.

Clips (PushClip, PushRoundedClip), transforms and offscreen layers with group opacity (BeginLayer, EndLayer) are stacks. SetRegion limits drawing to a damage region of at most three rectangles, and drawing a scene in parts gives exactly the same pixels as drawing it at once. FillPath and StrokePath draw vector paths with lines, curves, arcs, caps, joins and dashes, and DrawMask draws text glyphs from a coverage mask.

Things to know

  • Coordinates are logical pixels as f64. Fractional edges are anti-aliased; images, clips and layers snap to whole pixels.
  • Rasterization uses integers and fixed point only, so a picture is meant to have the same hash on every system and backend. Tests compare Hash() and a few pixels.
  • Every drawing call follows the whole transform, rotation and skew included. Borders, gradients, shadows and tiled images under a rotation or skew are drawn upright in a scratch layer and then resampled, and a clip under a rotation becomes a coverage mask.
  • Dashed and dotted sides are patterned along their rounded corners too, with the pattern spaced so that each corner gets a whole dash or dot.
  • Filters work on layers: BeginFilterLayer and EndLayerFiltered give CSS filter, and BackdropFilter gives backdrop-filter, compared with Chromium on opaque, translucent and nested backdrops. Colour filters work on straight colours in sRGB, as browsers do, and blurs use three box blurs, as the filter specification describes.
  • DrawNineSlice draws an image cut into nine parts around a rectangle, the way CSS border-image does, with stretched, repeated, rounded or spaced edges.
  • Free every canvas, path and gradient you make. A canvas from WrapCanvas or Sub still needs Free for its scratch memory, but leaves the pixels alone.
  • The benchmark in tools/bench/paint_frame.salam draws 200 rounded boxes with a shadow, a background and a border over a full screen gradient at 1920x1080.

Painting a CSS box

A box is painted in the order CSS uses: the shadow first, then the background, then the border, and the outline last. All of them take the same rectangle and radii, so the shadow, the gradient and the border line up exactly. The outer shadow is cut out under the box, so a translucent background does not show it.

gui-paint-guide-card.salam
import gui.paint

func main:
    mut cv := paint.NewCanvas(160, 100)
    cv.Clear(paint.Rgb(240, 242, 247))
    box := paint.RectOf(20.0, 20.0, 120.0, 60.0)
    radii := paint.Corners(16.0, 16.0, 4.0, 4.0)
    cv.DrawShadow(box, radii, paint.Shadow { offset_y = 4.0, blur = 12.0, color = paint.Rgba(20, 30, 60, 80) })
    mut bg := paint.LinearGradient(180.0)
    bg.AddStop(0.0, paint.Rgb(255, 255, 255))
    bg.AddStop(1.0, paint.Rgb(226, 234, 252))
    cv.FillGradient(box, radii, bg)
    bg.Free()
    cv.DrawBorder(box, radii, paint.SolidBorder(1.5, paint.Rgb(150, 170, 220)))
    cv.DrawOutline(box, radii, 2.0, 2.0, paint.Rgba(60, 110, 230, 160))
    top := cv.Pixel(80, 24)
    bottom := cv.Pixel(80, 75)
    println "top of the card:", top.r, top.g, top.b
    println "bottom of the card:", bottom.r, bottom.g, bottom.b
    println "hash:", cv.Hash()
    cv.Free()
end
Outputtop of the card: 253 253 255 bottom of the card: 228 236 252 hash: a7600df3ad82d161

Repainting only what changed

When something moves, only its old and new places need painting. Put both rectangles in a Region, set it with SetRegion and draw the whole scene as usual: everything outside the region is left alone. Coverage is computed for the whole shape and only then clipped, so the result is the same, pixel for pixel, as painting everything again.

gui-paint-guide-damage.salam
import gui.paint

func draw(cv &: paint.Canvas, x: f64):
    cv.Clear(paint.Rgb(255, 255, 255))
    cv.FillRoundedRect(paint.RectOf(x, 10.0, 30.0, 30.0), paint.Uniform(8.0), paint.Rgb(230, 80, 40))
end

func main:
    mut screen := paint.NewCanvas(100, 50)
    draw(screen, 10.0)
    mut damage := paint.Region {}
    damage.Add(paint.IntRectOf(10, 10, 30, 30))
    damage.Add(paint.IntRectOf(50, 10, 30, 30))
    screen.SetRegion(damage)
    draw(screen, 50.0)
    screen.ClearRegion()
    mut fresh := paint.NewCanvas(100, 50)
    draw(fresh, 50.0)
    println "rectangles repainted:", damage.Count()
    println "same as a full repaint:", screen.Hash() == fresh.Hash()
    fresh.Free()
    screen.Free()
end
Outputrectangles repainted: 2 same as a full repaint: true

Types

BorderStyle

enum BorderStyle
How one side of a border is drawn.
NameTypeDescription
NoneNo line on this side.
SolidA solid line.
DashedDashes as Chromium draws them: twice the side width long with gaps as wide as the side when the side is 3 pixels or wider, and three times long with gaps twice as wide when it is thinner. The gap is stretched or shrunk so that both ends of the side get a whole dash.
DottedRound dots as wide as the side, spaced so that both ends get a dot. On straight sides the dots snap to whole pixels, so thin dotted lines stay crisp.
gui-paint-Box.salam
import gui.paint

func main:
    mut cv := paint.NewCanvas(120, 80)

gui-paint-Image.salam
import gui.paint
import os
import filepath

func main:
    mut tile := paint.NewCanvas(2, 2)
    tile.Clear(paint.Rgb(230, 230, 230))
    tile.FillRect(paint.RectOf(0.0, 0.0, 1.0, 1.0), paint.Rgb(90, 90, 90))
    tile.FillRect(paint.RectOf(1.0, 1.0, 1.0, 1.0), paint.Rgb(90, 90, 90))
    mut cv := paint.NewCanvas(80, 60)
    cv.DrawImageTiled(tile, paint.RectOf(0.0, 0.0, 80.0, 60.0), paint.RectOf(0.0, 0.0, 8.0, 8.0), 1.0)
    photo := paint.FitImage(paint.ObjectFit.Contain, 4, 2, paint.RectOf(10.0, 10.0, 60.0, 40.0), 0.5, 0.5)
    println "photo box:", photo.x, photo.y, photo.width, photo.height
    cv.PushRoundedClip(photo, paint.Uniform(6.0))
    cv.BeginLayer(photo)
    cv.FillRect(photo, paint.Rgb(0, 120, 255))
    cv.FillRect(paint.RectOf(30.0, 20.0, 20.0, 20.0), paint.Rgb(255, 60, 60))
    cv.EndLayer(0.8)
    cv.PopClip()
    path := filepath.Join(os.TempDir(), "salam_paint_example.png")
    println "saved:", paint.SavePNG(cv, path)
    mut ok := false
    mut back := paint.LoadPNG(path, ok)
    println "loaded:", ok, back.width, back.height, back.Hash() == cv.Hash()
    os.Remove(path)
    back.Free()
    tile.Free()
    cv.Free()
end
Outputphoto box: 10 15 60 30 saved: true loaded: true 80 60 true

gui-paint-Path.salam
import gui.paint

func main:
    mut cv := paint.NewCanvas(100, 60)
    cv.Clear(paint.Rgb(255, 255, 255))
    mut star := paint.NewPath()
    star.MoveTo(30.0, 5.0)
    star.LineTo(42.0, 52.0)
    star.LineTo(5.0, 22.0)
    star.LineTo(55.0, 22.0)
    star.LineTo(18.0, 52.0)
    star.Close()
    cv.FillPath(star, paint.FillRule.EvenOdd, paint.Rgb(250, 190, 0))
    cv.StrokePath(star, paint.Stroke { width = 2.0, join = paint.LineJoin.Round }, paint.Rgb(120, 60, 0))
    star.Free()
    mut wave := paint.NewPath()
    wave.MoveTo(0.0, 0.0)
    wave.CubicTo(10.0, -15.0, 20.0, 15.0, 30.0, 0.0)
    cv.Translate(62.0, 30.0)
    cv.StrokePath(wave, paint.Stroke { width = 3.0, cap = paint.LineCap.Round, dash = 6.0, gap = 4.0 }, paint.Rgb(0, 100, 200))
    cv.PopTransform()
    wave.Free()
    println "middle of the star is a hole:", cv.Pixel(30, 30).b == 255
    println "point of the star:", cv.Pixel(30, 12).g
    println "hash:", cv.Hash()
    cv.Free()
end

gui-paint-Filter.salam
import gui.paint

func main:
    mut cv := paint.NewCanvas(120, 60)
    cv.Clear(paint.Rgb(255, 255, 255))
    repeat 6 in i:
        cv.FillRect(paint.RectOf((i * 20) as f64, 0.0, 10.0, 60.0), paint.Rgb(30, 30, 30))
    end
    mut glass := paint.FilterChain {}
    glass.Add(paint.NewFilter(paint.FilterKind.Blur, 3.0))
    glass.Add(paint.NewFilter(paint.FilterKind.Brightness, 1.3))
    cv.BackdropFilter(paint.RectOf(4.0, 4.0, 50.0, 30.0), paint.Uniform(6.0), glass)
    glass.Free()
    mut look := paint.FilterChain {}
    look.Add(paint.NewFilter(paint.FilterKind.Sepia, 1.0))
    look.Add(paint.DropShadowFilter(3.0, 3.0, 2.0, paint.Rgba(0, 0, 0, 160)))
    println "room around the layer:", look.Extent(), "empty:", look.IsEmpty()
    tile := paint.RectOf(70.0, 10.0, 30.0, 30.0)
    cv.BeginFilterLayer(tile, look)
    cv.FillRoundedRect(tile, paint.Uniform(6.0), paint.Rgb(40, 120, 220))
    cv.EndLayerFiltered(look, 1.0)
    look.Free()
    println "frosted glass is grey:", cv.Pixel(14, 20).r > 60
    println "sepia tile:", cv.Pixel(85, 25).r > cv.Pixel(85, 25).b
    println "hash:", cv.Hash()
    cv.Free()
end
Outputroom around the layer: 12 empty: false frosted glass is grey: true sepia tile: true hash: 547e5fb9c6152229

import gui.paint

func main:
    mut cv := paint.NewCanvas(120, 80)
    cv.Clear(paint.Rgb(255, 255, 255))
    turn := paint.Translation(-30.0, -20.0).Then(paint.Rotation(20.0)).Then(paint.Skewing(10.0, 0.0)).Then(paint.Translation(45.0, 40.0))
    cv.PushTransform(turn)
    card := paint.RectOf(0.0, 0.0, 60.0, 40.0)
    cv.DrawShadow(card, paint.Uniform(8.0), paint.Shadow { offset_y = 3.0, blur = 6.0, color = paint.Rgba(0, 0, 0, 90) })
    cv.FillRoundedRect(card, paint.Uniform(8.0), paint.Rgb(250, 240, 200))
    mut b := paint.SolidBorder(3.0, paint.Rgb(200, 60, 0))
    b.top_style = paint.BorderStyle.Dashed
    b.bottom_style = paint.BorderStyle.Dotted
    cv.DrawBorder(card, paint.Uniform(8.0), b)
    cv.PushRoundedClip(paint.RectOf(10.0, 10.0, 40.0, 20.0), paint.Uniform(6.0))
    cv.FillRect(paint.RectOf(0.0, 0.0, 60.0, 40.0), paint.Rgba(0, 90, 200, 120))
    cv.PopClip()
    cv.PopTransform()
    cv.DrawOutlineStyled(paint.RectOf(90.0, 20.0, 20.0, 40.0), paint.Uniform(4.0), 2.0, 3.0, paint.Rgb(0, 0, 0), paint.BorderStyle.Dotted)
    corner := turn.Apply(paint.Point { x = 0.0, y = 0.0 })
    back := turn.Invert().Apply(corner)
    box := turn.MapRect(card)
    println "card corner on screen:", corner.x > 10.0, corner.y < 20.0
    println "back to the card:", back.x > -0.001 and back.x < 0.001
    println "screen box wider than the card:", box.width > 60.0
    println "identity:", paint.Identity().IsIdentity(), turn.IsIdentity()
    println "hash:", cv.Hash()
    cv.Free()
end

import gui.paint

func main:
    mut frame := paint.NewCanvas(30, 30)
    frame.Clear(paint.Rgb(40, 90, 200))
    frame.FillRect(paint.RectOf(10.0, 10.0, 10.0, 10.0), paint.Rgb(240, 240, 240))
    frame.FillRect(paint.RectOf(0.0, 0.0, 10.0, 10.0), paint.Rgb(220, 50, 50))
    mut ns := paint.NineSlice { slice_top = 10.0, slice_right = 10.0, slice_bottom = 10.0, slice_left = 10.0 }
    ns.width_top = 6.0
    ns.width_right = 6.0
    ns.width_bottom = 6.0
    ns.width_left = 6.0
    ns.repeat_x = paint.ImageRepeat.Round
    ns.repeat_y = paint.ImageRepeat.Stretch

    mut cv := paint.NewCanvas(100, 60)
    cv.Clear(paint.Rgb(255, 255, 255))
    cv.DrawNineSlice(frame, paint.RectOf(4.0, 4.0, 92.0, 52.0), ns, 1.0)
    c := cv.Pixel(6, 6)
    println "corner:", c.r, c.g, c.b
    m := cv.Pixel(50, 30)
    println "middle:", m.r, m.g, m.b
    println "hash:", cv.Hash()
    cv.Free()
    frame.Free()
