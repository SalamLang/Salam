gui.raylib

Games and graphics with raylib: windows, 2D and 3D drawing, textures, text, input and audio.

import gui.raylib

This package binds raylib 5.5, a small library for 2D and 3D games and graphics programs. It opens a window with an OpenGL context, and gives drawing of shapes, textures, text and 3D models, keyboard, mouse, gamepad and touch input, and sound and music. The names are the ones of the raylib cheat sheet, so every raylib tutorial reads almost the same in Salam.

Use it for games, visual toys, tools with a custom picture and teaching programs. For forms and buttons use a layout or the webview package, and for pictures that are only saved to a file the image package needs no outside library.

Things to know

  • Programs link against the raylib shared library (libraylib, version 5.5). Install it with your package manager or build it from source; if it is missing, the build fails at the link step.
  • Raylib passes Color, Vector2, Rectangle, Camera3D and the other structs by value. Salam passes them the way the C compiler of the platform does, on x86-64 (System V and Windows) and AArch64. The --backend=native compiler refuses such calls with a clear message; use the default backend.
  • Raylib works with 32-bit floats. Every function that takes a f32 also has a version that takes f64, so DrawCircle(400, 225, 50.0, Red()) works. Struct fields are f32; build vectors and rectangles with Vec2, Vec3 and Rect.
  • Colors are functions: Red(), RayWhite(), Blank(). Build your own with RGB and RGBA.
  • Functions that change a value in place, such as ImageResize and UpdateCamera, take a variable and need it declared with mut.
  • Strings returned by raylib, such as GetMonitorName, belong to raylib: copy them if you keep them and never free them.
  • Everything you load (LoadTexture, LoadSound, LoadModel, ...) has an Unload call; raylib does not free it for you before the window closes.
  • The window needs a desktop session, so the examples on this page are only type-checked by the site.

A bouncing ball

Every raylib program has the same shape: open a window, ask for a frame rate, then loop until WindowShouldClose, drawing between BeginDrawing and EndDrawing. GetFrameTime gives the seconds since the last frame, which keeps movement the same speed on every machine.

gui-raylib-guide-ball.salam
import gui.raylib

func main:
    raylib.InitWindow(800, 450, "Bouncing ball")
    raylib.SetTargetFPS(60)
    mut x := 400.0
    mut y := 225.0
    mut dx := 240.0
    mut dy := 180.0
    until not raylib.WindowShouldClose():
        dt := raylib.GetFrameTime() as f64
        x += dx * dt
        y += dy * dt
        if x < 20.0 or x > 780.0:
            dx = 0.0 - dx
        end
        if y < 20.0 or y > 430.0:
            dy = 0.0 - dy
        end
        raylib.BeginDrawing()
        raylib.ClearBackground(raylib.RayWhite())
        raylib.DrawCircle(x as int, y as int, 20.0, raylib.Maroon())
        raylib.DrawText("Close the window to quit", 10, 10, 20, raylib.DarkGray())
        raylib.EndDrawing()
    end
    raylib.CloseWindow()
end

Keyboard and collisions

IsKeyDown reports a key that is held, IsKeyPressed only the frame it went down. CheckCollisionRecs tests two rectangles, which is enough for many 2D games: try the move first and keep it only when it does not hit the wall.

gui-raylib-guide-input.salam
import gui.raylib

func main:
    raylib.InitWindow(800, 450, "Move the square")
    raylib.SetTargetFPS(60)
    mut px := 100.0
    mut py := 100.0
    wall := raylib.Rect(500.0, 150.0, 60.0, 150.0)
    until not raylib.WindowShouldClose():
        dt := raylib.GetFrameTime() as f64
        mut nx := px
        mut ny := py
        if raylib.IsKeyDown(raylib.KEY_RIGHT): nx += 200.0 * dt end
        if raylib.IsKeyDown(raylib.KEY_LEFT): nx -= 200.0 * dt end
        if raylib.IsKeyDown(raylib.KEY_DOWN): ny += 200.0 * dt end
        if raylib.IsKeyDown(raylib.KEY_UP): ny -= 200.0 * dt end
        player := raylib.Rect(nx, ny, 40.0, 40.0)
        if not raylib.CheckCollisionRecs(player, wall):
            px = nx
            py = ny
        end
        raylib.BeginDrawing()
        raylib.ClearBackground(raylib.RayWhite())
        raylib.DrawRectangleRec(wall, raylib.DarkGray())
        raylib.DrawRectangle(px as int, py as int, 40, 40, raylib.Blue())
        raylib.DrawText("Arrow keys move the square", 10, 10, 20, raylib.Gray())
        raylib.EndDrawing()
    end
    raylib.CloseWindow()
end

A 3D scene

3D drawing sits between BeginMode3D and EndMode3D and uses a Camera3D. UpdateCamera with CAMERA_ORBITAL turns the camera around its target; it changes the camera, so declare it with mut.

gui-raylib-guide-3d.salam
import gui.raylib

func main:
    raylib.InitWindow(800, 450, "3D cube")
    raylib.SetTargetFPS(60)
    mut camera := raylib.NewCamera3D(raylib.Vec3(6.0, 6.0, 6.0), raylib.Vec3(0.0, 1.0, 0.0), raylib.Vec3(0.0, 1.0, 0.0), 45.0, raylib.CAMERA_PERSPECTIVE)
    until not raylib.WindowShouldClose():
        raylib.UpdateCamera(camera, raylib.CAMERA_ORBITAL)
        raylib.BeginDrawing()
        raylib.ClearBackground(raylib.RayWhite())
        raylib.BeginMode3D(camera)
        raylib.DrawCube(raylib.Vec3(0.0, 1.0, 0.0), 2.0, 2.0, 2.0, raylib.Red())
        raylib.DrawCubeWires(raylib.Vec3(0.0, 1.0, 0.0), 2.0, 2.0, 2.0, raylib.Maroon())
        raylib.DrawGrid(10, 1.0)
        raylib.EndMode3D()
        raylib.DrawFPS(10, 10)
        raylib.EndDrawing()
    end
    raylib.CloseWindow()
end

func main:
    raylib.InitWindow(400, 300, "Sound")
    raylib.InitAudioDevice()
    beep := raylib.LoadSound("beep.wav")
    until not raylib.WindowShouldClose():
        if raylib.IsKeyPressed(raylib.KEY_SPACE):
            raylib.PlaySound(beep)
        end
        raylib.BeginDrawing()
        raylib.ClearBackground(raylib.RayWhite())
