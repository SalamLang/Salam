gui.typeset

Text for the native UI: fonts, fallback, OpenType shaping, bidi, line breaking, paragraph layout, glyph masks and caret geometry.

import gui.typeset
On this page
  1. Lay out a mixed Persian and English paragraph
  2. Caret and selection in a text input
  3. Types
  4. Constants and variables
  5. Functions

This package turns styled text into lines of positioned glyphs and draws those glyphs as coverage masks. It is the text half of the native UI runtime: the page language uses it to lay out every heading, paragraph and input, and a painter blends its masks into pixels. It is written in Salam with no outside library, and Persian and mixed Persian and English text are the main case it is built for.

The steps are the ones a browser takes. A FontCollection holds fonts, picks a face for every character from a family list like CSS font-family and falls back per script to other faces, the system fonts included. NewParagraph splits styled spans into bidi, script and font runs and shapes each run once with the font's OpenType tables: joining forms, ligatures, kerning and mark positioning. LayoutParagraph breaks lines at any width without shaping again, reorders each line for right to left text and aligns it. RasterizeGlyph and GlyphCache give 8 bit masks, and HitTest, CaretRect and SelectionRects give the geometry an editor needs.

Things to know

  • TrueType outlines only. Fonts with CFF outlines (most .otf files) are skipped by the collection and refused by LoadFont.
  • Offsets are UTF-8 byte offsets into Paragraph.text, the span texts joined together. SpanAt maps an offset back to its span, and every glyph run carries the tag of its span.
  • Layout math is fixed point in 1/64 pixel and masks are made with integer math, so the numbers and the pixels are the same on every OS and backend.
  • When a font has no Arabic joining features the shaper uses the Unicode presentation forms instead, like std/ai/image always did; that package now uses this one for its fonts.
  • A mask from CachedGlyph belongs to the cache and stays valid until a later call may evict it; draw it before asking for more.
  • The examples read fonts from the books/fonts folder of the Salam repository.

Lay out a mixed Persian and English paragraph

Each span has its own family list and size; the tag lets you find which element a run came from. The paragraph is shaped once, then laid out at two widths. In this right to left paragraph the English word keeps its own left to right order inside the line, and every line is aligned to the right, the start side.

typeset-guide-paragraph.salam
import gui.typeset
import os
import filepath

func main:
    fonts := filepath.Join(filepath.Dir(os.Env("SALAM_STD")), "books/fonts/")
    mut fc := typeset.NewFontCollection()
    typeset.AddFontFile(fc, fonts + "XB Zar.ttf")
    typeset.AddFontFile(fc, fonts + "DejaVuSansMono.ttf")
    mut spans := Vector {} as Vector<typeset.TextSpan>
    spans.push(typeset.TextSpan { text = "زبان برنامه‌نویسی ", families = "XB Zar", size = 20.0, tag = 1 })
    spans.push(typeset.TextSpan { text = "Salam", families = "DejaVu Sans Mono", size = 16.0, tag = 2 })
    spans.push(typeset.TextSpan { text = " متن فارسی را درست می‌چیند.", families = "XB Zar", size = 20.0, tag = 3 })
    mut p := typeset.NewParagraph(fc, spans, typeset.ParagraphStyle {})
    println "min", typeset.MinContentWidth(p), "max", typeset.MaxContentWidth(p)
    each width in [400.0, 160.0]:
        mut l := typeset.LayoutParagraph(p, fc, width)
        println "width", width, "lines", l.lines.len(), "height", l.height
        each line in l.lines:
            print "  baseline ", line.baseline, ":"
            mut k := line.run_start
            until k < line.run_start + line.run_count:
                run := l.runs.get(k)
                if run.glyph_count > 0:
                    print " [tag ", run.tag, " x ", run.x, (run.rtl ? " rtl" : " ltr"), "]"
                end
                k++
            end
            println ""
        end
        typeset.FreeLayout(l)
    end
    typeset.FreeParagraph(p)
    spans.free()
    typeset.FreeFontCollection(fc)
end

MinContentWidth and MaxContentWidth are what a flex or table layout needs before it decides the width. Changing only the width calls LayoutParagraph again; the fonts and the shaping stay cached in the paragraph.

Caret and selection in a text input

An input keeps a TextPosition: a byte offset and whether it sticks to the text before it. HitTest turns a click into a position, MoveVisual moves it as the arrow keys do on screen, and CaretRect says where to draw it. On a line that mixes directions the caret walks through the English letters from right to left of the screen, the way the eye follows them.

typeset-guide-caret.salam
import gui.typeset
import os
import filepath

func main:
    mut fc := typeset.NewFontCollection()
    typeset.AddFontFile(fc, filepath.Join(filepath.Dir(os.Env("SALAM_STD")), "books/fonts/XB Zar.ttf"))
    mut spans := Vector {} as Vector<typeset.TextSpan>
    spans.push(typeset.TextSpan { text = "سلام ABC دنیا", families = "XB Zar", size = 20.0 })
    mut st := typeset.ParagraphStyle {}
    st.white_space = typeset.WhiteSpace.PreWrap
    mut p := typeset.NewParagraph(fc, spans, st)
    mut l := typeset.LayoutParagraph(p, fc, 0.0)
    mut pos := typeset.HitTest(p, l, l.width, 10.0)
    println "click at the right edge: offset", pos.offset
    repeat 6:
        pos = typeset.MoveVisual(p, l, pos, false)
        caret := typeset.CaretRect(p, l, pos)
        println "left arrow: offset", pos.offset, "caret x", caret.x
    end
    rects := typeset.SelectionRects(p, l, 6, 15)
    println "selection of 'م ABC د' needs", rects.len(), "rectangles"
    rects.free()
    typeset.FreeLayout(l)
    typeset.FreeParagraph(p)
    spans.free()
    typeset.FreeFontCollection(fc)
end

import gui.typeset
import os
import filepath

func main:
    mut fc := typeset.NewFontCollection()
    typeset.AddFontFile(fc, filepath.Join(filepath.Dir(os.Env("SALAM_STD")), "books/fonts/XB Zar.ttf"))
    mut spans := Vector {} as Vector<typeset.TextSpan>
    spans.push(typeset.TextSpan { text = "نام Salam است", families = "XB Zar", size = 20.0 })
    mut st := typeset.ParagraphStyle {}
    st.white_space = typeset.WhiteSpace.PreWrap
    mut p := typeset.NewParagraph(fc, spans, st)
    mut l := typeset.LayoutParagraph(p, fc, 0.0)
    hit := typeset.HitTest(p, l, 40.0, 10.0)
    println hit.offset, hit.upstream, hit.line
    caret := typeset.CaretRect(p, l, hit)
    println caret.x, caret.y, caret.width, caret.height
    rects := typeset.SelectionRects(p, l, 3, 12)
    each r in rects:
        println r.x, r.width
    end
    rects.free()
    println typeset.NextGrapheme(p, 0), typeset.PrevGrapheme(p, 4), typeset.NextWordEnd(p, 0), typeset.PrevWordStart(p, 12)
    mut pos := typeset.TextPosition { offset = 0 }
    repeat 4:
        pos = typeset.MoveVisual(p, l, pos, false)
        print pos.offset, " "
    end
    println ""
    typeset.FreeLayout(l)
    typeset.FreeParagraph(p)
    spans.free()

import gui.typeset
import os
import filepath

func main:
    mut ok := false
    mut f := typeset.LoadFont(filepath.Join(filepath.Dir(os.Env("SALAM_STD")), "books/fonts/XB Zar.ttf"), ok)
    gid := typeset.GlyphIndex(f, 0x0634)
    mut m := typeset.RasterizeGlyph(f, gid, 24.0, typeset.SubpixelOf(12.25))
    println m.width, m.height, m.stride, m.left, m.top, typeset.GlyphMaskHash(m)
    println typeset.GlyphOriginX(12.25, m), typeset.GlyphOriginY(30.0, m)
    bp := m.data as u8*
    repeat m.height in y:
        repeat m.width in x:
            print bp[y * m.stride + x] > (127 as u8) ? "#" : "."
        end
        println ""
    end
    typeset.FreeGlyphMask(m)
    mut cache := typeset.NewGlyphCache(65536)
    a := typeset.CachedGlyph(cache, f, gid, 24.0, 12.25)
    b := typeset.CachedGlyph(cache, f, gid, 24.0, 40.25)
    println a.width == b.width, cache.hits, cache.misses, cache.capacity, cache.bytes > 0, cache.clock, cache.slots.len(), cache.index.size()
    slot := cache.slots.get(0)
    println slot.key > (0 as i64), slot.mask.width, slot.stamp, slot.used
    typeset.FreeGlyphCache(cache)
    mut o := typeset.TransformedOutline(f, gid, 0.01, 0.0, 0.0, -0.01, 2.0, 20.0)
    pt := o.points.get(0)
    println o.points.len(), o.ends.len(), pt.on
    mut cov := typeset.OutlineCoverage(o, 64, 64)
    println cov.x, cov.y, cov.width, cov.height, cov.values.len()
    typeset.FreeCoverageRows(cov)
    typeset.FreeOutline(o)
    typeset.FreeFont(f)
end
