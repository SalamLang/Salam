image

Reading, editing and saving images, and writing text on them.

import image

This package works with images without any outside library: it reads and writes PNG, JPEG and BMP. It also reads and writes WebP, both lossy and lossless. From a GIF it reads the first frame, and it saves an image in a GIF with at most 256 colors. Open and Save work the format out from the content or the extension. Drawing, resizing, cropping, rotating and filters such as blurring and sharpening are all there.

For text, read a TrueType font with LoadFont and write with DrawTextStyled; Persian and Arabic text is shaped and laid out right to left on its own. Use this package for thumbnails, generated cards and charts, watermarks and simple image checks. For computer vision (edges, contours, feature matching) see opencv, and to draw in a browser page, web/canvas.

Things to know

  • Pixels are 8 bit RGBA in memory. Every image owns that memory; release it with Free.
  • Save picks the format from the extension and returns false for one it does not know. It uses quality 90; SaveQuality takes your own.
  • JPEG has no transparency: transparent pixels are laid on white before saving. WebP at quality 100 is lossless, below that lossy.
  • GIF reading gives only the first frame of an animation, and saving reduces the image to 256 colors.
  • Persian shaping uses the Arabic presentation forms of the font, so the font must contain them. FindArabicFont looks for an installed one that does (or the file in $SALAM_FONT_ARABIC).

Thumbnails and fixed-size cards

An upload form usually needs the same picture in several sizes. Thumbnail shrinks the image so that its longer side fits and keeps the shape. ResizeFill fills an exact box and cuts off what sticks out, which suits square avatars and product cards. ResizeFit keeps the whole picture inside the box and centers it, leaving empty bands at the sides. Save chooses the format from the extension, so the same code writes PNG, JPEG or WebP.

image-guide-thumbs.salam
import image

func size(img: image.Image): str:
    ret "" + img.width + "x" + img.height
end

func main:
    mut photo := image.New(1200, 800)
    defer image.Free(photo)
    image.FillHex(photo, "#3a6ea5")
    image.DrawCircleFilled(photo, 600, 400, 250, image.ParseHex("#f2c14e"))
    if image.Save(photo, "photo.jpg") == false:
        println "could not write photo.jpg"
        ret 1
    end

    mut ok := false
    mut loaded := image.Open("photo.jpg", ok)
    defer image.Free(loaded)
    println "opened:", ok, size(loaded)

    mut thumb := image.Thumbnail(loaded, 200)
    mut card := image.ResizeFill(loaded, 300, 300)
    mut banner := image.ResizeFit(loaded, 600, 200)
    defer image.Free(thumb)
    defer image.Free(card)
    defer image.Free(banner)
    println "thumbnail:", size(thumb)
    println "square card:", size(card)
    println "banner box:", size(banner)
    image.Save(thumb, "thumb.png")
    image.Save(card, "card.webp")
    println "formats:", image.FormatFromExt("thumb.png") == image.FormatPNG, image.FormatFromExt("card.webp") == image.FormatWebP
end
Outputopened: true 1200x800 thumbnail: 200x133 square card: 300x300 banner box: 600x200 formats: true true

Open reports through its bool argument whether the file could be read. Every image allocates memory for its pixels, so release each one with Free, as the defer lines do.

Draw a simple chart

Lines, rectangles and circles plus the built-in pixel font are enough for a small bar chart, a badge or a placeholder image, with no font file needed. LerpColor mixes two colors, here to make taller bars darker, and ParseHex and ToHexRGB move between colors and CSS-style hex. TextWidth measures text before you draw it, so labels can be centered under their bars.

image-guide-chart.salam
import image

func main:
    sales := [12, 30, 22, 41, 35]
    labels := ["MON", "TUE", "WED", "THU", "FRI"]
    width := 260
    height := 160
    mut chart := image.NewFilled(width, height, image.RGB(255, 255, 255))
    defer image.Free(chart)
    low := image.ParseHex("#9ecae1")
    high := image.ParseHex("#08519c")
    image.DrawLine(chart, 20, 130, 250, 130, image.Gray(80))
    each i, value in sales:
        bar := value * 2
        x := 30 + i * 45
        shade := image.LerpColor(low, high, (value as f64) / 41.0)
        image.DrawRectFilled(chart, x, 130 - bar, 30, bar, shade)
        image.DrawText(chart, x + 15 - image.TextWidth(labels[i], 1) / 2, 136, labels[i], image.Gray(40), 1)
    end
    image.DrawText(chart, 20, 8, "SALES", image.Gray(20), 2)
    image.Save(chart, "chart.png")

    top := image.GetPixel(chart, 30 + 3 * 45 + 15, 130 - 41)
    println "tallest bar color:", image.ToHexRGB(top)
    println "first bar color:", image.ToHexRGB(image.GetPixel(chart, 45, 129))
    println "background:", image.ToHexRGB(image.GetPixel(chart, 5, 5))
    println "title width:", image.TextWidth("SALES", 2), "px"
end
Outputtallest bar color: #08519c first bar color: #72a6cc background: #ffffff title width: 60 px

The pixel font has only capital English letters, digits and the signs . , - : ! ?; anything else, lower case letters included, is drawn as a blank. For Persian or any other script, and for smooth text at large sizes, load a TrueType font with LoadFont and use DrawTextStyled, which shapes Persian letters and lays them out right to left.

Filters and measuring the difference

Blurred and Sharpened return new images; Grayscale, Threshold, Brightness and Contrast change the image in place. To compare two images, MeanAbsError gives the average difference per channel and PSNR the signal to noise ratio in decibels, where higher means more alike. The numbers show that sharpening a blurred image does not bring the original back: it makes the edges stronger, not correct.

image-guide-filters.salam
import image
import fmt

func main:
    mut base := image.New(64, 64)
    defer image.Free(base)
    image.Fill(base, image.RGB(30, 30, 30))
    image.DrawRectFilled(base, 16, 16, 32, 32, image.RGB(240, 240, 240))

    mut soft := image.Blurred(base, 3)
    mut crisp := image.Sharpened(soft, 1.0)
    defer image.Free(soft)
    defer image.Free(crisp)
    println "edge pixel, original:", image.ToHexRGB(image.GetPixel(base, 16, 32))
    println "edge pixel, blurred: ", image.ToHexRGB(image.GetPixel(soft, 16, 32))
    println "blur error:", fmt.FloatPrec(image.MeanAbsError(base, soft), 2), "PSNR", fmt.FloatPrec(image.PSNR(base, soft), 1), "dB"
    println "sharpened again:", fmt.FloatPrec(image.PSNR(base, crisp), 1), "dB, edge", image.ToHexRGB(image.GetPixel(crisp, 16, 32))

    mut gray := image.Clone(base)
    defer image.Free(gray)
    image.FillHex(gray, "#cc3344")
    image.Grayscale(gray)
    println "red after Grayscale:", image.ToHexRGB(image.GetPixel(gray, 0, 0)), "luminance", image.Luminance(image.ParseHex("#cc3344"))
    image.Threshold(gray, 128)
    println "after Threshold(128):", image.ToHexRGB(image.GetPixel(gray, 0, 0))
end
Outputedge pixel, original: #f0f0f0 edge pixel, blurred: #969696 blur error: 10.94 PSNR 19.2 dB sharpened again: 15.0 dB, edge #969696 red after Grayscale: #626262 luminance 98 after Threshold(128): #000000

Grayscale uses perceived brightness, the same value Luminance returns, so a strong red becomes a fairly dark gray. These measures are also handy in tests: render an image and check that its PSNR against a stored reference stays above a limit.

A share card with Persian text

A link preview image is a fixed 1200 by 630 canvas with a title that must fit whatever its length. DrawTextFitBox finds the largest size up to a limit at which the text fits a share of the box, centers it and returns the size it chose. TextWidthStyled measures text first, here to right-align the address in the corner; the y coordinate of DrawTextStyled is the baseline.

image-guide-card.salam
import image
import os

func main:
    args := os.Args()
    mut path := image.FindArabicFont()
    if args.len() > 1:
        path = args.get(1)
    end
    mut ok := false
    font := image.LoadFont(path, ok)
    if not ok:
        println "no font with Persian letters; pass a .ttf path"
        ret 1
    end
    defer image.FreeFont(font)
    mut card := image.NewFilled(1200, 630, image.ParseHex("#1b4332"))
    defer image.Free(card)
    white := image.RGB(255, 255, 255)
    title := image.TextStyle { size = 72.0 }
    size := image.DrawTextFitBox(card, 80.0, 120.0, 1040.0, 260.0, "سلام ۰٫۶ منتشر شد: سریع‌تر و کوچک‌تر", white, font, title, 0.9, 96.0)
    println "title size:", size
    small := image.TextStyle { size = 36.0 }
    width := image.TextWidthStyled(font, "salamlang.ir", small)
    image.DrawTextStyled(card, 1120.0 - width, 560.0, "salamlang.ir", image.ParseHex("#95d5b2"), font, small)
    println "saved:", image.Save(card, "release-card.png")
end

The program takes a font path as its first argument and otherwise asks FindArabicFont, so it needs a font file and the site only compiles it. With Vazirmatn the title came out at about 61 pixels; the joined letters, the zero width non-joiner in سریع‌تر and the right to left order are all handled by the package.

Watermark a photo

Overlay draws one image on top of another at a position, with an opacity from 0 to 1, and respects the transparency of the top image. Here the mark is a half transparent black box with white text, placed ten pixels from the bottom right corner.

image-guide-watermark.salam
import image

func main:
    mut photo := image.NewFilled(400, 300, image.ParseHex("#2d6a4f"))
    defer image.Free(photo)
    text := "MADE WITH SALAM"
    scale := 2
    mut mark := image.New(image.TextWidth(text, scale) + 8, image.FontHeight * scale + 8)
    defer image.Free(mark)
    image.Fill(mark, image.RGBA(0, 0, 0, 160))
    image.DrawText(mark, 4, 4, text, image.RGB(255, 255, 255), scale)
    println "mark size:", mark.width, "x", mark.height

    x := photo.width - mark.width - 10
    y := photo.height - mark.height - 10
    image.Overlay(photo, mark, x, y, 0.6)
    println "placed at", x, y
    println "untouched corner:", image.ToHexRGB(image.GetPixel(photo, 0, 0))
    println "under the mark:", image.ToHexRGB(image.GetPixel(photo, x + 1, y + 1))
    image.Save(photo, "marked.png")
end

JPEGOptions

struct JPEGOptions
Settings for the streaming JPEG writer and for EncodeJPEGOptions and SaveJPEGOptions: quality, chroma subsampling, the JFIF pixel density and an optional comment. The output is a baseline JPEG with the same coded data libjpeg writes for the same settings.
NameTypeDescription
qualityint = 90The quality from 1 to 100, 90 by default; values outside that range are clamped. It scales the standard quantization tables the way libjpeg does.
subsamplebool = trueTrue (the default) stores the color at half width and half height (4:2:0), which makes the file smaller; false keeps full color resolution (4:4:4) for sharper color edges.
density_unitint = 0The JFIF density unit: 0 means the densities only give the pixel aspect ratio (the default), 1 is dots per inch and 2 is dots per centimeter.
x_densityint = 1The horizontal density in density_unit, 1 by default; 300 with unit 1 marks a 300 DPI print.
y_densityint = 1The vertical density in density_unit, 1 by default.
commentstr = ""A text stored in a JPEG comment (COM) segment; empty (the default) writes no comment, and a comment of 65000 bytes or more is left out.
image-JPEGStream.salam
import image
import compress
import os

func main:
    opts := image.JPEGOptions { quality = 80, subsample = true, density_unit = 1, x_density = 300, y_density = 300, comment = "made with Salam" }
    mut img := image.NewFilled(40, 24, image.RGB(30, 120, 200))
    image.DrawRectFilled(img, 10, 6, 20, 12, image.RGB(250, 200, 40))

    mut s := image.NewJPEGStream(40, 24, opts)
    println s.ok, s.mcu_w, s.mcu_h, s.mcus_x, s.mcu_rows
    mut top := image.Crop(img, 0, 0, 40, 16)
    image.JPEGStreamWrite(s, top)
    image.Free(top)
    println s.rows_written, s.mcu_row
    mut row := compress.NewByteBuf()
    repeat 8 in y:
        compress.BufReset(row)
        repeat 40 in x:
            c := image.GetPixel(img, x, 16 + y)
            compress.BufPush(row, c.r as int)
            compress.BufPush(row, c.g as int)
            compress.BufPush(row, c.b as int)
        end
        image.JPEGStreamWriteRow(s, row.data as u8*, 3)
    end
    compress.BufFree(row)
    println image.JPEGStreamFinish(s), s.rows_written
    println compress.BufGet(s.out, 0), compress.BufGet(s.out, 1), compress.BufGet(s.out, 13), compress.BufGet(s.out, 14) * 256 + compress.BufGet(s.out, 15)

    mut ok := false
    mut back := image.DecodeJPEG(s.out.data, s.out.len, ok)
    println ok, back.width, back.height
    image.Free(back)
    mut whole := image.EncodeJPEGOptions(img, opts)
    println compress.BufEquals(whole, s.out)
    compress.BufFree(whole)
    compress.BufFree(s.out)

    println image.SaveJPEGOptions(img, "card.jpg", image.JPEGOptions { quality = 95, subsample = false }), os.FileSize("card.jpg") > 0
    os.Remove("card.jpg")
    image.Free(img)
end

JPEGStream

struct JPEGStream
A JPEG encoder that takes the picture a row at a time, so the input pixels never have to be in memory all at once: only one strip of 16 rows (8 without subsampling) is held. The encoded file itself still builds up in memory. Start it with NewJPEGStream, feed rows with JPEGStreamWriteRow or JPEGStreamWrite, then call JPEGStreamFinish; the file is in out.
NameTypeDescription
widthint = 0The picture width in pixels, 1 to 65535.
heightint = 0The picture height in pixels, 1 to 65535.
rows_writtenint = 0How many rows have been fed so far; the picture is complete when it equals height.
okbool = falseThe stream was set up and is still open. It is false for a bad size or when memory ran out, and JPEGStreamFinish sets it to false.
outcompress.ByteBufThe encoded bytes: the headers right after NewJPEGStream, the whole file after JPEGStreamFinish. The caller frees it with compress.BufFree.
hsint = 2The horizontal sampling factor of the brightness channel: 2 with subsampling, 1 without.
vsint = 2The vertical sampling factor of the brightness channel: 2 with subsampling, 1 without.
mcu_wint = 16The width of one MCU (minimum coded unit) in pixels: 16 with subsampling, 8 without.
mcu_hint = 16The height of one MCU in pixels, which is also how many rows are buffered before a strip is encoded.
mcus_xint = 0How many MCUs make up one row of the picture.
full_wint = 0The row width rounded up to whole MCUs; the last pixel of each row is repeated to fill it.
y_wibint = 0The picture width in 8 by 8 brightness blocks, rounded up; blocks past it are padding.
y_hibint = 0The picture height in 8 by 8 brightness blocks, rounded up.
c_wint = 0The width of the color planes after subsampling, in samples.
mcu_rowint = 0The number of the next strip (MCU row) to encode.
mcu_rowsint = 0How many strips the whole picture has.

cbbvoid*Internal: the blue difference (Cb) samples of the current strip at full resolution.
crbvoid*Internal: the red difference (Cr) samples of the current strip at full resolution.
cbdvoid*Internal: the Cb samples of the current strip after subsampling.
crdvoid*Internal: the Cr samples of the current strip after subsampling.
lqvoid*Internal: the brightness quantization table, scaled for the quality.
cqvoid*Internal: the color quantization table, scaled for the quality.
hcvoid*Internal: the Huffman codes of the four standard tables.
hlvoid*Internal: the lengths of those Huffman codes.
workvoid*Internal: the 64 value block the DCT works in.
acci64 = 0Internal: the bit accumulator of the entropy coder.
nbitsint = 0Internal: how many bits are waiting in acc.

dc_cbint = 0Internal: the last Cb DC value.

AreaResampler

struct AreaResampler
A shrinker that averages the area under each new pixel, computing exactly what libgd's gdImageCopyResampled (PHP's imagecopyresampled) gives. Source rows go in one at a time and only a few output rows of sums are kept, so a picture that is still being made, or is too large to hold, can be shrunk on the way. Alpha passes through gd's 7 bit alpha, so it comes out in 128 steps.
NameTypeDescription
src_wint = 0The source width in pixels.
src_hint = 0The source height in pixels.
dst_wint = 0The output width in pixels.
dst_hint = 0The output height in pixels.
outImageThe output RGBA image; each row is filled as soon as its last source row arrives, and rows not reached yet stay transparent. AreaResamplerFree leaves it, so the caller frees it with Free.
okbool = falseThe resampler was set up; false when a size is zero or less or the output could not be made, and after AreaResamplerFree.
next_rowint = 0The number of the next source row to push; it equals src_h when every row is in.
x_startvoid*Internal: for each output column, where its source spans start in x_src and x_part.
x_countvoid*Internal: how many source columns each output column covers.
x_srcvoid*Internal: the source column of each span.
x_partvoid*Internal: how much of that source column the span covers, from 0 to 1.
y_firstvoid*Internal: the first source row each output row covers.
y_lastvoid*Internal: the last source row each output row covers.
ringint = 0Internal: how many output rows of sums are kept at once.
accvoid*Internal: the running sums, seven 32 bit floats for every pixel of each kept output row.
image-ResizeArea.salam
import image
import compress

func main:
    mut img := image.NewFilled(6, 4, image.Gray(0))
    image.DrawRectFilled(img, 3, 0, 3, 4, image.Gray(255))
    mut small := image.ResizeArea(img, 2, 1)
    println small.width, small.height, image.ToHexRGB(image.GetPixel(small, 0, 0)), image.ToHexRGB(image.GetPixel(small, 1, 0))
    mut dot := image.ResizeArea(img, 1, 1)
    println image.ToHexRGB(image.GetPixel(dot, 0, 0))
    image.Free(dot)
    image.Free(small)
    image.Free(img)

    mut r := image.NewAreaResampler(6, 4, 3, 2)
    println r.ok, r.dst_w, r.dst_h, r.next_row
    mut row := compress.NewByteBuf()
    repeat 4 in y:
        compress.BufReset(row)
        repeat 6 in x:
            v := x < 3 ? 0 : 255
            compress.BufPush(row, v)
            compress.BufPush(row, y * 60)
            compress.BufPush(row, 100)
        end
        image.AreaResamplerPushRow(r, row.data as u8*, 3)
    end
    compress.BufFree(row)
    image.AreaResamplerFree(r)
    println r.next_row, r.ok
    repeat 2 in y:
        println image.ToHexRGB(image.GetPixel(r.out, 0, y)), image.ToHexRGB(image.GetPixel(r.out, 1, y)), image.ToHexRGB(image.GetPixel(r.out, 2, y))
    end
    image.Free(r.out)
end
