log

Recording what a program does, with levels, a prefix, structured fields, JSON output and writing to a file.

import log
On this page
  1. Constants and variables
  2. Functions

For a program running on a server, println is not enough: you need to know how important each message is and when it was written, and to be able to silence the unimportant ones. The log package has four levels, debug, info, warn and error, and records only the messages at or above the level you set; the default level is info.

By default the log goes to standard error with a timestamp. The examples below turn the time off so their output is stable.

Constants and variables

LevelDebug

const LevelDebug: i32 = 0
The debug level: detail for whoever is working on the code.
log-Info.salam
import log

func main:
    log.ToStdout()
    log.ShowTime(false)
    log.SetPrefix("[app]")
    log.Debug("this is not shown")
    log.Info("the server is ready")
    log.Warn("memory is running low")
    log.Error("the connection dropped")
    log.SetLevel(log.LevelDebug)
    log.Debug("now it is shown")
    log.Log(log.LevelWarn, "at a level of my choosing")
    println log.GetLevel(), log.LevelName(log.LevelError), log.ParseLevel("warn"), log.LevelInfo
end
Output[INFO] [app] the server is ready [WARN] [app] memory is running low [ERROR] [app] the connection dropped [DEBUG] [app] now it is shown [WARN] [app] at a level of my choosing 0 ERROR 2 1

FormatText

const FormatText: i32 = 0
The readable text format.
log-InfoKV.salam
import log

func main:
    log.ToStdout()
    log.ShowTime(false)
    mut keys := Vector {} as Vector<str>
    mut values := Vector {} as Vector<str>
    defer keys.free()
    defer values.free()
    keys.push("user")
    values.push("sara")
    keys.push("ms")
    values.push("42")
    log.InfoKV("request served", keys, values)
    log.WarnKV("it was slow", keys, values)
    log.ErrorKV("it failed", keys, values)
    log.SetLevel(log.LevelDebug)
    log.DebugKV("the details", keys, values)
    log.SetFormat(log.FormatJSON)
    log.Info("as JSON")
    println log.GetFormat() == log.FormatJSON, log.FormatText
    mut fields := Vector {} as Vector<str>
    defer fields.free()
    fields.push(log.Field("path", "/login"))
    fields.push(log.FieldInt("status", 200))
    fields.push(log.FieldBool("cached", false))
    println log.KV("response", fields)
end
Output[INFO] request served user=sara ms=42 [WARN] it was slow user=sara ms=42 [ERROR] it failed user=sara ms=42 [DEBUG] the details user=sara ms=42 {"level": "INFO", "msg": "as JSON"} true 0 response path=/login status=200 cached=false

SetRotation

func SetRotation(max_bytes: i64, max_backups: int)
For a file log: when the file grows past max_bytes it is set aside, and at most max_backups old copies are kept.
log-ToFile.salam
import log
import io

func main:
    log.ShowTime(false)
    println log.ToFile("app.log")
    log.SetRotation(1024 * 1024, 3)
    log.Info("written to the file")
    log.CloseFile()
    log.ToStderr()
    print io.ReadFile("app.log")
end
Output0 [INFO] written to the file

Debugf

func Debugf(tmpl: str, args: Vector<str>)
A formatted debug message; every {} is filled with the next value.
log-Infof.salam
import log

func main:
    log.ToStdout()
    log.ShowTime(false)
    mut args := Vector {} as Vector<str>
    defer args.free()
    args.push("Sara")
    args.push("3")
    log.Infof("user {} signed in and has {} messages", args)
    log.Warnf("a failed attempt for {}", args)
    log.Errorf("user {} was blocked", args)
    log.SetLevel(log.LevelDebug)
    log.Debugf("id {}", args)
end
Output[INFO] user Sara signed in and has 3 messages [WARN] a failed attempt for Sara [ERROR] user Sara was blocked [DEBUG] id Sara
