log

Recording what a program does, with levels, a prefix, structured fields, JSON output and writing to a file.

For a program running on a server, println is not enough: you need to know how important each message is and when it was written, and to be able to silence the unimportant ones. The log package has four levels, debug, info, warn and error, and records only the messages at or above the level you set; the default level is info. Each line goes out in plain text or as one JSON object, to standard error, standard output or a file that can rotate.

A text line looks like 2026-10-17 13:09:22 [INFO] shop order 1042 accepted: the local time, the level, the prefix and the message. The examples below turn the time off with ShowTime(false) so their output is stable.

All settings are global to the program: call SetLevel, SetFormat, SetPrefix and one of ToStderr, ToStdout or ToFile once near the start of main, and every package that imports log writes the same way. For a quick look at a value while you work on the code, debug is the better tool; for timing and memory figures, runtime.

The things people get wrong:

  • A file log is buffered. Lines reach the disk when the buffer fills or at CloseFile, so tail -f lags behind and a crash loses the last lines. Call CloseFile on every way out of the program.
  • The text format writes the message as it is. A value from a user that holds a line break starts a fake log line; use JSON, which escapes it (see below).
  • The settings are plain globals with no lock. Change them at startup only, not while other threads are logging.
  • The time is local time with no zone offset, also in JSON. Run servers with TZ=UTC when logs from several machines are compared.

Choose the level from the settings

The level should not be fixed in the code. During development you want debug messages; on a busy server you want warnings and errors only. Read the level as text from a settings file or the environment and turn it into a number with ParseLevel. It accepts debug, info, warn, warning and error in any case, and falls back to info for anything else, so a typo never silences the log completely.

log-level-config.salam
import log
import config

func setup(text: str):
    mut c := config.ParseEnv(text)
    defer config.Free(c)
    level := log.ParseLevel(config.GetOr(c, "LOG_LEVEL", "info"))
    log.SetLevel(level)
    log.SetPrefix(config.GetOr(c, "APP_NAME", "app"))
    println "-- level", log.LevelName(log.GetLevel())
end

func work():
    log.Debug("cache lookup for key user:7")
    log.Info("order 1042 accepted")
    log.Warn("payment provider answered slowly")
    log.Error("could not send the receipt email")
end

func main:
    log.ToStdout()
    log.ShowTime(false)
    setup("LOG_LEVEL=debug\nAPP_NAME=shop\n")
    work()
    setup("LOG_LEVEL=warning\nAPP_NAME=shop\n")
    work()
    setup("LOG_LEVEL=loud\n")
    work()
end
Output-- level DEBUG [DEBUG] shop cache lookup for key user:7 [INFO] shop order 1042 accepted [WARN] shop payment provider answered slowly [ERROR] shop could not send the receipt email -- level WARN [WARN] shop payment provider answered slowly [ERROR] shop could not send the receipt email -- level INFO [INFO] app order 1042 accepted [WARN] app payment provider answered slowly [ERROR] app could not send the receipt email

The config package used here is described on its own page, config. The prefix is a good place for the program's name, so that lines from several programs in one log stay apart.

JSON logs for a log collector

Text lines are easy to read; JSON lines are easy for tools such as Loki, Elasticsearch or a cloud log service to search. SetFormat(FormatJSON) turns every line into one JSON object with level, the optional prefix, msg, and one member for each key given to the ...KV functions. With the time switched on, a time member in ISO 8601 comes first.

log-json-requests.salam
import log
import str

struct Request:
    pub method: str = ""
    pub path: str = ""
    pub status: int = 0
    pub ms: int = 0
end

func record(r: Request):
    mut keys := Vector {} as Vector<str>
    mut vals := Vector {} as Vector<str>
    defer keys.free()
    defer vals.free()
    keys.push("method")
    vals.push(r.method)
    keys.push("path")
    vals.push(r.path)
    keys.push("status")
    vals.push(str.FromInt(r.status as i64))
    keys.push("ms")
    vals.push(str.FromInt(r.ms as i64))
    if r.status >= 500:
        log.ErrorKV("request failed", keys, vals)
    else r.status >= 400:
        log.WarnKV("request rejected", keys, vals)
    else:
        log.InfoKV("request served", keys, vals)
    end
end

func main:
    log.ToStdout()
    log.ShowTime(false)
    log.SetFormat(log.FormatJSON)
    log.SetPrefix("api")
    record(Request { method = "GET", path = "/products", status = 200, ms = 12 })
    record(Request { method = "POST", path = "/login", status = 401, ms = 3 })
    record(Request { method = "GET", path = "/report \"q3\"", status = 503, ms = 950 })
end
Output{"level": "INFO", "prefix": "api", "msg": "request served", "method": "GET", "path": "/products", "status": "200", "ms": "12"} {"level": "WARN", "prefix": "api", "msg": "request rejected", "method": "POST", "path": "/login", "status": "401", "ms": "3"} {"level": "ERROR", "prefix": "api", "msg": "request failed", "method": "GET", "path": "/report \"q3\"", "status": "503", "ms": "950"}

Picking the level from the result, error for a 5xx answer and warn for a 4xx one, lets you alert on errors without reading every request. Quotes inside a value are escaped, so each line stays valid JSON. All values are written as JSON strings, numbers included.

Log to a file that does not grow forever

ToFile appends to a file and returns 0, or minus one when the file cannot be opened. SetRotation(max_bytes, max_backups) keeps it in check: when the file has reached max_bytes, the next line first renames it to .1, shifts the older copies up by one and starts a new, empty file. Copies past max_backups are deleted.

log-rotation.salam
import log
import os
import io
import str

func first_line(path: str): str:
    lines := io.ReadFile(path).split("\n")
    defer lines.free()
    ret lines.get(0)
end

func main:
    files := ["worker.log", "worker.log.1", "worker.log.2", "worker.log.3"]
    each f in files:
        os.Remove(f)
    end
    log.ShowTime(false)
    if log.ToFile("worker.log") != 0:
        println "cannot open worker.log"
        ret 1
    end
    log.SetRotation(120, 2)
    repeat 24 in i:
        log.Info("processed job " + str.FromInt(i as i64))
    end
    log.CloseFile()
    each f in files:
        if os.Exists(f):
            println f, "starts with", first_line(f)
        else:
            println f, "does not exist"
        end
    end
end
Outputworker.log starts with [INFO] processed job 22 worker.log.1 starts with [INFO] processed job 17 worker.log.2 starts with [INFO] processed job 12 worker.log.3 does not exist

The limit here is tiny so that the example rotates a few times. A real service uses something like 10 * 1024 * 1024 bytes and five backups. The size is checked before each line is written, so a file can end up one line longer than the limit. Call CloseFile before the program ends, or the last lines stay in the buffer; Fatal closes the file for you before it exits with status 1.

Key and value fields in text logs

For text logs, Field, FieldInt and FieldBool build key=value pieces and KV joins them after a message. Field puts quotes around a value that contains a space or a quote, and escapes the quotes inside, so a line can still be split into fields by a program.

log-fields.salam
import log

func login_line(user: str, attempts: i64, ok: bool, agent: str): str:
    mut fields := Vector {} as Vector<str>
    defer fields.free()
    fields.push(log.Field("user", user))
    fields.push(log.FieldInt("attempts", attempts))
    fields.push(log.FieldBool("ok", ok))
    fields.push(log.Field("agent", agent))
    ret log.KV("login", fields)
end

func main:
    log.ToStdout()
    log.ShowTime(false)
    log.Info(login_line("sara", 1, true, "curl/8.5"))
    log.Warn(login_line("guest user", 3, false, "my \"test\" bot"))
    println log.Field("empty", "")
    println log.Field("path", "/a b")
end
Output[INFO] login user=sara attempts=1 ok=true agent=curl/8.5 [WARN] login user="guest user" attempts=3 ok=false agent="my \"test\" bot" empty= path="/a b"

An empty value is written as key= with nothing after it. Only spaces and quotes trigger the quoting: a tab, a backslash or a line break goes through unchanged. These helpers only build text; the level filter still applies when you pass the result to Info or Warn.

Formatted messages and values from users

Infof and the other ...f functions fill each {} with the next string from a vector, which reads better than a chain of +. They do not clean the values. Here a user name with a line break forges an [ERROR] line in the text log, while the JSON line keeps it inside one string as \n.

log-untrusted.salam
import log

func pair(a: str, b: str): Vector<str>:
    mut v := Vector {} as Vector<str>
    v.push(a)
    v.push(b)
    ret v
end

func main:
    log.ToStdout()
    log.ShowTime(false)
    name := "mina\n[ERROR] disk full"
    args := pair(name, "10.0.0.7")
    defer args.free()
    log.Infof("user {} signed in from {}", args)
    keys := pair("user", "ip")
    defer keys.free()
    log.SetFormat(log.FormatJSON)
    log.InfoKV("user signed in", keys, args)
    log.SetFormat(log.FormatText)
    log.SetLevel(log.LevelError + 1)
    log.Error("nobody sees this")
    log.SetLevel(log.LevelInfo)
    log.Info("logging is back on")
end
Output[INFO] user mina [ERROR] disk full signed in from 10.0.0.7 {"level": "INFO", "msg": "user signed in", "user": "mina\n[ERROR] disk full", "ip": "10.0.0.7"} [INFO] logging is back on

The end of the example shows a trick for tests and quiet tools: a level above LevelError silences everything, and setting it back turns logging on again.

log-InfoKV.salam
import log

func main:
    log.ToStdout()
    log.ShowTime(false)
    mut keys := Vector {} as Vector<str>
    mut values := Vector {} as Vector<str>
    defer keys.free()
    defer values.free()
    keys.push("user")
    values.push("sara")
    keys.push("ms")
    values.push("42")
    log.InfoKV("request served", keys, values)
    log.WarnKV("it was slow", keys, values)
    log.ErrorKV("it failed", keys, values)
    log.SetLevel(log.LevelDebug)
    log.DebugKV("the details", keys, values)
    log.SetFormat(log.FormatJSON)
    log.Info("as JSON")
    println log.GetFormat() == log.FormatJSON, log.FormatText
    mut fields := Vector {} as Vector<str>
    defer fields.free()
    fields.push(log.Field("path", "/login"))
    fields.push(log.FieldInt("status", 200))
    fields.push(log.FieldBool("cached", false))
    println log.KV("response", fields)
end
Output[INFO] request served user=sara ms=42 [WARN] it was slow user=sara ms=42 [ERROR] it failed user=sara ms=42 [DEBUG] the details user=sara ms=42 {"level": "INFO", "msg": "as JSON"} true 0 response path=/login status=200 cached=false
