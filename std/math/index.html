math

The basic mathematics: powers and roots, logarithms, trigonometry, rounding, minimum and maximum, and the greatest common divisor.

import math

The math package holds what you would expect from a scientific calculator. Most of its functions work on f64; the ones whose names end in I or I64 are the whole-number versions.

The angles in the trigonometric functions are in radians, not degrees. Use Radians and Degrees to convert.

For averages, medians and percentiles of a list use stats; for money and other exact decimals, decimal; for whole numbers too large for i64, bigint; for random numbers, rand.

Behaviour worth knowing

  • Round rounds halves up, toward positive infinity: Round(2.5) is 3 but Round(-2.5) is -2. Round the absolute value and put the sign back if you need halves away from zero.
  • Mod keeps the sign of the first argument, as C's fmod does: Mod(-7.0, 3.0) is -1, not 2.
  • Factorial returns an i64 and is exact only up to 20; from 21 on the result overflows and is wrong.
  • Hypot squares its arguments directly, so values above about 1e154 give infinity.

Distances, angles and circles

Most geometry in a program is a distance or a direction between two points. Hypot gives the straight line distance, and Atan2 gives the angle of a direction from all four quarters of the plane, which plain Atan cannot tell apart. Convert between degrees and radians at the edges of your program and keep radians inside it.

math-guide-geometry.salam
import math
import fmt

func distance(x1: f64, y1: f64, x2: f64, y2: f64): f64:
    ret math.Hypot(x2 - x1, y2 - y1)
end

func heading(x1: f64, y1: f64, x2: f64, y2: f64): f64:
    deg := math.Degrees(math.Atan2(y2 - y1, x2 - x1))
    if deg < 0.0: ret deg + 360.0 end
    ret deg
end

func main:
    println "distance:", distance(1.0, 2.0, 4.0, 6.0)
    println "heading east:", heading(0.0, 0.0, 5.0, 0.0)
    println "heading north:", heading(0.0, 0.0, 0.0, 5.0)
    println "heading south-west:", heading(0.0, 0.0, -3.0, -3.0)
    r := 2.5
    println "circle area:", fmt.FloatPrec(math.PI * math.Pow(r, 2.0), 2)
    println "circumference:", fmt.FloatPrec(math.TAU * r, 2)
    x := 10.0 * math.Cos(math.Radians(60.0))
    y := 10.0 * math.Sin(math.Radians(60.0))
    println "point at 60 degrees:", fmt.FloatPrec(x, 3), fmt.FloatPrec(y, 3)
end
Outputdistance: 5 heading east: 0 heading north: 90 heading south-west: 225 circle area: 19.63 circumference: 15.71 point at 60 degrees: 5.000 8.660

fmt.FloatPrec from fmt prints a number with a fixed count of decimals, which keeps results such as 8.660254037844386 readable.

Growth, loans and rounding

Pow handles compound growth and Log answers the reverse question of how long it takes. To round to a number of decimal places, multiply by Pow10, round, and divide again. The last two lines show why: f64 cannot store 0.1 exactly, so sums of prices pick up tiny errors.

math-guide-money.salam
import math
import fmt

func round_to(x: f64, places: int): f64:
    scale := math.Pow10(places)
    ret math.Round(x * scale) / scale
end

func monthly_payment(principal: f64, yearly_rate: f64, months: int): f64:
    r := yearly_rate / 12.0
    ret principal * r / (1.0 - math.Pow(1.0 + r, -(months as f64)))
end

func main:
    mut balance := 1000.0
    repeat 1 to 5 in year:
        balance = balance * 1.06
        println "year", year, fmt.FloatPrec(balance, 2)
    end
    println "after 5 years:", round_to(1000.0 * math.Pow(1.06, 5.0), 2)
    println "doubling time at 6%:", fmt.FloatPrec(math.Log(2.0) / math.Log(1.06), 1), "years"
    println "monthly payment:", fmt.FloatPrec(monthly_payment(20000.0, 0.18, 36), 2)
    println "0.1 + 0.2 =", 0.1 + 0.2
    println "rounded:", round_to(0.1 + 0.2, 2)
end
Outputyear 1 1060.00 year 2 1123.60 year 3 1191.02 year 4 1262.48 year 5 1338.23 after 5 years: 1338.23 doubling time at 6%: 11.9 years monthly payment: 723.05 0.1 + 0.2 = 0.30000000000000004 rounded: 0.3

For real money, where every cent must add up, use decimal instead of f64; the rounding trick above is fine for display and for estimates.

Whole numbers: Gcd and Lcm

The greatest common divisor reduces fractions and finds the largest tile or package size that divides evenly; the least common multiple finds the next time two repeating events line up. Both work on int; GcdI64 takes 64-bit values.

math-guide-fractions.salam
import math
import str

func show(n: int, d: int): str:
    g := math.Gcd(math.AbsI(n), math.AbsI(d))
    ret str.FromInt(n / g) + "/" + str.FromInt(d / g)
end

func add(an: int, ad: int, bn: int, bd: int): str:
    common := math.Lcm(ad, bd)
    ret show(an * (common / ad) + bn * (common / bd), common)
end

func main:
    println "12/18 =", show(12, 18)
    println "1/4 + 1/6 =", add(1, 4, 1, 6)
    println "3/10 + 7/15 =", add(3, 10, 7, 15)
    println "buses every 12 and 18 minutes meet every", math.Lcm(12, 18), "minutes"
    tiles := math.Gcd(240, 180)
    println "largest square tile for a 240 x 180 floor:", tiles
    println "tiles needed:", (240 / tiles) * (180 / tiles)
end
Output12/18 = 2/3 1/4 + 1/6 = 5/12 3/10 + 7/15 = 23/30 buses every 12 and 18 minutes meet every 36 minutes largest square tile for a 240 x 180 floor: 60 tiles needed: 12

Mean and spread by hand

Min, Max, Pow and Sqrt are enough for a small summary of a list. For anything bigger, such as the median, percentiles or a correlation, the stats package already has the functions.

math-guide-stats.salam
import math
import fmt

func main:
    scores := [72.0, 85.5, 90.0, 64.5, 88.0]
    mut sum := 0.0
    mut low := scores[0]
    mut high := scores[0]
    each s in scores:
        sum += s
        low = math.Min(low, s)
        high = math.Max(high, s)
    end
    mean := sum / 5.0
    mut squares := 0.0
    each s in scores:
        squares += math.Pow(s - mean, 2.0)
    end
    deviation := math.Sqrt(squares / 5.0)
    println "mean:", mean
    println "lowest:", low, "highest:", high
    println "standard deviation:", fmt.FloatPrec(deviation, 2)
    each s in scores:
        z := (s - mean) / deviation
        println s, "is", fmt.FloatPrec(math.Abs(z), 2), "deviations", z < 0.0 ? "below" : "above"
    end
end
Outputmean: 80 lowest: 64.5 highest: 90 standard deviation: 9.98 72 is 0.80 deviations below 85.5 is 0.55 deviations above 90 is 1.00 deviations above 64.5 is 1.55 deviations below 88 is 0.80 deviations above

NaN, infinity and comparing decimals

Dividing by zero does not stop a Salam program when the numbers are f64: it gives infinity, or NaN for zero divided by zero, and both spread silently through later sums. Check results that come from user data with IsNaN and IsInf. Never compare two computed decimals with ==; compare the size of their difference instead. ClampI and ClampF keep a value inside a range.

math-guide-safe.salam
import math

func safe_ratio(a: f64, b: f64): f64:
    r := a / b
    if math.IsNaN(r) or math.IsInf(r): ret 0.0 end
    ret r
end

func near(a: f64, b: f64): bool:
    ret math.Abs(a - b) < 0.000000001
end

func main:
    println "1 / 0 =", 1.0 / 0.0, "->", safe_ratio(1.0, 0.0)
    println "0 / 0 =", 0.0 / 0.0, "->", safe_ratio(0.0, 0.0)
    println "6 / 4 =", safe_ratio(6.0, 4.0)
    root := math.Sqrt(-4.0)
    println "sqrt(-4) is NaN:", math.IsNaN(root)
    println "cbrt(-8) =", math.Cbrt(-8.0)
    println "0.1 + 0.2 == 0.3:", 0.1 + 0.2 == 0.3
    println "near(0.1 + 0.2, 0.3):", near(0.1 + 0.2, 0.3)
    println "volume 130% clamped:", math.ClampI(130, 0, 100)
    println "opacity -0.2 clamped:", math.ClampF(-0.2, 0.0, 1.0)
end
Output1 / 0 = inf -> 0 0 / 0 = nan -> 0 6 / 4 = 1.5 sqrt(-4) is NaN: true cbrt(-8) = -2 0.1 + 0.2 == 0.3: false near(0.1 + 0.2, 0.3): true volume 130% clamped: 100 opacity -0.2 clamped: 0
