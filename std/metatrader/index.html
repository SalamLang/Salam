metatrader

Read account, symbols, rates and history, and send trades through a local MetaTrader 5 bridge.

import metatrader

metatrader is a client for a local bridge to a running MetaTrader 5 terminal. The package speaks HTTP and JSON: every call sends a request to the bridge, and the bridge asks the terminal for the data or the trade. There is no DLL, no COM and no terminal plugin inside your program, so the same Salam program runs on Linux, macOS and Windows as long as the bridge is reachable.

The terminal itself must be running and logged in, and a bridge must be listening on the address you set. The default is http://127.0.0.1:18812, the value of DEFAULT_BRIDGE_URL. The bridge implements the endpoints below; the package only calls them and decodes the JSON.

Start with the account

Set the bridge address once, call Initialize, then read the account. Every call returns a value even when it fails, so check Ok or LastError after the calls that matter, and stop when the bridge is not there.

metatrader-quickstart.salam
import metatrader

func main:
    metatrader.SetBridgeUrl("http://127.0.0.1:18812")

    if not metatrader.Initialize("", 0 as i64, "", "", 60000, false):
        e := metatrader.LastError()
        printerrln "no bridge:", e.code, e.description
        ret 1
    end

    a := metatrader.GetAccountInfo()
    if not metatrader.Ok():
        e := metatrader.LastError()
        printerrln "account failed:", e.code, e.description
        metatrader.Shutdown()
        ret 1
    end
    println a.login, a.name, a.currency
    println "balance", a.balance, "equity", a.equity
    println "margin", a.margin, "free", a.margin_free

    t := metatrader.GetTerminalInfo()
    println t.company, t.name, t.build, t.connected

    metatrader.Shutdown()
    ret 0
end

Initialize and Login mark the session connected only when the bridge answers with a 2xx status. IsConnected reports that flag, not a live socket: call Version or GetTerminalInfo when you need to know that the terminal is still there. Shutdown only asks the bridge to close; it does not free anything in your program.

Errors and retcodes

A failed call returns the zero value of its type, an empty vector, an empty struct, or false, and leaves the reason in LastError. Ok is true exactly when the last code is RES_S_OK. The bridge uses the RES_E_* constants for transport and parameter errors, and the trade server uses TRADE_RETCODE_* in the result of OrderCheck and OrderSend.

a := metatrader.GetAccountInfo()
if not metatrader.Ok():
    e := metatrader.LastError()
    printerrln "account failed:", e.code, e.description
    ret 1
end
println a.balance

An HTTP error and a rejected trade are different: the first leaves Ok false, the second is a normal answer with a retcode. Always read retcode after OrderSend; a successful HTTP call does not mean the trade was accepted.

Symbols, prices and ticks

SymbolsGet returns every symbol with its contract rules and session data; the group forms filter with a mask such as *USD*, where * matches any text. GetSymbolInfo asks for one symbol, and SymbolInfoTick is the cheap call for the current bid and ask.

metatrader-symbols.salam
import metatrader

func main:
    metatrader.SetBridgeUrl("http://127.0.0.1:18812")

    println "symbols:", metatrader.SymbolsTotal()
    each s in metatrader.SymbolsGet():
        println s.name, s.digits, s.spread, s.trade_mode
    end

    majors := metatrader.SymbolsGetGroup("*USD*")
    println "usd symbols:", majors.len()

    info := metatrader.GetSymbolInfo("EURUSD")
    println info.bid, info.ask, info.point, info.digits
    println info.volume_min, info.volume_step, info.volume_max
    println info.trade_stops_level, info.trade_contract_size

    tick := metatrader.SymbolInfoTick("EURUSD")
    println tick.time, tick.bid, tick.ask, tick.last, tick.volume

    if not metatrader.SymbolSelect("EURUSD", true):
        printerrln "cannot select EURUSD"
    end
    ret 0
end

digits and point tell you how to round a price; volume_min, volume_max and volume_step tell you which volumes the server accepts; trade_stops_level is the shortest distance in points between the price and a stop loss or take profit.

Candles and ticks

Rates are returned oldest first. CopyRatesFromPos counts from the newest candle, so position 0 is the candle that is still forming, and CopyRatesFrom starts at a time. Times are seconds since the epoch, as in time; tick times are milliseconds in time_msc, which is what CopyTicksRange expects.

metatrader-rates.salam
import metatrader

func main:
    metatrader.SetBridgeUrl("http://127.0.0.1:18812")

    from := metatrader.CopyRatesFrom("EURUSD", metatrader.TIMEFRAME_H1, 1700000000 as i64, 10)
    each r in from:
        println r.time, r.open, r.high, r.low, r.close, r.tick_volume
    end

    recent := metatrader.CopyRatesFromPos("EURUSD", metatrader.TIMEFRAME_M5, 0, 5)
    println "recent:", recent.len()

    window := metatrader.CopyRatesRange("EURUSD", metatrader.TIMEFRAME_D1, 1700000000 as i64, 1700086400 as i64)
    println "daily:", window.len()

    ticks := metatrader.CopyTicksFrom("EURUSD", 1700000000 as i64, 100, metatrader.COPY_TICKS_ALL)
    each t in ticks:
        println t.time_msc, t.bid, t.ask, t.last, t.flags
    end

    trade_ticks := metatrader.CopyTicksRange("EURUSD", 1700000000000 as i64, 1700000600000 as i64, metatrader.COPY_TICKS_TRADE)
    println "trade ticks:", trade_ticks.len()
    ret 0
end

The tick filters keep the payload small: COPY_TICKS_INFO keeps bid and ask changes, COPY_TICKS_TRADE keeps trades, and COPY_TICKS_ALL keeps both. Check flags on each tick when you need to know which side changed.

Checking and sending an order

Fill a TradeRequest, call OrderCheck, and look at its margin fields before you send anything. Then call OrderSend and read retcode. A check returning 0 means the request is valid; the send returns TRADE_RETCODE_DONE for a filled order, TRADE_RETCODE_PLACED for a pending order, and an error code otherwise.

metatrader-trade.salam
import metatrader

func main:
    metatrader.SetBridgeUrl("http://127.0.0.1:18812")

    println "orders:", metatrader.OrdersTotal()
    each o in metatrader.OrdersGet():
        println o.ticket, o.symbol, o.order_type, o.state, o.volume_current, o.price_open
    end
    each p in metatrader.PositionsGet():
        println p.ticket, p.symbol, p.position_type, p.volume, p.price_open, p.profit
    end

    mut req := metatrader.TradeRequest {}
    req.action = metatrader.TRADE_ACTION_DEAL
    req.symbol = "EURUSD"
    req.volume = 0.10
    req.price = 1.0821
    req.order_type = metatrader.ORDER_TYPE_BUY
    req.type_filling = metatrader.ORDER_FILLING_IOC
    req.type_time = metatrader.ORDER_TIME_GTC
    req.deviation = 10
    req.magic = 2026
    req.comment = "salam"

    check := metatrader.OrderCheck(req)
    println "check:", check.retcode, check.margin, check.margin_free, check.comment
    if check.retcode != 0:
        ret 1
    end

    sent := metatrader.OrderSend(req)
    println "send:", sent.retcode, sent.order, sent.deal, sent.price
    if sent.retcode != metatrader.TRADE_RETCODE_DONE and sent.retcode != metatrader.TRADE_RETCODE_PLACED:
        printerrln "order rejected:", sent.comment
        ret 1
    end

    margin := metatrader.OrderCalcMargin(metatrader.ORDER_TYPE_BUY, "EURUSD", 0.10, 1.0821)
    profit := metatrader.OrderCalcProfit(metatrader.ORDER_TYPE_BUY, "EURUSD", 0.10, 1.0821, 1.09)
    println margin, profit
    ret 0
end

action selects what the request does: TRADE_ACTION_DEAL for a market order, TRADE_ACTION_PENDING for a pending one, TRADE_ACTION_SLTP to change stops, TRADE_ACTION_MODIFY and TRADE_ACTION_REMOVE for pending orders, and TRADE_ACTION_CLOSE_BY to close one position with another. Set type_filling to a mode the symbol allows, and set magic so you can find your own orders later.

Orders, positions and history

OrdersGet returns active orders, PositionsGet returns open positions, and the history calls return what is already closed. Every filter has a total and a get form; the get form returns a vector, even when you ask by ticket, because the bridge keeps one answer shape.

History times are seconds since the epoch. Give both ends of the range; an empty range returns an empty vector, not an error.

metatrader-history.salam
import metatrader

func main:
    metatrader.SetBridgeUrl("http://127.0.0.1:18812")

    date_from := 1700000000 as i64
    date_to := 1700086400 as i64

    println "orders:", metatrader.HistoryOrdersTotal(date_from, date_to)
    each o in metatrader.HistoryOrdersGet(date_from, date_to):
        println o.ticket, o.symbol, o.state, o.volume_initial, o.price_open
    end

    println "deals:", metatrader.HistoryDealsTotal(date_from, date_to)
    each d in metatrader.HistoryDealsGet(date_from, date_to):
        println d.ticket, d.order, d.position_id, d.deal_type, d.entry, d.profit, d.commission, d.swap
    end

    if metatrader.MarketBookAdd("EURUSD"):
        each b in metatrader.MarketBookGet("EURUSD"):
            println b.book_type, b.price, b.volume
        end
        metatrader.MarketBookRelease("EURUSD")
    end
    ret 0
end

Market depth

Market depth is a subscription. Call MarketBookAdd once, read the levels with MarketBookGet as often as you need, and call MarketBookRelease when you stop. The depth stays empty until the terminal has it and the subscription is active.

What the package does not do

  • It does not start the terminal. The bridge must be running and the terminal logged in; Initialize is a request to the bridge, not to the terminal process.
  • It does not retry. A timeout, a closed bridge or an HTTP 5xx is returned once; decide in your own code whether to repeat the call.
  • It does not replace OrderCheck with local validation. The broker has the last word on volume, stops, filling and market hours.
  • It does not keep a cache. Every call asks the bridge for fresh data, so a tight loop of SymbolInfoTick is a lot of HTTP requests; sleep between them.

import metatrader

func main:
    metatrader.SetBridgeUrl("http://127.0.0.1:18812")

    each r in from:
        println r.time, r.open, r.high, r.low, r.close, r.tick_volume
    end

    recent := metatrader.CopyRatesFromPos("EURUSD", metatrader.TIMEFRAME_M5, 0, 5)
    println "recent:", recent.len()

    window := metatrader.CopyRatesRange("EURUSD", metatrader.TIMEFRAME_D1, 1700000000 as i64, 1700086400 as i64)
    println "daily:", window.len()

    ticks := metatrader.CopyTicksFrom("EURUSD", 1700000000 as i64, 100, metatrader.COPY_TICKS_ALL)
    each t in ticks:
        println t.time_msc, t.bid, t.ask, t.last, t.flags
    end

    trade_ticks := metatrader.CopyTicksRange("EURUSD", 1700000000000 as i64, 1700000600000 as i64, metatrader.COPY_TICKS_TRADE)
    println "trade ticks:", trade_ticks.len()
    ret 0

import metatrader

func main:
    metatrader.SetBridgeUrl("http://127.0.0.1:18812")

    println "orders:", metatrader.OrdersTotal()
    each o in metatrader.OrdersGet():
        println o.ticket, o.symbol, o.order_type, o.state, o.volume_current, o.price_open
    end
    each p in metatrader.PositionsGet():
        println p.ticket, p.symbol, p.position_type, p.volume, p.price_open, p.profit
    end

    mut req := metatrader.TradeRequest {}
    req.action = metatrader.TRADE_ACTION_DEAL
    req.symbol = "EURUSD"
    req.volume = 0.10
    req.price = 1.0821
    req.order_type = metatrader.ORDER_TYPE_BUY
    req.type_filling = metatrader.ORDER_FILLING_IOC
    req.type_time = metatrader.ORDER_TIME_GTC
    req.deviation = 10
    req.magic = 2026
    req.comment = "salam"

    check := metatrader.OrderCheck(req)
    println "check:", check.retcode, check.margin, check.margin_free, check.comment
    if check.retcode != 0:
        ret 1
    end

    sent := metatrader.OrderSend(req)
    println "send:", sent.retcode, sent.order, sent.deal, sent.price
    if sent.retcode != metatrader.TRADE_RETCODE_DONE and sent.retcode != metatrader.TRADE_RETCODE_PLACED:
        printerrln "order rejected:", sent.comment
        ret 1
    end

    margin := metatrader.OrderCalcMargin(metatrader.ORDER_TYPE_BUY, "EURUSD", 0.10, 1.0821)
    profit := metatrader.OrderCalcProfit(metatrader.ORDER_TYPE_BUY, "EURUSD", 0.10, 1.0821, 1.09)
    println margin, profit
    ret 0
end

HistoryOrdersTotal

func HistoryOrdersTotal(date_from: i64, date_to: i64): int
The number of orders in the history between two times, both in seconds since the epoch.
metatrader-History.salam
import metatrader

func main:
    metatrader.SetBridgeUrl("http://127.0.0.1:18812")

    date_from := 1700000000 as i64
    date_to := 1700086400 as i64

    println "orders:", metatrader.HistoryOrdersTotal(date_from, date_to)
    each o in metatrader.HistoryOrdersGet(date_from, date_to):
        println o.ticket, o.symbol, o.state, o.volume_initial, o.price_open
    end

    println "deals:", metatrader.HistoryDealsTotal(date_from, date_to)
    each d in metatrader.HistoryDealsGet(date_from, date_to):
        println d.ticket, d.order, d.position_id, d.deal_type, d.entry, d.profit, d.commission, d.swap
    end

    if metatrader.MarketBookAdd("EURUSD"):
        each b in metatrader.MarketBookGet("EURUSD"):
            println b.book_type, b.price, b.volume
        end
        metatrader.MarketBookRelease("EURUSD")
    end
    ret 0
end

GetAccountInfo

func GetAccountInfo(): AccountInfo
The current account state: login, balance, equity, margin, currency, server and company.
metatrader-Account.salam
import metatrader

func main:
    metatrader.SetBridgeUrl("http://127.0.0.1:18812")

    a := metatrader.GetAccountInfo()
    if not metatrader.Ok():
        e := metatrader.LastError()
        printerrln "account failed:", e.code, e.description
        ret 1
    end
    println a.login, a.name, a.server, a.currency
    println "balance", a.balance, "equity", a.equity
    println "margin", a.margin, "free", a.margin_free, "level", a.margin_level
    println "leverage", a.leverage, "limit", a.limit_orders
    if a.trade_allowed:
        println "trading is allowed"
    end

    t := metatrader.GetTerminalInfo()
    println t.company, t.name, t.build, t.connected
    println t.path
    println t.data_path
    ret 0
end
