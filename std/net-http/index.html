This package has both halves of HTTP/1.1: a server for web pages and JSON APIs, and a client for calling other services. The server hands each request to a net/router router, which picks the handler by method and path. Every handler takes one i64, the context id of the request; you read the request and write the response with the context functions below, or turn the id into a Context struct with Ctx and call the same names on it.

The packages around it:

  • net/http/middleware for access logs, CORS and cache headers, net/http/session for logins with a cookie, net/http/validate for checking input, and net/http/swagger for API documentation;
  • net/http2 for HTTP/2, and net/websocket for connections that stay open.

Things people get wrong:

  • Register every route before Use. The server keeps a copy of the router.
  • Post, Put and Patch label a body as a form (application/x-www-form-urlencoded) unless you pass a Content-Type; send JSON with PostWith and that header.
  • The client does not follow redirects unless you ask. A 302 comes back as a 302 with its Location header; set max_redirects in RequestOptions (or call SetMaxRedirects on a client) to follow them. It never hangs or reads without limit: a read or write that is idle for 30 seconds fails, a response over 256 MB fails, and timeout_ms caps the whole request.
  • Ok means a 2xx status. When the server could not be reached at all, Status is 0 and Error says why.
  • A value read from a request is freed when the handler returns; see the end of the page.

The examples run the server with RunBackground on 127.0.0.1 and send requests to it from the same program.

A JSON API in one file

The most common job is a small JSON API: list some records, show one by its id, and create new ones. Register each route on the router with its handler, hand the router to the server with Use, and start it. Here the records are Salam structs: json.Marshal turns them into the response body, and json.UnmarshalLenient reads the posted body back into a struct, ignoring fields it does not know and leaving the missing ones at their defaults.

net-http-guide-api.salam
import net.http
import net.router
import encoding.json
import encoding.encerr
import conv

mut books := Vector {} as Vector<Book>

struct Book:
    @json "id"
    pub id: int = 0
    @json "title"
    pub title: str = ""
end

func list(ctx: i64):
    http.Json(ctx, json.Marshal(books))
end

func show(ctx: i64):
    id := conv.Atoi(http.Param(ctx, "id"))
    each b in books:
        if b.id == id:
            http.Json(ctx, json.Marshal(b))
            ret
        end
    end
    http.SetStatus(ctx, 404)
    http.Json(ctx, `{"error":"no such book"}`)
end

func create(ctx: i64):
    mut b := Book {}
    mut e := encerr.NoError()
    if not json.UnmarshalLenient(http.Body(ctx), b, e):
        http.SetStatus(ctx, 400)
        http.Json(ctx, "{" + json.Member("error", e.message) + "}")
        ret
    end
    b.id = books.len() + 1
    books.push(b)
    http.SetStatus(ctx, 201)
    http.SetHeader(ctx, "Location", "/books/" + b.id)
    http.Json(ctx, json.Marshal(b))
end

func main:
    mut r := router.NewRouter()
    router.Get(r, "/books", list)
    router.Get(r, "/books/:id", show)
    router.Post(r, "/books", create)
    mut s := http.NewServer(19761)
    http.Use(s, r)
    _ := http.RunBackground(s)
    base := "http://127.0.0.1:19761"
    a := http.Post(base + "/books", `{"title": "The Little Prince"}`)
    println http.Status(a), http.GetHeader(a, "location"), http.Body(a)
    _ := http.Post(base + "/books", `{"title": "Rumi"}`)
    println http.Body(http.Get(base + "/books"))
    println http.Body(http.Get(base + "/books/2"))
    c := http.Get(base + "/books/9")
    println http.Status(c), http.Body(c)
    d := http.Post(base + "/books", `{"title": 7}`)
    println http.Status(d), http.Body(d)
end
Output201 /books/1 {"id":1,"title":"The Little Prince"} [{"id":1,"title":"The Little Prince"},{"id":2,"title":"Rumi"}] {"id":2,"title":"Rumi"} 404 {"error":"no such book"} 400 {"error": "value does not match the expected type"}

Nothing is sent until the handler returns: the status, the headers and the body are collected and go out together, and a second body call replaces the first. That is why a handler returns right after it writes an error. A 201 with a Location header is the usual answer to a create, and a 404 with a short JSON error is easier for a client to handle than an empty page. Path parameters such as :id always arrive as text, so convert them with conv.Atoi before comparing.

HTML forms, query strings and redirects

A browser form arrives as application/x-www-form-urlencoded. Form reads one field and decodes it, so %40 becomes @ and + becomes a space. Query does the same for the query string. After a successful POST, answer with Redirect so that pressing reload in the browser does not send the form again.

net-http-guide-forms.salam
import net.http
import net.router
import template

mut messages := Vector {} as Vector<str>

func board(ctx: i64):
    mut html := "<ul>"
    each m in messages:
        html = html + "<li>" + template.EscapeHTML(m) + "</li>"
    end
    http.Html(ctx, html + "</ul>")
end

func post(ctx: i64):
    name := http.Form(ctx, "name")
    text := http.Form(ctx, "text")
    if name == "" or text == "":
        http.SetStatus(ctx, 400)
        http.Text(ctx, "name and text are required")
        ret
    end
    messages.push(name + ": " + text)
    http.Redirect(ctx, "/board")
end

func search(ctx: i64):
    word := http.Query(ctx, "q")
    mut found := 0
    each m in messages:
        if m.find(word) >= 0:
            found += 1
        end
    end
    http.Text(ctx, "'" + word + "' found in " + found + " message(s)")
end

func main:
    mut r := router.NewRouter()
    router.Get(r, "/board", board)
    router.Post(r, "/board", post)
    router.Get(r, "/search", search)
    mut s := http.NewServer(19762)
    http.Use(s, r)
    _ := http.RunBackground(s)
    base := "http://127.0.0.1:19762"
    mut form := http.NewHeaders()
    form.insert("name", "Sara")
    form.insert("text", "see you at 5 & bring tea")
    mut headers := http.NewHeaders()
    headers.insert("Content-Type", "application/x-www-form-urlencoded")
    a := http.PostWith(base + "/board", http.EncodeForm(form), headers)
    println http.Status(a), http.GetHeader(a, "location")
    b := http.PostWith(base + "/board", "name=Reza", headers)
    println http.Status(b), http.Body(b)
    println http.Body(http.Get(base + "/board"))
    mut q := http.NewHeaders()
    q.insert("q", "bring tea")
    println http.Body(http.Get(http.WithQuery(base + "/search", q)))
end
Output302 /board 400 name and text are required <ul><li>Sara: see you at 5 &amp; bring tea</li></ul> 'bring tea' found in 1 message(s)

Anything a user typed must be escaped before it goes into HTML; otherwise a message containing <script> runs in every visitor's browser. template.EscapeHTML does that, as the &amp; in the output shows. On the client side, EncodeForm builds a form body from a map and WithQuery adds a query string to a URL, both with correct escaping.

Route groups and a login check

router.Group puts a route under a common prefix, which is how an API is versioned under /api/v1. There is no separate middleware chain: a check that several handlers share is a plain function that returns true when the request may go on, or writes the error response itself and returns false. Each handler calls it on its first line and returns when it fails.

net-http-guide-groups.salam
import net.http
import net.router

func signed_in(ctx: i64): bool:
    if http.Header(ctx, "Authorization") == "Bearer s3cret":
        ret true
    end
    http.SetStatus(ctx, 401)
    http.SetHeader(ctx, "WWW-Authenticate", "Bearer")
    http.Json(ctx, `{"error":"sign in first"}`)
    ret false
end

func health(ctx: i64):
    http.Text(ctx, "ok")
end

func profile(ctx: i64):
    if not signed_in(ctx): ret end
    http.Json(ctx, `{"user":"maryam"}`)
end

func remove(ctx: i64):
    if not signed_in(ctx): ret end
    http.SetStatus(ctx, 204)
    http.Text(ctx, "")
end

func main:
    mut r := router.NewRouter()
    router.Get(r, "/health", health)
    router.Group(r, "/api/v1", "GET", "/profile", profile)
    router.Group(r, "/api/v1", "DELETE", "/posts/:id", remove)
    mut s := http.NewServer(19763)
    http.Use(s, r)
    _ := http.RunBackground(s)
    base := "http://127.0.0.1:19763"
    println http.Body(http.Get(base + "/health"))
    a := http.Get(base + "/api/v1/profile")
    println http.Status(a), http.GetHeader(a, "www-authenticate"), http.Body(a)
    mut auth := http.NewHeaders()
    auth.insert("Authorization", "Bearer s3cret")
    println http.Body(http.GetWith(base + "/api/v1/profile", auth))
    println http.Status(http.DeleteWith(base + "/api/v1/posts/3", auth))
    println http.Status(http.Get(base + "/profile"))
end
Outputok 401 Bearer {"error":"sign in first"} {"user":"maryam"} 204 404

A route that is not registered answers 404 on its own, so /profile without the prefix is not found. For a cookie based login instead of a token, see net/http/session.

Static files and server settings

router.Static serves a whole directory under a prefix, with the content type taken from the file extension. A path that tries to climb out of the directory with .. is refused, and a missing file is a 404. HideTokens drops the version number from the Server header, so the answer says only Salam.

net-http-guide-static.salam
import net.http
import net.router
import os

func main:
    _ := os.MkdirAll("public/css")
    _ := os.WriteFile("public/index.html", "<h1>Welcome</h1>")
    _ := os.WriteFile("public/css/site.css", "body { margin: 0 }")
    mut r := router.NewRouter()
    router.Static(r, "/site", "public")
    mut s := http.NewServer(19764)
    http.HideTokens(s)
    http.Use(s, r)
    _ := http.RunBackground(s)
    base := "http://127.0.0.1:19764"
    a := http.Get(base + "/site/index.html")
    println http.Status(a), http.GetHeader(a, "content-type"), http.Body(a)
    b := http.Get(base + "/site/css/site.css")
    println http.GetHeader(b, "content-type"), http.Body(b)
    println http.Status(http.Get(base + "/site/missing.png"))
    println http.Status(http.Get(base + "/site/../secret.txt"))
    println http.GetHeader(a, "server")
end
Output200 text/html; charset=utf-8 <h1>Welcome</h1> text/css body { margin: 0 } 404 404 Salam

Running a real server

The examples above use RunBackground so that one program can be both the server and its own client. A real service calls Run, which never returns. Read the port from the environment, listen on 0.0.0.0 when the server sits in a container or behind a proxy, and turn on the access log while you are getting it running.

net-http-guide-server.salam
import net.http
import net.router
import os
import conv

func home(ctx: i64):
    http.Html(ctx, "<h1>Salam</h1>")
end

func health(ctx: i64):
    http.Json(ctx, `{"status":"ok"}`)
end

func main:
    mut port := 8080
    if os.Env("PORT") != "":
        port = conv.Atoi(os.Env("PORT"))
    end
    http.SetMaxBodyBytes(1048576)
    http.SetKeepAliveIdle(5000)
    mut r := router.NewRouter()
    router.Get(r, "/", home)
    router.Get(r, "/health", health)
    router.Static(r, "/assets", "public")
    mut s := http.NewServer(port)
    http.SetHost(s, "0.0.0.0")
    http.HideTokens(s)
    http.EnableAccessLog(s)
    http.Use(s, r)
    println "listening on port " + port
    http.Run(s)
end

Run it and try it from a second terminal:

PORT=8080 salam run server.salam
curl http://127.0.0.1:8080/health

The limits are for the whole process: SetMaxBodyBytes and SetMaxHeaderBytes reject requests that are too large, SetKeepAliveIdle closes idle connections, and SetKeepAliveMaxRequests caps how many requests one connection may send. For HTTPS, call RunTLS with a certificate and key file instead of Run, or put the server behind a proxy that handles TLS.

Calling an API as a client

Get, Post and the other one-line calls send a request and return a Response; the ...With forms take a map of extra headers. The program below shows the four answers a client has to handle. A Post without a content type reaches the server as a form, so a JSON API refuses it with 415; the same body through PostWith with Content-Type: application/json creates the ticket. A redirect is not followed, so Get returns the 302 and you read Location yourself. A server that is not running gives status 0 and the reason in Error.

net-http-guide-client.salam
import net.http
import net.router
import encoding.json

func create_ticket(ctx: i64):
    kind := http.Header(ctx, "Content-Type")
    if kind != "application/json":
        http.SetStatus(ctx, 415)
        http.Json(ctx, "{\"error\":\"expected JSON, got " + kind + "\"}")
        ret
    end
    title := json.Get(http.Body(ctx), "title")
    http.SetStatus(ctx, 201)
    http.Json(ctx, "{\"id\":31,\"title\":" + json.Str(title) + "}")
end

func old_tickets(ctx: i64): http.Redirect(ctx, "/v2/tickets") end

func main:
    mut r := router.NewRouter()
    router.Post(r, "/tickets", create_ticket)
    router.Get(r, "/tickets", old_tickets)
    mut s := http.NewServer(18631)
    http.SetHost(s, "127.0.0.1")
    http.Use(s, r)
    if not http.RunBackground(s):
        println "port 18631 is busy"
        ret 1
    end
    base := "http://127.0.0.1:18631"
    body := `{"title": "Printer is out of paper"}`

    plain := http.Post(base + "/tickets", body)
    println "Post:", http.Status(plain), http.Body(plain)

    mut headers := http.NewHeaders()
    headers.insert("Content-Type", "application/json")
    made := http.PostWith(base + "/tickets", body, headers)
    println "PostWith:", http.Status(made), http.Ok(made), "id", json.GetInt(http.Body(made), "id")

    moved := http.Get(base + "/tickets")
    println "Get:", http.Status(moved), "Location:", http.GetHeader(moved, "location")

    down := http.Get("http://127.0.0.1:1/tickets")
    println "dead server:", http.Status(down), http.Ok(down), http.Error(down)
    ret 0
end
OutputPost: 415 {"error":"expected JSON, got application/x-www-form-urlencoded"} PostWith: 201 true id 31 Get: 302 Location: /v2/tickets dead server: 0 false could not connect to 127.0.0.1:1

Gzip and chunked answers are decoded for you, and every request is sent with Connection: close. For a series of calls that share a login, NewClient keeps the cookies from each answer and sends them with the next request, plus any headers set with SetHeader. A cookie is sent back only to the host that set it; a cookie you add with SetCookie goes to the host of the first request, never to a host a redirect leads to.

Any number of threads can use the one-line calls at once, because a call keeps no state outside itself. A Client from NewClient can be shared by threads too: it carries its own lock, so SetHeader, the cookie jar and the settings stay consistent. Call Free when you are done with a shared client. A Client {} written as a literal has no lock and belongs to one thread.

Raw requests: your own headers, bytes and time limits

The one-line calls above build the request for you. When you need full control of the request line and headers, for example to sign a request, to send a binary body or to talk to an API with unusual headers, write the request head yourself and send it with SendRaw. The aws, webpush, db/meilisearch, db/elasticsearch and db/typesense packages are built on these calls. The examples run against a small server in a thread of the same program, so they need no network.

Every raw call takes an Endpoint from ParseEndpoint (host, port and TLS on or off; any path in the URL is dropped, because the path goes in your request line) and a request head: the request line, the headers and an empty line, each line ending in \r\n. The body is a pointer and a length, so it can hold any bytes. The answer is a RawResponse with the body as bytes, chunked bodies already decoded, freed with FreeRaw. SendRaw waits as long as the server does; SendRawTimeout adds a time limit in milliseconds; SendRawTLS adds your own tls.Config. A response larger than RawLimit (256 MB by default) is reported as an error.

Things that catch people out:

  • Send Connection: close unless the answer is framed. The raw calls stop as soon as an answer with a Content-Length or a chunked body is complete. An answer with neither is read until the server closes the connection, so on a kept-alive connection the call waits until then (or until the time limit).
  • ok means a 2xx status, not "an answer arrived". Check status to tell a 404 from a dead server.
  • A str stops at the first zero byte, so binary bodies stay in data; RawText cuts at the first zero.

POST JSON with your own headers

ParseEndpoint turns a URL into the host, port and whether to use TLS. The request head is plain text that you write: the request line, a Host header, and here an Authorization token, the content type and the body length, closed by an empty line. SendRawTimeout sends the head and the body and returns the answer; RawText turns the reply body into a str. HeaderValue finds a header in the response head, ignoring case.

net-http-raw-post-json.salam
import net.http
import net.tcp
import encoding.json

mut server := tcp.Server {}

func read_request(conn: tcp.Conn): str:
    mut got := tcp.Read(conn, 4096)
    until got.find("\r\n\r\n") < 0:
        got += tcp.Read(conn, 4096)
    end
    head_end := got.find("\r\n\r\n") + 4
    want := http.HeaderValue(got, "content-length").to_int()
    until got.len() < head_end + want:
        got += tcp.Read(conn, 4096)
    end
    ret got
end

func api():
    conn := tcp.Accept(server)
    request := read_request(conn)
    at := request.find("\r\n\r\n") + 4
    body := request.substr(at, request.len() - at)
    name := json.Get(body, "name")
    auth := http.HeaderValue(request, "authorization")
    reply := "{\"id\": 7, \"name\": \"" + name + "\", \"auth\": \"" + auth + "\"}"
    head := "HTTP/1.1 201 Created\r\nContent-Type: application/json\r\nLocation: /users/7\r\nContent-Length: " + reply.len() + "\r\nConnection: close\r\n\r\n"
    _ := tcp.Write(conn, head + reply)
    tcp.Close(conn)
end

func main:
    server = tcp.Bind(0)
    t := spawn(api)
    ep := http.ParseEndpoint("http://127.0.0.1:" + tcp.Port(server))
    body := `{"name": "Sara", "role": "editor"}`
    mut head := "POST /users HTTP/1.1\r\n"
    head += "Host: 127.0.0.1\r\n"
    head += "Authorization: Bearer abc123\r\n"
    head += "Content-Type: application/json\r\n"
    head += "Content-Length: " + body.len() + "\r\n"
    head += "Connection: close\r\n\r\n"
    mut r := http.SendRawTimeout(ep, head, body as void*, body.len(), 5000)
    reply := http.RawText(r)
    http.FreeRaw(r)
    join(t)
    tcp.CloseServer(server)
    println "status:", r.status, r.ok
    println "location:", http.HeaderValue(r.head, "Location")
    println "id:", json.GetInt(reply, "id")
    println "body:", reply
end
Outputstatus: 201 true location: /users/7 id: 7 body: {"id": 7, "name": "Sara", "auth": "Bearer abc123"}

Content-Length must be the length in bytes, which is what str.len() returns, so it stays right for text in any language. A wrong length makes servers wait for more data or cut the body.

Status codes and failures

A RawResponse tells three cases apart. ok is true only for a 2xx status. A 4xx or 5xx answer still has its status and a body, which usually explain the problem. When no answer came at all, because the connection was refused, the host was unknown or the URL could not be parsed, status is 0 and error says why.

net-http-raw-status-errors.salam
import net.http
import net.tcp

mut server := tcp.Server {}

func api():
    repeat 2:
        conn := tcp.Accept(server)
        request := tcp.Read(conn, 4096)
        if request.find("GET /missing ") == 0:
            tcp.WriteHTTP(conn, "404 Not Found", "application/json", `{"error": "no such page"}`)
        else:
            tcp.WriteHTTP(conn, "503 Service Unavailable", "text/plain", "try again later")
        end
        tcp.Close(conn)
    end
end

func get(ep: http.Endpoint, path: str):
    head := "GET " + path + " HTTP/1.1\r\nHost: " + ep.host + "\r\nConnection: close\r\n\r\n"
    mut r := http.SendRawTimeout(ep, head, null, 0, 5000)
    body := http.RawText(r)
    if r.ok:
        println path, "worked:", body
    else r.status > 0:
        println path, "answered", r.status, "with", body
    else:
        println path, "failed:", r.error
    end
    http.FreeRaw(r)
end

func main:
    server = tcp.Bind(0)
    t := spawn(api)
    ep := http.ParseEndpoint("http://127.0.0.1:" + tcp.Port(server))
    get(ep, "/missing")

Chunked answers and time limits

A server that does not know the length of its answer in advance sends it in chunks, each one prefixed by its size in hex. SendRawTimeout removes that framing for you. The last parameter of SendRawTimeout is a time limit in milliseconds for each read and write, and on Linux also for the connect, so a server that accepts the connection and then says nothing cannot hang the program. The second request below hits such a server with a 300 ms limit.

net-http-raw-chunked.salam
import net.http
import net.tcp

mut server := tcp.Server {}

    repeat 2 in i:
        conn := tcp.Accept(server)
        _ := tcp.Read(conn, 4096)

            _ := tcp.Write(conn, "HTTP/1.1 200 OK\r\nContent-Type: text/plain\r\nTransfer-Encoding: chunked\r\n\r\n6\r\nnews: \r\n9\r\nall quiet\r\n0\r\n\r\n")
        else:
            _ := tcp.Read(conn, 4096)
        end
        tcp.Close(conn)
    end
end

func main:
    server = tcp.Bind(0)
    t := spawn(feed)
    ep := http.ParseEndpoint("http://127.0.0.1:" + tcp.Port(server))

    mut raw := http.SendRawTimeout(ep, head, null, 0, 2000)
    println "body:", http.RawText(raw)
    http.FreeRaw(raw)

    mut slow := http.SendRawTimeout(ep, head, null, 0, 300)

A timeout is reported as the request timed out and an answer cut short by a closing connection as the response body was cut short; both are worth a retry later. SendRaw has no time limit at all; give SendRawTimeout a limit for any server you do not control. SendRawTLS takes the same limit plus a tls.Config for a private CA.

Binary downloads

A str ends at the first zero byte, so an image or a zip file turned into one is cut short. Read it from the RawResponse instead: data points at the body bytes and len is their count. The program downloads twelve bytes of a PNG header and shows that RawText, which turns the body into a str, keeps only the eight bytes before the first zero.

net-http-raw-binary.salam
import net.http
import net.tcp
import mem
import conv

mut server := tcp.Server {}

func files():
    conn := tcp.Accept(server)
    _ := tcp.Read(conn, 4096)
    image := [137, 80, 78, 71, 13, 10, 26, 10, 0, 0, 0, 13]
    buf := mem.Allocate(12 as u64) as u8*
    repeat 12 in i:
        buf[i] = image[i] as u8
    end
    _ := tcp.Write(conn, "HTTP/1.1 200 OK\r\nContent-Type: image/png\r\nContent-Length: 12\r\nConnection: close\r\n\r\n")
    _ := tcp.WriteBytes(conn, buf as void*, 12)
    mem.Free(buf as void*)
    tcp.Close(conn)
end

func main:
    server = tcp.Bind(0)
    t := spawn(files)
    ep := http.ParseEndpoint("http://127.0.0.1:" + tcp.Port(server))
    head := "GET /logo.png HTTP/1.1\r\nHost: 127.0.0.1\r\nConnection: close\r\n\r\n"

    join(t)
    tcp.CloseServer(server)
    println r.ok, r.status, http.HeaderValue(r.head, "content-type")
    println "bytes received:", r.len

    mut hex := ""
    repeat r.len in i:
        if i > 0: hex += " " end
        if bytes[i] < 16: hex += "0" end
        hex += conv.FormatHex(bytes[i] as u64)
    end
    println hex
    println "is a PNG:", r.len >= 4 and bytes[1] as int == 80 and bytes[2] as int == 78 and bytes[3] as int == 71
    println "RawText keeps", http.RawText(r).len(), "bytes"
    http.FreeRaw(r)
end

Timeouts, limits and redirects

Client requests run under the limits below. RequestOptions holds the limits and Do sends a request with them; a Client keeps its own copy, changed with SetTimeout, SetIdleTimeout, SetMaxRedirects and SetMaxBody. idle_ms (30 seconds by default) is how long one read or write may stall, timeout_ms (off by default) is the time for the whole request including redirects, and max_body (256 MB by default) bounds the body, also after gzip is unpacked, so a small compressed answer cannot fill memory. Looking up a host name is done by the system resolver, and on systems other than Linux the connect itself waits the system default; neither is covered by these limits. A request that runs out of time reports the request timed out, and an answer cut short by a closing connection is an error rather than a smaller body.

Redirects are followed only when max_redirects is above zero. A 301 or 302 after a POST and every 303 turn into a GET without the body; 307 and 308 repeat the request as it was. When a redirect leads to another host, the Authorization and Cookie headers are dropped, and a redirect from https to http is refused. The final address is in the url field of the response.

The request is checked before anything is sent: a method, header name or address with a space or a control character, and a header value with a line break, are refused with a message in err, so a value taken from outside cannot add headers to the request. A Content-Length, Transfer-Encoding, Connection or Accept-Encoding header of yours is replaced by the one the client computes. The example sends a request to a server that answers late and one that never answers, follows a redirect and refuses an answer that is too large.

import mem
import str
import compress
import net.http
import net.mime
import net.router

func echo(ctx: i64):
    n := http.BodyLen(ctx)
    p := http.BodyBytes(ctx) as u8*
    mut zeros := 0
    repeat n in i:
        if p[i] == 0 as u8: zeros += 1 end
    end
    http.SetHeader(ctx, "X-Zeros", http.Own(ctx, str.FromInt(zeros as i64)))
    http.Bytes(ctx, "application/octet-stream", http.BodyBytes(ctx), n)
end

func upload(ctx: i64):
    mut parts := http.Multipart(ctx)
    defer mime.FreeMultipart(parts)
    if parts.items.len() == 0:
        http.SetStatus(ctx, 400)
        http.Text(ctx, "not multipart")
        ret
    end
    mut answer := ""
    each part in parts.items:
        answer = answer + part.name + ":" + part.filename + ":" + str.FromInt(part.body.len as i64) + " "
    end
    answer = answer + "note=" + mime.PartValue(parts, "note")
    http.Text(ctx, http.Own(ctx, answer))
end

    router.Post(r, "/echo", echo)
    router.Post(r, "/upload", upload)
    mut s := http.NewServer(19645)
    http.Use(s, r)
    println http.RunBackground(s)
    ep := http.ParseEndpoint("http://127.0.0.1:19645")

    println a.status, a.len, http.HeaderValue(a.head, "x-zeros"), http.HeaderValue(a.head, "content-type")
    println back[0] as int, back[1] as int, back[2] as int, back[3] as int
