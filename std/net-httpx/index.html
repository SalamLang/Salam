net/httpx

Sending a raw HTTP request with headers of your own and taking the response as text or bytes.

import net.httpx
On this page

  6. HTTPS
  7. Types

This package sends one HTTP/1.1 request that you write by hand and gives back the answer as it came. Reach for it when you need full control of the request line and headers, for example to sign a request or to talk to an API with unusual headers; the aws, webpush, db/meilisearch, db/elasticsearch and db/typesense packages are built on it. For everyday requests, with headers in a map, redirects and cookies, use net/http. The examples run against a small server in a thread of the same program, so they need no network.

Every call takes an Endpoint from ParseEndpoint (host, port and TLS on or off; any path in the URL is dropped, because the path goes in your request line) and a request head: the request line, the headers and an empty line, each line ending in \r\n. There are two families of calls:

CallBody asChunked bodiesTime limitSize limit
Send, SendTextstr in a Responseleft encodednonestops reading at 32 MB, silently
SendRaw, SendRawTimeout, SendRawTLSbytes in a Raw, freed with FreeRawdecodedoptional, in millisecondsRawLimit, 256 MB by default, reported as an error

Things that catch people out:

  • Always send Connection: close. Both families read until the server closes the connection; on a kept-alive connection the call waits forever (or until the time limit).
  • SendText does not decode Transfer-Encoding: chunked. Many servers chunk their answers; use the raw calls, or the body has chunk sizes mixed into it.
  • ok means a 2xx status, not "an answer arrived". Check status to tell a 404 from a dead server.
  • A str stops at the first zero byte, so binary bodies need the raw calls.

POST JSON with your own headers

ParseEndpoint turns a URL into the host, port and whether to use TLS. The request head is plain text that you write: the request line, a Host header, and here an Authorization token, the content type and the body length, closed by an empty line. SendText sends the head and the body and returns the answer. HeaderValue finds a header in the response head, ignoring case.

net-httpx-post-json.salam
import net.httpx
import net.tcp
import encoding.json

mut server := tcp.Server {}

func read_request(conn: tcp.Conn): str:
    mut got := tcp.Read(conn, 4096)
    until got.find("\r\n\r\n") < 0:
        got += tcp.Read(conn, 4096)
    end
    head_end := got.find("\r\n\r\n") + 4
    want := httpx.HeaderValue(got, "content-length").to_int()
    until got.len() < head_end + want:
        got += tcp.Read(conn, 4096)
    end
    ret got
end

func api():
    conn := tcp.Accept(server)
    request := read_request(conn)
    at := request.find("\r\n\r\n") + 4
    body := request.substr(at, request.len() - at)
    name := json.Get(body, "name")
    auth := httpx.HeaderValue(request, "authorization")
    reply := "{\"id\": 7, \"name\": \"" + name + "\", \"auth\": \"" + auth + "\"}"
    head := "HTTP/1.1 201 Created\r\nContent-Type: application/json\r\nLocation: /users/7\r\nContent-Length: " + reply.len() + "\r\nConnection: close\r\n\r\n"
    _ := tcp.Write(conn, head + reply)
    tcp.Close(conn)
end

func main:
    server = tcp.Bind(0)
    t := spawn(api)
    ep := httpx.ParseEndpoint("http://127.0.0.1:" + tcp.Port(server))
    body := `{"name": "Sara", "role": "editor"}`
    mut head := "POST /users HTTP/1.1\r\n"
    head += "Host: 127.0.0.1\r\n"
    head += "Authorization: Bearer abc123\r\n"
    head += "Content-Type: application/json\r\n"
    head += "Content-Length: " + body.len() + "\r\n"
    head += "Connection: close\r\n\r\n"
    r := httpx.SendText(ep, head, body)
    join(t)
    tcp.CloseServer(server)
    println "status:", r.status, r.ok
    println "location:", httpx.HeaderValue(r.head, "Location")
    println "id:", json.GetInt(r.body, "id")
    println "body:", r.body
end
Outputstatus: 201 true location: /users/7 id: 7 body: {"id": 7, "name": "Sara", "auth": "Bearer abc123"}

Content-Length must be the length in bytes, which is what str.len() returns, so it stays right for text in any language. A wrong length makes servers wait for more data or cut the body.

Status codes and failures

A Response tells three cases apart. ok is true only for a 2xx status. A 4xx or 5xx answer still has its status and body, which usually explain the problem. When no answer came at all, because the connection was refused, the host was unknown or the URL could not be parsed, status is 0 and error says why.

net-httpx-status-errors.salam
import net.httpx
import net.tcp

mut server := tcp.Server {}

func api():
    repeat 2:
        conn := tcp.Accept(server)
        request := tcp.Read(conn, 4096)
        if request.find("GET /missing ") == 0:
            tcp.WriteHTTP(conn, "404 Not Found", "application/json", `{"error": "no such page"}`)
        else:
            tcp.WriteHTTP(conn, "503 Service Unavailable", "text/plain", "try again later")
        end
        tcp.Close(conn)
    end
end

func get(ep: httpx.Endpoint, path: str):
    head := "GET " + path + " HTTP/1.1\r\nHost: " + ep.host + "\r\nConnection: close\r\n\r\n"
    r := httpx.SendText(ep, head, "")
    if r.ok:
        println path, "worked:", r.body
    else r.status > 0:
        println path, "answered", r.status, "with", r.body
    else:
        println path, "failed:", r.error
    end
end

func main:
    server = tcp.Bind(0)
    t := spawn(api)
    ep := httpx.ParseEndpoint("http://127.0.0.1:" + tcp.Port(server))
    get(ep, "/missing")
    get(ep, "/busy")
    join(t)
    tcp.CloseServer(server)
    get(httpx.ParseEndpoint("http://127.0.0.1:1"), "/nobody-listens")
    bad := httpx.ParseEndpoint("ftp://files.example.com")
    println "ftp endpoint ok:", bad.ok
    get(bad, "/")
end
Output/missing answered 404 with {"error": "no such page"} /busy answered 503 with try again later /nobody-listens failed: could not connect to 127.0.0.1:1 ftp endpoint ok: false / failed: the endpoint could not be parsed

A 503 or 429 often means "try again later"; read Retry-After with HeaderValue before you retry, and do not retry a 4xx such as 404, which will not change.

A small API client

A struct that holds the endpoint and the token, with one method per kind of request, keeps the header writing in one place. The JSON in the replies is read with encoding/json: json.Get for a field and json.Items to walk an array.

net-httpx-api-client.salam
import net.httpx
import net.tcp
import encoding.json

mut server := tcp.Server {}

struct Api:
    pub ep: httpx.Endpoint = httpx.Endpoint {}
    pub token: str = ""

    pub func get(path: str): httpx.Response:
        mut head := "GET " + path + " HTTP/1.1\r\n"
        head += "Host: " + this.ep.host + "\r\n"
        head += "Authorization: Bearer " + this.token + "\r\n"
        head += "Accept: application/json\r\n"
        head += "Connection: close\r\n\r\n"
        ret httpx.SendText(this.ep, head, "")
    end
end

func backend():
    repeat 2:
        conn := tcp.Accept(server)
        request := tcp.Read(conn, 4096)
        if request.find("GET /users/7 ") == 0:
            tcp.WriteHTTP(conn, "200 OK", "application/json", `{"id": 7, "name": "Sara", "city": "Shiraz"}`)
        else:
            tcp.WriteHTTP(conn, "200 OK", "application/json", `[{"item": "pen", "qty": 3}, {"item": "notebook", "qty": 1}]`)
        end
        tcp.Close(conn)
    end
end

func main:
    server = tcp.Bind(0)
    t := spawn(backend)
    api := Api { ep = httpx.ParseEndpoint("http://127.0.0.1:" + tcp.Port(server)), token = "abc123" }
    user := api.get("/users/7")
    println json.Get(user.body, "name"), "from", json.Get(user.body, "city")
    orders := api.get("/users/7/orders")
    each order in json.Items(orders.body):
        println " ", json.GetInt(order, "qty"), "x", json.Get(order, "item")
    end
    join(t)
    tcp.CloseServer(server)
end
OutputSara from Shiraz 3 x pen 1 x notebook

Chunked answers and time limits

A server that does not know the length of its answer in advance sends it in chunks, each one prefixed by its size in hex. SendText hands you that framing as it arrived; SendRawTimeout removes it. The last parameter of SendRawTimeout is a time limit in milliseconds for each read and write, so a server that accepts the connection and then says nothing cannot hang the program. The third request below hits such a server with a 300 ms limit.

net-httpx-chunked.salam
import net.httpx
import net.tcp
import str

mut server := tcp.Server {}

func feed():
    repeat 3 in i:
        conn := tcp.Accept(server)
        _ := tcp.Read(conn, 4096)
        if i < 2:
            _ := tcp.Write(conn, "HTTP/1.1 200 OK\r\nContent-Type: text/plain\r\nTransfer-Encoding: chunked\r\n\r\n6\r\nnews: \r\n9\r\nall quiet\r\n0\r\n\r\n")
        else:
            _ := tcp.Read(conn, 4096)
        end
        tcp.Close(conn)
    end
end

func main:
    server = tcp.Bind(0)
    t := spawn(feed)
    ep := httpx.ParseEndpoint("http://127.0.0.1:" + tcp.Port(server))
    head := "GET /feed HTTP/1.1\r\nHost: 127.0.0.1\r\nConnection: close\r\n\r\n"

    text := httpx.SendText(ep, head, "")
    println "SendText body:", str.Replace(text.body, "\r\n", "|")

    mut raw := httpx.SendRawTimeout(ep, head, null, 0, 2000)
    println "SendRaw body:", httpx.RawText(raw)
    httpx.FreeRaw(raw)

    mut slow := httpx.SendRawTimeout(ep, head, null, 0, 300)
    println "silent server:", slow.ok, slow.status, slow.error
    httpx.FreeRaw(slow)
    join(t)
    tcp.CloseServer(server)
end
OutputSendText body: 6|news: |9|all quiet|0|| SendRaw body: news: all quiet silent server: false 0 the server closed without answering

A timeout is reported with the same message as a server that closed without answering, so treat both as "try again later". Send and SendText have no time limit at all; use the raw calls for any server you do not control. SendRawTLS takes the same limit plus a tls.Config for a private CA.

Binary downloads

A str ends at the first zero byte, so an image or a zip file read through SendText is cut short. Use SendRawTimeout instead: data points at the body bytes and len is their count. The program downloads twelve bytes of a PNG header and shows that RawText, which turns the body into a str, keeps only the eight bytes before the first zero.

net-httpx-binary.salam
import net.httpx
import net.tcp
import mem
import conv

mut server := tcp.Server {}

func files():
    conn := tcp.Accept(server)
    _ := tcp.Read(conn, 4096)
    image := [137, 80, 78, 71, 13, 10, 26, 10, 0, 0, 0, 13]
    buf := mem.Allocate(12 as u64) as u8*
    repeat 12 in i:
        buf[i] = image[i] as u8
    end
    _ := tcp.Write(conn, "HTTP/1.1 200 OK\r\nContent-Type: image/png\r\nContent-Length: 12\r\nConnection: close\r\n\r\n")
    _ := tcp.WriteBytes(conn, buf as void*, 12)
    mem.Free(buf as void*)
    tcp.Close(conn)
end

func main:
    server = tcp.Bind(0)
    t := spawn(files)
    ep := httpx.ParseEndpoint("http://127.0.0.1:" + tcp.Port(server))
    head := "GET /logo.png HTTP/1.1\r\nHost: 127.0.0.1\r\nConnection: close\r\n\r\n"
    mut r := httpx.SendRawTimeout(ep, head, null, 0, 5000)
    join(t)
    tcp.CloseServer(server)
    println r.ok, r.status, httpx.HeaderValue(r.head, "content-type")
    println "bytes received:", r.len
    bytes := r.data as u8*
    mut hex := ""
    repeat r.len in i:
        if i > 0: hex += " " end
        if bytes[i] < 16: hex += "0" end
        hex += conv.FormatHex(bytes[i] as u64)
    end
    println hex
    println "is a PNG:", r.len >= 4 and bytes[1] as int == 80 and bytes[2] as int == 78 and bytes[3] as int == 71
    println "RawText keeps", httpx.RawText(r).len(), "bytes"
    httpx.FreeRaw(r)
end
Outputtrue 200 image/png bytes received: 12 89 50 4e 47 0d 0a 1a 0a 00 00 00 0d is a PNG: true RawText keeps 8 bytes

A Raw body is limited to RawLimit bytes, 256 MB unless you change it with SetRawLimit; a larger answer is reported as an error instead of filling memory. The data buffer belongs to you until FreeRaw.

HTTPS

An https:// URL gives an endpoint with secure set, and the same calls then speak TLS through tls, checking the server certificate. Nothing else changes. This example asks the GitHub API about the Salam repository, so it needs the internet; GitHub requires a User-Agent header.

net-httpx-https.salam
import net.httpx
import encoding.json

func main:
    ep := httpx.ParseEndpoint("https://api.github.com")
    println ep.host, ep.port, ep.secure
    mut head := "GET /repos/SalamLang/Salam HTTP/1.1\r\n"
    head += "Host: api.github.com\r\n"
    head += "User-Agent: salam-example\r\n"
    head += "Accept: application/vnd.github+json\r\n"
    head += "Connection: close\r\n\r\n"
    r := httpx.SendText(ep, head, "")
    if r.status == 0:
        println "request failed:", r.error
        ret 1
    end
    println "status:", r.status
    println "rate limit left:", httpx.HeaderValue(r.head, "x-ratelimit-remaining")
    if r.ok:
        println json.Get(r.body, "full_name"), "is written in", json.Get(r.body, "language")
    end
    ret 0
end

When this page was written it printed:

api.github.com 443 true
status: 200
rate limit left: 58
SalamLang/Salam is written in TeX

The rate limit number counts down with each call from your address, and the language is what GitHub detects for the repository at the time.

net-httpx-Send.salam
import tls
import net.httpx
import net.tcp
import mem

mut server := tcp.Server {}

func responder():
    repeat 3:
        conn := tcp.Accept(server)
        _ := tcp.Read(conn, 4096)
        tcp.WriteHTTP(conn, "200 OK", "text/plain", "hello from the server")
        tcp.Close(conn)
    end
end

func main:
    remote := httpx.ParseEndpoint("https://api.example.com:8443")
    println remote.ok, remote.host, remote.port, remote.secure
    server = tcp.Bind(0)
    t := spawn(responder)
    local := httpx.ParseEndpoint("http://127.0.0.1:" + tcp.Port(server))
    head := "GET / HTTP/1.1\r\nHost: 127.0.0.1\r\nConnection: close\r\n\r\n"
    r := httpx.SendText(local, head, "")
    println r.ok, r.status, r.body, "[" + r.error + "]"
    println httpx.HeaderValue(r.head, "content-type")
    mut raw := httpx.SendRawTimeout(local, head, null, 0, 2000)
    println raw.ok, raw.status, raw.len, httpx.RawText(raw)
    httpx.FreeRaw(raw)
    mut cfg := tls.NewConfig("127.0.0.1")
    cfg.ca_file = "/etc/ssl/certs/ca-certificates.crt"
    mut secured := httpx.SendRawTLS(local, head, null, 0, 2000, cfg)
    println secured.status, secured.len
    httpx.FreeRaw(secured)
    join(t)
    tcp.CloseServer(server)
    println httpx.RawLimit() > 0
    httpx.SetRawLimit(1024 * 1024)
    println httpx.RawLimit()
    mut n := 0
    p := httpx.CopyOut("abc", n)
    println n
    mem.Free(p)
    r2 := httpx.Send(local, head, null, 0)
    raw2 := httpx.SendRaw(local, head, null, 0)
    println r2.ok, raw2.ok
end
Outputtrue api.example.com 8443 true true 200 hello from the server [] text/plain true 200 21 hello from the server 200 21 true 1048576 3 false false

ParseEndpoint

func ParseEndpoint(endpoint: str): Endpoint
Reads an address such as https://api.example.com:8443; the default port is 80 for http and 443 for https. A path after the host is ignored.

Send

func Send(ep: Endpoint, head: str, body: void*, n: int): Response
Sends the request head you wrote and n bytes of body from a pointer, then reads until the server closes. No time limit, no chunked decoding, and reading stops at 32 MB.

The example for this item is shown with the ones above: net-httpx-Send.salam

SendText

func SendText(ep: Endpoint, head: str, body: str): Response
Like Send, with a text body.

The example for this item is shown with the ones above: net-httpx-Send.salam

HeaderValue

func HeaderValue(head: str, name: str): str
The value of one header in the header text; the name is case insensitive.

The example for this item is shown with the ones above: net-httpx-Send.salam

CopyOut

func CopyOut(body: str, out_len &: int): void*
Copies a string into fresh memory, returns the pointer and puts the length in out_len; free the pointer with mem.Free. Returns null for an empty string.

The example for this item is shown with the ones above: net-httpx-Send.salam
