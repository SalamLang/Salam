net.censor

Helpers for networks that interfere with traffic: protocol sniffing and TLS server name reading, ClientHello fragmentation, padding, domain rule sets with Iran lists, a probe guard and a replay cache.

import net.censor

Some networks do not just carry traffic. They look at it: the first bytes of a connection tell a filter which protocol it is, and the server name in the first TLS message tells it which site you are going to. This package is a set of small helpers, each independent of the others, for working with that. Sniff and ParseClientHello read what a filter would read. FragmentClientHello and SNISplitSizes cut that first message into pieces, so that a filter that only looks at one packet never sees the whole name. DomainSet and Classifier decide, from rules, which hosts go direct, through a proxy or nowhere. ProbeGuard, ReplayCache and DecoyResponse are the pieces of a server that does not give itself away to someone who is trying it. To see how the pieces fit together in an app, read Building a v2ray style or VPN app.

It does not open any connection and has no state of its own. It works on bytes and text you give it, so it fits in front of any of the proxy packages: net.tunnel, net.socks, net.httpproxy, net.trojan. None of them calls it for you; you wire it in where you need it.

Core ideas:

  • Sniff needs only the first few bytes and says KindTLS, KindHTTP, KindSSH, KindSOCKS5 or KindSOCKS4, or KindTooShort when it cannot tell yet.
  • ParseClientHello reads a TLS ClientHello without a TLS library: server name, offered protocols, whether Encrypted Client Hello is present.
  • Fragmenting is a plan plus a cut. SplitSizes or SNISplitSizes make the plan (sizes that add up to the total), Slice cuts bytes into plain pieces and FragmentRecords cuts one TLS record into several records. FragmentClientHello does the whole job for a ClientHello.
  • Padding hides sizes: WrapRecord and WrapStream add random padding inside records that look like TLS application data, and UnwrapRecord takes it off.
  • A DomainSet holds domain rules (example.com, full:name, keyword:word); a Classifier has three of them and a default and answers DecisionProxy, DecisionDirect or DecisionBlock.

Things that catch people out:

  • Fragmentation is not encryption and not magic. It helps against filters that look at the first packet or the first record only. Filters change, and many networks reassemble. Test it on the network you actually use, and do not rely on it alone.
  • Padding is not encryption either. WrapStream hides how large the pieces are, not what is in them. Use it inside TLS or another encrypted channel, never in place of one. The padded records use TLS looking headers of this package's own making: they will not pass for real TLS to a careful observer.
  • Fragment before TLS goes out, at the start only. The cut goes on the first record of a handshake. A connection already running is not affected.
  • The Iran lists are starting points. IranDirectList and FilteredList are short, human edited lists that age. Treat them as examples to edit, and keep your own list in a file for AddRules.
  • ProbeGuard and ReplayCache have no lock. They are plain data. When several threads use one, wrap the calls in your own lock. They do not stop a probe by themselves: you call them from your server's accept path.
  • ShouldFallback is a single comparison. A server that has a real website to show is what does the hiding; see the Trojan package.
  • Randomness is secure. RandomInt and RandomBytes draw from the system's secure source. SplitRandom is the one exception: with a seed it is repeatable on purpose, which makes it fine for tests and a poor choice for hiding a pattern.

Fragmenting a TLS hello

A client sends its first TLS message as one record. SNISplitSizes finds the server name in it and plans a cut in the middle of the name; Slice cuts the bytes, and the pieces are sent one after another, each in its own packet. A server reads them as one stream and sees the same message. The example sends a ClientHello in two pieces over loopback and shows what the receiving side reads.

net-censor-guide-fragment.salam
import net.censor
import net.tcp
import sync

const HELLO := "160301008c010000880303000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f206465666768696a6b6c6d6e6f707172737475767778797a7b7c7d7e7f80818283000613011302c02b0100003900000014001200000f7777772e6578616d706c652e636f6d000a00040002001d0010000e000c02683208687474702f312e31002b0003020304"

mut port := 0
mut seen := ""
mut ready := sync.NewWaitGroup()

func server():
    srv := tcp.Bind(0)
    port = tcp.Port(srv)
    sync.Done(ready)
    c := tcp.Accept(srv)
    tcp.SetReadDeadline(c, 1500)
    until true:
        data := tcp.Read(c, 4096)
        if data.len() == 0:
            break
        end
        seen += data.len() + " "
    end
    tcp.Close(c)
end

func main:
    sync.Add(ready, 1 as i64)
    t := spawn(server)
    sync.Wait(ready)

    hello := censor.FromHex(HELLO)
    sizes := censor.SNISplitSizes(hello.data, hello.len, false)
    mut pieces := censor.Slice(hello.data, hello.len, sizes)
    println "server name starts at byte", censor.ParseClientHello(hello.data, hello.len).sni_offset, "and is cut after", sizes.get(0), "bytes"

    conn := tcp.Dial("127.0.0.1", port)
    tcp.SetNoDelay(conn, true)
    repeat pieces.len() in i:
        piece := pieces.get(i)
        tcp.WriteBytes(conn, piece.data, piece.len)
        sync.SleepMs(60)
    end
    tcp.Close(conn)
    join(t)
    println "the server read:", seen
    println "pieces sent:", pieces.len()
    censor.FreePieces(pieces)
end
Outputserver name starts at byte 97 and is cut after 104 bytes the server read: 3 8 pieces sent: 2

That cuts the bytes of the stream, which any TCP server reassembles. FragmentClientHello does something different: it cuts the record into several TLS records, so even a filter that reassembles packets sees the server name split between records. A server that follows TLS accepts both. Send the pieces with a short pause or with the TCP no-delay option on, so that each leaves in its own packet.

Domain rules and the Iran lists

A DomainSet reads rules from text, one per line: example.com matches that domain and everything under it, full:name only that name, keyword:word any host containing the word. A Classifier holds a block set, a proxy set and a direct set and answers in a fixed order: block, then proxy, then direct (the direct set or any private address), then its default. So a rule in the proxy set wins over the direct set, and a private address is direct unless you say otherwise.

mut classifier := censor.NewClassifier(censor.DecisionProxy)
classifier.direct = censor.IranDirectSet()
println censor.Classify(classifier, "www.digikala.com")   // direct
println censor.Classify(classifier, "mail.sharif.ir")     // direct
println censor.Classify(classifier, "youtube.com")        // proxy (the default)

IranDirectList holds .ir and a few large domestic sites; FilteredList holds sites commonly filtered. Both are short and will age: copy them into a file, edit them, and load your own with AddRules. For a router that works on tags, net.tunnel has tunnel.IranRouter and tunnel.ParseRules.

Hiding a server from probes

A server that is being probed sees connections that do not authenticate. The safe answer is to look like an ordinary web server: hand the connection to a real site (ShouldFallback says yes for anything not authenticated), or at least send a plain 404 (DecoyResponse). A ProbeGuard adds a memory: after max_fails failures from one address within window_ms, GuardAllowed says no for ban_ms. A ReplayCache remembers the first bytes of authentications, so that a recorded handshake sent again is noticed (ReplaySeen). A small random wait (DelayMs) before answering a failed client keeps the timing of the failure path from standing out.

if not censor.GuardAllowed(guard, client_ip, now):
    close(connection)
else if not authenticated:
    censor.GuardRecordFail(guard, client_ip, now)
    hand_to_real_website(connection)
end

The net.trojan server already hands failed clients to a real website. These helpers are the extra layer for servers you build yourself.

What to know

  • Every function works on bytes and text you pass in. Nothing here opens a socket or keeps global state.
  • Fragmenting and padding are partial measures, not encryption; use them inside an encrypted channel and test them on your own network.
  • The Iran lists are short and out of date quickly. Keep your own.
  • ProbeGuard and ReplayCache are plain data without a lock and must be freed (FreeProbeGuard, FreeReplayCache); so must the sets, pieces and buffers you create (FreeDomainSet, FreePieces).
  • Addresses are IPv4 text or IPv6 text; the helpers do not resolve names.
  • No logging happens by itself.

import compress
import net.censor

const HELLO := "160301008c010000880303000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f206465666768696a6b6c6d6e6f707172737475767778797a7b7c7d7e7f80818283000613011302c02b0100003900000014001200000f7777772e6578616d706c652e636f6d000a00040002001d0010000e000c02683208687474702f312e31002b0003020304"

func total(v: Vector<int>): int:
    mut sum := 0
    repeat v.len() in i:
        sum += v.get(i)
    end
    ret sum
end

func main:
    hello := censor.FromHex(HELLO)

    even := censor.SplitSizes(100, censor.SplitEven, 3, 0, 1 as i64)
    println even.get(0), even.get(1), even.get(2), total(even)
    random := censor.SplitSizes(1000, censor.SplitRandom, 5, 0, 42 as i64)
    again := censor.SplitSizes(1000, censor.SplitRandom, 5, 0, 42 as i64)
    println random.len(), total(random), random.get(0) == again.get(0), random.get(4) == again.get(4)
    first := censor.SplitSizes(517, censor.SplitFirst, 2, 5, 0 as i64)
    println first.get(0), first.get(1)
    println censor.SplitSizes(3, censor.SplitEven, 10, 0, 0 as i64).len()

    cuts := censor.SNISplitSizes(hello.data, hello.len, false)
    println cuts.get(0), cuts.get(1), total(cuts)
    lone := censor.SNISplitSizes(hello.data, hello.len, true)
    println lone.len(), lone.get(0), lone.get(1), total(lone)

    mut pieces := censor.Slice(hello.data, hello.len, cuts)
    println pieces.len(), compress.BufEquals(censor.Concat(pieces), hello)
    censor.FreePieces(pieces)

    mut records := censor.FragmentClientHello(hello.data, hello.len, 4, censor.SplitEven, 0 as i64)
    println records.len()
    head := records.get(0)
    println head.len, compress.BufGet(head, 0), compress.BufGet(head, 1), compress.BufGet(head, 2)
    all := censor.Concat(records)

import compress
import net.censor

func main:
    body := "secret payload"
    wrapped := censor.WrapRecord(body as void*, body.len(), 20)
    println wrapped.len, compress.BufGet(wrapped, 0), compress.BufGet(wrapped, 1), compress.BufGet(wrapped, 2)
    mut got := compress.NewByteBuf()
    println censor.UnwrapRecord(wrapped.data, wrapped.len, got), got.len
    println "needs more:", censor.UnwrapRecord(wrapped.data, wrapped.len - 1, got)
    println "not a record:", censor.UnwrapRecord("GET / HTTP/1.1" as void*, 14, got)
    println "too big:", censor.WrapRecord(body as void*, 20000, 0).len

    mut big := compress.NewByteBuf()
    repeat 40000 in i:
        compress.BufPush(big, i % 251)
    end
    stream := censor.WrapStream(big.data, big.len, 5, 50)
    mut back := compress.NewByteBuf()
    mut offset := 0
    mut records := 0
    until offset < stream.len:
        used := censor.UnwrapRecord(((stream.data as i64) + (offset as i64)) as void*, stream.len - offset, back)
        if used <= 0:
            break
        end
        offset += used
        records++
    end
    println records, compress.BufEquals(back, big), offset == stream.len

    println censor.PadLength(100, 10, 10, 64)
    println censor.PadLength(100, 0, 0, 1)
    println censor.RandomBytes(32).len, censor.RandomInt(5, 5)
    r := censor.RandomInt(10, 20)
    println r >= 10, r <= 20
end
