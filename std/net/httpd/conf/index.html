net.httpd.conf

The reader of the web server config: blocks, settings and values in Salam block syntax, with positions for errors.

import net.httpd.conf
On this page

  2. Walk the children and tell the kinds apart
  3. Report errors with their position
  4. Types
  5. Constants and variables
  6. Functions

This package reads text written in the block style that net.httpd uses for its config, and gives back a tree. It knows nothing about web servers: it only recognises the shapes, and net.httpd decides which names are valid. You can use it for settings files of your own that look like Salam.

There are two shapes. A setting is a name, an equals sign and one or more values on the same line: max connections = 100. A block is a name, optional strings, a colon, its contents and end: location "/api/": cache = 1h end. A name may be several words (error page), values are strings in double quotes (with \n, \t, \" and \\), strings in backticks (taken as written, so a regular expression needs no doubling of backslashes), numbers with an optional unit such as 64mb or 30d, and plain words such as tls. Comments are // to the end of the line, or /* ... */.

Everything lives in a Doc, a list of nodes that point at each other by number: node 0 is the root, Find and ChildAt move down, and the fields of a node hold its words, labels, values and children. Free the document with Free when you are done with it.

The things people get wrong:

  • A value list ends at the end of the line, at end, or where the next setting starts on the same line, so a = 1 b = 2 is two settings. A bare word at the end of a list is read as a value, which is why listen = 443 tls works.
  • A parse stops at the first error, and ok is then false. The error has the line and the column, and ErrorText puts them in front of the message the way compilers do.
  • Addresses and anything with a colon in it need quotes: listen = "127.0.0.1:8080". Without them the colon would read as the start of a block.
  • A node's words hold its name, so Name joins them with single spaces. Block labels, such as the path of a location, are in labels, not in the name.

Parse a config and read a value

Parse returns a Doc. Check ok first, then walk down from the root: Find returns the number of the first child with a given name, and ValueText reads one value of a setting by position. A node number of -1 means the child was not found.

net-httpd-conf-guide-parse.salam
import net.httpd.conf

func main:
    text := `
server:
    max connections = 100
    site:
        listen = 8080
        names = "a.test"
    end
end
`
    mut d := conf.Parse(text)
    defer conf.Free(d)
    if not d.ok:
        println conf.ErrorText(d, "app.salam")
        ret 1
    end
    server := conf.Find(d, conf.Root(), "server")
    println conf.Name(d, server), conf.Count(d, server)
    limit := conf.Find(d, server, "max connections")
    println conf.ValueText(d, limit, 0)
    site := conf.Find(d, server, "site")
    println conf.ValueText(d, conf.Find(d, site, "names"), 0)
end
Outputserver 2 100 a.test

The setting name max connections has two words and is found by that full name with a single space. Always free the document, here with defer, because the nodes are heap memory.

Walk the children and tell the kinds apart

To go through everything in a block, use Count and ChildAt, then look at the node itself in d.nodes. A block has block set and its strings in labels; a setting has its values, and each value has a kind that is VAL_WORD, VAL_STR or VAL_NUM, plus the line and column where it was written.

net-httpd-conf-guide-walk.salam
import net.httpd.conf

func main:
    text := `
server:
    site:
        listen = 80 tls
        names = "a.test"
        location "/api/": cache = 1h end
    end
end
`
    mut d := conf.Parse(text)
    defer conf.Free(d)
    site := conf.Find(d, conf.Find(d, conf.Root(), "server"), "site")
    repeat conf.Count(d, site) in i:
        n := d.nodes.get(conf.ChildAt(d, site, i))
        if n.block:
            println "block", conf.Name(d, conf.ChildAt(d, site, i)), n.labels.get(0), n.line
        else:
            v := n.values.get(0)
            println "setting", conf.Name(d, conf.ChildAt(d, site, i)), v.text, v.kind == conf.VAL_NUM
        end
    end
end
Outputsetting listen 80 true setting names a.test false block location /api/ 6

80 is a number, and tls, which follows it on the same line, is a second value of the same setting. The numbers keep their unit as text, so 30d is one VAL_NUM value whose text is 30d; turning it into seconds is up to the program that owns the config.

Report errors with their position

The parser stops at the first error and sets ok to false. ErrorText turns it into file:line:column: message, with the file name you pass in, so a user can jump straight to the spot.

net-httpd-conf-guide-errors.salam
import net.httpd.conf

func check(text: str):
    mut d := conf.Parse(text)
    defer conf.Free(d)
    if d.ok:
        println "ok"
    else:
        println conf.ErrorText(d, "app.salam")
    end
end

func main:
    check("listen = 80\n")
    check("server:\n    site:\n")
    check("names = \"open\n")
    check("listen 80\n")
end
Outputok app.salam:3:1: missing 'end' for the block opened on line 2 app.salam:1:9: unterminated string app.salam:1:8: expected '=' or ':' after 'listen'

The first text is fine: this package only reads the shapes, so listen = 80 at the top level is not an error here. Whether a setting makes sense in that place is for the program that reads the tree, as net.httpd does for its own names.

net-httpd-conf-Parse.salam
import net.httpd.conf

func main:
    text := `
server:
    site:
        listen = 80 tls
        names = "a.test www.a.test"
        location "/api/": cache = 1h end
    end
end
`
    mut d := conf.Parse(text)
    println d.ok, d.nodes.len(), conf.Count(d, conf.Root())
    server := conf.Find(d, conf.Root(), "server")
    site := conf.Find(d, server, "site")
    println conf.Name(d, site), conf.Count(d, site), d.nodes.get(site).block
    listen := conf.Find(d, site, "listen")
    v := d.nodes.get(listen).values.get(0)
    println v.text, v.kind == conf.VAL_NUM, v.line, v.col
    w := d.nodes.get(listen).values.get(1)
    println w.text, w.kind == conf.VAL_WORD, conf.ValueText(d, conf.Find(d, site, "names"), 0)
    names := d.nodes.get(conf.Find(d, site, "names")).values.get(0)
    println names.kind == conf.VAL_STR
    loc := conf.ChildAt(d, site, 2)
    n := d.nodes.get(loc)
    println conf.Name(d, loc), n.labels.get(0), n.block, n.words.len(), n.children.len(), n.line, n.col
    conf.Free(d)
end
Outputtrue 7 1 site 3 true 80 true 4 18 tls true a.test www.a.test true location /api/ true 1 1 6 9

import net.httpd.conf

func show(text: str):
    mut d := conf.Parse(text)
    println d.ok, conf.ErrorText(d, "web.salam"), d.error, d.line, d.col
    conf.Free(d)
end

    show("server:\n    site:\n")
    show("server:\nend\nend\n")

    show("a = 1 # no\n")

end
