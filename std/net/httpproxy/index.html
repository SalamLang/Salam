net.httpproxy

An HTTP and HTTPS proxy: a client with Basic login and CONNECT tunnels, a server that forwards plain requests and opens tunnels, with access rules, TLS and a connector for proxy chains.

import net.httpproxy

An HTTP proxy handles two kinds of traffic. A plain request (GET http://example.com/ HTTP/1.1) is forwarded by the proxy, which opens the connection to the website itself. A CONNECT host:port request asks the proxy to open a raw tunnel, and then bytes pass untouched in both directions, which is how HTTPS and any other TCP protocol cross a proxy. This package has both sides: Get, Post, Request and Connect are the client, Start runs a server. It also plugs into net.tunnel as an HttpInbound that can share one port with SOCKS, and as an HttpConnector that is one hop of a proxy chain. To see how the pieces fit together in an app, read Building a v2ray style or VPN app.

Core ideas:

  • Get, Post and Request fetch a plain http:// URL through the proxy and return a Response. For https:// use Connect, which returns a stream, and run TLS over it yourself.
  • Failure is a value. ok and ok are false, with err or status saying why. A 404 or a 407 is a successful round trip with that status.
  • A server is a ServerConfig given to Start. SetConnector or SetDialer decide how targets are reached, so it can be joined to routing rules and proxy chains; allow refuses methods, hosts or ports.
  • The parser is strict on purpose: a request with both Content-Length and Transfer-Encoding, two different lengths, folded or malformed headers, a bad method or a head over MaxHeadBytes is refused instead of guessed at. That is how request smuggling is kept out.

Things that catch people out:

  • A server listens on bind_host, which is 127.0.0.1 by default. Set 0.0.0.0 only on purpose. Without a login, an open HTTP proxy reachable from outside will be used by strangers. Use AddUser, a firewall, or both.
  • A CONNECT proxy can reach internal addresses. A client that may open tunnels to any host and port can reach services on your own network (a database on 10.0.0.5, a metadata address) or send mail on port 25. Restrict it with allow, for example to port 443 and to public hosts.
  • Basic login is not encrypted. The user name and password are Base64, which is only an encoding. Use SetTLS to make the proxy itself speak TLS, or keep it on a trusted link.
  • Bodies are text. body stops at the first NUL byte, and through a HttpInbound a plain request body is limited to 1 MiB of text. Tunnels have no such limit.
  • Only absolute http:// URLs. Request refuses https:// and relative URLs. ParseURL reads both schemes, but only http can go the plain way.
  • HTTP/1.1 only. There is no HTTP/2 and no compressed transfer encoding (a gzip transfer encoding is answered with 501).
  • Close streams returned in stream.

Using an HTTP proxy from a program

For a plain website, Get sends the request through the proxy. For anything that is not plain HTTP, and for HTTPS, Connect opens a tunnel and gives you the stream; run TLS or any other protocol over it. The example uses a local proxy and two local servers so that it runs anywhere.

net-httpproxy-guide-proxy.salam
import net.httpproxy
import net.tcp
import sync

mut origin_port := 0
mut echo_port := 0
mut ready := sync.NewWaitGroup()

func origin():
    srv := tcp.Bind(0)
    origin_port = tcp.Port(srv)
    sync.Done(ready)
    until true:
        c := tcp.Accept(srv)
        request := tcp.Read(c, 4096)
        first := request.Substr(0, request.Find("\r\n"))
        body := "origin saw: " + first
        tcp.Write(c, "HTTP/1.1 200 OK\r\nContent-Length: " + body.Len() + "\r\nConnection: close\r\n\r\n" + body)
        tcp.Close(c)
    end
end

func echo():
    srv := tcp.Bind(0)
    echo_port = tcp.Port(srv)
    sync.Done(ready)
    until true:
        c := tcp.Accept(srv)
        tcp.Write(c, "echo:" + tcp.Read(c, 100))
        tcp.Close(c)
    end
end

func start_backends():
    sync.Add(ready, 2 as i64)
    _a := spawn(origin)
    _b := spawn(echo)
    sync.Wait(ready)
end

func main:
    start_backends()
    mut server_cfg := httpproxy.NewServerConfig(0)
    httpproxy.AllowPrivate(server_cfg, true)
    server := httpproxy.Start(server_cfg)
    client := httpproxy.NewClient("127.0.0.1", server.port)

    plain := httpproxy.Get(client, "http://127.0.0.1:" + origin_port + "/news")
    println "plain http:", plain.status, plain.body

    tunnel := httpproxy.Connect(client, "127.0.0.1", echo_port)
    tunnel.stream.Write("anything, even TLS")
    println "tunnel:", tunnel.status, tunnel.stream.Read(100)
    tunnel.stream.Close()
    httpproxy.Stop(server)
end
Outputplain http: 200 origin saw: GET /news HTTP/1.1 tunnel: 200 echo:anything, even TLS

If the proxy needs a login use NewClientAuth; a 407 status means the login was missing or wrong. To use the proxy as one hop of several, see HttpConnector and tunnel.Chain.

Running an HTTP proxy

NewServerConfig gives a config for a port, AddUser turns the login on and Start serves in the background. The server keeps connections alive, handles pipelined requests, chunked request bodies, Expect: 100-continue and Upgrade, and strips the headers that belong to one hop (IsHopByHop) before it forwards a request. Slow or silent clients are cut by handshake_timeout_ms and idle_timeout_ms.

Decide what the proxy may do before you open it to anyone: allow_connect and allow_plain switch the two kinds of traffic, and allow sees every method, host and port. A proxy for a site should usually allow CONNECT only to port 443 and refuse private addresses.

mut config := httpproxy.NewServerConfig(3128)
httpproxy.AddUser(config, "alice", "a long random password")
config.allow = (method: str, _host: str, port: int): ret port == 443 or method != "CONNECT" end
httpproxy.SetTLS(config, "proxy.crt", "proxy.key")
server := httpproxy.Start(config)

SetTLS turns the proxy into an HTTPS proxy: clients connect to it over TLS (set tls) and only then send their requests, so the login and the targets are no longer visible on the wire. Use a certificate for the name clients connect to.

What to know

  • The server listens on bind_host (loopback by default). Use a login or a firewall, and restrict CONNECT targets.
  • Basic login is Base64 only. Use SetTLS or a trusted link.
  • Through HttpInbound (the tunnel adapter) each plain request gets its own connection and a body of up to 1 MiB of text; the standalone Start server keeps connections alive.
  • Head limits are MaxHeadBytes bytes and MaxHeaders header lines. Bigger heads get 431.
  • HTTP/1.1 only, no HTTP/2, no compressed transfer encoding.
  • No logging happens by itself.

func main:

    url := "http://127.0.0.1:" + origin_port + "/"

    mut acl := httpproxy.NewServerConfig(0)
    httpproxy.AllowPrivate(acl, true)
    acl.allow = (method: str, _host: str, port: int): ret method == "GET" and port != 25 end
    acl_server := httpproxy.Start(acl)
    acl_client := httpproxy.NewClient("127.0.0.1", acl_server.port)
    println "GET:", httpproxy.Get(acl_client, url).status
    println "POST:", httpproxy.Post(acl_client, url, "text/plain", "x").status
    println "port 25:", httpproxy.Get(acl_client, "http://127.0.0.1:25/").status
    httpproxy.Stop(acl_server)

    mut no_connect := httpproxy.NewServerConfig(0)
    httpproxy.AllowPrivate(no_connect, true)
    no_connect.allow_connect = false
    nc := httpproxy.Start(no_connect)
    println "connect off:", httpproxy.Connect(httpproxy.NewClient("127.0.0.1", nc.port), "127.0.0.1", echo_port).status, httpproxy.Get(httpproxy.NewClient("127.0.0.1", nc.port), url).status
    httpproxy.Stop(nc)

    mut no_plain := httpproxy.NewServerConfig(0)
    httpproxy.AllowPrivate(no_plain, true)
    no_plain.allow_plain = false
    np := httpproxy.Start(no_plain)
    opened := httpproxy.Connect(httpproxy.NewClient("127.0.0.1", np.port), "127.0.0.1", echo_port)
    println "plain off:", httpproxy.Get(httpproxy.NewClient("127.0.0.1", np.port), url).status, opened.status
    opened.stream.Close()
    httpproxy.Stop(np)

    mut routed := httpproxy.NewServerConfig(0)
    httpproxy.AllowPrivate(routed, true)
    httpproxy.SetConnector(routed, (host: str, _port: int): if host == "echo.internal": ret socks.DirectConnect("127.0.0.1", echo_port, 2000) end ret socks.Outbound { ok = false, code = socks.RepNetUnreachable, err = "no route" } end)
    rs := httpproxy.Start(routed)
    named := httpproxy.Connect(httpproxy.NewClient("127.0.0.1", rs.port), "echo.internal", 1)
    named.stream.Write("by name")
    println "routed:", named.status, named.stream.Read(100)
    println "unknown:", httpproxy.Connect(httpproxy.NewClient("127.0.0.1", rs.port), "other.internal", 1).status
    httpproxy.Stop(rs)

    mut blocked := httpproxy.NewServerConfig(0)
    httpproxy.AllowPrivate(blocked, true)
    httpproxy.SetDialer(blocked, tunnel.Block())
    bs := httpproxy.Start(blocked)
    println "block dialer:", httpproxy.Connect(httpproxy.NewClient("127.0.0.1", bs.port), "127.0.0.1", echo_port).status
    httpproxy.Stop(bs)

    mut config := httpproxy.NewServerConfig(0)
    httpproxy.AllowPrivate(config, true)
    println config.handshake_timeout_ms, config.idle_timeout_ms, config.relay_idle_ms, config.allow_connect, config.allow_plain
end
