net.nats

A NATS client: publish and subscribe, request and reply, queue groups, automatic reconnection, JetStream and a key value helper.

import net.nats

NATS is a small, fast message bus. Programs publish messages to subjects such as orders.eu.new, other programs subscribe to subjects or patterns, and the server delivers. This package is a client for the core protocol, request and reply, queue groups, headers, JetStream streams and consumers, and a simple key value helper. It speaks the text protocol over TCP or TLS and needs nothing but the standard library.

The model: Connect opens a connection and you pass it by reference to every call. Nothing runs in the background. Messages are read, handlers are called and PINGs are answered only while you call Pump, NextMsg, Flush, Request or Fetch, so a program that stops calling them stops answering the server. Failures are values: a call returns false, or a message whose ok is false with the reason in err.

  • Subjects are tokens joined by dots. * matches one token and a final > matches the rest, in subscriptions only.
  • Queue groups split a subject among workers: each message goes to one member.
  • Payloads are text. A str stops at its first NUL byte, so send binary data encoded, for example with Base64.

Connecting

Connect takes a URL such as nats://127.0.0.1:4222; tls:// turns TLS on, and nats://user:password@host or nats://token@host carries credentials. ConnectWith takes an Options value for the rest. A failed connection is a connection with ok false, so check IsConnected and read LastError.

mut nc := nats.Connect("nats://127.0.0.1:4222")
if not nats.IsConnected(nc):
    println nats.LastError(nc)
end

Publishing and subscribing

Subscribe returns a handle; NextMsg waits for its next message. Or give SubscribeHandler a function and let Pump call it. Flush sends a PING and waits for the PONG, which proves the server has received everything you published before it.

sub := nats.Subscribe(nc, "greet.*")
nats.Publish(nc, "greet.bob", "hello")
m := nats.NextMsg(nc, sub, 1000)
println m.subject, m.data

Headers

A Header carries key and value pairs next to the payload. NewHeader makes one, HeaderAdd appends a value, HeaderSet replaces the values of a key, HeaderGet and HeaderValues read them, and HeaderEncode and HeaderParse turn a header to and from its wire form.

net-nats-headers.salam
import net.nats

func main:
    mut h := nats.NewHeader()
    nats.HeaderAdd(h, "Trace", "a1")
    nats.HeaderAdd(h, "Trace", "b2")
    nats.HeaderSet(h, "Tenant", "acme")
    println nats.HeaderGet(h, "Tenant"), nats.HeaderCount(h), nats.HeaderHas(h, "Trace")
    println nats.ValidSubject("orders.created"), nats.ValidSubject("bad subject")
end
Outputacme 3 true true false

Subjects and wildcards

A subscription may use two wildcards: * stands for exactly one word and > for one or more words at the end. So orders.* matches orders.created but not orders.created.eu, and orders.> matches both but not orders alone. SubjectMatches applies the same rule locally, which makes it handy in tests. ValidSubject rejects an empty name, spaces and control characters, a leading or trailing dot and an empty word between two dots. Neither call needs a server.

net-nats-guide-subjects.salam
import net.nats

func show(pattern: str, subject: str):
    println pattern, subject, nats.SubjectMatches(pattern, subject)
end

func main:
    show("orders.*", "orders.created")
    show("orders.*", "orders.created.eu")
    show("orders.>", "orders.created.eu")
    show("orders.>", "orders")
    show("*.created", "orders.created")
    show("orders.created", "orders.created")
    println nats.ValidSubject("orders..created"), nats.ValidSubject(".orders"), nats.ValidSubject("orders.")
    println nats.ValidSubject(""), nats.ValidSubject("a b"), nats.ValidSubject("orders.>")
end
Outputorders.* orders.created true orders.* orders.created.eu false orders.> orders.created.eu true orders.> orders false *.created orders.created true orders.created orders.created true false false false false false true

Request and reply

Request sends a message with a private reply subject and waits for one answer. It returns a Msg, so check ok before reading data. When nothing is subscribed to the subject the server says so and err is no responders; when somebody is subscribed but does not answer in time it is timeout. SubscribeReplier takes a function from a message to the reply text. Nothing runs in the background: handlers run while the connection is being pumped, which Request, NextMsg, Flush and Pump all do. To answer by hand, subscribe with Subscribe and call Respond with the incoming message.

net-nats-guide-request.salam
import net.nats

func main:
    mut nc := nats.Connect("nats://127.0.0.1:4222")
    if not nats.IsConnected(nc):
        println "cannot connect:", nats.LastError(nc)
        ret 1
    end
    _s := nats.SubscribeReplier(nc, "svc.shout", "", (m: nats.Msg): ret m.data + "!" end)

    r := nats.Request(nc, "svc.shout", "hello", 1000)
    if r.ok:
        println "reply:", r.data
    else:
        println "failed:", r.err
    end

    gone := nats.Request(nc, "svc.nobody", "x", 1000)
    println gone.ok, gone.err

    slow := nats.Request(nc, "svc.silent", "x", 150)
    println slow.ok, slow.err

    nats.Close(nc)
    ret 0
end

Queue groups and a clean exit

Subscriptions that share a queue name are one group, and the server delivers each message to just one of them, which is how several workers split a stream of jobs. Which member gets which message is up to the server, so count what was handled, not who handled it. NextMsg waits up to the given milliseconds and returns a message with ok false and err set to timeout when nothing arrives. AutoUnsubscribe removes a subscription after that many deliveries. Drain stops the subscriptions, flushes what is pending and closes the connection, so it is the right last call.

net-nats-guide-queue.salam
import net.nats

func main:
    mut nc := nats.Connect("nats://127.0.0.1:4222")
    if not nats.IsConnected(nc):
        println "cannot connect:", nats.LastError(nc)
        ret 1
    end
    a := nats.QueueSubscribe(nc, "jobs", "workers")
    b := nats.QueueSubscribe(nc, "jobs", "workers")
    _ok := nats.AutoUnsubscribe(nc, a, 10)
    repeat 6 in i:
        _sent := nats.Publish(nc, "jobs", "job " + i)
    end
    _flushed := nats.Flush(nc, 1000)

    mut handled := 0
    repeat 2 in k:
        s := k == 0 ? a : b
        mut m := nats.NextMsg(nc, s, 200)
        until m.ok:
            handled++
            m = nats.NextMsg(nc, s, 200)
        end
    end
    println "handled", handled, "subscriptions", nats.SubscriptionCount(nc)
    println "drained", nats.Drain(nc, 1000)
    ret 0
end

Reconnecting

By default a lost connection is closed for good. Set max_reconnects to a positive number, or a negative one to never give up, and the client reconnects by itself. It walks the list made of the URL and servers, waits reconnect_wait_ms between attempts, sends all subscriptions again (an AutoUnsubscribe limit counts only what is left) and then sends the publishes that were held while the link was down, up to reconnect_buffer bytes. Reconnecting happens inside Pump, NextMsg, Flush and Request, since nothing runs in the background. A request that was already on its way when the link broke gets no answer and times out. Errors such as a refused login close the connection instead of retrying.

mut opts := nats.DefaultOptions()
opts.servers.push("nats://10.0.0.2:4222")
opts.max_reconnects = 20
opts.reconnect_wait_ms = 500

JetStream

JetStream stores messages in streams and hands them to consumers. AddStream makes a stream for some subjects, JSPublish publishes and returns the receipt with the stored sequence number, and a pull consumer made with AddConsumer is read with Fetch. Acknowledge every message with Ack; Nak asks for a redelivery and Term gives up on a message.

A push consumer made with AddPushConsumer has the server send messages to a subject you subscribed to. Read them with NextPush, which also answers flow control and skips heartbeats. Any other JetStream call is available through JSRequest.

Key value buckets

A bucket is a stream called KV_ followed by its name, with one subject for each key. KVCreate, KVPut, KVGet and KVDelete cover the common cases. A delete writes a marker, so KVGet then reports found false and deleted true. Watching keys, compare-and-set updates and purging are not provided; use JSRequest or the stream calls for those.

What to know

  • Nothing runs in the background. Call Pump or a waiting function regularly, or the server drops you as a slow consumer or a stale connection.
  • A connection is not safe to use from two threads at once.
  • Payloads stop at the first NUL byte. Binary data needs encoding.
  • The default is no reconnecting. Turn it on with max_reconnects.
  • Authentication is user and password or a token. NKeys, JWT credentials and client certificates are not supported.
  • JetStream calls need a server started with JetStream. Without it they return jetstream not enabled or no responders.

import net.nats

Pump

func Pump(nc &: Conn, timeout_ms: int): int
Waits up to the timeout for data, handles everything that arrived (calling handlers, answering PINGs, queueing messages) and returns how many messages it dealt with. While the link is down it runs reconnect attempts instead.
net-nats-Handlers.salam
import net.nats

mut seen := 0

func note(m: nats.Msg):
    seen++
    println "event", m.subject, m.data
end

func shout(m: nats.Msg): str:
    ret "HELLO " + m.data
end

func main(): int:
    mut nc := nats.Connect("nats://127.0.0.1:4222")
    if not nats.IsConnected(nc):
        println "cannot connect:", nats.LastError(nc)
        ret 1
    end
    nats.SubscribeHandler(nc, "events.>", "", (m: nats.Msg): note(m) end)
    nats.SubscribeReplier(nc, "greet", "", (m: nats.Msg): ret shout(m) end)
    nats.Publish(nc, "events.a.b", "started")

    mut fwd := nats.Msg {}
    fwd.subject = "events.copy"
    fwd.data = "forwarded"
    nats.PublishMsg(nc, fwd)

    repeat 20:
        nats.Pump(nc, 100)
    end
    println "handled", seen
    nats.Close(nc)
    ret 0
end

net-nats-PubSub.salam
import net.nats

func main(): int:
    mut nc := nats.Connect("nats://127.0.0.1:4222")
    if not nats.IsConnected(nc):
        println "cannot connect:", nats.LastError(nc)
        ret 1
    end
    all := nats.Subscribe(nc, "orders.*")
    first := nats.QueueSubscribe(nc, "jobs", "workers")
    once := nats.Subscribe(nc, "ping")
    nats.AutoUnsubscribe(nc, once, 1)
    println "subscriptions:", nats.SubscriptionCount(nc)

    nats.Publish(nc, "orders.new", "order 1")
    nats.Publish(nc, "jobs", "job 1")
    nats.Publish(nc, "ping", "hello")
    nats.Flush(nc, 1000)
    println "waiting:", nats.Pending(nc, all), nats.Pending(nc, first)

    m := nats.NextMsg(nc, all, 1000)
    if m.ok:
        println m.subject, m.data
    end
    p := nats.NextMsg(nc, once, 1000)
    println p.data, nats.Delivered(nc, once), nats.IsValidSubscription(nc, once)

    nats.Unsubscribe(nc, all)
    nats.Close(nc)
    ret 0
end

import net.nats

func main(): int:
    mut opts := nats.DefaultOptions()
    opts.servers.Push("nats://10.0.0.2:4222")
    opts.servers.Push("nats://10.0.0.3:4222")
    opts.max_reconnects = 20
    opts.reconnect_wait_ms = 500
    opts.reconnect_buffer = 1048576
    mut nc := nats.ConnectWith("nats://10.0.0.1:4222", opts)
    if not nats.IsConnected(nc):
        println "cannot connect:", nats.LastError(nc)
        ret 1
    end
    sub := nats.Subscribe(nc, "metrics.>")
    until not nats.IsClosed(nc):
        m := nats.NextMsg(nc, sub, 1000)
        if m.ok:
            println m.subject, m.data
        end
        if nats.IsReconnecting(nc):
            println "link is down, buffered", nats.BufferedBytes(nc), "bytes"
            nats.Publish(nc, "audit", "waiting for the server")
        end
        if nats.IsClosed(nc):
            break
        end
    end
    println "reconnected", nats.Reconnects(nc), "times"
    nats.Close(nc)
    ret 0
end

import net.nats

func main(): int:
    mut nc := nats.Connect("nats://127.0.0.1:4222")
    if not nats.IsConnected(nc):
        println "cannot connect:", nats.LastError(nc)
        ret 1
    end
    mut subjects := Vector {} as Vector<str>
    defer subjects.Free()
    subjects.Push("orders.*")
    made := nats.AddStream(nc, "ORDERS", subjects, 2000)
    println "stream:", made.ok, made.err
    ack := nats.JSPublish(nc, "orders.new", "order 1", 2000)
    println "stored at", ack.stream, ack.seq

    mut h := nats.NewHeader()
    nats.HeaderAdd(h, "Nats-Msg-Id", "order-2")
    again := nats.JSPublishHeaders(nc, "orders.new", h, "order 2", 2000)
    println again.ok, again.duplicate

    info := nats.StreamInfo(nc, "ORDERS", 2000)
    println info.messages, info.first_seq, info.last_seq, info.consumers
    raw := nats.JSRequest(nc, "STREAM.NAMES", "", 2000)
    println raw.ok

    nats.AddConsumer(nc, "ORDERS", "worker", "orders.*", 2000)
    batch := nats.Fetch(nc, "ORDERS", "worker", 10, 1000)
    each m in batch.msgs:
        println m.data, "number", nats.MsgSequence(m)
        if m.data == "order 1":
            nats.Ack(nc, m)
        else m.data == "order 2":
            nats.Nak(nc, m)
        else:
            nats.Term(nc, m)
        end
    end
    if batch.msgs.Len() > 0:
        nats.InProgress(nc, batch.msgs.Get(0))
    end

    nats.DeleteConsumer(nc, "ORDERS", "worker", 2000)
    nats.PurgeStream(nc, "ORDERS", 2000)
    nats.DeleteStream(nc, "ORDERS", 2000)
    nats.Close(nc)
    ret 0
end
