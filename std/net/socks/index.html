net.socks

SOCKS4, SOCKS4a and SOCKS5: a client with login, BIND and UDP associate, a server with users, access rules and a pluggable way to reach targets, and a connector for proxy chains.

import net.socks

SOCKS is the plain, widely supported proxy protocol: a program asks a proxy to connect somewhere on its behalf and then talks through the connection as if it were direct. This package has both sides. Connect is the client; Start runs a server. It also plugs into net.tunnel, as a Socks5Inbound or Socks4Inbound that can share one port with an HTTP proxy, and as a SocksConnector that is one hop of a proxy chain. To see how the pieces fit together in an app, read Building a v2ray style or VPN app.

Core ideas:

  • A client is a value: NewClient or NewClientAuth fills a Client, and Connect returns a ConnectResult with a stream. Failure is a value too: ok is false and code and err say why.
  • SOCKS5 is the default. Set version to Socks4 or Socks4a for older servers. SOCKS4 sends an IPv4 address; SOCKS4a lets the server resolve a name.
  • A name sent to a SOCKS5 or SOCKS4a proxy is resolved by the proxy, so the lookup does not happen on your machine.
  • A server is a ServerConfig given to Start. How it reaches targets is a callback (SetConnector) or a tunnel.Dialer (SetDialer), which is how it is joined to routing rules and proxy chains.
  • Associate opens a UDP relay and Bind waits for an incoming connection. Both are SOCKS5 features the server can switch off.

Things that catch people out:

  • A server listens on bind_host, which is 127.0.0.1 by default. Set it to 0.0.0.0 (or an address) only on purpose. A SOCKS server without a login that is reachable from outside is an open proxy anyone can abuse. Require a user (AddUser), restrict it with a firewall, or put it behind a tunnel.
  • The login is not encrypted. SOCKS5 user name and password travel in clear text. Use it on a local port or through an encrypted tunnel, or set tls when the proxy is reachable over TLS. The server side of this package speaks plain TCP only.
  • SOCKS4 has no passwords. A server that requires logins refuses SOCKS4 clients, and allow_v4 can switch SOCKS4 off.
  • allow_bind is off by default because BIND makes the proxy open a listening port for the client, and a UDP relay does the same with a UDP port. Those sockets are bound to bind_host too, and that is the address reported to the client.
  • UDP has no fragments. Only fragment 0 is supported, and there is no UDP over SOCKS4.
  • IPv6 works end to end. TCP CONNECT, BIND and the UDP relay carry IPv6 targets (address type 4), and the server can listen on ::1 or on :: for both families. A UDP relay bound to an IPv4 address still reaches IPv6 targets through a second outbound socket. SOCKS4 stays IPv4.
  • Close streams. A stream is an open connection. Close it when you are done.

Using a SOCKS proxy from a program

Make a client for the proxy, connect to a target, and use the stream. The proxy here is a local server so the example runs anywhere; in real use it is the address of the proxy you trust.

net-socks-guide-client.salam
import net.socks
import net.tcp

func echo_conn(arg: i64):
    c := tcp.ConnFromFd(arg)
    until true:
        data := tcp.Read(c, 4096)
        if data.len() == 0:
            break
        end
        tcp.Write(c, data)
    end
    tcp.Close(c)
end

func echo_accept(arg: i64):
    srv := tcp.Server { fd = arg }
    until true:
        c := tcp.Accept(srv)
        if not tcp.ConnOk(c):
            break
        end
        socks.Go(echo_conn, c.fd as void*)
    end
end

func start_echo(): int:
    listener := tcp.Bind(0)
    socks.Go(echo_accept, listener.fd as void*)
    ret tcp.Port(listener)
end

func main:
    target := start_echo()
    mut proxy_cfg := socks.NewServerConfig(0)
    socks.AllowPrivate(proxy_cfg, true)
    proxy := socks.Start(proxy_cfg)

    client := socks.NewClient("127.0.0.1", proxy.port)
    result := socks.Connect(client, "127.0.0.1", target)
    if not result.ok:
        println "the proxy said no:", result.code, result.err
        ret
    end
    result.stream.Write("hello from behind the proxy")
    println result.stream.Read(100)
    result.stream.Close()
    socks.Stop(proxy)
end
Outputhello from behind the proxy

DialConn does the same but returns a plain TCP connection for code that already uses net.tcp. Through a proxy that needs a login use NewClientAuth. To go through two proxies in a row, see tunnel.Chain and the chain example below.

Running a SOCKS server

NewServerConfig gives a config for a port; AddUser turns the login on; Start binds and returns at once, and Stop ends it. How the server reaches a target is the part you usually change: leave DirectConnect for a plain proxy, set a callback with SetConnector to route by name, or give it a tunnel.Dialer with SetDialer to use rules, chains and block lists from net.tunnel. allow can refuse commands, hosts or ports before any connection is made.

To put SOCKS on the same port as an HTTP proxy, give a Socks5Inbound to a tunnel.MixedProtocol instead of calling Start. Handle serves a single stream you accepted yourself.

mut config := socks.NewServerConfig(1080)
socks.AddUser(config, "alice", "a long random password")
server := socks.Start(config)
if not server.ok:
    println "port 1080 is busy"
end

What to know

  • The server listens on bind_host (loopback by default). Use a login or a firewall, never an open proxy.
  • The login is plain text. SOCKS4 has no login at all.
  • Names are resolved by the proxy for SOCKS5 and SOCKS4a, and by the client for SOCKS4.
  • Start runs the accept loop on its own thread; connections run on further threads. Stop stops new clients only.
  • The decoders (DecodeRequest, DecodeReply, Decode4Request, DecodeAddress) return the bytes used, 0 for "need more data" and -1 for invalid, so they work on a growing buffer.
  • No logging happens by itself.

func main:
    echo := start_echo()
    mut first_cfg := socks.NewServerConfig(0)
    socks.AllowPrivate(first_cfg, true)
    first := socks.Start(first_cfg)
    mut second_cfg := socks.NewServerConfig(0)
    socks.AllowPrivate(second_cfg, true)
    second := socks.Start(second_cfg)

    hop := socks.Connect(socks.NewClient("127.0.0.1", first.port), "127.0.0.1", second.port)
    println "first hop:", hop.ok
    onward := socks.ClientHandshake(hop.stream, socks.NewClient("", 0), socks.CmdConnect, "127.0.0.1", echo)
    println "second hop:", onward.ok
    hop.stream.Write("through two proxies")
    println hop.stream.Read(100)
    hop.stream.Close()

    mut chain := tunnel.NewChain(tunnel.Direct())
    tunnel.ChainAdd(chain, socks.NewConnector(socks.NewClient("127.0.0.1", first.port)))
    tunnel.ChainAdd(chain, socks.NewConnector(socks.NewClient("127.0.0.1", second.port)))
    println chain.Name()
    s := chain.Dial(tunnel.NewAddr("127.0.0.1", echo))
    s.Write("same thing with a chain")
    println s.Read(100)
    s.Close()

    connector := socks.NewConnector(socks.NewClient("127.0.0.1", first.port))
    println connector.Name(), connector.Server().String() == "127.0.0.1:" + first.port
    socks.Stop(first)
    socks.Stop(second)
end

net-socks-Udp.salam
import mem
import net.socks
import net.udp
import str

func udp_echo(arg: i64):
    s := udp.Socket { fd = arg }
    buf := mem.Allocate(2048 as u64)
    until true:
        mut host := ""
        mut port := 0
        n := udp.ReceiveBytes(s, buf, 2048, host, port)
        if n < 0:
            break
        end
        udp.SendBytes(s, host, port, buf, n)
    end
end

func main:
    echo := udp.Bind(0)
    echo_port := udp.Port(echo)
    socks.Go(udp_echo, echo.fd as void*)

    mut server_cfg := socks.NewServerConfig(0)
    socks.AllowPrivate(server_cfg, true)
    server := socks.Start(server_cfg)
    client := socks.NewClient("127.0.0.1", server.port)
    session := socks.Associate(client)
    println "associated:", session.ok, session.relay_host
    socks.UDPSetTimeout(session, 2000)
    println "sent:", socks.UDPSend(session, "127.0.0.1", echo_port, "datagram one")

    buf := mem.Allocate(1024 as u64)
    mut from := socks.Address {}
    n := socks.UDPReceiveBytes(session, buf, 1024, from)
    println "received:", n, "from", from.host, from.port == echo_port
    (buf as u8*)[n] = 0 as u8
    println str.Clone(buf as str)
    println "bytes sent:", socks.UDPSendBytes(session, "127.0.0.1", echo_port, "raw" as void*, 3)
    mem.Free(buf)
    socks.CloseUDP(session)

    mut four := socks.NewClient("127.0.0.1", server.port)
    four.version = socks.Socks4
    println "socks4 has no udp:", socks.Associate(four).ok
    socks.Stop(server)
end
