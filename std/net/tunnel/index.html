net.tunnel

The shared core for proxy and VPN style tools: streams, addresses, dialers and proxy chains, a mixed inbound, routing rules with an Iran preset, share links and v2ray style configs.

This package is the common core of Salam's proxy tools. It does not speak one proxy protocol itself. It gives the packages of this family one shared shape, so any inbound (the side that accepts clients) can be joined to any outbound (the side that reaches the world): net.socks, net.httpproxy and net.trojan all plug into it, and so will the protocol packages that follow. To see how the pieces fit together in an app, read Building a v2ray style or VPN app.

It is a toolkit for a proxy, not for a system wide VPN: there is no virtual network interface, so an application has to be pointed at the local port (SOCKS or HTTP) or be proxy aware. Its purpose is privacy and access to information. Use it on networks and with servers you are allowed to use, and keep the people who rely on it safe.

application  ->  inbound  ->  router  ->  outbound  ->  remote server  ->  target
             mixed       rules      direct, proxy chain, block
             SOCKS/HTTP  .ir direct

Core ideas:

  • A Stream is a two way byte connection. TCP, TLS, WebSocket and in memory pipes all look the same, so a protocol or a relay never cares what is underneath.
  • An Addr is a target: a host name or IP and a port. Every dialer and every inbound speaks in Addr values.
  • A Dialer opens an outgoing connection. DirectDialer, BlockDialer, Chain (several proxy hops in a row), Fallback and RouterDialer are all dialers, and they nest. A Connector is one proxy hop that a chain can use.
  • An InboundProtocol reads a client's request and answers it; ListenTcp accepts connections and a Handler (usually ForwardHandler) serves them. MixedProtocol puts SOCKS4, SOCKS5 and HTTP proxy on one port.
  • A Router turns a target into a tag (direct, proxy, block) using ordered rules, with IranRouter as a ready preset.
  • ParseLink and ParseSubscription read vmess://, vless://, trojan:// and ss:// share links, and ParseConfig reads v2ray style JSON.

Things that catch people out:

  • Failure is a closed stream, not an exception. A dial that fails returns a stream whose Ok is false. Check it before you write.
  • A config does not build protocols by itself. BuildDialer knows freedom (direct) and blackhole (block). Any other outbound protocol needs a maker registered with RegisterOutbound; until one is, that outbound refuses traffic instead of leaking it. The packages in this family give you dialers and connectors you can build in code, as the guide below does.
  • It is TCP. Streams carry TCP. UDP relays are the business of the individual protocol packages.
  • Examples use IPv4 loopback; tests cover IPv6 too. Listeners accept ::1 and :: (both families), DirectDialer reaches IPv6 targets and races IPv6 and IPv4 addresses of a name, and the per-source limit treats IPv4-mapped clients as IPv4 and groups IPv6 clients by their /64 prefix.
  • Share links are untrusted input. ParseLink rejects what it cannot read, but a subscription comes from someone else's server. Look at allow_insecure before you trust a node.
  • A Stats value and a IdleTimer own native counters. Free them with FreeStats and Free when you are done.

Building a v2ray style or VPN app

A v2ray style app is a small pipeline: something accepts the application's connection (inbound), something decides where it should go (router), and something carries it there (outbound). In Salam each piece is a value, and this package joins them.

              +--------------------------- your process ----------------------------+
application   |  inbound          router              outbound                   |   remote server
(browser,     |  MixedProtocol  Router            Dialer                   |   (trojan, ...)
 curl, app) -> |  SOCKS4/5 + HTTP  rules decide a tag  direct                    | ->      |
127.0.0.1:1080|  -> Session      .ir, private: direct  Via(hop), Chain         |           -> target
              |     target Addr everything else: proxy BlockDialer           |
              +----------------------------------------------------------------------+
                         ForwardHandler relays bytes both ways (Relay)

The example runs this whole pipeline on loopback. Two echo servers stand in for the Internet: local is reached directly and abroad only through a Trojan server, which the router chooses by port. A mixed inbound takes a SOCKS5 client and an HTTP CONNECT client on the same port.

net-tunnel-guide-app.salam
import net.tcp
import net.socks
import net.httpproxy
import net.trojan
import net.tunnel
import sync

mut local_port := 0
mut abroad_port := 0
mut ready := sync.NewWaitGroup()

func serve_echo(name: str, port: int):
    srv := tcp.Bind(port)
    if name == "local":
        local_port = tcp.Port(srv)
    else:
        abroad_port = tcp.Port(srv)
    end
    sync.Done(ready)
    until true:
        c := tcp.Accept(srv)
        data := tcp.Read(c, 100)
        tcp.Write(c, name + " saw " + data)
        tcp.Close(c)
    end
end

func local_echo():
    serve_echo("local", 0)
end

func abroad_echo():
    serve_echo("abroad", 0)
end

func ask(proxy_port: int, port: int, text: str): str:
    r := socks.Connect(socks.NewClient("127.0.0.1", proxy_port), "127.0.0.1", port)
    r.stream.Write(text)
    answer := r.stream.Read(100)
    r.stream.Close()
    ret answer
end

func main:
    sync.Add(ready, 2 as i64)
    _a := spawn(local_echo)
    _b := spawn(abroad_echo)
    sync.Wait(ready)

    mut remote_cfg := trojan.NewServerConfig("", "")
    trojan.AddPassword(remote_cfg, "secret")
    remote := trojan.ServePlain(remote_cfg, 0)

    rules := tunnel.ParseRules("DST-PORT," + abroad_port + ",proxy\nDOMAIN-SUFFIX,ir,direct\nFINAL,direct\n", "direct")
    println "rule errors:", rules.errors.Len()

    mut dialer := tunnel.NewRouterDialer(rules.router)
    tunnel.RouterDialerAdd(dialer, "direct", tunnel.Direct())
    hop := trojan.NewConnector("127.0.0.1", remote.port, "secret")
    tunnel.RouterDialerAdd(dialer, "proxy", tunnel.Via(tunnel.Direct(), hop))

    mut mixed := tunnel.NewMixed()
    tunnel.MixedSetSocks5(mixed, socks.NewInbound(socks.NewServerConfig(0)))
    tunnel.MixedSetHttp(mixed, httpproxy.NewInbound(httpproxy.NewServerConfig(0)))
    forward := tunnel.NewForwarder(dialer, mixed)
    inbound := tunnel.ListenTcp(0)
    tunnel.ServeBackground(inbound, mixed, forward)

    println ask(inbound.port, local_port, "hello")
    println ask(inbound.port, abroad_port, "hello")

    web := httpproxy.Connect(httpproxy.NewClient("127.0.0.1", inbound.port), "127.0.0.1", abroad_port)
    println "http connect:", web.status
    web.stream.Write("via http")
    println web.stream.Read(100)
    web.stream.Close()

    sync.SleepMs(100)
    println "connections:", forward.stats.Total()
    inbound.Stop()
    trojan.Stop(remote)
end
Outputrule errors: 0 local saw hello abroad saw hello http connect: 200 abroad saw via http connections: 3

The pieces, in order: ParseRules builds the Router; a RouterDialer maps each tag to a dialer (Direct for direct, Via with a trojan Connector for proxy); NewMixed with MixedSetSocks5 and MixedSetHttp is the inbound protocol; NewForwarder joins the dialer and the protocol into a handler; ListenTcp and ServeBackground start serving. To add more hops use Chain; to try several outbounds in turn use Fallback.

Practical advice for Iran

  • Send domestic traffic direct. IranRouter sends .ir (and the Persian .ایران forms), private addresses and a few large domestic services straight out, and everything else to your proxy tag. That keeps banking, delivery and government sites working at normal speed and with their normal IP, and keeps the load on your server down. Add your own lines with RuleSuffix or a rule file for ParseRules.
  • Use TLS, and give the server a real face. A Trojan server that holds a real certificate and a real website behind it (trojan.SetFallback) looks like any HTTPS site to a probe: anything that is not an authenticated client is handed to that site. Use a domain you own, a valid certificate and a fallback that serves actual content.
  • Fragment the TLS hello. Some filters read the server name in the first TLS record. net.censor can split that record into pieces (censor.FragmentClientHello, censor.SNISplitSizes) before it is sent. Treat it as one tool that works on some networks and not on others, and test it where you are.
  • Resolve names over an encrypted channel. Plain DNS on UDP port 53 is readable and easy to tamper with. net.doh resolves over DNS over HTTPS or TLS, caches answers, and can run a local stub resolver for other programs. Resolve through the proxy side where you can, so that the name lookup does not reveal what you visit.
  • Keep the rules honest. A proxy that sends everything out hurts everyday browsing, and one that sends too much direct leaks. Review your rule list the same way you review a firewall.
  • Protect the people on the other end. Do not log targets, rotate passwords, and do not share a server with a shared password across people you cannot vouch for.

This package is a tool for privacy and for reaching information. It cannot make you anonymous, it does not hide that you use a proxy from your network provider, and it is not meant for abuse of other people's services or networks.

From a config or a share link

If your app takes a subscription, ParseSubscription gives a list of Node values and ConfigFromNodes turns them into a ready Config (a mixed inbound, one outbound per node, direct and block, and the .ir rule). BuildDialer then builds the dialer, but only for outbound protocols that have a registered maker. Writing a maker is a few lines, see OutboundMaker.

Quick start: building a proxy or VPN app with Salam

This is the short path from a share link to a local proxy that a browser or any other program can connect to. Each step is one call, and the program below puts them together.

  1. Read the link or the subscription. ParseLink reads one vless://, vmess://, trojan:// or ss:// link and ParseSubscription reads a text with many links (Base64 or one link per line). A bad line is dropped and counted in skipped; the program does not stop. A link that comes from someone else is untrusted input: look at allow_insecure before you trust a node.
  2. Build a config. ConfigFromNodes makes a mixed inbound (SOCKS4, SOCKS5 and HTTP on one local port), one outbound per node, the direct and block outbounds and the .ir rule. With no extra work, .ir domains and private addresses go direct and everything else goes through your node.
  3. Turn on DoH and fragmenting. With RegisterWith, the fragment option sends the ClientHello in several packets and use_doh resolves names with DNS over HTTPS. Both are only options: they help on some networks and not on others.
  4. Start. StartAll brings the inbounds up and Stop closes each one. If the config is a V2Ray style JSON file, RunConfig loads it, checks it and runs it until Ctrl-C.
  5. Connect your programs. The inbound listens on 127.0.0.1 only. In a browser or an app, set the SOCKS5 or HTTP proxy to that port. To test from a command line, curl --socks5-hostname 127.0.0.1:1080 https://example.com resolves the name through the proxy too.
net-tunnel-guide-quickstart.salam
import net.doh
import net.tunnel
import net.vpn

func main:
    links := "vless://b831381d-6324-4d53-ad4f-8cda48b30811@vpn.example.org:443?security=tls&type=ws&host=vpn.example.org&path=%2Fws&sni=front.example.net#My Server\ntrojan://s3cret@vpn.example.org:443?sni=vpn.example.org#Backup\nnot a link"
    sub := tunnel.ParseSubscription(links)
    println "servers:", sub.nodes.Len(), "skipped:", sub.skipped

    mut options := vpn.Options {}
    options.fragment = true
    options.use_doh = true
    options.resolver = doh.NewResolver(doh.DefaultServers())
    vpn.RegisterWith(options)

    cfg := tunnel.ConfigFromNodes(sub.nodes, 18080)
    errors := tunnel.ValidateConfig(cfg)
    println "config problems:", errors.Len()

    stats := tunnel.NewStats()
    listeners := vpn.StartAll(cfg, stats)
    println "listening:", vpn.Ok(listeners[0])
    vpn.Stop(listeners[0])
end
Outputservers: 2 skipped: 1 config problems: 0 listening: true

The example has made up servers (example.org) and only shows building and listening; put your own link in, save it to a file and run it:

salam run proxy.salam

A few honest points before you use it:

  • This is a tool for privacy and for reaching information. It does not make you anonymous and it does not promise that you will not be seen: a network that can recognize a proxy from its TLS fingerprint, its traffic pattern or active probing can block it.
  • Fragmenting and DoH are small measures. Test both on the network you are really on, and do not rely on one trick alone.
  • Only work with servers and links you know. The operator of any proxy can see where you connect, and a share link is itself a password or key; do not publish it.
  • Before you run a service for other people, or use one, learn the laws and rules of the country and the network you are in. The responsibility for how you use it is yours.
  • The limits of each protocol (not tested against a real server, no ML-KEM, the server clock for VMess and so on) are on the page of that package.

Streams and relays

Everything above sits on Stream. Wrap a TCP, TLS or WebSocket connection with WrapTcp, WrapTls or WrapWebSocket, or make two in memory ends with NewPipe, and the rest of the code is the same. Relay copies both ways until one side ends; RelayWith adds counters and an idle limit and is what ForwardHandler uses. Helpers such as ReadFull, ReadUntil and WriteAll deal with short reads and writes.

In memory pipes make protocol code easy to test without a socket: write the client's bytes to one end, run the handshake on the other, and compare the reply.

Routing rules

A Router holds ordered Rule values. A rule has destination conditions (exact host, suffix, keyword, regular expression, CIDR) and port conditions; a target matches when it passes one destination condition and one port condition (each only if the rule has some). The first matching rule gives its tag; when none match, the default tag is used. Matching ignores case and a trailing dot, and a suffix such as ir matches a.b.ir but not evilir.

Rules come from code, from ParseRules or LoadRules (the Clash like line format shown there), or from the routing part of a v2ray config through BuildRouter. A rule that names no condition never matches. ParseRules keeps the good lines and lists the bad ones in errors with their line numbers, so a typo does not silently drop a rule.

# one rule per line: KIND,value,tag
DOMAIN-SUFFIX,ir,direct
DOMAIN-KEYWORD,tracker,block
IP-CIDR,203.0.113.0/24,direct
GEOIP,PRIVATE,direct
DST-PORT,25,block
FINAL,proxy

GEOIP understands only PRIVATE. There is no country database in the package, which is why Iranian destinations are recognised by their domain suffix and a short list of well known domains rather than by IP ranges.

What to know

  • This is a proxy toolkit, not a VPN with a virtual interface.
  • Streams are TCP. IPv6 is parsed, routed, dialed and accepted.
  • A failed dial returns a closed stream. Check Ok.
  • Outbound protocols in a config need a registered maker, otherwise the outbound refuses traffic.
  • A Stats and an IdleTimer must be freed. A TcpInbound stops with Stop; connections already relayed carry on to their end.
  • TcpInbound serves each connection on a pool thread. The default handshake limit is 15 seconds, so a client that connects and says nothing is dropped.
  • No logging happens by itself. Add your own where it is safe to do so.

import net.tunnel
import mem

func main:
    pair := tunnel.NewPipe()
    a := tunnel.PipeA(pair)
    b := tunnel.PipeB(pair)

    println tunnel.WriteAll(a, "HELLO world\nsecond line\n")
    println tunnel.ReadByte(b)
    println tunnel.ReadUntil(b, "\n", 100).Len()
    println tunnel.ReadUntil(b, "\n", 100)

    a.Write("12345678")
    buf := mem.Allocate(8 as u64)
    println tunnel.ReadFull(b, buf, 8), (buf as u8*)[0], (buf as u8*)[7]
    mem.Free(buf)

    a.WriteBytes("abc" as void*, 3)
    w := tunnel.WithPrefix(b, "<")
    println w.Read(4)
    println w.Read(10)

    b.SetDeadline(50)
    println "nothing to read: [" + b.Read(10) + "]"

    println a.Ok(), b.Ok()
    a.Close()
    println a.Ok(), b.Read(10).Len()
    dead := tunnel.ClosedStream {}
    println dead.Ok(), dead.Write("x") > 0, dead.Read(10).Len()
end

import net.tcp
import net.tunnel
import net.websocket
import sync

mut tcp_port := 0
mut ws_port := 0
mut ready := sync.NewWaitGroup()

func tcp_server():
    srv := tcp.Bind(0)
    tcp_port = tcp.Port(srv)
    sync.Done(ready)
    c := tcp.Accept(srv)
    s := tunnel.WrapTcp(c)
    s.Write("tcp:" + s.Read(100))
    s.Close()
end

func ws_server():
    srv := websocket.Listen(0)
    ws_port = websocket.Port(srv)
    sync.Done(ready)
    c := websocket.Accept(srv)
    s := tunnel.WrapWebSocket(c)
    first := s.Read(5)
    rest := s.Read(100)
    s.Write("ws:" + first + rest)
    s.Close()
end

func main:
    sync.Add(ready, 2 as i64)
    t1 := spawn(tcp_server)
    t2 := spawn(ws_server)
    sync.Wait(ready)

    plain := tunnel.DialTcp("127.0.0.1", tcp_port, 2000)
    plain.Write("hello")
    println plain.Read(100)
    plain.Close()

    conn := websocket.Dial("127.0.0.1", ws_port, "/")
    stream := tunnel.WrapWebSocket(conn)
    tunnel.WriteAll(stream, "hello world")
    println tunnel.ReadByte(stream)
    println stream.Read(100)
    stream.Close()
    join(t1)
    join(t2)
end

import net.tunnel
import mem

func hex(v: Vector<u8>): str:
    digits := "0123456789abcdef"
    mut out := ""
    repeat v.Len() in i:
        b := v[i] as int
        out += digits.Substr(b / 16, 1) + digits.Substr(b % 16, 1)
    end
    ret out
end

func main:
    target := tunnel.NewAddr("example.com", 443)
    socks := tunnel.EncodeSocks(target)
    vless := tunnel.EncodeVless(target)
    println "socks5", hex(socks)
    println "vless ", hex(vless)
    p := tunnel.VectorBytes(socks)
    back := tunnel.DecodeSocks(p, socks.Len())
    println back.valid, back.String(), back.size == socks.Len()
    q := tunnel.VectorBytes(vless)
    again := tunnel.DecodeVless(q, vless.Len())
    println again.valid, again.String()
    short := tunnel.DecodeSocks(p, 3)
    println "short", short.valid
    mem.Free(p)
    mem.Free(q)

    pair := tunnel.NewPipe()
    a := tunnel.PipeA(pair)
    b := tunnel.PipeB(pair)
    tunnel.WriteAllBytes(a, tunnel.VectorBytes(socks), socks.Len())
    println tunnel.ReadSocksAddr(b).String()
    tunnel.WriteAllBytes(a, tunnel.VectorBytes(vless), vless.Len())
    println tunnel.ReadVlessAddr(b).String()
end
