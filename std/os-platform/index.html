os/platform

Identifying the system the program is running on: the operating system, the processor, the core count and the memory.

import os.platform
On this page
  1. Functions

The os.platform package says at run time what system the program is on. For decisions that belong at compile time, constants such as SALAM_OS_WINDOWS and conditional compilation are the better fit; this package is for reports, automatic settings and messages.

The example below prints whether the properties hold rather than the system's name, so that its output is the same everywhere.

Functions

IsLinux

func IsLinux(): bool
True on Linux.
os-platform-OS.salam
import os.platform

func main:
    known := platform.IsLinux() or platform.IsWindows() or platform.IsMac() or platform.IsFreeBSD() or platform.IsBSD() or platform.IsAndroid() or platform.IsWasm()
    println known, platform.OS().len() > 0
    arch := platform.IsX64() or platform.IsArm64() or platform.IsX86() or platform.IsArm()
    println arch, platform.Arch().len() > 0
    println platform.CpuCount() >= 1
    println platform.TotalMemory() > 0, platform.AvailableMemory() <= platform.TotalMemory()
end
