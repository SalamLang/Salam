os

Files, directories, system commands, program arguments and environment variables.

import os

The os package is the simplest way to talk to the system: whole-file reads and writes, folders, shell commands, the program's arguments and its environment. Each function does one thing and takes paths as plain strings. Reach for it in scripts, build tools and small servers. When you need to know why something failed, or to read a big file piece by piece, the fs family (fs.file, fs.dir, fs.path) does more; for building paths use filepath, and for configuration from the environment env.

Results follow two conventions. Functions that change something (Remove, Mkdir, Move, Copy, MkdirAll, RemoveAll) return 0 on success and -1 on failure, with no reason attached. WriteFile and AppendFile return the number of bytes written, or -1. Functions that read return an empty value when they fail: ReadFile gives empty text and ListDir an empty vector for a missing folder.

There are sub-packages for more specialised work: os.process for running other programs with exact arguments, os.shell for capturing command output and errors, os.platform for identifying the system, os.temp for temporary files, os.user for the current user and os.error for error codes.

What people get wrong:

  • Building a shell command from user input. Run, RunCapture and Output hand the whole string to /bin/sh, so a name such as x; rm -rf ~ runs the second command too.
  • Expecting RunCapture to capture errors. It captures standard output only; the command's standard error still goes to the terminal. Add 2>&1 to the command when you want both.
  • Running RemoveAll or Walk on a tree with symbolic links. Both follow a link to a folder as if it were a real folder: Walk lists what is behind it (and never ends on a link loop), and RemoveAll deletes the contents of the link's target, even outside the tree. Do not point them at folders that may contain links to elsewhere.
  • Using Move across disks. It is a rename, and a rename between file systems fails with -1; copy and remove instead.

The sections below walk through the jobs this package is used for most, each with a complete program and the output it printed. The programs work in the current directory and remove what they create.

Read a settings file with defaults

A small program usually keeps its settings in a text file next to it. Exists tells you whether the file is there yet, WriteFile creates it with sensible values the first time, and ReadFile gives you the whole text to pick apart. Every setting that is missing falls back to a default, so an old file keeps working after you add a new option.

os-guide-config.salam
import os

func setting(text: str, key: str, fallback: str): str:
    each line in text.split("\n"):
        if line.starts_with(key + "="):
            ret line.substr(key.len() + 1, line.len() - key.len() - 1)
        end
    end
    ret fallback
end

func main:
    path := "app.conf"
    if not os.Exists(path):
        os.WriteFile(path, "port=8080\nname=notes\n")
        println "wrote a default", path
    end
    text := os.ReadFile(path)
    println "port:", setting(text, "port", "80")
    println "name:", setting(text, "name", "app")
    println "debug:", setting(text, "debug", "off")
    os.Remove(path)
end
Outputwrote a default app.conf port: 8080 name: notes debug: off

ReadFile returns an empty string both for an empty file and for one it cannot read. When the difference matters, ask Exists first, as here. For a real format, read the text with encoding.json or a similar package instead of splitting lines by hand.

Keep a log and rotate it

AppendFile adds to the end of a file and creates it when it is missing, which is all a log needs. FileSize says how big the log has become; once it passes a limit, Move renames it out of the way and the next AppendFile starts a fresh one.

os-guide-log.salam
import os

func log(path: str, line: str):
    os.AppendFile(path, line + "\n")
end

func main:
    path := "app.log"
    log(path, "started")
    log(path, "user sara signed in")
    log(path, "stopped")
    println "size:", os.FileSize(path), "bytes"
    lines := os.ReadFile(path).split("\n")
    println "first entry:", lines.get(0)
    if os.FileSize(path) > 32:
        os.Move(path, "app.log.1")
        println "rotated:", os.Exists("app.log.1"), os.Exists(path)
    end
    log(path, "a fresh log")
    println "new size:", os.FileSize(path)
    os.Remove(path)
    os.Remove("app.log.1")
end
Outputsize: 36 bytes first entry: started rotated: true false new size: 12

Each call opens and closes the file, which is fine for a few lines a second. For a busy log, open it once with Open(path, "ab") and write to the handle.

Create, walk and remove a directory tree

MkdirAll creates a path with every parent it needs, so the order you create folders in does not matter. Walk lists every file below a directory, at any depth, and ListDirs only the folders directly inside it. RemoveAll deletes the whole tree at the end.

os-guide-tree.salam
import os
import sort

func main:
    os.MkdirAll("site/pages/blog")
    os.MkdirAll("site/assets")
    os.WriteFile("site/pages/index.salam", "func main: end")
    os.WriteFile("site/pages/blog/first.salam", "func main: end")
    os.WriteFile("site/assets/logo.svg", "<svg/>")
    mut count := 0
    mut bytes := 0 as i64
    each p in os.Walk("site"):
        if p.ends_with(".salam"):
            count += 1
            bytes += os.FileSize(p)
        end
    end
    println "source files:", count, "with", bytes, "bytes"
    folders := os.ListDirs("site")
    sort.Sort(folders)
    each name in folders:
        println "folder:", name
    end
    os.RemoveAll("site")
    println "cleaned up:", not os.Exists("site")
end
Outputsource files: 2 with 28 bytes folder: assets folder: pages cleaned up: true

Walk returns full paths that start with the folder you gave it, while ListDir and ListDirs return bare names, hidden ones included and . and .. left out. The system returns directory entries in no particular order, and the order changes between file systems. Sort the names, as the program does with sort, before you print them or compare them with something.

Run shell commands and check them

Run, RunCapture and Output pass the command to the system shell, so pipes, redirection and quoting work just as they do in a terminal. Run only gives back the exit code, and the command prints straight to the program's own output; that is enough to ask whether a tool is installed. RunCapture gives the code and the standard output together, and Output only the text, final newline included, so trim it.

os-guide-commands.salam
import os

func tool_exists(name: str): bool:
    ret os.Run("command -v " + name + " > /dev/null") == 0
end

func main:
    println "sh available:", tool_exists("sh")
    println "made-up tool available:", tool_exists("no-such-tool-here")
    r := os.RunCapture("printf 'b\\na\\nc\\n' | sort")
    if r.code != 0:
        printerrln "sort failed with", r.code
        ret 1
    end
    print r.out
    count := os.Output("printf 'x\\ny\\n' | wc -l").trim()
    println "lines counted by wc:", count
end
Outputsh available: true made-up tool available: false a b c lines counted by wc: 2

Because a shell reads the command, never build one from text a user typed: a name such as x; rm -rf ~ would run the second command too. To pass untrusted values, use os.process, which hands each argument to the program untouched.

Which function for which job

JobFunction
Read or replace a whole small fileReadFile, WriteFile
Add lines to a logAppendFile
Read a big file piece by pieceOpen, then the handle's readline and close
Know if a path is there, and what it isExists, IsDir, or Stat for everything at once
Make or delete foldersMkdirAll, RemoveAll (Mkdir and Rmdir for one level)
Find files below a folderWalk; ListDir for one level
Run a shell commandRun, RunCapture, Output
Run a program with exact argumentsos.process or os.shell
Find out why a file operation failedfs.file together with os.error

os-Files.salam
import os

func main:
    os.WriteFile("note.txt", "first line\n")
    os.AppendFile("note.txt", "second line\n")
    print os.ReadFile("note.txt")
    println os.Exists("note.txt"), os.FileSize("note.txt")
    info := os.Stat("note.txt")
    println info.exists, info.is_dir, info.size
    os.Copy("note.txt", "copy.txt")
    os.Move("copy.txt", "new name.txt")
    println os.Exists("copy.txt"), os.Exists("new name.txt")
    os.Remove("new name.txt")
    println os.Exists("new name.txt")
    f := os.Open("note.txt", "rb")
    println f.readline()
    f.close()
end
Outputfirst line second line true 23 true false 23 false true false first line

os-Run.salam
import os

func main:
    code := os.Run("echo from the shell")
    println "exit code:", code
    r := os.RunCapture("echo hello")
    println r.code, "[" + r.out + "]"
    println "[" + os.Output("echo world") + "]"
    println os.Pid() > 0
end
Outputfrom the shell exit code: 0 0 [hello ] [world ] true

Ends the program immediately with the given code. Inside main write ret instead, because exiting does not run the defer statements (error E109).
os-Args.salam
import os

func fail(message: str):
    printerrln message
    os.Exit(2)
end

func give_up():
    os.Abort()
end

func main:
    args := os.Args()
    println "argument count:", args.len()
    home := os.Env("HOME")
    println home.len() > 0 or os.Env("USERPROFILE").len() > 0
    if args.len() > 10:
        fail("too many arguments")
    end
    if args.len() > 100:
        give_up()
    end
end

os-Dirs.salam
import os

func main:
    os.Mkdir("project")
    os.MkdirAll("project/src/helpers")
    os.WriteFile("project/readme.txt", "hello")
    os.WriteFile("project/src/main.salam", "func main: end")
    println os.IsDir("project"), os.IsDir("project/readme.txt")
    println os.ListDir("project/src").len(), os.ListDirs("project")
    println os.Walk("project").len()
    os.CopyTree("project", "backup")
    println os.Exists("backup/src/main.salam")
    start := os.Cwd()
    os.Chdir("project")
    println os.Exists("readme.txt")
    os.Chdir(start)
    os.Rmdir("project/src/helpers")
    os.RemoveAll("project")
    os.RemoveAll("backup")
    println os.Exists("project"), os.TempDir().len() > 0
end
Outputtrue false 2 ["src"] 2 true true false true
