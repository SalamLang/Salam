rand

Random numbers, text and choices: dice, one-time codes, unique identifiers and shuffling a list.

import rand
On this page
  1. Functions

The rand package is for games, simulations, sample data and generating identifiers. Call SeedAuto once before anything else, so that each run of the program gets different numbers. If you want the same result every time, in a test for instance, call Seed with a fixed number instead.

This package is not built for cryptography. For keys, session tokens and passwords, use the crypto package.

The examples on this page print properties of the values, such as whether they fall in a range, rather than the values themselves, because a random number differs on every run.

Functions

Seed

func Seed(s: i64)
Starts the generator from a fixed number. With the same seed the sequence of numbers is always the same.
rand-Seed.salam
import rand

func main:
    rand.Seed(42)
    a := rand.IntRange(1, 100)
    rand.Seed(42)
    b := rand.IntRange(1, 100)
    println a == b
    rand.SeedAuto()
    die := rand.Int32Range(1, 6)
    println die >= 1 and die <= 6
    n := rand.Int()
    n32 := rand.Int32()
    println rand.IntN(10) < 10, n == n, n32 == n32
    println rand.IntWithLength(6) >= 100000
end
Outputtrue true true true true true

rand-Text.salam
import rand
import str

func main:
    println rand.Alpha(8).len(), rand.AlphaUpper(8).len(), rand.AlphaMixed(8).len()
    println rand.Digit(6).len(), rand.Alnum(12).len(), rand.Text(10).len()
    println rand.TextFrom(5, "ab").len(), str.Contains("ab", rand.ChoiceChar("ab"))
    println rand.Bytes(4).len(), rand.HexBytes(4).len()
    println rand.Hash().len(), rand.Hash160().len(), rand.Hash256().len()
    id := rand.UUID()
    println id.len(), id.substr(14, 1)
end

ChoiceStr

func ChoiceStr(v: Vector<str>): str
Returns a random element of a vector of strings.
rand-Choice.salam
import rand

func main:
    mut names := Vector {} as Vector<str>
    defer names.free()
    names.push("Ali")
    names.push("Sara")
    names.push("Reza")
    winner := rand.ChoiceStr(names)
    println winner == "Ali" or winner == "Sara" or winner == "Reza"
    mut numbers := Vector {} as Vector<int>
    defer numbers.free()
    repeat 1 to 5 in i:
        numbers.push(i)
    end
    println rand.ChoiceInt(numbers) <= 5
    shuffled := rand.ShuffleInt(numbers)
    mut total := 0
    each n in shuffled:
        total += n
    end
    println shuffled.len(), total
    println rand.ShuffleStr(names).len()
end
Outputtrue true 5 15 3
