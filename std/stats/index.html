stats

Descriptive statistics over a list of numbers: mean, median, variance, standard deviation and percentiles.

import stats
On this page

  6. Functions

The stats package answers the first questions you ask of a list of numbers: how many, the total, the typical value, the spread and the extremes. Use it for reports, monitoring (latency percentiles), grading and checking a simulation. It covers descriptive statistics only; there is no mode, correlation, regression or histogram. For scalar maths use math, for fitting models ml, and to generate the numbers in the first place rand.

Every function takes a Vector<f64> and never changes it. Whole numbers have to be converted with as f64 on the way in. Median and Percentile sort a private copy on each call, so asking for p50, p90 and p99 sorts three times; that is fine for thousands of values and worth knowing for millions.

Variance and standard deviation come in two forms. Variance and Stdev treat the data as a sample of a larger group and divide by n−1; PopVariance and PopStdev treat it as the whole group and divide by n. The sample form is the usual choice.

What people get wrong:

  • Trusting the result of an empty list. Nothing fails: Mean, Median, Min, Max and Percentile return 0, which looks like real data. Check len() first.
  • Reporting the mean of skewed data. One slow request or one very rich customer moves the mean a long way; the median and percentiles do not move.
  • Averaging growth rates with Mean. Factors that multiply need Geomean.

A summary of a class

The usual job is a short report on a list of numbers: how many, the middle, the spread and the extremes. Put the values in a Vector<f64> once and call the functions you need; none of them changes the vector. The standard deviation also lets you flag values that are far from the rest: a value more than one standard deviation from the mean is unusual in a small group.

stats-guide-report.salam
import stats
import conv

func main:
    names := ["Sara", "Reza", "Mina", "Ali", "Neda", "Omid", "Leila"]
    mut scores := Vector {} as Vector<f64>
    defer scores.free()
    each s in [14.5, 17.0, 19.5, 11.0, 16.0, 8.5, 18.0]:
        scores.push(s)
    end
    mean := stats.Mean(scores)
    sd := stats.Stdev(scores)
    println "students:", scores.len()
    println "mean:    ", conv.FormatFloatPrec(mean, 2)
    println "median:  ", stats.Median(scores)
    println "stdev:   ", conv.FormatFloatPrec(sd, 2)
    println "range:   ", stats.Min(scores), "to", stats.Max(scores)
    println "top 25%: ", stats.Percentile(scores, 75.0), "and above"
    each i, name in names:
        z := (scores.get(i) - mean) / sd
        if z > 1.0:
            println name, "is well above the class:", conv.FormatFloatPrec(z, 2)
        else z < -1.0:
            println name, "needs help:", conv.FormatFloatPrec(z, 2)
        end
    end
end
Outputstudents: 7 mean: 14.93 median: 16 stdev: 3.93 range: 8.5 to 19.5 top 25%: 17.5 and above Mina is well above the class: 1.16 Omid needs help: -1.64

A class or a survey is usually a sample, so Stdev is the right choice. Use PopStdev only when the list holds every member of the group you are describing, for example all the machines in a cluster.

Response times: median and percentiles

One slow request can pull the mean far away from what most users see. In this example nine requests take about 40 ms and one takes 1200 ms; the mean says 157 ms, while the median (the 50th percentile) says 41.5 ms. Monitoring therefore uses percentiles: p90 is the time 90% of requests stay under, and p99 shows the worst cases.

stats-guide-latency.salam
import stats
import conv

func show(label: str, x: f64):
    println label, conv.FormatFloatPrec(x, 1), "ms"
end

func main:
    mut ms := Vector {} as Vector<f64>
    defer ms.free()
    each t in [42.0, 38.0, 45.0, 40.0, 39.0, 41.0, 44.0, 37.0, 43.0, 1200.0]:
        ms.push(t)
    end
    show("mean:", stats.Mean(ms))
    show("p50: ", stats.Percentile(ms, 50.0))
    show("p90: ", stats.Percentile(ms, 90.0))
    show("p99: ", stats.Percentile(ms, 99.0))
    show("max: ", stats.Max(ms))
    budget := 100.0
    if stats.Percentile(ms, 90.0) > budget:
        println "alert: p90 is over the budget of", budget, "ms"
    else:
        println "p90 is within the budget"
    end
end
Outputmean: 156.9 ms p50: 41.5 ms p90: 160.5 ms p99: 1096.1 ms max: 1200.0 ms alert: p90 is over the budget of 100 ms

Percentile interpolates between the two nearest values, so with few samples the high percentiles land between a normal value and the outlier. Collect a few hundred values before you trust p99.

Growth rates and the geometric mean

When values are multiplied, as with yearly returns or growth factors, the arithmetic mean overstates the result. A gain of 50% followed by a loss of 40% is not an average gain. Geomean gives the single factor that, repeated, reaches the same end value.

stats-guide-growth.salam
import stats
import conv

func main:
    mut factors := Vector {} as Vector<f64>
    defer factors.free()
    each f in [1.50, 0.60, 1.20, 1.10]:
        factors.push(f)
    end
    mut value := 1000.0
    each f in factors:
        value = value * f
    end
    println "after four years:", conv.FormatFloatPrec(value, 2)
    arith := stats.Mean(factors)
    geo := stats.Geomean(factors)
    println "arithmetic mean factor:", conv.FormatFloatPrec(arith, 4)
    println "geometric mean factor: ", conv.FormatFloatPrec(geo, 4)
    mut a := 1000.0
    mut g := 1000.0
    repeat 4:
        a = a * arith
        g = g * geo
    end
    println "replayed with the arithmetic mean:", conv.FormatFloatPrec(a, 2)
    println "replayed with the geometric mean: ", conv.FormatFloatPrec(g, 2)
end
Outputafter four years: 1188.00 arithmetic mean factor: 1.1000 geometric mean factor: 1.0440 replayed with the arithmetic mean: 1464.10 replayed with the geometric mean: 1188.00

Reading numbers from text

Data usually arrives as text, with empty cells, labels such as n/a and sometimes Persian digits. Check each cell with types.IsNumeric from types, turn Persian digits into English ones with str.ToEnglishDigits and parse with conv.ParseFloat. Count what you skipped, so that a report on bad data does not look like a report on good data.

stats-guide-parse.salam
import stats
import str
import conv
import types

func main:
    line := "12.5, 15, ۱۸, n/a, 20, , 9.75"
    mut values := Vector {} as Vector<f64>
    defer values.free()
    mut skipped := 0
    each cell in str.Split(line, ","):
        t := str.Trim(cell)
        if types.IsNumeric(t):
            values.push(conv.ParseFloat(str.ToEnglishDigits(t)))
        else:
            skipped += 1
        end
    end
    println "read", values.len(), "numbers, skipped", skipped
    println "sum:   ", stats.Sum(values)
    println "mean:  ", stats.Mean(values)
    println "median:", stats.Median(values)
end
Outputread 5 numbers, skipped 2 sum: 75.25 mean: 15.05 median: 15

Empty and tiny lists

The functions do not fail on awkward input; they return a number, and that number can mislead. An empty vector gives 0 for the mean, the median and the maximum. One value has a variance of 0. A zero or a negative value makes the geometric mean 0, and a percentile outside 0 to 100 is moved to the nearest end. Check len() before you report anything.

stats-guide-edge.salam
import stats

func main:
    empty := Vector {} as Vector<f64>
    println "empty:", stats.Mean(empty), stats.Median(empty), stats.Max(empty)
    mut one := Vector {} as Vector<f64>
    defer one.free()
    one.push(7.0)
    println "one value:", stats.Variance(one), stats.PopVariance(one)
    mut rates := Vector {} as Vector<f64>
    defer rates.free()
    each r in [1.2, 0.0, 1.5]:
        rates.push(r)
    end
    println "geomean with a zero:", stats.Geomean(rates)
    println "percentile 150 is clamped:", stats.Percentile(rates, 150.0)
    if empty.len() == 0:
        println "no data, nothing to report"
    end
end
Outputempty: 0 0 0 one value: 0 0 geomean with a zero: 0 percentile 150 is clamped: 1.5 no data, nothing to report

import stats

Median

func Median(v: Vector<f64>): f64
The middle number after sorting, or the mean of the middle two when there is an even count; 0 for an empty vector. It stands up to outliers better than the mean. Sorts a copy on each call.

The example for this item is shown with the ones above: stats-Mean.salam

Variance

func Variance(v: Vector<f64>): f64
The sample variance, dividing by n−1 after a first pass for the mean. Fewer than two values give 0.

The example for this item is shown with the ones above: stats-Mean.salam

PopVariance

func PopVariance(v: Vector<f64>): f64
The population variance, dividing by n; 0 for an empty vector.

The example for this item is shown with the ones above: stats-Mean.salam

Stdev

func Stdev(v: Vector<f64>): f64
The sample standard deviation, the square root of Variance. Fewer than two values give 0.

The example for this item is shown with the ones above: stats-Mean.salam

PopStdev

func PopStdev(v: Vector<f64>): f64
The population standard deviation, the square root of PopVariance.

The example for this item is shown with the ones above: stats-Mean.salam

Geomean

func Geomean(v: Vector<f64>): f64
The geometric mean, the n-th root of the product, computed through logarithms so it does not overflow. It suits growth factors and ratios. Every number has to be positive: a zero or a negative value makes the result 0, and so does an empty vector.

The example for this item is shown with the ones above: stats-Mean.salam

Percentile

func Percentile(v: Vector<f64>, p: f64): f64
The pth percentile, with p from 0 to 100, interpolating linearly between the two nearest sorted values (the method of Excel PERCENTILE.INC and the NumPy default). p outside that range is moved to the nearest end; 0 gives the minimum and 100 the maximum. Sorts a copy on each call.

The example for this item is shown with the ones above: stats-Mean.salam
