str

Everything to do with text: searching, slicing, replacing, digits, case, and building long strings.

import str

The str package is the one you will reach for most. Anywhere you touch text, from reading user input to building output, its functions apply.

One thing to know before you start: Salam strings are UTF-8. In UTF-8 an English letter is one byte, while a letter in most other scripts takes two or more. That is why most of these functions come in two forms: Len, Substr and IndexOf work in bytes and are fast, while CharCount, CharSubstr and CharFind work in characters. Wherever the count or the cut has to match what the reader sees, use the character form.

One step further out is the "grapheme": what a reader sees as a single letter. A letter with an accent is two characters but one grapheme, and a family emoji is seven characters but one grapheme. For reversing or cutting text that carries marks or emoji, the grapheme functions are the safe ones.

Three methods also sit on every string and need no import: text.starts_with("salam"), text.ends_with(".txt") and text.includes("world"). All three return true or false and behave the same on every backend.

Neighbouring packages: unicode classifies and converts single code points, fmt pads and fills templates, conv parses numbers, regex matches patterns, and arabic normalises Persian and Arabic letters.

Things that catch people out:

  • Upper and Lower change only the ASCII letters A to Z: Upper("café") is CAFé. For other scripts map each code point with unicode.ToUpper or unicode.ToLower; to compare without case use EqualFold, which does follow the full Unicode rules.
  • Trim and its relatives remove only the ASCII space, tab, carriage return and newline. A no-break space (U+00A0), common in text pasted from the web, stays.
  • A str ends at its first zero byte, so binary data passed through these functions is cut short there.
  • Every function that returns a string returns a new one; the argument is never changed.

Making a URL slug from a title

A slug is the readable part of a URL, such as /blog/hello-world. To build one, lower the case, keep letters and digits, and turn every run of anything else into a single dash. Working on code points with CodePoints and IsAlnum keeps letters of every script, so a Persian title gives a Persian slug instead of an empty one.

str-guide-slug.salam
import str

func slug(title: str): str:
    mut b := str.NewBuilder()
    defer str.BufFree(b)
    cps := str.CodePoints(str.Lower(str.Trim(title)))
    defer cps.free()
    mut dash := false
    each cp in cps:
        if str.IsAlnum(cp):
            if dash and not str.BufIsEmpty(b):
                str.BufAppend(b, "-")
            end
            str.BufAppendCp(b, cp)
            dash = false
        else:
            dash = true
        end
    end
    ret str.BufStr(b)
end

func main:
    println slug("Hello, World!")
    println slug("  10 Tips for Faster   Builds ")
    println slug("Salam 0.5: what's new?")
    println slug("سلام دنیا، به سلام خوش آمدید")
end
Outputhello-world 10-tips-for-faster-builds salam-0-5-what-s-new سلام-دنیا-به-سلام-خوش-آمدید

The StringBuilder collects the result without making a new string for every character; BufAppendCp adds one code point as UTF-8 and BufStr returns the finished text. One thing to watch in Persian text: the zero width non-joiner (U+200C) inside a word such as می‌شود is not a letter, so this function would split the word there. If you want to keep it, treat 8204 like a letter in the test.

Counting words

Fields splits on any run of whitespace and drops empty pieces, which is what you want for words; Split with " " would give an empty word for every double space. Lower the case first and turn punctuation into spaces, then count with a HashMap. A separate vector remembers the order in which words first appeared, since a map has no order of its own.

str-guide-words.salam
import str

func main:
    text := "The cat sat. The dog sat too, and the cat ran!"
    clean := str.Replace(str.Replace(str.Replace(str.Lower(text), ".", " "), ",", " "), "!", " ")
    words := str.Fields(clean)
    defer words.free()
    mut counts := HashMap {} as HashMap<str, int>
    defer counts.free()
    mut order := Vector {} as Vector<str>
    defer order.free()
    each w in words:
        if counts.has(w):
            counts.put(w, counts.get(w) + 1)
        else:
            counts.put(w, 1)
            order.push(w)
        end
    end
    println words.len(), "words,", order.len(), "different"
    each w in order:
        if counts.get(w) > 1:
            println w, counts.get(w)
        end
    end
end
Output11 words, 7 different the 3 cat 2 sat 2

Each Replace returns a new string. For a long list of characters to remove, one pass over CodePoints with IsPunct is cleaner than a chain of replacements. For Persian text, run it through arabic.SearchKey first so different spellings of the same word count together.

Building CSV with a StringBuilder

Every field that holds a comma, a quote or a line break has to be wrapped in quotes, with each quote inside it doubled. Contains decides whether a field needs that and Replace doubles the quotes. A StringBuilder collects the rows, which is much faster than + once the text grows to thousands of lines.

str-guide-csv.salam
import str

func csv_field(s: str): str:
    if str.Contains(s, ",") or str.Contains(s, "\"") or str.Contains(s, "\n"):
        ret "\"" + str.Replace(s, "\"", "\"\"") + "\""
    end
    ret s
end

func add_row(b &: str.StringBuilder, cells: str[]):
    each i, c in cells:
        if i > 0:
            str.BufAppend(b, ",")
        end
        str.BufAppend(b, csv_field(c))
    end
    str.BufAppend(b, "\n")
end

func main:
    mut b := str.NewBuilder()
    defer str.BufFree(b)
    add_row(b, ["name", "city", "note"])
    add_row(b, ["Ali", "Tehran", "likes tea"])
    add_row(b, ["Sara", "Shiraz, Fars", "said \"hi\""])
    print str.BufStr(b)
end
Outputname,city,note Ali,Tehran,likes tea Sara,"Shiraz, Fars","said ""hi"""

The builder is passed with &: so that add_row appends to the caller's builder instead of a copy. Free it once with BufFree when you are done. For reading CSV back, or for files with unusual quoting, use encoding/csv.

Parsing chat commands

A bot or a console reads lines such as /say good morning. Trim removes the stray spaces around the line, StartsWith tells a command from a plain message, and IndexOf finds the first space that separates the command from its argument. EqualFold compares without caring about upper or lower case, so /HELP and /help do the same thing.

str-guide-commands.salam
import str

func handle(line: str): str:
    text := str.Trim(line)
    if not str.StartsWith(text, "/"):
        ret "chat: " + text
    end
    space := str.IndexOf(text, " ")
    mut name := text
    mut rest := ""
    if space > 0:
        name = str.Substr(text, 0, space)
        rest = str.Trim(str.Substr(text, space + 1, text.len() - space - 1))
    end
    if str.EqualFold(name, "/help"):
        ret "commands: /help, /say TEXT, /shout TEXT"
    else str.EqualFold(name, "/say"):
        ret "bot says: " + rest
    else str.EqualFold(name, "/shout"):
        ret "bot shouts: " + str.Upper(rest)
    end
    ret "unknown command " + str.TrimPrefix(name, "/")
end

func main:
    each line in ["hello everyone", "/HELP", "  /say good morning ", "/Shout fire drill", "/dance"]:
        println handle(line)
    end
end
Outputchat: hello everyone commands: /help, /say TEXT, /shout TEXT bot says: good morning bot shouts: FIRE DRILL unknown command dance

IndexOf and Substr count in bytes. That is safe here because the space being searched for is a single byte, so the cut always lands on a character boundary even when the argument is Persian. When the position comes from counting characters instead, use CharFind and CharSubstr.

import str

func main:

ByteSub

func ByteSub(s: str, start: int, n: int): str
Cuts n bytes starting at byte start. The C and LLVM backends return the bytes untouched, but the JavaScript backend decodes them as UTF-8, so a cut that falls inside a multi-byte character produces a replacement character and a different byte length. For cutting by character use CharSubstr.
