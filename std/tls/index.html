tls

Secure TLS 1.3 and 1.2 connections and public key cryptography tools, with no OpenSSL needed.

The tls package is a complete implementation of TLS 1.2 and 1.3 written in Salam, with no outside library. A client connects with Dial and checks the server certificate against the system roots; a server reads its certificate and key with NewServerConfig and secures each accepted socket with WrapServer. Most programs never call it directly: net.http, net.email and net.websocket use it for https, SMTPS and wss. For code written in the OpenSSL style (a context, SSL_connect, SSL_read), ssl offers that interface on top of this package.

The cryptography tools here are also useful for protocols and storage of your own: the two sides make a shared secret with ECDH, derive a key from it with HKDF, and encrypt and seal the message with AES-GCM; P-256 signs and verifies. Keys and data are passed around as base64 text, which keeps binary bytes safe inside a str.

Things to know:

  • Check ConnOk after Dial. A failed handshake or a bad certificate gives a closed connection, and ConnError says why.
  • Read returns a str, which stops at a zero byte. For binary data use ReadBytes and WriteBytes with your own buffer.
  • Clients cannot present a certificate (no mutual TLS), and a Conn is passed by reference and belongs to one thread at a time.
  • Never repeat an AES-GCM nonce under one key; the sealing section shows a counter that avoids it.
  • AES-GCM runs on the processor's AES instructions when it has them: AES-NI and PCLMULQDQ on x86-64, the Crypto Extensions on AArch64, in every build made with the LLVM backend, which includes all releases. This covers AeadNew, the one shot AesGcmSealRaw and AesGcmOpenRaw and the TLS record layer, so the proxy and VPN protocols get it with no change. Other backends, and processors without the instructions, use the table based code, which gives the same bytes. cpu tells which path is in use and can force the software one.

Connect to a server and handle a bad certificate

Dial does the whole handshake and checks the certificate chain against the system roots and the name in NewConfig. When something is wrong, the connection is not open and ConnError says why: the certificate expired, it was issued for another name, or it does not chain to a trusted root. Always check ConnOk before you write. The program below tries a working site and three of the deliberately broken hosts at badssl.com.

tls-https-check.salam
import tls

func probe(host: str):
    cfg := tls.NewConfig(host)
    mut conn := tls.Dial(host, 443, cfg)
    if not tls.ConnOk(conn):
        println host, "refused:", tls.ConnError(conn)
        ret
    end
    println host, tls.Version(conn), tls.CipherName(conn), tls.PeerCertCount(conn), "certificates"
    tls.Close(conn)
end

func main:
    probe("www.salamlang.ir")
    probe("expired.badssl.com")
    probe("wrong.host.badssl.com")
    probe("self-signed.badssl.com")
end

It needs network access, so it is only checked here. When it was run, it printed the lines below; the cipher and the number of certificates depend on the server.

www.salamlang.ir TLS1.3 TLS_CHACHA20_POLY1305_SHA256 3 certificates
expired.badssl.com refused: certificate verification failed: certificate expired
wrong.host.badssl.com refused: certificate verification failed: hostname does not match certificate
self-signed.badssl.com refused: certificate verification failed: no trusted issuer found

For a private server with its own certificate authority, set ca_file in the config to that CA's PEM file. insecure_skip_verify turns the check off; use it only for a quick local test, never in a program others rely on.

Encrypt records with AES-GCM

AesGcmSeal encrypts a text and adds a tag, so that AesGcmOpen notices any change: a wrong key, a wrong nonce or a changed byte all make ok false instead of returning garbage. The key is 32 random bytes as base64; make it once with RandomSalt(32) and keep it secret. The nonce must never repeat under one key. The simple rule is a counter: GcmNonce(0) for the first message, GcmNonce(1) for the next, and the counter is stored next to the record so that it can be opened later.

tls-sealed-records.salam
import tls

func main:
    key := "q1V0kA8mY8l3R9m0bJvT0F6c0w2f5yYQ1aZt3pK8sXo="
    records := ["balance=120", "balance=95", "balance=310"]

    mut sealed := Vector {} as Vector<str>
    mut ok := false
    each i, r in records:
        sealed.Push(tls.AesGcmSeal(key, tls.GcmNonce(i as i64), r, ok))
    end
    println "sealed", sealed.Len(), "records:", ok
    println "first one:", sealed.Get(0)

    each i, s in sealed:
        plain := tls.AesGcmOpen(key, tls.GcmNonce(i as i64), s, ok)
        println "record", i, "->", plain, ok
    end

    _ := tls.AesGcmOpen(key, tls.GcmNonce(1), sealed.Get(0), ok)
    println "opened with the wrong nonce:", ok
    _ := tls.AesGcmOpen("AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA=", tls.GcmNonce(0), sealed.Get(0), ok)
    println "opened with the wrong key:", ok
end
Outputsealed 3 records: true first one: q/F2IqBhzaLO/CFJROFcuA2GEUtg3H4MyDU5 record 0 -> balance=120 true record 1 -> balance=95 true record 2 -> balance=310 true opened with the wrong nonce: false opened with the wrong key: false

With a fixed key and nonce the output is always the same, which is why the program can print it. That is also the danger: the same nonce for two different texts lets an attacker learn about both, so never reset the counter while the key stays the same.

A shared key from public keys

Two programs that have never met can agree on a key without sending it. Each makes an ECDH key pair with EcdhP256Generate and sends the other only its public key. EcdhP256Shared then gives both the same secret, and HkdfSha256 turns it into a key for AES-GCM. Someone who saw both public keys still cannot compute the secret. The info text names what the key is for, so one secret can safely give separate keys for separate uses.

tls-secure-channel.salam
import tls

struct Party:
    pub private_key: str = ""
    pub public_key: str = ""
end

func new_party(): Party:
    mut p := Party {}
    _ := tls.EcdhP256Generate(p.private_key, p.public_key)
    ret p
end

func session_key(me: Party, peer_public: str, salt: str): str:
    mut ok := false
    shared := tls.EcdhP256Shared(me.private_key, peer_public, ok)
    ret tls.HkdfSha256(shared, salt, "notes app v1 session", 32, ok)
end

func main:
    alice := new_party()
    bob := new_party()
    salt := tls.RandomSalt(16)

    alice_key := session_key(alice, bob.public_key, salt)
    bob_key := session_key(bob, alice.public_key, salt)
    println "both sides derived the same key:", alice_key == bob_key

    mut ok := false
    wire := tls.AesGcmSeal(alice_key, tls.GcmNonce(0), "meet at the station at nine", ok)
    println "alice sent", wire.Len(), "base64 characters"
    println "bob reads:", tls.AesGcmOpen(bob_key, tls.GcmNonce(0), wire, ok)

    eve := new_party()
    eve_key := session_key(eve, alice.public_key, salt)
    _ := tls.AesGcmOpen(eve_key, tls.GcmNonce(0), wire, ok)
    println "eve, with only the public keys, can read it:", ok
end
Outputboth sides derived the same key: true alice sent 60 base64 characters bob reads: meet at the station at nine eve, with only the public keys, can read it: false

ECDH alone does not tell you who is on the other side. In a real protocol, sign the public key, or check it against one you already know, or someone in the middle can make a key with each side.

Sign and verify with P-256

P256Sign signs a SHA-256 digest with a private key, and anyone with the public point can check it with P256Verify. It suits licence files, update manifests and messages that must be checked by many readers but written by one. The signature follows RFC 6979, so the same key and digest always give the same signature and no random number generator is involved.

tls-signed-license.salam
import tls
import crypto
import encoding
import mem

func digest_of(text: str): str:
    out := mem.Allocate(32 as u64)
    crypto.Sha256Bytes(text as void*, text.Len(), out)
    d := encoding.Base64EncodeBytes(out, 32)
    mem.Free(out)
    ret d
end

func main:
    vendor_private := "cqXpGz8zHwUzjEQonZMVMh4K9+jyX3zMfzeFP0025Rk="
    vendor_public := tls.EcdhP256PublicPoint(vendor_private)

    license := "customer=Pars Co;seats=25;until=2027-12-31"
    mut ok := false
    signature := tls.P256Sign(vendor_private, digest_of(license), ok)
    println "signed:", ok
    println "signature:", signature

    println "genuine license:", tls.P256Verify(vendor_public, digest_of(license), signature)
    edited := "customer=Pars Co;seats=250;until=2027-12-31"
    println "seats edited:", tls.P256Verify(vendor_public, digest_of(edited), signature)
    println "same signature again:", tls.P256Sign(vendor_private, digest_of(license), ok) == signature
end
Outputsigned: true signature: Z9NSfoPJN31QJ2ELmSVzzziGYOZrA/+elf2AUQXUjx4uBr0U+Pyx7HxCt/gsuGacDKrD0KcJ6g1KkSOOjI1Hlg== genuine license: true seats edited: false same signature again: true

The private key in the program is there so that the output stays the same. Keep a real one out of the source code: read it from a file or the environment, and ship only the public point with the program that checks.

JobUse
An HTTPS or other TLS clientNewConfig, Dial, Write, Read, Close; for plain web requests, net.http does this for you
A TLS serverNewServerConfig, then WrapServer on each accepted socket
Upgrade a socket that is already open (STARTTLS)WrapClient
Encrypt data at restAesGcmSeal, AesGcmOpen, GcmNonce

tls-Server.salam
import tls
import net.tcp
import mem

func main:
    cfg := tls.NewServerConfig("cert.pem", "key.pem")
    if not cfg.ok:
        println "the certificate or key could not be read"
        ret
    end
    server := tcp.Bind(8443)
    until true:
        sock := tcp.Accept(server)
        mut conn := tls.WrapServer(sock.fd, cfg)
        if tls.ConnOk(conn):
            if tls.Readable(conn) or tls.Pending(conn) > 0:
                println tls.Read(conn, 1024)
            end
            buffer := mem.Allocate(256 as u64)
            n := tls.ReadBytes(conn, buffer, 256)
            _ := tls.WriteBytes(conn, buffer, n)
            tls.Cork(conn)
            _ := tls.Write(conn, "HTTP/1.1 200 OK\r\nContent-Length: 5\r\n\r\nhello")
            _ := tls.Flush(conn)
            mem.Free(buffer)
            println tls.Fd(conn) >= 0
        end
        tls.Close(conn)
    end
end

tls-Client.salam
import tls

func main:
    mut cfg := tls.NewConfig("example.com")
    cfg.alpn = "http/1.1"
    mut conn := tls.Dial("example.com", 443, cfg)
    if not tls.ConnOk(conn):
        println "error:", tls.ConnError(conn)
        ret
    end
    println tls.Version(conn), tls.CipherName(conn), tls.PeerCertCount(conn)
    _ := tls.Write(conn, "GET / HTTP/1.1\r\nHost: example.com\r\nConnection: close\r\n\r\n")
    mut body := ""
    until tls.ConnOk(conn):
        chunk := tls.Read(conn, 4096)
        if chunk.Len() == 0:
            break
        end
        body += chunk
    end
    println body.Len() > 0
    tls.Close(conn)
end

import encoding
import io

func main:
    mut roots := tls.LoadRoots("/etc/ssl/cert.pem")

    println tls.RootCount(chain)
    mut key := tls.LoadPrivateKeyFile("key.pem")
    mut key2 := tls.ParsePrivateKeyPEM("-----BEGIN ...")
    tls.FreePrivateKey(key2)

    cert := tls.HexDecodeBuf("3082...")
    println tls.CertIsValid(cert), tls.CertSubjectCN(cert)
    code := tls.VerifyCert(cert, roots, "example.com")
    println code, tls.VerifyError(code)

    digest := tls.HashDigest(false, "message")

    pem := io.ReadFile("rsa-key.pem")
    mut good := false
    println tls.RsaKeyBits(pem)

    tls.Close(conn2)
    println tls.TLS10, tls.TLS11, tls.TLS12, tls.TLS13
    println tls.SelfTest()

AEAD_AES_128_GCM

const AEAD_AES_128_GCM: i32 = 0
The cipher number of AES-128-GCM for AeadNew; its key is 16 bytes.
tls-Aead.salam
import tls
import mem

const DIGITS := "0123456789abcdef"

func hex_of(p: void*, n: int): str:
    mut out := ""
    repeat n in i:
        b := (p as u8*)[i] as int
        out += DIGITS.Substr(b / 16, 1) + DIGITS.Substr(b % 16, 1)
    end
    ret out
end

func filled(n: int, start: int): void*:
    p := mem.AllocateZeroed(n as u64)
    repeat n in i:
        (p as u8*)[i] = ((start + i) % 256) as u8
    end
    ret p
end

func main:
    println tls.AEAD_AES_128_GCM, tls.AEAD_AES_256_GCM, tls.AEAD_CHACHA20_POLY1305
    println tls.AEAD_TAG_LEN, tls.AEAD_NONCE_LEN
    println tls.AeadKeyLen(tls.AEAD_AES_128_GCM), tls.AeadKeyLen(tls.AEAD_AES_256_GCM), tls.AeadKeyLen(tls.AEAD_CHACHA20_POLY1305)

    key := filled(32, 0)
    nonce := filled(12, 100)
    message := "attack at dawn"
    n := message.Len()
    out := mem.AllocateZeroed((n + tls.AEAD_TAG_LEN) as u64)
    back := mem.AllocateZeroed((n + 1) as u64)

    each kind in [tls.AEAD_AES_128_GCM, tls.AEAD_AES_256_GCM, tls.AEAD_CHACHA20_POLY1305]:
        ctx := tls.AeadNew(kind, key)
        tls.AeadSeal(ctx, nonce, null, 0, message as void*, n, out)
        println kind, hex_of(out, n + tls.AEAD_TAG_LEN)
        println tls.AeadOpen(ctx, nonce, null, 0, out, n, back), (back as str).Substr(0, n)
        (out as u8*)[0] = ((out as u8*)[0] as int ^ 1) as u8
        println tls.AeadOpen(ctx, nonce, null, 0, out, n, back)
        tls.AeadFree(ctx)
    end

    println tls.AesGcmSealRaw(key, 16, nonce, null, 0, message as void*, n, out)
    println hex_of(out, n + tls.AEAD_TAG_LEN)
    println tls.AesGcmOpenRaw(key, 16, nonce, null, 0, out, n + tls.AEAD_TAG_LEN, back), (back as str).Substr(0, n)

    println tls.ChaCha20Poly1305SealRaw(key, nonce, null, 0, message as void*, n, out)
    println hex_of(out, n + tls.AEAD_TAG_LEN)
    println tls.ChaCha20Poly1305OpenRaw(key, nonce, null, 0, out, n + tls.AEAD_TAG_LEN, back), (back as str).Substr(0, n)

    nonce24 := filled(24, 100)
    println tls.XChaCha20Poly1305SealRaw(key, nonce24, null, 0, message as void*, n, out)
    println hex_of(out, n + tls.AEAD_TAG_LEN)
    println tls.XChaCha20Poly1305OpenRaw(key, nonce24, null, 0, out, n + tls.AEAD_TAG_LEN, back), (back as str).Substr(0, n)

    plain := mem.AllocateZeroed(16 as u64)
    repeat 16 in i:
        (plain as u8*)[i] = (i * 17) as u8
    end
    cipher := mem.AllocateZeroed(16 as u64)
    key16 := filled(16, 0)
    println tls.AesEcbBlock(key16, 16, plain, cipher, false), hex_of(cipher, 16)
    println tls.AesEcbBlock(key16, 16, cipher, back, true), hex_of(back, 16) == hex_of(plain, 16)

    mem.Free(key)
    mem.Free(nonce)
    mem.Free(nonce24)
    mem.Free(out)
    mem.Free(back)
    mem.Free(plain)
    mem.Free(cipher)

            if part.Len() == 0:

            end
