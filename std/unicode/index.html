unicode

What Unicode knows about a character: category, script, writing direction, case, decomposition and composition.

import unicode
On this page
  1. Constants and variables
  2. Functions

Unicode gives every character of every script in the world a number, called a code point: "ش" is 1588 and "A" is 65. For any code point, the unicode package says what kind of character it is: letter or digit, which script it belongs to, whether it is written right to left or left to right, and what its upper and lower case forms are.

Most of the time the str package is enough, and it uses this one underneath. This package is for when you are inspecting text character by character yourself, in a parser, an editor or a text cleaning tool. The data is generated from the official Unicode database, version 16.

To get the code points of a string, use str.CodePoints.

Constants and variables

ZWNJ

const ZWNJ: i32 = 8204
The code point of the zero width non-joiner (U+200C), which in Persian keeps two letters side by side without joining them, as in «می‌روم».

import unicode

func main:
    println unicode.ZWNJ, unicode.ZWJ, unicode.MaxCodePoint
    println "unicode", unicode.Version
end

MaxFoldLen

const MaxFoldLen: i32 = 3
The largest number of code points a full case fold of one character can produce. A buffer of this size is enough to fold any character.
unicode-ToUpper.salam
import unicode

func main:
    println unicode.ToUpper(945), unicode.ToLower(913), unicode.ToTitle(454), unicode.ToFold(913)
    println unicode.ToUpper(1588)
    c := 223
    println unicode.HasFullFold(c), unicode.FullFoldLen(c)
    repeat unicode.FullFoldLen(c) in i:
        print unicode.FullFoldAt(c, i), ""
    end
    println ""
    println unicode.MaxFoldLen
end
Output913 945 453 945 1588 true 2 115 115 3

CombiningClass

func CombiningClass(cp: int): int
Returns the combining class of a mark. During normalisation, the marks following a letter are sorted by this number so that the order they were typed in does not matter. For ordinary characters it is zero.

import unicode

func main:
    alef_madda := 1570
    println unicode.DecompLen(alef_madda), unicode.DecompAt(alef_madda, 0), unicode.DecompAt(alef_madda, 1)
    println unicode.Compose(1575, 1619), unicode.Compose(1575, 65)
    println unicode.CombiningClass(1614), unicode.CombiningClass(1616), unicode.CombiningClass(1575)
    lam_alef := 65271
    println unicode.DecompLen(lam_alef), unicode.CompatDecompLen(lam_alef)
    println unicode.CompatDecompAt(lam_alef, 0), unicode.CompatDecompAt(lam_alef, 1)
end
