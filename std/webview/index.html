webview

A desktop program with an HTML interface in a native window.

import webview
On this page
  1. Types
  2. Constants and variables
  3. Functions

This package opens a native window with the browser the operating system already has in it: WebView2 on Windows, WKWebView on macOS and WebKitGTK on Linux. Write the interface of the program in HTML and CSS, show it with SetHTML or Navigate, and start the event loop with Run.

The examples open a window, which is why the site only checks them.

Types

WebView

struct WebView
A window with a browser inside it.
NameTypeDescription
handlevoid*The handle of the browser on Linux and CEF.
windowvoid*The handle of the window in the operating system.
closedbool = falseThe window has been closed.
webview-Window.salam
import webview

func main:
    mut win := webview.Create(true)
    win.SetTitle("hello")
    win.SetSize(800, 600, webview.HINT_NONE)
    win.Init("window.salam = { version: 1 };")
    win.SetHTML("<h1>hello world</h1>")
    win.Eval("document.title = 'ready'")
    win.Run()
    if not win.IsClosed():
        win.Terminate()
    end
    win.Destroy()
    println webview.HINT_FIXED
end

import webview

func main:
    mut win := webview.Create()
    win.SetTitle("the Salam language")
    win.SetSize(1024, 768, webview.HINT_FIXED)
    win.Navigate("https://salamlang.github.io/Salam/")
    win.Run()
    win.Destroy()
end
