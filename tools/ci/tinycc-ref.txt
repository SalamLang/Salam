# The TinyCC commit every build of tcc in this repo is pinned to - CI
# bundles, CI test jobs, and tools/bash/install-tcc.sh for developers.
#
# Why a commit and not a release: upstream's last tagged release is 0.9.27
# (December 2017) and Savannah has published nothing since. The mob branch
# self-identifies as 0.9.28rc and is what every distro's "0.9.27+git..."
# package is cut from, so tracking a pinned mob commit is the only way to
# get eight years of fixes - including the win64 miscompile of a call whose
# first two arguments are both floating point, which 0.9.27 has and this
# does not (std/opencv/native/mock/opencv_mock.c documents what it cost).
#
# To move the pin: change the SHA, run the full test suite on Windows and
# Linux, and say in the PR what upstream changed. One line, SHA only.
