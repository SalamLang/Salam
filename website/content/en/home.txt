home.faq_title = Frequently asked questions about Salam
faq.1.q = What is Salam?
faq.1.a = Salam is a <strong>general-purpose, statically typed, open source programming language</strong>. Its distinguishing feature is that it is fully bilingual: you can write a program in English or in Persian, and either way it compiles to a native executable for Linux, macOS, Windows and the web.
faq.2.q = What does bilingual actually mean here?
faq.2.a = Every keyword, built-in type, standard library package and compiler message has an English name and a Persian one, and the compiler accepts both. Persian digits are accepted wherever English ones are. The command <code>salam translate en program.salam</code> converts a Persian program to English, and <code>translate fa</code> goes the other way.
faq.3.q = Is Salam fast?
faq.3.a = Yes. Salam compiles to native machine code with no virtual machine and no garbage collector. Across our benchmark of 42 equivalent programs it ran on a par with C and Rust and many times faster than Python and PHP. The <a href="/speed/">speed page</a> has the numbers and the method.
faq.4.q = What is Salam good for?
faq.4.a = The same things any systems language is good for: command line tools, servers, compilers, numeric work, embedded and operating system code. The compiler itself is written in Salam, and so is an operating system and the program that builds this website.
faq.5.q = Is Salam free and open source?
faq.5.a = Yes. Salam is released under the GNU GPL version 3 and the full source is on GitHub.
faq.6.q = Which operating systems does Salam run on?
faq.6.a = Salam installs on Linux, macOS and Windows, and compiles programs for those plus WebAssembly and the browser. You can also write and run code in the online editor without installing anything.
faq.7.q = Do I need to know Persian to use Salam?
faq.7.a = No. The English form of the language is complete on its own: this site, the course and the standard library reference are all usable without a word of Persian. The Persian form is there for people who prefer it, and the two interoperate.
