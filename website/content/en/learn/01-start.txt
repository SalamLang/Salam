<h2 id="hello">Hello, world</h2>
<p>Every Salam program starts at <code>func main</code>, the first thing that runs. A block opens with a colon (<code>:</code>) and closes with <code>end</code>, and indenting the lines inside it keeps the code readable.</p>
{{example.hello}}

<h2 id="run">Running a program</h2>
<p>Save your code in a file with a <code>.salam</code> extension, say <code>hello.salam</code>. <code>salam run hello.salam</code> compiles it and runs it straight away. If you want a standalone executable instead, use <code>salam build hello.salam</code> and a native binary appears next to your source. <code>salam format</code> tidies the code into one consistent shape, and <code>salam translate fa hello.salam</code> turns an English program into a Persian one (<code>translate en</code> goes the other way). You can also run every example here in the <a href="https://editor.salamlang.ir">online editor</a> without installing anything.</p>

<h2 id="print">Printing output</h2>
<p><code>println</code> prints its values and moves to the next line; <code>print</code> stays on the same line. Separate several values with commas and Salam writes them out with one space between them.</p>
{{example.start-print}}
<p>For error messages use <code>printerrln</code> and <code>printerr</code>. They write to standard error, so they stay out of the program's real output and survive being piped elsewhere.</p>
{{example.start-stderr}}

<h2 id="input">Reading input</h2>
<p><code>input</code> reads one line from the user and gives it back as a string. Like <code>print</code> it takes no parentheses, and it always wants a prompt, which it prints before reading. If you do not want one, write <code>input ""</code>:</p>
{{example.start-input}}

<h2 id="comments">Comments</h2>
<p>Anything after <code>//</code> to the end of the line, and anything between <code>/*</code> and <code>*/</code>, is a comment and is not run.</p>
{{example.start-comments}}
