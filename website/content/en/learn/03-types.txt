<p>Text has a lesson of its own, <a href="/learn/strings/">strings and text</a>. This one is about numbers, booleans and characters, and about moving values from one type to another.</p>

<h2 id="numbers">Number sizes and bases</h2>
<p>Numbers can be written in base sixteen (<code>0xFF</code>), base two (<code>0b1010</code>) and base eight (<code>0o17</code>), and you can group the digits with <code>_</code> to make them readable.</p>
{{example.types-ints}}
<p>A whole number literal is an <code>int</code>, unless it is too big for one: <code>9000000000</code> becomes an <code>i64</code> on its own. <code>sizeof</code> gives the size of a type in bytes:</p>
{{example.types-sizeof}}
<p>An <code>int</code> runs from about minus two billion to plus two billion, an <code>i64</code> to about nine quintillion. A <code>u8</code> holds 0 to 255, which is exactly one byte.</p>

<h2 id="overflow">When a number does not fit</h2>
<p>If a calculation goes past the end of its type, the number wraps around to the other end and the program carries on without a word. A page counter stored in an <code>int</code> turns negative after about two billion views; the same counter in an <code>i64</code> keeps going. Unsigned types wrap at zero instead, so taking 5 from 3 gives a huge positive number.</p>
{{example.types-overflow}}
<p>So pick the type from the largest value you expect, not the first value you see. Use <code>i64</code> for counters, sizes of files, money in the smallest unit and time in milliseconds, and keep unsigned types for things that really are never negative, such as bytes.</p>

<h2 id="floats">Decimal numbers</h2>
<p>A decimal literal such as <code>2.5</code> is an <code>f64</code>, and it can be written with an exponent: <code>1.5e3</code> is 1500. Printing uses the shortest form that reads back as the same number, so <code>10.0</code> prints as <code>10</code>. Decimal numbers are stored in binary, and most decimal fractions have no exact binary form:</p>
{{example.types-float}}
<p>That tiny error is why you should not compare decimal results with <code>==</code>; check that the difference is small enough instead. <code>f32</code> (also called <code>float</code>) saves memory but keeps only about seven digits, as the last line shows. For money, where every cent must add up, use the <a href="/std/decimal/">decimal</a> package, or count in whole cents with an <code>i64</code>.</p>

<h2 id="chars">Booleans and characters</h2>
<p>A <code>bool</code> is <code>true</code> or <code>false</code>, and every condition in Salam has to be one. There is no "truthy" number: <code>if count:</code> is an error (if condition must be bool, got 'i32'); write <code>if count != 0:</code>.</p>
<p>A <code>char</code> holds one character. <code>'A'</code> works for a single byte, such as an English letter or digit; anything else needs the <code>u</code> prefix, as in <code>u'م'</code>, and the compiler says so if you forget. Converting a character to <code>int</code> gives its Unicode code, and converting back goes the other way:</p>
{{example.types-char}}

<h2 id="cast">Mixing types and converting</h2>
<p>Arithmetic may widen a value when nothing can be lost: an <code>int</code> with an <code>f64</code> gives an <code>f64</code>, and an <code>int</code> with an <code>i64</code> gives an <code>i64</code>. Going the other way is never silent. Storing an <code>f64</code> in an <code>int</code> variable, or passing an <code>i64</code> to an <code>int</code> parameter, is an error until you write the conversion with <code>as</code>.</p>
{{example.types-mix}}
<p>Dividing two whole numbers gives a whole number, with the fraction dropped. Convert one side first when you want the fraction:</p>
{{example.types-cast}}
<p>The rules of <code>as</code> in short:</p>
<ul>
<li>Decimal to whole cuts the fraction off toward zero: <code>3.9 as int</code> is 3 and <code>-7.9 as int</code> is -7. It does not round.</li>
<li>A whole number that does not fit the target wraps: <code>300 as u8</code> is 44.</li>
<li>A cast to the type the value already has is an error (E093 useless cast), so remove it.</li>
<li>Text never becomes a number through <code>as</code>: <code>"42" as int</code> is an error. Use <code>to_int()</code>, below.</li>
</ul>

<h2 id="text">Text and numbers</h2>
<p>Numbers often arrive as text: typed by a user, read from a file, sent by a web form. <code>to_int()</code> and <code>to_float()</code> turn text into numbers, and <code>+</code> with a string on the left turns a number into text.</p>
{{example.types-parse}}
<p>Watch the third value: text that is not a number gives 0, with no error. If 0 is a value that could really appear, check the text first, for example with the digit tests in the <a href="/std/str/">str</a> package. To write a number with a fixed number of decimal places, use <code>conv.FormatFloatPrec</code> from the <a href="/std/conv/">conv</a> package.</p>
