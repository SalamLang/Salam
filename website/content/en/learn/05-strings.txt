<h2 id="literals">Ways to write a string</h2>
<ul>
<li><code>"..."</code> is an ordinary string, and escapes such as <code>\n</code> (a new line), <code>\t</code> and <code>\"</code> work inside it.</li>
<li><code>`...`</code> (backticks) is a raw string: everything inside stays exactly as written, and it may span several lines.</li>
<li><code>"""..."""</code> is a multi-line string in which escapes still work.</li>
<li><code>«...»</code> is another ordinary string, and it works only in Persian files. Escapes apply there too, and a closing guillemet has to be escaped as <code>\»</code>.</li>
</ul>
{{example.str-literals}}
