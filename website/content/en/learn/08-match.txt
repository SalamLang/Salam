<h2 id="match">match</h2>
<p><code>match</code> is an expression: it compares a value against the cases and gives back the result of the branch that matched. Several cases can share one branch by separating them with commas, and <code>else</code> catches everything left over.</p>
{{example.match-values}}
<p>Over an enum, match also checks that no case has been left out:</p>
{{example.match}}

<h2 id="switch">switch</h2>
<p><code>switch</code> is a statement for choosing between cases. A case label can be one value, several values separated by commas, or a range such as <code>1 to 3</code>. If a case does not end with <code>break</code>, execution falls into the next one, so write <code>break</code> wherever you do not want that.</p>
{{example.switch}}
<p>A switch label may begin with a comparison operator, such as <code>&gt;= 90</code>. <code>switch true</code> takes the place of a chain of ifs: every label is a condition, and the first one that holds runs.</p>
{{example.switch-true}}

<h2 id="struct-patterns">Struct patterns</h2>
<p>match can test a struct against its fields. <code>x = 0</code> means the field has to equal zero, and a bare name such as <code>y</code> binds the field's value to a variable of that name. Because patterns carry conditions, a final <code>else</code> is required.</p>
{{example.match-struct}}
<div class="note"><p>Use match when you need a value back, or when you want the compiler to check that the cases are complete; use switch when each case runs several statements.</p></div>
