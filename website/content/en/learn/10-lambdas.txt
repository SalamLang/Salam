<h2 id="lambda">An anonymous function</h2>
<p><code>(parameters): body end</code> builds a function with no name. The body is an ordinary block, so a single <code>ret</code> fits on one line and a longer body spreads over several, closing with <code>end</code>.</p>
{{example.lambda}}

<h2 id="type">The function type</h2>
<p>The type of a function is written <code>func (parameter types) result type</code>; <code>func (int) int</code>, for instance, is a function that takes one <code>int</code> and gives back an <code>int</code>. With that type a function such as <code>apply</code> can accept any compatible function.</p>
<div class="note"><p>An anonymous function copies the outside variables it uses at the moment it is created. If you need to change something outside it, pass that in as a reference parameter instead.</p></div>
