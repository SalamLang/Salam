<h2 id="lambda">An anonymous function</h2>
<p><code>(parameters): body end</code> builds a function with no name, often called a lambda. The body is an ordinary block, so a single <code>ret</code> fits on one line and a longer body spreads over several lines and closes with <code>end</code>. You call it like any other function.</p>
{{example.lambda}}
<p>Never write a result type on a lambda: <code>(x: int): int: ret x end</code> does not parse. Salam works the type out from the <code>ret</code> statements. A lambda that returns nothing simply has no <code>ret</code> with a value.</p>

<h2 id="type">The function type</h2>
<p>The type of a function is written <code>func (parameter types) result type</code>. <code>func (int) bool</code> takes one <code>int</code> and gives back a <code>bool</code>; <code>func (int)</code> takes an <code>int</code> and gives back nothing. Use such a type for a parameter, and the function accepts any compatible function. When a type is long or used often, give it a name with <code>type</code>.</p>
{{example.lambda-type}}
<p>The rule can be a lambda kept in a variable, like <code>hot</code>, or written straight into the call. Either way <code>count where</code> does not know or care what the rule checks.</p>

<h2 id="named">Passing a named function</h2>
<p>The bare name of a named function is its address, typed <code>i64</code>, not a value of a function type, so <code>apply all(prices, with tax)</code> is rejected with E012, "cannot pass 'i64' to 'func(i32) i32'". Wrap the function in a lambda that calls it:</p>
{{example.lambda-named}}
<p>The <code>i64</code> form exists for C-style callback slots, such as the routes of a web server. Inside Salam code, the lambda wrapper is the way to go.</p>

<h2 id="sort">Sorting with a comparator</h2>
<p>A comparator is a function that takes two items and answers "should the first come before the second?". <code>sort.SortBy</code> sorts a <code>Vector</code> with it, so you decide the order: by name, by score, highest first, or anything else. <code>sort.StableSortBy</code> also keeps items that compare equal in the order they already had.</p>
{{example.lambda-sort}}
<p>Lena and Arash both have 85. Because the second sort is stable, they stay in the alphabetical order the first sort left them in. The <a href="/learn/collections/">collections lesson</a> covers <code>Vector</code>, and the <a href="/std/sort/">sort package</a> has the full list of sorting functions.</p>

<h2 id="return">Returning a function</h2>
<p>A function may build a lambda and return it. The lambda keeps a copy of the values it uses, so every call to the outer function produces a different function. This is a neat way to make a family of related functions from one recipe.</p>
{{example.lambda-make}}

<h2 id="capture">What a lambda captures</h2>
<p>A lambda copies the outside variables it uses at the moment it is created. Changing the variable afterwards does not reach the lambda, and a lambda that changes a captured variable changes only its own copy. That copy lives as long as the lambda, so a lambda can count across calls, but the caller never sees the count.</p>
{{example.lambda-capture}}
<p>To let a lambda change something outside it, use a <code>mut</code> global, as below, or have the lambda return the new value and assign it at the call.</p>
{{example.lambda-share}}
<p>Notice that a lambda can be the last argument of a call and still span several lines; the call's closing parenthesis comes right after its <code>end</code>.</p>

<h2 id="store">Keeping functions in a Vector</h2>
<p>A function type can be the element type of a <code>Vector</code>, so a list of steps can be built at run time and then applied in order. Here each step changes the value and passes it on to the next.</p>
{{example.lambda-pipeline}}

<h2 id="rules">Rules of thumb</h2>
<ul>
<li>Use a lambda for a short piece of behaviour that belongs to one call; give it a name with <code>func</code> once it grows or is needed in several places.</li>
<li>Name long function types with <code>type</code>.</li>
<li>To pass a named function, wrap it: <code>(p: int): ret with tax(p) end</code>.</li>
<li>A lambda works on copies. Share state through a return value or a global.</li>
<li>Every time a lambda that captures variables is created, it allocates room for its copies, and that memory is not freed. Create such a lambda once, outside a loop, rather than in every round.</li>
</ul>
