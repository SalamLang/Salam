<h2 id="defer">defer</h2>
<p>A statement written after <code>defer</code> runs at the end of the block, whichever way the function leaves it. With several defers, the last one runs first. The commonest use is freeing memory right beside the line that allocated it.</p>
{{example.defer}}

<h2 id="modifiers">Function modifiers</h2>
<p>These modifiers may be written before <code>func</code>:</p>
<ul>
<li><code>pure</code>: the function has no side effects, so it neither prints nor changes a global, and the compiler checks that.</li>
<li><code>inline</code> and <code>noinline</code>: a hint that the body should, or should not, be placed at the call site.</li>
<li><code>noret</code>: the function never returns, like one that ends the program.</li>
<li><code>deprecated</code>: the function is obsolete, and using it warns.</li>
<li><code>pub</code>: the function is reachable outside its package, which the packages lesson covers.</li>
</ul>
{{example.fn-mods}}
