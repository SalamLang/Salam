lesson.body <<
<h2 id="vector">Vector</h2>
<p>Build one with <code>Vector {} as Vector&lt;type&gt;</code>. <code>push</code> adds an element, <code>get</code> and <code>set</code> read and replace one, <code>pop</code> takes the last one off and <code>len</code> gives the count.</p>
{{example.vector}}
<div class="note"><p>A Vector and a HashMap both allocate. Write <code>defer ....free()</code> straight after creating one, so the memory is released when the function ends.</p></div>

<h2 id="map">HashMap</h2>
<p>A HashMap connects keys to values: <code>put</code> stores a pair, <code>get</code> returns the value for a key, <code>has</code> tests whether a key is there, <code>remove</code> takes it out and <code>size</code> gives the number of pairs. <code>each key, value in map</code> walks all of them.</p>
{{example.hashmap}}
