<h2 id="generic">Generic functions and structs</h2>
<p>Write <code>&lt;T&gt;</code> after the name and the function or struct is written once for any type <code>T</code>. Salam generates a separate, fully specialised version for every type you use it with.</p>
{{example.generics}}

<h2 id="interface">Interfaces</h2>
<p>An <code>interface</code> is a list of methods. Any struct that has all of them implements the interface automatically. A parameter of type <code>dyn Shape</code> accepts any value that implements <code>Shape</code>.</p>
{{example.interface}}
<p>An interface method may carry a default body. A struct that does not write that method gets the default, and a struct that does write it gets its own:</p>
{{example.interface-default}}

<h2 id="impl">impl and type constraints</h2>
<p><code>impl Interface on Type</code> adds an interface's methods to any type at all, including <code>int</code> and <code>str</code>. <code>&lt;T: Ranked&gt;</code> means the function accepts only types that implement that interface.</p>
{{example.impl}}
