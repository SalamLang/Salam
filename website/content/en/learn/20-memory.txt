<h2 id="copy">Values are copied</h2>
<p>When you put a struct into another variable, or pass it to a function, a copy is made, and changing the copy leaves the original alone. If a function has to change the original, declare the parameter as a reference with <code>&amp;:</code>.</p>
{{example.mem-copy}}

<h2 id="free">Freeing memory</h2>
<p>Numbers, strings and plain structs look after themselves. A Vector and a HashMap, though, take memory that has to be handed back with <code>free()</code>. The habit worth forming is to write <code>defer list.free()</code> immediately after creating one.</p>

<h2 id="pointers">Pointers</h2>
<p>For talking to C libraries Salam has pointers as well: <code>int*</code> is a pointer to an int, <code>void*</code> is an untyped pointer and <code>null</code> is the empty one. Ordinary Salam code does not need them.</p>
