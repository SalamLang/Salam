<h2 id="flags">The flags you get</h2>
<ul>
<li>Operating system: <code>SALAM_OS_WINDOWS</code>, <code>SALAM_OS_MAC</code>, <code>SALAM_OS_LINUX</code>, <code>SALAM_OS_UNIX</code>, <code>SALAM_OS_ANDROID</code>, <code>SALAM_OS_WASM</code>, and the BSD family</li>
<li>Processor: <code>SALAM_ARCH_X64</code>, <code>SALAM_ARCH_ARM64</code>, <code>SALAM_ARCH_WASM</code> and the rest</li>
<li>As text: <code>SALAM_OS</code> and <code>SALAM_ARCH</code>, holding values such as <code>"linux"</code> and <code>"arm64"</code></li>
</ul>
<p>These names are ordinary constants in normal code too, so you can print one or use it in a switch.</p>
