<h2 id="link">Linking a library</h2>
<p>For an outside library, write <code>link dynamic "sqlite3"</code> (or <code>link static</code>) before the declarations. A function that takes a variable number of arguments, such as <code>printf</code>, needs <code>...</code> in its declaration.</p>

<h2 id="export">export</h2>
<p>Functions that C code has to call go in an <code>export:</code> block, so they are reachable from C under their plain name.</p>
