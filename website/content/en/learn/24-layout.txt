<h2 id="page">A page</h2>
<p>A <code>layout:</code> block is a tree of page elements. Attributes and styles are written as <code>name = value</code> inside each element:</p>
{{example.layout-page}}

<h2 id="build">Building the page</h2>
<p><code>salam layout build page.salam</code> produces an HTML, a CSS and a JS file, and <code>--inline</code> puts all three into one HTML file. The common elements are <code>header</code>, <code>box</code>, <code>heading</code>, <code>paragraph</code>, <code>link</code>, <code>image</code>, <code>form</code> and <code>button</code>.</p>

<h2 id="table">Tables</h2>
<p>One name can produce a different element depending on where it sits. Inside <code>table</code>, <code>header</code>, <code>main</code> and <code>footer</code> are <code>thead</code>, <code>tbody</code> and <code>tfoot</code>, and <code>column</code> becomes <code>th</code> in a header row and <code>td</code> everywhere else:</p>
{{example.layout-table}}

<h2 id="runtime">Layouts with parameters</h2>
<p>A layout can take a name and parameters, and is then called like a function and returns a string of HTML. Inside it you can use <code>if</code> and <code>each</code> and the values of the parameters. Text that comes from a parameter is escaped for you, so a <code>&lt;script&gt;</code> in the input never reaches the page (new in 0.5.0):</p>
{{example.layout-runtime}}

<h2 id="font">Web fonts</h2>
<p>The <code>font</code> element produces an <code>@font-face</code>. <code>name</code> and <code>url</code> are required; if you leave <code>type</code> out, Salam works it out from the extension in the URL and then from the bytes of a file sitting next to the program. Use the font afterwards with <code>font family</code> (new in 0.5.0):</p>
{{example.layout-font}}

<h2 id="check">Checked while compiling</h2>
<p>Salam checks every element and attribute before it builds the page. A misspelled name, an attribute that element does not have, a malformed value such as a URL in the wrong shape, a required attribute left out, or an element in the wrong place, such as <code>item</code> outside a <code>list</code>, is an error, and the message suggests the nearest valid name.</p>
