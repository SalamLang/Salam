<p><code>salam translate fa program.salam</code> turns English code into Persian, and <code>salam translate en</code> goes the other way. It rewrites keywords, types, the entry function and the built-in methods. The compiler decides which language a file is in from its keywords, and a file uses one language throughout: in a Persian file the English spelling of a built-in name is an error, and the message names the Persian one.</p>

<p>The comparison words <code>eq</code>, <code>neq</code>, <code>lt</code>, <code>gt</code>, <code>lte</code> and <code>gte</code> stand for <code>==</code>, <code>!=</code>, <code>&lt;</code>, <code>&gt;</code>, <code>&lt;=</code> and <code>&gt;=</code>, and both forms work in both languages. In Persian, <code>تا</code> is <code>until</code> at the start of a statement and <code>to</code> inside a <code>repeat</code> header, and <code>هر</code> is <code>each</code> at the start of a statement and the step <code>by</code> inside a <code>repeat</code> header. <code>main</code> is not a keyword but the name of the entry function, which a Persian program calls <code>ریشه</code>.</p>
