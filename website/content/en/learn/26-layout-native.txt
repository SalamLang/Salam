<h2 id="run">Run and build natively</h2>
<p>To run a layout as a native window:</p>
<pre class="code snip" dir="ltr"><code>salam run app.salam --ui=native
salam build app.salam --ui=native</code></pre>
<p><code>run</code> launches the app; <code>build</code> produces a native executable. This uses the layout DSL but targets Salam's native UI runtime instead of generating browser HTML/CSS/JS files.</p>

<h2 id="common">What stays the same</h2>
<ul>
<li>Tree structure of pages/elements and nesting</li>
<li>Attributes and style properties (including simpler values like <code>50%</code> and <code>#hex</code>)</li>
<li>Components (<code>component</code>/<code>بخش</code>), parameters, conditionals/loops in dynamic layouts, and overall DSL patterns</li>
</ul>
<p>The goal is to share much of the UI description, while runtime behavior and supported features depend on the target engine.</p>

<h2 id="differences">Differences and limitations vs web</h2>
<p>The native target is not a browser, so web-specific features may be unavailable or behave differently. Elements/capabilities tied to the browser DOM/runtime (such as raw browser scripts, iframes, some web-only media/embed features, or HTML document APIs) do not map the same way. The compiler can report errors/warnings for features not supported in native UI targets.</p>
<p>For native interactivity, use patterns and APIs supported by Salam's UI runtime and keep application logic in Salam code as appropriate for the target.</p>

<h2 id="paths">Desktop paths in Salam</h2>
<ul>
<li><strong>Native DSL (<code>--ui=native</code>):</strong> UI rendered by Salam's engine; useful when you want a browserless native UI.</li>
<li><strong>WebView (<a href="/std/gui-webview/">gui.webview</a>):</strong> a native window hosting HTML/CSS/JS content (Tauri/Electron-like model); useful when you want web tech inside a desktop shell.</li>
<li><strong>Other graphics libraries:</strong> such as <a href="/std/gui-raylib/">gui.raylib</a> for games/rendering-specific use cases.</li>
</ul>

<div class="note"><p>For browser output and web deployment, see <a href="/learn/layout-web/">Layout on the web</a>. For WebView APIs and packaging, see <a href="/std/gui-webview/">gui.webview</a> docs.</p></div>
