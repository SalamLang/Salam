lesson.body <<
<h2 id="hello">A hello window</h2>
<p>Any page is a native program. Save this as <code>hello.salam</code>:</p>
{{example.native-hello}}
<pre class="code" dir="ltr"><code>salam run hello.salam --ui=native
salam build hello.salam --ui=native</code></pre>
<p><code>run</code> opens the window. <code>build</code> makes an executable that you can give to someone else; it needs no browser. The layout, the colours, the hover state and the text are the ones the web build would draw, because they come from the same <a href="/learn/style-reference/">style vocabulary</a>.</p>
<h2 id="same">What is the same</h2>
<ul>
<li>The tree of elements, <code>component</code>, <code>if</code> and <code>each</code>.</li>
<li>Every style property: <code>layout</code>, <code>gap</code>, <code>align</code>, sizes, colours, <code>radius</code>, <code>shadow</code>, text properties and states such as <code>hover</code>.</li>
<li>State declared with <code>name := value</code> and event handlers such as <code>click</code>. The window redraws only what a change touched.</li>
<li>Persian and English source, and right to left text.</li>
</ul>
<h2 id="web-only">What is web only</h2>
<p>Things that only make sense in a browser are ignored or refused in a native window. <code>salam check page.salam --ui=native</code> lists them. Web metadata gives a warning and is skipped: SEO tags, <code>meta</code>, <code>head link</code>, <code>base</code>, <code>noscript</code>, <code>srcset</code>, <code>loading</code>, <code>rel</code>, <code>target</code>, <code>data</code> attributes, and form <code>action</code> and <code>method</code>. Elements that need a browser engine are errors: <code>script</code>, <code>iframe</code>, <code>embed</code>, <code>object</code>, <code>template</code>, <code>svg</code>, <code>math</code>, <code>contenteditable</code> and <code>popover</code>.</p>
<h2 id="both">One page for both</h2>
<p>Wrap the web only part in <code>if SALAM_UI_WEB:</code>. The compiler folds it away in a native build. <code>SALAM_UI_NATIVE</code> is the opposite.</p>
{{example.native-both}}
<h2 id="webview">Other desktop paths</h2>
<p>If you want a browser engine inside a window, <a href="/std/gui/webview/">gui.webview</a> hosts HTML, CSS and JS. That is a different path from the native page language, which has no browser inside.</p>
<div class="note"><p>For browser output, see <a href="/learn/layout/web/">Layout on the web</a>. The next lessons cover each element and the style vocabulary.</p></div>
>>
