<h2 id="relative">Relative sizes</h2>
<p>Percent, <code>fill</code>, <code>vw</code> and <code>vh</code> follow the room. <code>max width</code> keeps a column readable on a wide screen, and <code>margin = 0, "auto"</code> centres it.</p>
<h2 id="count">Let the row wrap</h2>
<p>A row with <code>wrap = true</code> whose children have <code>grow = 1</code> and <code>min width = 140</code> puts as many cards on a line as fit, and shares the rest of the line between them. Resize the window and the cards rearrange themselves.</p>
{{example.dsl-responsive}}
<h2 id="wrap">Placing the lines</h2>
<p><code>align content</code> places the lines of a wrapped row.</p>
<h2 id="shapes">Keeping a shape</h2>
<p><code>aspect ratio = 1.5</code> keeps the proportions of a box while the width changes, and <code>image fit = "cover"</code> fills an image box without stretching.</p>
<h2 id="env">Reading the window with <code>page</code></h2>
<p>Inside a page or a component, <code>page</code> is the window the page is shown in. <code>page.width</code> and <code>page.height</code> are its size in pixels. <code>page.compact</code>, <code>page.regular</code> and <code>page.wide</code> are true below 600, from 600 to 1024 and above 1024 pixels. <code>page.landscape</code>, <code>page.portrait</code>, <code>page.dark</code>, <code>page.light</code>, <code>page.touch</code>, <code>page.mouse</code>, <code>page.reduced motion</code>, <code>page.high contrast</code>, <code>page.rtl</code> and <code>page.ltr</code> describe the device and the person's settings. They join with <code>and</code>, <code>or</code> and <code>not</code>, and with your own variables.</p>
<pre class="code snip" dir="ltr"><code>page:
    background = &quot;white&quot;
    if page.width &gt;= 400 and page.height &lt; 900:
        background = &quot;honeydew&quot;
    end
    nav:
        layout = "row"
        gap = 16
        if page.compact:
            layout = &quot;column&quot;
            gap = 4
        end
        if page.dark:
            color = &quot;white&quot;
        end
        link: url = &quot;/&quot; content = &quot;Home&quot; end
        link: url = &quot;/about&quot; content = &quot;About&quot; end
    end
    if page.width &lt; 500:
        paragraph: content = &quot;Turn the phone for more room.&quot; end
    end
end</code></pre>
<p>An <code>if</code> can change style attributes, as on <code>nav</code>, or show and hide elements, as with the last paragraph. The page reads the window when it opens and again when the window is resized or a system setting changes, so the page follows. On the web a style <code>if</code> on the page, an element or a component that uses only <code>page</code> sizes and settings becomes a CSS <code>@media</code> rule, which applies before any script runs. In a native window the layout is computed again at the new size, so text keeps its size instead of being scaled with the window.</p>
<p>Because <code>page</code> names the window, it cannot be a variable, parameter or loop name inside a page or a component (E253), and an unknown property such as <code>page.size</code> is reported as E254. The short words <code>compact</code>, <code>wide</code>, <code>dark</code>, <code>screen width</code> and the others still work in a style <code>if</code>.</p>
