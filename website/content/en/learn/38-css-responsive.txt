<h2 id="relative">Relative sizes</h2>
<p>Percent, <code>fill</code>, <code>vw</code> and <code>vh</code> follow the room. <code>max width</code> keeps a column readable on a wide screen, and <code>margin = 0, auto</code> centres it.</p>
<h2 id="count">Let the row wrap</h2>
<p>A row with <code>wrap = true</code> whose children have <code>grow = 1</code> and <code>min width = 140</code> puts as many cards on a line as fit, and shares the rest of the line between them. Resize the window and the cards rearrange themselves.</p>
{{example.dsl-responsive}}
<h2 id="wrap">Placing the lines</h2>
<p><code>align content</code> places the lines of a wrapped row.</p>
<h2 id="shapes">Keeping a shape</h2>
<p><code>aspect ratio = 1.5</code> keeps the proportions of a box while the width changes, and <code>image fit = cover</code> fills an image box without stretching.</p>
<h2 id="env">Asking about the environment</h2>
<p>Sometimes the room is not the only thing that changes: the person may use a phone, a dark colour scheme or ask for less motion. Inside an <code>if</code> that holds style attributes you can name these directly: <code>compact</code>, <code>regular</code> and <code>wide</code> (below 600, 600 to 1024, above 1024 pixels), <code>screen width &lt; 500</code>, <code>screen height</code>, <code>landscape</code>, <code>portrait</code>, <code>dark</code>, <code>light</code>, <code>touch</code>, <code>mouse</code>, <code>reduced motion</code>, <code>high contrast</code>, <code>rtl</code> and <code>ltr</code>. They join with <code>and</code>, <code>or</code> and <code>not</code>, and with your own variables.</p>
<pre class="code snip" dir="ltr"><code>nav:
    padding = 16
    if compact:
        padding = 4
    else if wide:
        padding = 32
    end
    if touch and screen width &lt; 500:
        gap = 12
    end
    if dark:
        color = &quot;white&quot;
    end
end</code></pre>
<p>The page reads the window when it opens and again when the window is resized or the person changes a system setting, so the styles follow. In a native app these words are not available yet and the compiler reports E233; use a variable you set yourself.</p>
