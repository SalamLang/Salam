<h2 id="states">State prefixes</h2>
<p><code>hover background = #1d4ed8</code> applies only while the pointer is over the element. The states are <code>hover</code>, <code>focus</code>, <code>focus within</code>, <code>active</code>, <code>disabled</code>, <code>checked</code>, <code>invalid</code>, <code>placeholder</code> and <code>selection</code>. Any style property can carry one.</p>
{{example.dsl-hover}}
<h2 id="state-blocks">State blocks</h2>
<p>When one state changes several properties, write the state name with a colon and put the properties inside. <code>hover:</code> followed by <code>background = navy</code> and <code>padding = 12</code> means exactly <code>hover background = navy</code> and <code>hover padding = 12</code>. Every state works as a block name, also <code>focus within:</code>. A state block holds style properties only, no child elements, and state blocks do not nest.</p>
{{example.dsl-state-blocks}}
<h2 id="transition">Smooth changes</h2>
<p><code>transition = 300ms, ease out</code> makes every animatable property take 300 milliseconds to change. <code>transition properties = background, scale</code> limits it to some. Easing is <code>linear</code>, <code>ease</code>, <code>ease in</code>, <code>ease out</code> or <code>ease in out</code>. The reference marks which properties animate.</p>
{{example.dsl-transition}}
<h2 id="blocks">State blocks</h2>
<p>When several properties change in the same state, write the state once as a block: <code>hover:</code>, <code>focus:</code>, <code>active:</code>, <code>focus within:</code> and the other states of the list above open a block that holds style properties only and closes with <code>end</code>. A block is the same as putting the state in front of each property.</p>
{{example.dsl-hover-block}}
<h2 id="if-style">Style that depends on state</h2>
<p>An <code>if</code> inside an element, holding only style properties, applies them while its condition is true. The page reads the state, so the style follows it. <code>else if</code> and <code>else</code> work too, and a state block may sit inside. A number property needs a base value before the <code>if</code> (for example <code>opacity = 1</code>).</p>
{{example.dsl-if-style}}
