<h2 id="state">State</h2>
<p><code>count := 0</code> in a page or a component declares state. Handlers such as <code>click = (): count++ end</code> change it. The compiler sees which elements read <code>count</code> and redraws only those, on the web and in a native window alike.</p>
{{example.dsl-state}}
<h2 id="lists">If and each</h2>
<p><code>if</code> shows a part only when its condition holds, and <code>each</code> repeats a part for every item of a list. Add an item and the list follows. Give each row a <code>key</code> so that it keeps its identity when the list changes.</p>
{{example.dsl-each}}
<h2 id="events">Events</h2>
<p>An event is an attribute whose value is a function: <code>click</code>, <code>input</code>, <code>change</code>, <code>focus</code>, <code>blur</code> and more. Give a handler the name of a function or write it inline with <code>():</code> and <code>end</code>.</p>
<h2 id="input">Text input</h2>
<p>A text field passes what the user typed to its <code>input</code> handler. Give the handler one parameter and write it into state: <code>input = (v: str): name = v end</code>. The paragraph below reads <code>name</code>, so it follows every key.</p>
{{example.dsl-input}}
<h2 id="pointer">Pointer, selection and scrolling</h2>
<p><code>cursor</code> picks the pointer (<code>pointer</code>, <code>text</code>, <code>move</code>, <code>not allowed</code>), <code>interactive = false</code> makes an element ignore the pointer, <code>selectable</code> controls text selection, and <code>scrollbar</code> is <code>auto</code>, <code>thin</code> or <code>none</code>. <code>accent</code> colours checkboxes, radios and sliders.</p>
<h2 id="targets">Two targets</h2>
<p>Build for the web with <code>salam page build</code> and run as a desktop program with <code>--ui=native</code>. The code above does not change. See <a href="/learn/layout/native/">native apps</a>.</p>
