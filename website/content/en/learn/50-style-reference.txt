<h2 id="states">States</h2>
<p>Any style property can carry one state prefix and then applies only in that state, for example <code>hover background = #ffeecc</code>. The states are <code>hover</code>, <code>focus</code>, <code>focus within</code>, <code>active</code>, <code>disabled</code>, <code>checked</code>, <code>invalid</code>, <code>placeholder</code> and <code>selection</code>.</p>
<h2 id="values">Value forms</h2>
<ul>
<li>A bare number uses the natural unit of the property: pixels for lengths, milliseconds for times, degrees for angles.</li>
<li>Percent: <code>50%</code>. Units: <code>px</code> <code>em</code> <code>rem</code> <code>fr</code> <code>vw</code> <code>vh</code> <code>ms</code> <code>s</code> <code>deg</code> <code>turn</code>.</li>
<li>A comma list continues one property: <code>padding = 8, 16</code>. Brackets group one item of a repeated property: <code>shadow = [0, 4, 8, black], [0, 1, 2, red]</code>.</li>
<li>Colours: <code>red</code>, <code>#3366aa</code>, <code>rgb(51, 102, 170)</code>, <code>hsl(210, 50%, 40%)</code>, <code>mix(red, blue, 30%)</code>, <code>light dark(white, black)</code>.</li>
</ul>
