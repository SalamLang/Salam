pkg.en = io
pkg.name = io
pkg.group = Basics
pkg.summary = Reading from the keyboard, reading and writing files, and writing to standard error.
pkg.title = The io package in Salam | Reading and writing files
pkg.description = The io package in Salam: reading user input, reading and writing whole files, reading line by line, copying, and writing to standard error, with examples.
pkg.intro <<
<p>Most programs have to read something and write something. The <code>io</code> package holds the simplest ways to do it: read one line from the user, read or write a whole file in one go, or work through an open file piece by piece.</p>
<p>The functions that take a file name, such as <code>ReadFile</code>, open and close the file themselves. The functions that take a <code>File*</code> work on a file you opened yourself with <code>os.Open</code>; remember to close it with <code>Close</code>.</p>
<div class="note"><p>Sizes in this package are counted in <strong>bytes</strong>, not characters. Outside ASCII one character takes several bytes, so reading a file in chunks can split a character across two chunks.</p></div>
>>

doc.Input = Reads one line from standard input, usually the keyboard, and returns it without the line ending. It is the same thing <code>input ""</code> does. The example below waits for you to type, so here it is only compiled and not run.
doc.Read = Reads up to <code>size</code> bytes from the current position in the file. At the end of the file it returns an empty string.
doc.Readline = Reads one line from the file, without the line ending. At the end of the file it returns an empty string.
doc.Write = Writes a string to an open file and returns the number of bytes written.
doc.Seek = Moves the reading and writing position in a file. <code>offset</code> is a distance in bytes and <code>whence</code> says where to count from: zero is the start of the file, one is the current position and two is the end. It returns zero on success.
doc.Close = Closes the file. Every file you open has to be closed once, and <code>defer</code> is a good place for it.
doc.ReadFile = Reads the whole content of a file in one go. If the file does not exist, or cannot be read, it returns an empty string.
doc.WriteFile = Creates the file, or empties it if it already exists, and writes the string into it. It returns the number of bytes written, or minus one if the file could not be opened.
doc.AppendFile = Adds the string to the end of the file, leaving what was already there alone. If the file does not exist it is created. Like <code>WriteFile</code> it returns a byte count or minus one.
doc.Lines = Reads a file and returns its lines in a vector. Trailing whitespace and the empty final line are dropped. Release the vector with <code>free</code> when you are done with it.
doc.EPrint = Writes a string to standard error, without a line break. Errors and warnings belong here rather than in the program's real output.
doc.EPrintln = Like <code>EPrint</code>, but moves to the next line after the message.
doc.Flush = Writes out whatever is still sitting in the output buffer. Useful when you have written something with <code>print</code> that has no line ending and want the user to see it at once.
doc.ReadAll = Reads everything left from the current position to the end of the file.
doc.Copy = Writes everything left in the file <code>src</code> into the file <code>dst</code> and returns the number of bytes copied. It suits large files, since it never holds the whole file in memory.
doc.WriteLines = Writes each element of a vector as one line of the file. An existing file is rewritten. It returns a byte count, or minus one.

ex.Readline = io-Read
ex.Seek = io-Read
ex.Close = io-Read
ex.ReadAll = io-Read
ex.WriteFile = io-ReadFile
ex.AppendFile = io-ReadFile
ex.WriteLines = io-Lines
ex.EPrintln = io-EPrint
ex.Flush = io-EPrint
ex.Copy = io-Write
