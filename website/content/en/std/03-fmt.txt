pkg.intro <<
<p>When you want tidy, readable output, the <code>fmt</code> package is what you reach for. With it you turn numbers into text, line text up in fixed-width columns, and build sentences from a template.</p>
<p>The templates are simple: every <code>{}</code> in the template is filled with the next element of the vector of values. Since the values are strings, convert numbers first with a function such as <code>Int</code>.</p>
>>

doc.Int = Turns a whole number into text, with a minus sign where one is needed.
doc.Float = Turns a decimal number into text and leaves off the useless trailing digits.
doc.Bool = Turns a boolean into <code>"true"</code> or <code>"false"</code>.
doc.PadLeft = If the text is shorter than <code>width</code>, adds spaces on its left until it reaches that width. The width counts characters, so it behaves correctly outside ASCII too. In a column of numbers this is what lines them up on the right.
doc.PadRight = Like <code>PadLeft</code>, but puts the spaces on the right of the text.
doc.Center = Places the text in the middle of the given width. When the padding does not divide evenly, the extra space goes on the right.
doc.Sprintf = Takes the template and fills each <code>{}</code> in turn from the <code>args</code> vector. If the values run out the remaining holes are left empty, and extra values are ignored.
doc.Fprintf = Like <code>Sprintf</code>, but writes the result straight into an open file and returns the number of bytes written.
doc.FloatPrec = Turns a decimal number into text with the number of decimal places you ask for, rounding it.
doc.Uint = Turns an unsigned 64-bit number into text, for numbers too large to fit in an <code>i64</code>.
doc.Hex = Writes the number in base sixteen in lower case, with no <code>0x</code> prefix.

ex.Float = fmt-Int
ex.Bool = fmt-Int
ex.FloatPrec = fmt-Int
ex.Uint = fmt-Int
ex.Hex = fmt-Int
ex.PadRight = fmt-PadLeft
