pkg.intro <<
<p>Salam strings are UTF-8, but some systems, Windows and a few C libraries above all, want text in UTF-16. In UTF-16 an ordinary character is one 16-bit "unit" and a rarer one, such as an emoji, takes two.</p>
<p>The <code>text</code> package converts in both directions. The memory <code>ToUtf16</code> returns belongs to you, and ends with a zero unit.</p>
<h2 id="guide-limit">Checking a length limit the way JavaScript counts</h2>
<p>A browser, a JSON API written in JavaScript, Java or C#, and many databases measure a string in UTF-16 units. If your Salam server checks a limit in bytes or in characters, it can disagree with the form that sent the text: a limit of 12 that the browser enforced may look like 22 bytes to you, or a message the browser rejected may look short enough to Salam. <code>Utf16Len</code> counts the same way they do.</p>
{{example.text-guide-limit}}
<p>The three numbers per line are the byte length (<code>len</code>), the character count (<code>char_count</code>) and the UTF-16 length. For plain English they are equal. An accented letter adds a byte but not a unit. Each emoji is one character but two units, so the last message is only 10 characters long yet goes over a limit of 12.</p>

<h2 id="guide-pairs">Walking UTF-16 units and surrogate pairs</h2>
<p><code>ToUtf16</code> builds a zero terminated array of 16-bit units, the shape that Windows functions with a <code>W</code> in their name and many C libraries want. Characters above U+FFFF, such as most emoji, take two units: a high surrogate between 55296 and 56319 followed by a low surrogate between 56320 and 57343. The example reads the units back one by one and joins each pair into its code point.</p>
{{example.text-guide-pairs}}
<p>The array is allocated on the heap and belongs to you: release it with <code>mem.Free</code>, here through <code>defer</code>. <code>FromUtf16</code> goes the other way and turns the units, pairs included, back into an ordinary Salam string, which is how you read text that a UTF-16 API handed back.</p>

doc.Utf16Len = Returns the number of UTF-16 units in the string. For most scripts this equals the number of characters, but each emoji counts as two.
doc.ToUtf16 = Converts a string into a zero-terminated UTF-16 array and returns its address.
doc.Utf16UnitAt = Reads unit number <code>i</code> from a UTF-16 array. For an emoji you see two consecutive units, a surrogate pair.
doc.FromUtf16 = Converts a zero-terminated UTF-16 array back into a Salam string.

ex.ToUtf16 = text-Utf16Len
