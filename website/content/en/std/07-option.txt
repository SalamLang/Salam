pkg.summary = A value that may or may not be there, without nulls and without magic numbers such as minus one.
pkg.title = The option package in Salam | An optional value without null
pkg.description = The option package in Salam: the Option struct and the Some, None, IsSome, IsNone, Unwrap and UnwrapOr functions, with an example.
pkg.intro <<
<p>Sometimes the answer from a function is "nothing": a search found no match, or a setting was never given. Returning minus one or an empty string for that is convenient, and later forgotten, and then it is a bug. <code>Option&lt;T&gt;</code> makes it explicit: either there is a value of type <code>T</code>, or there is not.</p>
<p>If the reason for the failure matters as well as its absence, <a href="/std/result/">result</a> is the better fit.</p>
>>

doc.Option = A struct that keeps a value and a "present or not" flag side by side. Build one with <code>Some</code> or <code>None</code>, so that the two fields always agree.
doc.Option.value = The value itself. When <code>present</code> is false this is the zero value of <code>T</code> and means nothing.
doc.Option.present = True when there is a value.
doc.Some = Builds an option that holds a value.
doc.None = Builds an empty option. The type <code>T</code> comes from where the value is used, such as the return type of the function.
doc.IsSome = Returns true when the option holds a value.
doc.IsNone = Returns true when the option is empty.
doc.UnwrapOr = Returns the value, or the default you supplied when the option is empty.
doc.Unwrap = Returns the value. If the option is empty, the program stops.
doc.Expect = Like <code>Unwrap</code>, but stops with a message of your own when the option is empty; a good message makes the problem easy to find.
