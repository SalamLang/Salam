pkg.intro <<
<p>The <code>str</code> package is the one you will reach for most. Anywhere you touch text, from reading user input to building output, its functions apply.</p>
<p>One thing to know before you start: Salam strings are UTF-8. In UTF-8 an English letter is one byte, while a letter in most other scripts takes two or more. That is why most of these functions come in two forms: <code>Len</code>, <code>Substr</code> and <code>IndexOf</code> work in <strong>bytes</strong> and are fast, while <code>CharCount</code>, <code>CharSubstr</code> and <code>CharFind</code> work in <strong>characters</strong>. Wherever the count or the cut has to match what the reader sees, use the character form.</p>
<p>One step further out is the "grapheme": what a reader sees as a single letter. A letter with an accent is two characters but one grapheme, and a family emoji is seven characters but one grapheme. For reversing or cutting text that carries marks or emoji, the grapheme functions are the safe ones.</p>
<p>Three methods also sit on every string and need no import: <code>text.starts_with("salam")</code>, <code>text.ends_with(".txt")</code> and <code>text.includes("world")</code>. All three return true or false and behave the same on every backend.</p>
<p>Neighbouring packages: <a href="/std/unicode/">unicode</a> classifies and converts single code points, <a href="/std/fmt/">fmt</a> pads and fills templates, <a href="/std/conv/">conv</a> parses numbers, <a href="/std/regex/">regex</a> matches patterns, and <a href="/std/arabic/">arabic</a> normalises Persian and Arabic letters.</p>
<div class="note"><p>Things that catch people out:</p>
<ul>
<li><code>Upper</code> and <code>Lower</code> change only the ASCII letters A to Z: <code>Upper("café")</code> is <code>CAFé</code>. For other scripts map each code point with <code>unicode.ToUpper</code> or <code>unicode.ToLower</code>; to compare without case use <code>EqualFold</code>, which does follow the full Unicode rules.</li>
<li><code>Trim</code> and its relatives remove only the ASCII space, tab, carriage return and newline. A no-break space (U+00A0), common in text pasted from the web, stays.</li>
<li>A <code>str</code> ends at its first zero byte, so binary data passed through these functions is cut short there.</li>
<li>Every function that returns a string returns a new one; the argument is never changed.</li>
</ul></div>
<h2 id="guide-slug">Making a URL slug from a title</h2>
<p>A slug is the readable part of a URL, such as <code>/blog/hello-world</code>. To build one, lower the case, keep letters and digits, and turn every run of anything else into a single dash. Working on code points with <code>CodePoints</code> and <code>IsAlnum</code> keeps letters of every script, so a Persian title gives a Persian slug instead of an empty one.</p>
{{example.str-guide-slug}}
<p>The <code>StringBuilder</code> collects the result without making a new string for every character; <code>BufAppendCp</code> adds one code point as UTF-8 and <code>BufStr</code> returns the finished text. One thing to watch in Persian text: the zero width non-joiner (U+200C) inside a word such as <code>می‌شود</code> is not a letter, so this function would split the word there. If you want to keep it, treat 8204 like a letter in the test.</p>

<h2 id="guide-words">Counting words</h2>
<p><code>Fields</code> splits on any run of whitespace and drops empty pieces, which is what you want for words; <code>Split</code> with <code>" "</code> would give an empty word for every double space. Lower the case first and turn punctuation into spaces, then count with a <code>HashMap</code>. A separate vector remembers the order in which words first appeared, since a map has no order of its own.</p>
{{example.str-guide-words}}
<p>Each <code>Replace</code> returns a new string. For a long list of characters to remove, one pass over <code>CodePoints</code> with <code>IsPunct</code> is cleaner than a chain of replacements. For Persian text, run it through <a href="/std/arabic/">arabic</a>.<code>SearchKey</code> first so different spellings of the same word count together.</p>

<h2 id="guide-csv">Building CSV with a StringBuilder</h2>
<p>Every field that holds a comma, a quote or a line break has to be wrapped in quotes, with each quote inside it doubled. <code>Contains</code> decides whether a field needs that and <code>Replace</code> doubles the quotes. A <code>StringBuilder</code> collects the rows, which is much faster than <code>+</code> once the text grows to thousands of lines.</p>
{{example.str-guide-csv}}
<p>The builder is passed with <code>&amp;:</code> so that <code>add_row</code> appends to the caller's builder instead of a copy. Free it once with <code>BufFree</code> when you are done. For reading CSV back, or for files with unusual quoting, use <a href="/std/encoding/csv/">encoding/csv</a>.</p>

<h2 id="guide-commands">Parsing chat commands</h2>
<p>A bot or a console reads lines such as <code>/say good morning</code>. <code>Trim</code> removes the stray spaces around the line, <code>StartsWith</code> tells a command from a plain message, and <code>IndexOf</code> finds the first space that separates the command from its argument. <code>EqualFold</code> compares without caring about upper or lower case, so <code>/HELP</code> and <code>/help</code> do the same thing.</p>
{{example.str-guide-commands}}
<p><code>IndexOf</code> and <code>Substr</code> count in bytes. That is safe here because the space being searched for is a single byte, so the cut always lands on a character boundary even when the argument is Persian. When the position comes from counting characters instead, use <code>CharFind</code> and <code>CharSubstr</code>.</p>

doc.TrimLeft = Removes the spaces, tabs and newlines at the start of the string.
doc.TrimRight = Removes the spaces, tabs and newlines at the end of the string.
doc.TrimPrefix = If the string starts with <code>prefix</code>, removes it; otherwise returns the string untouched.
doc.TrimSuffix = If the string ends with <code>suffix</code>, removes it; handy for stripping a file extension.
doc.Trim = Removes spaces, tabs, carriage returns and newlines at both ends. Use it on user input before anything else. Other Unicode spaces, such as the no-break space, are kept.
doc.DigitValue = Returns the numeric value of a digit, whether it is written in English, Persian or Arabic digits. For a character that is not a digit it returns minus one.
doc.IsArabicDigit = True when the character is one of the Arabic digits <code>٠</code> to <code>٩</code>. Persian digits have a different shape and do not count here.
doc.IsPersianDigit = True when the character is one of the Persian digits <code>۰</code> to <code>۹</code>.
doc.IsAnyDigit = True when the character is an English, Persian or Arabic digit. Use this to accept a number from a user with any keyboard.
doc.ToEnglishDigits = Converts every Persian and Arabic digit in the string to an English one and leaves the rest of the text alone. Useful before storing a phone number or an identifier in a database.
doc.ToArabicDigits = Converts every digit in the string to an Arabic one.
doc.ToPersianDigits = Converts every digit in the string to a Persian one, for showing a number to a Persian-speaking reader.
doc.HasEnglishDigits = True when the string contains at least one English digit.
doc.HasArabicDigits = True when the string contains at least one Arabic digit.
doc.HasPersianDigits = True when the string contains at least one Persian digit.
doc.NewBuilder = Creates an empty string builder. When you are building a long piece of text in parts, this is far faster than joining with <code>+</code> over and over. Release it with <code>BufFree</code> when you are done.
doc.BufAppend = Adds a string to the end of the builder.
doc.BufAppendChar = Adds one byte by its numeric code, for ASCII characters such as a comma (44).
doc.BufAppendCp = Adds one Unicode character by its code point, for anything outside ASCII.
doc.BufAppendInt = Adds a whole number in its text form.
doc.BufLen = Returns the size of the text built so far, in bytes.
doc.BufIsEmpty = True when nothing has been added to the builder yet.
doc.BufStr = Returns the text built so far as a fresh string. The builder stays usable afterwards.
doc.BufReset = Empties the builder but keeps its memory, so it can be reused for the next piece of text.
doc.BufFree = Releases the builder's memory. The best place for it is a <code>defer</code> right after creating the builder.
doc.NFD = Converts the string to Unicode "canonical decomposition": every composed character is split into its base and its marks.
doc.NFC = Converts the string to "canonical composition": bases and marks are recombined into single characters wherever possible. Two strings that look identical but are stored with different codes become equal after this, so apply it before comparing or storing.
doc.NFKD = Like canonical decomposition, but it also expands the "compatibility" forms; Arabic presentation forms such as <code>ﻻ</code>, for instance, become ordinary letters.
doc.NFKC = Compatibility decomposition followed by canonical composition. It suits text gathered from mixed sources, such as PDFs.
doc.IsNFC = True when the string is already in canonical composition. The check is cheaper than the conversion.
doc.StringBuilder = A string builder: the memory in which you build a string piece by piece. Always create one with <code>NewBuilder</code> and use it through the Buf functions; do not change its fields directly.
doc.StringBuilder.data = The address of the memory the text is written into.
doc.StringBuilder.len = How many bytes have been written so far.
doc.StringBuilder.cap = The size of the memory taken, in bytes. It grows by itself when it fills up.
doc.CodePointAt = Reads the character starting at byte <code>i</code>, puts its code point in <code>cp</code> and returns how many bytes it took. For walking a string by hand, character by character.
doc.CharLen = From the first byte of a character, says how many bytes that character takes, from 1 to 4.
doc.CharAt = Returns the character starting at byte <code>i</code>. That is a byte position, not a character position; for a character position see <code>CharAtIndex</code>.
doc.Reverse = Reverses the order of the characters in the string. If the text carries marks or emoji, <code>ReverseGraphemes</code> is the correct one.
doc.CharCount = Returns the number of characters in the string rather than bytes. For <code>"سلام"</code> it is four, while <code>Len</code> says eight.
doc.CharSubstr = Cuts <code>n</code> characters starting at character <code>start</code>. It is the safe version of <code>Substr</code> for text outside ASCII.
doc.CharAtIndex = Returns character number <code>i</code>, counting from zero.
doc.CharFind = Returns the position of the first occurrence of <code>sub</code> in characters, or minus one when it is not there.
doc.CodePoints = Returns the code points of every character in the string, in a vector.
doc.FromCodePoints = The reverse of <code>CodePoints</code>: builds a string from a vector of code points.
doc.AllAscii = True when every character in the string is ASCII. Useful for choosing a faster path when processing text.
doc.Chars = Returns each character of the string as a separate string in a vector.
doc.Repeat = Repeats the string <code>n</code> times, one after another; good for drawing a separator line.
doc.Fields = Splits the string into words on any run of spaces, tabs or newlines, dropping the empty pieces.
doc.Contains = True when <code>sub</code> occurs anywhere in the string.
doc.StartsWith = True when the string starts with <code>prefix</code>.
doc.EndsWith = True when the string ends with <code>suffix</code>.
doc.Search = Returns the position of the first occurrence of <code>sub</code> in bytes, or minus one. It is the same as <code>IndexOf</code>.
doc.IndexOf = Returns the position of the first occurrence of <code>sub</code> in bytes, or minus one when it is not found.
doc.IndexFrom = Like <code>IndexOf</code>, but starts the search at byte <code>from</code>, for finding the next occurrence.
doc.Count = Returns the number of non-overlapping occurrences of <code>sub</code> in the string.
doc.LastIndex = Returns the position of the last occurrence of <code>sub</code> in bytes, or minus one.
doc.IsAscii = True when the code is in the ASCII range, zero to 127.
doc.IsAsciiSpace = Only ASCII whitespace: space, tab, newline and the like.
doc.IsAsciiDigit = Only the English digits <code>0</code> to <code>9</code>.
doc.IsAsciiUpper = Only the capital English letters <code>A</code> to <code>Z</code>.
doc.IsAsciiLower = Only the small English letters <code>a</code> to <code>z</code>.
doc.IsAsciiAlpha = Only English letters, capital or small.
doc.IsAsciiAlnum = An English letter or digit.
doc.IsSpace = Any Unicode whitespace, including the ASCII spaces and the ideographic space.
doc.IsDigit = Any Unicode decimal digit, Persian and Arabic included.
doc.IsUpper = A capital letter in any script that has them, such as Latin, Greek and Cyrillic.
doc.IsLower = A small letter in any script that has them.
doc.IsAlpha = Any letter in any script.
doc.IsAlnum = Any letter or digit in any script.
doc.IsPunct = Any punctuation mark, such as a full stop, a comma or a question mark.
doc.IsMark = A combining mark, such as an accent or an Arabic vowel sign.
doc.IsControl = A control character such as a newline or a tab: invisible, and doing something rather than showing something.
doc.Len = Returns the length of the string in bytes. For the number of characters see <code>CharCount</code>.
doc.ByteLen = Returns the length of the string in bytes and gives the same answer on every backend. On the JavaScript backend <code>Len</code> counts UTF-16 units, so use this one for byte-level work.
doc.ByteSub = Cuts <code>n</code> bytes starting at byte <code>start</code>. The C and LLVM backends return the bytes untouched, but the JavaScript backend decodes them as UTF-8, so a cut that falls inside a multi-byte character produces a replacement character and a different byte length. For cutting by character use <code>CharSubstr</code>.
doc.Concat = Joins two strings one after the other; the same thing <code>+</code> does.
doc.Compare = Compares two strings byte by byte: minus one when the first comes earlier, zero when they are equal and one when it comes later. It is what you want for sorting strings.
doc.Equals = True when the two strings are exactly the same; the same thing <code>==</code> does.
doc.Substr = Cuts <code>n</code> bytes starting at byte <code>start</code>. Outside ASCII, take care not to cut through the middle of a character, or use <code>CharSubstr</code> instead.
doc.SubstrIn = Like <code>Substr</code>, but when the range runs past the end of the string it does not fail and returns only the part that is there.
doc.Find = Returns the position of the first occurrence of <code>sub</code> in bytes, or minus one.
doc.Split = Splits the string wherever <code>delim</code> occurs and returns the pieces in a vector. Free the vector when you are done with it.
doc.Join = Joins the pieces of a vector with <code>sep</code> between them; the reverse of <code>Split</code>.
doc.ToInt = Turns the string into a whole number, accepting Persian and Arabic digits too. When it finds no number it returns zero.
doc.ToFloat = Turns the string into a decimal number.
doc.IsEmpty = True when the string has no characters at all.
doc.Clone = Makes an independent copy of the string.
doc.Replace = Replaces every occurrence of <code>find</code> with <code>replacement</code>.
doc.FromInt = Turns a whole number into text.
doc.FromFloat = Turns a decimal number into text.
doc.Upper = Converts the ASCII letters a to z to upper case. Everything else, accented and non-Latin letters included, is left alone, so <code>"café"</code> becomes <code>"CAFé"</code>.
doc.Lower = Converts the ASCII letters A to Z to lower case and leaves every other character alone.
doc.Title = Capitalises the first letter of every word and lowers the rest, using the Unicode case tables, so <code>"élan VITAL"</code> becomes <code>"Élan Vital"</code>. Words are separated by whitespace only.
doc.EqualFold = Compares two strings ignoring letter case, following the full Unicode rules, so that "Straße" equals "STRASSE".
doc.CompareFold = Compares two strings ignoring letter case and returns a negative number, zero or a positive one; only the sign matters, not the size.
doc.GraphemeCount = Returns the number of grapheme clusters, that is, the number of "letters" a reader sees.
doc.Graphemes = Splits the string into grapheme clusters: a letter with its marks, or a composed emoji, is one piece.
doc.ReverseGraphemes = Reverses the string cluster by cluster, so that marks stay attached to their letter.
