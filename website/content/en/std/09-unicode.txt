pkg.name = unicode
pkg.group = Text
pkg.summary = What Unicode knows about a character: category, script, writing direction, case, decomposition and composition.
pkg.title = The unicode package in Salam | Character categories, scripts and properties
pkg.description = The unicode package in Salam: the category and script of a character, case mapping, decomposition and composition, the bidirectional class, and the zero width non-joiner, with examples.
pkg.intro <<
<p>Unicode gives every character of every script in the world a number, called a code point: "ش" is 1588 and "A" is 65. For any code point, the <code>unicode</code> package says what kind of character it is: letter or digit, which script it belongs to, whether it is written right to left or left to right, and what its upper and lower case forms are.</p>
<p>Most of the time the <a href="/std/str/">str</a> package is enough, and it uses this one underneath. This package is for when you are inspecting text character by character yourself, in a parser, an editor or a text cleaning tool. The data is generated from the official Unicode database, version 16.</p>
<p>To get the code points of a string, use <code>str.CodePoints</code>.</p>
>>

doc.ZWNJ = The code point of the zero width non-joiner (U+200C), which in Persian keeps two letters side by side without joining them, as in «می‌روم».
doc.ZWJ = The code point of the zero width joiner (U+200D), which joins two characters; composed emoji such as the family are built with it.
doc.MaxCodePoint = The largest code point Unicode allows, 0x10FFFF.
doc.Version = The version of Unicode the data in this package was generated from.
doc.MaxFoldLen = The largest number of code points a full case fold of one character can produce. A buffer of this size is enough to fold any character.
group.Hangul.title = Hangul syllable constants
group.Hangul = The numbers needed to compose and decompose Korean (Hangul) syllables arithmetically. Each syllable is built from a leading consonant, a vowel and sometimes a trailing consonant, and its code point can be computed directly.
group.Cat.title = General categories
group.Cat = Every Unicode character has a "general category". <code>Category</code> returns one of these numbers and <code>CategoryName</code> returns its two-letter short name, such as <code>Lo</code>. Categories whose first letter is the same are numbered consecutively.
group.Gcb.title = Grapheme break classes
group.Gcb = The classes <code>GraphemeBreak</code> returns. The str package uses them to find where one "visible letter" ends and the next begins; a letter with its marks, or a composed emoji, is one cluster.
group.Incb.title = Conjunct break classes
group.Incb = The classes <code>ConjunctBreak</code> returns. This rule keeps consonants joined by a virama in Indic scripts inside a single cluster.
group.Bc.title = Bidirectional classes
group.Bc = The class <code>BidiClass</code> returns, which the bidirectional algorithm uses to decide where each character of mixed text appears. Arabic script letters are "Arabic", Latin letters are "left to right", and digits have classes of their own.
group.Pbt.title = Paired bracket types
group.Pbt = The result of <code>PairedBracketType</code>: whether the character is an opening bracket, a closing one, or not a bracket at all.
group.Script.title = Script identifiers
group.Script = Every script Unicode knows has an identifier, and <code>Script</code> returns one of them. Persian and Arabic letters are both "Arabic script". "Common" characters such as digits and punctuation are used by several scripts, and "inherited" means the character takes the script of the character before it, as marks do.
doc.Category = Returns the number of the character's general category, one of the Cat constants above.
doc.CategoryName = Returns the two-letter category name, such as <code>Lo</code> for a Persian letter and <code>Nd</code> for a digit.
doc.IsAssigned = True when this code point has been assigned to a character in Unicode.
doc.IsLetter = True when the character is a letter, that is, in one of the L categories.
doc.IsAlphabetic = Like <code>IsLetter</code>, but wider: it also counts the marks that are part of reading a letter. Most of the time this is what "is it a letter?" means.
doc.IsUpper = True when the character is an upper case letter.
doc.IsLower = True when the character is a lower case letter.
doc.IsTitle = The few "title case" letters that are half upper and half lower case, such as "ǅ".
doc.IsMark = True when the character is a combining mark, such as an accent or an Arabic vowel sign.
doc.IsDigit = Decimal digits only, in any script; Persian digits count.
doc.IsNumber = Any numeric character, Roman numerals and fractions included; wider than <code>IsDigit</code>.
doc.IsAlnum = A letter or a digit.
doc.IsPunct = Punctuation, such as a comma in any script.
doc.IsSymbol = Symbols, such as currency signs and mathematical operators.
doc.IsSpace = Whitespace characters by Unicode's official White_Space property. The zero width non-joiner is not whitespace.
doc.IsControl = Control characters.
doc.IsFormat = Invisible formatting characters, such as the zero width non-joiner and the direction marks.
doc.IsJoinControl = Only the zero width non-joiner and the zero width joiner, the two characters that control whether letters join.
doc.ToUpper = Returns the upper case form of a character, or the character itself when it has none.
doc.ToLower = Returns the lower case form of a character.
doc.ToTitle = Returns the title case form of a character.
doc.ToFold = Returns the simple case folded form of a character, the form used for case insensitive comparison.
doc.HasFullFold = True when the full case fold of the character is more than one code point, as "ß" folds to "ss".
doc.FullFoldLen = The number of code points in the character's full case fold.
doc.FullFoldAt = Code point number <code>k</code> of the character's full case fold.
doc.CombiningClass = Returns the combining class of a mark. During normalisation, the marks following a letter are sorted by this number so that the order they were typed in does not matter. For ordinary characters it is zero.
doc.DecompLen = The number of code points in the character's canonical decomposition, or zero when it does not decompose.
doc.DecompAt = Code point number <code>k</code> of the character's canonical decomposition.
doc.CompatDecompLen = The number of code points in the character's compatibility decomposition. Arabic presentation forms expand to ordinary letters here.
doc.CompatDecompAt = Code point number <code>k</code> of the compatibility decomposition.
doc.Compose = Combines two code points into one when they have a canonical composition, and returns minus one otherwise.
doc.GraphemeBreak = Returns the character's grapheme break class.
doc.ConjunctBreak = Returns the character's conjunct break class, used by Indic scripts.
doc.BidiClass = Returns the character's bidirectional class.
doc.PairedBracketType = Says whether the character is an opening bracket, a closing one, or neither.
doc.PairedBracket = Returns the partner of a bracket; the partner of "(" is ")". For a character that is not a bracket it returns the character itself.
doc.Script = Returns the identifier of the character's script.
doc.ScriptName = Returns the English name of the character's script, such as <code>Arabic</code>.
