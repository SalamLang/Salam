pkg.intro <<
<p>Arabic-script text does not arrive in one shape. One source writes «كتاب» with an Arabic kaf and another with a Persian one; one adds vowel marks, another a tatweel (ـــ), and some text, from a PDF for instance, carries the presentation forms of the letters. To a reader they are the same word; to a computer they are different strings, and the search fails.</p>
<p>The <code>arabic</code> package removes those differences. <code>Normalize</code> works from flags you choose, combined with <code>+</code>. For most purposes <code>NormalizePersian</code> or <code>SearchKey</code> is all you need.</p>
>>

doc.FoldLetters = A flag: converts Arabic letters to their Persian counterparts, "ي" to "ی" and "ك" to "ک".
doc.StripHarakat = A flag: removes the vowel marks, fatha, kasra, damma, tanwin, shadda and the rest.
doc.StripTatweel = A flag: removes the tatweel (ـ).
doc.FoldDigits = A flag: converts Persian and Arabic digits to English ones.
doc.FoldAlef = A flag: converts the forms of alef (أ, إ, آ) to plain "ا".
doc.FoldTehMarbuta = A flag: converts "ة" to "ه".
doc.StripZWNJ = A flag: removes the zero width non-joiner, so that «می‌خواهم» and «میخواهم» become one string.
doc.FoldPresentation = A flag: converts the presentation forms of letters, such as «ﻻ» and «ﻣ», back to the ordinary letters.
doc.IsArabicScript = True when the character belongs to the Arabic script, which includes the Persian letters.
doc.IsHaraka = True when the character is one of the vowel marks.
doc.IsTatweel = True when the character is a tatweel (ـ).
doc.Normalize = Normalises the text with the flags you give. Any aspect whose flag you leave out is left untouched.
doc.NormalizePersian = The default normalisation for Persian text: it converts Arabic letters to Persian ones, removes tatweel and expands presentation forms, but keeps the vowel marks, the zero width non-joiner and the digits, so the text still reads as it was written.
doc.SearchKey = Builds a key for searching: it applies every flag, so that two spellings a reader sees as the same produce the same key. Do not display the key; it is only for comparing and indexing.
doc.EqualLoose = Compares two strings after building a search key for each, so that «مي‌خواهم» and «میخواهم» count as equal.
