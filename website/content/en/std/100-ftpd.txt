pkg.intro <<
<p>This package runs an FTP server in Salam. It can serve files from a root directory to FTP clients, with plain FTP or secure FTPS. For secure deployments, enable TLS and use explicit FTPS (<code>AUTH TLS</code>) or implicit FTPS so that credentials and data can be protected.</p>
<p>Supported features include passive mode transfers (PASV/EPSV), basic authentication (configured user/password or anonymous access), common file and directory commands, and TLS protection levels for the data channel (<code>PROT C</code>/<code>PROT P</code>) when TLS is configured.</p>

<h2 id="guide-basic">Run a basic FTP server</h2>
<p>Create a configuration, choose a host, port and root directory, then listen and serve incoming connections.</p>
{{example.ftpd-basic}}

<h2 id="guide-ftps">Run a secure FTPS server</h2>
<p>Provide a certificate and key to enable TLS. Clients can upgrade with <code>AUTH TLS</code> and protect data transfers with <code>PROT P</code>. You can also require TLS before login.</p>
{{example.ftpd-ftps}}
