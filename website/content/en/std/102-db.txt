pkg.intro <<
<p>Every database engine has its own package: <a href="../db-sqlite/">db/sqlite</a>, <a href="../db-mysql/">db/mysql</a>, <a href="../db-postgres/">db/postgres</a>, and for key and value <a href="../db-redis/">db/redis</a>. This package gives the <code>Connection</code> interface that the three SQL engines implement; write your code against it and changing engine is one line.</p>
<p>Migrations move the database schema along with the code: every change has a number and <code>MigrateUp</code> applies only the ones not applied yet. Never paste a value a user typed straight into SQL; send it through <code>QuoteLiteral</code> or as a prepared parameter.</p>
>>

doc.MIGRATION_TABLE = The default name of the table the applied versions are recorded in.
doc.Migration = One migration: one numbered change to the database schema.
doc.Migration.version = The version number; migrations are applied in that order.
doc.Migration.name = The name.
doc.Migration.up = The SQL that applies it; separate several statements with <code>;</code>.
doc.Migration.down = The SQL that undoes it.
doc.Migrator = A set of migrations.
doc.Migrator.items = The migrations.
doc.Migrator.table = The name of the version table.
doc.NewMigrator = A migrator with the default table.
doc.NewMigratorIn = A migrator with a version table of another name.
doc.FreeMigrator = Frees the memory.
doc.AddMigration = Adds a migration with a number, a name and the up and down SQL; the order you add them in does not matter.
doc.MigrationCount = The number of migrations.
doc.SplitStatements = Splits SQL text into statements; a <code>;</code> inside a string is not a separator.
doc.EnsureTable = Makes the version table when it is not there.
doc.SchemaVersion = The highest applied version; zero when there is none.
doc.IsApplied = This version has been applied.
doc.PendingCount = The number of migrations not applied yet.
doc.MigrateUp = Applies every migration not applied yet, in order, and returns how many; each migration in its own transaction.
doc.Rollback = Undoes the last migration.
doc.MigrateTo = Goes up or down until the version reaches the given number and returns how many steps; zero means undo them all.
doc.SQLITE = The name of the SQLite engine.
doc.MYSQL = The name of the MySQL engine.
doc.POSTGRES = The name of the PostgreSQL engine.
doc.TYPE_NULL = Column type: null.
doc.TYPE_INT = Column type: integer.
doc.TYPE_FLOAT = Column type: float.
doc.TYPE_TEXT = Column type: text.
doc.TYPE_BLOB = Column type: binary.
doc.Rows = The interface of the rows of a query; its methods are <code>next</code>, <code>text</code>, <code>int</code>, <code>close</code> and the like.
doc.Tx = The transaction interface; its methods are <code>exec</code>, <code>query</code>, <code>commit</code> and <code>rollback</code>.
doc.Connection = The interface shared by every engine. Code written against it runs unchanged on SQLite, MySQL and PostgreSQL; get one from the <code>Connect</code> of whichever engine.
doc.QueryInt = The first column of the first row as an integer; for <code>COUNT</code> and the like.
doc.QueryInt64 = The same, 64 bit.
doc.QueryFloat = The same, as a float.
doc.QueryText = The same, as text.
doc.CountRows = The number of rows in the result of a query.
doc.Run = Runs one statement; true when it succeeded.
doc.RunAll = Runs the statements in order and returns how many succeeded.
doc.InTx = Runs every statement in one transaction; when one fails, none of them is applied.
doc.QuoteLiteral = Returns the string as an SQL value, quoted and with <code>'</code> escaped.
doc.NO_LEASE = The number <code>Acquire</code> returns when no connection is free.
doc.Pool = A pool of connections, for programs that need several at once.
doc.Pool.conns = The connections.
doc.Pool.taken = Which connections are taken.
doc.Pool.limit = The greatest number of connections.
doc.NewPool = An empty pool with a greatest number of connections.
doc.Add = Adds a connection to the pool; false when the pool is full.
doc.Acquire = Takes a free connection and returns the lease number.
doc.Leased = This lease number is valid.
doc.Conn = The connection of a lease.
doc.Release = Returns the connection to the pool.
doc.Size = The number of connections.
doc.Idle = The number of free connections.
doc.InUse = The number of connections taken.
doc.DropDead = Closes and removes the free connections that no longer answer.
doc.CloseAll = Closes every connection.
doc.Free = Frees the memory of the pool.
