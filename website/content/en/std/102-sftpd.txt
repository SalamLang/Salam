pkg.intro <<
<p>This package is an SFTP server written in Salam: a server that does one thing, file transfer over SSH. It is built on the <a href="/std/sshd/">sshd</a> package, so it logs users in the same way and uses the same host key, but it allows only the SFTP subsystem. A client cannot run a command or open a shell, which is what you want for a drop box where partners upload and download files you trust them with.</p>
<p>Give it a root directory and a list of users, call <code>Listen</code> and then <code>Serve</code>. Clients are the usual ones: <code>sftp</code> from OpenSSH, FileZilla, or the <a href="/std/ssh/">ssh</a> package with <code>SftpOpen</code>, <code>Upload</code> and <code>Download</code>.</p>
<p>What to know before you use it:</p>
<ul>
<li><strong>Users are the <code>User</code> values of the <a href="/std/sshd/">sshd</a> package</strong>, with a name, a password and a home directory below the root. Login is by password.</li>
<li><strong>Set <code>host_key_file</code></strong> to the path of an OpenSSH private key. Without it the server uses a key that is built into the library and that everyone can read, which is only fine for tests.</li>
<li><strong>Clients stay inside the root.</strong> Clients see <code>root</code> as <code>/</code>. A symbolic link made through SFTP must point inside the root (an absolute target is read from the root), and a link that points outside it or at nothing is refused rather than followed. The server still runs with the rights of its own process, so keep the root on a directory that holds only what users may see.</li>
<li><strong>Connections are served one after another</strong>, so a long transfer holds up the next client.</li>
</ul>

<h2 id="guide-listen">Defaults and a free port</h2>
<p>A fresh configuration listens on all interfaces on port 22 and serves the current directory. The program below fills in a user, binds to port 0 on the loopback address, and reads the port the system chose with <code>Port</code>. Nothing connects, so it runs without a network.</p>
{{example.sftpd-listen}}

<h2 id="guide-serve">Run a drop box</h2>
<p>For a real server set the root, the host key and the users, then check <code>Listen</code> before <code>Serve</code>. Ports below 1024, including 22, need extra rights on most systems, so the example uses 2222. The password is read from <code>SFTP_PASSWORD</code>, so none is written in the page.</p>
{{example.sftpd-serve}}
<p>This runs until it is stopped, so it is only checked here. Connect with <code>sftp -P 2222 partner@host</code>.</p>
