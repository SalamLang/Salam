pkg.intro <<
<p>SQLite is a database that fits in one file and needs no server; for desktop programs, tools and a great many websites it is enough. The sqlite3 library has to be on the system to run it.</p>
<p>There are two ways to work: the functions of this package, such as <code>Query</code> and <code>Next</code>, which reach everything SQLite offers; or the database and row methods and <code>Conn</code>, which is the shared interface of <a href="../db/">db</a>. Send user values through <code>Prepare</code> and the <code>Bind...</code> functions, not by pasting them into the SQL text.</p>
>>
