pkg.group = Database
pkg.summary = Connecting to MySQL and MariaDB.
pkg.title = The db/mysql package in Salam | MySQL and MariaDB
pkg.description = The db/mysql package in Salam: connecting to MySQL and MariaDB, the utf8mb4 encoding, queries, transactions and the shared database interface, with an example.
pkg.import = db.mysql
pkg.intro <<
<p>This package implements the MySQL and MariaDB protocol directly and needs no outside library; when the server offers TLS the connection is encrypted. The example needs a running server, so it is checked and not run. For text outside ASCII, call <code>SetCharset</code> with <code>utf8mb4</code> once you are connected.</p>
>>
