pkg.intro <<
<p>Typesense is an open source search engine with typo tolerance, filters, facets, grouping, vector and hybrid search. This package speaks its HTTP API directly with <code>net.httpx</code> and covers all of it: collections and their fields, documents one at a time or in bulk JSONL imports and exports, every search parameter, multi search and union search, synonym sets and curation sets, presets, stopwords, stemming dictionaries, API keys and scoped search keys signed with no request, analytics rules and events, conversation (RAG) models, natural language search models and the cluster operations. The examples need a running server, so they are only checked.</p>
<p>Every call takes an <code>Error</code> as its last argument and fills it when something fails; check it with <code>Ok</code>, or with <code>IsNotFound</code> and <code>IsConflict</code> for the two answers code usually handles. A client can hold several nodes: a node that does not answer, or answers with a 5xx, is skipped for <code>healthcheck_ms</code> and the request moves to the next one, the same way the official clients behave. Documents and hits come back as raw JSON text; read them into your own structs with <code>GetDocumentAs</code> and <code>HitsAs</code>, and send your structs with <code>ImportOf</code> and <code>CreateDocumentOf</code>. Typesense 30 replaced per collection synonyms and overrides with synonym sets and curation sets; both kinds are here, so the package works with 29 and 30 servers alike. For a route with no function of its own, use <code>Request</code>.</p>
>>
