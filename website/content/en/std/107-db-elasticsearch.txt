pkg.description = The db/elasticsearch package in Salam: index, get, update and delete documents, full text search with a query builder, aggregations, scroll and point in time paging, bulk loading, SQL through the db interfaces, aliases and templates, over HTTP or TLS with basic, API key or bearer authentication.
pkg.import = db.elasticsearch
pkg.intro <<
<p>Elasticsearch is a search engine and document store spoken to with JSON over HTTP. This package is written in Salam on top of <code>net.httpx</code> and <code>tls</code>, with no outside library. It works with Elasticsearch 7 and 8, Elastic Cloud (<code>ConnectCloud</code>) and OpenSearch; SQL and point in time calls switch to the OpenSearch endpoints by themselves. A client keeps one connection open per node and can list several nodes: it rotates over them, skips a node that refuses connections for <code>DEAD_NODE_MS</code>, and retries on 502, 503 and 504. Documents and query clauses are plain JSON text, so you can mix the builders here with JSON you write by hand, and <code>Perform</code> reaches every API that has no function of its own. After any call, <code>Error</code>, <code>ErrorType</code> and <code>Status</code> describe what the server said. The examples need a running cluster, so they are only checked.</p>
<p>New to Elasticsearch? <a href="/learn/elasticsearch/">Lesson 26, Search with Elasticsearch</a>, walks through the package step by step with runnable examples.</p>
>>
