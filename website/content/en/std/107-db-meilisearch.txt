pkg.intro <<
<p>Meilisearch is a fast search engine with typo tolerance, filters, facets and AI powered hybrid search. This package speaks its HTTP API directly with <code>net.http</code> and covers all of it: indexes, documents in JSON, NDJSON or CSV, every search parameter, multi-search and federated search, facet search, similar documents, every index setting, tasks and batches, API keys and tenant tokens, webhooks, dynamic search rules and chat workspaces. The examples need a running server, so they are only checked.</p>
<p>Every call takes an <code>Error</code> as its last argument and fills it when something fails; check it with <code>Ok</code>. Writes do not happen at once: they return a <code>TaskInfo</code> and Meilisearch applies them in order, so call <code>Wait</code> when the next step needs the change. Search hits and documents come back as raw JSON text; read them into your own structs with <code>HitsAs</code> and <code>GetDocumentAs</code>. For a route with no function of its own, use <code>Request</code>. Requests have no time limit until you set one with <code>WithTimeout</code>, and a client is a plain value, so threads can share it.</p>
>>
