pkg.description = The db/opensearch package in Salam: a complete OpenSearch client with documents, bulk, the query DSL, aggregations, scroll and point in time paging, index and cluster admin, SQL and PPL through the shared db interface, k-NN and neural search, ISM policies, the security plugin and AWS SigV4 signing, with examples.

pkg.intro <<
<p>OpenSearch is an open source search and analytics engine. This package speaks its REST API directly over <code>net.tcp</code> and <code>tls</code>, with no outside library: several nodes with retries and dead node skipping, basic, bearer and AWS SigV4 authentication (for Amazon OpenSearch Service and Serverless), and TLS with your own CA file or, for a test server, no verification. On top of that it covers documents, bulk, every common query and aggregation, scroll and point in time paging, index, alias, template and data stream admin, cluster, task, snapshot and pipeline admin, and the plugins that make OpenSearch what it is: SQL and PPL, k-NN and neural search, hybrid search pipelines, ISM policies, the security plugin, alerting monitors and ML Commons.</p>
<p>Queries, aggregations and request bodies are plain JSON text: the builders such as <code>Match</code>, <code>BoolOf</code> and <code>TermsAgg</code> return it, and anything they do not cover can be written as a backtick string. Results come back as Salam structs whose JSON parts (a hit's source, the aggregations) are raw text you read with <code>Buckets</code>, <code>AggValue</code> and <code>JsonPath</code>. Every call records its status and error on the client, so read <code>Error</code> or <code>ErrorType</code> after a call that returned false. <code>Conn</code> boxes a client as a <code>db.Connection</code>, so SQL code written for the other engines can query OpenSearch too. For a route with no function of its own, use <code>Perform</code>. Only the examples for the query builders and request signing run here; the others need a server, so they are only checked.</p>
<p><a href="../db-elasticsearch/">db/elasticsearch</a> also talks to the OpenSearch core API. Use this package when you need what only OpenSearch has: PPL, k-NN, neural and hybrid search, ISM, the security plugin, alerting, ML Commons, or AWS SigV4 for Amazon OpenSearch Service and Serverless.</p>
>>
