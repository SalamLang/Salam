pkg.intro <<
<p>GraphQL is a language for asking an API for data: the client asks for exactly the fields it needs and the server sends back just those. This package is a complete server side implementation of the specification. Write the schema as SDL text and pass it to <code>ParseSchema</code>, or build it with the <code>Add...</code> functions, register resolvers for the fields and run a query with <code>ExecuteSource</code>.</p>
<p>A resolver is a function that takes a slot number; it reads the arguments and the parent object with <code>ArgStr</code>, <code>ParentField</code> and their siblings, and answers with one of the <code>Resolve...</code> functions or with <code>Fail</code>. A field without a resolver takes the value of the same name from the parent object. For a web server, call <code>HandleHttpSimple</code> inside a <a href="../net-http/">net/http</a> handler.</p>
>>
