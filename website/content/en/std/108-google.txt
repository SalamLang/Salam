pkg.summary = Google service account authentication for the Google APIs.
pkg.title = The google package in Salam | Service accounts and OAuth
pkg.description = The google package in Salam: reading a service account file, getting an OAuth access token with a JWT for Firebase and Cloud Storage, and the authorization header, with examples.
pkg.import = google
pkg.intro <<
<p>Server programs reach the Google APIs through a "service account". Get the account JSON file from the Google console, read it with <code>ParseServiceAccount</code>, and get a token for the scope you need with <code>AccessToken</code>; then send it in your <a href="../net-http/">net/http</a> requests with <code>Authorization</code>. Keep the service account file as carefully as a password.</p>
>>

doc.SCOPE_FCM = The access scope for sending notifications with Firebase Cloud Messaging.
doc.SCOPE_STORAGE = The scope for reading and writing in Cloud Storage.
doc.SCOPE_CLOUD = The full Google Cloud scope.
doc.ServiceAccount = A Google service account.
doc.ServiceAccount.client_email = The account email.
doc.ServiceAccount.private_key = The PEM private key.
doc.ServiceAccount.token_uri = The address the token comes from.
doc.ServiceAccount.project_id = The project id.
doc.ServiceAccount.ok = It was read correctly.
doc.ParseServiceAccount = Reads a service account JSON file.
doc.AccessToken = Gets an OAuth access token for the given scope; the token is kept and reused until it expires.
doc.Forget = Throws away the kept token of the account, so the next one is fetched fresh.
doc.Authorization = The value of the <code>Authorization</code> header with the token.
