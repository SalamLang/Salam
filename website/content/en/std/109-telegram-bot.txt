pkg.name = telegram/bot
pkg.group = Web and services
pkg.summary = Building a bot with the Bot API: messages, buttons, webhooks and a polling loop.
pkg.title = The telegram/bot package in Salam | Telegram Bot API
pkg.description = The telegram/bot package in Salam: building a bot, sending messages and photos, inline buttons and keyboards, commands, a secured webhook and the update polling loop, with examples.
pkg.import = telegram.bot
pkg.intro <<
<p>To build a bot, get a token from BotFather and make one with <code>NewBot</code>. A bot has two ways of taking messages: <code>Poll</code>, which asks Telegram itself and suits testing and simple servers, or a webhook, where Telegram POSTs the messages to your server.</p>
<p>With a webhook you can send the answer straight in the body of the HTTP response; the <code>Reply...</code> functions build that JSON text. Set a secret with <code>SetWebhookSecret</code> and check its header on every request.</p>
>>
