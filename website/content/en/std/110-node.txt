pkg.description = The node package in Salam: running a program under Node.js, loading a module with require, files and directories, running another program, promises, and working with JavaScript objects, with examples.
pkg.import = node
pkg.intro <<
<p>This package is for programs translated to JavaScript with <code>salam js</code> and run under Node.js, the VS Code editor extension for instance. Load any Node or npm module with <code>Require</code> and call its methods with the <code>Call...</code> functions. That is why the examples here are only checked.</p>
<p>JavaScript objects are held as one <code>i64</code>. The call functions are named after the types of their arguments: <code>CallS1</code> for one string, <code>CallV1</code> for one JavaScript value.</p>
>>
