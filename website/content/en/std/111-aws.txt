pkg.intro <<
<p>This package works with Amazon S3 and any storage compatible with it without the official SDK, including MinIO, Cloudflare R2, DigitalOcean Spaces, Wasabi, Backblaze and any other S3 compatible cloud storage. Build the configuration with <code>ForAws</code> or <code>ForEndpoint</code> and hand it the keys with <code>WithCredentials</code>, or let the package find them itself with <code>FromEnvironment</code> and <code>ResolveConfig</code>.</p>
<p>The <code>S3...</code> functions work with objects and buckets: writing and reading, listing, copying, files and folders, multipart uploads for large files, and presigned URLs so a browser can talk to S3 directly. The <code>Sqs...</code> functions cover SQS message queues and the <code>AssumeRole...</code> functions cover temporary STS credentials. For other services, such as DynamoDB, call any API with <code>NewJsonCall</code> and <code>Invoke</code>.</p>
<p>Never write keys into your code; use environment variables or an IAM role. The examples that need an AWS account are only checked on the site, not run.</p>
>>
