pkg.intro <<
<p>LLVM is the compiler infrastructure that also backs Salam. With this package you can build your own compiler or interpreter: make a <code>Context</code> and a <code>Module</code>, write the instructions with a <code>Builder</code>, test the module with <code>Verify</code> and then run it with the JIT or turn it into an object file.</p>
<p>If you have the IR as text, <code>Run</code> does the whole pipeline with one <code>Options</code>. For linking, LLD works inside the program itself for Linux with musl, Windows with MinGW and WASI; for the rest <code>LinkExternal</code> calls the system linker.</p>
<p>This package needs the <code>libsalam_llvm</code> library. The examples on the site are only checked.</p>
>>
