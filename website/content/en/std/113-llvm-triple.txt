pkg.intro <<
<p>A target triple, such as <code>x86_64-unknown-linux-gnu</code>, names the architecture, the vendor, the operating system and the environment. Without linking against LLVM, this package gives from it what a compiler needs before it generates code, such as the pointer size and the data layout.</p>
>>

doc.HostDatalayout = The data layout of the host machine.
doc.Datalayout = The LLVM data layout string for the triple: the byte order, the pointer size and the alignment of the types; empty for an unknown target.
doc.PointerBits = The pointer size of the target in bits: 32 or 64.
doc.IsWindows = The target is Windows.
doc.IsGlibc = The target is Linux with glibc, not musl.
