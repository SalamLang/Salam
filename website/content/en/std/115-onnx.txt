pkg.title = The onnx package in Salam | Running an ONNX model
pkg.description = The onnx package in Salam: loading an ONNX model trained in PyTorch or TensorFlow, looking at its nodes and attributes, and running it over tensors, with an example.
pkg.import = onnx
pkg.intro <<
<p>ONNX is a common format for machine learning models: export a model you trained in PyTorch or TensorFlow to <code>.onnx</code> and read it in Salam with <code>LoadOnnx</code>. <code>Run</code> runs the graph over the input tensors.</p>
<p>So that it works without an outside file, the example below builds a small model with <a href="../encoding-protobuf/">encoding/protobuf</a>; in practice nothing but <code>LoadOnnx</code> and <code>Run</code> is needed.</p>
>>

doc.Attr = One node attribute, such as alpha.
doc.Attr.name = The name.
doc.Attr.kind = The value kind in the ONNX format: 1 float, 2 integer, 3 string, 4 tensor, 6 and 7 lists.
doc.Attr.f = The float value.
doc.Attr.i = The integer value.
doc.Attr.s = The string value.
doc.Attr.t = The tensor value.
doc.Attr.floats = The float list.
doc.Attr.ints = The integer list.
doc.Attr.free = Frees the attribute.
doc.Node = One graph node: one operator with named inputs and outputs.
doc.Node.op = The operator name, such as Gemm or Relu.
doc.Node.name = The node name.
doc.Node.inputs = The names of the inputs.
doc.Node.outputs = The names of the outputs.
doc.Node.attrs = The attributes.
doc.Node.attr_index = The index of the attribute with this name; -1 when there is none.
doc.Node.attr_int = An integer attribute, or the default value.
doc.Node.attr_float = A float attribute, or the default value.
doc.Node.free = Frees the node.
doc.Model = A parsed ONNX model.
doc.Model.inputs = The names of the graph inputs.
doc.Model.outputs = The names of the outputs.
doc.Model.nodes = The nodes, in the order they run.
doc.Model.init_names = The names of the fixed weights.
doc.Model.inits = The fixed weights.
doc.Model.ir_version = The IR version in the file.
doc.Model.error = The error message.
doc.Model.ok = It was read correctly.
doc.Model.feed_names = The inputs you have to supply, meaning the inputs that are not fixed weights; pass them to <code>Run</code> in that order.
doc.Model.free = Frees the model.
doc.ParseOnnx = Reads the model from bytes in memory.
doc.LoadOnnx = Reads the model from a <code>.onnx</code> file.
doc.Run = Runs the model over the inputs and returns the outputs in the order of the graph outputs; the usual operators are supported, among them Gemm, MatMul, Add, Mul, Relu, LeakyRelu, Softmax and Transpose.
