pkg.title = The gguf package in Salam | llama.cpp models
pkg.description = The gguf package in Salam: reading the metadata and tensors of GGUF language models such as Llama and Qwen, and unpacking F16 and quantised weights, with an example.
pkg.import = gguf
pkg.intro <<
<p>GGUF is the llama.cpp file format for large language models. One file holds the metadata, such as the architecture and the tokenizer vocabulary, and the weights, usually quantised. <code>LoadGguf</code> reads only the header, and <code>LoadTensorF32</code> turns each weight into a tensor whenever you need it.</p>
<p>The example below builds a small file so that it runs without downloading a model.</p>
>>

doc.GGML_F32 = Weight type: 32 bit float.
doc.GGML_F16 = Weight type: 16 bit float.
doc.GGML_Q4_0 = Weight type: 4 bit quantised with a scale.
doc.GGML_Q4_1 = Weight type: 4 bit quantised with a scale and a minimum.
doc.GGML_Q8_0 = Weight type: 8 bit quantised.
doc.META_STRING = Metadata type: a string.
doc.META_ARRAY = Metadata type: an array.
doc.MetaValue = One metadata value.
doc.MetaValue.kind = The type.
doc.MetaValue.elem_kind = The type of the elements, for an array.
doc.MetaValue.i = The integer value.
doc.MetaValue.f = The float value.
doc.MetaValue.s = The string.
doc.MetaValue.ints = The integer array.
doc.MetaValue.floats = The float array.
doc.MetaValue.strs = The string array, such as the tokenizer vocabulary.
doc.MetaValue.free = Frees the value.
doc.TensorInfo = The information about one tensor in the file.
doc.TensorInfo.name = The name, such as <code>blk.0.attn_q.weight</code>.
doc.TensorInfo.dims = The dimensions.
doc.TensorInfo.ggml_type = The weight type, one of the constants above.
doc.TensorInfo.offset = Where the data sits, from the start of the data section.
doc.TensorInfo.count = The number of elements.
doc.TensorInfo.free = Frees it.
doc.Gguf = A parsed GGUF file.
doc.Gguf.version = The format version.
doc.Gguf.keys = The metadata keys.
doc.Gguf.values = The values, in the same order as the keys.
doc.Gguf.tensors = The tensors.
doc.Gguf.alignment = The data alignment.
doc.Gguf.data_offset = Where the data section starts in the file.
doc.Gguf.raw = The bytes of the file.
doc.Gguf.error = The error message.
doc.Gguf.ok = It was read correctly.
doc.Gguf.meta_index = The index of a metadata key; -1 when there is none.
doc.Gguf.meta_int = An integer metadata value, or the default value.
doc.Gguf.meta_str = A string metadata value.
doc.Gguf.tensor_index = The index of the tensor with this name.
doc.Gguf.free = Frees all of it.
doc.ParseGguf = Reads the file from a buffer; the buffer belongs to the result from then on.
doc.LoadGguf = Reads a <code>.gguf</code> file.
doc.TensorBytes = The size of the tensor data in bytes.
doc.LoadTensorF32 = Converts the tensor to float and loads it; the F16 and quantised types are unpacked.
