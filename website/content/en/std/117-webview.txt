pkg.title = The webview package in Salam | A desktop program
pkg.description = The webview package in Salam: building a desktop program for Windows, macOS and Linux with an HTML and JavaScript interface in a native window, with examples.
pkg.import = webview
pkg.intro <<
<p>This package opens a native window with the browser the operating system already has in it: WebView2 on Windows, WKWebView on macOS and WebKitGTK on Linux. Write the interface of the program in HTML and CSS, show it with <code>SetHTML</code> or <code>Navigate</code>, and start the event loop with <code>Run</code>.</p>
<p>The examples open a window, which is why the site only checks them.</p>
>>

doc.HINT_NONE = The user can resize the window.
doc.HINT_FIXED = The window size is fixed.
doc.WebView = A window with a browser inside it.
doc.WebView.handle = The handle of the browser on Linux and CEF.
doc.WebView.window = The handle of the window in the operating system.
doc.WebView.webview = The handle of the browser on macOS.
doc.WebView.closed = The window has been closed.
doc.WebView.Destroy = Closes the window and frees the resources.
doc.WebView.Run = Runs the event loop until the window is closed.
doc.WebView.Terminate = Stops the event loop.
doc.WebView.SetTitle = The window title.
doc.WebView.SetSize = The window size, with one of the <code>HINT</code> constants.
doc.WebView.SetHTML = Shows the HTML content.
doc.WebView.Navigate = Opens the address.
doc.WebView.Eval = Runs JavaScript in the current page.
doc.WebView.Init = The JavaScript that runs before every page.
doc.WebView.IsClosed = The window has been closed.
doc.Create = Makes a new window; with the debug flag the developer tools open with it.
