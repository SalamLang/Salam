pkg.intro <<
<p>This package opens a native window with the browser the operating system already has in it: WebView2 on Windows, WKWebView on macOS and WebKitGTK on Linux. Write the interface of the program in HTML and CSS, show it with <code>SetHTML</code> or <code>Navigate</code>, and start the event loop with <code>Run</code>.</p>
<p>The examples open a window, which is why the site only checks them.</p>
<p>A window needs a desktop session, so run these programs on your own machine with <code>salam run</code>. On Linux install the WebKitGTK development package first (<code>libwebkit2gtk-4.1-dev</code> on Debian and Ubuntu); Windows 10 and 11 already ship WebView2, and macOS ships WKWebView.</p>

<h2 id="guide-report">Showing data your program computed</h2>
<p>The simplest desktop program builds an HTML string and shows it. Everything the page needs, the style sheet included, can travel in that one string, so there are no files to ship next to the executable. <code>HINT_FIXED</code> keeps the window at the size you chose, which suits a small dialog like this order summary.</p>
{{example.webview-guide-report}}
<p>The item names go into the HTML as they are. When the text comes from a user or a file, pass it through <code>EscapeHTML</code> from <a href="/std/template/"><code>template</code></a> first, or a name with a <code>&lt;</code> in it breaks the page.</p>

<h2 id="guide-data">Handing structured data to the page</h2>
<p>For anything bigger than a table, let JavaScript draw the page and give it the data as JSON. <code>Init</code> runs its script before the page's own scripts, so <code>window.tasks</code> exists by the time the page loops over it. <code>Marshal</code> from <a href="/std/encoding-json/"><code>encoding/json</code></a> turns a vector of structs into a JSON array whose keys are the field names. <code>Eval</code> runs code in the page that is already loaded; here it sets the window title from the data.</p>
{{example.webview-guide-data}}
<p>Data flows one way here, from Salam to the page. Passing <code>true</code> to <code>Create</code> opens the developer tools, which is the quickest way to see a JavaScript error in the page.</p>

<h2 id="guide-launch">Opening a site or a local server</h2>
<p><code>Navigate</code> loads an address instead of a string, so the window can show a remote site or a web interface your own program serves on <code>127.0.0.1</code>. This one takes the address from the command line, so <code>salam run webview-guide-launch.salam http://127.0.0.1:8000</code> wraps a local development server in a native window.</p>
{{example.webview-guide-launch}}
<p><code>Run</code> blocks until the user closes the window; the lines after it are where you save state and clean up. Call <code>Destroy</code> once at the end in every case. Another thread that wants to close the window calls <code>Terminate</code>, which makes <code>Run</code> return.</p>
>>
