pkg.intro <<
<p>A tensor is a multi dimensional array of numbers: a vector is one dimensional, a matrix two, and a batch of images four. The data is 32 bit floats in row order. The <code>+</code>, <code>-</code>, <code>*</code> and <code>/</code> operators work element by element and take tensors of the same shape, or shapes that broadcast.</p>
<p>This package is arithmetic, with no gradients. To train a network, use <a href="../autograd/">autograd</a> and <a href="../nn/">nn</a>. Matrix multiplication and convolution go multi threaded with <code>SetThreads</code>.</p>
>>
