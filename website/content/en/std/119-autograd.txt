pkg.intro <<
<p>Training a model means lowering the loss with gradients. This package records every computation on a <code>Tape</code>, and <code>Backward</code> works out the gradient of the loss for every input. The functions return a node index rather than a tensor; read the value with <code>Value</code> and the gradient with <code>Grad</code>.</p>
<p>Use it directly for a custom loss, a new layer or any function you need the slope of. For ordinary networks, the ready made layers are in <a href="/std/nn/">nn</a> and the optimisers in <a href="/std/optim/">optim</a>; both sit on top of this package. The values themselves are <a href="/std/tensor/">tensor</a>s.</p>
<h3>Things that trip people up</h3>
<ul>
<li>Call <code>reset</code> on the tape at the start of every step. It frees every value and gradient the tape made, so a tensor you got from <code>Value</code> or <code>Grad</code> is gone after it; keep one with <code>tensor.Clone</code> first.</li>
<li><code>Input</code>, <code>Watch</code> and <code>Param</code> do not copy: the tape reads your tensor itself, so do not change or free it before <code>Backward</code>. <code>Constant</code> makes a copy.</li>
<li>Gradients are added into the tensors you pass to <code>Param</code>, never replaced. Zero them every step.</li>
<li><code>Backward</code> on a loss with more than one value treats it as the sum of its values.</li>
<li>Set <code>tape.training = false</code> when you evaluate a model: dropout then does nothing and batch normalization uses its running averages. The number given to <code>NewTape</code> seeds the dropout random numbers.</li>
</ul>
<h2 id="guide-derivative">Derivatives without doing the calculus</h2>
<p>Give the tape a tensor with <code>Watch</code>, build an expression from it, and <code>Backward</code> fills in how much the result changes when each input changes. The loss has to be a single number, so the program sums the five values of <code>f(x) = x&#179; - 2x</code>; because each value depends on one point only, the gradient of the sum is the slope at each point. The last column is the slope worked out by hand, <code>3x&#178; - 2</code>, for comparison.</p>
{{example.autograd-guide-derivative}}

<h2 id="guide-fit">Training loop: fitting a line</h2>
<p>This is the whole shape of training in a few lines. The weights live outside the tape, with a gradient tensor of the same shape next to each. Every step clears the tape with <code>reset</code>, zeroes the gradients, records the forward pass with <code>Param</code> for the weights, <code>Input</code> for the data and <code>Constant</code> for the targets, then calls <code>Backward</code> and moves each weight a little against its gradient with <code>tensor.AddScaled</code>.</p>
{{example.autograd-guide-fit}}
<p>The data is the line <code>y = 2x + 1</code> with some noise, and the loss settles near the noise level instead of reaching zero. Forget to zero the gradients and they add up from step to step, which looks like a learning rate that keeps growing. Once the loop works, <a href="/std/optim/"><code>optim</code></a> takes over the update step and <a href="/std/nn/"><code>nn</code></a> the layers.</p>

<h2 id="guide-check">Checking a gradient numerically</h2>
<p><code>GradCheck</code> nudges each input by a small step <code>h</code>, measures how a plain function of the tensor changes, and compares that with the gradient you give it. Use it when you write a new layer or loss: compute the function once with tensor operations, compute the gradient with the tape, and check that they agree. A wrong gradient, such as the doubled one in the second test, fails.</p>
{{example.autograd-guide-check}}
<p>The comparison is approximate. A step that is too small loses precision in 32 bit floats and one that is too big misses curvature; <code>0.001</code> with a tolerance of <code>0.01</code> suits most smooth functions.</p>

<h2 id="guide-which">Which input function to use</h2>
