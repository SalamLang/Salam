pkg.description = The autograd package in Salam: recording a computation on a tape, backpropagation and gradients, convolution and normalisation layers, loss functions and checking a gradient numerically, with examples.
pkg.import = autograd
pkg.intro <<
<p>Training a model means lowering the loss with gradients. This package records every computation on a <code>Tape</code>, and <code>Backward</code> works out the gradient of the loss for every input. The functions return a node index rather than a tensor; read the value with <code>Value</code> and the gradient with <code>Grad</code>.</p>
<p>Call <code>reset</code> on the tape at every training step. The ready made layers are in <a href="../nn/">nn</a> and the optimisers in <a href="../optim/">optim</a>.</p>
>>
