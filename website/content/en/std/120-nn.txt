pkg.intro <<
<p>This package has ready made layers for building a model. The weights of every layer live in one <code>ParamStore</code>; make each layer with a <code>New...</code> function and a unique name, and call <code>forward</code> on the <a href="../autograd/">tape</a> at every step. <code>Sequential</code> runs several layers one after the other.</p>
<p>Once it is trained with <a href="../optim/">optim</a>, save the model with <code>SaveCheckpoint</code> and load it again later.</p>
>>

doc.ParamStore.count = The number of parameters.

doc.Bind = Binds a parameter to the tape and returns its node.

doc.TransformerEncoderLayer.forward = Works out the output of the layer on the tape.
doc.NewTransformerEncoderLayer = An encoder layer.

doc.GRU.wx = The input weight.
doc.GRU.wh = The state weight.
doc.GRU.hidden = The state size.
doc.GRU.forward = Returns the state of every step.
doc.NewLSTM = An LSTM with an input and a state size.
doc.NewGRU = A GRU with an input and a state size.
doc.LastStep = The state of the last step of each sequence; for sequence classification.
doc.XavierUniform = Xavier uniform initialisation; for layers with tanh and sigmoid.
doc.XavierNormal = Xavier normal initialisation.
doc.KaimingUniform = Kaiming uniform initialisation; for layers with a rectifier.
doc.KaimingNormal = Kaiming normal initialisation.
