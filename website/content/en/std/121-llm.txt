pkg.en = llm
pkg.name = llm
pkg.group = Machine learning
pkg.summary = Running Llama and Qwen language models from a GGUF file.
pkg.title = The llm package in Salam | Running a language model
pkg.description = The llm package in Salam: loading GGUF models such as Llama and Qwen, BPE and SentencePiece tokenizers, the key value cache, sampling with temperature and top-p, and generating text, with examples.
pkg.import = llm
pkg.intro <<
<p>This package runs large language models of the Llama architecture, such as Llama, Qwen and Mistral, on the processor with no outside dependency. Download the quantised model in <a href="../gguf/">GGUF</a> form, read it with <code>LoadGgufModel</code> and make text with <code>Generate</code>.</p>
<p>For more control, <code>Forward</code> gives the logits and a <code>Sampler</code> picks the next token with temperature, top-k, top-p and a repetition penalty. The runnable example builds a small random model so it works without a download.</p>
>>

doc.Config = The architecture configuration of a model, of the Llama kind.
doc.Config.vocab = The vocabulary size.
doc.Config.dim = The embedding size.
doc.Config.layers = The number of layers.
doc.Config.heads = The number of attention heads.
doc.Config.kv_heads = The number of key and value heads; fewer than heads means grouped attention.
doc.Config.ff = The size of the feed forward layer.
doc.Config.ctx = The greatest text length.
doc.Config.eps = The small number for normalisation.
doc.Config.rope_theta = The base of the rotary embedding.
doc.Config.rope_kind = The kind of rotary embedding, one of the <code>ROPE_</code> constants.
doc.Config.head_dim = The size of each attention head.
doc.ROPE_NORMAL = The Llama rotary embedding.
doc.ROPE_NEOX = The GPT-NeoX rotary embedding, for Qwen and the like.
doc.Layer = The weights of one transformer layer.
doc.Layer.attn_norm = The normalisation before the attention.
doc.Layer.wq = The query weight.
doc.Layer.wk = The key weight.
doc.Layer.wv = The value weight.
doc.Layer.wo = The attention output weight.
doc.Layer.ffn_norm = The normalisation before the feed forward layer.
doc.Layer.w_gate = The SwiGLU gate weight.
doc.Layer.w_up = The up weight.
doc.Layer.w_down = The down weight.
doc.Layer.free = Frees the weights.
doc.Model = A language model.
doc.Model.cfg = The configuration.
doc.Model.tok_embed = The token embedding table.
doc.Model.layers = The layers.
doc.Model.out_norm = The final normalisation.
doc.Model.out_head = The output weight back to the vocabulary.
doc.Model.ok = It was built or loaded correctly.
doc.Model.free = Frees the model.
doc.KVCache = The key value cache: it keeps the keys and values of the earlier tokens so each new token is worked out only once.
doc.KVCache.k = The keys, one set per layer.
doc.KVCache.v = The values.
doc.KVCache.len = The number of tokens processed.
doc.KVCache.ctx = The capacity.
doc.KVCache.reset = Empties it for a fresh text.
doc.KVCache.free = Frees it.
doc.NewKVCache = A cache for a configuration.
doc.RandomModel = A model with random weights; for testing without a download.
doc.TOK_SPM = The SentencePiece tokenizer, as Llama 2 uses.
doc.TOK_BPE = The byte level BPE tokenizer, as GPT-2, Llama 3 and Qwen use.
doc.Tokenizer = The tokenizer: it turns text into indices and back.
doc.Tokenizer.kind = The kind.
doc.Tokenizer.tokens = The text of the tokens.
doc.Tokenizer.scores = The scores, for SentencePiece.
doc.Tokenizer.index = The index of each token.
doc.Tokenizer.merges = The ranks of the BPE merges.
doc.Tokenizer.merge_keys = The merge keys.
doc.Tokenizer.bos = The index of the beginning token; -1 means there is none.
doc.Tokenizer.eos = The index of the end token.
doc.Tokenizer.unk = The index of the unknown token.
doc.Tokenizer.add_bos = Add the beginning token when encoding.
doc.Tokenizer.byte_ids = The token index of each byte.
doc.Tokenizer.b2u = The byte to character map of byte level BPE.
doc.Tokenizer.add_token = Adds a token and returns its index.
doc.Tokenizer.add_merge = A BPE merge rule, in rank order.
doc.Tokenizer.finish = Call it once the tokens are added, to ready the tables.
doc.Tokenizer.size = The number of tokens.
doc.Tokenizer.token_text = The text of one token.
doc.Tokenizer.encode = Text into indices.
doc.Tokenizer.decode = Indices into text.
doc.Tokenizer.free = Frees it.
doc.NewTokenizer = An empty tokenizer of one kind.
doc.Forward = Passes the tokens through the model and returns the logits of each position; the cache is updated.
doc.LogitsRow = The logits of one position.
doc.Sampler = The sampler: it picks the next token from the logits.
doc.Sampler.temperature = The temperature; lower means a more certain answer.
doc.Sampler.top_k = Out of the k likeliest tokens only; zero means no limit.
doc.Sampler.top_p = Out of the tokens whose probabilities add up to p only.
doc.Sampler.repeat_penalty = The penalty for repeating a recent token.
doc.Sampler.rng = The random generator.
doc.Sampler.sample = Picks the next token, with the recent tokens taken into account.
doc.NewSampler = A sampler from a seed.
doc.Greedy = The likeliest token.
doc.GenerateIds = Generates up to n new tokens after the starting indices; it stops at the end token.
doc.Generate = Carries on from the starting text and returns the new text.
doc.ConfigFromGguf = The configuration from GGUF metadata.
doc.ModelFromGguf = Loads the weights from a GGUF file.
doc.TokenizerFromGguf = Builds the tokenizer from the vocabulary in the file.
doc.LoadGgufModel = Loads the model and the tokenizer from a <code>.gguf</code> file.
