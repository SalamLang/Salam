pkg.intro <<
<p>This package works with images without any outside library: it reads and writes PNG, JPEG and BMP. It also reads and writes WebP, both lossy and lossless. From a GIF it reads the first frame, and it saves an image in a GIF with at most 256 colors. <code>Open</code> and <code>Save</code> work the format out from the content or the extension. Drawing, resizing, cropping, rotating and filters such as blurring and sharpening are all there.</p>
<p>For text, read a TrueType font with <code>LoadFont</code> and write with <code>DrawTextStyled</code>; Persian and Arabic text is shaped and laid out right to left on its own. Use this package for thumbnails, generated cards and charts, watermarks and simple image checks. For computer vision (edges, contours, feature matching) see <a href="/std/ai/opencv/">opencv</a>, and to draw in a browser page, <a href="/std/web/canvas/">web.canvas</a>.</p>
<h3>Things to know</h3>
<ul>
<li>Pixels are 8 bit RGBA in memory. Every image owns that memory; release it with <code>Free</code>.</li>
<li><code>Save</code> picks the format from the extension and returns false for one it does not know. It uses quality 90; <code>SaveQuality</code> takes your own.</li>
<li>JPEG has no transparency: transparent pixels are laid on white before saving. WebP at quality 100 is lossless, below that lossy.</li>
<li>GIF reading gives only the first frame of an animation, and saving reduces the image to 256 colors.</li>
<li>Persian shaping uses the Arabic presentation forms of the font, so the font must contain them. <code>FindArabicFont</code> looks for an installed one that does (or the file in <code>$SALAM_FONT_ARABIC</code>).</li>
</ul>

<h2 id="guide-thumbs">Thumbnails and fixed-size cards</h2>
<p>An upload form usually needs the same picture in several sizes. <code>Thumbnail</code> shrinks the image so that its longer side fits and keeps the shape. <code>ResizeFill</code> fills an exact box and cuts off what sticks out, which suits square avatars and product cards. <code>ResizeFit</code> keeps the whole picture inside the box and centers it, leaving empty bands at the sides. <code>Save</code> chooses the format from the extension, so the same code writes PNG, JPEG or WebP.</p>
{{example.image-guide-thumbs}}
<p><code>Open</code> reports through its <code>bool</code> argument whether the file could be read. Every image allocates memory for its pixels, so release each one with <code>Free</code>, as the <code>defer</code> lines do.</p>

<h2 id="guide-chart">Draw a simple chart</h2>
<p>Lines, rectangles and circles plus the built-in pixel font are enough for a small bar chart, a badge or a placeholder image, with no font file needed. <code>LerpColor</code> mixes two colors, here to make taller bars darker, and <code>ParseHex</code> and <code>ToHexRGB</code> move between colors and CSS-style hex. <code>TextWidth</code> measures text before you draw it, so labels can be centered under their bars.</p>
{{example.image-guide-chart}}
<p>The pixel font has only capital English letters, digits and the signs <code>. , - : ! ?</code>; anything else, lower case letters included, is drawn as a blank. For Persian or any other script, and for smooth text at large sizes, load a TrueType font with <code>LoadFont</code> and use <code>DrawTextStyled</code>, which shapes Persian letters and lays them out right to left.</p>

<h2 id="guide-filters">Filters and measuring the difference</h2>
<p><code>Blurred</code> and <code>Sharpened</code> return new images; <code>Grayscale</code>, <code>Threshold</code>, <code>Brightness</code> and <code>Contrast</code> change the image in place. To compare two images, <code>MeanAbsError</code> gives the average difference per channel and <code>PSNR</code> the signal to noise ratio in decibels, where higher means more alike. The numbers show that sharpening a blurred image does not bring the original back: it makes the edges stronger, not correct.</p>
{{example.image-guide-filters}}
<p><code>Grayscale</code> uses perceived brightness, the same value <code>Luminance</code> returns, so a strong red becomes a fairly dark gray. These measures are also handy in tests: render an image and check that its PSNR against a stored reference stays above a limit.</p>

<h2 id="guide-card">A share card with Persian text</h2>
<p>A link preview image is a fixed 1200 by 630 canvas with a title that must fit whatever its length. <code>DrawTextFitBox</code> finds the largest size up to a limit at which the text fits a share of the box, centers it and returns the size it chose. <code>TextWidthStyled</code> measures text first, here to right-align the address in the corner; the y coordinate of <code>DrawTextStyled</code> is the baseline.</p>
{{example.image-guide-card}}
<p>The program takes a font path as its first argument and otherwise asks <code>FindArabicFont</code>, so it needs a font file and the site only compiles it. With Vazirmatn the title came out at about 61 pixels; the joined letters, the zero width non-joiner in <code>سریع‌تر</code> and the right to left order are all handled by the package.</p>

<h2 id="guide-watermark">Watermark a photo</h2>
<p><code>Overlay</code> draws one image on top of another at a position, with an opacity from 0 to 1, and respects the transparency of the top image. Here the mark is a half transparent black box with white text, placed ten pixels from the bottom right corner.</p>
