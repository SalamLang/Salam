pkg.name = image
pkg.group = Machine learning
pkg.summary = Reading, editing and saving images, and writing text on them.
pkg.title = The image package in Salam | PNG, JPEG and text
pkg.description = The image package in Salam: reading and saving PNG, JPEG, BMP, WebP and GIF, drawing, resizing and cropping, filters, a histogram and writing text with a TrueType font, with examples.
pkg.import = image
pkg.intro <<
<p>This package works with images without any outside library: it reads and writes PNG, JPEG and BMP. It also reads and writes WebP, both lossy and lossless. From a GIF it reads the first frame, and it saves an image in a GIF with at most 256 colors. <code>Open</code> and <code>Save</code> work the format out from the content or the extension. Drawing, resizing, cropping, rotating and filters such as blurring and sharpening are all there.</p>
<p>For text, read a TrueType font with <code>LoadFont</code> and write with <code>DrawTextStyled</code>; Persian and Arabic text is shaped and laid out right to left on its own. For building social media images automatically, <code>DrawTextFitBox</code> finds the size that fits. The font example needs a font file and on the site it is only checked.</p>
>>

doc.SaveWebP = Saves the image in a lossless WebP file; it returns true if the writing worked.
doc.DecodeWebP = Reads WebP from bytes, both lossy and lossless, with the transparency. From an animated WebP it returns the first frame. For broken data, ok becomes false.
doc.OpenWebP = Reads a WebP file, both lossy and lossless.

doc.DecodeGIF = Reads a GIF from bytes. From an animated GIF it returns the first frame, and the transparent pixels get an alpha of zero. For broken data, ok becomes false.
doc.OpenGIF = Reads a GIF file.
doc.EncodeGIF = Encodes the image as GIF. If the image has 256 colors or fewer the colors stay exact; otherwise the best 256 colors are picked and put in their place with error diffusion. Pixels with an alpha below 128 become transparent.
doc.SaveGIF = Saves the image in a GIF file; it returns true if the writing worked.
