pkg.intro <<
<p>This package gives you the classic machine learning algorithms behind an interface much like scikit-learn. The data is a <a href="../matrix/">matrix</a> where each row is a sample and each column a feature, and the labels are a one-column matrix. Every model is a struct: build it with its parameters, train it with <code>fit</code> and use it with <code>predict</code>.</p>
<p>Before training, prepare the data with <code>StandardScaler</code> and <code>SimpleImputer</code> and split it with <code>TrainTestSplit</code>; after that, measure the model with metrics such as <code>Accuracy</code>, <code>F1</code> and <code>R2Score</code>, and pick the parameters with <code>GridSearch</code>. For neural networks see <a href="../nn/">nn</a>.</p>
>>
