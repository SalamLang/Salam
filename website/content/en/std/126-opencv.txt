pkg.intro <<
<p>This package binds the OpenCV library and gives most of the everyday computer vision work: color conversion, resizing, filters, edge detection and thresholds, contours, ORB and SIFT features, face detection with a cascade classifier, running DNN networks, and reading and writing video and camera frames.</p>
<p>Use it for real computer vision: finding objects, matching features, reading camera frames, running a detection network. For thumbnails, drawing, text on images and format conversion with no outside library, the <a href="/std/image/">image</a> package is enough. To run a model file without OpenCV, see <a href="/std/onnx/">onnx</a>.</p>
<h3>Things to know</h3>
<ul>
<li>Programs link against the <code>salam_opencv_shim</code> library, which in turn needs OpenCV 4. If the shim is missing, the build fails at the link step or the program refuses to start with "cannot open shared object file"; it never gets as far as your code.</li>
<li>A <code>Mat</code> stores colour in OpenCV's blue, green, red order, but every function of this package takes and returns <code>Color</code> values as red, green, blue, and <code>FromImage</code> and <code>ToImage</code> convert for you.</li>
<li>Every <code>Mat</code> owns native memory that Salam does not track. Free each one, especially inside a loop over video frames.</li>
<li>Calls that fail return an empty <code>Mat</code> (or false) and leave the reason in <code>LastError</code>.</li>
</ul>
<p>The examples need OpenCV, so the site only type-checks them.</p>

<h2 id="guide-setup">Set up OpenCV</h2>
<p>The package talks to OpenCV 4 through a small C++ shim, <code>salam_opencv_shim</code>, that lives in <code>std/opencv/native</code> of the Salam repository. On Debian or Ubuntu, install OpenCV and the build tools, build the shim, and let the loader find it:</p>
<pre class="code" dir="ltr"><code>sudo apt install libopencv-dev cmake g++
cd std/opencv
cmake -S native -B native/build -DCMAKE_BUILD_TYPE=Release
cmake --build native/build --config Release
export LD_LIBRARY_PATH=$PWD/native/build:$LD_LIBRARY_PATH</code></pre>
<p>Every program on this page starts by calling <code>Available</code>, which reports whether OpenCV answers and returns its version through <code>Version</code>. The outputs shown below are what the programs printed with OpenCV 4.10 on Linux.</p>

<h2 id="guide-shapes">Find and measure shapes</h2>
<p>The classic pipeline for counting objects is: convert to gray, threshold to a black and white mask, then find the contours of the white areas. <code>THRESH_BINARY_INV</code> makes dark shapes on a light background white. <code>Contours</code> gives the number of shapes and, for each one, its <code>area</code> and <code>bounding_rect</code>. Drawing methods such as <code>rectangle</code> and <code>circle</code> change the image in place, and a thickness of -1 fills the shape.</p>
{{example.opencv-guide-shapes}}
<pre class="code" dir="ltr"><code>shapes found: 3
  shape at 150 190 size 200 x 70 area 13731
  shape at 230 40 size 101 x 101 area 7704
  shape at 40 40 size 120 x 80 area 9401
saved: true</code></pre>
<p>The area is measured along the traced outline, so it comes out a little smaller than width times height.</p>

<h2 id="guide-edges">Edge detection</h2>
<p><code>canny</code> finds edges, and works best on a gray image that has been smoothed first with <code>gaussian_blur</code>, so that noise does not turn into tiny false edges. The two thresholds control how strong an edge must be to start a line and to continue one. <code>dilate</code> thickens the result, which helps when the edges go on to a contour search. When <code>photo.jpg</code> is missing, the program draws a test image instead.</p>
{{example.opencv-guide-edges}}
<pre class="code" dir="ltr"><code>photo.jpg not found, using a drawn test image
size: 320 x 240 channels: 3
edge pixels: 480 after dilate: 1600
saved: true</code></pre>
<p>Every method that returns a new <code>Mat</code> allocates; free each result, as the <code>defer</code> lines do, or a long running program, such as one that processes camera frames, will grow without limit.</p>

<h2 id="guide-template">Find a picture inside another</h2>
<p><code>find_template</code> slides a small image over a large one and reports the best position and a score between 0 and 1. That is how a test robot finds a button on a screenshot, or a program finds a logo in a scan. Check <code>found</code> and the <code>score</code> before you trust the position.</p>
{{example.opencv-guide-template}}
<pre class="code" dir="ltr"><code>button at 420 300 score above 0.99: true
saved: true</code></pre>

<h2 id="guide-video">Write and read video</h2>
<p><code>NewVideoWriter</code> takes a file name, a four letter codec, the frames per second and the frame size; every frame you <code>write</code> must have that size. <code>OpenVideo</code> reads a file and <code>OpenCamera(0)</code> the first camera; <code>read</code> returns an empty <code>Mat</code> when there are no more frames. Which codecs work depends on how OpenCV was built; <code>MJPG</code> in an <code>.avi</code> file is available almost everywhere.</p>
{{example.opencv-guide-video}}
<pre class="code" dir="ltr"><code>frames: 20 fps: 10
read 20 frames, last frame 160 x 120</code></pre>
<p>To show frames in a window while you work, use <code>Imshow</code> and <code>WaitKey</code>; they need a desktop session. <code>ToImage</code> and <code>FromImage</code> move pictures between this package and <a href="/std/image/">image</a>, for example to draw Persian text with a TrueType font.</p>
