pkg.intro <<
<p>The au format is the simplest real sound file there is: a 24 byte big-endian header and then the samples. It came from Sun, it is what <code>/dev/audio</code> spoke, and it is still a pleasant way to hand raw audio between programs because there is almost nothing to get wrong.</p>
<p>It carries more encodings than its size suggests: mu-law and A-law, signed PCM at 8, 16, 24 and 32 bits, and IEEE floating point at 32 and 64. Everything is big-endian.</p>
<h3>Things to know</h3>
<ul>
<li>8 bit au PCM is <strong>signed</strong>, where 8 bit WAVE is unsigned. The shared helpers in <a href="/std/audio/">audio</a> take that as an argument, so neither format has to guess.</li>
<li>A companded file decodes to a clip marked 16 bit, because that is the depth mu-law and A-law reconstruct to.</li>
<li><code>data_offset</code> may be larger than <code>HeaderSize</code>; the gap is a text note, and this package steps over it.</li>
<li>A data size of 0xFFFFFFFF means unknown, which this package treats as everything to the end of the file.</li>
</ul>

<h2 id="guide-encodings">Choosing an encoding</h2>
<p>An AU file has a 24 byte header followed by the samples, and the header names the encoding. <code>EncodeAUEncoding</code> takes one of <code>EncPcm16</code>, <code>EncMuLaw</code>, <code>EncALaw</code>, <code>EncFloat32</code> and the others the package lists. For 64 mono frames the three files are 152, 88 and 280 bytes: 16 bit PCM, one byte per sample, and 32 bit floats.</p>
{{example.audio-au-guide-encodings}}
<p><code>ReadHeader</code> fills a <code>Header</code> with the encoding, rate, channels and data size. <code>DecodeAU</code> expands the mu-law file to a 16 bit clip, and the sample is within 0.02 of the original.</p>

<h2 id="guide-disk">Saving, probing and opening</h2>
<p><code>SaveAU</code> writes 16 bit PCM and returns <code>true</code> on success. <code>ProbeAU</code> works on bytes, so the program encodes the clip first and probes the buffer: rate, depth and frame count come from the header without decoding.</p>
{{example.audio-au-guide-disk}}
<p><code>OpenAU</code> reads the file written to disk and returns the clip with its rate and frames intact. Free the buffer and every clip when you are done.</p>
>>

doc.EncALaw = Eight bit A-law.
doc.EncFloat32 = 32 bit IEEE floating point.
doc.EncFloat64 = 64 bit IEEE floating point.
doc.EncMuLaw = Eight bit mu-law, the original au encoding.
doc.EncPcm16 = 16 bit signed PCM.
doc.EncPcm24 = 24 bit signed PCM.
doc.EncPcm32 = 32 bit signed PCM.
doc.EncPcm8 = Eight bit signed PCM, not unsigned as in WAVE.
doc.HeaderSize = The 24 bytes an au header always takes, before any text note.
doc.DecodeAU = Decodes a whole au file from memory into a clip.
doc.EncodeAU = Encodes a clip as au, picking the integer encoding from the depth the clip remembers.
doc.EncodeAUEncoding = Encodes a clip as au in the encoding you name, including the two companded ones.
doc.IsAU = True when these bytes start with the .snd magic number.
doc.OpenAU = Reads an au file from disk into a clip.
doc.ProbeAU = Reads only the header, so you learn the length and rate without decoding.
doc.ReadHeader = Reads the whole header and checks it against the file length.
doc.SaveAU = Writes a clip to an au file.
doc.Header = The whole of an au header: where the samples are, how they are coded, and their shape.
doc.Header.data_offset = Where the samples start. At least HeaderSize, and anything between is a text note.
doc.Header.data_size = How many bytes of samples there are, held inside the file.
doc.Header.encoding = Which Enc number the samples use.
doc.Header.rate = Frames per second.
doc.Header.channels = How many channels.
