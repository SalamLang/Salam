pkg.intro <<
<p>FLAC is lossless: what comes out is exactly what went in, and the file is usually a little over half the size of the same sound as 16 bit PCM. This package reads and writes it without any outside library.</p>
<p>The decoder handles the whole format: constant, verbatim, fixed-predictor and LPC subframes, Rice-coded and escaped residuals, and all four ways FLAC can share a stereo pair between two channels. The encoder writes constant, verbatim and fixed-predictor subframes, choosing per block whichever is smallest, which is where most of the compression comes from.</p>
<h3>Things to know</h3>
<ul>
<li>Lossless means lossless: a <a href="/std/audio/">clip</a> at 8, 16 or 24 bits comes back bit for bit. <code>VerifyFLAC</code> proves it on a given file by decoding it again.</li>
<li>An encode is only as good as the clip it was given. A clip has no bit depth of its own until something sets <code>bits</code>, and the encoder then assumes 16.</li>
<li>Tags are not here. FLAC keeps them in a metadata block, which <a href="/std/audio/tag/">audio/tag</a> reads and writes.</li>
<li><code>Blocks</code> hands back a vector you must free, and a stream header holds an MD5 you must release with <code>FreeStreamInfo</code>.</li>
<li>Compression depends entirely on the material. A tone goes to a fifth of its PCM size, noise barely moves, and real music lands somewhere near half.</li>
</ul>
>>

doc.BlockApplication = Data belonging to some other program.
doc.BlockCueSheet = Track boundaries, as a CD would have them.
doc.BlockPadding = Empty space, so a tag can grow later.
doc.BlockPicture = Cover art.
doc.BlockSeekTable = Seek points into the audio.
doc.BlockStreamInfo = The stream header, always the first block.
doc.BlockVorbisComment = The tags, in Vorbis comment form. Read them with audio/tag.
doc.DefaultBlock = The block size the encoder uses unless a level asks for another.
doc.MaxBlockSize = The largest block FLAC allows.
doc.MaxChannels = The most channels FLAC allows.
doc.Blocks = Every metadata block, in order. Free the vector when you are done.
doc.CRC16 = The CRC-16 FLAC puts at the end of every frame, polynomial 0x8005.
doc.CRC16Buf = The same CRC-16 over a byte buffer.
doc.CRC8 = The CRC-8 FLAC puts at the end of every frame header, polynomial 0x07.
doc.DecodeFLAC = Decodes a whole FLAC stream from memory into a clip. Constant, verbatim, fixed and LPC subframes are all handled, as are Rice and escaped residuals and all four channel assignments.
doc.EncodeFLAC = Encodes a clip as FLAC at the middle level.
doc.EncodeFLACLevel = Encodes a clip as FLAC at a level from 0 to 8. The level picks the block size; every level is lossless.
doc.FreeStreamInfo = Releases the MD5 a stream header holds.
doc.IsFLAC = True when these bytes start with the fLaC magic number.
doc.OpenFLAC = Reads a FLAC file from disk into a clip.
doc.ProbeFLAC = Reads the stream header alone, so you learn the length and rate without decoding.
doc.ProbeFileFLAC = Reads the stream header of a file on disk.
doc.ReadFrameHeader = Reads one frame header and checks its CRC-8. It returns how many bytes the header took, or -1 when this is not a frame.
doc.ReadStreamInfo = Reads the stream header and works out where the audio starts.
doc.SaveFLAC = Writes a clip to a FLAC file.
doc.SaveFLACLevel = Writes a clip to a FLAC file at a level you choose.
doc.VerifyFLAC = Decodes a stream again and checks it against its own header. Use it to prove an encode really was lossless.
doc.FrameInfo = What a frame header says, which may differ from the stream header.
doc.FrameInfo.block_size = How many frames this block holds.
doc.FrameInfo.rate = Frames per second.
doc.FrameInfo.channels = How many channels this frame carries.
doc.FrameInfo.bits = Bits per sample.
doc.FrameInfo.assignment = How the channels are stored: independent, or left/side, right/side or mid/side.
doc.FrameInfo.variable = True when the frame is numbered by sample rather than by frame.
doc.FrameInfo.number = The frame or sample number this frame starts at.
doc.MetaBlock = One metadata block: what kind it is and where its body is.
doc.MetaBlock.kind = Which Block number it is.
doc.MetaBlock.offset = Where the body starts.
doc.MetaBlock.size = How many bytes the body holds.
doc.MetaBlock.last = True on the final block before the audio.
doc.StreamInfo = What a FLAC stream says about itself, read from its first metadata block.
doc.StreamInfo.min_block = The smallest block the encoder used.
doc.StreamInfo.max_block = The largest block it used.
doc.StreamInfo.min_frame = The smallest frame in bytes, or 0 when unknown.
doc.StreamInfo.max_frame = The largest frame in bytes.
doc.StreamInfo.rate = Frames per second.
doc.StreamInfo.channels = How many channels.
doc.StreamInfo.bits = Bits per sample, from 4 to 32.
doc.StreamInfo.total = How many frames the whole stream holds, or 0 when the encoder did not know.
doc.StreamInfo.md5 = The MD5 of the decoded signal, 16 bytes. Release it with FreeStreamInfo.
doc.StreamInfo.audio_offset = Where the first audio frame starts, past every metadata block.
