pkg.intro <<
<p>A sound file carries more than sound. This package reads and writes the part that says what the music is: the title, who played it, which album it came from, and the picture on the cover.</p>
<p>Three tag formats cover almost everything in use. ID3v1 is the 128 bytes at the end of an MP3. ID3v2 sits at the front and is what modern files really use, in any of four text encodings. Vorbis comments are what FLAC and Ogg keep their tags in. <code>ReadTags</code> works out which one a file has and reads it, so most callers never name a format at all.</p>
<h3>Things to know</h3>
<ul>
<li>Every string in a <code>Tags</code> is owned by it. Release the whole set with <code>FreeTags</code>; an unset field is empty and costs nothing.</li>
<li>Text comes back as UTF-8 whatever the file used, so Persian and Arabic titles survive an ID3v2 round trip.</li>
<li>Writing produces ID3v2.4 with UTF-8, which every current player reads.</li>
<li>Cover art comes back as a byte buffer still in its own format, so hand it straight to <a href="/std/image/">image</a> to decode.</li>
<li><code>AudioStart</code> and <code>AudioEnd</code> say where the sound really is, which is what a decoder needs in order to skip the tags.</li>
</ul>
>>

doc.BlockPicture = The block cover art lives in.

doc.EncUtf16BE = ID3v2 text in big-endian UTF-16 with no mark.
doc.EncUtf8 = ID3v2 text in UTF-8, which is what this package writes.
doc.AudioEnd = Where the audio stops, before any ID3v1 tag.
doc.AudioStart = Where the audio starts, past any ID3v2 tag.
doc.FlacBlocks = Every FLAC metadata block. Free the vector when you are done.
doc.FreeTags = Releases every string and the artwork a set of tags holds.
doc.GenreName = The name of an ID3v1 genre number, or an empty string for one this package does not name.
doc.HasID3v1 = True when the last 128 bytes are an ID3v1 tag.
doc.HasID3v2 = True when the file starts with an ID3v2 tag.
doc.HasTags = True when anything worth showing was found.
doc.ID3v2Size = How many bytes the whole ID3v2 tag takes, which is where the audio starts.
doc.ID3v2Version = Which major version the ID3v2 tag is, 2, 3 or 4.
doc.IsFlacTagged = True when these bytes are a FLAC stream, whose tags this package can read.
doc.NewTags = An empty set of tags.
doc.ReadFlacTags = Reads the Vorbis comment and the cover art out of a FLAC stream.
doc.ReadID3v1 = Reads an ID3v1 tag from the end of the file, including the v1.1 track number.
doc.ReadID3v2 = Reads an ID3v2 tag, versions 2.2 through 2.4, in any of the four text encodings, including the cover art.
doc.ReadTags = Reads whatever tags a file has, picking the reader from the file itself: ID3v2, then a FLAC comment, then ID3v1.
doc.ReadTagsFile = The same from a path.
doc.ReadVorbisComment = Reads a Vorbis comment block, which is what FLAC and Ogg both use for tags.
doc.StripTags = The file with its tags taken off, leaving only the audio.
doc.WriteID3v1 = Builds the 128 bytes of an ID3v1 tag.
doc.WriteID3v2 = Builds an ID3v2.4 tag with UTF-8 text.
doc.WriteVorbisComment = Builds a Vorbis comment block.
doc.Block = One FLAC metadata block, as the tag reader walks them.
doc.Block.kind = Which Block number it is.
doc.Block.offset = Where the body starts.
doc.Block.size = How many bytes it holds.
doc.Block.last = True on the final block.
doc.Tags = What a file says about the music in it: who made it, what it is called, and a picture.
doc.Tags.title = The track title.
doc.Tags.artist = Who performed it.
doc.Tags.album = The album it belongs to.
doc.Tags.albumartist = Who the album is credited to, which a compilation needs.
doc.Tags.composer = Who wrote it.
doc.Tags.genre = What kind of music it is.
doc.Tags.comment = A free note.
doc.Tags.lyrics = The words.
doc.Tags.art_mime = The media type of the cover art, such as image/jpeg.
doc.Tags.year = The year, or 0 when there is none.
doc.Tags.track = Which track this is.
doc.Tags.tracks = How many tracks the album has.
doc.Tags.disc = Which disc this is.
doc.Tags.bpm = Beats per minute, as the tag claims.
doc.Tags.art = The cover art itself, still in whatever format it was stored in. Hand it to image.Decode.
