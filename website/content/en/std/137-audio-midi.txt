pkg.intro <<
<p>A MIDI file holds notes, not sound: which note, when, how hard and on what instrument. That makes it tiny, and it makes it editable in a way a recording is not.</p>
<p>This package reads and writes standard MIDI files, and <code>Render</code> turns one into sound through <a href="/std/audio-synth/">audio/synth</a>, so a file of notes becomes a <a href="/std/audio/">clip</a> you can save as WAV or FLAC.</p>
<h3>Things to know</h3>
<ul>
<li>Everything is in ticks, and <code>division</code> says how many ticks a quarter note is. <code>TicksToSeconds</code> needs the tempo as well, which is why it takes the whole song.</li>
<li>A note is two events, on and off. <code>AddNote</code> writes both, and <code>Notes</code> pairs them back up and gives you lengths in seconds.</li>
<li>A note on with velocity 0 means a note off, and the reader turns it into one so you never have to check.</li>
<li>Release a song with <code>FreeSong</code>: it owns a vector per track plus the vector of tracks.</li>
<li><code>Render</code> uses a single plain envelope for every note. For anything more, take <code>Notes</code> and render it yourself.</li>
</ul>
>>

doc.ControlChange = A controller moving, such as a volume pedal.
doc.DefaultDivision = The ticks per quarter note a new song gets, 480.
doc.MetaEndOfTrack = The end of a track.
doc.MetaEvent = A status byte saying the real kind is in the meta field.
doc.MetaTempo = A tempo change.
doc.MetaTimeSignature = A time signature.
doc.MetaTrackName = A track name.
doc.NoteOff = A note ending. A note on with velocity 0 is read as one of these.
doc.NoteOn = A note starting.
doc.ProgramChange = The instrument changing.
doc.AddControl = Adds a controller change.
doc.AddNote = Adds a note on and the matching note off, which is what writing a note really means.
doc.AddProgram = Adds an instrument change.
doc.AddTempo = Adds a tempo change in beats per minute.
doc.AddTrack = Adds a track to a song.
doc.Bpm = The tempo in beats per minute.
doc.DecodeMIDI = Reads a standard MIDI file, following running status and skipping system events.
doc.EncodeMIDI = Writes a song out as a standard MIDI file.
doc.FreeSong = Releases every track and event a song holds.
doc.IsMIDI = True when these bytes start with the MThd header.
doc.NewSong = An empty song with a division you choose.
doc.NewTrack = An empty track.
doc.Notes = Every note in the song as a synth note, with its start and length already in seconds.
doc.OpenMIDI = Reads a MIDI file from disk.
doc.ProgramName = The General MIDI name of an instrument number, or an empty string for one this package does not name.
doc.Render = Renders a whole song to a clip through audio/synth.
doc.SaveMIDI = Writes a song to a MIDI file.
doc.SecondsToTicks = The other way round.
doc.TicksToSeconds = How many seconds a number of ticks lasts at the song's tempo.
doc.TotalTicks = The tick the last event happens at, so how long the song is.
doc.Event = One MIDI event, with the tick it happens at.
doc.Event.tick = When it happens, in ticks from the start.
doc.Event.status = Which kind of event it is.
doc.Event.channel = Which of the sixteen channels it is on.
doc.Event.data1 = The first byte, a note number or a controller.
doc.Event.data2 = The second byte, a velocity or a value.
doc.Event.meta = Which meta event it is, when the status says meta.
doc.Event.value = The number a meta event carries, such as a tempo.
doc.Song = A whole MIDI file: its format, its timing and its tracks.
doc.Song.format = Which SMF format it is, 0 for one track and 1 for several.
doc.Song.division = Ticks per quarter note, which is what every tick is measured in.
doc.Song.tempo = Microseconds per quarter note. 500000 is 120 beats per minute.
doc.Song.tracks = The tracks themselves.
doc.Track = One track: a list of events in tick order.
doc.Track.events = The events.
