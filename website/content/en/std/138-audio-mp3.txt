pkg.intro <<
<p>An mp3 file is a run of frames, each with a header saying how it is coded and how long it is. This package reads those headers, so you can tell what a file is, how long it lasts, how many frames it holds and where in it a given second falls, all without decoding any sound.</p>
<p>That covers everything a library listing, a player's seek bar or a tag editor needs. Every MPEG version and layer is parsed, including the MPEG-2 and 2.5 half and quarter sample rates, and the Xing, Info and VBRI headers that say how long a variable bit rate file really is.</p>
<h3>Things to know</h3>
<ul>
<li><strong>Audio decoding is not here yet.</strong> This package reads the structure of an mp3, not its sound, and <code>CanDecode</code> in <a href="/std/audio-codec/">audio/codec</a> says so. Layer III decoding needs the ISO Huffman and scalefactor tables, which are a separate and much larger job.</li>
<li>A frame is only trusted when another frame follows where it says one should, which is what stops <code>FindSync</code> locking onto a run of 0xFF bytes inside a tag.</li>
<li>The frame count in a Xing header does not include the frame the header itself sits in, so a file with 10 audio frames reports 11 when counted and 10 when asked.</li>
<li>For a constant bit rate file the length is frames times samples per frame. For a variable one, only the Xing header knows, which is why <code>ProbeMP3</code> prefers it.</li>
<li>Tags are <a href="/std/audio-tag/">audio/tag</a>'s job, and this package uses it to find where the audio starts.</li>
</ul>
>>

doc.Layer1 = Layer I.
doc.Layer2 = Layer II.
doc.Layer3 = Layer III, which is what an mp3 file is.
doc.ModeDual = Two unrelated channels.
doc.ModeJoint = Joint stereo, which shares information between them.
doc.ModeMono = One channel.
doc.ModeStereo = Two independent channels.
doc.Version1 = MPEG-1, the usual one.
doc.Version2 = MPEG-2, at half the sample rates.
doc.Version25 = The MPEG-2.5 extension, at a quarter.
doc.AudioStart = Where the first frame is, past any ID3v2 tag.
doc.CountFrames = How many frames the file holds, by walking all of them.
doc.FindSync = The next frame from a position, confirmed by checking that a second frame follows where the first says it should.
doc.FrameAt = Where a frame is by index, or -1 when there is no such frame.
doc.Headers = Every frame header, in order. Free the vector when you are done.
doc.IsMP3 = True when this looks like an mp3: an ID3v2 tag, or a frame that checks out.
doc.ParseHeader = Reads one frame header and works out its size, or says this is not a frame.
doc.ProbeFileMP3 = The same from a path.
doc.ProbeMP3 = Everything a listing needs: the rate, the channels, the length and the bit rate, from the headers alone.
doc.ReadVbrInfo = Reads a Xing, Info or VBRI header, which is the only cheap way to know how long a variable bit rate file is.
doc.SamplesPerFrame = How many PCM frames one MPEG frame holds, which depends on the version and the layer.
doc.SeekToSecond = Where the frame covering a time is, which is how you start playing from the middle.
doc.Header = What one MPEG audio frame header says.
doc.Header.version = Which MPEG version, one of the Version numbers.
doc.Header.layer = Which layer, one of the Layer numbers.
doc.Header.bitrate = The bit rate in kilobits per second.
doc.Header.rate = Frames per second.
doc.Header.channels = How many channels, worked out from the mode.
doc.Header.mode = The channel mode, one of the Mode numbers.
doc.Header.mode_ext = The mode extension, which says what joint stereo is doing.
doc.Header.padding = 1 when this frame carries one extra byte to keep the average bit rate.
doc.Header.crc = True when a CRC follows the header.
doc.Header.frame_size = How many bytes the whole frame takes, padding included.
doc.Header.samples = How many PCM frames this frame decodes to.
doc.VbrInfo = What a Xing, Info or VBRI header says about the file as a whole.
doc.VbrInfo.frames = How many audio frames follow. The header's own frame is not counted.
doc.VbrInfo.bytes = How many bytes of audio there are.
doc.VbrInfo.vbr = True for a Xing header, which means the bit rate varies.
doc.VbrInfo.quality = The quality number the encoder recorded.
doc.VbrInfo.delay = How many samples the encoder added at the front, which gapless playback must drop.
doc.VbrInfo.padding = How many samples it added at the end.
doc.VbrInfo.found = True when such a header was there at all.
