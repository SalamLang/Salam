pkg.intro <<
<p>This package reads text written in the block style that <a href="/std/net/httpd/">net/httpd</a> uses for its config, and gives back a tree. It knows nothing about web servers: it only recognises the shapes, and <code>net/httpd</code> decides which names are valid. You can use it for settings files of your own that look like Salam.</p>
<p>There are two shapes. A setting is a name, an equals sign and one or more values on the same line: <code>max connections = 100</code>. A block is a name, optional strings, a colon, its contents and <code>end</code>: <code>location "/api/": cache = 1h end</code>. A name may be several words (<code>error page</code>), values are strings in double quotes (with <code>\n</code>, <code>\t</code>, <code>\"</code> and <code>\\</code>), strings in backticks (taken as written, so a regular expression needs no doubling of backslashes), numbers with an optional unit such as <code>64mb</code> or <code>30d</code>, and plain words such as <code>tls</code>. Comments are <code>//</code> to the end of the line, or <code>/* ... */</code>.</p>
<p>Everything lives in a <code>Doc</code>, a list of nodes that point at each other by number: node 0 is the root, <code>Find</code> and <code>ChildAt</code> move down, and the fields of a node hold its words, labels, values and children. Free the document with <code>Free</code> when you are done with it.</p>
<p>The things people get wrong:</p>
<ul>
<li>A value list ends at the end of the line, at <code>end</code>, or where the next setting starts on the same line, so <code>a = 1 b = 2</code> is two settings. A bare word at the end of a list is read as a value, which is why <code>listen = 443 tls</code> works.</li>
<li>A parse stops at the first error, and <code>ok</code> is then false. The error has the line and the column, and <code>ErrorText</code> puts them in front of the message the way compilers do.</li>
<li>Addresses and anything with a colon in it need quotes: <code>listen = "127.0.0.1:8080"</code>. Without them the colon would read as the start of a block.</li>
<li>A node's <code>words</code> hold its name, so <code>Name</code> joins them with single spaces. Block labels, such as the path of a location, are in <code>labels</code>, not in the name.</li>
</ul>
>>

doc.VAL_WORD = The kind of a value that is a plain word such as <code>tls</code> or <code>auto</code>.
doc.VAL_STR = The kind of a value written in quotes or backticks.
doc.VAL_NUM = The kind of a value that starts with a digit, with or without a unit, such as <code>8080</code> or <code>30d</code>; the text keeps the unit.
doc.Value = One value of a setting.
doc.Value.kind = <code>VAL_WORD</code>, <code>VAL_STR</code> or <code>VAL_NUM</code>.
doc.Value.text = The value as text; strings without their quotes and with escapes resolved.
doc.Value.line = The line, counting from 1.
doc.Value.col = The column, counting from 1.
doc.Node = One setting or block of the tree.
doc.Node.block = True for a block, false for a setting.
doc.Node.words = The words of the name, such as <code>error</code> and <code>page</code>.
doc.Node.labels = The strings written between the name and the colon of a block.
doc.Node.values = The values of a setting.
doc.Node.children = The numbers of the nodes inside a block.
doc.Node.line = The line where it starts.
doc.Node.col = The column where it starts.
doc.Doc = A parsed document: all the nodes and the first error.
doc.Doc.nodes = Every node; node 0 is the root.
doc.Doc.ok = True when the text parsed without an error.
doc.Doc.error = The message of the first error, empty when there is none.
doc.Doc.line = The line of the error.
doc.Doc.col = The column of the error.
doc.Parse = Parses text and returns the document; check <code>ok</code> before using it.
doc.Free = Frees the memory of a document.
doc.ErrorText = The first error as <code>file:line:column: message</code>, or an empty string when the document is valid. The first argument is the name to show for the file.
doc.Name = The name of a node: its words joined by single spaces.
doc.Root = The number of the root node, which is 0.
doc.Count = The number of children of a block.
doc.ChildAt = The node number of the child at a position, counting from 0.
doc.Find = The node number of the first child of a node with a given name, or -1.
doc.ValueText = The text of the value at a position of a setting.
