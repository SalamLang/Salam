pkg.intro <<
<p>This package binds <a href="https://www.raylib.com/">raylib</a> 5.5, a small library for 2D and 3D games and graphics programs. It opens a window with an OpenGL context, and gives drawing of shapes, textures, text and 3D models, keyboard, mouse, gamepad and touch input, and sound and music. The names are the ones of the raylib cheat sheet, so every raylib tutorial reads almost the same in Salam.</p>
<p>Use it for games, visual toys, tools with a custom picture and teaching programs. For forms and buttons use a layout or the <a href="/std/gui/webview/">webview</a> package, and for pictures that are only saved to a file the <a href="/std/image/">image</a> package needs no outside library.</p>
<h3>Things to know</h3>
<ul>
<li>Programs link against the raylib shared library (<code>libraylib</code>, version 5.5). Install it with your package manager or build it from source; if it is missing, the build fails at the link step.</li>
<li>Raylib passes <code>Color</code>, <code>Vector2</code>, <code>Rectangle</code>, <code>Camera3D</code> and the other structs by value. Salam passes them the way the C compiler of the platform does, on x86-64 (System V and Windows) and AArch64. The <code>--backend=native</code> compiler refuses such calls with a clear message; use the default backend.</li>
<li>Raylib works with 32-bit floats. Every function that takes a <code>f32</code> also has a version that takes <code>f64</code>, so <code>DrawCircle(400, 225, 50.0, Red())</code> works. Struct fields are <code>f32</code>; build vectors and rectangles with <code>Vec2</code>, <code>Vec3</code> and <code>Rect</code>.</li>
<li>Colors are functions: <code>Red()</code>, <code>RayWhite()</code>, <code>Blank()</code>. Build your own with <code>RGB</code> and <code>RGBA</code>.</li>
<li>Functions that change a value in place, such as <code>ImageResize</code> and <code>UpdateCamera</code>, take a variable and need it declared with <code>mut</code>.</li>
<li>Strings returned by raylib, such as <code>GetMonitorName</code>, belong to raylib: copy them if you keep them and never free them.</li>
<li>Everything you load (<code>LoadTexture</code>, <code>LoadSound</code>, <code>LoadModel</code>, ...) has an <code>Unload</code> call; raylib does not free it for you before the window closes.</li>
<li>The window needs a desktop session, so the examples on this page are only type-checked by the site.</li>
</ul>

<h2 id="guide-ball">A bouncing ball</h2>
<p>Every raylib program has the same shape: open a window, ask for a frame rate, then loop until <code>WindowShouldClose</code>, drawing between <code>BeginDrawing</code> and <code>EndDrawing</code>. <code>GetFrameTime</code> gives the seconds since the last frame, which keeps movement the same speed on every machine.</p>
{{example.gui-raylib-guide-ball}}

<h2 id="guide-input">Keyboard and collisions</h2>
<p><code>IsKeyDown</code> reports a key that is held, <code>IsKeyPressed</code> only the frame it went down. <code>CheckCollisionRecs</code> tests two rectangles, which is enough for many 2D games: try the move first and keep it only when it does not hit the wall.</p>
{{example.gui-raylib-guide-input}}

<h2 id="guide-3d">A 3D scene</h2>
<p>3D drawing sits between <code>BeginMode3D</code> and <code>EndMode3D</code> and uses a <code>Camera3D</code>. <code>UpdateCamera</code> with <code>CAMERA_ORBITAL</code> turns the camera around its target; it changes the camera, so declare it with <code>mut</code>.</p>
{{example.gui-raylib-guide-3d}}
