pkg.intro <<
<p>ClickHouse is a column oriented database for analytics: it scans billions of rows fast, and takes inserts in large batches. This package talks to it over its HTTP interface (port 8123, or 8443 with TLS) with <code>net.http</code>, so there is no driver library to install and no native protocol to speak. Results arrive as <code>JSONCompact</code>, with 64 bit integers quoted so that none of them loses digits.</p>
<p>Open a connection with <code>Open</code> or <code>OpenURL</code>, send statements with <code>Exec</code>, read rows with <code>Query</code>, and load many rows at once with a batch. Values go into the SQL through the argument functions, such as <code>StrArg</code> and <code>IntArg</code>, which escape them, or through ClickHouse's own typed <code>{name:Type}</code> placeholders. <code>AsDb</code> adapts a connection to the shared <a href="/std/db/">db</a> interface. A statement that fails behind a 200 status, because the server hit an exception while already streaming the reply, is caught too: it shows in <code>Error</code> and <code>Code</code> like any other failure.</p>
<p>The package does not speak the native TCP protocol or RowBinary, does not compress, and has no SQL dialect in <a href="/std/db/sql/">db/sql</a> yet. Each page section below is one part of the API, and each has a runnable example.</p>
<h2 id="guide-args">Put values into SQL safely</h2>
<p>Never build SQL by joining strings. Make each value with an argument function, which quotes and escapes it, and let <code>Bind</code> put the values into the <code>?</code> places in order. <code>Bind</code> does not run anything, so it is also a good way to see the final text. A <code>?</code> inside quotes or a comment is not a place, and when the number of values differs from the number of places the result is empty.</p>
{{example.db-clickhouse-guide-args}}
<p>The quote in <code>o'brien</code> is escaped for you. Table and column names are not values, so they go through <code>QuoteIdent</code>. <code>Exec</code> and <code>Query</code> do the same binding when you give them the values.</p>

<h2 id="guide-connect">Connect and create a table</h2>
<p>Start from <code>DefaultOptions</code> (a server on this machine, user <code>default</code>) and change what differs. <code>Open</code> sends nothing yet, so call <code>Ping</code> to see whether the server answers. <code>Exec</code> runs a statement that returns no rows and gives true on success; on failure <code>Error</code> and <code>Code</code> say why.</p>
{{example.db-clickhouse-guide-connect}}
<p>The table uses the <code>MergeTree</code> engine, the usual one, and its <code>ORDER BY</code> is the sort key that makes queries on day and page fast. ClickHouse has no auto increment key and no transactions to wait for; a statement is done when <code>Exec</code> returns.</p>

<h2 id="guide-insert">Insert in batches</h2>
<p>ClickHouse likes a few large inserts, not many small ones. <code>PrepareBatch</code> takes the <code>INSERT INTO table (columns)</code> part, <code>Append</code> adds one row of ready SQL values, and <code>SendBatch</code> sends all the rows in one request. <code>Append</code> returns false if the row has a different number of values than there are columns.</p>
{{example.db-clickhouse-guide-insert}}
<p>Hundreds or thousands of rows per batch is a good size to start with. A batch with no rows, or one that already has an error, is not sent.</p>

<h2 id="guide-query">Read the rows back</h2>
<p><code>Query</code> returns a <code>Rows</code>. Check <code>Ok</code>, then call <code>Next</code> in a loop and read the current row by column number with <code>Text</code>, <code>Int64</code> and the other readers; <code>Close</code> it when done. The loop is <code>until rows.Next():</code> because <code>until</code> runs while its condition is true. For a value that comes from outside, the typed placeholders <code>{name:Type}</code> of <code>QueryParams</code> let the server check the type.</p>
{{example.db-clickhouse-guide-query}}
<p>An aggregate such as <code>sum(hits)</code> is a 64 bit integer in ClickHouse, which arrives quoted in the JSON and is read back without losing digits by <code>Int64</code>.</p>
>>

doc.Options = How to reach the server.
doc.Options.addr = Host and port, <code>host:port</code>; a leading <code>http://</code> or <code>https://</code> is accepted. The port defaults to 8123, or 8443 when secure.
doc.Options.database = The database every statement runs in; empty means the user's default.
doc.Options.username = The user name, sent as <code>X-ClickHouse-User</code>. The default is <code>default</code>.
doc.Options.password = The password, sent as <code>X-ClickHouse-Key</code>.
doc.Options.secure = Use HTTPS.
doc.Options.timeout_ms = How long a request may take, in milliseconds.
doc.Options.settings = ClickHouse settings sent with every request, such as <code>max_threads</code>.
doc.Options.headers = Extra HTTP headers for every request.
doc.Conn = A connection to a ClickHouse server over its HTTP interface. Each call is one HTTP request, so there is nothing to keep alive. After a failed call <code>Ok</code> is false and <code>Error</code> and <code>Code</code> say why; the next call clears them.
doc.Conn.opts = The options the connection was opened with.
doc.Conn.base = The base URL, such as <code>http://127.0.0.1:8123</code>.
doc.Conn.connected = False after <code>Close</code> or when the address was invalid.
doc.Conn.status = The HTTP status of the last reply; 0 when no reply arrived.
doc.Conn.err = The last error text.
doc.Conn.code = The ClickHouse exception code of the last failure, 0 if none.
doc.Conn.query_id = The query id the server gave the last request.
doc.Conn.read_rows = Rows the last request read, from the server's summary header.
doc.Conn.written_rows = Rows the last request wrote, from the server's summary header.
doc.Conn.Ok = True when the connection is open and the last call did not fail.
doc.Conn.Error = The last error text; empty when the last call worked. A failure that the server reported partway through a reply is caught too, even though the status was 200.
doc.Conn.Code = The ClickHouse exception code of the last failure, read from the <code>X-ClickHouse-Exception-Code</code> header or the <code>Code: N</code> text of the body.
doc.Conn.Close = Closes the connection; later calls fail with an error.
doc.Conn.Ping = Asks <code>/ping</code>; true when the server answers.
doc.Conn.Exec = Runs a statement that returns no rows. Each <code>?</code> is replaced by the next value of <code>args</code>, built with <code>StrArg</code>, <code>IntArg</code> and the other argument functions. Question marks inside quotes and comments are left alone.
doc.Conn.ExecParams = Runs a statement with ClickHouse's own typed placeholders, <code>{name:Type}</code>, sent as <code>param_name</code> query parameters.
doc.Conn.ExecWith = Like <code>Exec</code>, with ClickHouse settings for this call only, added to those in the options.
doc.Conn.ExecFull = Runs a statement with both typed parameters and per-call settings.
doc.Conn.Query = Runs a query and returns its rows, with <code>?</code> placeholders as in <code>Exec</code>. Check <code>Ok</code> on the result, and call <code>Close</code> when done.
doc.Conn.QueryParams = Runs a query with typed <code>{name:Type}</code> placeholders.
doc.Conn.QueryWith = Like <code>Query</code>, with settings for this call only.
doc.Conn.QueryRow = Runs a query and returns the first row as text values; an empty vector when there is no row or the query failed.
doc.Conn.QueryFull = Runs a query with typed parameters and per-call settings.
doc.Conn.QueryText = The first column of the first row as text; empty when there is none.
doc.Conn.QueryInt = The first column of the first row as a 64 bit integer; 0 when there is none.
doc.Conn.ServerVersion = The server version, from <code>SELECT version()</code>.
doc.Conn.PrepareBatch = Starts a batch insert from <code>INSERT INTO table (columns)</code>; a trailing <code>VALUES</code> or semicolon is dropped. Anything else gives a batch whose <code>Error</code> says why.
doc.Conn.SendBatch = Sends every row of the batch as one <code>INSERT</code>; false when the batch is empty or broken, or the server refused it.
doc.Rows = The result of a query: column names and types, and the rows as JSON. Move with <code>Next</code>, then read the current row by column number or name.
doc.Rows.names = The column names.
doc.Rows.types = The column types as ClickHouse writes them, such as <code>Nullable(String)</code>.
doc.Rows.rows = Every row, each as JSON text.
doc.Rows.cells = The values of the current row as JSON text.
doc.Rows.pos = The index of the current row; -1 before the first <code>Next</code>.
doc.Rows.total = The row count the server reported.
doc.Rows.err = The error text; empty when the query worked.
doc.Rows.Ok = True when the query worked.
doc.Rows.Error = The error text.
doc.Rows.Next = Moves to the next row; false when there are no more.
doc.Rows.RowCount = The number of rows.
doc.Rows.ColumnCount = The number of columns.
doc.Rows.ColumnName = The name of a column, by number.
doc.Rows.ColumnType = The ClickHouse type of a column, by number.
doc.Rows.ColumnKind = The <code>KIND_...</code> group of a column's type.
doc.Rows.ColumnIndex = The number of the column with this name, or -1.
doc.Rows.Raw = The value of the current row as JSON text.
doc.Rows.IsNull = The value is <code>NULL</code>.
doc.Rows.Text = The value as text, without the JSON quotes.
doc.Rows.Int64 = The value as a 64 bit integer. ClickHouse sends 64 bit numbers as strings and this reads them without loss.
doc.Rows.Int = The value as a 32 bit integer.
doc.Rows.UInt64 = The value as an unsigned 64 bit integer.
doc.Rows.Float = The value as a float; <code>nan</code> and <code>inf</code> are understood.
doc.Rows.Bool = The value as a bool.
doc.Rows.List = An array value as a vector of text items.
doc.Rows.TextBy = Like <code>Text</code>, by column name.
doc.Rows.Int64By = Like <code>Int64</code>, by column name.
doc.Rows.FloatBy = Like <code>Float</code>, by column name.
doc.Rows.Row = The whole current row as a vector of text values.
doc.Rows.Close = Frees the rows.
doc.Batch = Rows collected for one insert. Build each row from the argument functions, <code>Append</code> it, then send the batch with <code>SendBatch</code>.
doc.Batch.head = The <code>INSERT INTO table (columns)</code> part.
doc.Batch.width = The number of columns the insert names; 0 when it names none.
doc.Batch.rows = The rows added so far, each already formatted as SQL.
doc.Batch.err = The error text; empty when the batch is fine.
doc.Batch.Append = Adds a row of SQL values; false, with <code>Error</code> set, when the count differs from the number of columns.
doc.Batch.Len = The number of rows added.
doc.Batch.Error = The error text.
doc.Batch.Abort = Throws the rows away and clears the error.
doc.StrArg = A string as a quoted SQL literal, with quotes, backslashes and line breaks escaped.
doc.QuoteIdent = A table or column name in backticks.
doc.IntArg = A signed integer as a SQL literal.
doc.UIntArg = An unsigned integer as a SQL literal.
doc.FloatArg = A float as a SQL literal; <code>nan</code>, <code>inf</code> and <code>-inf</code> are written as ClickHouse reads them.
doc.BoolArg = A bool as <code>true</code> or <code>false</code>.
doc.NullArg = The literal <code>NULL</code>.
doc.RawArg = SQL text passed through unchanged, such as <code>now()</code>. Never use it with user input.
doc.ArrayArg = An array literal from items that are already SQL literals.
doc.TupleArg = A tuple literal from items that are already SQL literals.
doc.MapArg = A <code>map(...)</code> literal from keys and values that are already SQL literals; the shorter list decides the size.
doc.Args = Returns the vector unchanged; it only makes a call site read as a list of arguments.
doc.Bind = Puts the values into the <code>?</code> places of the SQL and returns the text, without running it. Empty when the counts differ.
doc.BaseType = The type with <code>Nullable(...)</code> and <code>LowCardinality(...)</code> taken off.
doc.IsNullableType = The type is <code>Nullable</code>, possibly inside <code>LowCardinality</code>.
doc.TypeKind = The <code>KIND_...</code> group of a type.
doc.ElementType = The element type of an <code>Array(...)</code>; empty for anything else.
doc.DefaultOptions = Options for a server on this machine: <code>localhost:8123</code>, user <code>default</code>, no password.
doc.Open = Makes a connection from the options. Nothing is sent yet; <code>Ping</code> checks that the server is there.
doc.OpenURL = Makes a connection from an address like <code>clickhouse://user:pass@host:8123/db?secure=true&amp;max_threads=4</code>. <code>clickhouses://</code>, <code>http://</code> and <code>https://</code> also work. <code>database</code>, <code>username</code>, <code>password</code>, <code>secure</code> and <code>timeout</code> set options; any other key becomes a ClickHouse setting.
doc.AsDb = Wraps a connection as a <code>dyn db.Connection</code>, so code written against the shared <a href="/std/db/">db</a> interface runs on ClickHouse too. <code>Exec</code> returns 0 or -1, <code>Changes</code> is the rows the last request wrote, <code>LastInsertId</code> is always 0, and a transaction runs each statement at once: ClickHouse has none, so <code>Commit</code> returns 0 and <code>Rollback</code> returns -1.
