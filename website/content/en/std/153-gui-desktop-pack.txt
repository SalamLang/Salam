pkg.en = gui/desktop/pack
pkg.name = gui/desktop/pack
pkg.group = Web and browser
pkg.summary = The file format that holds an application's web files.
pkg.title = The gui/desktop/pack package in Salam | Bundled web files
pkg.description = The gui/desktop/pack package in Salam: pack a folder of web files into a compressed file, add it to an executable and read it back.
pkg.import = gui.desktop.pack
pkg.intro <<
<p>This is the file format behind the files of a <a href="/std/gui/desktop/"><code>desktop</code></a> application: a compressed and scrambled set of files, read from the end of an executable or from a file of its own. You rarely call it directly, because <code>salam bundle</code> does the packing and <code>desktop</code> does the reading. Scrambling keeps names and contents out of sight; it is not encryption.</p>
>>

doc.Blob = Bytes read from a pack. The caller owns them.
doc.Blob.data = A pointer to the bytes.
doc.Blob.size = The number of bytes.
doc.Pack = An opened pack.
doc.Pack.path = The file it was read from.
doc.Pack.key = The key it was opened with.
doc.Pack.Count = How many files it holds.
doc.Pack.Read = Reads one file. <code>data</code> is null when it is not there.
doc.ReadRange = Reads part of a file into new memory, or null.
doc.Open = Opens a pack found at the end of a file.
doc.PackDir = Packs a folder. Returns the file count, or -1.
doc.AppendPack = Adds a pack to the end of an executable.
