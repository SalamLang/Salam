pkg.intro <<
<p>Some programs behave differently when they are not on a terminal: a shell shows no prompt, a REPL does not echo or edit the line, <code>stty</code> has no size to report. The <code>os.pty</code> package starts a program attached to a pseudo terminal, a pair of devices that look like a real terminal to the program, and gives you the other end. What you write is typed keys; what you read is what a person would see on the screen, including the characters the terminal echoes back.</p>
<p><code>Open</code> takes the same <code>Command</code> as <a href="/std/os/process/">os.process</code> (program, arguments, folder and environment; the stream modes do not apply, because all three streams are the terminal) and returns the same <code>Child</code>. So <code>Write</code>, <code>ReadUntil</code>, <code>ReadFor</code>, <code>ReadAvailable</code>, <code>Wait</code>, <code>Kill</code> and <code>Close</code> work as described there. Two things differ: output and error output arrive mixed in one stream, and <code>CloseStdin</code> sends Ctrl-D, the end-of-input key, because closing the terminal would hang the program up.</p>
<p>What people get wrong:</p>
<ul>
<li>Sending <code>\n</code> for Enter. A terminal sends <code>\r</code> when Enter is pressed and the line discipline turns it into a newline for programs that read lines, so type <code>\r</code>. A program in raw mode sees the <code>\r</code> itself.</li>
<li>Expecting <code>\n</code> in the output. The terminal turns each newline into <code>\r\n</code>, so look for <code>\r\n</code> when waiting for a line end.</li>
<li>Reading without a time limit. Use <code>ReadUntil</code> with a prompt and a number of milliseconds, and check <code>timed_out</code>, so a program that never prints the prompt cannot hang yours.</li>
<li>Forgetting that your own typing is echoed. After <code>Write</code> the first thing to come back is the echo of what you typed.</li>
<li>Setting <code>TERM</code>. Programs that draw on the screen read it; put it in the command with <code>Env("TERM", "xterm")</code>.</li>
</ul>
<div class="note"><p>This package works on Linux, macOS and the BSDs. On Windows <code>Supported</code> returns false and <code>Open</code> returns a child whose <code>ok</code> is false.</p></div>
<h2 id="guide-open">Open a terminal and type into it</h2>
<p>Start the program with <code>Open</code> and the window size in rows and columns (0 means 24 by 80). Writing the text of a key press, with <code>\r</code> for Enter, reaches the program as input; reading returns the terminal echo first and then the program's answer. Calling <code>CloseStdin</code> ends the input of a program such as <code>cat</code>.</p>
{{example.os-pty-guide-open}}

<h2 id="guide-prompt">Wait for a prompt</h2>
<p>An interactive program prints a prompt and then waits. <code>ReadUntil</code> returns as soon as the prompt text has arrived, or reports <code>timed_out</code> after the time you gave. That is the loop of every terminal test: wait for the prompt, type a line, wait for the answer.</p>
{{example.os-pty-guide-prompt}}

<h2 id="guide-resize">Change the window size</h2>
<p><code>Resize</code> sets the size of the terminal and the system tells the program, which is how a full-screen program learns to redraw. <code>GetSize</code> reads the size back. The program sees the new size the next time it asks, for example through <code>stty size</code>.</p>
{{example.os-pty-guide-resize}}

doc.Size = The size of a terminal window in character cells.
doc.Size.rows = The number of rows.
doc.Size.cols = The number of columns.
doc.Supported = True where pseudo terminals exist: Linux, macOS and the BSDs. False on Windows.
doc.Open = Starts the command on a new pseudo terminal of the given rows and columns (0 for 24 by 80) and returns a <code>Child</code> whose reads and writes go through the terminal. The child gets its own session with the terminal as its controlling terminal. When the program cannot be found or started, <code>ok</code> is false and <code>error</code> says why.
doc.Resize = Sets the size of the terminal; the program is told about the change. False when the child has no terminal.
doc.GetSize = Reads the size of the terminal; zero rows and columns when it cannot be read.
