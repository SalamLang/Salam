pkg.intro <<
<p>The <code>rand</code> package makes everyday random values: a number in a range, a chance, a pick from a list, a shuffled order, a readable code and a UUID. Use it for games, simulations, sample data, load tests and identifiers that only need to be unique. For anything an attacker must not guess, use <a href="/std/crypto/">crypto</a>; to summarise the numbers you drew (mean, spread, median), use <a href="/std/stats/">stats</a>.</p>
<p>All functions share one generator: a 64-bit linear congruential generator (the state step of PCG, without its output permutation). It seeds itself from the clock the first time you use it, so a plain program already gets different numbers on each run. Two things change that:</p>
<ul>
<li><code>Seed(n)</code> starts from a fixed number, and the same seed always gives the same sequence. That is what a test or a reproducible simulation wants.</li>
<li><code>SeedAuto</code> reseeds from <code>time.Now()</code>, which counts whole seconds. Two programs started in the same second get the same numbers, so do not rely on it to give parallel workers different streams; seed each one with its own number instead.</li>
</ul>
<p>What people get wrong most often:</p>
<ul>
<li>Using it for secrets. The next value follows from the previous ones, and the state is seeded from a clock in seconds. Session tokens, reset links and API keys belong to <a href="/std/crypto/">crypto</a>.</li>
<li>Calling it on an empty input or a zero bound. <code>IntN(0)</code> and the <code>Choice</code> functions on an empty vector stop the program with <code>modulo by zero</code>.</li>
<li>Treating text as letters. <code>TextFrom</code> and <code>ChoiceChar</code> pick bytes, so a Persian alphabet comes out as broken characters.</li>
</ul>
<div class="note"><p>The generator is one global value with no lock. Threads that draw at the same time can get the same number; draw in one thread, or give each thread its own seeded run.</p></div>
<p>The examples on this page print properties of the values, such as whether they fall in a range, rather than the values themselves, so the output is the same on every run.</p>

<h2 id="guide-tests">Repeatable runs for tests</h2>
<p>A random program is hard to test because its output changes. <code>Seed</code> fixes the starting point, so the same seed always produces the same sequence. Seed once at the start of a test and compare the results with what you expect. Leave the seed out of the real program, which then seeds itself from the clock. A fixed seed only repeats on the same version of Salam, so compare properties or a whole run, not numbers copied from an old release.</p>
{{example.rand-guide-tests}}

<h2 id="guide-simulation">Dice and simulations</h2>
<p><code>Int32Range</code> gives a whole number with both ends included, which is exactly a die. <code>Float</code> gives a value from zero up to one, the building block of a Monte Carlo estimate: here, the share of random points that land inside a quarter circle gives an approximation of pi. With enough samples each face comes up close to one sixth of the time.</p>
{{example.rand-guide-simulation}}

<h2 id="guide-draw">Raffles and weighted picks</h2>
<p>To pick several different winners, shuffle a copy with <code>ShuffleStr</code> and take the first few; the original vector stays as it was. For a weighted choice, such as loot that is common 80% of the time, draw a number in the range of the total weight and walk through the weights until it runs out.</p>
{{example.rand-guide-draw}}

<h2 id="guide-codes">Coupon codes, PINs and IDs</h2>
<p><code>TextFrom</code> builds text from your own alphabet. Leaving out characters that look alike, such as <code>0</code> and <code>O</code> or <code>1</code> and <code>I</code>, makes a code people can read out loud. <code>Digit</code> keeps leading zeros, which a number from <code>IntWithLength</code> cannot, and <code>UUID</code> makes a version 4 identifier.</p>
{{example.rand-guide-codes}}
<p>These values are fine for coupons, test data and file names, but anyone who sees a few of them could predict the next. For a password reset link, an API key or a session token, use <code>crypto.RandomToken</code> or <code>crypto.RandomHex</code> from <a href="/std/crypto/">crypto</a>.</p>

<h2 id="guide-safe">Pitfalls</h2>
<p>A few cases need a guard of your own:</p>
<ul>
<li><code>ChoiceStr</code>, <code>ChoiceInt</code>, <code>ChoiceChar</code> and <code>IntN</code> divide by the length or by <code>n</code>, so an empty input or a zero stops the program with <code>modulo by zero</code>. Check <code>len()</code> first.</li>
<li><code>IntRange</code> and <code>Int32Range</code> need <code>lo</code> to be no larger than <code>hi</code>. With the bounds reversed they do not fail; they return numbers outside the range. When the bounds come from a user, order them with <code>math.MinI64</code> and <code>math.MaxI64</code>.</li>
<li><code>IntWithLength(1)</code> can return 0, and more than 18 digits overflows. For a code of a fixed width, <code>Digit</code> is the safer choice.</li>
<li><code>ChoiceChar</code> and <code>TextFrom</code> work on bytes, and a Persian letter takes two bytes in UTF-8. Put whole letters in a vector and use <code>ChoiceStr</code> or <code>ShuffleStr</code> instead.</li>
<li><code>Bytes</code> never returns a zero byte, because a <code>str</code> ends at the first one. Its bytes are 1 to 255, which is fine for filler data and wrong for keys.</li>
</ul>

doc.Seed = Starts the generator from a fixed number. With the same seed the sequence of numbers is always the same.
doc.SeedAuto = Reseeds the generator from <code>time.Now()</code>, in whole seconds. The generator does this by itself on first use, so call it only to start over after a <code>Seed</code>.
doc.Int = A random whole number from 0 to 2<sup>63</sup>-1; it is never negative. For a number in a particular range, <code>IntRange</code> is simpler.
doc.Int32 = A random whole number from 0 to 2<sup>31</sup>-1; it is never negative.
doc.IntN = A random number from zero to one less than <code>n</code>. <code>n</code> must be positive; 0 stops the program.
doc.IntRange = A random number from <code>lo</code> to <code>hi</code>, both included. <code>lo</code> must not be larger than <code>hi</code>.
doc.Int32Range = Like <code>IntRange</code> with a 32-bit result; for a die, 1 to 6.
doc.IntWithLength = A random number with exactly <code>digits</code> digits, such as 1000 to 9999 for 4. For 1 (or less) it returns 0 to 9, and above 18 it overflows.
doc.Float = A random decimal number from zero up to, but not including, one.
doc.FloatRange = A random decimal number from <code>lo</code> up to, but not including, <code>hi</code>.
doc.Bool = True or false, each with probability one half.
doc.BoolP = Returns true with probability <code>p</code>, between zero and one.
doc.Bytes = <code>n</code> random bytes from 1 to 255 as a <code>str</code>; a zero byte never appears, because it would end the string. Not for keys.
doc.TextFrom = Builds text of <code>n</code> bytes, each picked from the bytes of <code>charset</code>. Use an ASCII charset; a multi-byte letter would be split. Empty <code>charset</code> or <code>n</code> of 0 gives empty text.
doc.Alpha = Text of lower case English letters.
doc.AlphaUpper = Text of upper case English letters.
doc.AlphaMixed = Text of upper and lower case English letters.
doc.Digit = Text of digits only, for a one-time code.
doc.Alnum = Text of English letters and digits.
doc.Text = Text of English letters, digits and punctuation such as <code>!@#$</code>, for generating a test password.
doc.HexBytes = <code>n</code> random bytes as hexadecimal text, two characters per byte.
doc.Hash = A random 32-character hexadecimal string (16 bytes). It is not a hash of anything; the name only describes the shape.
doc.Hash160 = A random 40-character hexadecimal string, 160 bits.
doc.Hash256 = A random 64-character hexadecimal string, 256 bits.
doc.UUID = Builds a random version 4 UUID in lower case, of the form <code>xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx</code> where <code>y</code> is 8, 9, a or b.
doc.ChoiceStr = Returns a random element of a vector of strings. An empty vector stops the program.
doc.ChoiceInt = Returns a random element of a vector of numbers. An empty vector stops the program.
doc.ChoiceChar = Returns one random byte of a string as a one-byte string. Only right for ASCII text.
doc.ShuffleStr = Returns a shuffled copy of a vector of strings (a Fisher-Yates shuffle), leaving the vector itself alone. Free the copy when done.
doc.ShuffleInt = Returns a shuffled copy of a vector of numbers, leaving the vector itself alone.
