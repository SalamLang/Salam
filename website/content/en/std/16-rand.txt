pkg.intro <<
<p>The <code>rand</code> package is for games, simulations, sample data and generating identifiers. Call <code>SeedAuto</code> once before anything else, so that each run of the program gets different numbers. If you want the same result every time, in a test for instance, call <code>Seed</code> with a fixed number instead.</p>
<div class="note"><p>This package is not built for cryptography. For keys, session tokens and passwords, use the crypto package.</p></div>
<p>The examples on this page print properties of the values, such as whether they fall in a range, rather than the values themselves, because a random number differs on every run.</p>
>>

doc.Seed = Starts the generator from a fixed number. With the same seed the sequence of numbers is always the same.
doc.SeedAuto = Starts the generator from the current time, so that every run gets different numbers.
doc.Int = A random 64-bit whole number. For a number in a particular range, <code>IntRange</code> is simpler.
doc.Int32 = A random 32-bit whole number.
doc.IntN = A random number from zero to one less than <code>n</code>.
doc.IntRange = A random number from <code>lo</code> to <code>hi</code>, both included.
doc.Int32Range = Like <code>IntRange</code> with a 32-bit result; for a die, 1 to 6.
doc.IntWithLength = A random number with exactly <code>digits</code> digits, which suits SMS confirmation codes.
doc.Float = A random decimal number from zero up to, but not including, one.
doc.FloatRange = A random decimal number from <code>lo</code> up to, but not including, <code>hi</code>.
doc.Bool = True or false, each with probability one half.
doc.BoolP = Returns true with probability <code>p</code>, between zero and one.
doc.Bytes = <code>n</code> random bytes.
doc.TextFrom = Builds text of length <code>n</code> from the characters in <code>charset</code>.
doc.Alpha = Text of lower case English letters.
doc.AlphaUpper = Text of upper case English letters.
doc.AlphaMixed = Text of upper and lower case English letters.
doc.Digit = Text of digits only, for a one-time code.
doc.Alnum = Text of English letters and digits.
doc.Text = Text of English letters, digits and punctuation such as <code>!@#$</code>, for generating a test password.
doc.HexBytes = <code>n</code> random bytes as hexadecimal text, two characters per byte.
doc.Hash = A random 32-character hexadecimal string.
doc.Hash160 = A random 40-character hexadecimal string, 160 bits.
doc.Hash256 = A random 64-character hexadecimal string, 256 bits.
doc.UUID = Builds a version 4 unique identifier of the form <code>xxxxxxxx-xxxx-4xxx-...</code>.
doc.ChoiceStr = Returns a random element of a vector of strings.
doc.ChoiceInt = Returns a random element of a vector of numbers.
doc.ChoiceChar = Returns a random character from a string.
doc.ShuffleStr = Returns a shuffled copy of a vector of strings, leaving the vector itself alone.
doc.ShuffleInt = Returns a shuffled copy of a vector of numbers.
