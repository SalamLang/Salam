pkg.intro <<
<p>Ordinary DNS asks "what is the address of this name?" in plain text over UDP, so the network between you and the resolver can read every name you look up, and can change or block the answer. DNS over HTTPS (DoH) and DNS over TLS (DoT) send the same question inside an encrypted connection. This package speaks both, and plain UDP DNS too, and adds what a program needs on top: a <code>Resolver</code> that tries a list of servers in order, remembers answers for their TTL and answers <code>LookupHost</code> with a list of addresses. A <code>Stub</code> turns the resolver into a small local DNS server, so other programs can use it by pointing their DNS at it. To see how the pieces fit together in an app, read <a href="/std/net/tunnel/#guide-vpn-app">Building a v2ray style or VPN app</a>.</p>
<p>Core ideas:</p>
<ul>
<li>A <code>Server</code> says how to reach one DNS server: <code>KindDoH</code> (HTTPS POST), <code>KindDoHGet</code> (HTTPS GET), <code>KindDoT</code> (TLS on port 853) or <code>KindUDP</code> (plain). <code>Cloudflare</code>, <code>Google</code>, <code>Quad9</code> and their DoT forms are ready made, and <code>NewServer</code>, <code>NewDoT</code> and <code>NewPlain</code> make your own.</li>
<li>Give a server its IP addresses in <code>addrs</code>. Then the program does not need to resolve the server's own name first, which matters when DNS is exactly what is blocked.</li>
<li><code>Query</code> asks one server once. <code>NewResolver</code> and <code>Resolve</code> ask a list: a server that fails, times out or answers SERVFAIL or REFUSED is skipped for the next, and answers are cached (an answer for its TTL, kept between the limits of <code>SetTTLLimits</code>; a "no such name" answer for a short fixed time).</li>
<li>Certificates are checked. <code>insecure</code> turns that off for tests only.</li>
</ul>
<p>Things that catch people out:</p>
<ul>
<li><strong>Encrypted DNS hides the question from the network, not from the resolver.</strong> The resolver you pick sees every name you look up. Choose one you trust, and remember that connecting to a well known resolver address is itself visible.</li>
<li><strong>Blocked resolvers.</strong> A network can block the addresses of public DoH servers. Use several servers, keep a plain or private one as the last in the list, and see <code>IranPlainServers</code> for the plain servers used in Iran. Plain DNS is readable and can be changed on the way.</li>
<li><strong>No DNSSEC.</strong> Answers are trusted as the server gave them; nothing here checks DNSSEC signatures.</li>
<li><strong>The stub answers on UDP and TCP</strong> (the same port, TCP with the two byte length prefix) and has no access control. It listens on <code>127.0.0.1</code> when the host is empty; give <code>0.0.0.0</code> only on purpose, because an open DNS server on a public address is abused.</li>
<li><strong>Free what you hold.</strong> <code>FreeResponse</code>, <code>FreeAnswer</code> and <code>FreeServers</code> release memory; a <code>Resolver</code> and a <code>Stub</code> live until the program ends.</li>
<li><strong>The cache and counters are shared across threads</strong> and the resolver takes its own lock, so one resolver can serve many threads.</li>
<li><strong>IPv6 resolvers work.</strong> A server address may be an IPv6 literal, over UDP, TLS or HTTPS. The built-in servers list IPv4 first; <code>WithIPv6</code>, <code>Cloudflare6</code>, <code>Google6</code> and <code>Quad96</code> add or use the IPv6 addresses (<code>2606:4700:4700::1111</code>, <code>2001:4860:4860::8888</code>, <code>2620:fe::fe</code>). The local stub can listen on <code>::1</code> or <code>::</code>.</li>
<li><strong>Connections are reused.</strong> DoH over HTTPS keeps its connections alive and reuses them for later queries (up to 8 idle ones, for 30 seconds); a stale one is replaced by a new connection and the query is repeated once. <code>ReusedConnections</code> counts the reuses and <code>CloseIdleConnections</code> closes the idle ones.</li>
<li><strong>Iran presets are unverified.</strong> The addresses of <code>Shecan</code>, <code>Server403</code>, <code>Electro</code>, <code>Radar</code> and <code>Begzar</code> come from community lists and could not be confirmed against the official sites of those services. Check them before relying on them.</li>
</ul>

<h2 id="guide-resolver">Using a resolver</h2>
<p>Make a <code>Resolver</code> from a list of servers and ask it. The second lookup of the same name comes from the cache and does not touch the network. The example uses a tiny DNS server on loopback so that it runs anywhere; with real servers use <code>DefaultServers</code> or your own list.</p>
{{example.net-doh-guide-resolver}}
<p>For real use, put your servers in the order you trust them and give each one its addresses:</p>
<pre class="code"><code>mut servers := Vector {} as Vector&lt;doh.Server&gt;
servers.push(doh.Cloudflare())
servers.push(doh.GoogleDoT())
servers.push(doh.NewPlain("home", "192.168.1.1"))
resolver := doh.NewResolver(servers)
println doh.LookupHost(resolver, "example.com")</code></pre>

<h2 id="guide-iran">DNS when networks interfere</h2>
<p>Three kinds of trouble are common. The network can <em>read</em> your lookups: use DoH or DoT. It can <em>change</em> answers for some names, or return nothing: encrypted DNS stops changes on the path, but not a block of the resolver's address. It can <em>block the resolvers themselves</em>: list several, keep <code>addrs</code> filled so that no lookup is needed to reach them, and keep a plain server that works in your network as the last choice. <code>IranPlainServers</code> lists plain servers used in Iran; their traffic is not encrypted.</p>
<p>Run a <code>Stub</code> on <code>127.0.0.1</code> and point the operating system or a program at it, and every lookup it makes goes through your resolver and its cache. When a program does name lookups itself through a proxy, as SOCKS5 and Trojan do, let the proxy resolve the name, so that the lookup is not made locally at all.</p>

<h2 id="guide-limits">What to know</h2>
<ul>
<li>Encrypted DNS hides the question from the network, not from the resolver you choose.</li>
<li>Fill <code>addrs</code>, or set a bootstrap with <code>SetBootstrap</code>, so that the resolver does not need DNS to find its DNS.</li>
<li>Failed servers are skipped; a "no such name" answer is final and cached for the short failure time.</li>
<li>No DNSSEC validation. The stub has no access control; bind it to loopback.</li>
<li><code>Query</code> has a timeout in milliseconds, and a <code>Resolver</code> has <code>SetTimeout</code>; keep it short enough that a blocked server does not stall your program.</li>
<li>No logging happens by itself.</li>
</ul>
>>

doc.Response = The answer of one <code>Query</code>: the raw DNS message, the decoded message, how long it took and which server gave it.

doc.Response.err = A readable reason when <code>ok</code> is false, such as <code>id mismatch</code> or a connection error.
doc.QueryAddr = Sends one query to one address of a server and waits up to the timeout. Use it when you already know which IP to ask.
doc.Query = Sends one query to a server, trying each of its <code>addrs</code> in turn, or resolving its host name when it has none. <code>QueryAddr</code> does one address.
doc.FreeResponse = Frees the raw bytes of a response.
doc.KindDoH = <code>kind</code>: DNS over HTTPS with a POST request. The default.
doc.KindDoHGet = <code>kind</code>: DNS over HTTPS with a GET request, the query in the URL.
doc.KindDoT = <code>kind</code>: DNS over TLS on port 853.
doc.KindUDP = <code>kind</code>: ordinary DNS over UDP on port 53. Not encrypted.
doc.Server = One DNS server and how to talk to it: the protocol, where it is and which addresses to try first. The preset functions and <code>NewServer</code>, <code>NewDoT</code> and <code>NewPlain</code> make them.
doc.Server.name = A short name for logs and for <code>server</code>.
doc.Server.kind = <code>KindDoH</code>, <code>KindDoHGet</code>, <code>KindDoT</code> or <code>KindUDP</code>.
doc.Server.url = The URL of a DoH endpoint, such as <code>https://dns.google/dns-query</code>.
doc.Server.host = The host name (for the TLS name and the <code>Host</code> header) or the IP.
doc.Server.port = The port: 443 for DoH, 853 for DoT, 53 for plain DNS.
doc.Server.path = The request path of a DoH endpoint.
doc.Server.use_tls = True when the server uses TLS. It is true for DoH over <code>https</code> and for DoT.
doc.Server.addrs = IP addresses to connect to, so that the server's own name does not have to be looked up first. This is what makes an encrypted resolver work when DNS is the thing that is blocked.

doc.Url.use_tls = True for <code>https</code>, false for <code>http</code>.
doc.Url.host = The host.
doc.Url.port = The port, or 443 or 80 when the URL has none.
doc.Url.path = The path with the query, at least <code>/</code>.

doc.ParseIPv6 = Parses IPv6 text into sixteen bytes appended to a buffer. False when it is not an address.
doc.IsIP = True when the text is an IPv4 or IPv6 address and not a name.
doc.ParseURL = Parses an <code>http://</code> or <code>https://</code> URL.

doc.WithBootstrap = Returns a copy of a server with one more IP address to try.

doc.Stats = Returns the counters of a resolver.
doc.CacheSize = The number of entries in the cache.
doc.ClearCache = Throws away every cached answer.
doc.ResolveAt = Like <code>Resolve</code> but with the clock given in milliseconds, so the cache can be tested without waiting.
doc.Resolve = Answers a question from the cache, or asks the servers in order and caches the result. A server that fails, times out or answers SERVFAIL or REFUSED is skipped for the next one; a 'no such name' answer is final and cached for a short time.
doc.FreeAnswer = Frees the raw bytes of an answer.
doc.LookupA = Returns the IPv4 addresses of a name as text. Empty when there are none.
doc.LookupAAAA = Returns the IPv6 addresses of a name as text.
doc.LookupTXT = Returns the TXT records of a name.
doc.LookupCNAME = Returns the canonical name a name points to, or an empty text.
doc.LookupHost = Returns the addresses of a name, IPv4 then IPv6. A name that is already an IP comes back as itself without asking anyone.

doc.Stub.port = The UDP port it listens on, useful when you asked for 0.
doc.Stub.st = The internal state.
doc.StartStub = Starts the local DNS server on a host and port (0 picks a free port), answering on UDP and on TCP, on background threads. An empty host means <code>127.0.0.1</code>. Check <code>ok</code>, and <code>tcp_ok</code> for the TCP side.
doc.StubServed = How many queries the stub has answered.
doc.StopStub = Stops the local DNS server.
