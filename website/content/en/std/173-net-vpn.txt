pkg.intro <<
<p>This package joins <a href="/std/net/tunnel/">net.tunnel</a> to every protocol package: <a href="/std/net/socks/">socks</a>, <a href="/std/net/httpproxy/">http</a>, <a href="/std/net/trojan/">trojan</a>, <a href="/std/net/vless/">vless</a>, <a href="/std/net/vmess/">vmess</a> and <a href="/std/net/shadowsocks/">shadowsocks</a>, with the v2ray stream settings of <a href="/std/net/transport/">net.transport</a> (tcp, tls, ws, httpupgrade, and TLS hello fragmenting). One call to <code>Register</code> and a v2ray style JSON config runs, both the inbounds and the outbounds.</p>
<ul>
<li><code>Register</code> or <code>RegisterWith</code> installs the makers. After that <code>tunnel.CreateInbound</code>, <code>tunnel.CreateOutbound</code> and <code>tunnel.BuildDialer</code> understand every protocol above.</li>
<li><code>StartAll</code> starts every inbound of a config and <code>RunConfig</code> is a whole program: load, check, start, wait for Ctrl-C.</li>
<li><strong>Local by default.</strong> An inbound listens on <code>127.0.0.1</code> unless its <code>listen</code> field says otherwise. Write <code>"listen": "0.0.0.0"</code> for a server that other machines connect to.</li>
<li>With <code>use_doh</code> the names of servers are resolved over DNS over HTTPS, and routing rules with IP ranges can match domain targets, with answers cached.</li>
<li>Trojan inbounds start their own server; their bind address follows the trojan package.</li>
</ul>
{{example.net-vpn-guide-app}}
>>

doc.InMaker.Protocol = Returns the protocol name.
doc.InMaker.Make = Builds the inbound protocol from its settings.
doc.StreamSettings = Reads a v2ray streamSettings object: network (tcp, ws, httpupgrade, grpc), security (none, tls, reality), tlsSettings, realitySettings (client: serverName, publicKey, shortId, spiderX, fingerprint; server: privateKey, dest, serverNames, shortIds), wsSettings, httpupgradeSettings, grpcSettings (serviceName, multiMode), timeouts (read, write in milliseconds) and fragment (mode, sni, writes, min, max, delay).
doc.NodeSettings = The transport settings for the node of a share link, including the Reality keys and the gRPC service name, with the fragment and timeout options of <code>Register</code>.
doc.DialerFromNode = Builds the dialer of a node for vless, vmess, trojan, shadowsocks, socks or http. Other protocols give a dialer that refuses.
doc.ToTunnelAddr = Converts a transport address to a tunnel address.
doc.ToTransportAddr = Converts a tunnel address to a transport address.
doc.RegisterWith = Registers every protocol with the given options.
doc.Register = Registers outbounds and inbounds for socks, http, trojan, vless, vmess and shadowsocks, so a JSON config runs both sides.
doc.BuildDialer = Builds the router and dialers of a config, and gives the router the DNS over HTTPS resolver when it is on.
doc.TransportPending = An accepted connection waiting for its TLS or WebSocket upgrade.
doc.TransportPending.raw = The raw connection.
doc.TransportPending.settings = How to upgrade it.
doc.TransportPending.Valid = True when the accept worked.
doc.TransportPending.Open = Runs the upgrade and returns the stream.
doc.TransportPending.Abort = Drops the connection.
doc.TransportPending.Remote = The address of the client.
doc.TransportAcceptor = Accepts connections for a transport listener.
doc.TransportAcceptor.listener = The listener.
doc.TransportAcceptor.settings = Network and TLS settings.
doc.TransportAcceptor.Accept = Waits for the next connection.
doc.TransportAcceptor.Port = The port in use.
doc.TransportAcceptor.Ok = False when listening or loading the certificate failed.
doc.TransportAcceptor.Close = Stops listening.
doc.Listener = A running inbound.
doc.Listener.server = The accept server.
doc.Listener.has_server = False for a trojan inbound, which has its own server.
doc.Listener.trojan = The trojan server, when the protocol is trojan.
doc.Listener.port = The port in use.
doc.Listener.tag = The inbound tag.
doc.Start = Starts one inbound. It listens on the address of the config, 127.0.0.1 by default. Write 0.0.0.0 to open it to the network.
doc.StartAll = Starts every inbound of a config.
doc.Ok = True while the inbound listens.
doc.Stop = Stops an inbound.
doc.Summary = One line of traffic numbers.
doc.PENDING_PER_SOURCE = How many connections of one address <code>Start</code> lets sit in a handshake at once on each inbound it opens: 32. A client that opens a connection and says nothing is dropped after the handshake time limit.
doc.Wait = Waits for Ctrl-C or the time limit, printing the summary every few seconds.
doc.RunConfig = Loads a config file, checks it, starts everything and waits. Returns the exit code.
