pkg.intro <<
<p>This package is the drawing layer of the native user interface: it paints everything a CSS box can look like into a pixel buffer, in pure Salam, with the same pixels on every operating system. A <code>Canvas</code> holds premultiplied 32-bit pixels (<code>0xAARRGGBB</code>, so B, G, R, A bytes in memory), which X11, Win32, Cocoa and Wayland windows can show without a copy. Colours in the API are ordinary straight RGBA, as in CSS.</p>
<p>A box is painted in the CSS order: <code>DrawShadow</code>, then the background with <code>FillRoundedRect</code>, <code>FillGradient</code> or <code>DrawImage</code>, then <code>DrawBorder</code>, the content, and <code>DrawOutline</code>. Rounded corners take a horizontal and a vertical radius per corner and are scaled down the way CSS does when they do not fit. Edges are anti-aliased with exact coverage computed line by line in fixed point, borders have a width, colour and style (solid, dashed, dotted) per side, and shadows are Gaussian blurs computed analytically, outside or inside the box.</p>
<p>Clips (<code>PushClip</code>, <code>PushRoundedClip</code>), transforms and offscreen layers with group opacity (<code>BeginLayer</code>, <code>EndLayer</code>) are stacks. <code>SetRegion</code> limits drawing to a damage region of at most three rectangles, and drawing a scene in parts gives exactly the same pixels as drawing it at once. <code>FillPath</code> and <code>StrokePath</code> draw vector paths with lines, curves, arcs, caps, joins and dashes, and <code>DrawMask</code> draws text glyphs from a coverage mask.</p>
<h3>Things to know</h3>
<ul>
<li>Coordinates are logical pixels as <code>f64</code>. Fractional edges are anti-aliased; images, clips and layers snap to whole pixels.</li>
<li>Rasterization uses integers and fixed point only, so a picture is meant to have the same hash on every system and backend. Tests compare <code>Hash()</code> and a few pixels.</li>
<li>Every drawing call follows the whole transform, rotation and skew included. Borders, gradients, shadows and tiled images under a rotation or skew are drawn upright in a scratch layer and then resampled, and a clip under a rotation becomes a coverage mask.</li>
<li>Dashed and dotted sides are patterned along their rounded corners too, with the pattern spaced so that each corner gets a whole dash or dot.</li>
<li>Filters work on layers: <code>BeginFilterLayer</code> and <code>EndLayerFiltered</code> give CSS <code>filter</code>, and <code>BackdropFilter</code> gives <code>backdrop-filter</code>, compared with Chromium on opaque, translucent and nested backdrops. Colour filters work on straight colours in sRGB, as browsers do, and blurs use three box blurs, as the filter specification describes.</li>
<li><code>DrawNineSlice</code> draws an image cut into nine parts around a rectangle, the way CSS <code>border-image</code> does, with stretched, repeated, rounded or spaced edges.</li>
<li>Free every canvas, path and gradient you make. A canvas from <code>WrapCanvas</code> or <code>Sub</code> still needs <code>Free</code> for its scratch memory, but leaves the pixels alone.</li>
<li>The benchmark in <code>tools/bench/paint_frame.salam</code> draws 200 rounded boxes with a shadow, a background and a border over a full screen gradient at 1920x1080.</li>
</ul>

<h2 id="guide-card">Painting a CSS box</h2>
<p>A box is painted in the order CSS uses: the shadow first, then the background, then the border, and the outline last. All of them take the same rectangle and radii, so the shadow, the gradient and the border line up exactly. The outer shadow is cut out under the box, so a translucent background does not show it.</p>
{{example.gui-paint-guide-card}}

<h2 id="guide-damage">Repainting only what changed</h2>
<p>When something moves, only its old and new places need painting. Put both rectangles in a <code>Region</code>, set it with <code>SetRegion</code> and draw the whole scene as usual: everything outside the region is left alone. Coverage is computed for the whole shape and only then clipped, so the result is the same, pixel for pixel, as painting everything again.</p>
{{example.gui-paint-guide-damage}}
