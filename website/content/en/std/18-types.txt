pkg.description = The types package in Salam: recognising whole numbers, decimals and booleans in text, with Persian and English digits, and comparing vectors, with an example.
pkg.intro <<
<p>When data arrives from a CSV file, a form or the command line, everything is text. The <code>types</code> package says what kind of value a piece of text looks like, before you try to convert it. Persian and Arabic digits are recognised too.</p>
>>

doc.TypeKindNull = The kind of empty text.
doc.TypeKindBool = The kind of a boolean, <code>true</code> or <code>false</code>.
doc.TypeKindInt = The kind of a whole number.
doc.TypeKindFloat = The kind of a decimal number.
doc.TypeKindStr = Any other text.
doc.IsInt = True when the text is a whole number, with or without a sign. Persian and Arabic digits are accepted.
doc.IsFloat = True when the text is a decimal number, with a decimal separator or in scientific notation such as <code>2e5</code>. The Persian separator <code>٫</code> is accepted. A whole number does not count here.
doc.IsNumeric = True when the text is a whole or a decimal number.
doc.IsBool = True when the text is <code>true</code> or <code>false</code>, in any letter case.
doc.KindOf = Returns the kind of the text as one of the constants above.
doc.KindName = Returns the English name of a kind, such as <code>int</code>.
doc.Equal = True when two vectors have the same size and all their elements are equal in order.
