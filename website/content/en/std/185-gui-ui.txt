pkg.intro <<
<p><code>gui.ui</code> is what runs a Salam page on a desktop. A <code>page:</code> block is compiled into a function that receives a <code>Builder</code> and calls <code>Open</code>, <code>Id</code>, <code>SetText</code>, <code>Text</code>, <code>On</code> and <code>Close</code> on it; the runtime turns that element tree into boxes with <a href="/std/gui/style/">gui.style</a> values, lays them out with <a href="/std/gui/flow/">gui.flow</a>, and paints them with <a href="/std/gui/paint/">gui.paint</a>. You rarely call the builder by hand, but you can, and then you get the same runtime with no page syntax: that is how the examples below are written.</p>
<p>Three functions use a page function and a list of style patches:</p>
<ul>
<li><strong><code>RunPage</code></strong> opens a window and runs until it is closed. <code>RunPageWith</code> takes <code>Options</code> for the size, the title and a headless run.</li>
<li><strong><code>RenderPage</code></strong> builds the page, lays it out for a given size and returns the painted <code>paint.Canvas</code> without opening a window. <code>RenderPageScaled</code> does the same at a device scale such as 2.0.</li>
<li><strong><code>DumpPage</code></strong> does the same and returns a text report of the boxes (kind, id, x, y, width, height), which is the easiest thing to compare in a test.</li>
</ul>
<p>Things to know:</p>
<ul>
<li><strong>Style values are checked.</strong> <code>SetText</code> parses its text with <code>style.Parse</code> and prints the exact error for a bad one instead of ignoring it. Use <code>Set</code> with a parsed <code>style.Value</code> when you already have one.</li>
<li><strong>A style belongs to a state.</strong> Every <code>Set</code>, <code>SetText</code> and <code>Patch</code> names one of the <code>STATE_</code> constants; the base style always applies and a state style applies on top of it while the element is in that state.</li>
<li><strong>A patch is a named group of style values.</strong> Build it once with <code>NewPatch</code> and <code>Add</code>, return it from the function you give to <code>RunPage</code>, and apply it to any number of elements with <code>Builder.Patch</code>; the patch is the index in that list.</li>
<li><strong>Scopes re-run only what changed.</strong> <code>Scope</code> and <code>KeyedScope</code> wrap a part of the view; when state that the scope reads is touched, only that part runs again. The compiler writes these calls, together with <code>Reactive</code>, <code>ScopeSite</code>, <code>Instance</code> and <code>Fresh</code>, for every page that has state.</li>
<li><strong>Nothing needs a window to be tested.</strong> <code>RenderPage</code> and <code>DumpPage</code> never open a window, so they run on a machine with no display.</li>
</ul>

<h2 id="guide-cards">Draw a row of cards and check the pixels</h2>
<p>Three boxes of the same size in a <code>row</code> with a gap and padding. <code>DumpPage</code> shows where layout put each box, and <code>Pixel</code> on the canvas checks what was painted, including the gap between the cards that shows the background.</p>
{{example.gui-ui-guide-cards}}

<h2 id="guide-grid">A grid with spans</h2>
<p>The same builder with <code>layout</code> set to <code>grid</code>: three tracks (one fraction, two fractions and a fixed 100), a gap, and a cell that spans two columns. The report gives the position of every cell, so a layout rule becomes a test of a few lines.</p>
{{example.gui-ui-guide-grid}}
>>

doc.Patch = A group of style values with no element yet. Build one, return it in the list you give to a run or render function, and apply it with <code>Builder.Patch</code>.
doc.Patch.props = The property ids, in the order they were added.
doc.Patch.values = The style values, in the same order as <code>props</code>.
doc.Patch.Add = Adds one property and its value to the patch.
doc.Patch.Len = Number of properties in the patch.
doc.Builder = What a page function builds into: the elements, attributes, styles, text and handlers of one page. The compiler writes the calls for a <code>page:</code> block.
doc.Builder.Title = Sets the title of the page.
doc.Builder.Lang = Sets the language of the page, such as <code>en</code> or <code>fa</code>.
doc.Builder.Dir = Sets the text direction of the page, <code>ltr</code> or <code>rtl</code>.
doc.Builder.Open = Opens an element of this kind as the last child of the current one and makes it current. The kind is a page element name in English or Persian, such as <code>box</code>, <code>heading</code> or <code>جعبه</code>. An HTML tag such as <code>div</code> or <code>h2</code> is not a kind: it is reported once with the name to use, and the element stays hidden. Every <code>Open</code> needs a <code>Close</code>.
doc.Builder.Patch = Applies the patch with this index, from the list given to the run or render function, to the current element for a state.
doc.Builder.Set = Sets one style value of the current element for a state. A bad property or state is ignored.
doc.Builder.SetText = Sets one style of the current element for a state from text in the page syntax. A text that does not parse prints the exact error and changes nothing.
doc.Builder.Id = Sets the <code>id</code> of the current element, which tests and reports use to find it.
doc.Builder.Key = Sets the <code>key</code> of the current element, which keeps its state when a list is reordered.
doc.Builder.Attr = Sets any attribute of the current element, by name.
doc.Builder.BoolAttr = Sets a switch attribute such as <code>disabled</code>: present when the value is true, left out when it is false.
doc.Builder.Text = Adds a text child to the current element.
doc.Builder.On = Sets the function to run when the current element receives this event, such as <code>click</code>.
doc.Builder.Close = Closes the current element and goes back to its parent.
doc.Builder.Scope = Runs the function as one reactive scope with this site number. Only this part of the view runs again when the state it reads changes.
doc.Builder.KeyedScope = Like <code>Scope</code>, with a key so that a scope in a list keeps its place when the list changes order.
doc.Builder.Reactive = Registers how many state words the page has, the function that reads and clears the changed bits of a word, and the function that declares the sites. Only the first call in a run counts.
doc.Builder.Instance = Returns the slot of the component instance for the scope that is running, creating it on first use.
doc.Builder.Fresh = Reports whether the instance of the running scope was just created, so that its state can be set up once.
doc.Builder.Env = Registers the function that receives the window values: logical width and height, dark scheme, touch, reduced motion, high contrast and right to left. It is called at once, when the window opens and again on resize and scheme changes. The compiler writes this call for pages that read <code>page.width</code> and the other window values.
doc.NewPatch = Returns an empty patch.
doc.NoPatches = Returns an empty list of patches, for a page that uses none.
doc.RunPageWith = Opens a window with these options, builds the page and runs until the window is closed. Prints the reason when no window can be opened.
doc.RunPage = Opens a window with the default options, builds the page and runs until it is closed.
doc.RenderPage = Builds the page, lays it out and paints it for this width and height, and returns the canvas without opening a window. Free the canvas with <code>Free</code>.
doc.RenderPageScaled = Like <code>RenderPage</code> at a device scale, so a scale of 2.0 gives a canvas twice as wide and as high.
doc.DumpPage = Builds and lays out the page like <code>RenderPage</code> and returns a text report with one line per box: kind, id, x, y, width and height, indented by depth.
doc.Dump = The same report for the page that is running now.
doc.ScopeSite = Declares that a scope site reads this bit mask of a state word and belongs to this component. Called from the function given to <code>Reactive</code>.
doc.ScopeVars = Declares which bits of a component's variables the scope at this site reads, for the instance that encloses the scope. Called from the function given to <code>Reactive</code>.
doc.ScopeDerive = Registers a function for a component that works out its derived values after a write: it gets the instance and the mask of changed variables, and returns the mask with the derived values that really changed added. Written by the compiler.
doc.TouchInstance = Marks the state of one component instance as changed, so the scopes that read it run again.
doc.TouchInstanceVars = Marks some variables of one component instance as changed (a bit mask), so only the scopes that read those variables run again. <code>TouchInstance</code> marks all of them.
doc.Invalidate = Marks the whole view as changed, so every scope runs again.
doc.ScopeRuns = Number of scopes that ran in the last update, which tests use to prove that only the scope that read the state ran.
doc.ScopeNodes = Number of nodes built by scope re-runs so far, which tests use to show how little of the view a change rebuilt.
doc.STATE_BASE = The element with no state: the style that always applies.
doc.STATE_HOVER = The pointer is over the element.
doc.STATE_FOCUS = The element has keyboard focus.
doc.STATE_FOCUS_WITHIN = The element or one of its children has keyboard focus.
doc.STATE_ACTIVE = The element is being pressed.
doc.STATE_DISABLED = The element is disabled.
doc.STATE_CHECKED = A check box, radio button or switch is on.
doc.STATE_INVALID = The value of a field does not pass its check.
doc.STATE_PLACEHOLDER = The field is empty and shows its placeholder.
doc.STATE_SELECTION = The selected part of a text.
doc.Options = Settings for a window: size, title and whether it can be resized.
doc.Options.width = Width of the window in pixels. 1024 by default.
doc.Options.height = Height of the window in pixels. 768 by default.
doc.Options.title = Title of the window. When empty, the title set with <code>Builder.Title</code> is used.
doc.Options.resizable = Whether the user can resize the window. True by default.
doc.Options.headless = Opens the window with the headless backend, which draws to memory and needs no screen. False by default.
doc.Options.scale = Device scale of the window. 0 lets the window backend choose.
doc.Options.script = Reserved for scripted test runs. Empty for a normal run; the runtime does not read it yet.
doc.Event = The fields of an input event: what happened, where and with which key.
doc.Event.kind = Kind of the event, such as <code>click</code> or <code>key</code>.
doc.Event.target = Id of the element the event is for.
doc.Event.x = Horizontal position of the pointer in the window.
doc.Event.y = Vertical position of the pointer in the window.
doc.Event.button = Number of the mouse button, 0 for the left one.
doc.Event.key = Name of the key for a keyboard event.
doc.Event.text = Text typed for a text event.
doc.Event.value = Current value of the field for an input event.
doc.Event.checked = Whether a check box, radio button or switch is on after the event.
doc.Event.modifiers = Bit mask of the held modifier keys.
doc.Event.delta_x = Horizontal scroll amount.
doc.Event.delta_y = Vertical scroll amount.
doc.Profile = Time spent in each stage of one frame. The runtime does not fill it yet.
doc.Profile.build_ms = Milliseconds spent building the element tree.
doc.Profile.style_ms = Milliseconds spent computing styles.
doc.Profile.layout_ms = Milliseconds spent laying out.
doc.Profile.paint_ms = Milliseconds spent painting.
doc.Profile.elements = Number of elements in the page.
doc.ById = Finds an element of the running page by its <code>id</code>. The result can be used even if no element has that id; ask it <code>Exists</code>.
doc.ByKey = Finds an element of the running page by its <code>key</code>.
doc.CurrentEvent = The event whose handler is running now: kind, target id, pointer position, key, text and the value of a control.
doc.Element = A handle to one element of the running page, found by id or key, used by tests and by handlers to read and change it.
doc.Element.id = The id the handle looks for.
doc.Element.key = The key the handle looks for when no id is given.
doc.Element.Exists = True when the page has an element with this id or key.
doc.Element.Tag = The kind of the element, such as <code>button</code> or <code>input</code>.
doc.Element.Text = The text inside the element and its children.
doc.Element.SetText = Replaces the content of the element with this text.
doc.Element.Value = The value of an input, text area or select.
doc.Element.SetValue = Sets the value of a control and moves its caret to the end.
doc.Element.Checked = True when a check box or radio button is on.
doc.Element.SetChecked = Turns a check box or radio button on or off, as a click would, without the click events.
doc.Element.Focus = Gives the element keyboard focus and scrolls it into view.
doc.Element.ScrollIntoView = Scrolls every scrolling parent so the element is visible.
doc.Element.Click = Clicks the element as the pointer would, including its click handlers.
doc.Element.Attr = Reads an attribute of the element by name.
doc.Element.SetAttr = Sets an attribute of the element by name and lays the page out again.
doc.Element.Style = The computed style of the element after states such as hover and focus are applied.
doc.Element.Rect = The box of the element on screen: x, y, width and height.
doc.RunSteps = Plays script steps such as <code>click #save</code>, <code>type hello</code>, <code>key Tab</code>, <code>style #a color</code>, <code>dump</code> and <code>quit</code>, one per line.
doc.SetUrlOpener = Chooses the function that opens an <code>http</code>, <code>https</code> or <code>mailto</code> link. Without one the system browser is used.
doc.SetNavigator = Chooses the function that handles other links, such as a path to another page.
doc.OpenedUrls = Every link opened so far, in order.
doc.OpenUrl = Opens a link as a click on it would.
doc.Stop = Asks the running page to stop after the current step.

doc.AddFontFile = Adds a font file to the fonts used to draw text, so a page renders the same on every machine. Returns the number of faces added.
doc.AddFontDir = Adds every font file in a directory. Returns the number of faces added, and 0 when the directory does not exist.
doc.OffscreenOpen = Builds and draws a page into a canvas without a window and keeps it, so later changes can be drawn as a partial repaint. Returns false when one is already open.
doc.OffscreenUpdate = Runs the page again, repaints only the damaged part of the canvas and returns the damaged area in pixels. With <code>true</code> the damaged part is filled with a marker colour first, so a missed pixel shows.
doc.OffscreenRepaintAll = Repaints the whole canvas, to compare with a partial repaint.
doc.OffscreenCanvas = The canvas of the open offscreen page. It is freed by <code>OffscreenClose</code>.
doc.OffscreenClose = Closes the offscreen page and frees its canvas.
