pkg.import = encoding.uuid
pkg.intro <<
<p>A UUID is a 128 bit identifier that can be made on any machine without asking a server. This package follows RFC 9562, which replaced RFC 4122, and checks its output against the test vectors of that RFC. A <code>UUID</code> is a small value of two 64 bit halves, so it is cheap to copy, compare and use as a key.</p>
<p>Which version to use:</p>
<div class="table-wrap"><table>
<thead><tr><th>Version</th><th>Made by</th><th>Use it for</th></tr></thead>
<tbody>
<tr><td>4</td><td><code>NewV4</code>, <code>New</code></td><td>Plain random ids. The default choice.</td></tr>
<tr><td>7</td><td><code>NewV7</code></td><td>Database keys and anything you sort or index: the time comes first, so new ids land at the end of an index.</td></tr>
<tr><td>5</td><td><code>NewV5</code></td><td>The same name must always give the same id, for example an id for a URL.</td></tr>
<tr><td>3</td><td><code>NewV3</code></td><td>Like 5 with MD5, only to match ids that already exist.</td></tr>
<tr><td>1 and 6</td><td><code>NewV1</code>, <code>NewV6</code></td><td>Time based ids that other systems expect. Version 6 is version 1 reordered so it sorts by time; prefer it for new code.</td></tr>
<tr><td>8</td><td><code>NewV8</code></td><td>Your own layout in the 122 free bits.</td></tr>
</tbody>
</table></div>
<p>The random versions read only the operating system secure random source. The package never uses <code>std/rand</code>, which is not meant for identifiers. If the secure source cannot be read the process stops, because an id built from anything weaker would be a security hole; there is no half working mode to handle.</p>
<h2 id="guide-basics">Making an id</h2>
<p><code>New</code> makes a random version 4 id and <code>String</code> writes it as the usual 36 characters. <code>Nil</code> and <code>Max</code> are the all zero and all one ids. Printing a <code>UUID</code> with <code>println</code> writes the same text.</p>
{{example.encoding-uuid-guide-basics}}
<h2 id="guide-parse">Reading and writing text</h2>
<p><code>Parse</code> accepts the canonical form, the form in braces, the <code>urn:uuid:</code> form and the form with no hyphens, in capitals or not. It is strict: no spaces around the text, every hyphen where it belongs, nothing but hex digits. It returns a <code>ParseResult</code> with <code>ok</code>, <code>id</code> and <code>error</code>. Use <code>MustParse</code> for literals in your own code and <code>ParseOr</code> when you have a fallback. <code>String</code>, <code>Upper</code>, <code>Compact</code>, <code>Braced</code> and <code>URN</code> write the other direction.</p>
{{example.encoding-uuid-guide-parse}}
<h2 id="guide-names">Ids made from names</h2>
<p>Version 5 (and 3) hashes a namespace id and a name, so the same pair always gives the same id. The four namespaces of the RFC are <code>NamespaceDNS</code>, <code>NamespaceURL</code>, <code>NamespaceOID</code> and <code>NamespaceX500</code>; you can also use any UUID of your own as a namespace. The values below are the ones printed in RFC 9562.</p>
{{example.encoding-uuid-guide-names}}
<h2 id="guide-time">Time based ids</h2>
<p>Versions 1, 6 and 7 carry a time. <code>UnixMillis</code> and <code>UnixNanos</code> read it back, <code>Timestamp</code> gives the raw 60 bit count of version 1 and 6. The <code>From...Parts</code> functions build an id from exact parts, which is how the tests pin the RFC test vectors. <code>NewV7</code> returns a larger id on every call, even in the same millisecond, even from other threads, and even when the clock is set back. <code>NewV1</code> and <code>NewV6</code> never repeat either: ids in the same 100 nanosecond tick move the time forward by one tick, and a clock that jumps far back changes the clock sequence as RFC 9562 asks. Their node is random per process with the multicast bit set, never a real network address.</p>
{{example.encoding-uuid-guide-time}}
<h2 id="guide-threads">Many threads at once</h2>
<p>All the generators can be called from any number of threads, with <code>go</code>, <code>spawn</code> or a pool. The clock state, the version 7 counter and the buffer of random bytes sit behind locks of their own, so there are no duplicates and no id goes backwards in a thread. The example makes 8000 ids from 8 tasks and counts the different ones.</p>
{{example.encoding-uuid-guide-threads}}
<h2 id="guide-short">Short forms</h2>
<p><code>Base64URL</code> writes an id in 22 characters that are safe in a URL and <code>Base32</code> in 26 lowercase characters that are safe in a file name or a host name. Reading them back is as strict as <code>Parse</code>: the unused bits must be zero, so one id has one text.</p>
{{example.encoding-uuid-guide-short}}
<h2 id="guide-custom">Custom ids and bytes</h2>
<p>Version 8 keeps the version and variant bits and leaves the rest to you: <code>FromV8Parts</code> takes the three fields of the RFC and <code>NewV8</code> takes two 64 bit halves. <code>Bytes</code> and <code>FromBytes</code> convert to the 16 bytes in network order, and <code>ToBuffer</code> and <code>FromBuffer</code> do the same for raw memory.</p>
{{example.encoding-uuid-guide-custom}}
<p>What people get wrong:</p>
<ul>
<li>Using version 4 as a primary key in a big table. Random keys scatter writes over the whole index; version 7 keeps them together.</li>
<li>Hiding secrets in the time of a version 1, 6 or 7 id. The time can be read back by anyone who has the id.</li>
<li>Expecting version 5 to be secret. It is a hash of public values, anyone who knows the name can compute it.</li>
<li>Comparing the text of ids made in different cases. Compare with <code>Equal</code>, or write both with <code>String</code>.</li>
<li>Forgetting to free the vectors from <code>Bytes</code>, <code>Batch</code> and <code>BatchV7</code>.</li>
</ul>
<p>For random bytes and tokens see <a href="/std/crypto/">crypto</a>; for hex and base64 of arbitrary data see <a href="/std/encoding/">encoding</a>.</p>
>>

doc.New = Makes a random version 4 UUID from the secure random source. The same as NewV4.
doc.NewString = Makes a random version 4 UUID and returns it as lowercase text.
doc.Batch = Makes n random version 4 UUIDs. Free the vector when done.
doc.BatchV7 = Makes n version 7 UUIDs in order. Each one is larger than the one before. Free the vector when done.
doc.UUID = A 128 bit identifier kept as two unsigned 64 bit halves, hi (the first eight bytes) and lo (the last eight). It is a plain value: copy it, compare it with Equal and Compare, print it with println.
doc.UUID.hi = The first eight bytes, most significant first.
doc.UUID.lo = The last eight bytes, most significant first.
doc.UUID.to_str = Writes the canonical lowercase text, the same as String. It is what println uses to print a UUID.
doc.VARIANT_NCS = Variant of old NCS identifiers, the top bit of the variant field is 0.
doc.VARIANT_RFC = The variant of RFC 9562 and RFC 4122, bits 10. Every version 1 to 8 UUID made here has it.
doc.VARIANT_MICROSOFT = Variant reserved for old Microsoft GUIDs, bits 110.
doc.VARIANT_FUTURE = Variant reserved for the future, bits 111.
doc.Nil = The nil UUID, all 128 bits zero.
doc.Max = The max UUID, all 128 bits one.
doc.IsNil = True when every bit is zero.
doc.IsMax = True when every bit is one.
doc.Equal = True when two UUIDs have the same 128 bits.
doc.Compare = Returns -1, 0 or 1. The order is the order of the bytes, so it is also the order of the canonical text, and version 6 and 7 UUIDs sort by time.
doc.Less = True when a sorts before b.
doc.Version = The version number from the four version bits, 0 to 15.
doc.Variant = The layout of the identifier: one of the VARIANT_ constants.
doc.Byte = The byte at position 0 to 15, or 0 when the position is out of range.
doc.Bytes = The 16 bytes in network order as a vector. Free it when done.
doc.FromBytes = Builds a UUID from a vector of exactly 16 bytes. Any other length gives the nil UUID.
doc.ToBuffer = Writes the 16 bytes to the memory out points at. The buffer must hold at least 16 bytes.
doc.FromBuffer = Reads 16 bytes from the memory src points at.
doc.String = The canonical lowercase text, 36 characters: 8-4-4-4-12 hexadecimal digits.
doc.Upper = The canonical text in capitals.
doc.Compact = Lowercase without hyphens, 32 characters.
doc.Braced = The canonical text in curly braces, the form Microsoft tools write.
doc.URN = The canonical text with the urn:uuid: prefix.
doc.ParseResult = What Parse returns: ok says whether the text was a UUID, id is the value and error says what was wrong.
doc.ParseResult.ok = True when the text was a valid UUID.
doc.ParseResult.id = The parsed value, the nil UUID when ok is false.
doc.ParseResult.error = A short description of the problem, empty when ok is true.
doc.Parse = Reads a UUID from text. It accepts the canonical form, the form in braces, the urn:uuid: form and the form with no hyphens, in any case. Everything else is an error: spaces, a missing or misplaced hyphen, a character that is not a hex digit, a wrong length.
doc.ParseOr = Parses text and returns the fallback when it is not a UUID.
doc.IsValid = True when Parse would accept the text.
doc.MustParse = Parses text and stops the program with a message on standard error and exit code 2 when it is not a UUID. For literals in your own code.
doc.NamespaceDNS = The namespace UUID for fully qualified domain names, 6ba7b810-9dad-11d1-80b4-00c04fd430c8.
doc.NamespaceURL = The namespace UUID for URLs, 6ba7b811-9dad-11d1-80b4-00c04fd430c8.
doc.NamespaceOID = The namespace UUID for ISO object identifiers, 6ba7b812-9dad-11d1-80b4-00c04fd430c8.
doc.NamespaceX500 = The namespace UUID for X.500 distinguished names, 6ba7b814-9dad-11d1-80b4-00c04fd430c8.
doc.NewV3 = A name based UUID using MD5, version 3. The same namespace and name always give the same UUID. Prefer NewV5 unless you must match existing version 3 ids.
doc.NewV5 = A name based UUID using SHA-1, version 5. The same namespace and name always give the same UUID, on every machine and in every language that follows RFC 9562.
doc.Stamp = Writes a version and the RFC variant over any 128 bits (hi and lo) and returns the result.
doc.FromV4Parts = Builds a version 4 UUID from two given random halves, for tests that need a fixed value.
doc.FromV7Parts = Builds a version 7 UUID from a Unix time in milliseconds, 12 bits rand_a and 62 bits rand_b. This is the deterministic builder behind NewV7.
doc.FromV8Parts = Builds a version 8 UUID from 48 bits custom_a, 12 bits custom_b and 62 bits custom_c, the layout of RFC 9562.
doc.NewV4 = A random UUID, version 4. It has 122 random bits from the operating system secure random source and nothing else. The source is read in large blocks under a lock, so it is safe from many threads.
doc.NewV7 = A UUID made of the Unix time in milliseconds followed by a counter and random bits, version 7. Every call returns a larger UUID than the one before, in the whole process and across threads, even when the clock stands still or goes back.
doc.NewV8 = A custom UUID: your 128 bits with the version 8 and RFC variant bits written over them.
doc.NodeID = The 48 bit node this process puts in version 1 and 6 UUIDs: random, with the multicast bit set as RFC 9562 asks, so it never equals a real network card address.
doc.FromV1Parts = Builds a version 1 UUID from a 60 bit timestamp (100 nanosecond steps since 1582-10-15), a 14 bit clock sequence and a 48 bit node. The deterministic builder behind NewV1.
doc.FromV6Parts = Builds a version 6 UUID from the same parts as FromV1Parts. Version 6 is version 1 with the time bits reordered so the text sorts by time.
doc.NewV1 = A time based UUID, version 1: the current time, a clock sequence and the process node. It never repeats: when two calls land in the same tick the time is moved forward by one tick, and when the clock jumps far back the clock sequence is changed.
doc.NewV1WithNode = Like NewV1 with the 48 bit node you give instead of the random one.
doc.NewV6 = A time ordered UUID, version 6. It carries the same information as version 1 but sorts by time.
doc.HasTime = True for a version 1, 6 or 7 UUID of the RFC variant.
doc.Timestamp = The raw 60 bit timestamp of a version 1 or 6 UUID, or 0 for other versions.
doc.UnixNanos = The time inside a version 1, 6 or 7 UUID as nanoseconds since 1970, or 0 for other versions.
doc.UnixMillis = The same time in milliseconds.
doc.ClockSequence = The 14 bit clock sequence of a version 1 or 6 UUID, or 0.
doc.Node = The 48 bit node of a version 1 or 6 UUID, or 0.
doc.Base64URL = The UUID as 22 characters of URL safe base64 without padding.
doc.FromBase64URL = Reads the 22 character form back. The extra bits must be zero, so every UUID has exactly one text.
doc.Base32 = The UUID as 26 lowercase characters of RFC 4648 base32 without padding.
doc.FromBase32 = Reads the 26 character form back, in either case.
