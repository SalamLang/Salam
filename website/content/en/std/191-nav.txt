pkg.intro <<
<p>Path matching and history for apps that move between screens. A route pattern such as <code>/users/:id</code> names the parts of a path, <code>Match</code> and <code>Param</code> read them, <code>Rank</code> orders patterns from the most specific, and <code>History</code> is a back and forward stack. The package has no state and no platform code, so the same rules hold in the browser (it compiles to JavaScript), in a native window and on a server.</p>
<h2 id="guide-patterns">Patterns</h2>
<p>A pattern is a path whose segments are literal text, <code>:name</code> for one segment, <code>:name?</code> for a segment that may be missing, or <code>*name</code> (or <code>*</code>) at the end for the rest of the path. Literal segments are compared as written, so case matters, and a trailing <code>/</code> never does. Paths in a <code>Route</code> are decoded text, so Persian segments match as written; only the escapes the syntax reserves (<code>%2F</code>, <code>%25</code>, <code>%26</code>, <code>%3D</code>, <code>%23</code>, <code>%3F</code>, <code>%2B</code>) stay escaped until <code>Param</code> or <code>Query</code> decodes them.</p>
<h2 id="guide-paths">Paths and links</h2>
<p><code>Resolve</code> follows the rule most app routers use: a relative link is resolved under the current path, not next to it. <code>Href</code> and <code>StripBase</code> turn a path into a link and back for an app served under a base path or in hash mode (<code>#/path</code>).</p>
<h2 id="guide-history">History</h2>
<p><code>Push</code> drops everything after the current position, like a browser does after you go back and follow a new link. <code>Replace</code> swaps the current entry, which suits a redirect.</p>
>>

doc.Route = The current place in an app: the path, the query and the pattern that matched it.
doc.Route.path = The path, starting with /, without the query. Text in it is already decoded.
doc.Route.query = The query without the leading ?, as written in the address.
doc.Route.pattern = The route pattern that matched the path, or an empty text when none did.
doc.Route.Param = The value of the named parameter of the route pattern, unescaped; an empty text when the path does not match.
doc.Route.Query = The value of the named query key, unescaped, with + read as a space; an empty text when the key is missing.
doc.History = A stack of visited paths with a position, the way a native window keeps its back and forward list.
doc.History.entries = The visited paths, oldest first.
doc.History.index = The position of the current path in entries.
doc.Unescape = Decodes only the escapes that the path and query syntax reserves: %2F, %25, %26, %3D, %23, %3F and %2B. Other text, and other escapes, stay as they are.
doc.Normalize = Gives a path one shape: a leading /, no empty segments, . and .. applied, no trailing /.
doc.SplitUrl = Splits an address into its path and its query, and drops the #fragment.
doc.Resolve = Resolves a link against the current path. An absolute link replaces it, a link starting with ? keeps the path, and a relative link is resolved under the current path, so edit from /users/3 is /users/3/edit and .. is /users.
doc.Match = Tells whether a path matches a pattern. A segment :name matches one segment, :name? may be missing, and *name or * at the end matches the rest. Literal segments are compared as written, and a trailing / does not matter.
doc.Param = The value of one parameter of a pattern in a path, unescaped; an empty text when the path does not match. A * parameter gives the rest of the path.
doc.ParamInt = The value of an integer parameter, such as the 42 in /users/42 for /users/:id; 0 when the path does not match or the value is not a whole number that fits in an int. Check it with IsInt first when 0 is a real value.
doc.Query = The value of one query parameter, with + read as a space and reserved escapes decoded; an empty text when it is missing.
doc.Rank = A number that grows with how specific a pattern is: literal segments over parameters, parameters over optional ones, and a * last. Sort routes by it so /users/new wins over /users/:id, and /users wins over /users/:tab? for the path /users.
doc.IsInt = Tells whether a text is a whole number that fits in an int (-2147483648 to 2147483647), with an optional minus sign. Use it to check a parameter before converting it.
doc.Href = The address of a path for a link: #/path in hash mode, base plus path otherwise.
doc.StripBase = Removes the base path of an app from an address and normalizes the rest; an address outside the base is only normalized.
doc.NewHistory = A history that starts at one path.
doc.Current = The path at the current position.
doc.Push = Goes to a new path: everything after the current position is dropped and the path becomes the newest entry.
doc.Replace = Swaps the current path for another without adding an entry.
doc.CanBack = Tells whether there is a path before the current one.
doc.CanForward = Tells whether there is a path after the current one.
doc.Back = Moves one entry back; false when already at the oldest.
doc.Forward = Moves one entry forward; false when already at the newest.
doc.Reset = Clears the history and starts again at one path.
doc.Depth = How many entries lie up to and including the current one.
