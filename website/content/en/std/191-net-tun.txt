pkg.intro <<
<p><code>net.tun</code> gives a VPN app full device mode: every application on the machine goes through the tunnel, not only the ones that honour the system proxy. It creates a layer 3 tunnel device (<code>/dev/net/tun</code> on Linux, utun on macOS, a Wintun adapter on Windows), points the default routes at it and turns the IP packets that arrive into ordinary TCP connections, which it hands to any <code>net.tunnel</code> dialer: a router with direct, proxy and block rules, a VLESS, VMess, Trojan or Shadowsocks dialer, or a chain.</p>
<p>It has no TCP stack of its own. Like the system stack of sing-tun, it rewrites the addresses of each TCP packet so the connection lands on a local listener, and the kernel does all of TCP. Only IP and TCP headers are touched, with incremental checksum updates, so throughput stays close to the kernel.</p>
<pre class="code"><code>app -&gt; 1.1.1.1:443                        kernel TCP
  |  routes 0.0.0.0/1, 128.0.0.0/1             ^
  v                                            |
tun device -&gt; Nat.Rewrite: 172.19.0.2:10000 -&gt; 172.19.0.1:listener
                                               |
listener accepts, Nat.Lookup(10000) = 1.1.1.1:443, sniff SNI, dialer.Dial(host:443)</code></pre>
<p>Things to know:</p>
<ul>
<li><strong>It needs privileges.</strong> Root or CAP_NET_ADMIN on Linux, root on macOS, administrator rights and <code>wintun.dll</code> next to the executable on Windows (download it from wintun.net). Call <code>Available</code> first and show its reason.</li>
<li><strong>Exclude your servers.</strong> Put the VPN server names or addresses in <code>exclude</code>. They are resolved before the routes change and keep a route through the old gateway. For <code>direct</code> rules use <code>Bypass</code>, which binds to the physical interface.</li>
<li><strong>TCP and DNS by default.</strong> UDP queries to port 53 are answered through the dialer over TCP. Other UDP (QUIC, games, calls) is dropped unless you set <code>relay_udp</code> and give a relay such as <a href="/std/net/udprelay/">net.udprelay</a>. ICMP is dropped and IPv6 is blocked rather than leaked.</li>
<li><strong>Routes never replace the default route.</strong> Two /1 routes win over it and <code>Stop</code> removes everything it added. If the process is killed, the Linux and Windows device disappears with it; host routes for excluded servers stay until reboot.</li>
<li><strong>Linux is tested end to end</strong> by <code>tools/interop/tun_e2e.sh</code> in a container. The macOS and Windows device code is type checked for every target.</li>
</ul>
<h2 id="guide-vpn-app">Full device mode in a VPN app</h2>
<p>Build the same router dialer you would give a local SOCKS inbound, but use <code>Bypass()</code> for the <code>direct</code> tag so direct traffic leaves through the physical interface instead of looping back into the tunnel. Pass the VPN server in <code>exclude</code>, start the session when the user flips the switch and stop it when they flip it back or the app quits.</p>
<pre class="code"><code>import net.tun
import net.tunnel

func start_full_device(proxy: dyn tunnel.Dialer, server: str): tun.Session:
    av := tun.Available()
    if not av.ok:
        println "full device mode is off:", av.reason
        ret tun.Session {}
    end
    rules := tunnel.ParseRules("domain:ir direct\nprivate direct", "proxy")
    mut router := tunnel.NewRouterDialer(rules.router)
    tunnel.RouterDialerAdd(router, "direct", tun.Bypass())
    tunnel.RouterDialerAdd(router, "block", tunnel.Block())
    tunnel.RouterDialerAdd(router, "proxy", proxy)
    mut servers := Vector {} as Vector&lt;str&gt;
    servers.Push(server)
    s := tun.Start(tun.Options { dialer = router, exclude = servers })
    if not s.ok:
        println "could not start:", s.error
    end
    ret s
end

func main():
    s := start_full_device(tunnel.Direct(), "vpn.example.com")
    if s.ok:
        st := tun.SessionStats(s)
        println st.connections, st.dns_queries
        tun.Stop(s)
    end
end</code></pre>
<p>Show <code>Available().reason</code> next to a disabled switch when the process lacks the rights; a desktop app usually starts a small privileged helper for this mode. Read <code>SessionStats</code> on a timer for the traffic counters.</p>
<h2 id="guide-raw-device">Handling packets yourself</h2>
<p><code>OpenDevice</code> gives a bare device with no address, routes or stack: each <code>Read</code> returns one IP packet and each <code>Write</code> injects one. Combine it with <code>Parse</code>, <code>Nat</code> and the packet builders to write your own stack, a packet logger or a test harness. Configure the address and routes yourself, or look at what <code>BuildPlan</code> would run.</p>
<pre class="code"><code>import mem
import sync
import net.tun

func main():
    dev := tun.OpenDevice("salam0", 1500)
    if not dev.ok:
        println dev.error
        ret
    end
    nat := tun.NewNat("172.19.0.1", "172.19.0.2", 7000, 0)
    buf := mem.Allocate(65536 as u64)
    repeat 1000:
        n := dev.Read(buf, 65536, 200)
        if n &gt; 0:
            info := tun.Parse(buf, n)
            println info.src, info.sport, "-&gt;", info.dst, info.dport
            if nat.Rewrite(buf, n, sync.NowMs()) == tun.action_reply:
                _w := dev.Write(buf, n)
            end
        end
    end
    mem.Free(buf)
    tun.FreeNat(nat)
    dev.Close()
end</code></pre>
