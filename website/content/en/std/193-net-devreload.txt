pkg.intro <<
<p>Dev reload tells an open browser tab that the page has changed. The server keeps one endpoint, <code>/__salam_hmr</code>, and the tab listens to it with <code>EventSource</code>. Each answer is one event: <code>swap</code> (replace the app code in place and keep its state), <code>css</code> (reload the style sheets only), <code>style</code> (replace the inline styles and nothing else), <code>reload</code>, or <code>error</code> with the build log, which the script shows over the page.</p>
<p><code>salam serve</code> uses this package for pages and <code>salam serve --render</code> uses it inside the generated server. You only need it directly when you write your own development server.</p>
<h3 id="pitfalls">What trips people up</h3>
<ul>
<li><strong>Development only.</strong> <code>Inject</code> adds the script to a response; never call it on files you deploy.</li>
<li><strong>One answer per request.</strong> <code>Handler</code> waits up to 15 seconds for a change and answers once; the browser reconnects by itself and sends the id of the last event it saw.</li>
<li><strong>A new instance reloads every tab.</strong> The id carries the epoch given to <code>Init</code>, so a restarted server makes open tabs reload.</li>
</ul>
<h2 id="guide-state">Starting the state and injecting the script</h2>
<p><code>Init</code> or <code>InitLocal</code> starts the state. <code>Bump</code> then announces each change, and <code>Inject</code> adds the script to any page you serve. The program below runs these calls without a server.</p>
{{example.net-devreload-guide-basics}}
<h2 id="guide-server">Serving the event endpoint</h2>
<p>A development server registers <code>Handler</code> under <code>/__salam_hmr</code> and starts only when <code>InitFromEnv</code> says dev reload is on, so a release run is not affected.</p>

doc.Init = Starts the state with an epoch (any non-empty text without a colon that differs between server runs; colons are replaced with dashes) and the path of a file whose contents are the current build error, or an empty path.
doc.InitLocal = Like <code>Init</code>, but a change is announced only by <code>Bump</code>; use it when the builder lives in the same process as the server.
doc.InitFromEnv = Turns dev reload on when the environment variable <code>SALAM_DEV_HMR</code> is set, and reads the error file path from <code>SALAM_DEV_HMR_ERR</code>. Returns whether it is on.
doc.Enabled = Whether dev reload has been started.
doc.Bump = Announces a change: 0 reloads the page, 1 reloads only the style sheets, 2 asks the page to swap its code in place, 3 asks it to replace only its styles.
doc.Script = The browser script, with its start up code, as HTML.
doc.Inject = The HTML with the script added before <code>&lt;/body&gt;</code> and a small recorder after <code>&lt;head&gt;</code>.
doc.Handler = The request handler for <code>/__salam_hmr</code>: answers with one server sent event.
doc.SetLang = Sets the language of the overlay and its messages: <code>fa</code> (right to left) or <code>en</code> (left to right); anything else means <code>en</code>. Every event carries it.
doc.Lang = The language set with <code>SetLang</code>, <code>en</code> by default.
