pkg.intro <<
<p>A relay forwards traffic on behalf of someone else. Some links, such as SSH port forwarding, carry only byte streams, so a UDP packet cannot cross them as it is. <code>net.udprelay</code> puts a short header in front of every datagram, sends it over the stream, and the server half sends it on with <a href="/std/net/udp/">net.udp</a> and brings the replies back.</p>
<pre class="code"><code>app -&gt; Client == SSH stream ==&gt; Serve -&gt; UDP -&gt; internet</code></pre>
<p>The server is one small program. Build it for the machine it runs on and start it with the command given to <code>NewClient</code>:</p>
<pre class="code"><code>import net.udprelay

func main:
    ok := udprelay.Serve(0 as i64, 1 as i64, udprelay.ServerOptions {})
    ret ok ? 0 : 1
end</code></pre>
<p><a href="/std/net/tun/">net.tun</a> uses a client as its <code>udp</code> option when <code>relay_udp</code> is on.</p>
<ul><li><strong>The server needs POSIX.</strong> <code>Serve</code> returns false on Windows. The client works everywhere.</li><li><strong>IPv4 only.</strong></li><li><strong>Datagrams may be lost</strong>, as with UDP itself: when the queue is full or the stream is down they are dropped.</li></ul>
<h2 id="guide-server">The server program</h2>
<p>The far side is a program that only calls <code>Serve</code> on its standard input and output. Build it for the server, copy it there, and let the client start it over SSH. It ends when the input ends, so nothing keeps running after the connection closes.</p>
<pre class="code"><code>import net.udprelay

func main:
    ok := udprelay.Serve(0 as i64, 1 as i64, udprelay.ServerOptions {})
    ret ok ? 0 : 1
end</code></pre>
<h2 id="guide-tun">Using it with net.tun</h2>
<p>Give <code>NewClient</code> the command that starts the server, then pass the client to the tunnel. Blocking port 443 makes browsers use TCP instead of QUIC.</p>
<pre class="code"><code>import net.tun
import net.udprelay
import os.process

func options(): tun.Options:
    mut cmd := process.NewCommand("ssh")
    cmd.Arg("user@server")
    cmd.Arg("./udprelay")
    mut blocked := Vector {} as Vector<int>
    blocked.Push(443)
    ret tun.Options {
        relay_udp = true,
        udp = udprelay.NewClient(cmd),
        udp_blocked = blocked
    }
end</code></pre>
>>
