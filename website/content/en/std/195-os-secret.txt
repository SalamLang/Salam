pkg.intro <<
<p>A program that remembers a password should not write it to a file. <code>os.secret</code> hands it to the store the operating system already protects, addressed by two names: a service, usually your application id, and a key, usually the account.</p>
<ul><li><strong>It can be missing.</strong> A server or a minimal Linux desktop may have no Secret Service. Call <code>Available</code> and offer to remember only when it is true.</li><li><strong>The system may ask.</strong> The user can be prompted to unlock the store, or on macOS to let a rebuilt program read an old entry.</li><li><strong>Text only.</strong> A value stops at its first zero byte.</li></ul>
<h2 id="guide-remember">Remembering a password</h2>
<p>Store it after a successful sign in, and read it when the program starts.</p>
<pre class="code"><code>import os.secret

func remember(user: str, password: str): bool:
    if not secret.Available():
        ret false
    end
    ret secret.Set("com.example.app", user, password)
end

func recall(user: str): str:
    ret secret.Get("com.example.app", user)
end</code></pre>
<h2 id="guide-forget">Forgetting it</h2>
<p>When the user turns the option off or signs out, delete the entry.</p>
<pre class="code"><code>import os.secret

func forget(user: str):
    _gone := secret.Delete("com.example.app", user)
end</code></pre>
