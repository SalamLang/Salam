pkg.intro <<
<p><code>Vector</code> and <code>HashMap</code>, which turn up in every program, are defined in this package, but you do not have to import it to use them. The rest, such as the stack and the queue, become available with <code>import collections</code>.</p>
<p>All of these are generic: you set the element type with <code>&lt;...&gt;</code>, as in <code>collections.Stack&lt;str&gt;</code>. All of them allocate, so write <code>defer ....free()</code> right after creating one.</p>
<p>Which should you pick? For an ordinary list, <code>Vector</code>; for "last in, first out", <code>Stack</code>; for "first in, first out", <code>Queue</code>; for adding and removing at both ends, <code>Deque</code>; for fast lookup by a key, <code>HashMap</code>; for removing duplicates, <code>Set</code>; and for "always give me the smallest", <code>PriorityQueue</code>.</p>
>>

doc.Vector = A list whose size changes: the data structure you will use most. The elements sit next to each other in memory and access by index is immediate. You can also read and write elements with <code>[i]</code>.
doc.Vector.data = The address of the elements in memory.
doc.Vector.reserve = Reserves room for at least <code>need</code> elements in advance, so that later additions do not move the memory again.
doc.Vector.push = Adds an element at the end.
doc.Vector.pop = Removes the last element and returns it.
doc.Vector.get = Returns element number <code>i</code>.
doc.Vector.ref = Returns the address of element number <code>i</code>, so you can change it in place without a copy.
doc.Vector.set = Replaces element number <code>i</code>.
doc.Vector.resize_set = Like <code>set</code>, but grows the vector when <code>i</code> is past the end. The slots between the old length and <code>i</code> have no defined value, so either fill them in order or start with <code>zeros</code>.
doc.Vector.zeros = Gives the vector <code>n</code> zero elements.
doc.Vector.alloc = Sets the vector's length to <code>n</code> without initialising it; fill the elements before reading them.
doc.Vector.len = The number of elements.
doc.Vector.cap = The current capacity: how many more elements fit before new memory is taken.
doc.Vector.is_empty = True when the vector has no elements.
doc.Vector.first = The first element.
doc.Vector.last = The last element.
doc.Vector.clear = Removes every element but keeps the memory.
doc.Vector.insert = Inserts an element at position <code>i</code> and shifts the rest forward.
doc.Vector.remove_at = Removes and returns the element at position <code>i</code> and shifts the rest back.
doc.Vector.operator_index = The same as reading with <code>v[i]</code>.
doc.Vector.operator_index_set = The same as writing with <code>v[i] = x</code>.
doc.Vector.iter = Returns an iterator for walking the elements by hand. Most of the time <code>each ... in</code> is simpler.
doc.Vector.free = Releases the vector's memory.
doc.VectorIter = A vector iterator; walk element by element with <code>has_next</code>, <code>value</code> and <code>next</code>.
doc.VectorIter.data = The address of the vector's elements.
doc.VectorIter.len = The number of elements.
doc.VectorIter.pos = The current position.
doc.VectorIter.has_next = True when another element is left.
doc.VectorIter.value = The current element.
doc.VectorIter.next = Moves to the next element.
doc.HashMap = A map from key to value with fast lookup, like a dictionary. The order of the entries is not predictable; if the insertion order matters, see <code>OrderedMap</code>.
doc.HashMap.keys = The address of the array of keys.
doc.HashMap.vals = The address of the array of values.
doc.HashMap.state = The state of each slot: empty, filled or removed.
doc.HashMap.cap = The number of slots.
doc.HashMap.count = The number of keys present.
doc.HashMap.used = The number of slots in use, removed ones included.
doc.HashMap.put = Stores the value for a key, replacing an earlier value for the same key.
doc.HashMap.insert = The same as <code>put</code>.
doc.HashMap.has = True when the key is in the map.
doc.HashMap.get = Returns the value for a key. When the key is absent you get the zero value of the type, so ask with <code>has</code> first or use <code>get_or</code>.
doc.HashMap.get_or = Returns the value for a key, or the default when it is absent.
doc.HashMap.remove = Removes a key, and returns false when it was not there.
doc.HashMap.size = The number of keys.
doc.HashMap.is_empty = True when the map is empty.
doc.HashMap.iter = Returns an iterator over the keys and values. Most of the time <code>each key, value in</code> is simpler.
doc.HashMap.free = Releases the map's memory.
doc.MapIter = A map iterator.
doc.MapIter.keys = The address of the array of keys.
doc.MapIter.vals = The address of the array of values.
doc.MapIter.state = The state of the slots.
doc.MapIter.cap = The number of slots.
doc.MapIter.pos = The current position.
doc.MapIter.has_next = True when another entry is left.
doc.MapIter.key = The current key.
doc.MapIter.value = The current value.
doc.MapIter.next = Moves to the next entry.
doc.Stack = A stack: the last element added is the first one taken off, like a pile of books.
doc.Stack.items = The elements of the stack; the last one is the top.
doc.Stack.push = Puts an element on the stack.
doc.Stack.pop = Takes the top element off and returns it.
doc.Stack.peek = Shows the top element without taking it off.
doc.Stack.size = The number of elements.
doc.Stack.is_empty = True when the stack is empty.
doc.Stack.clear = Takes every element off.
doc.Stack.free = Releases the stack's memory.
doc.Queue = A queue: the first element in is the first one out, like a queue at a shop.
doc.Queue.inbox = The newly arrived elements.
doc.Queue.outbox = The elements ready to leave; whenever it empties it is refilled from <code>inbox</code>.
doc.Queue.enqueue = Adds an element at the back of the queue.
doc.Queue.dequeue = Takes the element at the front out.
doc.Queue.peek = Shows the element at the front without taking it out.
doc.Queue.size = The number of elements.
doc.Queue.is_empty = True when the queue is empty.
doc.Queue.free = Releases the queue's memory.
doc.Deque = A double-ended queue: you can add and remove at either end, and both are fast.
doc.Deque.front = The elements at the front end.
doc.Deque.back = The elements at the back end.
doc.Deque.push_front = Adds an element at the front.
doc.Deque.push_back = Adds an element at the back.
doc.Deque.pop_front = Removes the front element and returns it.
doc.Deque.pop_back = Removes the back element and returns it.
doc.Deque.front_val = Shows the front element without removing it.
doc.Deque.back_val = Shows the back element without removing it.
doc.Deque.size = The number of elements.
doc.Deque.is_empty = True when it is empty.
doc.Deque.get = Element number <code>i</code> counted from the front.
doc.Deque.free = Releases the memory.
doc.LinkedList = A doubly linked list; adding and removing at either end is fast.
doc.LinkedList.vals = The values of the nodes.
doc.LinkedList.nxt = The index of each node's next node.
doc.LinkedList.prv = The index of each node's previous node.
doc.LinkedList.head = The index of the first node.
doc.LinkedList.tail = The index of the last node.
doc.LinkedList.freed = The index of the first freed node, kept for reuse.
doc.LinkedList.count = The number of elements.
doc.LinkedList.push_back = Adds an element at the end.
doc.LinkedList.push_front = Adds an element at the front.
doc.LinkedList.pop_front = Removes the front element and returns it.
doc.LinkedList.pop_back = Removes the last element and returns it.
doc.LinkedList.front_val = The front element.
doc.LinkedList.back_val = The last element.
doc.LinkedList.size = The number of elements.
doc.LinkedList.is_empty = True when it is empty.
doc.LinkedList.get = Element number <code>i</code> from the front. Reaching it means walking from the front, so for repeated access by index a vector is better.
doc.LinkedList.to_vector = Returns the elements, in order, in a new vector.
doc.LinkedList.free = Releases the memory.
doc.CircularList = A circular list: after the last element you come back to the first, for taking turns in rotation, such as the players in a game.
doc.CircularList.items = The elements in the order they were added.
doc.CircularList.head = The index of the current element.
doc.CircularList.add = Adds an element to the list.
doc.CircularList.size = The number of elements.
doc.CircularList.is_empty = True when it is empty.
doc.CircularList.get = The element <code>i</code> places on from the current one; a negative number is accepted.
doc.CircularList.rotate = Moves the current element on by <code>k</code> places, or back with a negative number.
doc.CircularList.current = The current element: whose turn is it?
doc.CircularList.advance = Passes the turn to the next element.
doc.CircularList.to_vector = Returns the elements from the current one onward, in a new vector.
doc.CircularList.free = Releases the memory.
doc.Set = A set: each element only once. For removing duplicates and asking "is this one there?" quickly.
doc.Set.m = The map that holds the elements as keys.
doc.Set.add = Adds an element; if it is already there, nothing happens.
doc.Set.has = True when the element is in the set.
doc.Set.remove = Removes an element, and returns false when it was not there.
doc.Set.size = The number of elements.
doc.Set.is_empty = True when it is empty.
doc.Set.free = Releases the memory.
doc.Counter = A counter: it counts how many times it has seen each thing, such as the words in a text.
doc.Counter.m = A map from each thing to its count.
doc.Counter.add = Adds one to the count of <code>k</code>.
doc.Counter.add_n = Adds <code>n</code> to the count of <code>k</code>.
doc.Counter.count = How many times <code>k</code> has been seen, or zero if never.
doc.Counter.distinct = The number of different things counted.
doc.Counter.free = Releases the memory.
doc.PriorityQueue = A priority queue: the smallest element comes out each time, whatever order they went in. For scheduling work and for shortest path algorithms.
doc.PriorityQueue.h = The elements as a binary heap.
doc.PriorityQueue.push = Adds an element.
doc.PriorityQueue.peek = Shows the smallest element without removing it.
doc.PriorityQueue.size = The number of elements.
doc.PriorityQueue.is_empty = True when it is empty.
doc.PriorityQueue.pop = Removes the smallest element and returns it.
doc.PriorityQueue.free = Releases the memory.
doc.OrderedMap = A map from string to string that keeps the insertion order, for headers, settings and anywhere the display order matters.
doc.OrderedMap.keys = The keys in insertion order.
doc.OrderedMap.vals = The values in the same order.
doc.OrderedMap.idx = A map from key to its position, for fast lookup.
doc.OrderedMap.index_of = Returns the position of a key, or minus one.
doc.OrderedMap.len = The number of keys.
doc.OrderedMap.has = True when the key is there.
doc.OrderedMap.get = The value for a key, or an empty string when it is absent.
doc.OrderedMap.get_or = The value for a key, or the default.
doc.OrderedMap.set = Stores the value for a key; a new key goes on the end and an existing key keeps its place. It returns the key's position.
doc.OrderedMap.key_at = Key number <code>i</code>.
doc.OrderedMap.val_at = Value number <code>i</code>.
doc.OrderedMap.set_at = Replaces value number <code>i</code>.
doc.OrderedMap.remove = Removes a key and returns the position it had, or minus one.
doc.OrderedMap.clone_keys = A copy of the keys in insertion order.
doc.OrderedMap.free = Releases the memory.
doc.Pair = A pair of values, for returning two things from a function or keeping a key and a value together.
doc.Pair.first = The first value.
doc.Pair.second = The second value.
doc.contains = True when <code>x</code> is in the vector.
doc.index_of = The position of the first occurrence of <code>x</code>, or minus one.
doc.reverse = A reversed copy of the vector; the original is unchanged.
doc.clone = An independent copy of the vector.
doc.slice = A new vector of <code>count</code> elements starting at <code>start</code>.
doc.swap = Exchanges two elements.
doc.count_of = How many times <code>x</code> occurs in the vector.
doc.last_index_of = The position of the last occurrence of <code>x</code>, or minus one.
doc.extend = Adds every element of <code>src</code> to the end of <code>dst</code>.
