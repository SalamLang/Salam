pkg.intro <<
<p>The <code>os</code> package is the simplest way to talk to the system: each function does one thing, and most of them take a file or directory path as a string. The functions that change something, such as <code>Remove</code> and <code>Mkdir</code>, return zero on success and some other number otherwise.</p>
<p>There are sub-packages for more specialised work: <a href="/std/os-process/">os.process</a> for running other programs, <a href="/std/os-shell/">os.shell</a> for capturing command output, <a href="/std/os-platform/">os.platform</a> for identifying the system, and the <a href="/std/fs-file/">fs.file</a> and <a href="/std/fs-dir/">fs.dir</a> packages, which do more.</p>
>>

doc.Run = Runs a command in the system shell and returns its exit code; the command's output goes straight to the program's own output.
doc.RunCapture = Runs a command and returns its exit code and its output together in a <code>CmdResult</code>.
doc.Output = Runs a command and returns only its output text, including the final newline.
doc.Pid = The process id of the running program.
doc.FileInfo = What <code>Stat</code> returns.
doc.FileInfo.size = The size of the file in bytes.
doc.FileInfo.is_dir = True when the path is a directory.
doc.FileInfo.exists = True when the path exists.
doc.CmdResult = The result of running a command with <code>RunCapture</code>.
doc.CmdResult.code = The command's exit code; zero means success.
doc.CmdResult.out = The command's output.
doc.Open = Opens a file in the given mode: <code>"rb"</code> to read, <code>"wb"</code> to rewrite and <code>"ab"</code> to append. It returns null when it cannot.
doc.Exit = Ends the program immediately with the given code. Inside <code>main</code> write <code>ret</code> instead, because exiting does not run the <code>defer</code> statements (error E109).
doc.Abort = Stops the program abruptly with an error, for a situation with no way to carry on.
doc.Args = The program's command line arguments; element zero is the program's own name.
doc.Env = The value of an environment variable, or an empty string when it is not set. The <a href="/std/env/">env</a> package does more.
doc.Remove = Deletes a file.
doc.Mkdir = Creates a directory; the parent has to exist already.
doc.Rmdir = Deletes an empty directory.
doc.Copy = Copies a file.
doc.Move = Moves or renames a file or a directory.
doc.ListDir = The names of everything inside a directory, without descending into subdirectories.
doc.IsDir = True when the path is a directory.
doc.Walk = The paths of every file inside a directory and its subdirectories; the directories themselves are not in the list.
doc.Exists = True when the path, file or directory, exists.
doc.Cwd = The program's current directory.
doc.Chdir = Changes the current directory; later relative paths are resolved from there.
doc.TempDir = The system's temporary directory, such as <code>/tmp</code>.
doc.ReadFile = Reads the whole content of a file, or an empty string when it cannot.
doc.WriteFile = Rewrites a file.
doc.AppendFile = Adds to the end of a file.
doc.FileSize = The size of a file in bytes, or minus one when it is not there.
doc.Stat = Returns everything about a path at once; when the path is absent, <code>exists</code> is false.
doc.MkdirAll = Creates a directory along with every parent it needs, and does nothing when it already exists.
doc.RemoveAll = Deletes a file or a directory with everything inside it. Take care; it cannot be undone.
doc.CopyTree = Copies a directory with all its subdirectories and files.
doc.ListDirs = Only the names of a directory's subdirectories.
