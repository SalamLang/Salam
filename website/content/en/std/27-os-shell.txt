pkg.intro <<
<p>The <code>os.shell</code> package runs a command and gives back the whole result at once: the exit code, the output and the error output.</p>
<div class="note"><p><code>Exec</code> splits the command on spaces alone and no shell is involved: pipes (<code>|</code>), redirection (<code>&gt;</code>) and quoting do not work. For those, call <code>sh -c</code> through <code>Run</code>, as the example does.</p></div>
>>

doc.CmdResult = The result of a command.
doc.CmdResult.code = The exit code; zero means success.
doc.CmdResult.out = The standard output.
doc.CmdResult.err = The error output.
doc.Run = Runs a program with its arguments given separately and waits for it to finish.
doc.Exec = Splits a command string on spaces into a program and its arguments and runs it, with no shell.
doc.System = Runs a command in the real shell (<code>/bin/sh</code> or <code>cmd</code>) and returns only the exit code; the output is printed directly.

ex.CmdResult = os-shell-Run
ex.Exec = os-shell-Run
ex.System = os-shell-Run
