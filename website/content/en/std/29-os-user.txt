pkg.intro <<
<p>Programs usually keep their settings in the user config directory and throwaway data in the user cache directory. This package gives the right path on every operating system; the config directory is <code>~/.config</code> on Linux and somewhere else on macOS and Windows.</p>
>>

doc.Username = The name of the current user.
doc.Uid = The numeric user id; minus one on Windows.
doc.Gid = The numeric group id of the user; minus one on Windows.
doc.HomeDir = The home directory of the user.
doc.ConfigDir = The standard directory for program settings.
doc.CacheDir = The standard directory for program caches.
