pkg.intro <<
<p>The <code>fs</code> package holds a few shared functions and three sub-packages you will use far more often: <a href="/std/fs-file/">fs.file</a>, <a href="/std/fs-dir/">fs.dir</a> and <a href="/std/fs-path/">fs.path</a>. Times are in seconds since the start of 1970, Unix time.</p>
<p>Write permissions in octal, such as <code>0o644</code>, meaning the owner reads and writes and everyone else reads. <code>Permissions</code> returns the same digits as an ordinary number, such as <code>644</code>, so that it reads easily.</p>
>>

doc.ModTime = When the file's content was last changed.
doc.AccessedTime = When the file was last read.
doc.CreatedTime = When the file was created, or zero where the system does not keep it.
doc.Chmod = Changes a file's permissions; give them in octal, such as <code>0o644</code>.
doc.Permissions = A file's permissions, as octal digits, such as <code>644</code>.

ex.AccessedTime = fs-ModTime
