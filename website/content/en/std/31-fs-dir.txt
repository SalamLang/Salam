pkg.intro <<
<p>The <code>fs.dir</code> package covers everything you do with directories. When a function fails it records the detail in the <a href="/std/os-error/">os.error</a> package.</p>
<p>Note that <code>Exists</code> here is true only for a <em>directory</em>; for files use <code>fs.file.Exists</code>.</p>
>>

doc.Mkdir = Creates one directory.
doc.MkdirAll = Creates a directory along with every parent it needs.
doc.Remove = Removes an empty directory.
doc.RemoveAll = Removes a directory with everything in it.
doc.List = The names of everything inside a directory.
doc.ListDirs = Only the names of the subdirectories.
doc.ListFiles = Only the names of the files.
doc.Walk = The paths of every file in a directory and its subdirectories.
doc.Copy = Copies a directory with all its contents.
doc.Move = Moves a directory; when a direct move is impossible, across two disks for instance, it copies and then removes the original.
doc.Exists = True when the path exists and is a <em>directory</em>.
doc.IsDir = True when the path is a directory.
doc.Size = The total size of every file in the directory and its subdirectories, in bytes.
doc.Permissions = The directory's permissions, as octal digits.
doc.ModTime = When the directory was last changed.
