pkg.intro <<
<p>The <code>fs.file</code> package is <strong>deprecated</strong>. Everything in it now lives in <a href="/std/fs/">fs</a>, and each function here only calls its <code>fs</code> twin, so old programs keep compiling and behave the same. In new code write <code>import fs</code> and call <code>fs.ReadText(path)</code>, <code>fs.WriteText(path, text)</code>, <code>fs.Copy(src, dst)</code> and the rest straight from <code>fs</code>. <code>file.FileInfo</code> is the same type as <code>fs.FileInfo</code>, so values pass between the two without conversion.</p>
<p>To migrate, change <code>import fs.file</code> to <code>import fs</code> and replace each <code>file.</code> prefix with <code>fs.</code>. The names, arguments and results are exactly the same. See the <a href="/std/fs/">fs</a> page for the guides and the full description of each function.</p>
>>
