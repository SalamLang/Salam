pkg.description = The fs/file package in Salam: reading text and lines, atomic writes, file information and permissions, MIME types, copying and renaming, and SHA-256 digests, with examples.
pkg.import = fs.file
pkg.intro <<
<p>The <code>fs.file</code> package is the fullest set of tools for working with files. For settings and anything else that matters, use <code>AtomicWrite</code>: it writes to a temporary file and then replaces the original, so an interrupted program never leaves a half written file behind.</p>
>>

doc.FileInfo = Everything about a file.
doc.FileInfo.size = The size in bytes.
doc.FileInfo.mod_time = When it was last changed.
doc.FileInfo.accessed_time = When it was last read.
doc.FileInfo.created_time = When it was created.
doc.FileInfo.permissions = The permissions, as octal digits.
doc.FileInfo.exists = True when the file exists.
doc.Open = Opens a file to work through it piece by piece; the modes are the same as <a href="/std/os/">os.Open</a>.
doc.Close = Closes an open file.
doc.ReadText = Reads the whole file as text.
doc.ReadAll = Reads the whole file; it suits binary files too.
doc.ReadBytes = Reads the first <code>n</code> bytes of the file.
doc.ReadLines = Returns the file's lines in a vector.
doc.WriteText = Writes text to a file, replacing what was there.
doc.WriteBytes = Writes binary data to a file.
doc.Append = Adds to the end of a file.
doc.AtomicWrite = Writes a file safely and all at once: either the complete new version survives or the old one does, never a half written file.
doc.Size = The size of a file in bytes.
doc.ModTime = When it was last changed.
doc.AccessedTime = When it was last read.
doc.CreatedTime = When it was created.
doc.Permissions = The permissions, as octal digits.
doc.Chmod = Changes the permissions; give the value in octal, such as <code>0o600</code>.
doc.Extension = The file's extension, with its dot.
doc.MimeType = The file's MIME type from its extension, for serving it over the web.
doc.Stat = Everything about a file at once.
doc.Copy = Copies a file.
doc.Move = Moves a file.
doc.Rename = Renames a file.
doc.Delete = Deletes a file.
doc.Exists = True when the file exists.
doc.Md5Hex = The MD5 digest of the file's content; for a quick comparison only, not for security.
doc.Sha1Hex = The SHA-1 digest of the file's content.
doc.Sha256Hex = The SHA-256 digest of the file's content, for checking that a download arrived intact.
doc.Sha512Hex = The SHA-512 digest of the file's content.
