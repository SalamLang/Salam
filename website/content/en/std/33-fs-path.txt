pkg.intro <<
<p>Do not build paths by concatenating strings; <code>Join</code> puts the right separator in for you. When a path comes from a user, check it with <code>IsSafe</code> before opening it, so that nobody climbs out of the permitted directory with <code>../..</code>.</p>
<p>Every function here works on the text of the path alone. None of them looks at the disk, except <code>Abs</code> and <code>Rel</code> with a relative path, which read the current directory. To create, read or list files, combine this package with <a href="/std/fs-dir/">fs.dir</a>, <a href="/std/fs-file/">fs.file</a> or <a href="/std/io/">io</a>, as the guide below does.</p>

<h2 id="guide-user-paths">Serving a file a user asked for</h2>
<p>A download handler gets a name such as <code>2026/report.pdf</code> from the request and has to turn it into a file inside one folder. <code>IsSafe</code> simplifies the joined path first and then checks that it still starts with the folder, so <code>a/../b.txt</code> is fine while <code>../secret.txt</code> and <code>a/../../etc/passwd</code> are refused. An empty name is refused too.</p>
{{example.fs-path-guide-safe}}
<p>Look at the <code>/etc/passwd</code> line: <code>Join</code> does not let an absolute second part replace the first, so the result lands inside the folder and is safe. The check works on text only; it does not follow symbolic links, so do not put links that point outside the folder in a directory you serve.</p>

<h2 id="guide-output-paths">Mapping one folder tree onto another</h2>
<p>A static site generator reads <code>content/blog/hello.md</code> and writes <code>public/blog/hello.html</code>. <code>Rel</code> gives the part below the source folder, <code>Dirname</code> and <code>Stem</code> take it apart, and <code>Join</code> and <code>Clean</code> build the new path. <code>Stem</code> removes only the last extension, so <code>salam.v2.md</code> keeps its <code>.v2</code>.</p>
{{example.fs-path-guide-output}}
<p>For a file directly in the source folder <code>Dirname</code> returns <code>.</code>; the final <code>Clean</code> removes the <code>/.</code> that <code>Join</code> leaves behind. The example uses absolute paths because <code>Rel</code> makes relative ones absolute against the current directory first.</p>

<h2 id="guide-backup">Making a new name next to a file</h2>
<p>To put a backup, a thumbnail or a converted copy next to the original, keep the folder and change only the name. Here <code>Stem</code> and <code>Ext</code> turn <code>plan.md</code> into <code>plan.bak.md</code>, and <a href="/std/fs-dir/">fs.dir</a> and <a href="/std/io/">io</a> do the actual work on disk.</p>
{{example.fs-path-guide-backup}}

<h2 id="guide-which">Which function for which job</h2>
<p>Several functions here have close names. <code>Filename</code> keeps the extension; <code>Basename</code> and <code>Stem</code> both drop it. <code>Normalize</code> only changes <code>\</code> to <code>/</code>; <code>Clean</code> is the one that resolves <code>.</code> and <code>..</code>.</p>

doc.PathParts = The two parts of a path.
doc.PathParts.dir = The directory part.
doc.PathParts.base = The file name.
doc.Join = Joins two parts of a path with the right separator.
doc.Split = Splits a path into its directory and its file name.
doc.Normalize = Turns Windows <code>\</code> separators into <code>/</code> and does nothing else. To resolve <code>..</code> and <code>.</code>, see <code>Clean</code>.
doc.Clean = Simplifies a path: it resolves <code>.</code> and <code>..</code> and removes repeated separators.
doc.IsAbs = True when the path is absolute.
doc.Abs = Makes the path absolute against the current directory.
doc.Rel = The path of <code>target</code> relative to <code>base</code>.
doc.Parent = The parent directory.
doc.Dirname = The directory part of a path.
doc.Filename = The file name with its extension.
doc.Basename = The file name without the directory and without its extension; the same as <code>Stem</code>. For the name with its extension, use <code>Filename</code>.
doc.Ext = The extension, with its dot.
doc.Stem = The file name without the extension.
doc.IsSafe = True when the given path, once simplified, still lies inside the <code>base</code> directory.
doc.Validate = True when the path is not empty; it checks nothing else.
