<p>The <code>filepath</code> package works on strings alone and never touches the file system, apart from <code>Abs</code>, which needs the current directory. The <a href="/std/fs-path/">fs.path</a> package is built on it; use whichever reads better to you.</p>

doc.Separator = The separator between the parts of a path: <code>/</code>.
doc.Normalize = Turns <code>\</code> separators into <code>/</code>.
doc.IsAbs = True when the path is absolute; a Windows path such as <code>C:/</code> counts as absolute.
doc.Join = Joins two parts of a path.
doc.Base = The name of the last part of a path.
doc.Dir = The path without its last part.
doc.Ext = The extension, with its dot.
doc.Stem = The last part's name without its extension.
doc.Clean = Simplifies a path.
doc.Abs = Makes a path absolute.
doc.Rel = The relative path from <code>base</code> to <code>target</code>.
doc.Validate = True when the path is not empty.
doc.IsSafe = True when the path stays inside <code>base</code>.
