pkg.title = The env package in Salam | Environment variables and .env files
pkg.description = The env package in Salam: reading environment variables as numbers and booleans, loading a .env file, the production and development profiles, and masking sensitive keys, with examples.
pkg.intro <<
<p>Settings such as a server port, a database address and API keys belong in environment variables rather than in the code. The <code>env</code> package reads them with the right type and gives you a default when they are not set. It can load them from a <code>.env</code> file too.</p>
<p>The "profile" is read from <code>SALAM_ENV</code> and says whether the program is running in development, test or production.</p>
>>

doc.Get = The value of a variable, or an empty string.
doc.GetOr = The value of a variable, or the default when it is not set.
doc.Has = True when the variable is set.
doc.GetInt = The value as a whole number, or the default when it is not set or is not a number.
doc.GetFloat = The value as a decimal number, or the default.
doc.GetBool = The value as a boolean; <code>true</code>, <code>1</code> and <code>yes</code> count as true.
doc.Set = Sets a variable for this program and for the processes it starts afterwards.
doc.Unset = Removes a variable.
doc.Mask = Masks a sensitive value for a log, showing only the first and last two characters.
doc.GetMasked = Returns a variable's value masked.
doc.Profile = The name of the run profile, from <code>SALAM_ENV</code>.
doc.IsProduction = True in the <code>production</code> profile.
doc.IsDevelopment = True in the <code>development</code> profile.
doc.IsTest = True in the <code>test</code> profile.
doc.IsStaging = True in the <code>staging</code> profile.
doc.Load = Loads a <code>KEY=VALUE</code> file without changing variables that are already set. It returns how many variables were read.
doc.Overload = Like <code>Load</code>, but it replaces existing variables with the file's values too.
doc.LoadText = Does the same from text instead of a file.
doc.LoadDotEnv = Loads the <code>.env</code> file.
doc.LoadProfile = Loads the <code>.env.&lt;profile&gt;</code> file from the given directory, such as <code>.env.test</code> in the test profile.
doc.Expand = Replaces <code>${name}</code> and <code>${name:-default}</code> in text with the values of the variables.
