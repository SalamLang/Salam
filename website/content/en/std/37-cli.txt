pkg.en = cli
pkg.name = cli
pkg.group = System and tools
pkg.summary = Command line programs with several commands, like <code>git commit</code>, and asking the user questions.
pkg.title = The cli package in Salam | Multi-command programs and prompts
pkg.description = The cli package in Salam: registering commands, dispatching arguments, automatic help, checking required flags, and prompting and confirming with the user, with examples.
pkg.intro <<
<p>Many tools have several commands: <code>salam build</code>, <code>salam run</code>. The <code>cli</code> package registers the commands, works out from the first argument which one was asked for, and builds the overall help text. For each command's own flags, use the <a href="/std/flag/">flag</a> package alongside it.</p>
<p><code>Prompt</code> and <code>Confirm</code> ask the user something in the terminal; their example is not run here because it would wait for an answer.</p>
>>

doc.CmdHelp = What <code>Dispatch</code> returns when help was asked for, or no argument was given.
doc.CmdVersion = What <code>Dispatch</code> returns when the version was asked for.
doc.CmdUnknown = What <code>Dispatch</code> returns for a command that was never registered.
doc.App = A command line program and its commands.
doc.App.name = The program's name.
doc.App.desc = The program's description.
doc.App.version = The program's version.
doc.App.cmd_names = The names of the commands.
doc.App.cmd_descs = The descriptions of the commands.
doc.New = Creates a program with a name, a description and a version.
doc.Register = Registers one command with its description.
doc.HasCommand = True when the command has been registered.
doc.CommandDesc = The description of a command.
doc.Dispatch = Says from the first argument which command was asked for. Pass the arguments <em>without</em> the program's name. <code>--help</code> and <code>--version</code> are recognised automatically.
doc.RemainingArgs = The arguments after the first, which is the command name, for handing to the flag package.
doc.Usage = The program's overall help text with the list of commands.
doc.RequireFlags = Of the names you give, returns the flags that did not appear on the command line; for required flags.
doc.Confirm = Asks a yes or no question; <code>y</code> or <code>yes</code> is true and anything else is false.
doc.Prompt = Asks a question and returns the user's answer.
doc.PromptOr = Like <code>Prompt</code>, but returns the default when the user types nothing.
