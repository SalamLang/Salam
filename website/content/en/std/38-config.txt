pkg.title = The config package in Salam | INI and YAML settings files
pkg.description = The config package in Salam: reading INI, YAML and env files, sectioned keys, merging settings and writing them back out, with examples.
pkg.intro <<
<p>The <code>config</code> package keeps settings as an ordered list of keys and values. Keys in sections are dotted: the key <code>host</code> in the <code>[db]</code> section of an INI file, or under <code>db:</code> in YAML, becomes <code>db.host</code>.</p>
<p>The usual pattern is to read the default settings, <code>Merge</code> the current environment's settings on top, and then read the values with the right type.</p>
>>

doc.Config = A set of settings.
doc.Config.m = The ordered map that keeps the keys and values in order.
doc.New = Empty settings.
doc.Len = The number of keys.
doc.Has = True when the key is there.
doc.Set = Sets a key's value.
doc.Get = A key's value, or an empty string.
doc.GetOr = A key's value, or the default.
doc.GetInt = A key's value as a whole number, or the default.
doc.GetFloat = A key's value as a decimal, or the default.
doc.GetBool = A key's value as a boolean; <code>true</code>, <code>1</code> and <code>yes</code> are true.
doc.Remove = Removes a key, returning false when it was not there.
doc.Keys = Every key, in order.
doc.Section = Returns one section's settings on their own, with the section prefix stripped from the keys.
doc.Merge = Builds new settings with the keys of <code>override</code> sitting on top of <code>base</code>.
doc.Free = Releases the settings' memory.
doc.ParseINI = Reads INI text.
doc.ParseEnv = Reads <code>KEY=VALUE</code> text.
doc.ParseYAML = Reads simple YAML text: nested keys and values.
doc.LoadINI = Reads an INI file.
doc.LoadEnv = Reads an env file.
doc.LoadYAML = Reads a YAML file.
doc.FormatINI = Turns the settings into INI text.
doc.FormatEnv = Turns the settings into <code>KEY=VALUE</code> text.
doc.FormatEnvExport = Like the env form, with <code>export</code> before each line, to be run in a shell.
