pkg.name = log
pkg.group = System and tools
pkg.summary = Recording what a program does, with levels, a prefix, structured fields, JSON output and writing to a file.
pkg.title = The log package in Salam | Levelled and JSON logging
pkg.description = The log package in Salam: levels from debug to error, formatted messages, key and value fields, JSON logs, and writing to a file with rotation, with examples.
pkg.intro <<
<p>For a program running on a server, <code>println</code> is not enough: you need to know how important each message is and when it was written, and to be able to silence the unimportant ones. The <code>log</code> package has four levels, debug, info, warn and error, and records only the messages at or above the level you set; the default level is info.</p>
<p>By default the log goes to standard error with a timestamp. The examples below turn the time off so their output is stable.</p>
>>

doc.LevelDebug = The debug level: detail for whoever is working on the code.
doc.LevelInfo = The info level: ordinary events.
doc.LevelWarn = The warn level: something unusual, but not an error.
doc.LevelError = The error level.
doc.FormatText = The readable text format.
doc.FormatJSON = The JSON format, one object per line, for log collectors.
doc.LevelName = The English name of a level.
doc.ParseLevel = Turns text such as <code>"warn"</code> into a level, for reading the level from a configuration file.
doc.SetLevel = The lowest level that is recorded.
doc.GetLevel = The current level.
doc.SetPrefix = A prefix that comes after the level on every message.
doc.ShowTime = Whether to show the time on each message.
doc.SetFormat = The text or JSON format.
doc.GetFormat = The current format.
doc.SetRotation = For a file log: when the file grows past <code>max_bytes</code> it is set aside, and at most <code>max_backups</code> old copies are kept.
doc.ToStderr = Write the log to standard error, which is the default.
doc.ToStdout = Write the log to standard output.
doc.ToFile = Write the log to a file, or return minus one when it cannot.
doc.CloseFile = Closes the log file.
doc.Log = Records a message at the level you choose.
doc.Debug = A debug message.
doc.Info = An info message.
doc.Warn = A warning.
doc.Error = An error message.
doc.Debugf = A formatted debug message; every <code>{}</code> is filled with the next value.
doc.Infof = A formatted info message.
doc.Warnf = A formatted warning.
doc.Errorf = A formatted error message.
doc.Fatal = Records an error message and ends the program with code one. Its example is not run here.
doc.Field = Builds one <code>key=value</code> field.
doc.FieldInt = A field with a numeric value.
doc.FieldBool = A field with a boolean value.
doc.KV = Puts a message and its fields together.
doc.DebugKV = A debug message with key and value fields.
doc.InfoKV = An info message with fields, which makes logs much easier to search.
doc.WarnKV = A warning with fields.
doc.ErrorKV = An error message with fields.
