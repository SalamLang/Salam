pkg.title = The testing package in Salam | Writing unit tests
pkg.description = The testing package in Salam: writing unit tests with assertions over numbers, strings and decimals, counting passes and failures, and printing a summary, with an example.
pkg.intro <<
<p>A test is a small program that checks your code does what it should. The <code>testing</code> package has assertions that print a clear message when they fail but do not stop the program, so every test runs and <code>Summary</code> says at the end how many passed and how many failed.</p>
<p>The value <code>Summary</code> returns is the number of failures. Return it from <code>main</code> so that the test program ends with a non-zero code in CI.</p>
>>

doc.Assert = Records a failure when the condition is false.
doc.AssertMsg = Like <code>Assert</code>, with a message of your own.
doc.AssertTrue = The condition has to be true.
doc.AssertFalse = The condition has to be false.
doc.AssertEqInt = Two whole numbers have to be equal; on failure both values are printed.
doc.AssertEqInt64 = Two 64-bit whole numbers have to be equal.
doc.AssertEqFloat = Two decimal numbers have to differ by less than <code>eps</code>. Never compare decimals with <code>==</code>.
doc.AssertContains = The first string has to contain the second.
doc.AssertEqStr = Two strings have to be equal.
doc.AssertEqBool = Two booleans have to be equal.
doc.AssertNeInt = Two whole numbers have to differ.
doc.AssertNeStr = Two strings have to differ.
doc.AssertNil = The pointer has to be null.
doc.AssertNotNil = The pointer must not be null.
doc.Reset = Sets the counters back to zero.
doc.Passed = The number of assertions that passed.
doc.Failed = The number of assertions that failed.
doc.Summary = Prints the summary and returns the number of failures.
