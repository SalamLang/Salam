pkg.summary = Structured errors with a kind, a message, a chain of causes, metadata and a retry policy.
pkg.title = The error package in Salam | Structured errors and retries
pkg.description = The error package in Salam: building an error with a kind and a message, wrapping an error with its cause, metadata, testing the kind, and a retry policy with exponential backoff, with examples.
pkg.intro <<
<p>A function that may fail can return an <code>error.Error</code>: either "nil", meaning everything went well, or an error with a <strong>kind</strong>, such as "not found", and a <strong>message</strong>. The kind is for the code to decide on; the message is for a person to read.</p>
<p>When an error comes up from a lower layer, <code>Wrap</code> it so the current layer's explanation is added. The final message shows the whole chain, as in "could not save the report: the disk is full", and <code>RootMessage</code> gives the original cause.</p>
<p>For transient errors, such as a dropped network connection, <code>RetryPolicy</code> says when and how often to try again and how long to wait between attempts; the delay doubles each time.</p>
>>
