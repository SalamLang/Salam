pkg.intro <<
<p>Most programs never need this package: vectors, maps and strings look after their own memory. The <code>mem</code> package is for low-level work, such as talking to a C library or building a data structure of your own. Everything you take with <code>Allocate</code> has to be given back with <code>Free</code>.</p>
<p>An <strong>arena</strong> is one large block you take pieces off the front of and then release all at once; it is very fast for work with many small objects that share a lifetime. A <strong>pool</strong> hands out and takes back blocks of one fixed size.</p>
>>

doc.Arena = A memory arena.
doc.Arena.buf = The address of the arena's memory.
doc.Arena.cap = The capacity in bytes.
doc.Arena.used = How much has been taken.
doc.NewArena = Builds an arena of the given capacity.
doc.ArenaAlloc = Takes memory off the arena; the size is rounded up to a multiple of eight. It returns null when there is no room, or when the size is zero.
doc.ArenaAllocZeroed = Like <code>ArenaAlloc</code>, with the memory zeroed.
doc.ArenaReset = Takes back everything at once so the arena can be used again.
doc.ArenaFree = Releases the arena's memory.
doc.ArenaUsed = The bytes taken so far.
doc.ArenaCapacity = The arena's capacity.
doc.ArenaRemaining = The bytes left.
doc.Pool = A pool of equally sized blocks.
doc.Pool.block_size = The size of each block.
doc.Pool.block_count = The number of blocks.
doc.Pool.blocks = The address of the blocks' memory.
doc.Pool.free_list = The list of free blocks.
doc.NewPool = Builds a pool with the given number and size of blocks.
doc.PoolAlloc = Hands out a free block, or null when none is left.
doc.PoolFree = Gives a block back to the pool; the next allocation hands out the same one.
doc.PoolBlockSize = The block size.
doc.PoolCapacity = The total number of blocks.
doc.PoolDestroy = Releases the pool's memory.
doc.Allocate = Takes a piece of memory of the given size; its contents are undefined.
doc.Reallocate = Changes the size of memory already taken and keeps its contents; it may return a new address.
doc.Free = Gives memory back.
doc.Set = Fills <code>n</code> bytes with the given value.
doc.Copy = Copies <code>n</code> bytes; the two ranges must not overlap.
doc.MemMove = Like <code>Copy</code>, but correct even when the ranges overlap.
doc.AllocateZeroed = Takes zeroed memory.
doc.AllocateArray = Takes zeroed memory for <code>count</code> elements of <code>size</code> bytes each.
doc.AllocCount = The number of allocations; zero unless the program was built with memory debugging.
doc.FreeCount = The number of frees; only with memory debugging.
doc.LiveBytes = The bytes taken and not yet given back.
doc.PeakBytes = The most memory held at one moment.
doc.IsMemDebug = True when the program was built with allocation counting.
doc.IsAsanActive = True when the program was built with the ASan checker.
doc.MemDebugActive = True when either memory checker is on.
doc.CheckLeaks = Reports any memory that was never given back; call it at the end of the program.
