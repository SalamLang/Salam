group.Key.title = Key codes
group.Key = The value of the <code>code</code> field of a <code>Key</code>. For the function keys, <code>KeyF1</code> is the code of F1 and F2 through F12 follow it in order.
group.Style.title = Style codes
group.Style = The display codes for text style; used with <code>Style</code> or <code>Sgr</code>.
group.Fg.title = Text colours
group.Fg = The text colour codes. Adding <code>Bright</code> to one of them gives the bright variant of the same colour, so 31 + 60 is bright red.
group.Bg.title = Background colours
group.Bg = The background colour codes; each is 10 more than the matching text colour.
group.Color.title = Colour modes
group.Color = The values for <code>SetColorMode</code>. In automatic mode, colour is only written when the output is a terminal.
group.Std.title = Standard file descriptors
group.Std = The descriptors of standard input, output and error, for <code>IsTTY</code> and <code>MakeRaw</code>.
pkg.intro <<
<p>The <code>term</code> package has everything a good looking command line program needs: text colour and style, progress bars, and for full screen programs, cursor movement and reading keys one at a time.</p>
<p>The colour functions, such as <code>Red</code>, return a new string and print nothing. When the output goes to a file or another program, or <code>NO_COLOR</code> is set, nothing is added and the text stays plain. <code>SetColorMode</code> changes that behaviour.</p>
<p>The functions whose names start with <code>Seq</code> only return the escape sequence, and the one with the same name without the prefix sends it right away. To read keys, put the terminal into raw mode with <code>MakeRaw</code> or <code>MakeCbreak</code>, and always put it back with <code>Restore</code>.</p>
>>
