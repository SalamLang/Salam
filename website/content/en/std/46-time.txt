pkg.description = The time package in Salam: the current time, durations and unit conversion, formatting and parsing ISO and HTTP dates, local and UTC time, measuring elapsed time, timers and tickers, with examples.
pkg.intro <<
<p>There are two kinds of "time" in this package. An <strong>instant</strong> is a number of seconds since the start of 1970 in UTC, the Unix epoch, and is what you use for dates and clock times. A <strong>duration</strong> is a span with nanosecond precision, such as "1 hour 30 minutes", which you can add up and compare.</p>
<p>Functions such as <code>Year</code> and <code>FormatDate</code> work in the machine's local time, and their <code>UTC</code> counterparts work in UTC. To measure how long a piece of code took, use the <strong>monotonic</strong> clock (<code>MonoNanos</code>) rather than <code>Now</code>; the system clock can jump forwards or backwards.</p>
<p>For the Persian and Hijri calendars and for time zones, see the <a href="../calendar/">calendar</a> package.</p>
>>

doc.Timer = A one-shot timer: it says whether the span you set has passed.
doc.Timer.deadline_ns = The end instant on the monotonic clock, in nanoseconds.
doc.Timer.active = Whether the timer is running.
doc.Timer.expired = True when the timer is running and its span has passed.
doc.Timer.remaining = The time left, or zero when it has passed or been stopped.
doc.Timer.wait = Sleeps until the span is over.
doc.Timer.reset = Starts the timer again from now, for a new span.
doc.Timer.stop = Stops the timer; from then on it never expires.
doc.Ticker = A ticker: it "ticks" at a fixed interval.
doc.Ticker.interval_ns = The interval between ticks, in nanoseconds.
doc.Ticker.next_ns = The instant of the next tick.
doc.Ticker.active = Whether the ticker is running.
doc.Ticker.dropped = How many ticks were missed because the program came back to the ticker late.
doc.Ticker.fired = True when a tick is due, and it moves on to the next one; it does not wait. For loops that have other work to do.
doc.Ticker.wait = Sleeps until the next tick.
doc.Ticker.advance = Moves the deadline on by one tick, counting and skipping the missed ticks so the ticker does not fall behind.
doc.Ticker.remaining = The time left until the next tick.
doc.Ticker.reset = Changes the interval and starts again from now.
doc.Ticker.stop = Stops the ticker.
doc.NewTimer = A timer that expires after the given span.
doc.NewTicker = A ticker with the given interval; a zero or negative interval makes an inactive ticker.
doc.AfterFunc = Waits for the given span and then runs the function. It happens on the same thread and does not return until the function is done.
doc.Every = Runs the function at a fixed interval for as long as it returns true, and returns how many times it ran.
doc.RepeatEvery = Runs the function <code>count</code> times at the given interval.
doc.WaitUntil = Checks the condition once every <code>poll</code> until it holds or <code>limit</code> passes, and says whether it held.
doc.SecondsPerMinute = The number of seconds in a minute.
doc.SecondsPerHour = The number of seconds in an hour.
doc.SecondsPerDay = The number of seconds in a day.

doc.DateTime.epoch = The seconds since the Unix epoch.
doc.Now = The current instant in seconds since the Unix epoch.
doc.NowDateTime = The current instant as a <code>DateTime</code>.
doc.FromEpoch = A <code>DateTime</code> from a number of epoch seconds.
doc.Epoch = The epoch seconds of a <code>DateTime</code>.

doc.YearUTC = The year of this instant in UTC.

doc.Second = The second of this instant in local time.
doc.SecondUTC = The second of this instant in UTC.
doc.Weekday = The day of the week in local time: zero is Sunday, one Monday, up to six for Saturday.
doc.YearDay = Which day of the year it is, counting from one, in local time.
doc.FormatDate = The local date as <code>2024-03-20</code>.
doc.FormatTime = The local clock time as <code>09:30:00</code>.
doc.Format = The local date and time with a space between them.

doc.FormatHTTPDate = The date format of HTTP headers, always in UTC: <code>Wed, 20 Mar 2024 14:05:09 GMT</code>.
doc.Sleep = Holds the program for a number of milliseconds.
doc.DiffSeconds = How many seconds there are from <code>earlier</code> to <code>later</code>.
doc.Since = How many seconds have passed since that instant.
doc.Until = How many seconds are left until that instant, negative when it is past.
doc.Duration = A span of time with nanosecond precision; it may be negative.
doc.Duration.ns = The span in nanoseconds.
doc.Duration.nanos = The span in nanoseconds.
doc.Duration.micros = The span in whole microseconds.
doc.Duration.millis = The span in whole milliseconds.
doc.Duration.secs = The whole seconds, with no fraction.
doc.Duration.seconds = The span in seconds, with a fraction.
doc.Duration.minutes = The span in minutes, with a fraction.
doc.Duration.hours = The span in hours, with a fraction.
doc.Duration.days = The span in days, with a fraction.
doc.Duration.add = The sum of two spans.
doc.Duration.sub = The difference of two spans.
doc.Duration.mul = Multiplies the span by a number.
doc.Duration.div = Divides the span by a number.
doc.Duration.ratio = How many whole times the other span fits in this one, or zero when the other is zero.
doc.Duration.neg = The span with its sign reversed.
doc.Duration.abs = The absolute value of the span.
doc.Duration.is_zero = True when the span is zero.
doc.Duration.is_negative = True when the span is negative.
doc.Duration.cmp = Compares with another span: minus one when shorter, zero when equal, one when longer.
doc.Duration.less = True when it is shorter than the other span.
doc.Duration.equals = True when it equals the other span.
doc.Duration.truncate = Rounds the span down to a multiple of <code>m</code>.
doc.Duration.round = Rounds the span to the nearest multiple of <code>m</code>, with halves going away from zero.
doc.Duration.to_str = Writes the span as <code>1h30m0s</code>; the same as <code>FormatDuration</code>.
doc.DurationResult = The result of parsing a duration.
doc.DurationResult.ok = Whether the text was read successfully.
doc.DurationResult.value = The span that was read.
doc.Nanoseconds = A span of <code>n</code> nanoseconds.
doc.Microseconds = A span of <code>n</code> microseconds.
doc.Milliseconds = A span of <code>n</code> milliseconds.
doc.Seconds = A span of <code>n</code> seconds.
doc.Minutes = A span of <code>n</code> minutes.
doc.Hours = A span of <code>n</code> hours.
doc.Days = A span of <code>n</code> days.
doc.SecondsF = A span of a fractional number of seconds, such as 0.25 for a quarter second.
doc.ZeroDuration = A span of zero.
doc.FormatDuration = Writes the span short and readable: <code>42ns</code>, <code>250us</code>, <code>1.5s</code>, <code>1m30s</code> or <code>1h15m30.5s</code>.
doc.ParseDuration = Reads text such as <code>1h15m30.5s</code> or <code>-250ms</code>. The units are <code>ns</code>, <code>us</code>, <code>ms</code>, <code>s</code>, <code>m</code>, <code>h</code> and <code>d</code> for days.
doc.ParseDurationOr = Like <code>ParseDuration</code>, returning the default when the text is not valid.
doc.SleepFor = Sleeps for the given span.
doc.SinceDuration = The span since an instant taken from <code>MonoNanos</code>.
doc.DurationBetween = The span between two epoch instants.
doc.AddDuration = Adds a span to an instant; any fraction of a second is dropped.
doc.TimeResult = The result of parsing a date and time.
doc.TimeResult.ok = Whether the text was read successfully.
doc.TimeResult.epoch = The instant that was read, in seconds since the Unix epoch.
doc.TimeResult.nanos = The fraction of a second, in nanoseconds.
doc.ParseISO = Reads an ISO 8601 date and time, such as <code>2024-03-20T17:35:09+03:30</code>. Without an offset it assumes local time.
doc.ParseISOIn = Like <code>ParseISO</code>, but without an offset it assumes <code>offsetMinutes</code> minutes.
doc.ParseHTTPDate = Reads the date format of HTTP headers.
doc.ParseFormat = Reads text with a pattern. <code>%Y</code> is a four digit year, <code>%y</code> a two digit one, <code>%m</code> the month, <code>%d</code> the day, <code>%H</code> the hour, <code>%M</code> the minute, <code>%S</code> the second, <code>%f</code> the fraction, <code>%b</code> the English month name, <code>%a</code> the day name, which is ignored, <code>%z</code> an offset such as <code>+0330</code> and <code>%Z</code> a zone name such as UTC. One space in the pattern matches any number of spaces in the text.
doc.ParseISOOr = Like <code>ParseISO</code>, returning the default when the text is not valid.
doc.FormatISOUTC = Writes the instant in UTC in ISO 8601, such as <code>2024-03-20T14:05:09Z</code>.
doc.FormatRFC3339 = Writes the instant in local time with its offset, such as <code>2024-03-20T17:35:09+03:30</code>, or <code>Z</code> when the offset is zero.
doc.LocalOffsetMinutesAt = The difference between local time and UTC at that instant, in minutes. With daylight saving it can change over the year.
doc.FromLocalParts = Builds an instant from a local year, month, day, hour, minute and second.
doc.FromUTCParts = Builds an instant from UTC parts.
doc.NowNanos = The current instant in nanoseconds since the Unix epoch.
doc.NowMicros = The current instant in microseconds since the Unix epoch.
doc.NowMillis = The current instant in milliseconds since the Unix epoch.
doc.ElapsedMs = The gap between two nanosecond clock readings, in milliseconds.
doc.ElapsedUs = The gap between two nanosecond clock readings, in microseconds.
doc.ElapsedSec = The gap between two nanosecond clock readings, in seconds.
doc.MonoNanos = The monotonic clock in nanoseconds. It never goes backwards, even if the system clock is changed, so use it for measuring spans. Its value on its own means nothing as a date.
doc.MonoMicros = The monotonic clock in microseconds.
doc.MonoMillis = The monotonic clock in milliseconds.
doc.SinceNanos = The nanoseconds that have passed since a monotonic clock reading.
doc.SinceMs = The milliseconds, with a fraction, since a monotonic clock reading.
doc.SinceUs = The microseconds, with a fraction, since a monotonic clock reading.
doc.SinceSec = The seconds, with a fraction, since a monotonic clock reading.
