pkg.description = The thread package in Salam: creating a thread with spawn, waiting for one to finish with join, and holding a group of threads together, with examples.
pkg.intro <<
<p>In Salam you start a function that should run alongside the rest of the program with <code>spawn</code>. It takes a function with no parameters and no result and gives back a number, the thread's handle. <code>join</code>, or <code>thread.Join</code>, waits for that thread to finish.</p>
<p>The <code>thread</code> package wraps that handle in a <code>Thread</code> so you can keep several of them in a vector and wait for all of them at once. Threads share the program's globals; for shared data use <a href="../sync/">sync</a> or <a href="../atomic/">atomic</a>.</p>
>>

doc.Thread = A thread, running or finished.
doc.Thread.handle = The handle <code>spawn</code> returned; zero means invalid.
doc.New = Wraps a <code>spawn</code> handle in a <code>Thread</code>.
doc.SpawnStack = Starts a function on a new thread with a stack of the size you give, in bytes, for work that needs more than the default, such as deep recursion. The function takes a <code>void*</code> and returns nothing. If the system cannot give that stack it returns an invalid handle, so check with <code>Valid</code>.
doc.Join = Waits for the thread to finish. It does nothing for an invalid thread.
doc.JoinAll = Waits for every thread in a vector to finish.
doc.Valid = True when the handle is not zero.
doc.Handle = The thread's handle.
doc.Collect = Adds a new thread with this handle to a vector and returns the vector.
