pkg.intro <<
<p>When several threads change the same variable they have to take turns, or the result depends on the order the threads happen to run in. A <strong>mutex</strong> is the simplest answer: each thread takes the lock before touching the data and releases it afterwards.</p>
<p>A <strong>wait group</strong> is for waiting until several pieces of work are done: call <code>Add</code> before starting them, <code>Done</code> at the end of each, and <code>Wait</code> on the main thread. Every tool in this package is created with a <code>New...</code> function and released with a <code>Destroy...</code> one.</p>
>>

doc.CondVar = A condition variable: threads sleep on it until another thread wakes them.

doc.WaitGroup.mu = The internal lock.
doc.WaitGroup.cv = The internal condition variable.
doc.RWMutex = A read-write lock: several readers together, or one writer alone.
doc.RWMutex.state = The internal state: the readers, the writer and the waiting writers.
doc.RWMutex.mu = The internal lock.
doc.RWMutex.cv = The internal condition variable.
doc.Semaphore = A semaphore: a limited number of permits that threads take and give back.
doc.Semaphore.permits = The number of free permits.
doc.Semaphore.mu = The internal lock.
doc.Semaphore.cv = The internal condition variable.
doc.Once = A "once": it runs a function only the first time.
doc.Once.done = Whether the function has run.
doc.Once.mu = The internal lock.
doc.NewMutex = A new mutex.
doc.Lock = Takes the lock, waiting when another thread holds it.
doc.Unlock = Releases the lock.
doc.Destroy = Releases the mutex.
doc.SleepMs = Puts the current thread to sleep for a number of milliseconds.
doc.NewCondVar = A new condition variable.
doc.WaitCond = Releases the lock and sleeps until it is signalled; the lock is held again on waking. Always recheck the condition in a loop.
doc.WaitCondTimeout = Like <code>WaitCond</code>, but for at most <code>ms</code> milliseconds. It returns false when the time runs out.
doc.NowMs = The current time in milliseconds, for working out deadlines.
doc.Signal = Wakes one of the waiting threads.
doc.Broadcast = Wakes every waiting thread.
doc.DestroyCondVar = Releases the condition variable.
doc.NewWaitGroup = A new wait group with a count of zero.
doc.Add = Increases the count of work by <code>delta</code>.
doc.Done = Reports one piece of work as finished.
doc.Wait = Waits until the count reaches zero; if it is already zero it returns at once.
doc.DestroyWaitGroup = Releases the wait group.
doc.NewRWMutex = A new read-write lock.
doc.RLock = Takes the lock for reading, waiting while a writer is working or waiting.
doc.RUnlock = Releases a read lock.
doc.WLock = Takes the lock for writing and waits for every reader to leave. A waiting writer comes before new readers.
doc.WUnlock = Releases the write lock.
doc.DestroyRWMutex = Releases the lock.
doc.NewSemaphore = A semaphore with the given number of permits.
doc.Acquire = Takes one permit, waiting when none is left.
doc.TryAcquire = Takes a permit if one is free and returns true; it never waits.
doc.Release = Gives one permit back and wakes one waiting thread.
doc.DestroySemaphore = Releases the semaphore.
doc.NewOnce = A new "once".
doc.Do = Runs the function only if this is the first time; other threads wait until it finishes.
doc.DestroyOnce = Releases the "once".
