pkg.title = The atomic package in Salam | A counter that is safe across threads
pkg.description = The atomic package in Salam: a 64-bit whole number and a flag shared between threads, with add, swap and compare-and-swap, with an example.
pkg.intro <<
<p>For a simple counter that several threads increment, you do not have to build a lock yourself: <code>I64</code> in this package does each operation in one indivisible step. <code>CompareAndSwap</code> is the base of most lock-free algorithms: it changes the value only if it is still the one you expected.</p>
<p>In the current implementation each cell is protected by a small lock, so it is correct, but no faster than the processor's atomic instructions.</p>
>>
