pkg.title = The ctx package in Salam | Cancellation and deadlines
pkg.description = The ctx package in Salam: building a context with cancellation, a timeout or a deadline, checking whether it is done, and waiting on it, with an example.
pkg.intro <<
<p>A context tells long-running work when to stop: either someone called <code>Cancel</code>, or its deadline passed. Contexts form a tree: you start from <code>Background</code> and make a child each time with <code>WithCancel</code>, <code>WithTimeout</code> or <code>WithDeadline</code>.</p>
<p>Cancelling a context ends all its children, but not its parent. The work should check <code>IsDone</code> from time to time, or wait on it with <code>Wait</code>. Free each context with <code>Free</code> when you are done with it, children before parents.</p>
>>

doc.Context = A context.
doc.Context.state = The internal state: cancelled, the deadline and whether there is one.
doc.Context.parent = The parent context, or null for the root.
doc.Context.mu = The lock every context in one tree shares.
doc.Context.cv = The condition variable that cancellation wakes.
doc.Context.is_root = Whether this context is the root.
doc.Background = The root context, which never finishes by itself.
doc.WithCancel = A child that ends when <code>Cancel</code> is called.
doc.WithTimeout = A child that ends <code>ms</code> milliseconds from now.
doc.WithDeadline = A child that ends at the instant <code>at_ms</code>, in milliseconds, as <code>sync.NowMs</code> gives it.
doc.Cancel = Ends the context and all its children and wakes everything waiting.
doc.IsDone = True when the context, or one of its parents, has been cancelled or has passed its deadline.
doc.Err = Why it finished: <code>cancelled</code> or <code>deadline exceeded</code>, or an empty string while it is still running.
doc.Deadline = The nearest deadline in the context and its parents, in milliseconds, or zero when there is none.
doc.Wait = Waits at most <code>ms</code> milliseconds for the context to finish and says whether it did.
doc.Free = Releases the context's memory.
