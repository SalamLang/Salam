pkg.intro <<
<p>This package holds the common ways of writing bytes as plain text: <strong>Base64</strong> for fitting binary data into JSON or email, <strong>hexadecimal</strong> for showing bytes, and <strong>URL encoding</strong> for putting text or special characters into a web address.</p>
<p>The larger formats, such as JSON, YAML and XML, have sub-packages of their own, listed in this same group.</p>

<h2 id="guide-basic-auth">Guide: an HTTP Basic login header</h2>
<p>HTTP Basic authentication sends <code>user:password</code> in Base64 after the word <code>Basic</code>. Base64 is not encryption, anyone can decode it, so this only belongs on HTTPS. Building the header is one call; reading it on the server side means decoding with <code>Base64DecodeStrict</code> and splitting at the first colon, since the password itself may contain more colons.</p>
{{example.encoding-guide-basic-auth}}
<p>The strict decoder reports through its <code>ok</code> argument whether the text was valid Base64, so a garbled header is refused instead of being turned into a random user name.</p>

<h2 id="guide-strict">Guide: strict or lenient Base64</h2>
<p><code>Base64Decode</code> never fails: it skips characters it does not know and accepts missing padding. That is handy for text you produced yourself. For anything that comes from outside, use <code>Base64DecodeStrict</code>, which accepts only padded standard Base64 and tells you when the input is broken.</p>
{{example.encoding-guide-strict}}
<p>Line breaks are allowed in both, because MIME and PEM files wrap Base64 at 76 or 64 characters. A typo is where the two differ: the strict form says no, the lenient form quietly returns damaged bytes. For binary data use <code>Base64EncodeBytes</code> and <code>Base64DecodeBytes</code>, which work on a pointer and a length, because a <code>str</code> stops at the first zero byte.</p>

<h2 id="guide-hex">Guide: seeing the bytes with hex</h2>
<p>Hexadecimal writes each byte as two digits, which makes it the easiest way to see what a string really holds. Persian letters take two bytes each in UTF-8, so <code>len</code> of a Persian word counts bytes, not letters. Hex is also the usual form for hashes, keys and colours.</p>
{{example.encoding-guide-hex}}
<p><code>HexEncode</code> writes lower case; <code>HexDecode</code> reads both cases.</p>

<h2 id="guide-url">Guide: putting text into a URL</h2>
<p>A query value cannot contain spaces, <code>&amp;</code>, <code>=</code> or non-ASCII letters as they are. <code>URLEncode</code> escapes everything except letters, digits and <code>- _ . ~</code>, so the result is safe anywhere in a URL. <code>URLDecode</code> undoes it and also reads <code>+</code> as a space, the way HTML forms send it.</p>
{{example.encoding-guide-url}}
<p>Encode each value on its own and join them with <code>&amp;</code>, as <code>link</code> does: encoding the whole URL at once would also escape the <code>?</code> and <code>&amp;</code> that hold it together. For whole query strings with repeated keys, <a href="/std/encoding-query/">encoding/query</a> does the bookkeeping, and <a href="/std/encoding-url/">encoding/url</a> parses and rebuilds complete URLs.</p>

doc.Base64Encode = Turns text into standard Base64, padded with <code>=</code>.
doc.Base64EncodeBytes = Turns <code>n</code> bytes of memory into Base64.
doc.Base64Decode = Turns Base64 back into text; spaces and newlines inside it are ignored.
doc.Base64DecodeStrict = Like <code>Base64Decode</code>, but any invalid character makes <code>ok</code> false and returns an empty string.
doc.Base64DecodeBytes = Decodes Base64 into the buffer <code>out</code>, of capacity <code>cap</code>, and returns how many bytes it wrote.
doc.HexEncode = Writes each byte of the text as two lower case hexadecimal digits.
doc.HexVal = The value of one hexadecimal digit, or -1 for an invalid character.
doc.HexDecode = Turns a hexadecimal string back into the original bytes.
doc.URLEncode = Percent-encodes text for a web address; letters, digits and <code>-_.~</code> are left as they are.
doc.URLDecode = Undoes percent encoding and turns <code>+</code> back into a space.
