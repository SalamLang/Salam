pkg.title = The encoding/url package in Salam | URLs
pkg.description = The encoding/url package in Salam: parsing a URL into its scheme, host and path, the registered domain and subdomain, editing query parameters, and resolving a relative address, with an example.
pkg.import = encoding.url
pkg.intro <<
<p><code>Parse</code> takes a full address such as <code>https://user@shop.example.co.uk:8443/path?page=2#top</code> apart. The parts are kept exactly as they appeared in the text; for the decoded form use functions such as <code>DecodedPath</code>.</p>
<p>The parameter functions edit the address's query through the <a href="../encoding-query/">query</a> package, and <code>String</code> builds the finished address.</p>
>>

doc.URL = A parsed web address.
doc.URL.scheme = The scheme, such as <code>https</code>.
doc.URL.userinfo = The user name and password before the <code>@</code>, still encoded.
doc.URL.host = The host name or numeric address.
doc.URL.port = The port, or zero when none was given.
doc.URL.path = The path, still encoded.
doc.URL.raw_query = The query after the <code>?</code>, still encoded.
doc.URL.fragment = The part after the <code>#</code>.
doc.Parse = Takes an address apart into its pieces.
doc.HostPort = The host and port together, such as <code>shop.example.co.uk:8443</code>.
doc.String = Turns the address back into text.
doc.DecodedPath = The path with its percent encoding undone.
doc.DecodedUserinfo = The user information, decoded.
doc.EncodePathSegment = Encodes one path segment; <code>/</code> is encoded too.
doc.Query = Turns the address's query into a <code>QueryMap</code>.
doc.SetQuery = Replaces the address's query with the given map.
doc.Join = Resolves a relative address against a base one, the way a browser does; <code>..</code> and <code>.</code> in the path are worked out.
doc.Hostname = The host name without the port.
doc.IsIP = True when the host is a numeric IP address.
doc.Labels = The parts of the host name, separated by dots.
doc.PublicSuffix = The public suffix of the domain, such as <code>co.uk</code> or <code>ir</code>.
doc.Domain = The registered domain: one label before the public suffix, such as <code>example.co.uk</code>.
doc.Subdomain = Whatever comes before the registered domain, such as <code>shop</code>.
doc.RemoveParam = Removes every value of a parameter and says whether it was there.
doc.SetParam = Sets the value of a parameter.
doc.KeepParams = Keeps only the parameters you name, for stripping tracking parameters.
doc.ClearQuery = Removes the whole query.
doc.ParamNames = The names of the parameters, in order.
