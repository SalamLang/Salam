pkg.en = encoding/envfile
pkg.name = encoding/envfile
pkg.group = Encoding and data
pkg.summary = Reading and writing <code>.env</code> files, with variable substitution.
pkg.title = The encoding/envfile package in Salam | .env files
pkg.description = The encoding/envfile package in Salam: reading a .env file, quoted values, export, ${VAR} substitution, merging and writing it back out, with an example.
pkg.import = encoding.envfile
pkg.intro <<
<p>A <code>.env</code> file holds a program's environment variables, one <code>KEY=value</code> per line. This package skips blank lines and <code>#</code> comments, accepts <code>export</code> before a key, strips the quotes, and keeps the keys in order.</p>
<p><code>Parse</code> substitutes references such as <code>${HOST}</code> from the same file; <code>ParseRaw</code> leaves them alone. The operating system's own environment variables are not read; for those see the <a href="../env/">env</a> package.</p>
>>

doc.Doc = The contents of an env file.
doc.Doc.m = The keys and values, in order.
doc.Doc.flags = For each key, whether its value takes substitution; single quotes turn it off.
doc.New = An empty document.
doc.Len = The number of keys.
doc.Has = True when the key is there.
doc.Get = A key's value, or an empty string when it is absent.
doc.GetOr = A key's value, or the default.
doc.Set = Sets a key's value; a new key goes on the end.
doc.Remove = Removes a key and says whether it was there.
doc.KeyAt = Key number <code>i</code>.
doc.ValueAt = Value number <code>i</code>.
doc.Keys = The keys, in order.
doc.MergeInto = Pours the keys of <code>src</code> into <code>dst</code>, replacing any that are already there.
doc.Free = Releases the document's memory.
doc.ExpandDoc = Builds a new document with the references substituted. Names are looked up in the document first and then in <code>base</code>.
doc.Expand = Substitutes the references in a string from the document and <code>base</code>.
doc.RefNames = The names of the variables the document's values refer to.
doc.RefNamesIn = The names of the variables referred to in a string, in both the <code>$A</code> and the <code>${A}</code> form.
doc.Quote = Puts a value in double quotes when it needs them.
doc.Format = Turns the document back into env file text.
doc.FormatExport = Like <code>Format</code>, with <code>export</code> before each line, for a shell.
doc.ParseRaw = Reads a file without substituting the references.
doc.Parse = Reads a file and substitutes the references.
doc.ParseStrict = Like <code>Parse</code>, but a malformed line is an error and <code>err</code> is filled in.
doc.Valid = True when every line is well formed.
doc.ParseScalar = Reads a single value, as on the right of an <code>=</code>: it strips the quotes and the escapes.
doc.ParseScalarEx = Like <code>ParseScalar</code>; when <code>semi</code> is true, <code>;</code> starts a comment as well as <code>#</code>.
