pkg.group = Encoding and data
pkg.summary = A dynamic value for data whose shape you do not know in advance; the shared language of every format in this group.
pkg.title = The encoding/value package in Salam | Dynamic values
pkg.description = The encoding/value package in Salam: dynamic null, boolean, number, string, array and object values for working with JSON, YAML, TOML and the other formats, with an example.
pkg.import = encoding.value
pkg.intro <<
<p>When you read JSON whose shape you do not know in advance, it cannot be poured into a fixed struct. That is what <code>Value</code> is for: every value carries its own kind, and it may be an array or an object of further values.</p>
<p>JSON, YAML, TOML, MessagePack, CSV and XML can all be turned into a <code>Value</code> and built from one; the <a href="../encoding-serde/">encoding.serde</a> package uses exactly this to convert between formats.</p>
>>

doc.Value = A dynamic value: null, boolean, whole number, decimal, string, array or object.
doc.Value.kind = The kind of the value; one of the Kind constants.
doc.Value.b = The boolean value.
doc.Value.i = The whole number value.
doc.Value.n = The decimal value.
doc.Value.s = The string value.
doc.Value.arr = The elements of an array.
doc.Value.obj = The keys and values of an object.
doc.KindNull = Null.
doc.KindBool = Boolean.
doc.KindInt = Whole number.
doc.KindFloat = Decimal.
doc.KindString = String.
doc.KindArray = Array.
doc.KindObject = Object.
doc.ValueNull = A null value.
doc.ValueBool = A boolean value.
doc.ValueInt = A whole number value.
doc.ValueFloat = A decimal value.
doc.ValueString = A string value.
doc.ValueArray = An array from a vector.
doc.ValueObject = An object from a map.
doc.NewValueArray = An empty array.
doc.NewValueObject = An empty object.
doc.IsNull = True when the value is null.
doc.IsBool = True when it is a boolean.
doc.IsInt = True when it is a whole number.
doc.IsFloat = True when it is a decimal.
doc.IsNumber = True when it is a whole number or a decimal.
doc.IsString = True when it is a string.
doc.IsArray = True when it is an array.
doc.IsObject = True when it is an object.
doc.AsBool = The boolean value; false for any other kind.
doc.AsInt = The whole number value; a decimal is truncated.
doc.AsFloat = The decimal value; a whole number is converted.
doc.AsString = The string value; an empty string for any other kind.
doc.ArrayLen = The number of elements in an array.
doc.ArrayGet = Element number <code>i</code>; the index has to be less than <code>ArrayLen</code>.
doc.ArraySet = Replaces element number <code>i</code>.
doc.ArrayPush = Adds an element at the end of an array.
doc.ObjectLen = The number of keys in an object.
doc.ObjectHas = True when the key is there.
doc.ObjectGet = The value for a key, or null when it is absent.
doc.ObjectGetOk = The value for a key, with <code>ok</code> saying whether the key was there; for telling "absent" apart from "null".
doc.ObjectSet = Sets a key.
doc.ObjectDelete = Removes a key and says whether it was there.
doc.ObjectKeys = The keys of an object. Their order is not fixed.
doc.Equal = True when two values, with all their nested elements, are equal.
doc.ValueClone = A complete, independent copy of a value.
doc.ValueFree = Releases the memory of a value and its elements.
doc.ToDebugString = A readable form with the kind of every element, such as <code>object{name: string(Ali)}</code>, for debugging.
