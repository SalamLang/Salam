pkg.intro <<
<p>This package has two interfaces. The <strong>document</strong> interface is the complete one: <code>Parse</code> reads the text into a document, and every node has a numeric id you use to get its name, attributes, children and text. XPath, DTD validation, namespaces, entities and the canonical form all work on that document.</p>
<p>The <strong>simple node</strong> interface (<code>Decode</code>, <code>Child</code>, <code>Attr</code>) is for small jobs, such as reading a small configuration file, and keeps the tree directly in plain structs. The <code>XMLTokenizer</code> reads the text without building a tree at all.</p>
>>
