pkg.title = The compress package in Salam | gzip and deflate
pkg.description = The compress package in Salam: byte buffers, RLE, Huffman, LZ77, LZW, Burrows Wheeler and DEFLATE compression, gzip, CRC-32 and Adler-32, and reading and writing bits, with examples.
group.Method.title = Method numbers
group.Method = The same <code>Method</code> enum cases as plain numbers, for <code>Compress</code> and <code>Decompress</code>.
pkg.intro <<
<p>This package is the base of all binary data work in Salam: <code>ByteBuf</code> and <code>ByteReader</code> are what packages such as <a href="../encoding-binary/">encoding/binary</a>, archive and <a href="../encoding-msgpack/">encoding/msgpack</a> pass around.</p>
<p>For compression, reach for <strong>gzip</strong> when the data has to be read by other programs. The other methods are mostly there to learn from and experiment with, and their output format belongs to this package alone. The examples show that for small data the overhead of Huffman and DEFLATE comes to more than the data itself.</p>
>>

doc.ByteBuf = A byte buffer: an array of bytes that grows by itself. Most packages in this group take and give binary data in one.
doc.ByteBuf.data = The memory address of the bytes.
doc.ByteBuf.len = The number of bytes.
doc.ByteBuf.cap = The capacity.
doc.ByteReader = A sequential reader of bytes over one piece of memory.
doc.ByteReader.data = The address of the data.
doc.ByteReader.len = The length of the data.
doc.ByteReader.pos = The current position.
doc.ByteReader.bad = A read went past the end of the data.
doc.NewByteBuf = An empty buffer.
doc.NewByteBufCap = An empty buffer with an initial capacity.
doc.BufPush = Adds one byte.
doc.BufPushBytes = Adds <code>n</code> bytes from memory.
doc.BufPushBuf = Adds the bytes of another buffer.
doc.BufPushU32 = Adds a 32 bit integer as 4 little-endian bytes.
doc.BufGet = Byte number <code>i</code>.
doc.BufSet = Sets byte number <code>i</code>.
doc.BufLen = The number of bytes.
doc.BufFree = Frees the memory of the buffer.
doc.BufReset = Empties the buffer and keeps the memory.
doc.BufClone = An independent copy of the buffer.
doc.BufEquals = True when two buffers hold the same bytes.
doc.BufFromStr = Puts the bytes of a string into a new buffer.
doc.BufToStrUnsafe = Takes the buffer to be a string; when the buffer holds a zero byte, the string ends right there.
doc.BufToBase64 = Turns the buffer into base64, for showing binary data.
doc.NewByteReader = A reader over <code>n</code> bytes of memory.
doc.ReaderFromBuf = A reader over the bytes of a buffer.
doc.RdLeft = The number of bytes not yet read.
doc.RdByte = Reads one byte; past the end <code>bad</code> becomes true.
doc.RdU32 = Reads a 4 byte little-endian integer.
doc.RdBytes = Reads <code>n</code> bytes into a new buffer.
doc.Method = The compression method, as an enum.
doc.Method.None = No compression.
doc.Method.RLE = Run length encoding.
doc.Method.Huffman = Huffman.
doc.Method.LZ77 = LZ77.
doc.Method.LZW = LZW.
doc.Method.Deflate = LZ77 and Huffman.
doc.Method.BWT = Burrows Wheeler.
doc.Compress = Compresses the data with the given method. The output does not carry the method number, so you have to know it to decompress.
doc.Decompress = Decompresses data that was compressed with the given method.
doc.CompressStr = Compresses a string.
doc.CompressBuf = Compresses a buffer.
doc.DecompressBuf = Decompresses a compressed buffer.
doc.CompressBest = Tries every method, returns the shortest output and puts its method in <code>method_out</code>.
doc.Ratio = The ratio of the compressed size to the original; under 1 means it got smaller.
doc.RLECompress = Run length encoding: shortens runs of the same byte; for data that repeats a lot.
doc.RLEDecompress = Decompresses RLE data.
doc.HuffmanCompress = Huffman coding: the more frequent bytes get shorter codes. The code table is stored with the data, so for small data the output gets bigger.
doc.HuffmanDecompress = Decompresses Huffman data.
doc.LZ77Compress = LZ77 compression: repeated pieces are replaced by a reference to where they were before.
doc.LZ77Decompress = Decompresses LZ77 data.
doc.LZWCompress = LZW compression, with a dictionary built as it goes.
doc.LZWDecompress = Decompresses LZW data.
doc.BWTTransform = The Burrows Wheeler transform: moves the bytes so that similar bytes end up next to each other; the index of the original row comes back in <code>primary_out</code>.
doc.BWTInverse = Undoes the Burrows Wheeler transform, given the index of the original row.
doc.BWTCompress = Burrows Wheeler, then move to front, then compression.
doc.BWTDecompress = Decompresses data compressed with Burrows Wheeler.
doc.MTFEncode = Move to front encoding: every byte is replaced by its place in a list of the recent bytes.
doc.MTFDecode = Undoes move to front.
doc.DeflateCompress = LZ77 and Huffman in a format of Salam's own. This is not standard zlib DEFLATE; for the standard format use <code>RawDeflate</code> or gzip.
doc.DeflateDecompress = Decompresses the output of <code>DeflateCompress</code>.
doc.RawDeflate = Standard DEFLATE (RFC 1951) with no header; what sits inside ZIP and gzip.
doc.RawInflate = Decompresses raw DEFLATE; <code>expected_size</code> is the rough size of the output.
doc.GzipCompress = Compresses the data into the gzip format, the one in <code>.gz</code> files.
doc.GzipDecompress = Decompresses gzip data; <code>ok</code> becomes false when the data is not gzip. The checksum inside the file is not checked.
doc.GzipCompressBuf = Gzips a buffer.
doc.GzipCompressStr = Gzips a string.
doc.GzipDecompressBuf = Decompresses a gzip buffer.
doc.CRC32 = The CRC-32 checksum, the one in ZIP and gzip, for checking that data is intact.
doc.CRC32Str = The CRC-32 of a string.
doc.CRC32Buf = The CRC-32 of a buffer.
doc.Adler32 = The Adler-32 checksum, the one in zlib; faster than CRC-32 but a little weaker.
doc.Adler32Str = The Adler-32 of a string.
doc.Adler32Buf = The Adler-32 of a buffer.
doc.BitWriter = A writer of bits; it fills each byte from the least significant bit.
doc.BitWriter.buf = The bytes written.
doc.BitWriter.acc = The bits waiting.
doc.BitWriter.nbits = The number of bits waiting.
doc.BitReader = A reader of bits in the same order.
doc.BitReader.data = The data.
doc.BitReader.len = The length of the data.
doc.BitReader.pos = The current byte position.
doc.BitReader.acc = The bits read.
doc.BitReader.nbits = The number of bits ready.
doc.BitReader.bad = A read went past the end of the data.
doc.NewBitWriter = A new bit writer.
doc.BitWriteBit = Writes one bit.
doc.BitWriteBits = Writes the low <code>count</code> bits of <code>value</code>.
doc.BitFlush = Sends the remaining bits to the last byte, padded with zeros.
doc.BitWriterLen = The number of bytes written.
doc.BitWriterFree = Frees the memory.
doc.NewBitReader = A bit reader over memory.
doc.BitReaderFromBuf = A bit reader over a buffer.
doc.BitReadBit = Reads one bit.
doc.BitReadBits = Reads <code>count</code> bits.
