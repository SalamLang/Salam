pkg.summary = Making and opening zip and tar archives, reading RAR, and gzipping a file.
pkg.title = The archive package in Salam | zip and tar
pkg.description = The archive package in Salam: making, listing and extracting zip and tar, reading RAR and gzipping a file, with examples.
pkg.intro <<
<p>An archive gathers several files into one. <strong>Zip</strong> compresses each file on its own; <strong>tar</strong> only puts the files one after another and is usually gzipped afterwards (<code>.tar.gz</code>).</p>
<p>The functions work both in memory and on files. They take the archive data as an address and a length, such as <code>b.data</code> and <code>b.len</code> of a byte buffer.</p>
>>

doc.Entry = One archive entry.
doc.Entry.name = The name and path inside the archive.
doc.Entry.size = The original size in bytes.
doc.Entry.compressed_size = The compressed size.
doc.Entry.is_dir = The entry is a directory.
doc.Entry.method = The compression method: zero for plain storage, 8 for DEFLATE.
doc.Entry.crc32 = The checksum of the contents.
doc.Entry.mtime = The modification time in seconds since the Unix epoch.
doc.FreeEntries = Frees the memory of the entry list.
doc.ZipFileInput = One file to put in a zip.
doc.ZipFileInput.name = The name inside the archive; a directory name ends with <code>/</code>.
doc.ZipFileInput.data_ptr = The address of the contents.
doc.ZipFileInput.data_len = The length of the contents.
doc.ZipFileInput.method = Zero for plain storage, 8 for DEFLATE.
doc.MakeZipFileInput = Makes one zip input.
doc.ZipCreate = Builds a zip archive in memory.
doc.ZipCreateFile = Writes a zip archive to a file.
doc.ZipList = The entries of a zip in memory.
doc.ZipExtractByName = Pulls out the contents of one entry; <code>ok</code> becomes false when the name is not found.
doc.ZipExtractAll = Writes every entry into the target directory. When the data is not a zip it has no entries and nothing is written.
doc.TarFileInput = One file to put in a tar.
doc.TarFileInput.name = The name inside the archive.
doc.TarFileInput.data_ptr = The address of the contents.
doc.TarFileInput.data_len = The length of the contents.
doc.TarFileInput.is_dir = The input is a directory.
doc.MakeTarFileInput = Makes one tar input.
doc.TarCreate = Builds a tar archive in memory, in the ustar format; tar does not compress, so gzip the result for that.
doc.TarCreateFile = Writes a tar archive to a file.
doc.TarList = The entries of a tar in memory.
doc.TarExtractByName = The contents of one tar entry.
doc.TarExtractAll = Writes every tar entry into the target directory.
doc.IsRar = True when the data starts with the RAR signature.
doc.RarList = The entries of a RAR archive.
doc.RarExtractByName = The contents of a RAR entry that was stored without compression.
doc.RarExtractAll = Pulls out every RAR entry.
doc.GzipCompressFile = Gzips a file.
doc.GzipDecompressFile = Decompresses a gzip file.
doc.ReadBinaryFile = Reads every byte of a file into a buffer.
doc.WriteBinaryFile = Writes <code>n</code> bytes to a file.
doc.WriteBinaryFileBuf = Writes a buffer to a file.
doc.EnsureDir = Makes the directory and the ones above it, when they are not there.
doc.LEGet16 = Reads a 16 bit little-endian integer from the given place in memory.
doc.LEGet32 = Reads a 32 bit little-endian integer.
doc.LEPut16 = Adds a 16 bit integer to a buffer, little-endian.
doc.LEPut32 = Adds a 32 bit integer, little-endian.
