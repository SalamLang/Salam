pkg.group = Encoding and data
pkg.summary = Reading and writing NumPy <code>.npy</code> and <code>.npz</code> files.
pkg.title = The npy package in Salam | NumPy npy and npz
pkg.description = The npy package in Salam: reading and writing NumPy arrays in npy and npz files and turning them into a matrix, with an example.
group.NPY_.title = Data types
group.NPY_ = The type of the elements in the file: 8 and 4 byte floats, 1 to 8 byte signed and unsigned integers, and boolean.
pkg.intro <<
<p><code>.npy</code> files are the standard way NumPy arrays are stored in Python, and <code>.npz</code> keeps several named arrays in one zip archive. With this package you can move data and model weights between Python and Salam.</p>
>>

doc.NpyArray = One multi dimensional NumPy array. The data is always held in memory as 64 bit floats.
doc.NpyArray.shape = The size of each dimension, such as <code>[2, 3]</code>.
doc.NpyArray.dtype = The data type in the file; one of the <code>NPY_</code> constants.
doc.NpyArray.data = The elements in row order.
doc.NpyArray.ndim = The number of dimensions.
doc.NpyArray.count = The total number of elements.
doc.NpyArray.free = Frees the memory of the array.
doc.ReadNpy = Reads the bytes of a <code>.npy</code> file from memory.
doc.ReadNpyFile = Reads a <code>.npy</code> file.
doc.WriteNpy = Turns the array into <code>.npy</code> bytes.
doc.WriteNpyFile = Writes the array to a <code>.npy</code> file.
doc.ToMatrix = Turns a two dimensional array into a matrix; for any other number of dimensions <code>ok</code> becomes false.
doc.FromMatrix = Turns a matrix into a two dimensional array of 64 bit floats.
doc.NpzList = The names of the arrays in a <code>.npz</code> file.
doc.NpzRead = Reads the array with the given name out of a <code>.npz</code>.
doc.NpzWrite = Writes several arrays with their names into one <code>.npz</code> file.
