pkg.intro <<
<p>TCP is the base of most internet protocols: a reliable, ordered stream of bytes between two programs. A server listens on a port with <code>Bind</code> and takes each new client with <code>Accept</code>; a client connects with <code>Dial</code>.</p>
<p><code>Accept</code> and <code>Read</code> wait until data arrives; to serve several clients, handle each in its own thread (<code>spawn</code>) or set a deadline. The examples run on <code>127.0.0.1</code>.</p>
>>

doc.Server = A TCP server listening on one port.
doc.Server.fd = The socket descriptor; -1 means invalid.
doc.Server.port = The port the server listens on.
doc.Conn = One TCP connection.
doc.Conn.fd = The socket descriptor; -1 means invalid.
doc.Bind = Listens on the given port; port zero means let the system pick a free one.
doc.Ok = True when the server was created properly.
doc.Port = The actual port of the server; for when you passed zero.
doc.Accept = Waits for a client to connect and returns its connection.
doc.CloseServer = Closes the server.
doc.Dial = Connects to a host and port; when it fails, <code>ConnOk</code> is false.
doc.ConnOk = True when the connection is up.
doc.Read = Reads at most <code>max</code> bytes; an empty string when the other side has closed the connection.
doc.Write = Sends the text and returns the number of bytes sent.
doc.ReadBytes = Reads at most <code>max</code> bytes into memory and returns how many; zero or less means the end or an error.
doc.WriteBytes = Sends <code>n</code> bytes from memory.
doc.Close = Closes the connection.
doc.DialTLS = Makes an encrypted TLS connection; for HTTPS and the like.
doc.UpgradeTLS = Upgrades an existing plain connection to TLS with the given configuration; as STARTTLS does.
doc.ConnFromFd = Builds a connection from a socket descriptor that was made somewhere else.
doc.WriteHTTP = Sends a complete HTTP/1.1 response with the status line, the content type, <code>Content-Length</code> and <code>Connection: close</code>; for very simple servers.
doc.SetReadDeadline = How many milliseconds a read may wait at most.
doc.SetWriteDeadline = How many milliseconds a write may wait at most.
doc.SetDeadline = Sets the read and write deadlines together.
doc.SetKeepAlive = Turns TCP keepalive packets on or off, so a dropped idle connection is noticed.
doc.SetNoDelay = Turns off Nagle's algorithm so small packets are sent at once; for interactive programs.
doc.Pool = A pool of idle connections to reuse.
doc.Pool.entries = The idle connections.
doc.Pool.idle_ttl_ms = The longest an idle connection is kept; 30 seconds by default.
doc.PoolEntry = One idle connection in the pool.
doc.PoolEntry.key = The host and port.
doc.PoolEntry.conn = The connection.
doc.PoolEntry.put_at_ms = When it was returned to the pool.
doc.PoolEntries = A list of idle connections.
doc.PoolEntries.items = The connections.
doc.NewPool = An empty pool.
doc.Get = When the pool holds a fresh idle connection to this host it returns that one, otherwise it makes a new one. <code>now_ms</code> is the current time.
doc.Put = Returns a connection to the pool after use.
doc.PoolLen = The number of idle connections in the pool.
