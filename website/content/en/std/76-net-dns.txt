pkg.summary = Finding the address of a name and asking for any kind of DNS record.
pkg.title = The net/dns package in Salam | DNS
pkg.description = The net/dns package in Salam: finding an IP address, MX, TXT and CNAME records and reverse lookups, and building and reading a DNS message, with examples.
pkg.import = net.dns
pkg.intro <<
<p>DNS turns names such as <code>salamlang.ir</code> into IP addresses. <code>Lookup</code> is the simplest way and does what a browser does. The <code>Lookup...</code> functions ask the DNS server for one particular kind of record and are what you want for building network tools or checking the configuration of a domain.</p>
>>

doc.TypeA = An IPv4 address record.
doc.TypeNS = A name server of the domain.
doc.TypeCNAME = An alias.
doc.TypeSOA = The start of authority of the domain.
doc.TypePTR = The name for an address (a reverse lookup).
doc.TypeMX = A mail server.
doc.TypeTXT = Free text, such as SPF records.
doc.TypeAAAA = An IPv6 address record.
doc.ClassIN = The internet class; nearly always this one.
doc.Message = One DNS message, a question or an answer.
doc.Message.id = The id that ties an answer to its question.
doc.Message.qr = The message is an answer.
doc.Message.opcode = The kind of operation; zero is an ordinary question.
doc.Message.aa = The answer comes from the authoritative server.
doc.Message.tc = The answer was truncated.
doc.Message.rd = A recursive lookup was asked for.
doc.Message.ra = The server supports recursive lookups.
doc.Message.rcode = The result code; zero means no error, 3 means the name does not exist.
doc.Message.questions = The questions.
doc.Message.answers = The answers.
doc.Message.authorities = The authority records.
doc.Message.extras = The additional records.
doc.Question = One question.
doc.Question.name = The domain name.
doc.Question.qtype = The record type.
doc.Question.qclass = The class.
doc.Questions = A list of questions.
doc.Questions.items = The questions.
doc.Record = One answer record.
doc.Record.name = The domain name.
doc.Record.rtype = The record type.
doc.Record.rclass = The class.
doc.Record.ttl = How many seconds the answer may be kept.
doc.Record.priority = The priority of an MX record; a smaller number means a higher priority.
doc.Record.data = The record data as text: an address, a name or some text.
doc.Records = A list of records.
doc.Records.items = The records.
doc.EncodeQuery = Builds a DNS question message to send over UDP.
doc.Decode = Reads a DNS message from bytes.
doc.Lookup = Finds the address of a host name using the operating system settings; the hosts file is read too.
doc.QueryServer = Asks the given server directly and returns the answer message.
doc.DefaultServers = The system DNS servers, from the network configuration.
doc.LookupA = The IPv4 addresses of a name.
doc.LookupAAAA = The IPv6 addresses of a name.
doc.LookupCNAME = The real name behind an alias.
doc.LookupMX = The mail servers of a domain, with their priority.
doc.LookupTXT = The text records of a domain.
doc.LookupPTR = The names of an IP address.
