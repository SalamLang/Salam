pkg.title = The net/mime package in Salam | MIME and multipart
pkg.description = The net/mime package in Salam: the MIME type from a file extension, parsing Content-Type, and building and reading a multipart/form-data body, with examples.
pkg.import = net.mime
pkg.intro <<
<p>A media type (MIME) tells the browser and other programs what the content is, such as <code>image/png</code>. This package finds the type from a file extension and reads the <code>Content-Type</code> header.</p>
<p>Forms that upload a file send a <code>multipart/form-data</code> body: several parts with a boundary between them. <code>ParseMultipart</code> reads one and <code>MultipartWriter</code> builds one.</p>
>>
