pkg.import = net.router
pkg.intro <<
<p>The router keeps one handler function per method and path. In a pattern, a segment that starts with <code>:</code> is a parameter; <code>/books/:id</code> matches <code>/books/42</code> with <code>id</code> set to 42. A <code>*</code> at the end of a pattern matches any continuation, without making a parameter.</p>
<p>Usually you hand the router to the <a href="../net-http/">net/http</a> server and it calls <code>Dispatch</code> itself; the handlers take the context id of the request.</p>
>>
