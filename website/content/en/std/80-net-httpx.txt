pkg.en = net/httpx
pkg.name = net/httpx
pkg.group = Network
pkg.summary = Sending a raw HTTP request with headers of your own and taking the response as text or bytes.
pkg.title = The net/httpx package in Salam
pkg.description = The net/httpx package in Salam: sending an HTTP and HTTPS request with headers written by hand and reading the response as text or binary, with an example.
pkg.import = net.httpx
pkg.intro <<
<p>This package is a thin layer under <a href="../net-http/">net/http</a>: you write the request line and the headers yourself and get the response untouched. It is what API clients that want full control of the headers are built on, such as the cloud service packages.</p>
>>

doc.Endpoint = The address of one server: the host, the port and whether it is secure.
doc.Endpoint.host = The host.
doc.Endpoint.port = The port; 443 by default.
doc.Endpoint.secure = Connect with TLS.
doc.Endpoint.ok = The address was read correctly.
doc.ParseEndpoint = Reads an address such as <code>https://api.example.com:8443</code>; the default port is 80 for http and 443 for https.
doc.Response = An HTTP response.
doc.Response.status = The status code.
doc.Response.head = The response headers, untouched.
doc.Response.body = The body.
doc.Response.ok = The request was sent and the response was read.
doc.Response.error = The error message.
doc.Send = Sends the request, with the headers you wrote and the given body, and returns the response.
doc.SendText = Like <code>Send</code>, with a text body.
doc.HeaderValue = The value of one header in the header text; the name is case insensitive.
doc.CopyOut = Copies a string into fresh memory and returns its length.
doc.Raw = A response with a binary body.
doc.Raw.status = The status code.
doc.Raw.head = The headers.
doc.Raw.data = The address of the body.
doc.Raw.len = The length of the body.
doc.Raw.ok = It succeeded.
doc.Raw.error = The error message.
doc.SendRaw = Like <code>Send</code>, but keeps the response body binary; for images and files.
doc.SendRawTimeout = The same, with a timeout.
doc.FreeRaw = Frees the memory of a raw response.
doc.RawText = The body of a raw response as a string.
doc.RawLimit = The greatest body size that is read.
doc.SetRawLimit = Changes that limit.
