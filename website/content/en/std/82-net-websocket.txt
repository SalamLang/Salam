pkg.en = net/websocket
pkg.name = net/websocket
pkg.group = Network
pkg.summary = A two way connection that stays open between browser and server, with rooms for broadcasting.
pkg.title = The net/websocket package in Salam | WebSocket
pkg.description = The net/websocket package in Salam: a WebSocket server and client, text and binary messages, ping, secure wss connections and broadcasting to rooms, with examples.
pkg.import = net.websocket
pkg.intro <<
<p>A WebSocket is a connection that stays open after one HTTP request, and either side sends a message whenever it likes; for live chat, notifications and games. The server takes connections with <code>Listen</code> and <code>Accept</code>, and a client connects with <code>Dial</code>.</p>
<p>To serve several clients, read each connection in its own thread and use a <code>Hub</code> to send a message to every member of a room.</p>
>>
