pkg.intro <<
<p>The Salam HTTP server hands requests to a <a href="../net-router/">router</a>, and the router calls the handler function. Every handler takes one <code>i64</code>, the context id of the request; you read the request and write the response with the <code>Ctx_...</code> functions, or turn it into a <code>Context</code> struct with <code>Ctx</code> so the names get shorter.</p>
<p>To send a request, <code>Get</code> and <code>Post</code> are the simplest way; <code>Client</code> keeps cookies the way a browser does. The examples run the server with <code>RunBackground</code> on 127.0.0.1 and send requests to it from the same program.</p>
>>
