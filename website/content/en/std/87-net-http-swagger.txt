pkg.en = net/http/swagger
pkg.name = net/http/swagger
pkg.group = Network
pkg.summary = Writing OpenAPI documentation for an API and serving the documentation page.
pkg.title = The net/http/swagger package in Salam | OpenAPI and Swagger
pkg.description = The net/http/swagger package in Salam: building OpenAPI 3.1 documentation from code, parameters, bodies and responses with automatic schemas, authentication and the documentation page, with examples.
pkg.import = net.http.swagger
pkg.intro <<
<p>Swagger builds the documentation of an API in the standard OpenAPI form and serves a page for looking at it and trying it out. <code>Route</code> picks one operation, and the functions after it, such as <code>Summary</code> and <code>Returns</code>, describe that one.</p>
<p>The schema of a body or a response is built from a sample value; pass an empty struct and its fields, under their <code>@json</code> names, appear in the documentation. <code>Missing</code> shows the routes that are not documented yet.</p>
>>

doc.Scheme = One authentication scheme.
doc.Scheme.name = The name.
doc.Scheme.kind = The kind: http or apiKey.

doc.Scheme.format = The token format, such as JWT.
doc.Scheme.loc = Where the key sits.
doc.Scheme.param = The name of the key parameter.
doc.Scheme.description = The description.
doc.Definition = The definition of one type in the schema.
doc.Definition.name = The name.
doc.Definition.body = The JSON schema.

doc.Contact = The contact details.
doc.License = The licence.
doc.BearerAuth = Defines authentication with a Bearer token.
doc.ApiKeyAuth = Defines authentication with an API key in a header, the query or a cookie.
doc.Route = Adds an operation for a method and path, or picks it when it is already there, and returns its index. The <code>:name</code> parameters of the path are registered by themselves.
doc.At = Picks an existing operation; false when there is none.
doc.Summary = The summary of the current operation.
doc.Details = The full description.
doc.Tag = A tag for grouping on the page.
doc.OperationId = The unique id of the operation, for code generating tools.
doc.Deprecated = Marks the operation deprecated.
doc.Secure = Makes a defined authentication scheme a requirement of the operation.
doc.Query = A string query parameter.
doc.QueryTyped = A query parameter whose type is taken from a sample value.
doc.QueryEnum = A query parameter with a set of allowed values.
doc.Header = A header parameter.
doc.Cookie = A cookie parameter.
doc.PathParam = The description of one path parameter.
doc.Accepts = A JSON body with the schema of a sample type.
doc.AcceptsOptional = The same, with the body optional.
doc.AcceptsRaw = A body with a content type and a schema of your own.
doc.AcceptsForm = A form body with the fields of a sample type.
doc.Returns = A JSON response with a code and the schema of a sample type.
doc.ReturnsRaw = A response with any content type and schema.
doc.ReturnsText = A text response.
doc.ReturnsHtml = An HTML response.
doc.ReturnsFile = A file response with a content type.
doc.ReturnsHeader = Adds a header to the response with this code.
doc.ReturnsNothing = A response with no body, such as a 204 or a 404.
doc.Spec = Turns the document into OpenAPI 3.1 JSON.
doc.SpecIndent = The same, readable with indenting.
doc.WriteSpec = Writes the document to a file.
doc.SpecFromFile = Reads a ready made spec from a file; an empty string when there is none.
doc.Scan = Makes an operation for every route of the router, so you can describe them afterwards.
doc.ScanPrefix = The same, for the routes under this prefix only.
doc.Problems = The faults of the document: an empty title or version, a duplicate id and the like.
doc.Undocumented = The operations with no summary, description or response.
doc.Missing = The routes of the router that are not in the document.
doc.Mount = Adds the documentation page and <code>openapi.json</code> to the router under the given prefix.
doc.MountSpec = The same, with a ready made spec.
doc.Serve = Runs the documentation page on a port of its own in the background.
doc.ServeSpec = The same, with a ready made spec.
doc.Page = The HTML of the documentation page, which reads the spec from the given address.
doc.Free = Frees the memory of the document.
doc.JSON_TYPE = The JSON content type.
doc.TEXT_TYPE = The plain text content type.
doc.HTML_TYPE = The HTML content type.
doc.FORM_TYPE = The form content type.
doc.TEXT_SCHEMA = The string schema.
doc.BINARY_SCHEMA = The binary data schema, for files.
