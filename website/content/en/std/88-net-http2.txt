group.H2_FLAG_.title = The frame flags
group.H2_FLAG_ = The flags in the fifth byte of a frame. What each flag means depends on the frame type; that is why <code>H2_FLAG_END_STREAM</code> and <code>H2_FLAG_ACK</code> are both 1, one for a data or headers frame and the other for settings and ping. Check them with <code>FrameHasFlag</code>.
pkg.intro <<
<p>This package implements HTTP/2 at the protocol level: it builds and reads frames, compresses the headers with HPACK and carries several requests at once over one connection as "streams". For building an ordinary web server <a href="../net-http/">net/http</a> is simpler; this package is for when you need the protocol itself.</p>
<p>How it goes: build a <code>Transport</code> over a TCP or TLS socket, take a connection with <code>NewConn</code> and do the handshake. Then the client sends a request with <code>SendHeaders</code> and reads the answer in <code>StreamAt</code> after <code>AwaitStreamEnd</code>. Over TLS, the client and the server must have agreed on <code>h2</code> through ALPN.</p>
>>
