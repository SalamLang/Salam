group.EV_.title = Event kinds
group.EV_ = The value of the <code>kind</code> field in the event that <code>Next</code> returns. A message event is one of the server's messages; the rest report on the connection itself: connecting and disconnecting, errors, reconnection attempts, pings, timeouts and the upgrade to WebSocket. Listeners are called with the English names of these events, such as <code>connect</code> and <code>disconnect</code>.
group.REASON_.title = Disconnect reasons
group.REASON_ = The text in the <code>message</code> field of a disconnect event, telling why the connection ended: the server or the program itself closed it, a ping did not arrive in time, the transport closed or failed, or a packet could not be read.
group.PUMP_.title = Pump results
group.PUMP_ = The result of <code>Pump</code> and <code>PumpManager</code>: something arrived and was handled, the timeout ran out, or the connection is closed.
group.EIO_.title = Engine packet kinds
group.EIO_ = Socket.IO runs on a layer called Engine.IO. Every message on that layer starts with a digit that gives its kind: open, close, ping, pong, message, upgrade and noop. Socket.IO packets travel inside messages of the "message" kind.
group.PKT_.title = Socket.IO packet kinds
group.PKT_ = The kinds of Socket.IO packet: connecting to a namespace, disconnecting, an event, an acknowledgement, a connect error, and the binary event and binary acknowledgement whose bytes follow the packet separately.
pkg.intro <<
<p>Socket.IO is the usual live messaging library in the Node.js world. This package is a client that connects to any Socket.IO version 4 server; it has no server of its own. <code>Dial</code> connects, <code>On</code> sets a listener for an event and the <code>Emit...</code> functions send events. Listeners are called while the program processes messages with <code>Run</code>, <code>RunFor</code>, <code>Pump</code> or <code>Next</code>.</p>
<p>The arguments of every event are a JSON array, read with <code>ArgStr</code>, <code>ArgInt</code> and the like. If the sender wants an answer, the event's <code>ack_id</code> is not negative and you answer it with <code>Reply</code>. For several namespaces on one connection, create a <code>Manager</code>.</p>
>>
