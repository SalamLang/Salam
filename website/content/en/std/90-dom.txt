pkg.description = The dom package in Salam: making and finding page elements, classes and style, click and keyboard events, timers, browser storage and calling JavaScript, with examples.
pkg.import = dom
pkg.intro <<
<p>A program that uses this package runs in the browser. Translate it to JavaScript with <code>salam js app.salam --output=app.js</code> and put it in a page with a <code>&lt;script src="app.js"&gt;</code> tag; <code>main</code> runs once the page is ready, and <code>println</code> writes to the browser console. That is why the examples on this page are not run, only checked.</p>
<p>Elements and JavaScript objects are held as one <code>i64</code> number. Events and timers take an anonymous function, such as <code>(): ... end</code>; keep a function you will want to drop later with <code>OffEvent</code> in a variable.</p>
>>

doc.Query = The first element that matches the CSS selector; zero when there is none.
doc.QueryAll = Every element that matches the selector, as a list; read it with <code>CountOf</code> and <code>ItemAt</code>.
doc.ById = The element with this id.
doc.Exists = An element with this id is there.
doc.Create = A new element with this tag; it is not in the page until you <code>Append</code> it.
doc.Body = The <code>body</code> element of the page.
doc.Document = The <code>document</code> object.
doc.Window = The <code>window</code> object.
doc.Global = A global JavaScript object by name, such as <code>Math</code>.
doc.Append = Adds the element to the end of the children of another element.
doc.Remove = Takes the element out of the page.
doc.SetText = Sets the text of the element; HTML in it is not interpreted.
doc.GetText = The text of the element.
doc.SetHtml = Sets the HTML inside the element. Do not put text a user wrote in here.
doc.SetValue = The value of an input box.
doc.GetValue = The current value of an input box.
doc.SetStyle = Sets one CSS property, such as <code>color</code>.
doc.GetStyle = The value of a CSS property set on the element itself.
doc.SetAttr = Sets one HTML attribute.
doc.GetAttr = The value of an attribute; an empty string when there is none.
doc.AddClass = Adds a class to the element.
doc.RemoveClass = Takes a class away.
doc.ToggleClass = Takes the class away when it is there, adds it when it is not.
doc.OnEvent = Registers a function for an element event, such as <code>click</code>.
doc.OnEventE = The same, but the function also takes the event object, to read with <code>EventKey</code> and the like.
doc.OnWindowE = A function with the event object, for window events such as <code>keydown</code>.
doc.OffEvent = Drops a function that was registered before; you have to pass the same function, so keep it in a variable.
doc.OnWindow = A function for a window event, such as <code>scroll</code>.
doc.OnReady = Calls the function once the page is ready; straight away when it already is.
doc.OnResize = Calls the function on every window resize.
doc.RequestFrame = Calls the function once before the next frame is drawn; the function takes the time in milliseconds.
doc.EveryFrame = Calls the function on every frame; for a game loop and animation.
doc.SetTimeout = Calls the function once after this many milliseconds and returns an id.
doc.SetInterval = Calls the function every this many milliseconds.
doc.ClearTimeout = Cancels a timeout that has not fired yet.
doc.ClearInterval = Stops a repeat.
doc.WinWidth = The window width in pixels.
doc.WinHeight = The window height.
doc.DocWidth = The document width.
doc.DocHeight = The document height.
doc.ScrollX = The horizontal scroll position.
doc.ScrollY = The vertical scroll position.
doc.Now = The exact time since the page loaded, in milliseconds; for measuring intervals.
doc.GetProp = A property of an object that is itself an object.
doc.GetNum = A numeric property.
doc.GetStr = A string property.
doc.GetBool = A boolean property.
doc.SetProp = Sets a property on an object.
doc.SetNum = Sets a numeric property.
doc.SetStr = Sets a string property.
doc.SetBool = Sets a boolean property.
doc.Call0 = Calls a method of an object with no arguments and returns the result.
doc.Call1 = With one numeric argument.
doc.Call2 = With two numeric arguments.
doc.Call3 = With three numeric arguments.
doc.Call4 = With four numeric arguments.
doc.CallS1 = With one string argument.
doc.CallS2 = With two string arguments.
doc.GetContext = The drawing context of a canvas element, such as <code>2d</code>; for easier drawing see <a href="../web-canvas/">web/canvas</a>.
doc.ItemAt = One element of the list that <code>QueryAll</code> returned.
doc.CountOf = The number of elements in the list.
doc.EventTarget = The element the event happened on.
doc.EventX = The horizontal position of the mouse pointer in the event.
doc.EventY = The vertical position of the pointer.
doc.EventKey = The key that was pressed, such as <code>Enter</code> or <code>a</code>.
doc.PreventDefault = Stops the default action of the browser, such as submitting a form.
doc.StopPropagation = Keeps the event from reaching the elements above.
doc.Alert = Shows a message in a browser window.
doc.Confirm = A question with an OK and a cancel button; true when the user confirmed.
doc.Prompt = Asks the user for some text; an empty string when they cancelled.
doc.SetTitle = Sets the title of the browser tab.
doc.Random = A random number from 0 up to but not including 1.
doc.RandomInt = A random integer from 0 up to but not including n.
doc.Tone = Plays a plain beep at the given frequency and length; browsers only allow sound after a click or a key.
doc.LoadImage = Starts loading an image and returns its object.
doc.ImageReady = The image has finished loading.
doc.StoreGetInt = A number kept in browser storage (localStorage); zero when there is none.
doc.StoreSetInt = Puts a number in browser storage; it stays after the page is closed.
doc.StoreGetStr = The stored text.
doc.StoreSetStr = Stores some text.
doc.TouchX = The horizontal position of the first finger in a touch event.
doc.TouchY = The vertical position of the first finger.
