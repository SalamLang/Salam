pkg.intro <<
<p>This package lets a Salam program drive a web page: find and create elements, change their text, classes and styles, react to clicks and keys, run timers and keep small values in <code>localStorage</code>. A program that uses it runs in the browser. Translate it to JavaScript with <code>salam js app.salam --output=app.js</code> and load it with a <code>&lt;script src="app.js"&gt;</code> tag; <code>main</code> runs once the page is ready, and <code>println</code> writes to the browser console. That is why the examples on this page are only checked, not run. For drawing use <a href="/std/web-canvas/">web/canvas</a>, for games that read the keyboard every frame <a href="/std/web-keys/">web/keys</a>, and for a desktop window around a page <a href="/std/webview/">webview</a>.</p>
<p>Elements and other JavaScript objects are held in an <code>i64</code> variable, and events and timers take an anonymous function such as <code>(): ... end</code>. Each function maps to one browser call (<code>SetText</code> is <code>textContent</code>, <code>SetStyle</code> is <code>style.setProperty</code> and so on), so the MDN documentation for that call applies.</p>
<p>Things that catch people out:</p>
<ul>
<li><strong>A missing element is JavaScript <code>null</code>, not 0.</strong> <code>el == 0</code> is never true for it, and using it throws. Check with <code>Exists(id)</code> before <code>ById</code>, or with <code>CountOf(QueryAll(sel)) == 0</code> for a selector.</li>
<li><strong><code>SetHtml</code> runs whatever HTML it gets.</strong> Put text from users in with <code>SetText</code>, never with <code>SetHtml</code>.</li>
<li><strong><code>SetStyle</code> takes CSS names</strong> such as <code>background-color</code>, not the JavaScript form <code>backgroundColor</code>.</li>
<li><strong><code>OnReady</code> does nothing when called from <code>main</code></strong>, because <code>main</code> already runs after the page is ready and the browser does not repeat the ready event. Put start-up code straight in <code>main</code>.</li>
<li><code>OffEvent</code> needs the very function value you registered, so keep it in a variable; a second lambda with the same body is a different function.</li>
</ul>

<h2 id="guide-run">Running the examples</h2>
<p>Each program below is a whole page's script. Save it as <code>app.salam</code>, translate it, and open an HTML file that loads the result:</p>
<pre class="code" dir="ltr"><code>salam js app.salam --output=app.js
echo '&lt;!doctype html&gt;&lt;meta charset="utf-8"&gt;&lt;body&gt;&lt;script src="app.js"&gt;&lt;/script&gt;' &gt; index.html
salam serve .</code></pre>
<p>Then visit <code>http://127.0.0.1:8000</code>. Output from <code>println</code> appears in the browser console. With <code>--output=app.html</code> instead, <code>salam js</code> writes one self contained page.</p>

<h2 id="guide-todo">A to-do list</h2>
<p>Most pages follow the same shape: build the elements once in <code>main</code>, keep the ones you need later in global variables, and react to events. A click handler that is created inside a function, like the one on each new list item, remembers the element it was made for. <code>StoreSetInt</code> and <code>StoreGetInt</code> keep a number in the browser's <code>localStorage</code>, so it survives a reload.</p>
{{example.dom-todo}}
<p><code>OnEvent</code> takes a handler without arguments; use <code>OnEventE</code> when you need the event itself, for example to read the key with <code>EventKey</code> or to stop the browser's default action with <code>PreventDefault</code>.</p>

<h2 id="guide-filter">Working with elements already on the page</h2>
<p>When the HTML comes from a server or a template, the script finds the elements instead of creating them. This one filters a product table as the user types. It first checks with <code>Exists</code> that the page has what it needs, then takes every row with <code>QueryAll</code> and walks them with <code>CountOf</code> and <code>ItemAt</code>. Hiding a row is <code>SetStyle(row, "display", "none")</code>, and an empty value removes the style again.</p>
{{example.dom-filter}}
<p>It expects markup such as <code>&lt;input id="search"&gt; &lt;p id="count"&gt;&lt;/p&gt; &lt;table id="products"&gt;&lt;tr&gt;&lt;td&gt;Green tea&lt;/td&gt;&lt;/tr&gt;...&lt;/table&gt;</code>. <code>QueryAll</code> returns the rows that exist at that moment; rows added later are not in the list, so query again after you change the table.</p>

<h2 id="guide-form">Checking a form as the user types</h2>
<p>The <code>input</code> event fires on every change to a text box, which makes it the place for live checks. One function looks at all fields, writes the first problem into a message element and switches the button with <code>SetBool(el, "disabled", ...)</code>. Calling it once at the end of <code>main</code> puts the form in the right state before the user touches it.</p>
{{example.dom-form-check}}
<p>An event wants a function value, so wrap a named function in a short lambda: <code>(): check() end</code>. Checks in the browser are for the user's comfort only; the server must check the same things again, for example with <a href="/std/net-http-validate/">net/http/validate</a>.</p>

<h2 id="guide-timers">A countdown with a timer</h2>
<p><code>SetInterval</code> calls a function every so many milliseconds and returns an id; keep it in a global so the function can stop itself with <code>ClearInterval</code>. For a single delayed call use <code>SetTimeout</code>, and for anything that moves on screen use <code>EveryFrame</code> instead, which follows the display's refresh rate.</p>
{{example.dom-countdown}}
<p><code>Tone</code> plays a short beep through the Web Audio API. Browsers only allow sound after the user has clicked or typed something on the page, so a beep from a timer that started on load may stay silent.</p>
>>

doc.Query = The first element that matches the CSS selector; JavaScript <code>null</code> when there is none, which does not compare equal to 0.
doc.QueryAll = Every element that matches the selector, as a list; read it with <code>CountOf</code> and <code>ItemAt</code>.
doc.ById = The element with this id; <code>null</code> when there is none, so check with <code>Exists</code> first.
doc.Exists = An element with this id is there.
doc.Create = A new element with this tag; it is not in the page until you <code>Append</code> it.
doc.Body = The <code>body</code> element of the page.
doc.Document = The <code>document</code> object.
doc.Window = The <code>window</code> object.
doc.Global = A global JavaScript object by name, such as <code>Math</code>.
doc.Append = Adds the element to the end of the children of another element.
doc.Remove = Takes the element out of the page.
doc.SetText = Sets the text of the element; HTML in it is not interpreted.
doc.GetText = The text of the element.
doc.SetHtml = Sets the HTML inside the element. Do not put text a user wrote in here.
doc.SetValue = The value of an input box.
doc.GetValue = The current value of an input box.
doc.SetStyle = Sets one CSS property by its CSS name, such as <code>color</code> or <code>background-color</code>; an empty value removes it.
doc.GetStyle = The value of a CSS property set on the element itself.
doc.SetAttr = Sets one HTML attribute.
doc.GetAttr = The value of an attribute; an empty string when there is none.
doc.AddClass = Adds a class to the element.
doc.RemoveClass = Takes a class away.
doc.ToggleClass = Takes the class away when it is there, adds it when it is not.
doc.OnEvent = Registers a function for an element event, such as <code>click</code>.
doc.OnEventE = The same, but the function also takes the event object, to read with <code>EventKey</code> and the like.
doc.OnWindowE = A function with the event object, for window events such as <code>keydown</code>.
doc.OffEvent = Drops a function that was registered before; you have to pass the same function, so keep it in a variable.
doc.OnWindow = A function for a window event, such as <code>scroll</code>.
doc.OnReady = Calls the function on the browser's <code>DOMContentLoaded</code> event. That event has already happened when <code>main</code> runs, so a call from <code>main</code> never fires.
doc.OnResize = Calls the function on every window resize.
doc.RequestFrame = Calls the function once before the next frame is drawn; the function takes the time in milliseconds.
doc.EveryFrame = Calls the function on every frame, for a game loop and animation. Its argument is the time since the previous frame in milliseconds, at most 100.
doc.SetTimeout = Calls the function once after this many milliseconds and returns an id.
doc.SetInterval = Calls the function every this many milliseconds.
doc.ClearTimeout = Cancels a timeout that has not fired yet.
doc.ClearInterval = Stops a repeat.
doc.WinWidth = The window width in pixels.
doc.WinHeight = The window height.
doc.DocWidth = The document width.
doc.DocHeight = The document height.
doc.ScrollX = The horizontal scroll position.
doc.ScrollY = The vertical scroll position.
doc.Now = The exact time since the page loaded, in milliseconds; for measuring intervals.
doc.GetProp = A property of an object that is itself an object.
doc.GetNum = A numeric property; 0 when it is missing or not a number.
doc.GetStr = A string property.
doc.GetBool = A boolean property.
doc.SetProp = Sets a property on an object.
doc.SetNum = Sets a numeric property.
doc.SetStr = Sets a string property.
doc.SetBool = Sets a boolean property.
doc.Call0 = Calls a method of an object with no arguments and returns the result.
doc.Call1 = With one numeric argument.
doc.Call2 = With two numeric arguments.
doc.Call3 = With three numeric arguments.
doc.Call4 = With four numeric arguments.
doc.CallS1 = With one string argument.
doc.CallS2 = With two string arguments.
doc.GetContext = The drawing context of a canvas element, such as <code>2d</code>; for easier drawing see <a href="/std/web-canvas/">web/canvas</a>.
doc.ItemAt = One element of the list that <code>QueryAll</code> returned.
doc.CountOf = The number of elements in the list.
doc.EventTarget = The element the event happened on.
doc.EventX = The horizontal position of the mouse pointer in the event, from the left edge of the window (<code>clientX</code>).
doc.EventY = The vertical position of the pointer.
doc.EventKey = The key that was pressed, such as <code>Enter</code> or <code>a</code>.
doc.PreventDefault = Stops the default action of the browser, such as submitting a form.
doc.StopPropagation = Keeps the event from reaching the elements above.
doc.Alert = Shows a message in a browser window.
doc.Confirm = A question with an OK and a cancel button; true when the user confirmed.
doc.Prompt = Asks the user for some text; an empty string when they cancelled.
doc.SetTitle = Sets the title of the browser tab.
doc.Random = A random number from 0 up to but not including 1.
doc.RandomInt = A random integer from 0 up to but not including n.
doc.Tone = Plays a plain beep at the given frequency and length; browsers only allow sound after a click or a key.
doc.LoadImage = Starts loading an image and returns its object.
doc.ImageReady = The image has finished loading.
doc.StoreGetInt = A number kept in browser storage (localStorage); zero when there is none.
doc.StoreSetInt = Puts a number in browser storage; it stays after the page is closed.
doc.StoreGetStr = The stored text.
doc.StoreSetStr = Stores some text.
doc.TouchX = The horizontal position of the first finger in a touch event.
doc.TouchY = The vertical position of the first finger.
