pkg.intro <<
<p>This package gives plain functions for two dimensional drawing on a <code>&lt;canvas&gt;</code> element: charts, simple games, signatures, diagrams. As with <a href="/std/dom/">dom</a>, the program is translated for the browser with <code>salam js</code>, and the elements, events and timers around the drawing come from <code>dom</code>. For key presses in a game loop add <a href="/std/web/keys/">web/keys</a>; for pictures saved to a file on the server side, see <a href="/std/image/">image</a>.</p>
<p>Get the drawing context with <code>Get</code> (by element id) or <code>Of</code> (for an element you hold) and pass it to every function. Each function is one call on the browser's <code>CanvasRenderingContext2D</code>. The coordinates are in canvas pixels, start at the top left corner, and the vertical axis points down, so angles turn clockwise.</p>
<p>Things that catch people out:</p>
<ul>
<li><strong>Set the size with the <code>width</code> and <code>height</code> attributes</strong>, not CSS. CSS stretches the picture; the attributes set how many pixels there are.</li>
<li><strong>Shapes built from a path pile up</strong> until <code>BeginPath</code>; see the last section.</li>
<li><strong>An image draws nothing until it has loaded.</strong> Check <code>dom.ImageReady</code> before <code>DrawImage</code>.</li>
<li><strong>Mouse positions from <code>dom.EventX</code> are window coordinates.</strong> Subtract the canvas position from <code>getBoundingClientRect</code> to get canvas coordinates.</li>
<li>Only the common calls are wrapped. Gradients, <code>measureText</code> and the rest are reached with <code>dom.Call...</code> and <code>dom.Set...</code> on the context.</li>
</ul>

<h2 id="guide-chart">A bar chart from data</h2>
<p>Drawing a chart is mostly arithmetic: turn each value into a height, each index into an x position, and draw from the bottom up because y grows downward. Set the canvas size with the <code>width</code> and <code>height</code> attributes rather than CSS; CSS only stretches the picture, while the attributes set how many pixels you draw on. <code>TextAlign(c, "center")</code> makes <code>FillText</code> centre each label on the x you give.</p>
{{example.web-canvas-bar-chart}}
<p>These programs run in the browser, so they are only checked here; see <a href="/std/dom/#guide-run">how to run them</a>.</p>

<h2 id="guide-animation">Animation: clear, move, draw</h2>
<p>An animation redraws the whole picture on every frame. <code>EveryFrame</code> from <a href="/std/dom/">dom</a> calls your function before each repaint, usually 60 times a second. Each call moves the objects a little, paints the background over the last frame and draws everything again. Keep the state in globals so it lasts from one frame to the next.</p>
{{example.web-canvas-bounce}}
<p>The speed here is per frame, so the ball moves faster on a 120 Hz screen. For the same speed everywhere, multiply by the argument of the frame function: it is the time since the last frame in milliseconds, at most 100 (so a hidden tab does not make things jump). The spinner below works that way.</p>

<h2 id="guide-input">Clicks and images</h2>
<p>A drawing that reacts to the mouse needs the click position in canvas coordinates. <code>dom.EventX</code> and <code>dom.EventY</code> are measured from the window, so the program asks the canvas for its box with <code>dom.Call0(board, "getBoundingClientRect")</code> and subtracts <code>left</code> and <code>top</code>. Each click stamps a picture there. <code>dom.LoadImage</code> starts the download at once and returns the image; until <code>dom.ImageReady</code> says it has arrived, the click does nothing. A right click clears the board, after <code>PreventDefault</code> stops the browser menu.</p>
{{example.web-canvas-stamp}}
<p>Put a <code>stamp.png</code> next to the page. When CSS makes the canvas larger or smaller than its <code>width</code> attribute, also scale the position by <code>canvas.Width(c) / box width</code>.</p>

<h2 id="guide-transform">Rotating with Save and Restore</h2>
<p><code>Translate</code>, <code>Rotate</code> and <code>Scale</code> move the coordinate system, not the shapes, and every later drawing call is affected. Wrap them in <code>Save</code> and <code>Restore</code> so the change ends where you want it to. The spinner below moves the origin to the centre, then draws the same small bar twelve times, turning a twelfth of a circle and raising <code>Alpha</code> each time.</p>
{{example.web-canvas-spinner}}
<p>Angles are in radians: a full turn is about 6.2832. <code>Alpha</code> is part of the saved state too, so the <code>Restore</code> at the end also brings it back to 1.</p>
<p>One trap: <code>RoundRect</code>, <code>MoveTo</code>, <code>LineTo</code> and <code>Arc</code> add to the current path, and <code>Fill</code> fills all of it. Without <code>BeginPath</code> before each shape, the twelfth <code>Fill</code> here would paint all twelve bars again at full strength and the fading tail would disappear. <code>FillRect</code> and <code>StrokeRect</code> draw at once and do not touch the path.</p>
>>

doc.Get = The two dimensional drawing context of the canvas element with this id. The element must exist, or the call throws.
doc.Of = The drawing context of a canvas element you already hold.
doc.Width = The canvas width in pixels, from its <code>width</code> attribute.
doc.Height = The canvas height.
doc.FillStyle = The fill colour, such as <code>#2a7</code> or <code>red</code>.
doc.StrokeStyle = The colour of the lines.
doc.LineWidth = The thickness of the lines.
doc.Font = The text font in CSS terms, such as <code>16px Inter</code>.
doc.TextAlign = The horizontal text alignment: <code>left</code>, <code>center</code> or <code>right</code>.
doc.Alpha = The transparency of everything drawn after this, from 0 to 1.
doc.FillRect = A filled rectangle.
doc.StrokeRect = The outline of a rectangle.
doc.ClearRect = Clears a part of the canvas and makes it transparent.
doc.RoundRect = Adds a rectangle with rounded corners to the path; call <code>Fill</code> or <code>Stroke</code> afterwards. Browsers without <code>roundRect</code> get square corners.
doc.BeginPath = Starts a new path.
doc.ClosePath = Closes the path back to its starting point.
doc.MoveTo = Moves the pen to this point without drawing.
doc.LineTo = Adds a line segment up to this point to the path.
doc.Arc = An arc with the given centre and radius, from the start angle to the end angle in radians; a full circle is 0 to 2π.
doc.Fill = Fills the inside of the path.
doc.Stroke = Draws the line of the path.
doc.FillText = Writes the text at this point.
doc.Save = Keeps the current colours, font and transforms.
doc.Restore = Brings back the last kept state.
doc.Translate = Moves the origin of the coordinates.
doc.Rotate = Rotates everything drawn after this by this angle in radians.
doc.Scale = Makes everything drawn after this larger or smaller.
doc.DrawImage = Draws an image you got from <code>dom.LoadImage</code>, stretched into this rectangle. An image that has not loaded yet draws nothing.
