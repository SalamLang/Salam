pkg.description = The web/keys package in Salam: reading the arrow keys and the space bar in a browser game loop, and the difference between holding a key and pressing it once, with an example.
pkg.import = web.keys
pkg.intro <<
<p>In a game you usually ask once per frame which keys are down, rather than taking an event for every press. This package listens to the keyboard events for you and keeps the state. Call <code>Init</code> once, then ask for the state inside the <code>EveryFrame</code> function from <a href="../dom/">dom</a>.</p>
>>

doc.Track = Adds a key to the list of tracked keys; the key name is the browser <code>key</code> value, such as <code>a</code>. Up to 32 keys.
doc.Init = Starts tracking and adds the arrow keys, Enter and the space bar. Those keys no longer scroll the page.
doc.Down = The key is being held right now; for continuous movement.
doc.Pressed = The key has been pressed since the last time you asked; every press returns true exactly once. For jumping or shooting.
