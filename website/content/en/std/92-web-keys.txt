pkg.intro <<
<p>In a game you usually ask once per frame which keys are down, rather than taking an event for every press. This package listens to the <code>keydown</code> and <code>keyup</code> events of the window for you and keeps the state of up to 32 keys. Call <code>Init</code> once, then ask <code>Down</code> or <code>Pressed</code> inside the <code>EveryFrame</code> function from <a href="/std/dom/">dom</a>, and draw with <a href="/std/web/canvas/">web/canvas</a>. For a form or a text field, where you want each key as it comes, use <code>dom.OnEventE</code> with <code>dom.EventKey</code> instead.</p>
<p>Keys are named by the browser's <code>key</code> value: <code>ArrowLeft</code>, <code>Enter</code>, <code>" "</code> for the space bar, <code>a</code> for the A key. Things to know:</p>
<ul>
<li><strong>Only tracked keys are seen.</strong> <code>Init</code> tracks the four arrows, Enter and the space bar; add others with <code>Track</code>. Asking about any other key returns false.</li>
<li><strong>Letters change with Shift and Caps Lock</strong>: <code>a</code> becomes <code>A</code>. Track and ask for both.</li>
<li><strong>Tracked keys stop doing their normal job on the page</strong>, so they cannot be typed into a text box while the game runs.</li>
<li><strong>A key can stay "down" after the window loses focus.</strong> When the player switches windows while holding a key, the browser sends no <code>keyup</code>, and <code>Down</code> stays true until that key is pressed and released again.</li>
</ul>

<h2 id="guide-down-pressed">Holding a key and pressing it once</h2>
<p>The two questions are different. <code>Down</code> is true for as long as the key is held, which suits walking. <code>Pressed</code> is true once per press, the next time you ask after the key went down, which suits jumping, shooting or opening a menu: holding the space bar does not make the player jump again and again.</p>
{{example.web-keys-jump}}
<p>Notice that the program asks <code>Pressed</code> on every frame and only then checks whether the player stands on the floor. If it wrote <code>y &gt;= floor and keys.Pressed(" ")</code>, a press in mid air would not be asked about, would stay waiting, and the player would jump by itself on landing.</p>

<h2 id="guide-track">Your own keys: pause with P</h2>
<p><code>Init</code> tracks the arrow keys, Enter and the space bar. Add any other key with <code>Track</code>, using the browser's <code>key</code> name: a letter, <code>Escape</code>, <code>Shift</code> and so on. The names are exact text, so with Shift or Caps Lock on, the P key arrives as <code>P</code>, not <code>p</code>; track both when it matters.</p>
{{example.web-keys-pause}}
<p>A tracked key no longer does its usual job in the page, because the package calls <code>PreventDefault</code> for it. That is what stops the arrows and the space bar from scrolling during a game, but it also means a tracked letter cannot be typed into a text box on the same page.</p>
<p>Like the <a href="/std/dom/">dom</a> examples, these run in the browser and are only checked here.</p>

<h2 id="guide-move">Smooth movement with arrows and WASD</h2>
<p>Most games accept both the arrow keys and W, A, S and D. The helper <code>held</code> checks an arrow, a letter and its capital, so Caps Lock does not stop the player. Each axis becomes -1, 0 or 1; when both are set the program divides by the length, so moving diagonally is not faster than moving straight. The speed is in pixels per millisecond and is multiplied by <code>ms</code>, the time since the last frame that <code>EveryFrame</code> passes in, so the dot moves at the same speed on a 60 Hz and a 144 Hz screen.</p>
{{example.web-keys-move}}

>>

doc.Track = Adds a key to the list of tracked keys; the key name is the browser <code>key</code> value, such as <code>a</code>. Up to 32 keys; more are ignored without a word. Works before or after <code>Init</code>.
doc.Init = Starts listening on the window and tracks the arrow keys, Enter and the space bar. Tracked keys no longer scroll the page or type into fields. Call it once; a second call adds a second pair of listeners.
doc.Down = The key is being held right now; for continuous movement.
doc.Pressed = The key has been pressed since the last time you asked; every press returns true exactly once. For jumping or shooting.
