pkg.intro <<
<p>In a game you usually ask once per frame which keys are down, rather than taking an event for every press. This package listens to the keyboard events for you and keeps the state. Call <code>Init</code> once, then ask for the state inside the <code>EveryFrame</code> function from <a href="../dom/">dom</a>.</p>

<h2 id="guide-down-pressed">Holding a key and pressing it once</h2>
<p>The two questions are different. <code>Down</code> is true for as long as the key is held, which suits walking. <code>Pressed</code> is true once per press, the next time you ask after the key went down, which suits jumping, shooting or opening a menu: holding the space bar does not make the player jump again and again.</p>
{{example.web-keys-jump}}
<p>Notice that the program asks <code>Pressed</code> on every frame and only then checks whether the player stands on the floor. If it wrote <code>y &gt;= floor and keys.Pressed(" ")</code>, a press in mid air would not be asked about, would stay waiting, and the player would jump by itself on landing.</p>

<h2 id="guide-track">Your own keys: pause with P</h2>
<p><code>Init</code> tracks the arrow keys, Enter and the space bar. Add any other key with <code>Track</code>, using the browser's <code>key</code> name: a letter, <code>Escape</code>, <code>Shift</code> and so on. The names are exact text, so with Shift or Caps Lock on, the P key arrives as <code>P</code>, not <code>p</code>; track both when it matters.</p>
{{example.web-keys-pause}}
<p>A tracked key no longer does its usual job in the page, because the package calls <code>PreventDefault</code> for it. That is what stops the arrows and the space bar from scrolling during a game, but it also means a tracked letter cannot be typed into a text box on the same page.</p>
<p>Like the <a href="/std/dom/">dom</a> examples, these run in the browser and are only checked here.</p>
>>

doc.Track = Adds a key to the list of tracked keys; the key name is the browser <code>key</code> value, such as <code>a</code>. Up to 32 keys.
doc.Init = Starts tracking and adds the arrow keys, Enter and the space bar. Those keys no longer scroll the page.
doc.Down = The key is being held right now; for continuous movement.
doc.Pressed = The key has been pressed since the last time you asked; every press returns true exactly once. For jumping or shooting.
