pkg.import = jwt
pkg.intro <<
<p>A JWT is a token the server signs after a user logs in and the client sends with every request; by checking the signature the server knows who the user is without going to the database. This package supports the HMAC algorithms, HS256, HS384 and HS512, and never accepts a token with the <code>none</code> algorithm.</p>
<p>For an API, make a <code>Guard</code> and call <code>Require</code> or one of its siblings in every handler; when the token is wrong the error response is sent for you. The secret has to be long and random, for instance from <code>RandomToken</code> in <a href="../crypto/">crypto</a>.</p>
>>
