pkg.name = tls
pkg.group = Security and cryptography
pkg.summary = Secure TLS 1.3 and 1.2 connections and public key cryptography tools, with no OpenSSL needed.
pkg.title = The tls package in Salam | TLS, AES-GCM and ECDH
pkg.description = The tls package in Salam: a secure HTTPS connection to a server, a TLS server with a certificate, certificate verification, AES-GCM encryption, ECDH key exchange, HKDF and P-256 signatures, with examples.
pkg.import = tls
pkg.intro <<
<p>The tls package is a complete implementation of TLS written in Salam and needs no outside library. A client connects with <code>Dial</code> and checks the server certificate against the system roots; a server reads its certificate and key with <code>NewServerConfig</code> and secures each connection with <code>WrapServer</code>.</p>
<p>The cryptography tools here are also useful for building protocols of your own: the two sides make a shared secret with ECDH, derive a key from it with HKDF, and encrypt and seal the message with AES-GCM. Keys and data are passed around as base64.</p>
>>
