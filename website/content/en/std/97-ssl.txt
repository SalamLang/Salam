pkg.name = ssl
pkg.group = Security and cryptography
pkg.summary = A familiar OpenSSL style interface for secure connections, on top of Salam's own TLS.
pkg.title = The ssl package in Salam
pkg.description = The ssl package in Salam: client and server TLS connections with an OpenSSL style interface, certificate verification, the hostname and the minimum version, with examples.
pkg.import = ssl
pkg.intro <<
<p>This package gives the same OpenSSL style context and connection interface, but underneath it is Salam's own <a href="../tls/">tls</a> and it needs no outside library. For new code <a href="../tls/">tls</a> is simpler; this package is for code already written in this style. Set the hostname before <code>Connect</code> when certificates are verified.</p>
<p>The flow: make a context, hand the TCP connection to it with <code>Wrap</code>, for a client set the hostname and call <code>Connect</code>, then read and write.</p>
>>

doc.Wrap = Makes a new SSL connection over an open socket.
doc.ConnOk = The connection was created.
doc.Connect = Does the client handshake.
doc.Accept = Does the server handshake.
doc.Read = Reads up to this many bytes.
doc.Write = Sends data and returns the number of bytes, or a negative number on an error.
doc.Shutdown = Sends the close alert.
doc.Close = Frees the connection.
doc.ErrorCode = The OpenSSL style error code for the result of one read or write.
doc.ConnErrorString = The error text of this connection; unlike <code>LastErrorString</code> it is not shared between threads.
doc.LastErrorString = The text of the last error, and clears it.
doc.SetHostname = Sets the hostname for SNI and for certificate verification.
doc.VerifyResult = The result of verifying the certificate of the other side.
doc.PeerVerified = The certificate of the other side was verified and accepted.
doc.NewClientContext = A client context with TLS 1.2 as the minimum, certificate verification and the system roots.
doc.NewServerContext = A server context with a certificate and key from files.
doc.CtxOk = The context was created.
doc.SetVerify = The certificate verification mode.
doc.LoadVerifyLocationsFile = Reads the root certificates from a file.
doc.SetDefaultVerifyPaths = Loads the system roots.
doc.SetMinVersion = The minimum TLS version.
doc.CloseContext = Frees the context.
doc.VERIFY_NONE = Verification mode: no verification.
doc.VERIFY_PEER = Verification mode: verify the certificate of the other side.
doc.FILETYPE_PEM = The PEM file type.
doc.TLS1_2 = The version number of TLS 1.2.
doc.TLS1_3 = The version number of TLS 1.3.
doc.CERT_OK = Verification result: the certificate is valid.
doc.Context = A TLS context, shared between connections.
doc.Context.handle = The pointer to the context state.
doc.Conn = One TLS connection.
doc.Conn.handle = The pointer to the connection state.
