pkg.summary = SSH connections, running a command on a server, and working with files over SFTP.
pkg.title = The ssh package in Salam | SSH and SFTP
pkg.description = The ssh package in Salam: connecting with a password or a key, checking the host key, running a command and a shell on a server, and uploading and downloading files over SFTP, with examples.
pkg.import = ssh
pkg.intro <<
<p>This package is an SSH client written in Salam and needs neither OpenSSH nor any other library. Make a <code>Config</code> with the host and the user, pick the login method, and connect with <code>Connect</code>; then send a command with <code>Exec</code>, or move files with <code>SftpOpen</code>. It suits automating deployments and backups.</p>
<p>The host key is checked against the known_hosts file, the way <code>ssh</code> itself does. The buffer and reader functions build and read the data format of the SSH protocol; an ordinary program does not need them.</p>
>>
