pkg.name = ftp
pkg.group = Network
pkg.summary = An FTP and FTPS client: listing a directory, uploading and downloading files.
pkg.title = The ftp package in Salam | FTP and FTPS
pkg.description = The ftp package in Salam: connecting to an FTP and FTPS server, logging in, listing a directory, reading and writing, and uploading and downloading files and directories, with an example.
pkg.import = ftp
pkg.intro <<
<p>This package connects to FTP servers, for uploading a site to shared hosting or pulling files off old equipment. Plain FTP sends the password and the data unencrypted; wherever the server supports it, use <code>DialTLS</code>, which encrypts both the commands and the data with AUTH TLS.</p>
<p>Transfers go in passive mode (PASV or EPSV), which works from behind a firewall. The parsing functions, such as <code>ParseListLine</code>, are available for writing tools of your own too.</p>
>>
