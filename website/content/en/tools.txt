tools.cli_rows <<
<tr><td><code>salam check app.salam</code></td><td>Find errors fast: lex, parse and type-check without building</td></tr>
<tr><td><code>salam check app.salam --fix</code></td><td>Apply the safe fixes the compiler suggests (missing or unused imports, a needless <code>mut</code>, <code>return</code> written for <code>ret</code>) in place, then check again</td></tr>
<tr><td><code>salam test</code></td><td>Run the <code>test_</code> functions in every <code>*_test.salam</code> file, each file in its own process</td></tr>
<tr><td><code>salam run app.salam</code></td><td>Compile and run, without keeping the executable</td></tr>
<tr><td><code>salam exec app.salam</code></td><td>Run on the interpreter, with no C compiler needed</td></tr>
<tr><td><code>salam build app.salam</code></td><td>Build a native executable; add <code>--target</code> to cross compile</td></tr>
<tr><td><code>salam build app.salam --backend=native</code></td><td>Build with Salam's own x86-64 code generator, with no C compiler or LLVM involved</td></tr>
<tr><td><code>salam new myapp</code></td><td>Create a new project directory, with <code>--lang=fa</code> for a Persian one</td></tr>
<tr><td><code>salam format .</code></td><td>Format every Salam file in the directory</td></tr>
<tr><td><code>salam doc</code></td><td>Generate API documentation as an HTML page</td></tr>
<tr><td><code>salam lsp</code></td><td>The language server editors talk to for errors, completion and navigation as you type</td></tr>
<tr><td><code>salam serve</code></td><td>Serve a folder over HTTP, or with <code>--config=FILE</code> run several sites from one config file (virtual hosts, redirects, caching); <code>--test</code> only checks the file</td></tr>
<tr><td><code>salam sql check src --schema=migrations</code></td><td>Check every SQL query against the schema, without a database</td></tr>
<tr><td><code>salam sql generate q --schema=db</code></td><td>Generate typed query functions from annotated SQL files</td></tr>
<tr><td><code>salam web page.salam</code></td><td>Build a web page from the layout language and Salam scripts</td></tr>
<tr><td><code>salam js app.salam</code></td><td>Compile to JavaScript to run in the browser</td></tr>
<tr><td><code>salam cli</code></td><td>An interactive prompt for trying out snippets</td></tr>
<tr><td><code>salam debug app.salam</code></td><td>Build with debug information and open the debugger</td></tr>
>>
