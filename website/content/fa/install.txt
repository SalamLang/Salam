install.title = نصب زبان سلام
install.description = راهنمای نصب مترجم زبان برنامه‌نویسی سلام روی لینوکس، مک و ویندوز با یک فرمان، به همراه داکر و ساخت از کد منبع.

install.heading = نصب سلام
install.lead = مترجم سلام یک فایل اجرایی تنهاست. نصب‌کننده آن را در پوشه‌ی خانه‌ی شما می‌گذارد و به مسیر سیستم اضافه می‌کند؛ به دسترسی مدیر نیازی نیست.

install.unix_title = لینوکس و مک
install.unix_text = این فرمان را در پایانه اجرا کنید. نصب‌کننده سیستم‌عامل و معماری شما را خودش تشخیص می‌دهد و پوشه‌ی سلام را به مسیر سیستم (PATH) اضافه می‌کند؛ پس از نصب، یک پایانه‌ی تازه باز کنید.
install.unix_cmd = { curl -fsSL https://raw.githubusercontent.com/SalamLang/Salam/refs/heads/main/install.sh || wget -qO- https://raw.githubusercontent.com/SalamLang/Salam/refs/heads/main/install.sh; } | sh
install.unix_note = برای دادن گزینه به نصب‌کننده، آن‌ها را بعد از <code>sh -s --</code> بنویسید؛ مثلاً <code>… | sh -s -- --version 0.4.7</code>.

install.win_title = ویندوز
install.win_text = پاورشل را باز کنید و این فرمان را اجرا کنید.
install.win_cmd = irm https://raw.githubusercontent.com/SalamLang/Salam/refs/heads/main/install.ps1 | iex
install.win_cmd_alt_text = اگر پاورشل خطای اتصال امن داد، از خط فرمان (cmd) این نصب‌کننده را اجرا کنید:
install.win_cmd_alt = curl -fsSLo "%TEMP%\salam-install.bat" https://raw.githubusercontent.com/SalamLang/Salam/refs/heads/main/install.bat && "%TEMP%\salam-install.bat"

install.check_title = درستی نصب را بسنجید
install.check_text = پایانه را دوباره باز کنید و نسخه‌ی سلام را ببینید. اگر نسخه چاپ شد، همه‌چیز آماده است.
install.check_cmd = salam version

install.docker_title = داکر
install.docker_text = اگر نمی‌خواهید چیزی روی سیستم نصب کنید، سلام را در داکر اجرا کنید. پوشه‌ی جاری در کانتینر در دسترس است.
install.docker_cmd = docker run --rm -it -v "$PWD":/work -w /work basemax/salam run app.salam

install.source_title = ساخت از کد منبع
install.source_text = مترجم سلام با خود سلام نوشته شده است. برای ساختنش به یک نسخه‌ی نصب‌شده‌ی سلام و یک مترجم C نیاز دارید.
install.source_cmd = git clone https://github.com/SalamLang/Salam && cd Salam && sh tools/bash/build-selfhost.sh
