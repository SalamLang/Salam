<h2 id="build">ساخت خروجی وب</h2>
<p>فرمان <code>salam page build page.salam</code> پرونده را به <code>page.html</code> و <code>page.css</code> تبدیل می‌کند؛ اگر اسکریپت/رویداد داشته باشد <code>page.js</code> هم ساخته می‌شود. با <code>--inline</code> خروجی در یک فایل HTML خودبسنده قرار می‌گیرد. برای چند صفحه، مثل <code>salam page build home.salam about.salam</code>، برای هر صفحه یک HTML و یک <code>style.css</code> مشترک ساخته می‌شود. بدون نام فایل، معمولاً <code>main.salam</code> یا همه‌ی صفحه‌های پوشه ساخته می‌شوند.</p>
<p>سبک‌ها به کلاس‌های تولیدشده منتقل می‌شوند تا HTML تمیزتر و سبک‌ها قابل اشتراک باشند.</p>

<h2 id="events">رویدادها و DOM در مرورگر</h2>
<p>ویژگی‌های رویداد مانند <code>کلیک</code>، <code>ارسال</code>، <code>ورودی</code>، <code>تغییر</code> و ... به رفتار تعاملی در مرورگر نگاشت می‌شوند. تابع‌های سلام که به رویداد وصل می‌شوند در خروجی وب به اسکریپت صفحه تبدیل می‌شوند. برای کار با عنصرها در مرورگر می‌توان از APIهای DOM (مثل <code>دام.با شناسه</code>) در کد رویداد استفاده کرد.</p>
<p>درس‌های <a href="/learn/events-mouse/">رویدادهای موس</a> تا <a href="/learn/events-dom/">حالت، DOM و زمان‌سنج‌ها</a> این بخش را کامل پوشش می‌دهند.</p>

<h2 id="runtime">صفحه‌های پارامتردار و رندر در زمان اجرا</h2>
<p>صفحه‌های پارامتردار می‌توانند در زمان اجرا HTML تولید کنند و با داده‌ی هر درخواست پر شوند. این برای سرورهای وب سلام مناسب است. مقدارهای متنی هنگام درج امن‌سازی می‌شوند تا محتوای کاربر به کد/نشانه‌گذاری تبدیل نشود. برای مقدارهای حساس/ساختاری (نشانی، رنگ، اندازه و ...) از اعتبارسنجی/تبدیل امن مناسب استفاده کنید.</p>
