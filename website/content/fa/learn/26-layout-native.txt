<h2 id="run">اجرا و ساخت بومی</h2>
<p>برای اجرای یک صفحه به‌صورت پنجره‌ی بومی:</p>
<pre class="code snip" dir="ltr"><code>salam run app.salam --ui=native
salam build app.salam --ui=native</code></pre>
<p><code>run</code> برنامه را اجرا می‌کند و <code>build</code> خروجی اجرایی بومی می‌سازد. این مسیر از همان DSL صفحه استفاده می‌کند، اما خروجی آن برنامه‌ی گرافیکی بومی است نه فایل‌های HTML/CSS/JS مرورگر.</p>

<h2 id="common">چه چیزهایی مثل وب است؟</h2>
<ul>
<li>ساختار درختی صفحه، عنصرها و تودرتویی</li>
<li>ویژگی‌ها و سبک‌های نوشتاری (شامل مقدارهای ساده‌تر مثل <code>50%</code> و <code>#hex</code>)</li>
<li>بخش‌ها (<code>component</code>/<code>بخش</code>)، پارامترها، شرط‌ها/حلقه‌ها در الگوهای پویا و الگوی کلی DSL</li>
</ul>
<p>هدف این است که بخش زیادی از توصیف رابط قابل اشتراک باشد، اما رفتار زمان اجرا و پشتیبانی قابلیت‌ها به موتور هدف وابسته است.</p>

<h2 id="differences">تفاوت‌ها و محدودیت‌ها نسبت به وب</h2>
<p>محیط بومی مرورگر نیست، بنابراین قابلیت‌های مخصوص وب ممکن است در دسترس نباشند یا متفاوت باشند. برای نمونه، عنصرها/قابلیت‌هایی که به DOM/مرورگر وابسته‌اند (مثل اسکریپت خام مرورگر، iframe، برخی رسانه‌ها/قابلیت‌های وب، یا APIهای مخصوص سند HTML) در مسیر بومی معنی یکسانی ندارند. مترجم می‌تواند برای موارد ناسازگار در هدف بومی خطا یا هشدار بدهد.</p>
<p>برای UI تعاملی بومی، از الگوها و قابلیت‌های پشتیبانی‌شده‌ی موتور رابط سلام استفاده کنید و در صورت نیاز منطق برنامه را در کد Salam نگه دارید.</p>

<h2 id="paths">مسیرهای دسکتاپ در سلام</h2>
<ul>
<li><strong>DSL بومی (<code>--ui=native</code>):</strong> رابط توسط موتور Salam رسم می‌شود؛ مناسب وقتی می‌خواهید بدون وابستگی به مرورگر یک UI بومی داشته باشید.</li>
<li><strong>WebView (<a href="/std/gui/webview/">gui.webview</a>):</strong> پنجره‌ی بومی که محتوای HTML/CSS/JS را نمایش می‌دهد (مدل شبیه Tauri/Electron)؛ برای زمانی که می‌خواهید از فناوری وب داخل پنجره‌ی دسکتاپ استفاده کنید.</li>
<li><strong>کتابخانه‌های گرافیکی دیگر:</strong> مانند <a href="/std/gui-raylib/">gui.raylib</a> برای رندر/بازی و کاربردهای ویژه.</li>
</ul>

<div class="note"><p>اگر می‌خواهید صفحه را به‌صورت سایت/HTML خروجی بگیرید یا در مرورگر اجرا کنید، <a href="/learn/layout/web/">زبان صفحه در وب</a> را ببینید. برای API دسکتاپ WebView و بسته‌بندی، مستندات <a href="/std/gui/webview/">gui.webview</a> را مطالعه کنید.</p></div>
