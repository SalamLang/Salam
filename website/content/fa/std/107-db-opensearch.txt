<p>اپن سرچ یک موتور جستجو و تحلیل متن‌باز است. این بسته مستقیم و بدون هیچ کتابخانه‌ی بیرونی، با <code>net.tcp</code> و <code>tls</code> با API آن کار می‌کند: چند گره با تلاش دوباره و کنار گذاشتن گره از کار افتاده، احراز هویت پایه، توکن حامل و امضای AWS SigV4 (برای Amazon OpenSearch Service و Serverless) و TLS با پرونده‌ی CA خودتان یا، برای سرور آزمایشی، بدون وارسی گواهی. روی این‌ها سند، دسته‌ای، پرسمان‌ها و تجمیع‌های رایج، صفحه‌بندی با پیمایش و نقطه‌ی زمانی، مدیریت نمایه، نام مستعار، الگو و جریان داده، مدیریت خوشه، کار، تصویر لحظه‌ای و خط لوله را پوشش می‌دهد و افزونه‌هایی که اپن سرچ را اپن سرچ می‌کنند: SQL و PPL، جستجوی k-NN و عصبی، خط لوله‌ی جستجوی ترکیبی، سیاست‌های ISM، افزونه‌ی امنیت، پایشگرهای هشدار و ML Commons.</p>
<p>پرسمان‌ها، تجمیع‌ها و بدنه‌ی درخواست‌ها متن ساده‌ی JSON هستند: سازنده‌هایی مثل <code>تطبیق</code>، <code>پرسمان منطقی ساخته</code> و <code>تجمیع واژه‌ها</code> آن را برمی‌گردانند و هر چه را پوشش نمی‌دهند می‌شود با رشته‌ی بک‌تیک نوشت. نتیجه‌ها ساختارهای سلام هستند و بخش‌های JSON آن‌ها (منبع یک یافته، تجمیع‌ها) متن خام‌اند که با <code>سطل‌ها</code>، <code>مقدار تجمیع</code> و <code>مسیر جیسون</code> خوانده می‌شوند. هر فراخوانی وضعیت و خطای خود را روی کارخواه ثبت می‌کند؛ پس از فراخوانی‌ای که نادرست برگرداند <code>خطا</code> یا <code>نوع خطا</code> را بخوانید. <code>اتصال عمومی</code> کارخواه را به شکل <code>اتصال</code> دیتابیس درمی‌آورد تا کد SQL نوشته‌شده برای موتورهای دیگر از اپن سرچ هم پرسمان کند. برای مسیری که تابع جداگانه ندارد <code>انجام</code> را به کار ببرید. فقط نمونه‌های سازنده‌های پرسمان و امضای درخواست این‌جا اجرا می‌شوند؛ بقیه به سرور نیاز دارند و فقط بررسی می‌شوند.</p>
<p><a href="../db-elasticsearch/">الستیک سرچ</a> هم با API پایه‌ی اپن سرچ کار می‌کند. هر جا به چیزی نیاز دارید که فقط اپن سرچ دارد این بسته را به کار ببرید: PPL، جستجوی k-NN، عصبی و ترکیبی، ISM، افزونه‌ی امنیت، هشدار، ML Commons یا امضای AWS SigV4 برای Amazon OpenSearch Service و Serverless.</p>
