pkg.intro <<
<p>فست‌سی‌جی‌آی همان پروتکلی است که php-fpm و <code>php-cgi -b</code> می‌فهمند و این بسته یک کارخواه برای آن است. سرور وب در <a href="/std/net-httpd/">net/httpd</a> برای تنظیم <code>fastcgi_pass</code> از همین بسته استفاده می‌کند؛ خودتان هم می‌توانید مستقیم از آن استفاده کنید وقتی برنامه‌ای باید یک درخواست را به یک اسکریپت PHP بسپارد.</p>
<p>یک درخواست فهرستی از متغیرهای CGI و یک بدنه است. <code>NewParams</code> فهرست را می‌سازد، <code>Add</code> آن را پر می‌کند، <code>Connect</code> اتصال TCP به پشتیبان باز می‌کند و <code>Execute</code> همه را می‌فرستد و منتظر پاسخ می‌ماند. پاسخ وضعیت، همه‌ی سرآیندها به همان ترتیبی که پشتیبان فرستاده و بدنه را به‌صورت اشاره‌گر و طول نگه می‌دارد، پس تصویر یا فایل فشرده سالم برمی‌گردد.</p>
<pre><code>// lang: en
package main

import net.fastcgi
import net.tcp

func main:
    p := fastcgi.NewParams()
    defer fastcgi.Free(p)
    fastcgi.Add(p, "GATEWAY_INTERFACE", "CGI/1.1")
    fastcgi.Add(p, "REQUEST_METHOD", "GET")
    fastcgi.Add(p, "SCRIPT_NAME", "/index.php")
    fastcgi.Add(p, "SCRIPT_FILENAME", "/srv/app/index.php")
    fastcgi.Add(p, "QUERY_STRING", "a=1")

    c := fastcgi.Connect("127.0.0.1", 9000, 5000)
    if not tcp.ConnOk(c):
        println "cannot reach the FastCGI backend"
        ret 1
    end
    defer tcp.Close(c)

    r := fastcgi.Execute(c, p, null, 0, 5000)
    if not r.ok:
        println "the request failed: ", r.error
        ret 1
    end
    println r.status, " ", r.len, " bytes"
    fastcgi.FreeResponse(r)
    ret 0
end</code></pre>
<p>هر اتصال یک درخواست را می‌برد، که همان چیزی است که php-fpm از یک جلوی ساده انتظار دارد. زمان‌سنج به میلی‌ثانیه است و کل تبادل را در بر می‌گیرد، از اتصال هم؛ صفر یعنی ۳۰ ثانیه. پشتیبانی که اتصال را زود ببندد، پاسخی که بلوک سرآیند نداشته باشد یا خطای پروتکل به‌صورت <code>ok = false</code> و پیام در <code>error</code> برمی‌گردد، نه به‌صورت از کار افتادن برنامه.</p>
<p>چیزهایی که مردم اشتباه می‌کنند:</p>
<ul>
<li><code>Execute</code> بدنه را به‌صورت اشاره‌گر و طول می‌گیرد. وقتی بدنه‌ای نیست <code>null</code> و <code>0</code> بدهید؛ رشته‌ی خالی اشاره‌گر نیست.</li>
<li><code>Add</code> نام و مقدار را کپی می‌کند، پس رشته‌ی موقت را می‌توانید بلافاصله بعد از <code>Add</code> آزاد کنید و <code>Free</code> همه‌ی کپی‌ها را آزاد می‌کند.</li>
<li>بدنه‌ی پاسخ متعلق به پاسخ است: وقتی کارتان تمام شد <code>FreeResponse</code> را صدا بزنید، وگرنه بافر آزاد نمی‌شود.</li>
<li>نشانی TCP است. php-fpm باید روی یک درگاه مثل <code>127.0.0.1:9000</code> گوش بدهد، نه روی سوکت یونیکس، و پر کردن متغیرهای CGI با شماست: پشتیبان دست‌کم به <code>SCRIPT_FILENAME</code> و <code>REQUEST_METHOD</code> نیاز دارد تا پاسخ بدهد.</li>
<li>خروجی خطای پشتیبان خطا نیست. یک اخطار PHP روی stderr درخواست را خراب نمی‌کند؛ فقط پاسخ شکسته یا نبودِ پاسخ این کار را می‌کند.</li>
</ul>
